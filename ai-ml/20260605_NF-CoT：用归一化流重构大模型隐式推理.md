论文 : Latent Reasoning with Normalizing Flows链接 : https://arxiv.org/abs/2606.06447显式思维链（Chain-of-Thought, CoT）虽然有效，但把复杂的中间计算强行塞进离散的文本 Token 中，不仅效率低下，还容易受限于语言的表达能力。现有的隐式推理方案要么牺牲了采样能力，要么依赖昂贵的迭代去噪。这篇论文提出的 NF-CoT，试图在保持大语言模型原生自回归解码优势的同时，用连续向量实现高效、可微的“脑内思考”。
### 现有方案的痛点目前的推理增强方法主要分为两类：显式 CoT 和隐式推理。
- 显式 CoT：将推理过程转化为自然语言。这导致信息密度极低，模型必须逐词生成冗长的中间步骤，且受限于 Token 的离散性。
- 隐式推理：试图用连续向量替代文本。
像 Coconut 这样的方法直接复用隐藏状态，但它们是确定性的，无法定义推理路径的概率分布，也就失去了采样多样性。
- 像 LaDiR 这样基于扩散模型的方法虽然引入了随机性，但需要多次迭代去噪，缺乏原生的从左到右的似然建模能力，且难以兼容现有的 KV Cache 解码接口。
核心矛盾在于：我们想要连续状态的高带宽和灵活性，又不想放弃自回归语言模型在采样、评分和解码上的工程便利性。
### NF-CoT 的核心设计直觉NF-CoT 的核心 Insight 是： 与其强行让扩散模型去拟合推理分布，不如构建一个专门面向 LLM 的连续思维空间，并通过归一化流（Normalizing Flow）建立其与显式 CoT 之间的可逆映射。
具体设计分为三层：
-双空间映射：
首先通过冻结的 VAE 编码器将显式 CoT 压缩为连续目标 ee。
- 引入浅层归一化流块，将 ee 映射到一个新的、更易于自回归采样的“LLM 友好”空间 uu。这个变换是可逆的，保证了信息无损。
-统一因果架构：
LLM 骨干网络同时处理连续思维 uu 和离散文本答案。
- 在思维位置，使用 NF Head 输出高斯分布参数（均值和方差），实现从左到右的连续向量采样。
- 在答案位置，使用标准的 LM Head 生成 Token。
- 关键在于，两者共享同一个因果流和 KV Cache，这意味着隐式推理可以无缝接入现有的推理引擎，无需重构解码逻辑。
-可微的优化接口：
由于归一化流提供了精确的似然估计，NF-CoT 可以直接在连续空间计算梯度。
- 这不仅支持监督微调（SFT），还允许直接应用策略梯度（Policy Gradient）进行强化学习（RL）。这是基于扩散模型的隐式推理难以做到的，因为后者缺乏直接的轨迹似然。
### 关键实验结果论文在代码生成基准上展示了 NF-CoT 的显著优势。以下是基于 Qwen3-8B-Base 的结果对比：
方法 MBPP Pass@1 HumanEval Pass@1 LCB v6 Pass@1 Base Model 60.5 42.0 17.7 Standard SFT 63.3 (+2.8) 45.5 (+3.5) 21.3 (+3.6) LaDiR (Diffusion) 73.2 (+12.7) 60.4 (+18.4) 21.4 (+3.7) NF-CoT (Unified) 85.8 (+25.3) 77.5 (+35.5) 25.1 (+7.4)
- 精度提升：NF-CoT 在 HumanEval 上比基线提升了 35.5%，远超 LaDiR 的 18.4%。
- 推理效率：这是工程落地的关键指标。LaDiR 需要 30 步去噪，而 NF-CoT 只需一次自回归采样。
HumanEval 上，NF-CoT 的总体推理时间仅为 LaDiR 的 53.7%（325.6s vs 625.3s）。
- 每样本计算量（FLOPs）降低了 59.4%（19.9T vs 49.3T）。
⚠️ 反直觉发现 ：在强化学习阶段，传统的 Token 空间 GRPO 往往会导致概率质量坍缩，使得 pass@k 随 k 增大不再提升。但 NF-CoT 在连续空间进行 RL 后，不仅提升了 pass@1，还保持了 pass@k 的上升趋势。这说明连续空间的策略梯度能更好地维持推理路径的多样性，而不是陷入局部最优。
### 工程启示与局限对于工程师而言，NF-CoT 的最大价值在于它提供了一种**“即插即用”的隐式推理接口**。你不需要重写推理引擎来支持扩散采样，现有的 vLLM 等框架只需稍作适配即可复用 KV Cache。
此外，精确的似然估计使得我们可以对“思维过程”本身进行打分和优化，这为后续的 Agent 规划提供了更细粒度的控制手段。
当然，局限依然存在：
- 可解释性差：连续向量无法像文本 CoT 那样直接阅读，解码后的文本仅是定性探针，而非真实的推理日志。
- 依赖验证器：目前的 RL 优化依赖代码执行的单元测试反馈，对于没有明确正确性判据的任务（如创意写作），如何设计奖励函数仍是挑战。
NF-CoT 证明了归一化流不仅是生成图像的工具，更是连接离散语言与连续思维的高效桥梁。随着自回归流技术的成熟，隐式推理有望成为大模型的标准配置。
