论文 : Late-Layer Fusion is Enough: Dual-Path Vision Token Routing for Multimodal Large Language Models under Visual Saturation链接 : https://arxiv.org/abs/2606.09131现在的多模态大语言模型（MLLM）有个“偷懒”的默认设定：不管你是图像还是文本，统统塞进同一个深层 Transformer 里跑完全程。这种对称架构简单粗暴，但真的合理吗？
这篇来自北大和清华的工作直接挑战了这个共识。作者发现，在 LLaVA-1.5 中，视觉 Token 在中间层就已经“饱和”了，继续让它们穿过深层网络纯属浪费算力。
### 痛点：视觉饱和与计算冗余通过对 LLaVA-1.5-7B 进行逐层分析，作者揭示了模态演化的异步性：
- 注意力断崖：文本对图像的注意力质量（Text-to-image attention mass）在第 0 层高达 0.68，到第 4 层骤降至 0.07，之后稳定在 0.04 左右。
- 状态停滞：视觉 Token 的相邻层余弦相似度始终高于 0.92，意味着深层更新几乎没带来什么新信息。
- 预测提前完成：通过 Logit-lens 分析，视觉 Token 在第 22 层就进入了预测空间，比文本 Token（第 23 层）还早一层。
⚠️ 核心洞察 ：深层网络主要服务于文本的语义组合推理，而视觉表征在浅层就已稳定。让视觉 Token 强行穿过深层，不仅计算冗余，还可能扰动已捕捉到的感知信息。
### 方法拆解：DPVR-LF（晚期融合）
基于上述发现，作者提出了 双路径视觉 Token 路由（Dual-Path Vision Token Routing, DPVR） ，其核心实现是 DPVR-LF 。
设计非常极简且巧妙：
- 分流：在视觉饱和点（7B 模型选第 18 层），将视觉 Token 路由到一个仅含 单层 的可训练旁路分支。
- 跳过：文本 Token 继续通过剩余的深层网络（如 7B 模型的 13 层），但完全跳过图像位置的计算。
- 晚期融合：仅在最后一层，将旁路的视觉表征与文本流重新组装，进行一次完整的注意力计算。
为什么只要一层旁路？
实验表明，旁路深度 dv=1d_v=1 ​ = 1 时性能即达到饱和。增加更多层不仅无益，反而可能因过拟合浅层特征而损害长尾推理能力。
梯度怎么传？
如果完全切断视觉与深层网络的联系，梯度将无法回传。DPVR-LF 的精髓在于最后一层的融合：文本 Query 关注图像 Key/Value，从而建立了一条有效的梯度反传路径。虽然这只有全量注意力的约 5% 梯度密度，但配合两倍的学习率（1e-4 vs 5e-5），足以训练出高性能模型。
### 关键结果：少即是多在 LLaVA-1.5-7B 上，DPVR-LF 仅使用 3% 的可训练参数（202M），就实现了惊人的效果：

- 鲁棒性：分流点 ss 在 [18, 24] 区间内性能波动小于 0.1 pp，说明该方法对超参不敏感，工程落地友好。
### 工程启示- 打破对称迷思：不要默认所有 Token 都需要同等深度的处理。针对模态特性进行架构裁剪，是提升 MLLM 效率的关键方向。
- 晚期融合足够强：对于大多数感知任务，最后一层的单次图文交互足以维持竞争力。这为设计轻量级多模态适配器提供了新思路。
- 微调策略优化：如果你在做 MLLM 的微调，可以尝试冻结深层视觉计算，仅训练浅层旁路和最后融合层，既能节省显存和算力，又能保持性能。
### 局限与展望尽管 DPVR-LF 表现优异，但在涉及多图关系推理（BLINK -2.0 pp）和跨语言图文对齐（MMBench-CN -1.9 pp）的任务上略有下降。这说明对于极度依赖深层跨模态交互的复杂任务，单一的晚期融合可能信息量不足。
未来工作可以将这种路由机制与 Token 压缩技术结合，进一步压榨推理延迟。但对��大多数日常应用，DPVR-LF 已经证明了： 在视觉饱和的世界里，跑得快比跑得深更重要。
