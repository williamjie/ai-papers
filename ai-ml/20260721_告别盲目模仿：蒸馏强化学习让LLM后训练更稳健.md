# ⭐⭐ 告别盲目模仿：蒸馏强化学习让LLM后训练更稳健

**日期**: 2026-07-21

---

论文 : Distilled Reinforcement Learning for LLM Post-training链接 : https://arxiv.org/abs/2607.17247大模型后训练（Post-training）现在卷得厉害，大家都在纠结：到底是用强化学习（RL）搞探索，还是用在线策略蒸馏（OPD）搞模仿？
这篇来自南开大学和北京中关村院的论文，直接给出了一个“既要又要”的解法： Distilled RL 。它不玩虚的，把老师模型（Teacher）的监督信号直接揉进 RL 的梯度里。
对于工程落地来说，这意味着我们可能不再需要小心翼翼地平衡 KL 散度和 Reward Loss，而是用一种更精细的方式，让模型在探索中学会“正确地模仿”。
### 现有方案的死结目前的后训练主要有两条路，但都有硬伤：
- 纯强化学习（RL）：靠最终结果的奖励信号更新。
痛点：监督太粗粒度。一个长推理过程里，只有最后几个 Token 决定对错，前面的步骤很难获得有效反馈（Credit Assignment 问题）。而且 RL 很难让模型学到它原本“不知道”的新知识。
- 在线策略蒸馏（OPD）：让学生模仿老师的概率分布。
痛点：无条件模仿很危险。如果老师学生太像，学不到新东西；如果差别太大（比如跨家族模型），强行模仿会导致噪声极大，甚至让性能崩盘。
⚠️ 关键洞察 ：OPD 收敛快但后劲不足，RL 进步慢但能持续探索。简单的 Loss 加权（如 OPD+RL）往往因为 OPD 过早收敛到局部最优，导致 RL 信号失效。
### 方法拆解：把老师变成“选择性导师”
Distilled RL 的核心直觉是： 不要让学生无条件模仿老师，而是让老师只在学生做对的时候提供细粒度指导。
它通过三个机制重构了 RL 的目标函数：
-反向重要性采样（Reverse Importance Sampling）
传统 RL 是用旧策略校正新策略。这里反过来，计算老师策略相对于旧学生策略的重要性比率。
- Why：这能衡量老师对学生生成的每个 Token 的偏好程度，为后续的细粒度指导提供权重。
-负样本重置（Negative Sample Reset） —— 这是最反直觉但也最关键的设计如果一条轨迹的优势值（Advantage）是负的（即表现不好），直接忽略老师的指导，权重重置为 1。
- Why：当学生犯错时，如果强行模仿老师，可能会把学生推离正确的方向（特别是当老师也没法解决或分布差异大时）。负样本只保留原始的 RL 惩罚，避免“越帮越忙”。
-序列级几何归一化（Sequence-level Geometric Normalization）
对 Token 级别的权重进行几何平均归一化。
- Why：自回归概率是乘性的，直接累加比率会导致整个序列的梯度被系统性放大或缩小。归一化后，老师只改变 Token 之间的相对偏好，而不改变整体优化的强度。
### 关键结果：跨家族蒸馏的救星论文在数学推理（AIME, MATH500 等）和知识密集型任务上做了大量实验。最亮眼的结果是它在 跨家族蒸馏 场景下的表现。
模型 基线 (Base) OPD RL (GRPO) Distilled RL vs OPD 提升 DSQW-1.5B (跨家族) 31.70 35.27 36.86 40.00 +4.73 Qwen3-4B (同家族) 46.33 55.97 57.40 58.96 +2.99- 跨家族优势明显：在 DSQW-1.5B 上，传统的 OPD 甚至跑不过纯 RL（因为分布不匹配导致模仿失效）。而 Distilled RL 通过选择性指导，大幅超越了两者。
- 消融实验验证：去掉“负样本重置”，性能暴跌 8.81 分（Qwen3-4B）和 6.39 分（DSQW-1.5B）。这证实了在错误路径上模仿老师是有害的。
### 工程启示- 别盲目加 KL Loss：如果你发现加上蒸馏 Loss 后模型性能不再提升甚至下降，可能是陷入了局部最优。尝试将教师信号作为 RL 的权重因子，而不是独立的 Loss 项。
- 负样本要“冷处理”：在利用强模型指导弱模型时，不要试图纠正所有错误。只在正收益路径上引入教师偏好，能显著提升训练稳定性。
- 跨架构微调新希望：如果你要用一个开源大模型（如 Llama）去蒸馏另一个架构的模型（如 Qwen），传统 OPD 可能很难奏效。Distilled RL 提供了一条更稳健的路径。
### 局限与展望虽然效果显著，但该方法依赖于教师模型对 Token 级别的概率评估。如果教师模型本身存在严重的幻觉或置信度偏差，这种细粒度的指导可能会引入噪声。此外，几何归一化虽然在数学上优雅，但在极端长文本下的计算稳定性仍需更多工程验证。
总之，这篇论文提供了一个非常实用的视角： 蒸馏不是模仿，而是引导。 在 RL 的框架下嵌入这种选择性引导，可能是未来 LLM 后训练的一个标准范式。
