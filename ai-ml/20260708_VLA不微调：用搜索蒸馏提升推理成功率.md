# ⭐⭐⭐½ VLA不微调：用搜索蒸馏提升推理成功率

**日期**: 2026-07-08

---

论文 : Look Before You Leap: Distilling Tree Search into Action Evaluation for Frozen VLA Models链接 : https://arxiv.org/abs/2607.03751机器人领域的视觉-语言-动作（Vision-Language-Action, VLA）模型虽然通用性强，但在实际部署中往往“脆得像张纸”。
面对泛化性差的问题，主流做法是进行监督微调（SFT）或强化学习（RL）。但这不仅计算昂贵，还会破坏预训练阶段积累的通用能力。
这篇论文提供了一个极其务实的解法：既然模型里已经藏着正确的动作，为什么不加个“裁判”帮它挑出来？
### 核心洞察：VLA不是不会做，是挑不准作者做了一个简单的 pass@k 诊断实验，结果令人震惊。
当冻结的 VLA 被允许独立尝试多次时，成功率随着尝试次数 kk 的增加而飙升。在整体任务中，单次执行（pass@1）的成功率仅为 33%，但当 k=32k=32 32 时，成功率高达 92%。
反直觉发现 ：VLA 的失败往往不是因为“生成不出”正确动作，而是因为缺乏“评估能力”。高质量的动作已经存在于模型的输出分布中，模型只是无法在执行前将其与平庸或有害的动作区分开来。
这意味着，与其费力微调整个大模型，不如保留 VLA 作为“提案者”，外挂一个轻量级的“评估器”来做决策。
### SVA 框架：搜索、估值、行动作者提出了 SVA (Search, Value, and Act) 框架，核心逻辑是将昂贵的蒙特卡洛树搜索（MCTS）蒸馏成一个可部署的价值模型。
- Search（搜索）：在仿真环境中利用 MCTS 探索 VLA 的输出分布。通过有前瞻性的搜索，收集大量带有经验回报（return）的轨迹。这一步利用了“搜索”来挖掘高信息量的数据。
- Value（估值）：将 MCTS 获得的对比信号蒸馏到一个轻量级的 Q 值模型中。该模型基于小型 VLM（如 Qwen3.5-0.8B），通过 LoRA 适配器和 MLP 头预测候选动作的长期后果。
- Act（行动）：在部署时，冻结的 VLA 生成 NN 个候选动作，Q 模型根据不确定性正则化的 Q 值选出最优解。无需在线仿真，推理延迟极低。
这种设计巧妙地实现了“行动提案”与“后果评估”的解耦。VLA 保持通用性，评估器提供“三思而后行”的能力。
### 实验结果：小模型打败大模型SVA 在多个基准测试中表现优异，且具备极强的模型无关性。
1. EmbodiedBench 表现SVA 在所有测试的骨干网络上均带来显著提升：

2. 操控任务表现在 SimplerEnv 和 RoboTwin 2.0 等精细操控基准上：
- π0\pi_0​ + SVA 在 SimplerEnv 的平均成功率达到 50.7%，优于基于偏好模型的 RoboMonkey。
- 在 RoboTwin 上，π0.5\pi_{0.5}​ + SVA 平均提升 7.5%，超越基线 5.2 个百分点。
3. 推理效率与扩展性这是最让工程师兴奋的部分。通过增加候选动作数量 NN ，SVA 实现了测试时扩展（Test-Time Scaling）。
- 9B vs 27B：Qwen3.5-9B + SVA (best-of-8) 的成功率达到 53.6%，比单次推理的 Qwen3.5-27B (46.7%) 高出 7 个百分点。
- 延迟更低：9B + SVA 的推理延迟仅为 7.43s，比 27B 基线（10.2s）低了 27%。
这表明，扩大测试时的评估计算量，比单纯扩大模型参数规模更具成本效益。
### 工程启示对于正在落地 VLA 的团队，这篇论文提供了三条关键建议：
- 不要盲目微调：如果基线模型在 pass@k 实验中表现出潜力，优先尝试外挂评估器，而非直接 SFT/RL。
- 重视评估信号：VLA 的瓶颈往往在于“短视”。引入基于长期回报的价值函数，能有效纠正局部合理但全局失败的动作。
- 利用测试时计算：在机器人场景允许的微秒级延迟内，通过增加候选采样数 NN 进行动态扩展，是提升鲁棒性的低成本手段。
当然，该方法目前依赖可重置的仿真环境进行蒸馏，且尚未在物理机器人上进行大规模测试。但这并不妨碍它成为当前 VLA 推理优化的最佳实践之一。
