建议 README 里至少写清楚：和 Cosmos3 原版比，Edge 版本到底剪掉了多少层？量化到了 INT8 还是 FP16？别只放一个 arxiv 链接就完事。
## 数据集 Top 2### 1. ianncity/GLM-5.2-Conversation23 个赞、1277 下载，热度 16。名字带 “GLM-5.2”，让人以为是智谱 GLM 系列官方数据，结果点进去只有 10K–100K 条对话，且全是英文。一个中文大模型的中文对话数据集用英文标注？这数据集的来源怕是拿 GPT 生成的，然后打上 GLM 的旗号蹭流量。
数据规模不到 10 万条，对于对话模型来说连热身都不够——你让 GLM-5.2 用这数据微调，大概率学到的不是对话技巧，而是数据集的过拟合模式。
建议作者在 README 里诚实标注：“本数据集由某闭源模型生成，未经人工校验”，否则别怪别人拿它跑 benchmark 然后骂模型弱智。
### 2. greghavens/fable-5-coding-and-debugging-traces25 个赞、3002 下载，热度 15。机器生成的代码调试轨迹，听起来很酷：记录 IDE 里断点、变量值、堆栈信息，用来训练 AI 自动 debug。但仔细看，是 machine-generated，说白了就是模拟器跑出来的假日志。
真正的调试过程充满随机性、人类直觉和上下文跳跃，合成数据只能学到“按照固定模式加 print”的假 debug 技巧——用它训练出来的模型，遇到真实 bug 大概率只会复读“请检查第 42 行”。
不过 CC-BY-4.0 协议值得表扬，至少别人可以拿去魔改，但建议作者同时提供一份真实的人类调试日志作为验证集，否则这 3000 次下载里有多少是下了就删的？
## Spaces Top 1### 1. pliny-the-prompter/obliteratus459 个赞，0 下载（Space 没有下载量），热度 51。名字 “obliteratus” 拉丁语意为“抹除”，加上标签里的 “abliteration”（消融+抹除），大概率是一个可视化神经元消除的工具——让你看看去掉某个 attention head 后模型输出怎么变。

不过 Gradio 界面做得漂亮，点赞高说明社区喜欢这种“黑盒拆黑盒”的玩具。建议作者再加个功能：把消融结果导出成 JSON，方便研究者复现——别只让用户爽完就关掉。
