### 现有方案的痛点目前的自评估（Self-Evaluation）研究多集中在数学、代码等可验证任务上，目标通常是预测一个标量正确性得分。但在开放域对话中，没有标准答案，只有多维度的质量评分（如帮助性、连贯性等）。传统做法是通过大规模强化学习（RL）或监督微调（SFT）让模型学习裁判的偏好。这不仅数据昂贵，还容易破坏模型原有的回答能力。
### 核心 Insight：是“提取”而非“获取”
作者发现，未经任何针对性训练的 Qwen3-4B-Base 基座模型，在 Few-shot 提示下，对裁判多维评分的非线性校准度（Calibration）已达到 0.50~0.70，远高于随机猜测。这意味着预训练阶段已经让模型内化了某种质量表征。
基于此，作者提出了 Self-Evaluation Elicitation (SEE) 方法，核心设计非常巧妙：
- 校准耦合强化学习（Calibration-Coupled RL）：
奖励函数包含两部分：回答质量项 + 自评分与裁判分的校准项。
- 关键细节：校准项使用了非线性指数 γ>1\gamma > 11。线性奖励会让模型倾向于预测平均分以“混”奖励，而非线性惩罚迫使模型在高低分两端都逼近真实值。
- 掩码裁判蒸馏（Masked Judge Distillation）：
这是防止回答能力退化的关键。利用 RL 阶段产生的 Rollout，将 Loss 仅限制在自评估 Token 上，回答部分的 Token 不参与梯度更新。
- 这相当于把裁判的知识“注入”到模型的自评估通道，而不干扰其生成逻辑。
### 关键结果：极致的数据效率SEE 仅需 160 个唯一样本 （Unique Examples），约为传统 RL 基线数据的 1/31 。
指标 Qwen3-4B (Base) Adapted RLCR (~5k samples) SEE (160 samples) HelpSteer2 校准分 0.632 0.675 0.731 WildBench v2 校准分 0.504 0.541 0.609 Top-5 Token 命中率 77.07% - 87.76%- 跨裁判泛化：用 GPT-5.4 训练的模型，在面对 Claude Sonnet 和 Gemini 等未见过的裁判时，校准优势依然保持。说明模型学到的是通用的“质量概念”，而非特定裁判的偏见。
- 局部化精准：SEE 模型预测的正确评分有 87.76% 的概率落在其 Top-5 概率最高的 Token 中，这意味着自评估信号非常尖锐，可直接用于下游决策。
### 工程启示- 低成本部署自评估 Agent：对于资源有限的场景，无需训练独立的 Reward Model。只需对基座模型进行极小规模的 SEE 微调，即可赋予其可靠的自我打分能力。
- 推理时优化（Test-time Compute）：模型可以根据自评分决定策略。例如，当预测分数低于阈值时，自动触发重试或升级至更强模型；当预测高分时直接输出。这完全在本地完成，零额外 API 成本。
- 微调策略解耦：SEE 证明了“回答优化”和“评估校准”可以解耦训练。在后续微调中，若需增强特定能力而不影响其他维度，可借鉴这种 Masked Distillation 思路，限制 Loss 作用范围。
### 局限与展望目前实验仅基于单一基座模型（Qwen3-4B）和 LLM 裁判。虽然跨 LLM 裁判表现良好，但未进行人类评估验证。此外，160 样本的效果虽好，但在更大规模数据或更强基座上的扩展性仍有待探索。
总之，这篇论文打破了“自评估需要大量标注数据”的认知惯性。对于工程师而言，这意味着我们可以更轻量地构建具备自我反思能力的智能体，只需轻轻推一下门，能力便已存在。
