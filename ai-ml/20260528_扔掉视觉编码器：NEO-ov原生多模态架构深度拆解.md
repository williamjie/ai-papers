论文 : From Pixels to Words — Towards Native One-Vision Models at Scale链接 : https://arxiv.org/abs/2605.28820如果还要为视频理解、多图推理和空间感知分别维护不同的视觉编码器（Vision Encoder），那你的多模态架构可能已经过时了。NEO-ov 这篇论文的核心主张非常激进：彻底抛弃预训练的图像/视频编码器，让模型直接从像素中学习时空关系。这不仅是架构上的极简主义，更是对“模块化拼接”范式的一次有力反击。
### 为什么我们要扔掉视觉编码器？
目前的业界主流方案（如 LLaVA, Qwen-VL）大多采用“编码器-投影器-LLM”的模块化设计。这种设计虽然成熟，但存在三个无法回避的工程痛点：
- 灵活性缺失：图像编码器擅长静态语义，缺乏时空推理能力；视频编码器则过度强调时间动态，处理单图或多图混合输入时表现不佳。
- 效率瓶颈：模块化解耦导致训练碎片化，且由于 KV Cache 无法跨模态复用，长视频或高分辨率输入的推理成本极高。
- 扩展性受限：视觉编码器和 LLM 的能力需要精细平衡，随着模型规模扩大，这种“拼凑”带来的摩擦成本指数级上升。
NEO-ov 认为，真正的统一视觉基础模型（One-Vision Model）应该是一个单体架构（Monolithic Architecture），在同一个骨干网络中端到端地学习像素与词的对应关系。
### 核心设计：原生注意力与时空解耦NEO-ov 的技术直觉在于： 不要压缩视觉信号，而是让交互尽早发生。
传统方案在编码器阶段就丢弃了纹理、局部几何等细粒度信息，而 NEO-ov 通过轻量级的 Patch Embedding 层（两个卷积层）将原始图像直接转化为 Token 序列，并保留在统一的 Decoder-only Transformer 中。其关键创新点在于 T-H-W 解耦的注意力机制 ：
- T (Temporal)：建模文本顺序、多图关系和跨帧依赖。
- H/W (Spatial)：专门捕获 2D 空间结构。
Query 和 Key 被定义为 qi=[qiT;qiH;qiW]q_i = [q^T_i; q^H_i; q^W_i] ​ = [ q i T ​ ; q i H ​ ; q i W ​ ] ，相关系数计算为各维度内积之和。这意味着模型在浅层就能进行像素级的交互，而不是像传统方案那样，等到高层语义压缩后才开始跨模态对齐。此外， 原生旋转位置编码（Native-RoPE） 为时间索引和空间坐标分配了不同的频率基（ θT=106,θH/W=104\theta_T=10^6, \theta_{H/W}=10^4 ​ = 1 0 6 , θ H / W ​ = 1 0 4 ），使得模型能天然区分“这是第几帧”和“这在图片的哪个角落”。
对于视频输入，NEO-ov 不提取全局特征，而是将采样帧序列化为带有时间戳的独立视觉单元。同一视觉单元内双向注意力（密集空间交互），不同单元间自回归注意力（因果时序依赖）。这种设计让跨图比较和时序推理从浅层到深层逐步细化。
### 实验结果：原生架构真的能打吗？
很多人担心去掉预训练编码器会导致性能暴跌，但 NEO-ov 的数据证明，原生架构在特定任务上甚至优于模块化方案。
1. 通用视觉问答与 OCR (Table 1)
在 8B 参数规模下，NEO-ov 的表现极具竞争力：
- MMMU: 68.1 vs Qwen3-VL 的 69.6（差距极小）
- MMBench: 85.1 vs Qwen3-VL 的 84.5 (超越)
- HallusionBench: 76.6 vs Qwen3-VL 的 71.5 (显著超越，幻觉抑制更强)
2. 视频与多图理解 (Table 2)
原生架构在处理时序任务时展现出巨大潜力：
- VideoMME: NEO-ov (8B) 达到 70.7，大幅领先其他原生模型（如 EVE 的 34.9），甚至接近模块化强基线。
- MLVU: 69.3，优于 InternVL3.5 (66.0)。

这是 NEO-ov 的绝对优势区。由于保留了细粒度几何信息：
- Mindcube-tiny: NEO-ov (8B) 达到 90.0，远超 Qwen3-VL (29.6) 和 InternVL3.5 (40.4)。

### 工程启示与局限对工程师的意义：
- 推理优化新路径：由于没有独立的视觉编码器，整个模型是一个统一的 Transformer，理论上可以更高效地实现 KV Cache 复用和长上下文优化。
- 微调更简单：不需要担心视觉编码器和 LLM 之间的对齐漂移，端到端的 Next-Token Prediction 目标让监督微调（SFT）更加稳定。
- 空间任务首选：如果你的应用场景涉及几何推理、文档版面分析或细粒度物体定位，原生架构可能是比传统 VLM 更好的选择。
局限与展望：
论文也坦诚了当前的短板：
- OCR 密集型任务仍有差距：相比经过专门 OCR 预训练的模块化模型，NEO-ov 在复杂文档理解上仍需更多高质量数据。
- 数据规模依赖：原生架构对训练数据的质量和多样性要求更高，目前与顶级模块化系统（如 Qwen3-VL）在部分通用基准上仍有微小差距。
NEO-ov 证明了“从像素到词”的直接映射不仅是可行的，而且在细粒度感知和时空推理上具有独特优势。随着多模态数据规模的扩大，这种原生单体架构有望成为下一代视觉基础模型的主流范式。
