# ⭐⭐⭐½ VisCo：用LLM自身做视觉Token压缩，极压不降智

**日期**: 2026-07-27

---

论文 : VisCo: Leveraging Large Language Models as Intrinsic Encoders for Visual Token Compression链接 : https://arxiv.org/abs/2607.12756VLM 的推理瓶颈在于海量的视觉 Token。现有的压缩方案要么靠启发式规则剪枝，导致高压缩比下模型“降智”；要么外挂压缩模块，重训成本高且破坏原生架构。VisCo 提出了一种极客思路：别整那些花哨的外部模块，直接让 LLM 自己通过少量 Memory Token 来压缩视觉信息。这不仅保留了模型原有的先验知识，还实现了极致的参数共享与高效推理。
### 痛点：剪枝太脆，外挂太重目前的视觉 Token 压缩主要分为两派。第一派是无训练（Training-free）方案，如 FastV 或 SparseVLM。它们利用注意力分数或相似度来丢弃“不重要”的 Token。这种方法的致命伤是抗风险能力极差，一旦压缩比拉高，丢失关键细节会导致幻觉和性能雪崩。第二派是有训练（Training-based）方案，通常引入额外的编码器或复杂的对齐模块。这虽然提升了鲁棒性，但迫使 VLM 骨干网络去适应新的压缩机制，导致重训成本高昂，且失去了即插即用的灵活性。
VisCo 的核心洞察在于：预训练的 VLM 本身就已经具备了强大的信息编码能力，只是被现有的外部压缩手段给“埋没”了。与其强行让模型学习一套陌生的压缩规则，不如直接复用其内在的注意力先验，通过轻量级的适配实现自压缩。
### 方法拆解：非对称自编码器与分层 KV 传递VisCo 的设计非常精妙，它是一个基于参数共享的非对称自编码器（Autoencoder）。
1. 编码阶段：Memory Token 的“吸星大法”
在视觉编码阶段，VisCo 引入了一组可学习的 Memory Token。这些 Token 被放置在视觉 Token 序列之后，利用 LLM 原生的因果掩码机制，每个 Memory Token 都能自然地关注到前面的所有视觉信息。浅层网络负责提取纹理等低级特征，深层网络则捕捉抽象语义。最终，模型将这些分层提取出的 Key-Value (KV) 对存入“记忆库”，而不是传递最终的隐藏状态。
2. 解码阶段：直接复用，无需投影在解码生成阶段，VisCo 移除了编码阶段的 LoRA 适配器，直接使用预训练的 LLM 骨干。它将之前存储的分层 Memory KV 对作为前缀（Prefix）填入解码器的 KV Cache 中。由于编解码器共享参数，且 KV 缓存已经携带了精细的分层信息，解码器无需任何额外的投影层就能直接复用这些特征进行自回归生成。
这种设计的最大优势在于“轻”。它不需要重新学习多模态生成过程，只需对 Memory Token 和少量的 LoRA 参数进行微调即可。
### 关键结果：极端压缩下的降维打击VisCo 在多个基准测试中展现了惊人的鲁棒性，尤其是在高压缩比下，其优势呈指数级放大。
1. LLaVA-1.5-7B 上的表现（Table 1）
当将原始的 576 个视觉 Token 压缩至 32 个时：
- VisCo 保留了原模型 91.8% 的平均性能。
- 相比之下，无训练方案 FastV 仅保留 57.6%，即便是需要训练的 PruMerge+ 也仅为 77.5%。
- VisCo 在 GQA、MMB-CN 等 4 个基准上均取得了最佳成绩。

当压缩至仅保留 1 个 Token 时，VisCo 依然保留了原模型 85.3% 的性能。这一结果远超 PruMerge+ (35.4%) 和 VisPruner (48.8%)，甚至在部分指标上超越了需要大规模重训的强基线 VoCo-LLaMA。

反直觉发现 : VisCo 学习到的 Memory Token 不仅仅是视觉信息的压缩版，它们甚至提供了互补的表征。实验显示，将 Memory Token 与原始视觉 Token 结合使用（VisCo+），其性能竟然 超过 了原始模型本身。这说明这种自压缩机制挖掘出了原模型未充分利用的特征维度。
### 工程启示：多轮对话的效率王者对于工程师而言，VisCo 的价值不仅在于精度，更在于推理效率。
- KV Cache 复用：FastV 等方法需要根据每个问题重新计算注意力并剪枝。而 VisCo 只需对图像压缩一次，生成的 Memory KV 缓存可以在多轮对话中反复使用。
- 长尾收益：在 MMVet 的长文本生成场景中，VisCo 的解码速度与基线持平，但总推理时间更短。在多轮问答场景下（如图 7），经过三轮对话后，VisCo 的平均响应时间显著低于 FastV。
### 局限与展望VisCo 目前主要依赖固定的 Memory Token 数量，且早期 Token 对主体物体的关注度远高于后期 Token（负责背景和细节）。这意味着在资源极度受限的嵌入式设备上，如何动态分配 Token 预算以平衡全局语义与局部细节，仍是值得探索的方向。此外，虽然其在图像上表现优异，但在视频压缩等高维时序任务上的迁移效果尚待验证。
