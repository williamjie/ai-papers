# ⭐⭐⭐½ 用反馈蒸馏替代GRPO，让LLM学会形式化证明

**日期**: 2026-06-11

---

论文 : Distilling LLM Feedback for Lean Theorem Proving链接 : https://arxiv.org/abs/2605.30861在形式化定理证明（如 Lean 4）中，传统的监督微调（SFT）加强化学习（RL）范式正面临瓶颈。Meta FAIR 团队提出的“反馈蒸馏”（Feedback Distillation）提供了一条新路径：不再依赖稀疏的轨迹级奖励，而是将外部模型的细粒度反馈直接内化为模型权重。
这种方法不仅解决了 GRPO 算法常见的模式崩溃问题，还显著提升了策略熵和测试时缩放能力。对于正在探索复杂推理任务微调方案的工程师来说，这是一篇值得深入拆解的工作。
### 现有方案的痛点：GRPO 的“虚假繁荣”
目前主流的后训练流程是 SFT + GRPO（Group Relative Policy Optimization）。虽然 GRPO 在数学推理上表现强劲，但论文指出其存在三个致命缺陷：
- 奖励稀疏：只有当证明完全正确时才能获得奖励，中间步骤的错误无法得到细粒度信号。
- 探索受限与模式崩溃：GRPO 倾向于收敛到训练前已存在的高奖励模式，而非真正激发新的推理能力。这导致模型在探索大型引理库（如 Mathlib）时缺乏多样性。
- 灾难性遗忘：SFT 阶段基于离线专家演示，容易导致模型在非微调分布上的性能下降。
核心洞察 ：我们需要一种既能提供细粒度信用分配（Credit Assignment），又能保持策略多样性的训练机制。
### 方法拆解：把“批评”变成“本能”
反馈蒸馏的核心思想源自自蒸馏（Self-Distillation），但引入了一个关键变量： 特权反馈 。
具体流程如下：
- 学生模型生成：给定题目 xx，学生模型 πθ\pi_\theta​ 生成尝试证明 yy。
- 获取反馈：将 yy、题目及验证器输出发送给反馈模型（如 Claude 或冻结的学生副本），生成文本反馈 F(y)F(y)。例如：“使用 Real.pi 而非 Unicode 符号 π\pi”。
- 教师条件分布：教师模型 πμ\pi_\mu​（通过指数移动平均 EMA 更新）在包含反馈 F(y)F(y) 的条件下重新生成该序列的概率分布。
- Token 级蒸馏：最小化学生与教师在每个 token 上的 KL 散度。
为什么这么设计？
- 细粒度信号：不同于 GRPO 对整个轨迹打分，反馈蒸馏在每�� token 位置都提供了监督信号。如果教师认为某个步骤错误，学生会立即调整该位置的词元概率。
- 知识内化：通过蒸馏，模型学会了“如何响应批评”，最终无需外部提示即可表现出更优的推理行为。论文实验显示，当反馈固定为“Be concise”时，模型生成长度显著缩短，证明反馈确实被写入了权重。
### 关键结果：多样性与性能的平衡论文在 LeanWorkbook 和 MiniF2F 基准上进行了评估，主要对比了 GRPO、反馈蒸馏以及两者的组合。

关键发现：
- 互补性：用反馈蒸馏的检查点初始化 GRPO，性能优于单独使用任一方法。FD 提供了良好的初始多样性和知识基础，GRPO 在此基础上进一步微调。
- 多样性优势：FD 维持了更高的策略熵。在 pass@1 相同的情况下，FD 的 pass@k 随 kk 增加而显著提升，证明其生成了更多样且高质量的候选解，而非均匀噪声。
- 样本效率：在训练初期，FD 比 GRPO 更节省样本。GRPO 需要更大的 batch size（5倍于 FD）才能稳定训练。
### 工程启示- 反馈源的选择：使用强模型（如 Claude）提供的自然语言反馈优于原始编译器错误信息或地面真值证明。前者能提供策略层面的指导，后者仅纠正语法或最终结果。
- EMA 的重要性：教师模型必须通过 EMA 缓慢跟踪学生，否则会导致训练不稳定。论文建议 α=0.9\alpha=0.90.9 作为平衡点。
- 自反馈蒸馏（Self-Feedback）：即使不使用外部强模型，仅用冻结的学生副本提供反馈，也能提升 GRPO 的最终性能。这意味着“自我反思”机制本身具有价值。
### 局限与展望尽管结果令人鼓舞，但方法仍存在挑战：
- 训练不稳定性：FD 和 FD+GRPO 在长期训练中仍可能出现崩溃，需要更鲁棒的稳定机制。
- 计算开销：虽然每步时间少于 GRPO（300s vs 550s），但需要额外的反馈模型调用或冻结副本推理，增加了系统复杂度。
总的来说，反馈蒸馏为复杂推理任务的微调提供了一种优雅的解决方案：它不依赖昂贵的专家数据生成，也不受限于稀疏奖励，而是通过“教模型如何从批评中学习”，实现了性能与多样性的双赢。对于构建本地化、高可靠性的数学推理 Agent 具有重要参考价值。
