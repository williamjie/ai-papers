# 让多模态模型在模糊图像下也能推理

**日期**: 2026-05-12

---

论文 : Reinforcing Multimodal Reasoning Against Visual Degradation链接 : https://arxiv.org/abs/2605.09262如果你刚用强化学习（Reinforcement Learning, RL）微调完一个多模态大语言模型（Multimodal Large Language Model, MLLM），并为此沾沾自喜于其在清晰测试集上的高分，那么这篇来自腾讯混元团队的文章可能会给你泼一盆冷水： 现实世界里的图片，往往没那么干净。
论文指出，现有的 RL 微调方法（如 GRPO）虽然能提升推理能力，但模型对视觉退化（模糊、压缩伪影、低分辨率扫描）极其脆弱。这种“洁癖”是部署的一大障碍。作者提出了 ROMA 框架，核心思路不是简单地在训练数据里加噪，而是从优化动力学层面解决“奖励中毒”问题。
### 为什么现有方案不行？
在传统的深度 RL 或视觉领域，提升鲁棒性通常靠数据增强（Data Augmentation）或值函数正则化。但在 MLLM 的 RL 微调中，这两条路都走不通：
- 架构不匹配：现代 MLLM 微调多用无 Critic（critic-free）算法（如 GRPO），传统的基于值网络的正则化无法直接应用。
- 奖励中毒（Reward Poisoning）：这是最致命的。如果直接在退化图像上进行 Rollout（轨迹采样），模型会因为看不清图片而“幻觉”出错误的推理路径，导致奖励信号惩罚的是感知失败而非推理错误，最终导致策略崩溃。
ROMA 的核心 Insight 在于： 不要在退化图像上采样新轨迹，而是复用干净图像生成的轨迹，去评估模型在退化视角下的表现。
### 方法拆解：ROMA 怎么做到“稳”的？
ROMA 的设计非常精巧，它通过一个**双前向传播（Dual-Forward-Pass）**策略，配合三个正则化项，在不增加推理成本的前提下增强鲁棒性。
1. 双前向传播策略第一步，在干净图像上进行标准的 RL Rollout，得到推理轨迹 yy 和优势值 AA 。
第二步，冻结这个轨迹 yy ，对同一张图像应用多种退化增强（如模糊、噪声），通过 Teacher Forcing 计算模型在这些退化视图下的 Token 概率。
- 关键点：因为轨迹 yy 是在干净图像上生成的，所以它本身是正确的（或至少是逻辑自洽的）。我们只观察模型在“看不清”时，是否还愿意坚持这个正确的推理路径。这从构造上避免了 Reward Poisoning。
2. 三个核心正则化项ROMA 的损失函数由三部分组成，缺一不可：
-最坏情况不变性惩罚（Worst-Case Invariance Penalty）：
对生成的 KK 个退化视图，计算 Token 级别的 KL 散度，只惩罚与干净视图分布差异最大的那个视图（Minimax 策略）。这迫使模型对抗最难的退化情况，而不是平均地适应轻微噪声。

-辅助策略梯度损失（Auxiliary Policy Gradient Loss）：
仅靠 KL 惩罚会导致模型变成“一致性错误”（Consistently Incorrect），即虽然输出一致，但全是胡话。因此，作者在退化视图上计算一个裁剪后的策略梯度损失，但优势值 AA 依然锚定在干净图像的 Rollout 结果上。这提供了直接的强化信号，告诉模型：“即使图片模糊，也要往这个正确的方向猜”。
-正确性条件正则化（Correctness-Conditioned Regularization）：
这是一个防呆设计。只有当干净图像上的推理轨迹是正确的（Reward > 0）时，才施加上述惩罚。如果原轨迹本身就是错的，强行让它对退化图像也保持“一致”，只会加速错误逻辑的传播。
### 关键结果：数字不会撒谎作者在 Qwen3-VL 4B/8B 上进行了验证，对比基线包括 Base Model 和标准 GRPO。
主要表现（8B 模型）：
场景 Clean Accuracy Seen Degradation Unseen Degradation Base 66.8% 58.9% (-7.9%) 53.4% (-13.4%) GRPO 68.9% 59.2% (-9.7%) 54.0% (-14.9%) ROMA (Ours) 68.7% 61.6% (+2.4%) 56.3% (+2.3%)
- Clean 性能：ROMA 与 GRPO 持平（68.7% vs 68.9%），说明没有牺牲基础能力。
- 鲁棒性提升：在 Seen 退化下，ROMA 比 GRPO 高出 2.4%；在 Unseen（零样本泛化）退化下，高出 2.3%。
- 下降幅度：GRPO 从 Clean 到 Unseen 下降了 14.9%，而 ROMA 仅下降 12.4%，稳定性显著更好。
### 工程启示- 不要盲目在 RL 阶段注入噪声：对于 MLLM，直接在环境里加噪会导致训练不稳定。采用“干净采样 + 退化评估”的双前向策略是更安全的选择。
- 正确性过滤至关重要：在引入任何鲁棒性正则化之前，务必检查基线轨迹的质量。用错误的轨迹去训练鲁棒性，只会得到“稳健的幻觉”。
- 对抗性增强优于平均增强：在计算不变性惩罚时，关注最坏情况（Worst-Case）比取平均更有效，这符合鲁棒优化的直觉。
### 局限与展望ROMA 目前主要依赖静态的视觉退化增强（如高斯模糊、JPEG 压缩）。虽然效果显著，但面对极端或非自然的对抗攻击时，其泛化能力仍有待验证。此外，双前向传播增加了训练时的计算开销（虽然不增加推理开销），在大规模微调时需权衡资源。
总的来说，ROMA 为 MLLM 的 RL 微调提供了一个非常实用的鲁棒性增强范式，特别适合那些需要部署在真实、嘈杂环境中的视觉推理 Agent。
