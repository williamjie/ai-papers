论文 : Mid-Training with Self-Generated Data Improves Reinforcement Learning in Language Models链接 : https://arxiv.org/abs/2605.08472当前大模型强化学习（Reinforcement Learning, RL）的一个核心痛点是：RL 往往只是对基座模型已有能力的“分布锐化”（distributional sharpening），而非真正激发新能力。如果基座模型没见过某种解题思路，RL 很难凭空变出来。这篇论文提出了一个简单但极其有效的工程解法：在 RL 之前，插入一个“中期微调”（Mid-Training, MT）阶段，利用基座模型自己生成的、基于不同启发式策略的多样化正确解法进行微调。
### 为什么 RL 需要“喂”多种解题思路？
现有的 RL 训练（如 GRPO）主要依赖策略梯度（Policy Gradient）更新。论文通过理论分析指出，如果模型在某个步骤上过于自信（单峰分布），梯度更新带来的概率变化极小（与 ϵ2\epsilon^2 成正比），导致模型难以跳出局部最优。相反，如果模型在微调阶段学习了多种解题路径（N 峰分布），在 RL 过程中，当某条路径被负奖励惩罚时，概率质量会重新分配到其他高概率的替代路径上。
这意味着： 中期微调的核心 Insight 不是让模型记住答案，而是让模型在关键分支点上保留多个高概率的“解题策略入口” 。这样 RL 才能有效地组合这些策略，形成更强大的推理链条。
### 方法拆解：基于波利亚启发式的自生成作者没有依赖外部强模型蒸馏，而是采用“自举”（Bootstrapping）方式：
- 启发式引导：借用 George Pólya 的解题启发式（如“逆向工作”、“分解重组”、“类比”等），为每个问题构建特定的 Few-shot Prompt。
- 多样化生成：对每个问题，基于不同的启发式生成多个候选解。
- 双重过滤：先用规则验证器（如 Math-Verify）确保答案正确，再用奖励模型（Reward Model）评估是否真正遵循了目标启发式。
- 中期微调：将筛选出的多样化正确轨迹用于监督微调（SFT）。
### 关键实验结果实验基于 Llama-3.2-3B-Instruct，对比了 Vanilla RL 和 STaR+RL。结果令人印象深刻，尤其是在高样本数（pass@k）场景下：

更关键的发现是： “广度”优于“深度” 。在固定微调预算下，学习少量问题的多种解法（Setting 2），比学习大量问题的单一解法（Setting 1）在 RL 后平均表现高出约 7%。此外，这种能力可以泛化到代码生成（HumanEval）和叙事推理（MuSR），证明学到的不是数学特化技巧，而是通用的问题解决策略。
### 工程启示- RL 前的数据准备至关重要：不要直接拿基座模型上 RL。先通过自生成数据做一轮 SFT，特别是引入解题策略的多样性，能显著降低 RL 的探索难度。
- 多样性优于数量：在微调数据构建时，刻意引入不同的解题视角（如通过 Prompt 工程引导不同思路），比单纯堆砌题目数量更有效。
- 低成本自改进：该方法无需访问更强的教师模型，仅利用自身生成+规则验证即可实现能力跃迁，适合资源受限的团队。
### 局限与展望论文指出，如果中期微调的数据包含错误答案，RL 性能反而下降。因此， 答案的正确性是底线 。此外，启发式策略的多样性受限于基座模型的能力，对于极复杂的推理，可能需要更强模型的支持或更精细的启发式设计。
