# 扩散模型该插在哪？DiHAL的几何直觉

**日期**: 2026-05-19

---

论文 : Where Should Diffusion Enter a Language Model? Geometry-Guided Hidden-State Replacement链接 : https://arxiv.org/abs/2605.14368把扩散模型（Diffusion Models）强行塞进语言模型（Language Models, LMs）的尝试已经很久，但效果始终不如自回归（Autoregressive, AR）架构。这篇论文没搞什么花哨的新架构，而是问了一个极其工程化、却常被忽略的问题： 扩散模块到底应该插在 Transformer 的哪一层？
作者提出的 DiHAL（Diffusion-Transformer Hybrid Architecture）不仅给出了答案，还提供了一套基于“几何特征”的量化方法。这对我们在本地部署混合生成模型、或者探索非 AR 加速方案有直接的参考价值。
### 为什么扩散模型在文本上总是“水土不服”？
传统观点认为，扩散模型在文本上表现差，是因为文本是离散的（Discrete），而扩散是在连续空间（Continuous Space）里做去噪。从连续向量映射回离散 Token 时，微小的去噪误差会导致 Token 识别错误。
但 DiHAL 的作者提出了一个更底层的直觉： 问题不在于连续性，而在于“空间几何”不匹配。
Transformer 内部有几十个层，每一层的隐藏状态（Hidden States）都是一个高维连续空间。但并不是所有层都适合做扩散去噪。有些层的几何结构过于复杂、维度太高，扩散模型根本学不会；有些层则结构简单、紧凑，非常适合扩散。
核心 Insight ：与其让扩散模型去硬刚最后的 Token 预测，不如让它去重构 Transformer 内部某个“对扩散友好”的中间层隐藏状态。只要扩散能把这个中间层的状态还原出来，剩下的解码工作交给原本强大的 Transformer 上层（Upper Layers）去完成即可。
### 方法拆解：用几何特征“定位”最佳插入点DiHAL 的核心是一个“定位-替换”（Locate-and-Replace）策略。它不盲目试错，而是用三个几何代理指标（Proxies）来给每一层打分，找出最适合扩散介入的位置：
- 局部曲率（Local Curvature, mcurvm_{curv}​）：衡量数据在局部邻域内的紧凑程度。曲率越大，表示数据分布越集中，扩散模型去噪时的“牵引力”越强，收敛越快。
- 全局单调性/刚度（Global Stiffness, mmonom_{mono}​）：衡量空间的全局方向稳定性。刚度越高，表示对去噪过程中的噪声扰动越鲁棒。
- 有效秩（Effective Rank, kk）：衡量表示的内在维度。有效秩越低，说明信息集中在少数几个方向上，扩散模型需要学习的复杂度越低。
选择策略 ：论文定义了一个综合分数，奖励高曲率和高刚度，惩罚高有效秩。

实验发现，对于 Llama-3.1-8B 和 Qwen3-8B，得分最高的层都集中在 靠近 Embedding 的前几层 （Layer 2-3）。这很有趣：越深层的特征越抽象、维度越分散，反而不适合扩散去噪；靠近输入的浅层保留了几何上的紧凑性，是扩散的“舒适区”。
找到这个层之后，DiHAL 用一个小巧的 UNet 扩散桥（Diffusion Bridge）替换掉它下面的所有 Transformer 层。扩散桥只负责根据输入 Embedding 重构出这一层的隐藏状态，然后“接力”给原模型的上层继续生成。
### 关键结果：几何分数能预测训练效果吗？
为了验证这套几何理论，作者在 8B 参数量的模型上做了严格的“固定预算”实验。
1. 几何分数与可桥接性（Bridgeability）高度相关作者训练了不同层的扩散桥，发现几何分数高的层，其验证集损失（Validation Loss）确实更低。
- 在 Llama-3.1-8B 上，几何分数与可桥接性的 Spearman 相关系数高达 0.9143。
- 在 Qwen3-8B 上，这一系数为 0.9267。
这意味着，我们不需要穷举每一层去训练测试，仅靠前向传播计算几何特征，就能精准预测哪一层最适合替换。
2. 隐藏状态重构优于 Token 级扩散在同等计算预算下（40 H100小时），DiHAL 与其他连续扩散基线（如 Diffusion-LM, CoDAR）对比：

3. 最终生成质量在完整训练后，DiHAL 在 WikiText-103 上的表现：
- Llama-3.1-8B: PPL 为 135.64，优于验证集损失最小的“Oracle”层（165.67）。
- Qwen3-8B: PPL 为 144.03，与 Oracle 层（139.77）相当。
虽然还没完全追平原始 AR 模型，但在不微调上层参数的情况下，仅靠替换前几层就达到这个水平，已经非常有说服力。
### 工程启示与局限对工程师的价值：
- 混合架构新思路：如果你想在资源受限场景下引入扩散模型（例如利用扩散的并行采样优势），不要试图从头训练一个大 Diffusion LM。试着在现成的开源 LLM（如 Llama/Qwen）的前 3-5 层插入一个轻量级扩散桥，可能比全量替换更划算。
- 几何特征作为监控指标：在微调或蒸馏过程中，监控隐藏状态的“有效秩”和“曲率”，可以作为判断模型是否过拟合或表示是否坍塌的辅助指标。
局限性：
- 依赖上层：DiHAL 本质上还是“寄生”在预训练 Transformer 上层上的，它不是一个独立的生成模型。如果上层被剪枝或替换，效果会大打折扣。
- 浅层限制：目前几何分数只指向浅层。深层表示更复杂，可能需要更强大的扩散架构或不同的几何引导方式，这留给了后续工作。
总的来说，DiHAL 用严谨的几何理论解决了“扩散插在哪”这个工程痛点。它提醒我们：在处理高维表示时， 理解数据的几何结构，往往比堆砌模型参数量更重要。
