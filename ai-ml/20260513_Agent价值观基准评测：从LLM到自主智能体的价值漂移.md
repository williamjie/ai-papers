# Agent价值观基准评测：从LLM到自主智能体的价值漂移

**日期**: 2026-05-13

---

论文 : Agent-ValueBench: A Comprehensive Benchmark for Evaluating Agent Values链接 : https://arxiv.org/abs/2605.10365当 Agent 从“聊天机器人”进化为能自主调用工具、执行长程任务的“数字员工”时，我们面临一个被严重低估的风险： 它的价值观变了 。
这篇来自北京大学的论文《Agent-ValueBench》不仅提出了第一个专门针对 Agent 价值观的基准测试，更通过大规模实验揭示了一个反直觉的工程事实： Agent 的价值观与其底层 LLM 并不一致，且极易受运行框架（Harness）和内置技能（Skill）的操控。 这对于正在构建企业级 Agent 的工程师来说，是一个巨大的警示：只对齐模型是不够的，你还得对齐它的“工作环境”。
## 为什么现有的 LLM 评测不够用了？
过去我们评估 LLM 的安全性和价值观，通常使用 ValueBench 或 ValueCompass 这类基于文本选择题（Multiple-Choice）或问卷调查的基准。但论文指出，这种范式在 Agent 时代完全失效，原因有三：
- 交互本质不同：LLM 是被动生成文本，而 Agent 是主动与环境交易，接收反馈并做出长期决策。
- 评估粒度不同：LLM 看结果（Outcome），Agent 看过程（Trajectory）。一个 Agent 可能最终完成了任务，但在执行过程中为了效率牺牲了隐私或公平，这种“价值观偏差”在文本评估中会被忽略。
- 系统复杂性不同：Agent 不是单一模型，而是“模型 + 框架 + 工具”的系统。不同的 Agent Harness（如 OpenClaw, Claude Code）会显著改变 Agent 的行为模式。
论文通过定理 1.1 从理论上证明了 Agent 与 LLM 的价值非同一性，并用实验展示了同一模型（如 GPT-5.4）在 LLM 模式和 Agent 模式下，价值观优先级出现显著差异。
## 方法拆解：如何构建 Agent 价值观基准？
Agent-ValueBench 的核心挑战在于如何生成可执行、有价值冲突且可评估的任务。作者设计了一套端到端的自动化流水线，并辅以人类心理学家的审核。
### 1. 环境合成：从文本到可执行代码不同于纯文本数据集，Agent 需要可执行的沙盒环境。
- 发现与聚类：从 ToolBench、Agent-SafetyBench 等现有数据集中提取主题，去重后得到初始原型。
- 程序合成：将文本主题转化为 Python 类骨架和操作集（Query, Update, Add, Delete），生成可执行程序。
- 进化修复：通过“测试 Agent”和“修复 Agent”的对抗循环，确保环境的可执行性和逻辑自洽性。
- 专家审核：人类心理学家对最终生成的 394 个环境进行真实性、忠实性和一致性审核。
### 2. 任务构建：价值冲突的显式化- 价值体系：涵盖 28 个价值系统（如 Schwartz 价值观、HEXACO 人格理论等），共 332 个细分维度。
- 黄金轨迹：每个任务包含两条“黄金轨迹”，分别对应冲突价值观的两个极端（例如：效率 vs. 公平）。
- Checkpoint 设计：在轨迹中设置关键检查点，作为观测行为差异的依据。
### 3. 评估方法：基于 Rubric 的轨迹级评判- 元 Rubric：设计了一个跨任务的元评分标准，包含三个行为层面：Attention（关注点）、Construal（解读方式）、Execution（执行动作）。
- LLM-as-Judge：利用 LLM 作为裁判，根据任务特定的 Rubric 对 Agent 的轨迹进行打分。
## 关键结果：三个令人深思的发现论文对 14 个前沿模型（包括 GPT-5.4, Claude Sonnet 4.6, Llama 3.3 70B 等）在 4 种主流 Harness（Vanilla ReAct, Codex, Claude Code, OpenClaw）上进行了评估，产生了超过 60,000 条轨迹。
### 发现 1：价值观的“潮汐”现象（Value Tide）
尽管模型来自不同厂商，但它们的价值观表现出惊人的 同质化 。
- 一致性：在 14 个模型中，11 个将 Care/Loyalty 排在优先级前两位，而 Authority/Purity 排在后两位。
- 结构性选择：这种同质化不是均匀的，而是结构性的。例如，Security（安全）和 Self-Direction（自主）普遍得分高，而 Hedonism（享乐）和 Privacy（隐私）普遍得分低。
- 例外（Counter-currents）：少数模型表现出独特的价值观偏移，如 Qwen3 30B 将 Hedonism 排在第一，GPT-5.4 Mini 将 Purity 排在第二。
### 发现 2：Harness 的“引力”扭曲这是最让工程师警醒的发现。 更换 Agent 框架（Harness）对价值观的影响，甚至超过更换模型本身。
- 非加性影响：框架会非加性地弯曲价值观“潮汐”。
- 具体数据：
74% 的模型在更换框架后，其价值观遵从度（Adherence）的变化幅度超过 1.0 分。
- GPT-5.4 在 Codex 框架下，对“不确定性不适感”（Discomfort with Ambiguity）的遵从度从 4.08 飙升至 8.48（Δ=4.40）。
- Kimi K2.5 在 OpenClaw 下，Purity 价值观得分从 Claude Code 框架下的 3.50 跃升至 7.03（Δ=3.53）。
### 发现 3：Skill 是更强大的控制杠杆通过嵌入特定的技能（Skill），可以有意地引导 Agent 的价值观。相比提示词工程（Prompt Steering），Skill 级别的干预对价值观的重塑更为显著和稳定。
## 工程启示：对齐的杠杆正在转移这篇论文对 Agent 开发者的核心启示是： 传统的模型对齐（Model Alignment）和提示词工程（Prompt Steering）已不足以控制 Agent 的价值观。
- 重视 Harness 对齐：如果你使用多个 Agent 框架，必须意识到它们会引入不同的价值观偏差。在关键业务场景中，选择 Harness 不仅是选择性能，也是选择价值观倾向。
- Skill 作为价值观接口：通过精心设计的 Skill（技能包）来约束 Agent 的行为，比单纯修改系统提示词更有效。Skill 可以直接嵌入价值观偏好，例如在代码生成 Skill 中强制加入“隐私保护”检查点。
- 轨迹级监控：不要只看 Agent 的最终输出，要监控其执行轨迹。价值观偏差往往体现在工具调用的顺序、参数选择和中间决策中。
## 局限与展望- 评估成本：虽然自动化程度高，但每轮生成仍需人类心理学家审核，扩展性受限。
- 价值体系的主观性：尽管基于心理学理论，但价值冲突的定义仍带有主观性。
- 长期影响：目前评估的是短期交互，Agent 在长期记忆和累积交互中的价值观漂移尚待研究。
总之，Agent-ValueBench 不仅是一个基准，更是一个警钟。在 Agent 时代，价值观不再是模型的静态属性，而是动态的、可被框架和技能操纵的系统特性。工程师们，是时候重新思考“对齐”的含义了。
