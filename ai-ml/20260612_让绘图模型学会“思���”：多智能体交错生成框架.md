论文 : InterleaveThinker: Reinforcing Agentic Interleaved Generation链接 : https://arxiv.org/abs/2606.13679现有开源统一多模态模型（UMMs）在长程任务中表现拉胯，而传统图像生成器又无法原生支持文本-图像的交错输出。这篇论文提出了一种通用的多智能体框架 InterleaveThinker，通过外挂“规划者”和“评论家”，强行给任何现有的图像生成器赋予了交错生成交互能力。
核心痛点：UMM 的“短视”与“累积误差”
目前的 UMMs（如 Emu3.5, Janus-Pro）虽然架构上支持交错生成，但在长序列任务中存在两个致命缺陷：
- 视觉过度依赖（Visual Over-reliance）：模型严重依赖前一步的图像状态。例如在生成交替动作时，它可能因为中间状态看起来像最终目标就提前终止，导致逻辑断裂。
- 逐步误差累积（Step-wise Error Accumulation）：早期步骤的微小画质下降或细节错误，会在后续步骤中不断放大，最终毁掉整个序列。
InterleaveThinker 的核心 Insight 在于： 解耦规划与生成 。不要让模型一边看图一边决定下一步，而是让一个专门的 Planner 预先制定全局计划，从而切断对局部视觉反馈的病态依赖。
方法拆解：Planner-Gen-Critic 闭环该框架由三个模块组成，核心逻辑如下：
- Planner（规划者）：接收输入序列，一次性输出 N 步执行计划。每步包含指令 uiu_i​、适配模型的提示词 pip_i​ 和辅助信息 aia_i​。这一步完全基于文本规划，避免了视觉干扰。
- Generator（生成器）：可以是任何现有的图像生成/编辑模型（如 FLUX.2-klein, Qwen-Image-Edit）。它根据 Planner 的指令和前一步图像生成当前图像。
- Critic（评论家）：这是提升质量的关键。它评估生成结果是否偏离计划。如果失败，它会生成修正后的提示词 ri+1r_{i+1}​ 并要求重新生成，直到满足标准或达到最大迭代次数。
训练策略：用单步 RL 模拟长程优化一个交错生成轨迹可能包含超过 25 次生成器调用，端到端优化计算成本极高且信用分配困难。作者采用了巧妙的**双奖励策略（Dual-Reward Strategy）**进行单步强化学习（GRPO）：
- 准确性奖励 (RaccR_{acc}​)：惩罚 Critic 对当前生成质量的���断与真实标签之间的差异，确保其能准确识别“成功/失败”。
- 逐步奖励 (RstepR_{step}​)：当 Critic 介入修正时，比较修正前后图像的质量得分差值。如果修正后质量提升，则给予正向奖励。
这种设计使得单步的 RL 优化能有效引导整个长轨迹的对齐，大幅降低了计算开销。
关键结果：吊打开源，比肩闭源在 UEval 基准测试中，InterleaveThinker 展现了惊人的通用性和性能提升：

- 推理能力溢出：更有趣的是，这种多智能体协作显著提升了基础模型的推理基准表现。在 WISE 上从 0.47 提升至 0.73，在 RISE 上从 13.3 跃升至 28.9。
⚠️ 反直觉发现 ：原本旨在提升图像生成质量的框架，竟然大幅增强了模型在纯推理任务上的表现。这表明“规划-执行-反思”的 Agent 范式具有极强的通用性。
工程启示与局限对于工程师而言，InterleaveThinker 的最大价值在于 解耦 。你不需要重新训练庞大的多模态底座，只需微调两个轻量级的 VLM（如 Qwen3-VL-8B）作为 Planner 和 Critic，即可让现有的商用或开源绘图模型获得长程逻辑控制能力。
- 数据构建：作者通过 Gemini 2.5 Pro 合成高质量轨迹数据，并设计了严格的过滤管道（SFT-112k, RL-13k），这为类似 Agent 训练提供了数据工程参考。
- 局限性：推理延迟显著增加。单步可能需要多次 Critic 迭代和重新生成，且涉及多个模型调用，不适合对实时性要求极高的场景。
总之，如果你需要构建复杂的视觉叙事、分步指导或机器人操控应用，这种“外挂大脑”的方案是目前开源领域最具落地价值的选择之一。
