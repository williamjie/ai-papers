论文 : SIA: Self Improving AI with Harness & Weight Updates链接 : https://arxiv.org/abs/2605.27276现在的 Agent 开发有个死结：人类既是模型微调者，又是 Prompt 工程师。SIA 这篇论文试图打破这个瓶颈，让 AI 自己搞定“怎么思考”和“怎么执行”。它不再依赖人工写死的强化学习（Reinforcement Learning, RL）流水线或静态的 Agent 框架，而是构建了一个闭环，让一个 Feedback-Agent 动态决定是修改代码逻辑还是更新模型权重。
### 痛点：两个孤立的改进孤岛目前 AI 自我改进的研究分裂成两派，且互不兼容。
第一派叫 Harness Update （如 Meta-Harness, Darwin Gödel Machine）。它们让元智能体重写 Agent 的脚手架——包括系统提示词、工具调用逻辑和重试策略。核心问题是：模型权重锁死，无论 Prompt 怎么变，模型底层的推理能力上限就在那里。
第二派叫 Test-Time Training （如 TTRL, Discover-TTT）。它们在测试时通过 RL 更新模型权重，但前提是脚手架固定不变。这意味着优化过程被限制在单一的任务结构中，无法适应复杂的交互流程。
SIA 的核心 Insight 很简单： 外部搜索策略（Harness）和内部知识编码（Weights）必须协同进化。 只有当 Agent 既能调整“怎么查资料”，又能内化“什么是正确答案”时，才能突破单一维度的性能天花板。
### 方法拆解：动态选择的两杆秤SIA 系统由三个组件构成：Meta-Agent（初始化）、Task-Specific Agent（执行）和 Feedback-Agent（决策与改进）。
关键在于 Feedback-Agent 的决策机制。它不是机械地交替执行步骤，而是根据轨迹反馈动态选择动作：
- Harness Update：当模型卡在逻辑错误或格式解析上时，Feedback-Agent 重写 Python 代码、调整工具链或优化 Prompt 结构。此时权重冻结。
- Weight Update：当 Harness 迭代停滞，但模型仍缺乏领域直觉时，触发 RL 训练。这里使用 LoRA（Low-Rank Adaptation）更新 gpt-oss-120b 的权重。
⚠️ 关键设计细节 ：Feedback-Agent 会根据任务特性自动选择 RL 算法。例如在奖励信号稀疏的代码生成任务中，它选用 Entropic Advantage Weighting；而在分类任务中则使用 PPO with GAE。这种“算法自适应”比固定流水线更灵活。
### 实验结果：双管齐下的威力论文在三个差异巨大的领域验证了 SIA 的效果，数据非常有说服力：

最反直觉的发现出现在生物去噪任务中。Harness 迭代只能微调超参数，得分卡在 0.241。而加入权重更新后，模型“学会”了一个简单的后处理步骤： np.clip + np.rint （将计数舍入为非负整数）。这个生物学约束从未在 Prompt 中提到，是模型通过梯度下降自行发现的内部知识。
### 工程启示与局限对工程师而言，SIA 指明了 Agent 系统的演进方向： 不要只盯着 Prompt Engineering。
- 权重微调是必要的：对于需要深度领域知识（如 CUDA 内核优化、法律条文辨析）的任务，仅靠外部工具链无法弥补模型内部的认知缺失。
- 动态切换策略：在实际部署中，可以借鉴 SIA 的思路，当 Agent 连续多次在相同逻辑错误上失败时，自动触发轻量级的 LoRA 微调，而不是无限重试。
当然，SIA 也有局限。论文提到了“耦合的 Goodhart 定律”风险：Harness 和 Weights 都在针对同一个验证器优化，可能导致系统在训练集上过拟合，而在分布外数据上表现脆弱。此外，同时维护两个优化器的计算成本远高于单一方案。
SIA 证明了“内外兼修”是 Agent 自我进化的正解。未来，随着推理成本的下降，这种动态更新权重的闭环可能会成为复杂任务 Agent 的标准配置。
