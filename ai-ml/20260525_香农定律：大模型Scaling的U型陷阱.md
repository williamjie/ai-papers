论文 : LLMs as Noisy Channels: A Shannon Perspective on Model Capacity and Scaling Laws链接 : https://arxiv.org/abs/2605.23901我们习惯了“大力出奇迹”：参数越大、数据越多，模型越强。但现实工程里，这种单调递增的Scaling Law经常失效——比如量化后精度暴跌，或者微调时训练过度导致性能倒退。这篇论文直接挑战了OpenAI和Chinchilla的经典假设，引入香农信息论视角，解释了为什么“盲目堆料”反而会毁掉模型。
### 痛点：Scaling不是线性的传统Scaling Law（如OpenAI Law）假设Loss随参数 NN 和数据量 DD 单调递减。但近期研究发现，在量化（Quantization）或监督微调（SFT）场景下，Loss曲线呈现 U型 ：初期提升，超过某个阈值后反而恶化。
- Catastrophic Overtraining: 预训练数据过多，导致下游微调能力下降。
- Quantization-induced Degradation (QiD): 模型越大，对量化噪声越敏感，低比特下性能崩塌。
现有方法只是简单地在幂律公式上加个惩罚项，缺乏物理直觉。这篇论文的核心Insight是： LLM训练本质上是一个有噪信道传输过程 。
### 核心拆解：把LLM看作香农信道作者将Shannon-Hartley定理映射到LLM训练：
- 带宽 (Bandwidth) →\rightarrow 模型参数 NN：决定信息吞吐上限。
- 信号功率 (Signal) →\rightarrow 训练Token数 DD：携带的知识量。
- 噪声功率 (Noise) →\rightarrow 数据噪声 + 模型交互噪声：这是关键创新点。
论文提出的 Shannon Scaling Law 公式如下：
CLLM=aNαlog⁡2(1+bDβc(DN)γ+dDδ+e)C_{LLM} = aN^\alpha \log_2 \left(1 + \frac{bD^\beta}{c(DN)^\gamma + dD^\delta + e}\right) ​ = a N α lo g 2 ​ ( 1 + c ( D N ) γ + d D δ + e b D β ​ )
这里的精妙之处在于分母的噪声项设计：
- dDδdD^\delta：数据诱导噪声。数据越多，累积的脏数据、矛盾信息越多。
- c(DN)γc(DN)^\gamma：模型交互噪声。这是论文的最大亮点。它认为噪声不仅来自数据，还来自“大模型处理大量数据时的内在不稳定性”。当NN和DD同时增大时，如果信噪比（SNR）不足，噪声项会指数级放大，导致容量CLLMC_{LLM}​饱和甚至下降，从而在Loss曲线上形成U型谷底。

### 工程启示：别盲目堆参数- 量化需谨慎：论文指出，在低比特（如2-bit）下，模型越大，噪声项 c(DN)γc(DN)^\gamma 越占主导。这意味着超大模型在极低精度下的收益远低于预期，甚至不如中等模型。工程上应考虑“中等参数+较高精度”的组合。
- 微调的U型陷阱：在SFT中，学习率过大或数据过多会导致Loss Basin（损失盆地）。Shannon Law提示我们，存在一个最优的 N−DN-DD 平衡点。超过这个点，继续增加数据只会放大模型内部的噪声敏感性。
- 信噪比思维：优化Scaling不仅是加参数，更是提升SNR。清洗数据（降低 dDδdD^\delta）和架构改进（降低不可约噪声 ee）可能比单纯增加Token更有效。
### 局限与展望目前Shannon Law依赖9个拟合常数，计算复杂度略高。作者提出了一个6参数的简化版（Shannon-Simpl），在单轴外推中表现相当，但在联合外推（同时预测更大模型和更多数据）时，完整版优势明显（ R2=0.847R^2=0.847 = 0.847 vs 0.6730.673 ）。
