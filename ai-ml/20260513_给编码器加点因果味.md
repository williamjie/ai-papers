# 给编码器加点因果味

**日期**: 2026-05-13

---

论文 : A Causal Language Modeling Detour Improves Encoder Continued Pretraining链接 : https://arxiv.org/abs/2605.12438做领域自适应（Domain Adaptation）时，大家通常对 Encoder 模型直接上 MLM（Masked Language Modeling）。但这篇论文发现，如果你敢在训练中途“绕道”去跑一下 CLM（Causal Language Modeling），哪怕最后还要切回 MLM，最终效果居然更好。这听起来像是一种玄学，但作者通过严密的实验证明，这背后有清晰的表示学习机制。
### 为什么要在 Encoder 里玩 CLM？
现在的做法很单一：预训练好的 Encoder，拿到领域数据后，继续做 MLM。比如 BioBERT 或者现代的 ModernBERT，基本都是这么干的。
作者觉得这可能不够。CLM 和 MLM 的监督信号密度完全不同：MLM 只关注被 Mask 的那 15%-30% 的 token，而 CLM 对序列中的每一个位置都提供监督。这种“密集监督”可能会迫使模型底层提取更通用的上下文特征，而不是仅仅依赖局部的掩码预测。
于是，他们设计了一个 CLM Detour （因果语言建模迂回）方案：
- Phase 1 (CLM)：把注意力掩码改成因果掩码，全量 token 预测，训练一段长时间。
- Phase 2 (MLM Decay)：切回双向注意力，恢复 MLM 目标，但只训练很短的时间（比如 Phase 1 的 10%），目的是让模型“稳定”下来，消除 CLM 带来的分布偏移，同时保留 CLM 学到的特征。
核心 Insight ：这不是为了改变推理时的架构（推理时还是 Encoder，双向注意力），而是利用 CLM 阶段对模型内部表示进行“重塑”，特别是底层表示。
### 关键实验：数字不会撒谎作者在生物医学领域做了大量实验，主要基于 ModernBERT 架构。数据包括法语和英语的生物医学文本。
法语生物医学任务（8个任务，Base模型）：
- MLM Baseline: 平均 Macro F1 为 58.9%- CLM Detour: 平均 Macro F1 为 61.6%- 提升: +2.8pp，且所有单任务均有提升。
英语生物医学任务（11个任务，Large模型）：
- MLM Baseline: 平均 Macro F1 为 89.4%- CLM Detour: 平均 Macro F1 为 90.4%- 提升: +1.0pp (具体任务提升在 0.3-0.8pp 之间)。
注意，英语的提升比法语小。论文解释得很合理：ModernBERT 的原始预训练数据里已经包含了不少英文生物医学文献（如 PubMed），底层已经有一些领域特征了；而法语通用预训练数据里几乎没有生物医学内容，领域差距大，CLM 的“重塑”空间就更大。
### 为什么有效？底层才是关键这才是这篇论文最硬核的部分。作者没有止步于“效果好”，而是深入分析了 为什么好 。
-CKA 分析（表示相似度）：
作者使用 CKA（Centered Kernel Alignment）比较了不同层的表示变化。结果发现，CLM 阶段对 Transformer 的低层（Layer 0-7） 的影响远大于 MLM。
在低层，CLM 导致的表示变化是随机噪声影响的 5-44倍。
- 而在中层和高层，CLM 和 MLM 的影响差异不大。
- 这种低层的改变在后续的 MLM Decay 阶段并没有被抹去，而是保留了下来。
-冻结干预（Freeze Interventions）：
为了验证因果关系，作者冻结了不同层的参数进行训练：
冻结低层（0-7）训练：CLM Detour 的优势完全消失，性能回退到 MLM Baseline 水平。
- 冻结中层（8-14）训练：CLM Detour 的优势依然保留。
- 结论：CLM 带来的提升，本质上是因为它强制修改了低层的表示。低层负责捕获基础的语法和领域词汇特征，CLM 的密集监督让这部分特征更鲁棒。
-长文本能力：
在 Needle-in-Haystack 测试中，CLM 模型在长文档（8192 token）中定位关键信息的能力显著优于 MLM 模型（+10.7pp）。这是因为 CLM 对每个位置都有监督，使得长距离的表示更均匀，不容易出现“中间位置信息丢失”的问题。
### 工程启示- 不要只盯着 MLM：如果你的领域数据和预训练数据差距很大（比如从通用法语文本转到生物医学法语），试试先跑一段 CLM，再切回 MLM。
- Decay 阶段不用太长：实验表明，MLM Decay 阶段只需要 CLM 阶段时长的 10% 就足够了。更长并没有额外收益，反而浪费算力。
- 关注底层表示：在分析模型为什么好时，多看看低层的变化。有时候，提升来自于底层特征的重新校准，而不是高层的逻辑推理能力。
- 开源模型：作者释放了 ModernCamemBERT-bio 和 ModernBERT-bio，可以直接拿来用，省得自己折腾。
### 局限与展望- Decoder 的不对称性：作者尝试在 Decoder（Gemma-3）上做反向实验（MLM -> CLM），发现效果不如 Encoder 明显（CKA 差异只有 26.3% vs 67.2%）。这说明 Encoder 结构对这种“迂回”训练更敏感。
- 可移植性存疑：虽然低层变化是原因，但直接把 CLM 模型的底层权重移植到 MLM 模型上，并不能恢复性能。这说明 CLM 和后续 MLM 训练是协同演化的，不能简单拆分。
总的来说，这篇论文提供了一个简单、低成本但高效的 Encoder 领域自适应技巧。下次做领域微调时，不妨试试给模型加点“因果味”。
