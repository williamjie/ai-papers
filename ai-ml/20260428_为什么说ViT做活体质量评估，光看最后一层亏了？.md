# 为什么说 ViT 做活体质量评估，光看最后一层亏了？

**日期**: 2026-04-28

---

论文 : EX-FIQA: Leveraging Intermediate Early eXit Representations from Vision Transformers for Face Image Quality Assessment链接 : https://arxiv.org/abs/2604.22842先甩结论：这篇论文干了一件事——把 ViT 在 FIQA 任务上“最后一层迷信”给打破了。而且，是 零额外训练 、 零结构改动 ，直接从预训练模型里薅出中间层特征 fused 一下，就在 8 个数据集上干过了单层 SOTA。
如果做边缘端人脸识别、或需要在吞吐和精度间 trade-off 的系统，这篇文章的思路可以直接抄。
## 问题：为什么大家都只看最后一层？
FIQA（Face Image Quality Assessment）和普通 IQA 不一样，它评估的是“这张脸能不能被识别系统认出来”，而不是“这张图拍得好不好看”。当前 SOTA 基本都基于 CNN 或 ViT，但无一例外： 只用在最后一层的表示做质量回归 。
对于 ViT，这其实有点浪费。ViT 的 12 个 transformer blocks 都在同一个 D=512 的表示空间里打转，每一层都在 refin 同一批 token。理论上，任何一层的 [CLS] 或 patch tokens 都应该能被同一套回归头处理——但没人真去测过中间层到底行不行。
## 核心 insight：中间层真能打，甚至在某些场景下更强作者把 ViT-FIQA [1] 的 12 个 block 挨个掏出来，单独过一遍预训练好的回归头，测了 8 个数据集 × 4 个 FR 模型。结果炸了：

## 为什么中间层能打？attention map 透露玄机Figure 3 画了质量 token 的 attention map 随层深的变化。关键观察：
- 浅层（Exit 1-4）：注意力散在整张脸，聚焦低阶 texture、边缘。这时候 token 还没“理解”什么是脸，只能看像素质量。
- 中层（Exit 5-8）：注意力开始聚合到身份相关区域（眼睛、鼻子），但还能看到一些局部 part 信息。这一层开始具备“识别导向”的质量判断能力。
- 深层（Exit 9-12）：注意力高度集中到少数几个语义区域，更“抽象”。但这反而可能丢失一些对质量敏感的低阶信号。
简单说： 浅层看“好不好看”，中层看“像不像人”，深层看“是谁” 。FIQA 要的是前两者，不是最后一个。
## 方法拆解：两个 trick 都没训练### 1. Early Exit 机制ViT 的先天优势：所有 block 输出维度都是 RN×D，回归头 WT（1×D）或 WC（1×D）可以 直接套用 ，无需任何适配层。
具体操作：
- ViT-FIQA(T)：取出每层的 quality token q_l ∈ R^D，过 BN + 原始 WT → 分数 s_l- ViT-FIQA(C)：把每层所有 patch tokens 拼成 h_l ∈ R^{N·D}，过原始两层 feature network → 分数 s_l计算量 ：Exit l 跳过 (12−l) 个 block。但注意，ViT-FIQA(C) 的 feature network 要≈76M FLOPs，所以实际省得不多；ViT-FIQA(T) 只花≈3000 FLOPs，几乎可以忽略。
### 2. Score Fusion：加权平均，depth-weightedEX-FIQA-F：均匀权重 w_l = 1/12EX-FIQA-FW：线性权重 w_l ∝ l，深层权重更大为什么线性加权更好 ？Table I 显示性能确实随深度提升（虽然中间有震荡），说明“越深质量越高”的大方向是对的，给深层更高权重合理。
融合的计算代价 ：必须跑完 12 个 block 才能加权，所以 fusion 版本反而比单 Exit 更贵。但换来的是 精度提升 ，尤其在 IJB-C 上。
## 工程启示：这三条可以立刻用-部署时动态选择 exit 点如果系统资源紧张（如移动端、边缘盒子），直接砍到 Exit 7-8，性能不崩，省 30-40% 算力。Table I 显示 Exit 7 在 IJB-C 上 FNMR@1e-4 是 9.921，Exit 12 是 10.185，精度反而提升 2.6%。
-多 exit 融合做 offline 质量过滤如果你有 batch 处理需求（比如视频流抽帧质检），上 EX-FIQA-FW，用计算换精度。Table II 里 IJB-C 的 pAUC 从 10.185 压到 9.915，对大规模数据筛选很香。
-中间层特征可视化做可解释性Figure 3 的 attention map 变化能解释“为什么某张脸被判定为低质量”——是遮挡？还是极端姿态？中层 attention 已经能 tells 你模型 focus 在哪里。
## 局限与后续方向（论文自己也点了）
- 只实验了 ViT-S（12 层），更深的 ViT 会不会有不同 exit 规律？未验证。
- 没有用动态路由（entropy-based），所有 exit 点都是预设的。如果加上 confidence-based early termination，可能省得更多。
- 没提不同 FR backbone（如 CNN-based）的 exit 表现是否一致。理论上 CNN 不好做 early exit 因为维度会变。
- 融合策略太简单（线性加权），如果能学一个 weights 或上 attention-based fusion，可能进一步涨点。
## 写在最后：范式转移的前兆传统 FIQA 思路是“越深越好、越大越准”。这篇论文用扎实的实验告诉你： 质量信息在 ViT 里是 distributed 的，不是集中式存储 。中层可能 already 具备了比深层更“对路”的质量表征，因为它们的 attention pattern 还没被高级语义完全 dominate。
工程上，这意味着你可以主动设计“早退”策略，在不影响识别链的前提下，把 FIQA 的计算压到 50% 以下。对于实时监控、手机端人脸解锁、无人机巡检这类场景，这个思路的落地价值比那点点 pAUC 数字重要得多。
