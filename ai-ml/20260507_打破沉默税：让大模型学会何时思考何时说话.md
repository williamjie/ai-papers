# 打破沉默税：让大模型学会何时思考何时说话

**日期**: 2026-05-07

---

论文 : When to Think, When to Speak: Learning Disclosure Policies for LLM Reasoning链接 : https://arxiv.org/abs/2605.03314在传统的流式推理（Streaming Reasoning）中，我们常面临一个尴尬的“沉默税”（Silence Tax）：模型为了追求最终答案的准确性，往往需要长时间的内部思考，导致用户看到的第一行字迟迟不来；而如果强行早输出，又容易因为思考不充分而产生幻觉。这篇论文提出了一种名为 Side-by-Side (SxS) 的机制，通过在一个自回归流中引入“思考”与“说话”两种动作，让模型学会在何时展示部分进展，何时继续内部 deliberation。
### 痛点：耦合的代价现有的 CoT（Chain-of-Thought）模式有一个结构性缺陷：生成的每一个 token 既更新模型状态，又立即成为对用户的公开承诺（Public Commitment）。这种耦合意味着，如果模型想多思考一步，用户就必须多等一步。现有的加速方案（如 Speculative Decoding）主要解决的是计算速度，而没有解决“可见性时机”的问题。
SxS 的核心 Insight 在于将“可见性”从格式问题转化为一个可控的策略决策。它不改变底层架构，只是在 token 流中引入了轻量级标签，区分 R (Reasoning, 私有思考) 和 A (Answer, 公开回答)。关键在于，只有当当前的回答片段被已有的推理前缀所蕴含（Entailed）时，才允许将其标记为 A 并展示给用户。
### 方法拆解：如何优雅地“边想边说”
SxS 的训练分为两步，核心在于解决“分布偏移”和“防止填充”。
-构建蕴含对齐的轨迹（Entailment-Aligned Interleaving）
为了训练模型学会这种双通道行为，作者首先从标准的 (Prompt, Reasoning, Answer) 数据集中提取素材。
分段与对齐：将推理过程和答案都按特定分隔符（如 \n\n）切分为块。
- 安全解锁：计算一个对齐边界 ℓk\ell_k​，表示在推理前缀 R1:kR_{1:k}​ 下，最大能安全展示的答案前缀 A1:ℓkA_{1:\ell_k}​​。如果推理进展支持了新的答案部分，就解锁并生成对应的 A 标签块；否则继续生成 R 标签块。
- SFT 阶段：通过监督微调（Supervised Fine-Tuning, SFT），让模型学习这种交替生成的模式。这一步教会了模型“什么时候该说话，什么时候该闭嘴”。
-强化学习恢复性能（RL Recovery）
SFT 虽然教会了格式，但由于改变了序列分布，往往会导致最终准确率下降（即“对齐税”）。因此，作者引入了基于组相对策略优化（GRPO）的强化学习。
奖励设计：主要使用最终答案的正确性作为奖励（Outcome Reward）。
- 粒度控制：虽然主要靠正确性驱动，但实验发现 SxS 格式在 RL 阶段具有鲁棒性，不会完全退化为单阶段 CoT。作者还探索了通过奖励塑形（Reward Shaping）鼓励更细粒度的交替，但这会牺牲一定的收敛速度。
### 关键结果：更少的等待，更好的权衡实验在 Qwen3-30B-A3B (MoE) 和 Qwen3-4B (Dense) 上进行，主要评估指标包括准确率（Accuracy）和 token 级别的延迟代理指标（如 AIRW，即两次可见更新之间的平均等待 token 数）。

### 工程启示- 无需改动架构：SxS 仅通过标签和训练策略实现，适用于现有的任何自回归 LLM。对于部署端，只需解析标签即可实现流式展示优化。
- 缓解灾难性遗忘：在特定领域（如数学）进行 RL 微调时，SxS 的双通道约束可能作为一种正则化手段，防止模型完全遗忘通用知识（如 GPQA 上的表现）。
- 可控制的交互节奏：通过调整 RL 中的奖励塑形，可以灵活控制“思考”与“说话”的比例。对于需要快速反馈的 Agent 场景，可以鼓励更频繁的 A 标签输出；对于高可靠性要求的场景，可以允许更长的 R 块。
### 局限与展望论文承认，SxS 引入了一定的 token 开销（用于标签和切换），且 SFT 阶段的初始准确率下降需要 RL 阶段来修复。此外，当前的对齐逻辑基于启发式分隔符，若推理结构复杂（如答案顺序与推理顺序不一致），可能存在对齐噪声。未来工作可能涉及更智能的动态分段和更细粒度的可见性控制。
