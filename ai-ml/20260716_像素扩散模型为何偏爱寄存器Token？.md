### 痛点与动机：DiT 真的需要寄存器吗？
在 ViT 领域，DINOv2 等工作发现，自注意力机制容易产生高范数的 Patch Token 异常值，导致特征图质量下降。引入额外的“寄存器 Token”作为全局信息的吸收器，能有效缓解这一问题。
随着 DiT 成为扩散模型的主流架构，工程师们自然想知道：DiT 是否也继承了这一顽疾？是否需要同样的药方？
直觉告诉我们，如果病灶不同，药效可能也会打折扣。这篇论文的核心动机正是验证这一点，并探索寄存器在生成式模型中的独特作用机制。
### 核心洞察：没有异常值，但依然受益论文首先通过对比实验发现了一个关键差异： DiT 并不存在 ViT 中那种显著的 Patch Token 高范数异常值。
- ViT (DINOv2): 注意力图在低信息区域（如背景）会出现异常，对应极高的 Token 范数。
- DiT: 注意力始终聚焦于主体对象，Patch Token 的范数分布均匀，无明显离群点。
⚠️ 反直觉发现 ：尽管没有异常值需要“吸收”，引入寄存器 Token 后，DiT 的性能依然显著提升，且高范数特征转移到了寄存器 Token 本身，而非 Patch Token。
这意味着寄存器在 DiT 中的作用机制与 ViT 不同。作者通过深入分析中间表示发现：
- 平滑特征图：寄存器能显著降低 Patch Token 的特征范数，特别是在高噪声水平（t∈[0,0.2]t \in [0, 0.2][0,0.2]）下，使中间特征更平滑、更具空间结构性。
- 双重角色：部分寄存器充当“范数汇”（Norm Sinks），吸收多余能量；另一部分则编码全局语义信息（如背景、物体整体结构）。
### 为什么像素空间收益更大？
实验数据显示，寄存器的增益在像素空间 DiT 中最为显著，而在潜空间（Latent-Space）模型中增益有限甚至略有负面。
训练空间 代表模型 寄存器效果 像素空间 pDiT, JiT 显著提升 (FID 降低明显) VAE 潜空间 SiT 中等提升 RAE 潜空间 RAE 性能下降原因分析 ：像素空间的特征维度更高、噪声更大，中间表示更粗糙。寄存器提供的正则化作用和结构平滑能力在此时尤为关键。相比之下，潜空间本身已具备较好的结构化特性，对寄存器的依赖较低。
此外，论文还指出，近期流行的“上下文类别条件”（In-Context Class Conditioning）技术，其本质可能就是隐式地引入了类似寄存器的机制。那些额外的类别 Token 中，部分变成了范数汇，部分编码了全局语义，从而提升了生成质量。
### 工程落地：Register Guidance (RG)
基于上述洞察，作者提出了一种简单的推理增强技巧： Register Guidance (RG) 。
- 原理：将有寄存器的模型预测作为强信号，无寄存器的模型预测作为弱信号（负向引导）。
- 实现：类似于 Classifier-Free Guidance (CFG)，但在训练时通过随机丢弃寄存器 Token 的方式，让同一个模型学会“有无寄存器”两种状态。
- 优势：相比使用两个独立模型，单模型 RG 避免了分布不对齐带来的伪影问题。
### 关键结果在 ImageNet 256x256 数据集上，结合 CFG 和 RG 的方法取得了优异表现：
- JiT-B/16: FID 从 3.80 (仅 CFG) 降至 3.47 (CFG + RG)。
- JiT-L/16: FID 从 3.96 降至 3.85。
- JiT-H/16: FID 从 2.69 降至 2.41。
在 512x512 分辨率下，RG 同样带来了稳定的性能提升，证明了该方法的泛化能力。
### 工程启示- 架构设计：如果你正在构建像素空间的 DiT，强烈建议引入寄存器 Token。这不仅是一个小 trick，而是对特征空间的有效正则化。
- 训练策略：尝试在深层网络（如第 4 层之后）引入寄存器，并适当增加数量（32 个比 4 个效果更好）。
- 推理优化：Register Guidance 是一种低成本、高效率的质量提升手段。它不需要额外的模型权重，只需在训练时加入简单的 Drop Register 策略，即可在推理时获得更干净、结构更连贯的图像。
