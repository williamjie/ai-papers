# 用扩散做语言模型？ELF 的连续空间捷径

**日期**: 2026-05-12

---

论文 : ELF: Embedded Language Flows链接 : https://arxiv.org/abs/2605.10938如果把扩散模型（Diffusion Models）比作“从噪声中雕刻图像”，那么将其用于语言建模（Language Modeling）就像是在试图用同样的手法雕刻空气——因为文本本质上是离散的。过去几年，离散扩散语言模型（Discrete DLMs，如 MDLM、Duo）虽然在性能上暂时领先，但连续空间方法（Continuous DLMs）一直被认为难以企及。
MIT 和 Meta AI 合作提出的 Embedded Language Flows (ELF) 论文直接打脸了这种偏见。它证明了：只要你把离散化的步骤推迟到最后一步，连续流匹配（Flow Matching）在语言任务上不仅能用，而且比现有的主流方法更强、更快、更省数据。
### 痛点：为什么连续扩散一直“拉胯”？
在图像领域，Diffusion 和 Flow Matching 是绝对王者，原因很简单：像素本身就是连续的。但在 NLP 领域，之前的连续扩散模型（如 Diffusion-LM, FLM）面临一个核心矛盾：
- 空间错位：它们在连续嵌入空间（Embedding Space）去噪，但语言本质是离散 Token。
- 监督泄漏：为了让模型“懂”语言，大多数现有方法在每一步去噪过程中都强行加入交叉熵（Cross-Entropy）损失或离散化约束。这导致模型在连续空间里的动力学轨迹（Dynamics）被离散的“引力”拉扯得歪歪扭扭，无法享受连续流匹配带来的数学美感。
- 架构臃肿：为了把连续向量变回 Token，很多方法引入了额外的解码头（Decoder），增加了推理复杂度和参数量。
### 方法拆解：极简主义的胜利ELF 的核心 Insight 非常反直觉： 不要在中间步骤纠结于离散性，只在最后一步离散。
#### 1. 全程连续，最后“落地”
ELF 构建了一个基于 Flow Matching 的框架。它的去噪过程（Denoising）完全发生在连续的嵌入空间中。
- 训练时：模型90%的时间在学如何从噪声恢复出干净的 Embedding（使用 MSE 损失），只有20%的时间在学如何把 Embedding 映射回 Token（使用 CE 损失）。
- 推理时：从纯高斯噪声 z0z_0​ 开始，通过 ODE/SDE 求解器一步步去噪得到干净 Embedding xx。只有在最后一步 t=1t=11，才通过一个共享权重的网络将 xx 投影回 Token 空间（Unembedding），并取 argmax 得到离散 Token。
这种设计的好处是巨大的：去噪轨迹在连续空间里是平滑、自由的，没有离散约束的干扰，这使得 Flow Matching 的高效采样优势得以完全释放。
#### 2. 共享权重的“单网络”架构ELF 不需要单独的解码器。它使用同一个神经网络 net_theta ，通过一个二进制的 mode 信号（denoise 或 decode）来切换功能。
- Denoise 模式：输入噪声嵌入，输出预测的干净嵌入，损失为 MSE。
- Decode 模式：输入带有轻微扰动的干净嵌入，输出 logits，损失为 CE。
这种共享权重的设计不仅节省了显存，还让模型在去噪过程中隐式地学习了如何解码，因为两者共享了相同的表征能力。
#### 3. 无缝接入 CFG由于 ELF 是连续空间的 Flow Matching 模型，它天然兼容 无分类器引导（Classifier-Free Guidance, CFG） 。这在离散扩散模型中是非常难搞定的（离散 CFG 效果往往不佳）。ELF 利用自条件（Self-conditioning）技术，轻松实现了 CFG，从而在生成质量和多样性之间提供了极佳的调控手段。

### 工程启示- 连续空间是蓝海：如果你正在构建基于 Diffusion 的 LLM，不要急着在每一步都做离散化约束。尝试在高层语义空间（如 T5 Embedding）做连续流匹配，最后再离散化，可能会得到更平滑的生成轨迹。
- CFG 是必选项：对于连续扩散语言模型，CFG 不再是可选实验，而是提升生成质量的关键杠杆。ELF 证明了它在语言任务上同样有效，且实现简单。
- 数据效率至上：ELF 证明了连续模型在数据效率上的巨大潜力。对于算力受限的团队，用更少的 Token 训练出更强的模型，比盲目堆数据更具工程价值。
### 局限与展望ELF 目前主要依赖预训练的 T5 Encoder 进行嵌入，虽然效果好，但引入了外部依赖。此外，SDE 采样器在极少步数（如 <10步）下仍优于 ODE，说明引入随机性可能有助于打破局部最优，但这增加了推理的不确定性。未来如何进一步压缩采样步数并实现纯端到端训练（不依赖预训练 Encoder），是下一个值得探索的方向。
