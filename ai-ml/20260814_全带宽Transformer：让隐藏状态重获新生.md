论文 : Full-bandwidth transformer链接 : https://arxiv.org/abs/2608.08888在自回归生成中，模型每一步只吐出一个个 Token，却丢弃了顶层隐藏状态的丰富信息。这篇论文提出了一种巧妙的“隐藏状态反馈”机制，以极低的推理成本换取显著的性能提升。它不改变架构，不增加参数量，却能大幅提升数据效率。
### 痛点：垂直通道的严重浪费传统 Transformer 在解码时存在一个巨大的带宽瓶颈。水平方向上，注意力机制让每个 Token 都能访问过去所有位置的信息；但在垂直方向上，信息流动是单向且受限的。
当模型生成第 tt 个 Token 时，它只接收了第 t−1t-1 1 步采样出的离散符号作为输入。这意味着，第 t−1t-1 1 步顶层隐藏状态中蕴含的所有非语言化计算（如中间推理结果、不确定性估计）都被压缩成了 log⁡2∣V∣\log_2 |V| 2 ​ ∣ V ∣ 比特的信息量。
这种“深度冻结”导致浅层网络永远无法直接读取深层处理过的历史状态。模型若想利用之前的复杂推理，要么通过冗长的 Chain-of-Thought 将其显式写出来，要么在每一步重新从头计算。这不仅浪费算力，也限制了模型的推理效率。
### 核心 Insight：隐藏状态回流全带宽 Transformer（Full-bandwidth Transformer）的核心设计是让顶层隐藏状态“回流”到底层输入中。
在解码第 tt 步时，模型不再仅使用 Token 嵌入，而是将上一步的顶层隐藏状态 ht−1Lh_{t-1}^L L ​ 与当前 Token 嵌入 ete_t ​ 融合，作为新的输入：
et⊗ht−1L=WUht−1L\odiesσ(WGet)e_t \otimes h_{t-1}^L = W_U h_{t-1}^L \odies \sigma(W_G e_t) ​ ⊗ h t − 1 L ​ = W U ​ h t − 1 L ​ \odies σ ( W G ​ e t ​ )
这里有一个精妙的设计细节： 非对称门控线性单元（GLU） 。隐藏状态走 Value 路径，Token 嵌入仅作为 Gate。这种设计强制模型必须读取隐藏状态，因为如果忽略 ht−1Lh_{t-1}^L L ​ ，输入就消失了。相比之下，简单的加法融合容易让模型退化为标准解码，导致宽通道闲置。
这一改动带来的收益是双重的：
- 非语言化状态可重用：中间计算结果可以带着全新的深度预算重新进入网络栈。
- 全层可见性：包括最浅层在内的所有层级，现在都能直接读取经过整个网络栈处理过的历史状态。
### 训练难题与解决方案最大的挑战在于训练。隐藏状态回流引入了序列依赖性，直接训练会破坏 Transformer 赖以生存并行教师强制（Parallel Teacher Forcing）。
作者提出了一种**多遍前向传播（Multi-pass）**策略：
- 第一遍：标准的前向传播，计算所有位置的隐藏状态。
- 后续遍：将上一遍的隐藏状态右移一位，与 Token 嵌入融合，再并行运行整个网络栈。
为了稳定训练并避免分布偏移，作者采用了两个关键技巧：
- 渐进式调度：大部分训练时间使用标准单遍目标，仅在预训练后期引入多遍反馈。
- 前缀混合（Prefix Mixin）：在训练批次中随机选择一部分位置保持纯 Token 输入，模拟推理时 Prompt 和生成部分的边界情况。
⚠️ 反直觉发现 ：仅使用两遍反馈训练会导致模型在长程推理时发散；但只需加入 3% 的三遍反馈批次，就能使隐藏状态映射收敛到稳定不动点，支持远超训练长度的推理。
### 关键结果：用计算换数据实验表明，全带宽 Transformer 能以极小的推理开销，换取相当于增加大量训练数据的性能提升。

具体来看：
- 推理效率提升：在 Math500 上，使用隐藏状态反馈的模型生成了更短的推理轨迹，但准确率更高。这说明模型不再需要把中间步骤全部“说”出来，而是直接在隐藏状态中维护计算上下文。
- 数据效率翻倍：经过两次融合预填充（Fused Prefill），训练 100B Token 的全带宽模型，其性能可媲美训练 200B Token 的标准模型。在部分任务上，甚至接近训练 5× Token 量的基线。
- 几乎零额外成本：每个生成 Token 仅增加两次矩阵乘法，推理延迟增加不到 1%。KV Cache 和现有服务栈完全兼容。
### 工程启示对于工程师而言，这篇论文的价值在于它提供了一种“无损升级”路径：
- 本地部署友好：不需要修改模型架构或增加显存占用，只需在推理代码中增加两行融合逻辑即可生效。
- Agent 与长上下文：隐藏状态的回流机制天然适合需要维护长期状态的 Agent 场景，以及需要精炼 Prompt 理解的长上下文任务。
- 微调策略：即使不进行全量预训练，在指令微调阶段引入多遍前向传播，也能显著提升模型对复杂指令的理解能力。
### 局限与展望目前该方法主要在 1B 参数规模上验证，更大规模的泛化性仍需观察。此外，虽然推理开销极低，但多遍预填充会增加首字延迟（TTFT），在实时性要求极高的场景中需权衡使用。
全带宽 Transformer 揭示了一个被忽视的优化维度：通过拓宽垂直反馈通道，我们可以从每个 Token 中提取更多的学习信号。这或许是大模型走向更高效率、更轻量化推理的重要一步。
