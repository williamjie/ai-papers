论文 : Towards Diverse Scientific Hypothesis Search with Large Language Models链接 : https://arxiv.org/abs/2606.10587在利用大语言模型（LLM）进行科学假设搜索时，工程师常面临一个尴尬局面：模型要么陷入局部最优，生成的方案千篇一律；要么为了追求多样性而牺牲了质量。这篇论文提出了一种名为 EvoDiverse 的框架，通过引入统计物理中的“平行退火”机制，在有限的验证预算下，同时实现了高质量与高多样性的平衡。
### 痛点：进化算法的“多样性崩溃”
现有的 LLM 科学发现流程大多采用标准的进化算法（Evolutionary Algorithm, EA）。其逻辑简单粗暴：LLM 生成假设，Oracle 打分，保留高分个体进入下一代。
这种强选择压力导致了严重的 多样性崩溃（Diversity Collapse） 。随着迭代进行，种群迅速收敛到狭窄的解空间区域。这在科学发现中是致命的，因为真实世界的验证充满噪声，单一的最优解往往无法应对下游的不确定性。科学家需要的不是一个“最好”的假设，而是一组高质量且相互独立的候选方案。
### 核心 Insight：把搜索看作采样问题论文的核心直觉是将假设搜索重构为一个 采样问题（Sampling Problem） ，而非单纯的优化问题。
作者受经典**平行退火（Parallel Tempering, PT）**算法启发，设计了双温度层的进化框架：
- 高温池（Hot Pool）：采用容忍度更高的选择策略（较小的 β\beta），鼓励激进探索，生成结构新颖但分数可能较低的假设。
- 低温池（Cold Pool）：采用严格的选择策略（较大的 β\beta），专注于精炼高分假设。
关键在于 信息交换机制 。不同于简单的岛屿模型直接迁移个体，EvoDiverse 使用 Metropolis-Hastings 规则 进行跨温度层的“交换”。只有当交换符合玻尔兹曼分布的概率时，个体才会在高低温池间流动。这确保了高质量个体能流向低温池被精炼，而具有潜力的新颖个体能保留在高温池继续演化，避免了劣质解污染收敛过程。

### 工程启示：如何落地？
对于正在构建科学 Agent 或自动化研发流水线的工程师，这篇论文提供了三个具体建议：
- 不要只保留 Top-K：在迭代搜索中，强行截断低分个体是多样性的杀手。应引入温度参数，动态调整选择压力。
- 结构化交换优于随机迁移：简单的多种群并行（Ensemble）缺乏有效通信，导致效率低下。采用基于概率的 Metropolis-Hastings 交换机制，能更精准地传递“有价值的新颖性”。
- 提示词工程需配合温度：论文提到，高温池可使用鼓励“结构多样性”的 Prompt，低温池使用“精炼活性”的 Prompt。这种软硬结合的策略值得在 Agent 设计中尝试。
### 局限与展望目前 EvoDiverse 主要验证于两个温度层。虽然理论上可扩展至多层，但计算开销和交换逻辑的复杂度会增加。此外， ξ(n)\xi(n) 参数的动态调整依赖启发式规则，在不同任务中可能需要重新调优。未来工作可探索自适应温度阶梯或结合质量多样性（Quality-Diversity）算法进一步优化。
总之，如果你发现你的 LLM 进化搜索总是“跑偏”或“死胡同”，不妨试试给种群加个“散热器”。
