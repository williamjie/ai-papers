# ⭐⭐⭐½ MLLM不废语言能力的神经元级微调方案

**日期**: 2026-08-13

论文 : NeuPAT: Neuron-aware Plasticity Allocation Tuning for Language-Preserving MLLMs链接 : https://arxiv.org/abs/2608.08107把大语言模型（LLM）扩展为多模态大模型（MLLM）时，我们常面临一个尴尬的权衡：视觉能力上去了，原本的语言推理能力却掉了。这篇论文提出了一种不依赖额外数据、不改架构的“神经元级”微调方案，能在保持多模态性能的同时，几乎完全恢复被遗忘的语言智能。
### 痛点：为什么加个眼睛会“变笨”？
理想情况下，给 LLM 增加视觉模块应该是能力的纯增量进化。但现实很骨感。论文指出，在标准的多模态指令微调（Multimodal Instruction Tuning）后，模型在关键语言基准上的平均性能暴跌约 39.8% 。
现有的补救措施大多显得笨重：
- 数据回放：混入纯文本数据进行监督微调（SFT），但需要额外的数据收集和复杂的比率调优。
- 架构隔离：修改模型结构以隔离多模态适配，增加了部署复杂度。
- 模型合并：训练后合并原始 LLM 和适配后的 MLLM，往往在语言保留和多模态适应之间难以平衡。
这些方法都是“外部干预”，而没有触及核心问题： 为什么微调会破坏语言能力？
### 核心洞察：神经元并非铁板一块NeuPAT 的核心直觉非常反直觉且优雅：预训练 LLM 内部的神经元具有 异质性的可塑性（Heterogeneous Plasticity） 。
并不是所有神经元都同等重要，也不是所有神经元都适合学习新知识。通过轻量级的探测阶段，作者发现：
- 语言敏感神经元：对保留语言智能至关重要，微调时若被大幅更新，语言能力就会崩塌。
- 多模态适应神经元：对视觉输入更敏感，具有更高的可塑性，适合吸收新的多模态知识。
- 共享与储备神经元：部分神经元在两种模态下都重要，或目前未被充分利用。
⚠️ 关键 Insight ：统一更新所有神经元是低效且危险的。它既无谓地破坏了语言关键表征，又未能充分利用模型内在的可塑性潜力。
### 方法拆解：给神经元“分派角色”
NeuPAT 不需要额外的训练数据，也不修改模型架构。它在微调前引入一个轻量级的探测阶段（Probing Stage），计算每个神经元在纯文本和视觉输入下的激活重要性得分。
基于此，它将每一层的神经元划分为四类角色，并施加不同的更新约束：
- 语言关联神经元 (ClangC_{lang}​)：冻结。直接屏蔽梯度，保护预训练的语言表征不被覆盖。
- 多模态适应神经元 (CmultiC_{multi}​)：全量更新。鼓励这些神经元吸收新的视觉知识。
- 储备神经元 (CreserveC_{reserve}​)：全量更新。作为额外的适应容量，提供灵活性。
- 共享神经元 (CsharedC_{shared}​)：正则化约束。这部分神经元对两种模态都重要，因此不能冻结也不能随意改。论文设计了输入侧和输出侧的偏差约束（Cosine Similarity），限制其偏离预训练参数的程度，以平衡保留与适应。
这种“因材施教”的策略，使得模型在微调过程中能够精准地分配可塑性资源。
### 关键结果：语言恢复率高达 94.5%实验数据非常有说服力。在 Qwen3-4B-Instruct backbone 上，NeuPAT 的表现如下：
指标 Vanilla Tuning NeuPAT 提升幅度 语言基准平均得分 43.92 49.06 +5.14 多模态基准平均得分 60.98 61.05 +0.07- 语言恢复：NeuPAT 恢复了因标准微调导致的 94.5% 的语言能力退化。在某些逻辑推理任务（如 BBH, bAbI）上，甚至略微超过了原始 LLM 的表现。
- 多模态无损：在 MMBench、RealWorldQA 等 5 个多模态基准上，NeuPAT 的平均得分与标准微调持平，甚至在 POPE 指标上提升了 1.03%。
- 泛化性强：该方法在 Qwen、Llama、Phi 等不同家族和规模（0.6B 到 14B）的模型上均有效。例如在 Phi-4-Mini-Instruct 上，语言平均得分提升了 8.75 分。
### 工程启示与局限对工程师的价值：
如果你正在将 LLM 扩展为 MLLM，或者担心微调导致“灾难性遗忘”，NeuPAT 提供了一个极低成本的解决方案。它不需要你收集额外的纯文本数据来平衡数据集，也不需要修改模型代码结构。只需在训练前跑一个轻量级的探测脚本，计算神经元重要性，然后在优化器中应用相应的掩码或正则化即可。
局限与展望：
- 规模验证：目前实验最大到 14B 参数，更大规模模型（如 70B+）的神经元分布可能更复杂，效果待验证。
- 模态限制：目前仅针对视觉-语言扩展。音频、视频或具身交互可能需要不同的重要性估计策略。
- 持续学习：论文主要关注单阶段扩展。在多阶段持续学习中，新引入的模态如何与已学的多模态知识共存，仍是挑战。
总之，NeuPAT 证明了通过理解模型内部的适应动态，我们可以更智能地控制微调过程。这是一种“少即是多”的工程智慧。
