# ⭐⭐½ Skill-3D：让 Agent 像老法师一样懂 3D 空间推理

**日期**: 2026-06-09

---

论文 : Skill-3D: Evolving Scene-Aware Skills for Agentic 3D Spatial Reasoning链接 : https://arxiv.org/abs/2606.07436搞过 3D Agent 的同学都知道，给 MLLM 挂上深度估计、3D 重建等工具后，效果往往不如预期。模型要么乱调工具，要么死磕某几个“万能”工具，导致推理质量停滞不前。这篇论文提供了一个很落地的解法：别把 Agent 当白纸，给它建个“技能库”，让它从过去的成败中学习场景感知的工具调用策略。
### 痛点：工具多了，Agent 反而“迷路”了现有方法（如 Think3D）通常采用统一的工具调用策略，不管场景如何变化，都套用同一套流程。论文指出，室内 3D 推理具有极强的 场景异质性（Scene Heterogeneity） 。
举个例子，问“桌子和炉灶的距离”，需要深度证据；但现有 Agent 往往盲目调用物体检测和 3D 重建，这些工具主要提供相对空间关系，而非绝对距离所需的深度 grounding。结果就是：加了工具也没用，甚至不如非 Agent 基线。
### 核心 Insight：从轨迹中提炼“场景感知技能”
Skill-3D 的核心直觉是： 成功的工具调用路径是可以复用和演化的 。它不再让 Agent 每次从零开始规划，而是通过两个核心组件实现经验传承：
- 场景记忆（Scene Memory）：记录每次推理的完整轨迹（包括问题、观察、工具调用、结果）。
- 技能库（Skill Library）：这是精华所在。它将成功轨迹蒸馏为可复用的“技能”（包含触发条件、所需证据、工具顺序），并将失败轨迹作为“教训（Lessons）”附加在对应技能上。
设计亮点在于“协同演化” ：
- 静态技能提供任务级先验，保持稳定。
- 动态技能根据新场景不断合并、打补丁，覆盖更广泛的变体（如从厨房深度估计泛化到客厅）。
- 失败即资产：失败轨迹不被丢弃，而是转化为 fallback 规则或新的动态技能，防止 Agent 重蹈覆辙。
### 关键结果：工具利用率翻倍，开源模型大幅受益论文在 VSI-Bench、BLINK、CV-3D 和 MMSI-Bench 上进行了全面评估，数据非常硬核：
- 有效工具使用率（ETU）飙升：这是最直观的提升。Skill-3D 将 VSI-Bench 上的 ETU 从 39.2% 提升至 78.7%。这意味着模型不再盲目调用工具，而是精准获取所需证据。
- 闭源模型显著受益：在 MMSI-Bench 上，Gemini-3-Flash 的得分提升了 67%。
- 开源模型通过微调内化技能：通过基于技能的监督微调（SFT）和组相对策略优化（GRPO），Qwen3-VL-8B 在 VSI-Bench 上的平均得分从 41.1 提升至 58.8，相对增益达 42.9%。

### 工程启示：如何落地这套方案？
- 不要只调工具，要管流程：单纯的 Tool Use 容易陷入局部最优。构建一个中间层的“技能检索”机制，能显著降低推理的不确定性。
- SFT + RL 是标配：论文展示了先用技能引导的轨迹进行 SFT，再用 GRPO 进行强化学习的完整链路。对于开源模型，这种“先模仿后优化”的策略能有效内化复杂的行为模式。
- 动态库需冻结训练：在 GRPO 阶段，建议冻结技能库以避免非平稳性（Non-stationarity）问题，确保训练稳定收敛。
### 局限与展望目前 Skill-3D 主要聚焦于室内场景。对于室外开放环境、实时机器人交互等场景，由于工具接口和场景特征的巨大差异，直接迁移可能面临挑战。此外，技能库的维护成本（检索、更新、去重）在实际大规模部署中仍需优化。
总之，Skill-3D 证明了在 3D 空间推理中， “经验”比“算力”更重要 。通过构建可演化的技能库，我们可以让 Agent 从“新手”快速成长为懂场景、会避坑的“老法师”。
