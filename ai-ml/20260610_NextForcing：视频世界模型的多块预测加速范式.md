论文 : Next Forcing: Causal World Modeling with Multi-Chunk Prediction链接 : https://arxiv.org/abs/2606.11187自回归视频生成在具身智能（Embodied AI）中越来越重要，但训练慢、推理拖沓是硬伤。这篇 Next Forcing 论文提供了一个优雅的解法：借鉴 LLM 的多 Token 预测思想，通过多块预测（Multi-Chunk Prediction, MCP）同时提升训练效率和推理速度。
## 痛点：短视监督与外观捷径现有的世界动作模型（World Action Models, WAMs）主要依赖教师强制（Teacher Forcing）进行下一视频块的去噪。这种范式存在严重的**短视监督（Myopic Supervision）**问题。
具体来说，相邻视频块在视觉上高度相似。模型很容易学会一个“近似恒等映射”，即直接复制上一块的像素特征到当前块，只需做微小修正即可大幅降低损失。这种**外观捷径（Appearance Shortcut）**让模型无需真正理解物理动态就能拟合数据。
⚠️ 关键发现 ：在 50 fps 的高帧率下，相邻帧差异极小，外观捷径几乎无损。这导致标准教师强制训练收敛极慢，且最终精度远低于低帧率场景。
## 核心 Insight：用长程预测打破捷径Next Forcing 的核心直觉非常清晰： 将局部单块目标扩展为长程多块目标，迫使模型学习潜在的时间演化动态。
作者引入了轻量级的辅助 MCP 模块，与主模型并行训练。这些模块不仅预测当前块，还同时预测未来第 1、2、3 个视频块（next1, next2, next3）。
### 设计细节拆解- 因果链结构：MCP 模块形成深度因果链。深度 2 的预测基于深度 1 的输出，深度 3 基于深度 2。这种设计让近未来预测为远未来提供信息，形成密集的多尺度时间监督。
- 多层特征融合：为了将 MCP 的监督信号深入传播到主模型，MCP 模块并非只读取主模型的最终层输出，而是融合来自第 4、12、20、30 层的中间隐藏状态。这使得梯度能反向影响主干网络的各个深度阶段。
- 时间步偏移策略：MCP 模块使用比主模型更高的时间步偏移参数（smcp>smains_{mcp} > s_{main}​>smain​）。这意味着 MCP 输入携带的自身目标信息更少，迫使它们更依赖主模型的表征去噪，从而将监督压力有效传递给主模型。

推理加速在推理阶段，MCP 模块可被保留用于并行预测下一视频块。由于 MCP 模块极轻（仅 3 个 Transformer Block），增加其前向传播几乎零成本，实现了 2× 的推理加速，且精度损失可控。
## 工程启示- 训练目标即正则化：不要只盯着上下文构造或噪声调度。改变预测目标（从单块到多块）本身就是一种强大的正则化手段，能有效抑制模型走捷径。
- 高帧率场景的必选项：如果你在做高频视觉控制或视频生成，Next Forcing 的多块预测机制几乎是必须的，否则模型会陷入“复制粘贴”的死循环。
- 部署灵活性：该架构支持两种模式。训练时启用 MCP 获得高质量表征；推理时可选择丢弃 MCP（零开销）或保留 MCP（2倍加速）。这种解耦设计对工程落地非常友好。
## 局限与展望论文指出，MCP 模块会引入额外的训练计算成本。此外，目前并行生成仅利用到深度 1 的预测，更深层的预测因漂移问题未在推理中使用，但这为未来的更高倍率加速留下了探索空间。
