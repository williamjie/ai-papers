# 按需分配：SplatWeaver 的动态高斯分配机制

**日期**: 2026-05-13

---

论文 : SplatWeaver: Learning to Allocate Gaussian Primitives for Generalizable Novel View Synthesis链接 : https://arxiv.org/abs/2605.07287在即时 3D 重建（Generalizable Novel View Synthesis）领域，效率与质量的平衡一直是工程师的噩梦。现有的前馈式（Feed-forward）方法大多采用“一刀切”的策略：要么给每个像素固定数量的 3D 高斯（3D Gaussian Splatting, 3DGS）原语，要么使用固定数量的 Token 查询。这种做法极其浪费——在平滑的墙面区域，大量高斯原语纯属冗余；而在复杂的纹理或几何细节处，预算又往往捉襟见肘。
哈尔滨工业大学和华为诺亚方舟实验室联合提出的 SplatWeaver ，核心洞察非常直接且务实： 既然场景复杂度是空间变化的，为什么高斯原语的分配不能也是动态的？ 它提出了一种基于“基数（Cardinality）”的高斯专家路由机制，让模型学会在复杂区域“多投”，在平滑区域“少投”。
## 痛点：均匀分配的浪费传统方法如 AnySplat 或 EcoSplat，虽然实现了无相机位姿（Pose-free）的前馈重建，但它们在分配高斯原语时缺乏自适应能力。
- 均匀分配：无论像素对应的是平坦墙壁还是精细栏杆，模型都分配相同数量的潜在高斯。
- 固定 Token 限制：如 C3G 和 TokenGS 虽然引入了 Token 查询，但预定义的 Token 数量限制了其适应性，导致要么过拟合要么欠拟合。
这种僵化的分配导致了两极分化：简单区域资源浪费，复杂区域细节丢失。SplatWeaver 试图打破这种僵局，实现“复杂处密集，平滑处稀疏”的智能分配。
## 方法拆解：专家路由与频率先验SplatWeaver 的核心设计可以拆解为三个关键模块，其工程直觉值得细品。
### 1. 基数高斯专家（Cardinality Gaussian Experts）
这是论文最核心的创新。作者没有让网络直接回归所有高斯参数，而是引入了多个“专家”网络。
- 专家分工：每个专家 EeE_e​ 专门负责预测特定数量（基数）的高斯原语，范围从 0 到 MM。论文中 MM 设为 3，即专家最多预测 3 个隐藏高斯。
- Null Expert：特意引入了一个预测 0 个高斯的“空专家”，用于处理完全平滑、无需额外几何信息的区域。
- 隐藏表示：专家不直接输出最终的高斯参数（位置、旋转、颜色等），而是输出空间位置 μ\mu 和潜在特征 FlF_l​。最终的缩放、旋转和颜色参数由后续的聚合模块结合上下文生成。
Why？ 这种解耦设计避免了专家直接预测复杂参数时的空间上下文缺失问题，让专家专注于“这里需要几个点”，让聚合模块专注于“这些点长什么样”。
### 2. 频率先验引导（High-Frequency Prior）
如何让模型知道哪里该多分配高斯？靠直觉是不够的，需要信号。
- 离散小波变换（DWT）：作者利用输入图像的小波变换提取高频分量（LH, HL, HH）。
- 高频能量图：计算高频能量的平方和，生成一张“复杂度地图”。直觉很朴素：高频能量高的地方（如边缘、纹理），结构复杂，需要更多高斯；低频能量高的地方（如天空、墙面），结构简单。
- 特征调制：将这张能量图通过简单的卷积和 Sigmoid 生成注意力图，调制原始像素特征。这使得路由网络在决策时，天然携带了场景复杂度的先验知识。
### 3. 像素级路由与正则化- 路由决策：每个像素根据调制后的特征，通过 Gumbel-Softmax 选择最适合的专家（Hard Top-1 选择，保留物理意义）。
- 路由正则化（Routing Regularization）：为了防止模型乱选专家，作者设计了一个辅助损失。根据高频能量图对像素进行排名，高频像素强制路由到高基数专家，低频像素路由到低基数专家。
- 训练策略：这个正则化仅在训练前半程使用，后期移除，让模型自主探索最优分布，同时配合一个总预算约束损失（LbudgetL_{budget}​）防止高斯总数爆炸。

## 工程启示- 显存与推理速度的杠杆：对于端侧部署或大规模场景重建，高斯原语的数量直接决定显存占用和渲染帧率。SplatWeaver 证明了通过动态分配，可以在不降低甚至提升质量的前提下，将原语数量减少一个数量级（从 ~1.5M 降至 ~150k）。
- 先验信号的价值：利用图像的频域特征（如小波变换）作为路由信号，是一种低成本且高效的引导方式。这种“内容感知”的思路可以迁移到其他神经渲染或点云生成任务中。
- 解耦设计的稳健性：将“数量决策”与“参数预测”解耦，并通过邻居聚合来完善参数，这种模块化设计提高了模型的稳定性和可解释性。
## 局限与展望尽管 SplatWeaver 表现优异，但仍需注意：
- 训练依赖：虽然推理是前馈的，但训练过程引入了路由正则化和频率先验计算，增加了训练阶段的复杂性。
- 极端纹理挑战：对于极度缺乏高频信息但结构复杂的场景（如纯白雾中的人形轮廓），高频先验可能失效，路由可能不够准确。
- 专家数量限制：当前 M=3M=33 的专家数量是基于实验设定的，对于超高清或超大场景，是否需要更多粒度的专家值得进一步探索。
总的来说，SplatWeaver 为通用 3D 重建提供了一个极具工程价值的思路： 不要平均用力，要让资源流向最需要的地方。
