# ⭐⭐⭐½ 音视频大模型加速：SEATS 分层剪枝实战

**日期**: 2026-05-20

论文 : Stage-adaptive Token Selection for Efficient Omni-modal LLMs链接 : https://arxiv.org/abs/2605.20035全模态大模型（Omni-modal LLMs）在处理音视频时，Token 数量动辄上万，导致推理成本极高。现有的加速方案要么只看视觉，要么在 LLM 之前粗暴地按固定比例裁剪，缺乏对模态间动态依赖关系的理解。SEATS 提出了一种“分层自适应”的 Token 选择策略，无需重新训练，即可在大幅降低计算量的同时，保持甚至超越全量 Token 的性能。
### 核心洞察：LLM 内部对音视频的依赖是动态递减的大多数现有方法假设所有层对非文本 Token 的依赖程度相同，或者仅在 LLM 入口处进行一次性筛选。SEATS 的作者通过实验发现，LLM 对音视频 Token 的依赖呈现明显的 块状（Block-wise）递减模式 ：
- 浅层（前 50% 层）：高度依赖音视频 Token 进行跨模态融合，此时移除会导致性能崩溃。
- 中层（50%-80% 层）：跨模态融合正在进行，文本 Token 逐渐吸收语义，对非文本 Token 的依赖减弱。
- 深层（后 20% 层）：融合基本完成，非文本 Token 已成为冗余，移除它们几乎不影响性能。
这一洞察直接挑战了“统一保留率”的传统做法，为动态分配计算资源提供了理论依据。
### 方法拆解：三阶段自适应策略SEATS 将加速过程分为三个阶段，针对不同阶段的特点采用不同策略：
-预 LLM 阶段（Pre-LLM）：基于多样性的窗口筛选痛点：音视频在时间窗口内存在大量时空冗余。
- 方案：改进 DivPrune 算法，在每个时间窗口内，利用注意力权重加权，通过贪心算法最大化 Token 间的多样性距离。这步操作旨在去除冗余，保留最具代表性的关键帧/音频片段，且保留率略高于后续阶段，为内部筛选留有余地。
-LLM 内部阶段（Inner-LLM）：指数衰减的保留率调度痛点：浅层需要更多信息，深层需要更少，固定比例要么太激进要么太保守。
- 方案：设计了一个块状衰减调度（Block-wise Decay Schedule）。
浅层：保持预 LLM 阶段的高保留率，不额外剪枝。
- 中层：保留率呈指数级递减。例如在 Qwen2.5-Omni-7B 中，第 17-24 层的保留率逐步降低，越深的层剪枝越激进。
- 深层：直接移除所有剩余的非文本 Token，后续层仅处理文本 Token，极大降低计算复杂度。
-动态预算分配：自顶向下的查询感知痛点：不同时间窗口和模态（视觉 vs 音频）对用户查询的重要性不同。
- 方案：采用“自顶向下”的两级分配策略。
窗口级：根据查询（Query）与窗口内视觉/音频 Token 的交叉注意力分数，分配 Token 预算。与查询相关的窗口获得更多保留名额。
- 模态级：在窗口内部，根据视觉和音频各自的相关性，动态调整两者的保留比例。例如，若问题侧重声音，则自动增加音频 Token 的保留率。
### 关键结果：效率与性能的双赢在 Qwen2.5-Omni-7B 和 Qwen3-Omni-30B 上的实验表明，SEATS 在多个基准测试中均取得了最佳的性能-效率权衡。

- 极致加速：在仅保留 10% Token 的极端情况下，SEATS 实现了 9.3 倍的 FLOPs 降低和 4.8 倍的预填充（Prefill）加速，同时保留了 96.3% 的性能。
- 开销极低：Token 选择本身的计算开销极小（预 LLM 阶段约 19-34ms，LLM 内部约 62-92ms），且随着保留率降低而减少，几乎不影响端到端延迟。
### 工程启示- 无需微调的即插即用：SEATS 是 Training-free 的，可以直接应用于现有的全模态模型，如 Qwen-Omni 系列。对于部署成本敏感的场景，这是一个低风险的优化选项。
- 动态预算分配是关键：实验表明，简单的全局排名或固定模态比例效果不佳。自顶向下的查询感知分配能更好地处理多模态交互中的不确定性（如某些问题更依赖音频）。
- 深层剪枝的可行性：在 LLM 深层完全移除非文本 Token 是一个大胆但有效的策略。这意味着在实现 KV Cache 优化时，可以针对深层设计特殊的缓存清理机制，进一步节省显存。
### 局限与展望- 模型依赖性：目前的边界层设置（如浅层/中层/深层的分界点）是针对特定模型（Qwen2.5/3-Omni）调优的。迁移到其他架构的全模态模型时，可能需要重新分析其层间依赖模式。
- 单模态泛化：虽然论文主要针对全模态，但其分层剪枝的思想同样适用于纯视频或纯图像 LLM，未来可进一步简化逻辑以适配单一模态场景。
SEATS 通过深入理解 LLM 内部的模态融合过程，证明了“智能剪枝”比“暴力压缩”更有效。对于追求极致推理效率的工程团队而言，这是一种值得尝试的优化路径。
