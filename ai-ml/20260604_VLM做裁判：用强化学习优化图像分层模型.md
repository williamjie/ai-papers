论文 : Stable-Layers: Fine-Tuning Image Layer Decomposition Models with VLM-Scored Reinforcement Learning链接 : https://arxiv.org/abs/2605.30257图像分层（Image Layer Decomposition）是专业修图的底层能力，但传统方法极度依赖成对的标注数据。Stability AI 提出的 Stable-Layers 证明了一个工程直觉：只要 VLM 的评判足够精细，我们完全可以用强化学习（RL）在自然图像上微调分层模型，彻底摆脱对合成数据的依赖。
### 痛点：为什么分层任务很难做 RL？
现有的分层模型（如 Qwen-Image-Layered）通常通过回归损失训练，这意味着当存在多种合理的分解方案时，模型会被迫向单一目标妥协。更麻烦的是，分层质量是多维度的：语义分离、Alpha 通道洁净度、背景重绘合理性等。
直接用 VLM 打分做奖励信号行不通。VLM 在孤立评估样本时，倾向于给出狭窄区间的分数（Score Compression）。如果一组候选样本的得分都在 0.7-0.9 之间，GRPO 算法就缺乏足够的组内方差来计算优势函数（Advantage），导致模型学不到东西。
### 核心设计：两阶段 VLM 奖励机制为了解决“奖励信号压缩”问题，作者设计了一套巧妙的 两阶段评估协议 ：
-第一阶段：结构化独立评分VLM 根据五个明确锚定的标准（语义分离、Alpha 洁净度等）对每个样本进行 0-5 分打分。这一步能迅速过滤掉明显的失败案例（如空白层或噪点层）。
-第二阶段：网格相对校准（Grid Calibration） ⚠️这是核心 Insight。当第一阶段分数趋同，VLM 会将所有候选样本拼成一个对比网格，进行相对重评分。
直觉解释：单独看两张图可能都“还行”，但放在一起比，就能看出谁的重绘更自然、谁的边缘更干净。这种相对校准恢复了组内方差，让 GRPO 有了可优化的梯度信号。
此外，针对 Flow-Matching 模型中 latent 序列打包导致的重要性比率（Importance Ratio）坍缩问题，作者修改了 RatioNorm，通过求和再缩放的方式，恢复了优化稳定性。
### 实验结果：数据不说谎在 Crello 数据集上的量化对比显示，Stable-Layers 在所有层数配置下均优于基线模型：

### 工程启示与避坑指南- 相对评估优于绝对评分：在 RLHF/RLAIF 实践中，如果 VLM 打分方差太小，务必尝试引入对比网格或 Pairwise Preference 机制来增强判别力。
- Prompt 越详细可能越差：消融实验显示，使用详细描述理想场景的 Prompt 反而导致性能下降。简单的固定 Prompt 配合 VLM 的视觉判断，效果更佳。
- 计算成本考量：由于 GRPO 需要采样多个候选并多次调用 VLM，训练被限制在最多 5 层。对于高维输出任务，需权衡推理延迟与奖励精度。
### 局限该方法依赖专有 VLM 作为裁判，存在 API 成本和模型版本漂移风险。且目前仅在少量层数上验证，20 层以上的极端分解场景尚未测试。
