论文 : SLPO: Scaling Latent Reasoning via a Surrogate Policy链接 : https://arxiv.org/abs/2607.19691显式思维链（Chain-of-Thought, CoT）虽然强大，但每个中间步骤都要解码为文本 token，计算成本极高且充满冗余。潜空间推理（Latent Reasoning）将中间计算压缩为连续向量，速度快、效率高，却长期被困在“模仿学习”阶段，无法像显式 CoT 那样通过结果奖励强化学习（Outcome-Reward RL）实现测试时扩展（Test-Time Scaling）。
SLPO 的出现打破了这一僵局。它让潜空间推理也能享受 RL 的红利，实现了真正的自适应计算分配。
### 为什么潜空间推理以前做不了 RL？
核心痛点在于 不可微的奖励分配 。
在显式 CoT 中，每一步都是词汇表上的离散采样，我们可以直接计算 log P(token) ，利用策略梯度（Policy Gradient）将最终答案的正确性奖励回溯到每一个 token。
但在潜空间推理中，中间状态是连续的隐藏向量（Hidden States），它们绕过了词汇分布。这导致两个致命问题：
- 缺乏可处理的似然函数：连续向量没有明确的 action probability，传统的 PPO 或 GRPO 无法直接计算优势函数（Advantage）。
- 固定思考预算：现有模型通常预设固定的推理步数，无法根据题目难度动态决定“何时停止思考”。
### SLPO 的核心设计直觉SLPO 通过两个关键组件解决了上述问题，其设计非常巧妙：
1. 代理策略似然（Surrogate Policy Likelihood）
既然连续向量没有解析的概率密度，那就 构造一个 。
SLPO 利用 MC-Dropout 的随机性，对每个前缀进行 KK 次前向传播，得到一组潜状态样本。然后，它用这些样本的均值和方差构建一个对角高斯分布作为“代理似然”。
- Why? 这为策略梯度提供了一个标量分数，使得最终奖励可以反向传播到潜空间的每一步过渡中。注意，采样出的轨迹被视为 stop-gradient 目标，梯度仅通过当前策略的重计算流动，确保了训练的稳定性。
2. 正确性监督的停止门（Stopping Gate Cold Start）
为了让模型学会“何时停”，SLPO 增加了一个停止头（Stopping Head）。
- 冷启动策略：在 RL 之前，先用确定性答案的正确性对停止时间进行监督微调。如果长度为 tt 时答案正确，就鼓励模型在该步停止。
- RL 优化：随后，将停止概率纳入整体策略目标。高奖励的轨迹会强化其对应的“继续/停止”决策。
### 实验效果：不仅准，而且省SLPO 在 GSM8K、GSM-Hard 和 MultiArith 等数学推理基准上进行了全面测试。以下是关键数据对比（基于 Llama-3.2-1B 骨干）：
方法 GSM8K Acc GSM-Hard Acc MultiArith Acc 平均推理长度 (#L) COCONUT (Baseline) 21.23% 4.55% 41.10% 6.00 (固定) COCONUT+SLPO 22.37% 5.77% 46.90% 5.77 (自适应) CODI (Baseline) 55.22% 12.82% 95.52% 6.00 (固定) CODI+SLPO 55.27% 13.20% 96.38% 6.30 (自适应)
⚠️ 反直觉发现 ：SLPO 不仅在准确率上提升，更实现了 计算资源的动态分配 。
实验显示，题目难度（以失败率衡量）与潜空间推理长度呈正相关（Pearson r=0.26r=0.26 0.26 ）。简单题快速终止，难题则分配更长向量序列。这种“按需思考”的能力是固定预算模型无法具备的。
此外，在并行采样（Pass@k）场景下，SLPO 带来的提升更为显著。例如在 GPT-2 骨干上，CODI+SLPO 的 Pass@16 从 54.81% 提升至 55.84% ，证明了 RL 优化后的潜策略具有更好的探索能力。
### 工程启示与落地建议对于正在构建高效推理 Agent 或本地部署模型的工程师，SLPO 提供了三点重要参考：
- 不要迷信显式 CoT：在资源受限场景下，潜空间推理是更优解。SLPO 证明了即使没有自然语言输出，模型也能通过向量迭代获得深度推理能力。
- RL 需要“代理”桥梁：如果你的任务涉及连续动作或隐状态，直接套用 PPO 会失败。考虑构建类似 SLPO 的代理似然（如基于采样统计的高斯近似），将离散奖励映射到连续空间。
- 停止机制至关重要：自适应推理长度是测试时扩展的核心。通过简单的正确性监督冷启动，再结合 RL 微调，可以让模型学会“知难而进”或“见好就收”，大幅降低平均推理成本。
### 局限与展望目前 SLPO 主要验证于数学推理任务（GSM8K, MATH500 等），其在开放域逻辑推理或多模态场景下的泛化能力仍需探索。此外，代理似然的构建依赖于 MC-Dropout 的随机性，这可能对某些确定性强的骨干模型效果有限。
总之，SLPO 为潜空间推理打开了一扇通往强化学习的大门。它不仅仅是一个算法改进，更是一种范式转移： 让隐式思考也能被奖励驱动，实现真正的智能扩展。
