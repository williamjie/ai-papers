# ⭐⭐⭐⭐ 机器人伦理新基准：当安全与隐私冲突时选谁？

**日期**: 2026-06-05

---

论文 : RobotValues: Evaluating Household Robots When Human Values Conflict链接 : https://arxiv.org/abs/2606.03312现在的家庭机器人评测大多盯着“任务完成率”看。但现实是，当老人摔倒且配偶在场时，是直接冲过去扶（优先安全），还是站在旁边等指令（优先自主权）？这种没有标准答案的“价值观冲突”，才是家庭机器人真正棘手的难题。这篇论文提出了 ROBOT VALUES 基准，专门用来测试机器人在这种两难境地下的决策逻辑。
### 现有评测的盲区目前的机器人基准（如 RT-2、OpenVLA 等）主要关注机械臂能否抓起物体或执行长程指令。它们假设目标已经明确，只评估执行能力。
然而，在家庭环境中，机器人拥有视觉感知权，其决策直接影响用户的隐私、尊严和安全。现有的评测体系缺乏对“价值观权衡”的量化标准。更麻烦的是，收集真实的家庭冲突数据涉及严重的隐私泄露风险，导致这一领域长期缺乏高质量数据集。
### 核心设计：基于利益相关者的价值锚定ROBOT VALUES 的核心 Insight 在于： 不要直接给动作贴标签，而是通过模拟“利益相关者”的反应来推导价值。
传统的做法是人工定义一套价值观分类树，然后强行给每个动作打标。这种方法容易流于表面。作者采用了一种更细腻的流程：
- 种子生成：利用世界价值观调查（WVS7）的数据作为 Persona 种子，确保场景涵盖不同国家、家庭结构和年龄层，避免 LLM 生成的同质化问题。
- 动作生成与反应模拟：针对每个场景生成 17 个可行动作。关键步骤是，让 LLM 模拟场景中所有利益相关者（如当事人、家属）对每个动作的第一人称反应（支持/反对/中立）。
- 价值提取：从这些具体的反应中，逆向推导出该动作优先保障的价值观（例如：“保护过敏源物品”或“尊重老年人独立性”）。
这种设计确保了价值标注是情境化的（Situated），而非通用的。最终通过多阶段的质量控制（包括图像真实性和第一人称视角合理性），筛选出 10,073 个高质量实例。
### 关键发现：模型有严重的“安全偏执”
作者使用 ROBOT VALUES 评测了多款主流机器人 VLM（如 Qwen3-VL、InternVL、Molmo 等）。结果揭示了一个反直觉的现象：
⚠️ 当用户明确要求优先保护隐私时，模型仍有 80% 的概率选择错误动作。
具体数据如下表所示（基于 Bradley-Terry 得分）：
模型 最高偏好值 (Safety/Accommodation) 最低偏好值 (Privacy/Security) Qwen3-VL-2B Safety (+0.70), Accommodation (+0.37) Security (-0.84), Privacy (-0.83) InternVL3-8B Safety (+0.61), Accommodation (+0.39) Security (-0.95), Privacy (-0.91) Molmo2-ER Honesty (+0.56), Safety (+0.38) Privacy (-0.68), Security (-0.67)
所有模型都表现出对“安全”和“迁就（Accommodation）”的强烈默认偏好，而极度忽视“隐私”和“信息安全”。
更严重的是 指令跟随能力的失效 。在“值条件化选择”实验中：
- 当目标值与模型默认偏好一致时，准确率在 40.2% - 51.3%。
- 当目标值与默认偏好冲突时，准确率暴跌至 6.9% - 16.8%。
这意味着，即便你明确告诉机器人“请优先保护隐私”，它依然会固执地选择它认为“更安全”的动作。这并非模型不懂什么是隐私（在单独的价值匹配测试中，模型能正确识别动作对应的价值观），而是它们无法在冲突中抑制自己的默认偏见。
### 工程启示：微调是唯一的解药吗？
对于正在构建家庭机器人 Agent 的工程师来说，这篇论文敲响了警钟：
- 不要迷信 Prompt Engineering：简单的指令注入（Instruction Tuning）不足以覆盖模型深层的价值偏见。如果底层预训练数据中“安全”权重过高，仅靠上下文提示很难扭转。
- 需要针对性的 SFT：作者在实验中发现，使用 ROBOT VALUES 对 Qwen3-VL-2B 进行监督微调（SFT），能显著改善其在值条件化任务上的表现。这表明，构建包含价值观冲突的小规模高质量数据集，并进行针对性微调，是目前可行的落地路径。
- 硬件无关的评估标准：该基准采用第一人称视角且隐藏机器人本体，这意味着你可以直接用它来评估你的视觉大模型（VLM）决策层，无需关心具体的机械臂型号。
### 局限与展望目前 ROBOT VALUES 依赖合成图像，虽然经过严格的质量控制，但仍可能无法完全复现真实家庭中的传感器噪声和复杂光照。此外，价值观的定义本身具有文化差异性，目前的 WVS7 种子虽覆盖了 64 个国家，但在细粒度的文化规范上仍有探索空间。
总之，如果你正在开发面向 C 端家庭的机器人产品，请务必关注“价值观冲突”这一维度。毕竟，一个总是过度保护而侵犯隐私的机器人，很难获得用户的长期信任。
