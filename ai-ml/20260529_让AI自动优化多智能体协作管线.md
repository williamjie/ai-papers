论文 : Discovering Cooperative Pipelines: Autoresearch for Sequential Social Dilemmas链接 : https://arxiv.org/abs/2605.30003这篇论文最让人兴奋的点在于：它不再局限于调优单个 Prompt，而是让一个“研究员 Agent”直接去改另一个“合成器 Agent”的底层代码管线。这种双层自动研究范式在解决多智能体协作难题时，展现了惊人的工程价值。
### 为什么需要这种方法？
在多智能体序列社会困境（Sequential Social Dilemmas, SSDs）中，传统强化学习面临信用分配和非平稳性的巨大挑战。前作 Gallego [3] 提出了用 LLM 生成 Python 策略代码的思路，这跳过了参数空间优化，直接在算法空间寻找协调逻辑。
但问题随之转移：内层合成管线包含系统提示、反馈函数、辅助库和迭代逻辑等大量自由参数。此前这些全靠人工调优，极其繁琐且难以保证全局最优。
核心直觉是：既然 LLM 能写策略代码，那它能不能也写“生成策略的流水线”？这就是本文提出的双层自动研究框架。
### 方法拆解：信息设计的视角系统分为两层：
- 内层（Inner Loop）：一个冻结的 LLM 作为策略合成器，根据当前管线配置生成 Python 策略函数，在自玩中评估并迭代优化。
- 外层（Outer Loop）：研究员 Agent（Claude Opus 4.6）作为编码代理，直接操作 Git 仓库。它读取内层源码、修改提示词和反馈逻辑、运行评估，并根据社会福利目标决定保留哪些修改。
核心 Insight ：这不仅是超参搜索，更是一种信息设计（Information Design）。研究员 Agent 充当机制设计师，通过控制向合成器暴露的信息结构（如是否强调公平性指标、提供何种辅助函数），来引导具有有限理性的合成器产生期望的协作行为。
研究员可以修改的配置空间 CC 包括：
- pp：系统提示词- ϕ\phi：反馈构建函数- HH：辅助函数库- ι\iota：迭代逻辑### 关键结果：自动发现公平机制实验在 Cleanup（公共物品提供）和 Gathering（公共资源竞争）两个游戏中进行，对比了人工基线和仅优化 Prompt 的 GEPA 方法。

⚠️ 反直觉发现 ：在优化功利主义效率（Utilitarian Efficiency）时，研究员倾向于让部分智能体固定承担清洁任务；但在优化罗尔斯极大极小（Rawlsian Maximin，即最差个体收益最大化）时，研究员会自动在提示词中注入基于时间的轮值公平机制。
在 Cleanup 游戏中，针对 Gemini 模型，极大极小优化仅牺牲了 1% 的效率（U: 3.20 vs 3.16），却将平等度从 0.55 提升至 0.98，并将最差个体收益从 -159 提升至 290。这种公平机制在研究员的系统提示中原本不存在，完全是根据优化目标自动涌现的。
### 工程启示- 管线即代码：将 LLM 应用的整个生成流程视为可搜索的代码库，比单纯调优 Prompt 空间更大、效果更稳。
- 自动化机制设计：通过外层 Agent 自动调整内层 Agent 的信息输入和工具可用范围，可以无需人工干预地实现复杂的公平性或效率权衡。
- 方差控制：研究员会自动增加评估种子数（从 5 增加到 12）来降低运行间方差，这是人类研究者容易忽略的工程细节。
### 局限与展望目前方法依赖于网格世界环境，且内层验证管线本身是人工设计的工件。未来可探索将框架应用于代码优化、科学实验设计等其他 LLM 驱动管线，并测试对抗性目标下的奖励黑客风险。
