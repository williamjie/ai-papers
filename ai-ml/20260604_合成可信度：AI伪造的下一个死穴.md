# ⭐⭐½ 合成可信度：AI伪造的下一个死穴

**日期**: 2026-06-04

---

论文 : SynCred-Bench: Benchmarking Synthetic Credibility in AI-Generated Visual Misinformation链接 : https://arxiv.org/abs/2606.03348现在的多模态大模型（MLLM）不仅能画图，还能画出“像真的”文件。
当一张伪造的银行流水或政府通知拥有完美的排版、印章和扫描痕迹时，现有的检测器彻底失灵了。
这篇来自清华大学的论文定义了一个新概念： 合成可信度（Synthetic Credibility） 。它指出，未来的视觉虚假信息威胁，不在于图像是否逼真，而在于它是否模仿了权威格式和传播痕迹。
### 为什么现在的检测器不管用了？
传统的 AIGC 检测主要关注自然场景照片或人脸 Deepfake。它们依赖的是生成模型留下的像素级指纹（如频率域异常）。
但“合成可信度”攻击完全不同。它由两个维度构成：
- 可信形式（Credible Form）：模仿新闻、公文、证书等具有权威性的视觉格式。
- 可信流通（Credible Circulation）：模仿扫描、拍照、截图压缩等真实传播过程中留下的痕迹。
这种设计直觉非常致命： 模型不再寻找“生成瑕疵”，而是被“真实感线索”误导。 当一张假图看起来像是一张被手机拍过的纸质文件时，检测器往往将其误判为真，因为那些噪点和畸变在人类认知中代表“真实”。
### 实验结果：全线崩盘作者构建了 SynCred-Bench ，包含 600 张 AI 生成的虚假信息图像和 450 张真实负样本（FP450）。测试结果令人绝望：
模型类型 典型表现 关键指标 (FPR ≤ 5%) 15个 MLLM 平均准确率仅 31.2% TPR 仅 10.5% 开源检测器 普遍失效 TPR < 5% 商业 API 表现相对最好 平均准确率 57.6% 人类标注员 即使多人投票也吃力 TPR 仅 63.0%⚠️ 反直觉发现 ：最强的 MLLM Claude Opus 4.6 在严格约束下（FPR 5%）TPR 也只有 69.5%，而大多数主流模型如 GPT-4o、Gemini 甚至低于 25%。
更可怕的是错误归因分析。模型判定为“真”的理由中， 66.1% 提到了结构化布局， 61.1% 提到了 UI/截图惯例。也就是说， 模型把“像真的排版”当成了“它是真的证据” 。
### 流通风格如何操纵判断？
论文深入分析了不同“流通风格”对检测的影响，发现某些处理手法会系统性降低检出率：
- 屏幕拍照（Screen Photograph）：检出率下降 11.1%。摩尔纹和反光让模型觉得这是真实拍摄。
- 裁剪视图（Cropped View）：检出率下降 10.3%。缺失边缘信息让模型难以判断上下文真实性。
- 传真副本（Fax Copy）：检出率反而上升 9.4%。因为低质量噪点更接近传统生成模型的瑕疵特征。
这意味着，攻击者只需对生成的假图进行简单的“手机拍照”或“截图裁剪”，就能大幅绕过现有检测防线。
### 工程启示与落地建议对于正在构建内容安全或鉴真系统的工程师，这篇论文给出了明确的警示：
- 放弃纯视觉指纹检测：传统的基于 CNN/扩散模型指纹的检测器在面对文档类、界面类伪造时基本无效。
- 引入来源验证（Provenance）：必须结合 C2PA 等水印和元数据验证技术。视觉特征不可信，但加密签名可信。
- 重新训练检测器：现有的 AIGC 检测数据集严重偏向自然图像。你需要补充大量包含“扫描、拍照、压缩”痕迹的文档类伪造样本进行微调。
- MLLM 提示词工程：不要只问“这是 AI 生成的吗？”。要引导模型区分“视觉合理性”与“来源真实性”，例如：“请忽略排版的专业性，仅从像素分布和文本渲染一致性角度分析。”
### 局限与展望目前该基准主要基于 GPT Image 2 生成，且仅覆盖中英文。随着更多开源生成模型具备文档生成能力，伪造的多样性和隐蔽性会进一步增加。
此外，人类标注员仅有 63% 的准确率也说明， 这是一个连人都难分辨的问题 。未来的方向不是让 AI 做得更像人眼，而是建立一套不依赖视觉直觉的、基于密码学和溯源技术的信任体系。
在“合成可信度”面前，眼见已不再为实。工程师们需要尽快从“检测伪造”转向“验证来源”。
