# 拒绝采样调控熵值，破解LLM强化学习瓶颈

**日期**: 2026-05-13

---

论文 : Addressing Performance Saturation for LLM RL via Precise Entropy Curve Control链接 : https://arxiv.org/abs/2604.26326在大型语言模型（Large Language Models, LLMs）的强化学习（Reinforcement Learning, RL）训练中，我们常遇到一个尴尬的现象：随着训练数据量和计算资源的增加，模型性能却在某个节点突然“撞墙”，不再提升。这就是 性能饱和（Performance Saturation） 。普渡大学团队提出的 Entrocraft 方法，没有引入复杂的损失函数，而是通过简单的**拒绝采样（Rejection Sampling）**直接操控策略的熵（Entropy）曲线，成功打破了这一瓶颈。
## 为什么现有方案搞不定熵崩溃？
RL 训练的核心矛盾在于 探索（Exploration） 与 利用（Exploitation） 的平衡。在长程推理任务中，模型容易过度自信地收敛到少数几条正确路径上，导致策略分布过于尖锐，熵值急剧下降。这种 熵崩溃 直接限制了模型的泛化能力和多样性。
现有的补救措施主要有三类：
- 正则化：在 Loss 中加入熵项，容易受超参数影响，导致训练不稳定。
- 截断（Clipping）：如 DAPO 或 Clip-Cov，通过截断高优势样本来抑制熵减，但往往导致熵值在后期漂移甚至爆炸。
- 正负解耦：分别处理正负样本，虽然有效，但改变了原有的优化目标，实现复杂。
这些方法的共同痛点是： 无法精确控制熵的演化轨迹 。它们要么让熵在高位震荡，要么在后期失控。我们需要一种能像调整学习率一样，精确规划熵值随训练步数变化的方法。
## Entrocraft 的核心 InsightEntrocraft 的关键突破在于重新建立了 优势函数（Advantage） 与 熵变化 之间的理论联系。
作者通过理论推导证明：在满足一定概率置信度条件时， 熵的变化与优势值符号相反 。
- 高优势样本（正反馈）：倾向于降低熵，使策略更确定。
- 低/负优势样本：倾向于增加熵，保持探索。
这意味着，如果我们想控制熵，不需要修改 Loss，只需要控制哪些样本进入梯度更新即可。
Entrocraft 的工程实现极其简洁：
它引入了一个基于当前熵值的动态拒绝采样过滤器。
- 设定一个目标熵范围 (hlow,hhigh)(h_{low}, h_{high})​,hhigh​)。
- 如果当前熵低于下限，说明模型太“自信”了，此时拒绝高优势样本，只保留低优势或负优势样本，强制增加探索。
- 如果当前熵高于上限，说明模型太“发散”了，此时拒绝负优势样本，只保留正优势样本，强制收敛。
这种方法不依赖任何额外的正则化项，且对优势估计器（Advantage Estimator）完全通用，可以直接插件式地嵌入到 GRPO、PPO 等任何策略梯度算法中。

更令人印象深刻的是长程训练的效果：
- 打破饱和：标准 GRPO 在 100K 样本后性能停滞，而 Entrocraft 能维持提升长达 4倍 的时长才进入平台期。
- 小模型击败大模型：使用 Entrocraft 训练的 4B 模型，在 AIME-25 上超过了使用标准 GRPO 训练的 8B 基线模型。
- 曲线稳定性：相比于固定熵目标导致的剧烈波动，**线性退火（Linear Annealing）**策略（从 0.6 线性衰减至 0.2）提供了最稳定的训练动态。
## 工程启示与局限对工程师的指导意义：
- 熵是可调超参数：不要只盯着 Loss 看。将熵视为类似学习率的可调度参数，采用退火策略（从高熵探索到低熵利用）是提升长程 RL 训练稳定性的最佳实践。
- 轻量级改造：如果你的 RL 训练出现早期收敛或后期震荡，优先检查采样分布。Entrocraft 证明，在采样阶段做简单的条件过滤，比修改优化目标更有效、更稳定。
- 推理时扩展：由于 Entrocraft 保持了更高的输出多样性，它在 pass@K 测试中表现更好，这意味着在推理阶段通过多次采样获取正确答案的概率显著增加。
局限与展望：
目前 Entrocraft 主要验证在数学推理任务上。对于开放性更强的创意写作或对话任务，熵的“最佳目标区间”可能不同，需要重新标定 hlowh_{low} ​ 和 hhighh_{high} ​ 。此外，拒绝采样会导致部分样本被丢弃，虽然计算开销未显著增加，但在极大规模并行训练下，有效批量大小的波动需要监控。
总的来说，Entrocraft 用极简的工程手段解决了 RL 训练中一个长期存在的理论痛点，为构建更强大的推理模型提供了一条清晰且可落地的路径。
