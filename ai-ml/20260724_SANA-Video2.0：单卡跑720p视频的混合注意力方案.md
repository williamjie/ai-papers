论文 : SANA-Video 2.0: Hybrid Linear Attention with Attention Residuals for Efficient Video Generation链接 : https://arxiv.org/abs/2607.21553视频生成模型正卡在算力瓶颈上。全 Softmax 注意力机制虽然质量高，但 O(N2)O(N^2) ) 的复杂度让长视频、高分辨率推理变得昂贵且缓慢。SANA-Video 2.0 提出了一种混合架构，在保持高质量的同时，将单卡 H100 生成 720p/5s 视频的耗时压缩至 13 秒左右。这不仅是一次架构创新，更是对工程落地可行性的强力验证。
### 痛点：全 Softmax 的算力噩梦现有主流视频 DiT（如 Wan 2.1、HunyuanVideo）依赖全 3D Softmax 注意力。在 VAE 压缩后，一个 1080p 片段包含数万潜在 Token，导致二次方计算开销巨大。论文指出，在生产级配置下，全 Softmax 骨干网比其混合方案慢 2.01 倍。对于长视频（>10s），这一差距会进一步拉大，使得大规模部署成本高昂。
### 核心方法：混合线性注意力与残差路由SANA-Video 2.0 的核心直觉是： 线性注意力负责全局高效混合，Softmax 锚点负责恢复精确交互 。
-混合线性-Softmax 注意力（Hybrid Linear-Softmax Attention）
设计逻辑：纯线性注意力受限于固定大小的状态矩阵，无法表达所有 Token 间的精细时空对应关系。为此，模型采用 3:1 的比例混合——75% 的层使用门控线性注意力（O(N)O(N) 复杂度），每四层插入一个 Softmax 锚点。
- Why：Softmax 锚点定期恢复低秩受限的 Token 交互，弥补线性注意力的表达缺陷；而线性主体保留了长序列扩展能力。实验表明，25% 的 Softmax 比例是质量与效率的最佳平衡点（Pareto Knee）。
-块注意力残差（Block Attention Residuals, AttnRes）
设计逻辑：传统加性残差迫使深层重新推导上游信息。AttnRes 将已完成的块特征摘要路由到后续线性层，实现锚点特征的复用。
- Why：通过共享路由查询（Shared Routing Queries），模型在减少内存开销的同时，使深层状态的有效秩提升了约 12%。这种设计避免了逐层学习路由参数带来的冗余，且无需显式的时间步条件输入（AdaLN 已隐含处理）。
-从头训练（From-Scratch Training）
不同于后验线性化预训练模型，SANA-Video 2.0 直接从头训练混合骨干网。这确保了模型在完整混合架构下学习运动和外貌，而非依赖预训练的 Softmax 先验。
### 关键结果：速度与质量的双重突破论文提供了详尽的对比数据，证明该架构在单卡环境下的显著优势。

- 速度优势：在 720p/60s 形状下，DiT 前向传播比匹配的全 Softmax 基线快 3.2 倍。结合 Sol-Engine 优化（内核融合、缓存等），端到端加速达 3.58 倍。
- 扩展性：随着视频时长增加，混合架构的优势扩大。在 60 秒视频中，绝对节省时间从 128ms 增长到 948ms。
### 工程启示- 单卡部署成为现实：无需多机集群，单张 H100 即可实现 720p 高质量视频生成。这对本地化部署、边缘计算及开发者调试极具价值。
- 混合架构是未来方向：纯线性注意力虽快但质量有损，全 Softmax 虽好但太慢。3:1 的混合比例提供了一个可复用的设计模板，适用于其他需要长序列处理的视觉任务。
- 训练策略的重要性：从头训练混合模型比后验转换更稳定。论文展示的从低分辨率到低噪声的多阶段课程学习（Curriculum Learning），为高效训练提供了完整参考。
### 局限与展望尽管性能优异，SANA-Video 2.0 仍有一些边界。首先，25% 的 Softmax 比例是通过代理研究确定的，不同分辨率或帧率下可能存在更优配置。其次，AttnRes 的路由机制虽简化了参数，但在极深层网络中的信息衰减问题仍需进一步探索。未来工作可能聚焦于因果门控 DeltaNet 初始化，以支持更长序列的生成。
SANA-Video 2.0 证明了通过巧妙的架构混合，可以在不牺牲太多质量的前提下，大幅降低视频生成的算力门槛。对于追求高效、低成本视频生成应用的工程师而言，这是一个值得深入研究的基准。
