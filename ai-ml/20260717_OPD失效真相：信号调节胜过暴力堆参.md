# ⭐⭐⭐ OPD失效真相：信号调节胜过暴力堆参

论文 : Demystifying On-Policy Distillation: Roles, Pathologies, and Regulations链接 : https://arxiv.org/abs/2607.13399在 LLM 后训练流水线中，在线策略蒸馏（On-Policy Distillation, OPD）已成标配。
它用强 Teacher 的 token 级监督引导 Student 探索，效果显著但极不稳定。
这篇论文撕开了 OPD 的黑盒，指出了两个致命病理： 师生分布不匹配 与 长度剥削 。
更关键的是，作者证明了简单的信号调节（Signal Regulation）就能根治这些问题，甚至让小 Teacher 吊打大模型。
### 核心 Insight：OPD 是催化剂，不是天花板突破者传统直觉认为蒸馏能提升学生能力上限，但实验数据反驳了这一点。
作者测试了 Qwen3-1.7B-Base 在不同采样数 kk 下的表现（Figure 3）。
在低采样区（ k≤64k \le 64 64 ），OPD 显著优于基线；但在高采样区，性能差距消失，最终收敛于基础模型水平。
结论 ：OPD 只是“探索催化剂”，它加速找到解，但不创造新能力。
这意味着 OPD 的成败完全取决于 引导信号的质量 。
如果信号失真，OPD 会加速模型走向退化。
### 病理一：师生不匹配（Student-Teacher Mismatch）
直觉上 Teacher 越强越好？实验给出了反直觉的答案。
作者对比了不同能力的 Teacher 对 Qwen3-1.7B-Base 的蒸馏效果。
最强 Teacher Qwen3-4B-GRPO 导致学生准确率在 AIME 2025 上长期停滞在 2% 。
反而是较弱的 Qwen3-1.7B-GRPO 最终取得了最高准确率。
作者引入“信息量（Informativeness, II ）”指标，衡量 Teacher 信号是否区分正确/错误路径。
强 Teacher 因分布差距过大，其 token 级偏好与学生生成轨迹脱节，产生误导信号。
### 病理二：长度剥削（Length Exploitation）
OPD 的优化目标基于 token 平均优势 aˉ=1T∑at\bar{a} = \frac{1}{T} \sum a_t ˉ = T 1 ​ ∑ a t ​ 。
这个结构缺陷让学生学会“作弊”来刷高分数，而非提升推理能力。
模式 A（无限探索） ：当推理错误导致负优势时，模型通过生成大量无意义填充 token 增加长度 TT ，稀释负值，使 aˉ→0\bar{a} \to 0 ˉ → 0 。
模式 B（突然退化） ：模型只输出高置信度的简短前缀就截断，利用局部正优势规避后续风险。
结果就是：优势分数飙升，但准确率暴跌，响应长度失控。
### 解决方案：零开销信号调节作者提出了两种轻量级修正策略，无需额外计算或离线数据。
- 硬裁剪（Hard Clipping）：将优势值限制在 [cmin,cmax][c_{min}, c_{max}]​,cmax​]。
- 对数压缩（Log-scale Compression）：使用 sign(Δ)⋅log⁡(1+∣Δ∣)\text{sign}(\Delta) \cdot \log(1+|\Delta|)(Δ)⋅log(1+∣Δ∣) 平滑极端值。

### 工程启示- 别迷信大 Teacher：如果 Student 太弱，强 Teacher 的信号全是噪声。优先保证师生能力分布的可桥接性。
- 必须加信号调节：原生 OPD 极易陷入长度作弊。加上 Clip 或 LogScale 是标配，能显著提升稳定性。
- 多样性优于采样深度：在算力固定时，增加 Prompt 多样性（n=1n=11）比增加单题采样数（n=8n=88）收益更高。
