论文 : Conditional Equivalence of DPO and RLHF: Implicit Assumption, Failure Modes, and Provable Alignment链接 : https://arxiv.org/abs/2605.20834DPO（Direct Preference Optimization）自问世以来，因其无需训练奖励模型、实现简单且效果强劲，迅速取代 RLHF 成为主流对齐方案。业界普遍接受的一个核心论断是：DPO 在数学上等价于 RLHF。然而，这篇来自 2026 年 ICML 的论文《Conditional Equivalence of DPO and RLHF》直接掀翻了桌子： 这种等价性是条件性的，而非普适的。 当参考模型（Reference Policy）质量不佳时，DPO 不仅无法继承 RLHF 的对齐保证，甚至可能收敛到“损失下降但违背人类偏好”的病态解。
### 为什么 DPO 会“背刺”我们？
DPO 的推导依赖于一个常被忽视的 隐式假设（Implicit Assumption） ：RLHF 的最优策略必须偏好人类选择的回答（ ywy_w ​ ）。具体来说，只有当参考模型 πref\pi_{ref} ​ 对 ywy_w ​ 的对数概率比 δπref\delta_{\pi_{ref}} ​ ​ 满足 δπref>−Δr∗/β\delta_{\pi_{ref}} > -\Delta r^*/\beta ​ ​ > − Δ r ∗ / β 时，这一假设才成立。
这里的 Δr∗\Delta r^* 是真实奖励差， β\beta 是温度参数。如果参考模型严重偏离人类偏好（例如，参考模型极度讨厌正确答案， δπref\delta_{\pi_{ref}} ​ ​ 为很大的负值），RLHF 的最优解可能会因为 KL 散度惩罚而被迫保留这种错误偏好。此时，DPO 的推导基础崩塌。
更致命的是，当假设被违反时，DPO 优化的目标发生了本质偏移：
- RLHF 优化的是绝对对齐（Absolute Alignment），即在奖励最大化和偏离参考模型之间寻找平衡。
- DPO 优化的是相对优势（Relative Advantage），即最大化 δπ−δπref\delta_{\pi} - \delta_{\pi_{ref}}​−δπref​​。
这意味着，只要当前策略比参考模型“稍微好一点”（ δπ>δπref\delta_{\pi} > \delta_{\pi_{ref}} ​ > δ π r e f ​ ​ ），DPO 的损失就会下降，即使当前策略依然偏好错误答案（ δπ<0\delta_{\pi} < 0 ​ < 0 ）。论文定义了一个 不良解空间（Undesirable Solution Space） U={π:δπ<0 and δπ>δπref}U = \{\pi : \delta_{\pi} < 0 \text{ and } \delta_{\pi} > \delta_{\pi_{ref}}\} { π : δ π ​ < 0  and  δ π ​ > δ π r e f ​ ​ } 。在这个区域内，梯度会随着优化进行而逐渐消失，导致模型被困在“看似收敛实则错误”的状态。
### 几何直觉：带负边距的排序损失为了直观理解，作者将 DPO 解释为一种 软边际排序损失（Soft Margin Ranking Loss） 。

在标准排序损失中，目标边际（Margin）通常为非负值。但在 DPO 中，目标边际是 δπref\delta_{\pi_{ref}} ​ ​ 。如果参考模型本身是错的（ δπref<0\delta_{\pi_{ref}} < 0 ​ ​ < 0 ），DPO 实际上是在执行一个 负边际 的排序任务。只要模型输出的对数概率比参考模型高一点点，损失就归零，优化停止。这解释了为什么在参考模型质量较差时，DPO 往往表现不稳定。
### 解决方案：CPO 与 E-CPOC^C针对上述问题，论文提出了 CPO（Constrained Preference Optimization） 。其核心思路是在 RLHF 目标中引入显式约束，强制策略偏好人类选择的答案。通过拉格朗日对偶推导，CPO 的损失函数变为：

此外，论文还提出了 E-CPO C^C （Explicitly Constrained Preference Optimization） ，这是一种无需奖励模型的保守变体，通过硬约束保证偏好对齐，并在统计学习假设下证明了其与显式约束 RLHF 的等价性。

### 工程启示- 参考模型至关重要：不要随意使用未经过精细 SFT 的基座模型作为 DPO 的参考模型。如果参考模型对偏好数据的分布理解偏差较大，DPO 极易陷入局部最优。
- 警惕“损失下降”的假象：在微调过程中，如果 DPO 损失快速下降但人工评估效果不佳，可能是陷入了不良解空间。此时检查参考模型对正样本的概率分布是必要的调试步骤。
