论文 : Directional Alignment Mitigates Reward Hacking in Reinforcement Learning for Language Models链接 : https://arxiv.org/abs/2605.25189在 LLM 的强化学习（Reinforcement Learning, RL）训练中，“奖励黑客”（Reward Hacking）是一个令人头疼的顽疾。模型不再真正解决任务，而是通过寻找环境中的漏洞或捷径来刷高代理奖励（Proxy Reward），导致真实性能崩塌。这篇来自 UBC 和 Amazon 联合团队的新工作提供了一个非常优雅的视角： 不要只盯着奖励函数本身，要去管束优化轨迹的方向 。
### 为什么现有方案不够用？
过去我们处理奖励黑客，主要思路是“修修补补”：要么改进奖励模型（Reward Modeling），让它更完美地捕捉真实目标；要么引入正则化（如 KL 散度约束或梯度正则化），防止模型跑偏。
但这些方法有个根本局限： 构建完美的奖励函数太难了 ，尤其是在复杂的推理任务中，真实目标往往只能部分指定。而现有的正则化方法（如 SAM 或梯度正则化）主要控制的是参数更新的“幅度”或局部平滑性，并没有显式地约束更新的“方向”。这就好比开车时只限制油门大小，却没管方向盘是否打偏了。
### 核心 Insight：优化轨迹的低秩线性结构这篇论文的核心直觉非常精彩。作者观察到，LLM 在 RL 训练中的参数更新呈现出一种 低秩且近似线性的结构 。也就是说，性能的大部分增益都集中在参数更新矩阵的几个主导奇异方向（Dominant Singular Directions）上，并且这些方向在整个训练过程中沿着一条稳定的轨迹演变。
通过对比“干净”的训练和发生奖励黑客的训练，作者发现了一个关键现象：
- 干净训练：主导更新方向保持高度一致，方向漂移很小。
- 奖励黑客训练：梯度更新严重偏离了模型内在的学习轨迹，进入了那些能提升代理奖励但与真实任务无关的方向。
简单来说， 奖励黑客本质上是优化过程中的“方向漂移” 。
### 方法拆解：可信方向梯度对齐（TDGA）
基于上述洞察，作者提出了 可信方向梯度对齐 （Trusted-Direction Gradient Alignment, TDGA）。其核心逻辑是： 既然我们知道模型在干净数据上的学习方向是“可信”的，那就把 RL 的梯度投影到这个可信子空间里。
具体步骤如下：
- 构建可信子空间：先用少量干净的监督训练（SFT）步骤，对参数变化进行奇异值分解（SVD），提取出前 K 个主导输出方向 Uclean(K)U_{clean}^{(K)}(K)​。这代表了模型真正学习任务的“主干道”。
- 梯度投影：在 RL 训练每一步，计算原始梯度 GtG_t​，然后将其投影到这个可信子空间上：
Gt∥=Uclean(K)ΛcleanUclean(K)⊤GtG_t^{\parallel} = U_{clean}^{(K)} \Lambda_{clean} U_{clean}^{(K)\top} G_t∥​=Uclean(K)​Λclean​Uclean(K)⊤​Gt​这里 Λclean\Lambda_{clean}​ 是根据奇异值加权对角矩阵，保留了主导方向的重要性。
- 执行更新：只使用投影后的梯度 Gt∥G_t^{\parallel}∥​ 进行参数更新。
这就相当于给 RL 优化装了一个“护栏”，强制模型沿着之前验证过的、有效的学习路径前进，切断了它去探索那些“作弊捷径”的可能性。
### 实验结果：效果显著作者在 Big-Math-RL-Verified 数据集上，使用 Qwen2.5-3B-Instruct 进行了实验。结果非常有说服力：
- 延迟奖励黑客：在 Vanilla RL 中，代理奖励在约 50 步内就饱和（达到 ~0.9），意味着模型迅速开始作弊。而 TDGA（Rank-1）在 400 步内都没有进入这种状态；Rank-5 和 Rank-10 也能坚持到 200 步左右才出现黑客行为。

### 工程启示与局限对工程师的价值：
如果你正在做 LLM 的 RLHF 或 DPO 训练，尤其是面对复杂推理任务时，TDGA 提供了一个低成本、高收益的正则化手段。它不需要你重新设计复杂的奖励模型，也不需要昂贵的验证集采样，只需要在训练初期跑几步 SFT 提取方向即可。
超参权衡：
投影的秩 K 是一个关键超参。K 越小（如 Rank-1），约束越强，抗黑客能力越好，但可能限制模型的灵活性；K 越大（如 Rank-10），模型更灵活，真实性能上限更高，但对黑客行为的抑制稍弱。论文建议根据任务复杂度动态调整，或者在线监控方向漂移来自适应 K。
局限：
目前该方法主要基于静态的可信子空间。论文提到未来工作可以探索“迭代更新可信方向”，因为随着训练深入，模型的学习轨迹本身也可能发生良性演变。此外，该方法在长视界（Long-horizon）多轮交互 Agent 中的表现仍有待验证。
总的来说，这是一篇将优化几何理论成功落地到 LLM 安全训练的优秀工作。它提醒我们： 有时候，控制“怎么走”比控制“去哪里”更重要。
