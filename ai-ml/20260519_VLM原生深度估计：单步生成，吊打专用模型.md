# VLM原生深度估计：单步生成，吊打专用模型

**日期**: 2026-05-19

---

论文 : Unlocking Dense Metric Depth Estimation in VLMs链接 : https://arxiv.org/abs/2605.15876现在的 VLM（视觉语言模型）在 2D 理解上已经卷到飞起，但在 3D 空间感知上依然“眼高手低”。这篇来自腾讯混元和大厂联合团队的论文，直接给 VLM 装上了一个轻量级的深度头，让它不仅能聊天，还能一次性输出全分辨率的稠密米制深度图。更关键的是，它在保持通用能力的同时，推理速度比之前的方案快了 30 倍，精度甚至超过了纯视觉的深度估计 SOTA 模型。
### 痛点：VLM 的 3D 困境与低效解法目前的 VLM 大多采用“纯文本监督”范式，视觉信号只是输入，输出只能是自回归文本。这导致两个严重后果：
- 无法输出稠密几何：VLM 天生缺乏对像素级几何结构的显式建模能力。
- 现有方案要么慢，要么烂：
Distillation 派：从外部 3D 模型蒸馏几何先验，容易积累误差，且无法原生输出深度图。
- DepthLM：虽然精度高，但采用“逐像素查询”策略，推理一张图需要 H×WH \times WW 次前向传播，耗时 13 小时，工程上完全不可用。
- Youtu-VL：支持全图预测，但输出的是粗糙的 Token 级结果，需要后处理插值，且训练成本极高。
### 核心 Insight：VLM 本身就是个稠密预测器作者的核心直觉非常巧妙： VLM 的视觉编码器（ViT）天然具备多尺度特征金字塔结构，无需额外复杂架构，只需一个轻量级 Head 即可解码出稠密深度。
DepthVLM 的设计极简且高效：
- 轻量级 DPT 风格深度头：
从 ViT 的中间层（浅层保留高频细节，深层保留语义）和 LLM 的最终隐藏状态中提取特征。
- 通过上采样构建自底向上的特征金字塔，融合后直接输出全分辨率深度图。
- 这个 Head 仅占 LLM 参数的 <1%，几乎不增加存储负担。
- 两阶段训练策略（Two-Stage Training）：
Stage 1：冻结 VLM 主干，仅训练深度头，初始化深度预测能力，避免噪声梯度破坏原有的多模态知识。
- Stage 2：解冻 LLM 主干，联合优化文本生成和深度预测损失，实现几何与语义的深度融合。
- 焦距归一化（Focal-Length Normalization）：
解决多源数据因相机焦距不同导致的尺度歧义。将所有图像重采样到统一焦距（如 1000px），消除跨数据集的尺度偏差。
### 关键结果：快、准、还能聊天实验数据证明了这套方案的强大：

亮点解读：
- 速度碾压：单次前向传播（O(1)）即可完成全图深度估计，比 DepthLM 快 30,000 倍，比 Youtu-VL 快 6 倍。
- 精度超越专用模型：Ours-4B 在 Waymo 和 ETH3D 上超过了纯视觉 SOTA 的 DepthAnythingV3。
- 能力无损：得益于两阶段训练，通用视觉问答能力几乎无损（MMB-EN 仅下降 0.1~0.5 分），而 DepthLM 因过度拟合文本监督导致通用能力完全崩溃。
### 工程启示- 统一架构优于拼接：不要试图用 Prompt 让 VLM 猜深度，也不要外挂独立的深度模型。将轻量级 Head 直接挂载在 VLM 主干上，共享特征，是兼顾精度和效率的最优解。
- 多尺度特征融合是关键：单纯依赖 LLM 输出或 ViT 顶层特征都不够。必须融合 ViT 浅层的高频细节和 LLM 的语义上下文，才能获得既清晰又符合语义的深度图。
- 数据预处理决定上限：焦距归一化看似简单，却是解决多源数据尺度冲突的关键。在实际落地中，务必对输入图像进行类似的几何标准化。
### 局限与展望目前 DepthVLM 主要聚焦于稠密深度估计，尚未扩展到 3D 检测、姿态估计等任务。此外，模型对极端遮挡或无纹理区域的深度推断仍有提升空间。未来，这种“原生几何预测 + 多模态理解”的统一范式，有望成为具身智能和 AR/VR 应用的基础设施。
