# ⭐⭐⭐⭐ VPD：让语言反馈驱动的策略蒸馏真正生效

**日期**: 2026-05-22

---

论文 : Learning from Language Feedback via Variational Policy Distillation链接 : https://arxiv.org/abs/2605.15113在强化学习从可验证奖励（RLVR）转向复杂推理任务时，稀疏的标量奖励往往导致严重的探索瓶颈。这篇来自 Salesforce AI Research 的论文提出了一种名为变分策略蒸馏（Variational Policy Distillation, VPD）的新框架，核心洞察在于：现有的自蒸馏方法将“教师”视为固定函数，导致随着学生能力提升，教师的指导能力迅速触顶失效。VPD 通过引入期望最大化（EM）算法，让教师和学生共同进化，从而持续从语言反馈中提取有价值的梯度信号。
### 现有方案的痛点：被动的“伪教师”
目前主流的解决奖励稀疏性的方案是自蒸馏策略优化（SDPO）。其基本逻辑是：利用环境或更强的模型生成的文本反馈 CC ，将同一个模型条件化作为“教师”，指导学生模仿带有反馈的 token 分布。
然而，这种设计存在一个致命缺陷： 教师是被动的 。在 SDPO 中，教师模型 πθ(⋅∣x,C)\pi_\theta(\cdot|x, C) ​ ( ⋅ ∣ x , C ) 的参数在蒸馏过程中是不更新的（通过 stop-gradient 隔离）。这意味着教师解读反馈的能力完全依赖于其零样本（Zero-shot）能力。当学生模型逐渐掌握基础逻辑后，简单的文本提示对教师的增益边际递减；更糟糕的是，如果反馈本身存在噪声，或者模型尚未具备将自然语言映射到结构修正的能力，这种固定的蒸馏目标甚至会提供反向梯度，导致训练停滞甚至崩溃。
### 方法拆解：EM 算法下的师生共演VPD 的核心创新在于将学习过程形式化为一个变分推断问题，并自然地分解为交替进行的 E-step 和 M-step。
- E-step（教师精炼）：这是 VPD 的灵魂。不同于传统方法，这里显式地优化教师参数 ϕ\phi，使其能够根据轨迹结果区分成功与失败。具体实现上，VPD 采用非配对偏好优化（Unpaired Preference Optimization），利用二元分类器优化（BCO）框架处理缺乏成对样本的问题。关键在于，为了防止分布偏移，VPD 动态地将参考先验锚定在当前学生策略 πθ\pi_\theta​ 上，形成一个自适应的信任区域（Trust Region）。
- M-step（学生蒸馏）：在教师更新后，学生通过最小化与精炼后教师的 KL 散度来内化这些密集的监督信号。
这种设计的精妙之处在于 动态参考先验 。由于教师始终被约束在学生当前的能力范围内，它提供的目标分布对学生而言是“可达”的，从而避免了传统蒸馏中常见的模式崩溃和梯度方差爆炸问题。此外，VPD 采用共享权重架构（ θ=ϕ\theta = \phi ϕ ），仅在推理时通过附加反馈上下文来区分师生角色，极大地降低了显存开销。
### 关键结果：稳定压倒一切论文在代码生成（LiveCodeBench）和科学推理（SciKnowEval）任务上进行了全面评估，结果令人信服。

2. SciKnowEval (多模型对比)
在科学推理任务中，VPD 在不同规模的模型上均优于基线：

### 工程启示与局限工程价值：
对于从事 Agent 开发或复杂推理微调的工程师而言，VPD 提供了一个更稳定的训练范式。它证明了仅仅“喂”给模型反馈是不够的，必须显式地训练模型“理解”反馈。共享权重设计使其易于部署，且无需额外的教师模型显存。
局限与边界：
论文诚实地指出了 VPD 的适用边界：
- 冷启动问题：在基础模型（Base Model）上直接应用自蒸馏会导致性能迅速崩溃。VPD 虽能延缓这一过程，但在纯冷启动场景下，传统的稀疏 RL（如 GRPO）仍是激发推理能力的必要手段。
- 数学推理的刚性：在严格的数学推导中，如果教师的反馈存在细微错误，蒸馏可能会强化错误的中间步骤。此时，鼓励广泛探索的稀疏 RL 反而比紧密跟随教师分布更有效。
总之，VPD 不是银弹，但它为解决“如何让模型从文本反馈中持续学习”这一难题提供了极具参考价值的理论框架和工程实现路径。
