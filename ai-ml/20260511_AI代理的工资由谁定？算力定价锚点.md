# AI代理的工资由谁定？算力定价锚点

**日期**: 2026-05-11

---

论文 : Who Prices Cognitive Labor in the Age of Agents? Compute-Anchored Wages链接 : https://arxiv.org/abs/2605.05558很多人直觉认为，AI Agent 可以无限复制，边际成本趋近于零，所以它作为“劳动力”供给无限弹性，最终会把人类的认知劳动工资压到零。这篇论文直接反驳了这个框架： Agent 不是劳动力，而是一种将算力资本（Compute Capital）转化为有效认知劳动的生产技术。
这个视角的转换至关重要。它意味着，决定人类认知劳动工资上限的，不再是劳动力市场的供需曲线，而是 算力资本市场的租金率 。
## 为什么传统框架失效？
在经典的曼昆（Mankiw）生产函数中，工资由劳动的边际产品决定，均衡工资由劳动供给和需求曲线的交点决定。如果简单地把 AI Agent 当作一种新的、零成本供给的劳动力类型加入模型，确实会得出工资为零的结论。
但论文指出，这种建模犯了根本性错误。Agent 的“供给”并非来自家庭的时间分配，而是来自 算力资本（ KcK_c ​ ）的供给 。算力资本受到半导体工厂产能、电力、水资源、土地等物理和政治经济约束，其供给在短期内是缺乏弹性的（Inelastic）。
因此，价格确定的机制发生了迁移：从劳动力市场迁移到了算力资本市场。
## 核心方法：计算锚定工资（CAW）
论文的核心贡献是推导出了**计算锚定工资（Compute-Anchored Wage, CAW）**上限。
### 1. 重新定义生产函数论文将 Agent 产生的认知劳动单位 LAL_A ​ 定义为：当固定束的算力资本 KcK_c ​ （包含 GPU 小时、能源、内存、模型权重摊销等）运行一单位时间所产生的认知劳动等价物。
LA=ϕ(Kc)≈Kc/kL_A = \phi(K_c) \approx K_c / k ​ = ϕ ( K c ​ ) ≈ K c ​ / k其中 kk 是生成一单位有效 Agent 劳动所需的算力强度。
### 2. CAW 边界推导假设在可替代任务集（Substitutable Tasks, TST_S ​ ）上，人类认知劳动 LHL_H ​ 和 Agent 劳动 LAL_A ​ 是完全替代的。令 λ\lambda 为人类相对于 Agent 的相对生产力（即 1 单位人类劳动等价于 λ\lambda 单位 Agent 劳动）。
在竞争性要素市场下，为了最小化成本，企业会在人类劳动和 Agent 劳动之间进行替代。
- 人类劳动的单位成本是工资 WHW_H​。
- Agent 劳动的单位有效成本是算力租金乘以算力强度：k⋅rck \cdot r_crc​。
- 考虑到生产力差异，λ\lambda 单位 Agent 劳动替代 1 单位人类劳动，其成本为 λ⋅k⋅rc\lambda \cdot k \cdot r_ck⋅rc​。
因此，只要人类劳动仍然被雇佣，其工资必须满足：
WH≤λ⋅k⋅rcW_H \le \lambda \cdot k \cdot r_c ​ ≤ λ ⋅ k ⋅ r c ​关键洞察 ：
- 如果 WH>λkrcW_H > \lambda k r_c​>λkrc​，企业会完全转向使用 Agent，人类在该任务上失业。
- 如果 WH<λkrcW_H < \lambda k r_c​<λkrc​，企业会完全使用人类，Agent 无人问津。
- 在均衡状态下，若两者共存，工资上限被严格锚定在 λkrc\lambda k r_c​。
这解释了为什么工资不会跌到零，而是被 算力租金率（ rcr_c ​ ） 、**算力强度（ kk ） 和 相对生产力（ λ\lambda ）**共同决定。

## 工程与职业启示### 1. 任务二分法：可替代 vs. 互补论文提出将认知任务分为两类：
- 可替代任务集 (TST_S​)：起草、代码生成、总结、分类等。σ\sigma（替代弹性）大，CAW 绑定，工资受算力成本压制。
- 互补任务集 (TCT_C​)：深度不确定性下的判断、法律责任、人际关系、跨领域整合等。σ\sigma 小或存在互补性，工资可能随 Agent 能力提升而上升。
启示 ：职业风险不再单纯由“技能高低”决定，而是由你在 TST_S ​ 和 TCT_C ​ 中的暴露比例决定。例如，初级合同审查律师（80% 在 TST_S ​ ）的工资将被 CAW 压制，而高级诉讼律师（70% 在 TCT_C ​ ）的工资可能上升。
### 2. 政策杠杆不在劳动力市场既然工资由算力市场决定，传统的劳动力市场政策（如最低工资、就业培训）对受替代的认知劳动效果有限。有效的政策杠杆应针对算力市场：
- 算力税：提高 rcr_c​，直接提高 CAW 上限，保护人类工资。
- 公共算力供应：降低 rcr_c​ 的垄断溢价，但可能进一步压低 CAW。
- 反垄断：针对加速器市场的集中定价，降低 rcr_c​ 中的垄断 markup。
## 局限与展望- 杰文斯悖论（Jevons Effects）：认知劳动成本下降可能扩大总需求，从而增加总就业，但 CAW 仅约束工资水平，不约束工资总额。
- 比较优势：即使 Agent 在所有任务上都更高效，人类仍可通过比较优势保留就业，但这仅决定分配，不改变价格锚定机制。
- 非生产力工资成分：责任、信任、物理在场等非边际生产力因素带来的溢价未被模型捕获，CAW 仅约束边际生产力部分。
- 内生技术改进：kk 随时间指数下降，CAW 上限长期来看趋向于零，除非硬件瓶颈或模型质量饱和。
## 总结这篇论文的价值不在于提出了复杂的数学模型，而在于 纠正了概念框架 。它告诉我们，在 AI 时代，认知劳动的价格不再由“人”决定，而是由“电”和“硅”决定。工程师和政策制定者需要关注的，不再是如何让人更努力，而是如何管理算力资源的定价与分配。
