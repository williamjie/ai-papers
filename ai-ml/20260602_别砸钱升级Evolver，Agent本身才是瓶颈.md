# ⭐⭐⭐⭐½ 别砸钱升级 Evolver，Agent 本身才是瓶颈

**日期**: 2026-06-02

---

论文 : Harness Updating Is Not Harness Benefit: Disentangling Evolution Capabilities in Self-Evolving LLM Agents链接 : https://arxiv.org/abs/2605.30621在构建自进化 Agent 系统时，我们常陷入一个误区：认为更强的“进化器”（Evolver）能带来更显著的收益。这篇来自 Penn State、UCSC 和 Amazon 的联合研究直接泼了一盆冷水： 进化器的能力与基础模型能力几乎无关，而真正决定上限的是执行任务的 Agent 本身。
### 痛点：黑盒评估掩盖了真实瓶颈目前的自进化 Agent 系统（如自动更新 Prompt、记忆或技能）通常只关注端到端的最终得分。这种评估方式混淆了两个截然不同的能力：
- Harness-updating：从执行轨迹中提取有用知识并更新外部工具包的能力。
- Harness-benefit：在实际任务中有效调用并遵循这些更新后工具包的能力。
如果不拆解这两个环节，我们就无法回答：到底该把算力预算花在升级“进化器”上，还是花在强化“执行者”上？
### 核心洞察：能力解耦与反直觉发现作者通过将七个不同层级的 LLM（从 Qwen3.5-9B 到 Claude Opus 4.6）在三个基准测试中进行排列组合，揭示了两个关键结论。
🚨 反直觉发现 1：进化器能力是“扁平”的无论使用最强的 Claude Opus 4.6 还是较小的 Qwen3.5-9B 作为进化器，它们产生的 Harness 更新带来的收益差异极小。在任何基准上，最佳与最差进化器的差距不超过 3.1 个百分点 。
这意味着，花大价钱升级进化器模型是性价比极低的操作。甚至在小规模案例研究中，Qwen3.5-9B 生成的技能脚本在程序逻辑上与 Opus 4.6 生成的完全同构，都能让下游 Agent 成功解决任务。
🚨 反直觉发现 2：受益能力呈“非单调”分布基础模型越强，受益越大？错。 中层模型（如 GPT-OSS-120B）受益最大 ，而顶层和底层模型受益均较少。
- 顶层模型：接近性能天花板，提升空间有限。
- 底层模型：虽然提升空间大，但几乎无法从进化中获益。
### 数据拆解：为什么弱模型学不会？
作者深入分析了弱模型（如 Qwen3-32B）在 SkillsBench 上的失败模式，发现并非它们“看不懂”更新后的技能，而是根本“用不上”。

- 遵循失败 (Adherence Failure)：即使技能被加载，弱模型也难以在长程任务中坚持执行。数据显示，Qwen3-32B 的遵循度从加载后的 0.52 急剧下降到最终验证阶段的 0.13，而 Opus 4.6 仅从 0.89 降至 0.80。
### 工程启示：钱要花在刀刃上对于正在构建或优化 Agent 系统的工程师，这篇论文提供了明确的指导原则：
- 停止升级 Evolver：除非你的进化器弱到连基本指令都无法生成，否则无需追求更大参数的进化模型。使用开源小模型作为进化器足以产生高质量的技能更新。
- 投资 Task-Solving Agent：系统的最终性能瓶颈在于执行任务的 Agent。预算应优先用于提升主模型的推理能力和工具调用稳定性。
- 针对性训练 (SFT/RL)：针对弱模型，不要只练通用能力。需要专门训练两个技能：
Harness Invocation：确保模型能独立、正确地发出加载指令。
- Long-horizon Instruction Following：增强模型在长轨迹中保持对已加载技能遵循的能力，防止中途“走神”。
### 局限与展望该研究主要关注非参数化的 Harness 更新，未涉及权重微调（Fine-tuning）或强化学习。此外，虽然实验覆盖了多个开源和闭源模型，但更广泛的模型网格测试可能进一步揭示不同训练配方对 Harness 遵循的影响。
总之，自进化 Agent 的未来不在于让“老师”变得更聪明，而在于让学生学会更好地“听课”和“执行”。
