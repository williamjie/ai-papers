# ⭐⭐⭐ 生物大模型微调陷阱：为何SFT越调OOD越差？

**日期**: 2026-06-26

---

论文 : How Post-Training Shapes Biological Reasoning Models链接 : https://arxiv.org/abs/2606.16517做垂直领域大模型（如医疗、生物）的工程师，通常有一个共识：通用基座不够用，必须通过持续预训练（Continued Pre-training, CPT）、监督微调（Supervised Fine-Tuning, SFT）和强化学习（Reinforcement Learning, RL）来“注入”专业知识。
但这篇来自哈佛与 Google DeepMind 合作的研究揭示了一个反直觉的事实： 在生物推理任务中，更多的 SFT 并不总是带来更好的泛化能力。 相反，过度的监督微调会导致模型在领域外（Out-of-Domain, OOD）性能显著下降。
### 为什么生物学是个“硬骨头”？
在数学或代码生成任务中，即使表面细节变化，底层逻辑结构往往保持一致。但在生物学中，未见过的通路、疾病或物种往往涉及完全不同的机制。
这意味着，如果模型只是在训练分布上“死记硬背”，它在面对新生物系统时会彻底失效。现有的研究大多关注最终性能，而忽略了不同训练阶段对泛化能力的非单调影响。本文通过控制变量实验，拆解了 CPT、SFT 和 RL 各自扮演的角色。
### 核心发现：SFT 的“过拟合”陷阱作者构建了包含基因组学、转录组学和蛋白质组的推理任务，并训练了超过 100 个模型变体。
1. SFT 的代价：ID 上升，OOD 暴跌实验显示，随着 SFT 计算量的增加（Epochs 增多），领域内（In-Domain, ID）性能持续提升，但 OOD 性能在早期达到峰值后迅速下降。
- DNA 任务数据：Qwen3-1.7B 模型经过 16 个 Epoch 的 SFT，ID 准确率从 0.68 升至 0.90；但其 OOD 准确率在第 2-4 个 Epoch 达到峰值（约 0.73），随后在 32 个 Epoch 时跌至 0.68。
- RNA 任务数据：Qwen3-4B 模型 ID 准确率从 0.78 升至 0.91，但 OOD 性能同样在第 4 个 Epoch 后开始下滑。
⚠️ 关键洞察 ：SFT 让模型变得更“专”，但也更“窄”。它极大地增强了模型对训练数据分布的拟合能力，却牺牲了对生物分布偏移（Distribution Shift）的鲁棒性。
2. RL 是 OOD 性能的“救星”
如果在 SFT 之后引入 RL，情况会发生逆转。从强的 SFT 检查点开始进行 RL 训练，能同时提升 ID 和 OOD 性能，且 OOD 的提升幅度更大。
- 蛋白质任务：Qwen3-4B 模型在 SFT 后继续 RL，OOD FmaxF_{max}​ 提升了约 0.08。
- DNA/RNA 任务：RL 带来的 OOD 提升约为 0.05，且大部分增益出现在前几个 Epoch。
3. CPT 是必要的“桥梁”
持续预训练（CPT）让模型适应生物学术语和语言结构。实验表明，经过 CPT 的模型在后续的 SFT 和 RL 中表现更好，尤其是在 OOD 场景下。对于较小的模型（如 Qwen3-1.7B），CPT 带来的 OOD 增益尤为明显（提升 0.2）。
### 工程落地指南：如何分配算力？
基于上述发现，作者提出了一套针对有限算力预算的最佳实践策略：
训练阶段 核心作用 最佳实践建议 CPT 对齐生物语言 必须做。它是后续微调的基础，能显著提升 OOD 上限。 SFT 建立任务能力 短平快 。只需少量 Epoch（1-3 个）让模型学会任务格式即可，切勿过度训练。 RL 恢复泛化能力 重投入 。在 SFT 之后分配更多算力给 RL，以弥补 SFT 造成的 OOD 损失。
具体的预算分配建议：
在固定的总 Epoch 预算下， “少量 SFT + 大量 RL” 的组合能实现最佳的 ID-OOD 权衡。例如，在 DNA 和 RNA 任务中，1-3 个 Epoch 的 SFT 配合剩余的 RL 训练，比纯 SFT 或纯 RL 都能获得更高的 OOD 准确率。
适配器容量也要“不对称”：
LoRA 调优时，SFT 阶段需要较高的 Rank（如 256）以吸收任务结构和多模态模式；而 RL 阶段较低的 Rank（如 16）即足够，过高的 Rank 反而可能降低 OOD 性能。
### 局限与展望尽管结论具有启发性，但研究仍局限于特定的任务集和模型家族。此外，RL 的效果高度依赖于奖励函数的设计，目前尚未完全探索不同奖励机制下的动态变化。未来工作需进一步验证这些规律在更广泛科学推理场景中的普适性。
总结：
不要盲目堆砌 SFT 数据。在构建生物医疗等大垂直领域模型时，请记住： SFT 负责“入门”，RL 负责“举一反三”。 合理的阶段配比，比单纯的算力堆积更重要。
