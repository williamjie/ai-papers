# 拒绝重RL：推理提升的本质是稀疏策略选择

**日期**: 2026-05-11

---

论文 : Rethinking RL for RL for LLM Reasoning: It’s Sparse Policy Selection, Not Capability Learning链接 : https://arxiv.org/abs/2605.06241最近大模型推理能力的提升几乎被强化学习（Reinforcement Learning, RL）垄断，DeepSeek-R1、OpenAI o1 等标杆模型都依赖昂贵的 RLVR（带可验证奖励的强化学习）管线。但这篇来自 USC 和 ARL 的新论文直接泼了一盆冷水： RL 并没有教会模型新技能，它只是在帮模型做“选择题” 。
如果 RL 只是把模型原本就有的正确路径推到前台，那我们真的需要跑几千个 GPU 小时的 RL 循环吗？作者给出的答案是：完全不需要。他们提出了一种名为 ReasonMaxxer 的方法，仅用几十道题、几分钟单卡训练，就达到了与全量 RL 相当甚至更好的效果，成本骤降三个数量级。
## 核心洞察：RL 到底在改什么？
长期以来，业界默认 RL 能激发模型涌现出新的推理策略。但作者通过 Token 级别的细致拆解，发现了一个惊人的事实：
- 极度稀疏：RL 模型与基座模型（Base Model）的输出差异仅集中在 1–4% 的 Token 位置上。
- 保守修正：RL 几乎从不引入新 Token。被 RL “选中”的 Token，原本就排在基座模型 Top-5 候选项的第 2 位左右（平均 Rank 2.14–2.39）。
- 高熵决策点：这些被修正的位置，恰好是基座模型生成概率分布最不确定（熵最高）的“分歧点”。
简单来说，RL 的作用不是“创造”，而是“纠偏”。它在模型犹豫不决时，强行把概率质量导向那条原本就存在的正确分支。
为了验证这一点，作者做了一个简单的“神谕干预”实验：在基座模型生成时，人工替换掉那些 RL 模型会修正的 Token。结果发现，仅替换这不到 4% 的 Token，就能 完全复现 RL 模型带来的准确率提升。反之，如果是随机替换，则毫无作用。
## 方法拆解：ReasonMaxxer既然 RL 的核心逻辑是“在高熵点做策略选择”，那我们可以直接跳过复杂的 RL 循环，用更简单的监督信号来模拟这一过程。ReasonMaxxer 的设计非常极简：
- 数据筛选：从少量数学题中采样基座模型的生成结果，只保留那些“有时对、有时错”的题目。这是关键，因为只有混合结果才能提供对比信号。
- 熵门控定位：计算基座模型生成的 Token 熵，只选取高熵位置作为“决策点”。无需 RL 模型参与，基座模型自己的不确定性就是最好的指引。
- 对比损失微调：仅在这些决策点上，使用优势加权对比损失（Advantage-Weighted Contrastive Loss）。正确路径的 Token 被增强，错误路径的 Token 被抑制。其余所有位置通过 KL 散度锚定回基座分布，防止过拟合。
- 低秩适配器：使用 Rank-32 的 LoRA 适配器，仅更新模型不到 0.5% 的参数。

可以看到，ReasonMaxxer 不仅在准确率上持平甚至微超 RL 模型，其训练成本更是从数百美元直接降至几美元。数据用量也从数千道题缩减到仅 50 道题 ，生成 rollout 次数仅为 1000 条 。
更有趣的是，即使对比那些结合了蒸馏（Distillation）或多域数据的复杂 RL 基线（如 DeepSeek-R1-Distill），ReasonMaxxer 依然能打出漂亮的数据。这进一步佐证了： 推理能力的提升，核心在于对稀疏关键点的精准校正，而非大规模的参数震荡。
## 工程启示这篇论文对工程师的实践价值极大：
- RL 不再是唯一解：对于资源有限的团队，不必盲目追求全量 RL 训练。基于熵的对比微调可能是一个更高效、更稳定的替代方案。
- 数据质量 > 数据数量：ReasonMaxxer 证明，少量高质量的“边缘案例”（Edge-of-Competence）比海量数据更有价值。筛选出模型“半对半错”的样本，比盲目收集错题集更重要。
- 小模型微调的可行性：由于只需要更新极小比例的参数（LoRA），这种微调方式对显存要求极低，甚至可以在消费级 GPU 上快速迭代。
## 局限与展望当然，这种方法并非万能。它主要适用于具有明确可验证奖励的任务（如数学推理、代码生成）。对于开放式生成或主观性较强的任务，高熵点的定义和对比信号的获取将更加困难。此外，论文主要聚焦于数学推理，其在自然语言理解任务上的泛化能力仍有待验证。
但无论如何，ReasonMaxxer 撕开了 RL 在 LLM 推理中“黑盒”的一角，让我们看到： 有时候，少即是多，轻即是强。
