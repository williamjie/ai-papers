# 让大模型自我评估：用内部状态做RL基线

**日期**: 2026-05-13

---

论文 : Your Language Model is Its Own Critic: Reinforcement Learning with Value Estimation from Actor’s Internal States链接 : https://arxiv.org/abs/2605.07579在强化学习验证奖励（Reinforcement Learning with Verifiable Rewards, RLVR）的训练中，如何低成本地估计“价值基线”一直是工程上的痛点。首尔大学团队提出的 POISE（Policy Optimization with Internal State Value Estimation）算法，直接抛弃了昂贵的独立 Critic 模型或高成本的 Group 采样，转而利用 Actor 模型自身的**隐藏状态（Hidden States）**来预测预期奖励。这不仅节省了算力，还让训练更稳定。
## 现有方案的痛点：贵且慢目前主流的 RLVR 方法主要在两条路上走：
- PPO 路线：训练一个与策略模型（Policy）规模相当的 Critic 模型。
痛点：内存占用翻倍，优化复杂度极高。每次更新都要处理完整的生成序列，工程落地门槛高。
- GRPO/DAPO 路线：不训练 Critic，而是对同一个 Prompt 采样多个 Rollout（如 G=8），用平均奖励作为基线。
痛点：用“样本量”换“参数”。为了估计稳定的基线，必须重复采样同一 Prompt，导致在固定算力预算下，Prompt 多样性下降，梯度方差增大。此外，如果所有 Rollout 都得到相同奖励（零优势），还需要额外的采样成本来剔除无效样本。
核心矛盾在于： 获取可靠的基线需要额外的计算资源（参数或样本）。
## 方法拆解：从“黑盒”中提取信号POISE 的核心直觉是：大模型在推理过程中，其内部隐藏状态已经编码了题目难度、模型信心以及答案正确性的相关信息。既然这些信息已经存在，何必再额外训练一个模型或浪费算力去采样？
### 1. 特征工程：不仅仅是最后一层POISE 提取了三个维度的内部信号来构建输入特征 ϕθ\phi_\theta ​ ：
- Prompt 状态：Prompt 结束时的隐藏状态平均值，反映模型对题目难度的初始感知。
- Trajectory 状态：推理过程结束时的隐藏状态平均值，包含生成过程中的动态信息。
- Token 熵统计：生成过程中的 token 不确定性，作为轻量级的置信度指标。
### 2. 关键设计：Cross-Rollout 防止偏差如果直接用当前 Rollout 的状态去预测当前 Rollout 的价值，会引入严重的梯度偏差（因为基线依赖于动作本身）。
POISE 采用了一个巧妙的**交叉采样（Cross-Rollout）**设计：
- 对每个 Prompt 只采样 2 个 独立的 Rollout：y(1)y^{(1)} 和 y(2)y^{(2)}。
- 用 y(2)y^{(2)} 的内部状态特征去预测 y(1)y^{(1)} 的价值，反之亦然。
- 训练目标是最小化预测值与“留一法”蒙特卡洛目标（Leave-one-out Monte Carlo target）的均方误差。由于目标值来自其他样本，保证了基线与当前动作的条件独立性，从而维持梯度无偏性。
### 3. 极简结构：线性回归足矣尽管可以使用 MLP，但实验表明，简单的**线性回归（Linear Regression）**作为 Probe 效果最好。这符合“Transformer 内部语义特征往往呈现线性分布”的直觉，既避免了过拟合，又实现了极低的计算开销。
## 关键结果：少采样，更稳定论文在 Qwen3-4B 和 DeepSeek-R1-Distill-Qwen-1.5B 上进行了验证，主要对比基线为 DAPO（SOTA 的 GRPO 变体）。
1. 性能相当，但更快POISE 在数学推理基准测试（Avg@32）上达到了与 DAPO 相当甚至略优的性能，且训练速度显著提升。
Model Benchmark Method Avg Time (Hours) Qwen3-4B AMC23/AIME/HMMT DAPO 0.508 ~49h (2x B200) Qwen3-4B AMC23/AIME/HMMT POISE 0.500 ~36h (2x B200) DeepSeek-1.5B AMC23/AIME/HMMT DAPO 0.296 ~24h (1x B200) DeepSeek-1.5B AMC23/AIME/HMMT POISE 0.303 < 18h (1x B200)
注：POISE 在 DeepSeek 1.5B 上不仅精度更高，还节省了约 25% 的墙钟时间。
2. 梯度更稳定由于每个 Prompt 只需 2 个 Rollout（而非 GRPO 的多个），在相同 Batch Size 下，POISE 能处理更多样化的 Prompt。根据论文推导，增加 Prompt 多样性能显著降低梯度方差。实验显示，POISE 的梯度范数在整个训练过程中持续低于 DAPO，证明其优化路径更平稳。
3. 内部状态确实有用POISE 的轻量级 Probe 在预测能力上甚至优于一个单独训练的、与 Actor 同规模的 Critic 模型（Pearson 相关系数 0.870 vs 0.676）。这强有力地证明了： Actor 自身的内部表征包含了比外部 Critic 更丰富的价值信号。
## 工程启示- 资源受限下的 RL 新选择：如果你没有足够的显存训练双模型（Actor + Critic），或者不想承担 GRPO 高采样成本，POISE 是一个极佳的替代方案。它几乎不增加前向传播的额外算力开销。
- Prompt 多样性优先：在 RLVR 训练中，增加不同 Prompt 的数量比增加单个 Prompt 的采样次数更能降低梯度噪声。POISE 通过单次/双次采样实现了这一目标。
- 可解释性新视角：模型内部的隐藏状态和熵不仅是诊断工具，更是实时的价值信号。这一思路可以延伸到 Agent 的早期停止（Early Stopping）或自我修正场景中。
## 局限与展望- 序列级价值：目前 POISE 预测的是整个序列的价值。未来可以扩展到 Token 级信用分配（Token-level credit assignment），从而更精细地奖励正确的推理步骤。
- 训练时长：当前实验主要关注短期效果，长期训练下的内部状态漂移（Drift）表现仍有待验证。
- 通用性：虽然论文展示了在代码、工具调用等任务上的泛化能力，但在更复杂的 Agentic 任务中，内部状态是否依然可靠，需要更多探索。
总之，POISE 证明了“不需要外人，大模型自己就能评估自己”。对于追求高效 RLVR 的工程团队来说，这是一个值得立即尝试的低成本优化路径。
