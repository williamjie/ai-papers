# 别只盯最后一层：视觉Token的多层特征融合

**日期**: 2026-05-13

---

论文 : Beyond the Last Layer: Multi-Layer Representation Fusion for Visual Tokenization链接 : https://arxiv.org/abs/2605.10780在生成式 AI 的管线中，视觉 Tokenizer（图像分词器）是连接像素与语义的咽喉。最近基于预训练视觉基础模型（如 DINOv2）的 Representation Autoencoder (RAE) 路线大行其道，因为它们能复用冻结的编码器，既保留了语义结构，又提升了重建质量。
但有个被忽视的痛点： 所有现有方法都只取 Encoder 的最后一层输出 。这就像读一本书只读结论，忽略了中间的论证过程。这篇来自北大、美团和清华的论文指出，这种做法系统性地丢弃了浅层保留的高频细节（纹理、边缘）。作者提出了 DRoRAE，通过一种轻量级的多层融合模块，不仅显著提升了重建指标，还意外发现了一个类似 NLP 词汇表规模的缩放定律。
## 问题与动机：为什么“最后一层”不够用？
在 Vision Transformer (ViT) 中，特征随深度增加发生语义抽象。浅层（Shallow Layers）保留着丰富的低层视觉细节，而深层（Deep Layers）专注于高层语义。
现有 RAE 方法直接丢弃中间层，仅使用最后一层输出 zLz_{L} ​ 作为 Latent。论文引用分析指出，低层信息在最后一层中仅作为残差连接（Residual Connections）中的“被动泄漏”存在。随着层数加深，语义变换叠加在这些残差上，导致高频信息逐渐衰减。
核心 Insight ：显式地融合多层特征，可以恢复这些信息，从而构建比单层更丰富的 Latent 表示。但这带来了两个工程挑战：
- 内容自适应融合：不同层统计特性差异大，且不同图像区域（如纹理区 vs 语义区）依赖不同层。
- 生成兼容性：Decoder 已经针对最后一层分布训练好。强行改变 Latent 分布会导致下游扩散模型（Diffusion Model）无法有效生成图像。
## 方法拆解：DRoRAE 的设计直觉DRoRAE (Depth-Routed Representation AutoEncoder) 的核心是一个约 29M 参数的轻量级融合模块，插在冻结的 Encoder 和 Decoder 之间。
### 1. 能量约束路由（Energy-Constrained Routing）
传统的 MoE（Mixture of Experts）通常使用 Softmax，权重非负且和为1。DRoRAE 设计了一个 Router，允许 负权重 。
- 为什么这么设计？ 允许负权重意味着模型可以主动“抑制”某些层的有害贡献，而不仅仅是加权平均。这相当于一个自适应的去噪机制。
- 归一化：使用权重向量的 L2 范数进行归一化，确保输出能量受限，避免数值爆炸。
### 2. 增量修正（Incremental Correction）
融合后的特征 zfusez_{fuse} ​ 并不直接替代原始特征，而是作为扰动加入：
zfinal=LN(zbase+β⋅(zfuse−zbase))z_{final} = LN(z_{base} + \beta \cdot (z_{fuse} - z_{base})) ​ = L N ( z ba se ​ + β ⋅ ( z f u se ​ − z ba se ​ ))
- 为什么这么设计？ 这是一种“残差学习”思路。当 β=0\beta=00 时退化为原始 RAE。β\beta 控制融合强度（实验设为 0.2）。这保证了即使融合效果不好，也不会完全破坏 Decoder 已经学到的解码能力，维持了分布的稳定性。
### 3. 三阶段解耦训练策略这是工程落地最关键的一环。直接联合训练会导致分布漂移，训练失败。
- Phase 1：冻结 Encoder，训练 Decoder。确立 Baseline 的解码能力。
- Phase 2：冻结 Encoder 和 Decoder，只训练融合模块。此时 Decoder 作为一个“隐式分布约束器”，迫使融合模块学习到的特征必须是 Decoder 能解码的。
- Phase 3：解冻 Decoder，与冻结的融合模块共同微调。Decoder 适应新的丰富特征，进一步提升重建质量。
## 关键结果：数字不会说谎实验在 ImageNet-256 上进行，对比基线包括 RAE、RApiAE 等。
重建质量（Reconstruction）：
指标 RAE (Baseline) DRoRAE (Phase 2) DRoRAE (Full, Phase 3) rFID 0.57 0.47 0.29 PSNR 18.8 21.79 24.32 LPIPS 0.256 0.195 0.134 SSIM 0.483 0.583 0.701DRoRAE 仅增加 29M 参数，就将 rFID 从 0.57 大幅降至 0.29，重建质量提升显著。
生成质量（Generation）：
使用相同的 DiT-XL 生成器：
- gFID (with AutoGuidance): RAE 为 1.74，DRoRAE 降至 1.65。
- IS (Inception Score): 从 235.0 提升至 230.6 (注：IS 越高越好，但 gFID 更综合，此处 gFID 提升更关键)。
- 文本到图像 (GenEval): 在 CC12M-LLaVA-Next 数据集上，DRoRAE 的整体 GenEval 得分 (0.60) 与 RAE (0.56) 相当，且单对象识别率 (0.98) 优于 RAE (0.96)。
消融实验揭示的关键点：
- 能量约束 vs Softmax：允许负权重的能量约束路由在 rFID 上优于 Softmax (0.470 vs 0.512)。
- 增量修正的必要性：若无增量修正，虽然重建 rFID 更低 (0.447)，但下游扩散模型训练损失 (DiT Loss) 高达 0.81，几乎是使用增量修正 (0.47) 的两倍。这证明了增量修正对保持生成兼容性至关重要。
## 工程启示：代表丰富度的缩放定律论文最迷人的发现之一是发现了 对数线性缩放定律 (Log-Linear Scaling Law) 。
- 专家容量扩展：固定融合12层，增加专家 MLP 的隐藏层维度，rFID 随参数量增加呈现对数线性下降 (R2=0.86R^2 = 0.86=0.86)。
- 层数扩展：固定专家容量，增加融合层数，rFID 也随层数增加而改善 (R2=0.49R^2 = 0.49=0.49)。
- 统一规律：将两者合并，总参数量与重建质量之间也存在显著的相关性 (R2=0.59R^2 = 0.59=0.59)。
这意味着， “表示丰富度” (Representation Richness) 成为了视觉 Tokenizer 中一个可预测、可缩放的新维度，类似于 NLP 中词汇表大小对语言模型的影响。
对工程师的建议：
- 不要忽视中间层：在使用 DINOv2 等 ViT 作为 Encoder 时，简单取最后一层是次优的。引入轻量级融合模块性价比极高。
- 训练策略至关重要：如果直接联合训练 Encoder、Fusion 和 Decoder，极易导致分布漂移，生成质量崩盘。采用“冻结-微调”的解耦策略是稳定落地的关键。
- 负权重是有用的：在特征融合中，允许模型“拒绝”某些层的噪声，比单纯的加权平均更鲁棒。
## 局限与展望目前 DRoRAE 仅在 DINOv2-B (12层) 上验证。论文提到，扩展到更大规模的 Encoder（更多层）以及视频 Tokenization 是未来的方向。此外，虽然重建质量大幅提升，但在某些极端复杂纹理下，生成模型的微调仍需小心控制学习率，以避免过拟合特定的高频噪声。
总的来说，DRoRAE 提供了一个清晰的范式： 利用预训练模型的层级信息，通过受控的融合机制，打破单层表示的信息瓶颈。 这对于任何基于 Latent 空间的视觉生成系统都是一个实用的升级路径。
