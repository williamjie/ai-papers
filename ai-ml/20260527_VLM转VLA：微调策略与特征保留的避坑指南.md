# ⭐⭐⭐⭐ VLM转VLA：微调策略与特征保留的避坑指南

**日期**: 2026-05-27

论文 : Rethinking VLM Representation for VLA Initialization链接 : https://arxiv.org/abs/2605.25802做机器人具身智能（Embodied AI）的工程师都知道，把视觉语言模型（Vision-Language Model, VLM）变成视觉语言动作模型（Vision-Language-Action, VLA）是目前的标配。但大家往往陷入一个误区：认为VLM越强、微调数据越多，下游控制效果就越好。这篇来自 CUHK 和 ACE Robotics 的论文直接泼了一盆冷水： 盲目全量微调（Full Finetune）可能会毁掉你的模型 。
它通过受控实验揭示了 VLM 到 VLA 初始化过程中的核心矛盾：如何在注入具身信号的同时，保留预训练特征？
### 为什么现在的做法有问题？
目前的 VLA 系统通常直接复用开源 VLM 作为策略主干。现有的研究（如 VLM4VLA）指出，更强的 VLM 理解能力并不一定转化为更好的控制策略。VLASER 也发现了视觉域间隙。但这些问题大多停留在粗粒度分析，没人系统地拆解过： 具体哪种具身能力有用？全量微调好还是 LoRA 好？
这篇论文把 VLA 初始化看作一个“受控表示设计”问题，从三个维度进行了深度拆解：
- 能力注入：哪些具身 VQA 领域（如空间、 grounding）对动作学习有益？
- 更新策略：全量微调 vs LoRA，谁更能保留有用的预训练特征？
- 数据耦合：机器人轨迹数据与感知侧 VQA 如何结合？
### 核心 Insight：少即是多，保留比重塑更重要#### 1. 具身能力不是越多越好，Grounding + Ego 是黄金组合作者将具身 VQA 分为 7 个领域。实验发现，单领域微调的效果高度依赖下游任务的瓶颈。
- Libero-10（长程任务）：几乎所有领域都能带来提升，最高 +4.0%。
- SimplerBridge（真实到仿真）：趋势反转，大多数领域表现下降，只有 Grounding 略有优势。
更关键的是多领域组合。 增益不是线性的 。最强的组合是 {Grounding + Egocentric Understanding} （定位 + 自我中心理解）。有趣的是，加入第三个领域（如 Spatial）或采用 7 领域均匀混合，性能反而下降。这说明不同能力信号之间存在干扰， 兼容性比覆盖面更重要 。
#### 2. LoRA 吊打全量微调：防止表示漂移这是本文最反直觉、也最具工程价值的结论。在注入具身信号时， LoRA 提供的初始化始终优于全量微调（Full Finetune） 。
- 现象：全量微调虽然能强行让模型学会 VQA 任务，但它严重破坏了预训练 VLM 中原本对动作学习有用的通用表示。
- 数据对比：在 Qwen3-VL-4B 基础上，使用 LoRA 进行 Grounding 微调，Libero-10 成功率从基线 92.4% 提升至 95.6%；而全量微调后，同一指标反而暴跌至 90.5%。
- 模型强度影响：基础模型越强，LoRA 的优势越明显。对于较弱的 PaliGemma2-3B，LoRA 甚至出现负增益，说明如果预训练表示本身就不够强，强行注入具身信号也难以奏效。
#### 3. 最佳实践：分阶段 LoRA 微调单纯注入感知信号不够，还需要动作侧的监督。作者测试了 AgiBot 机器人数据预训练的效果。
- 结论：最好的路径是 “分阶段 LoRA”。
先用 {Grounding + Ego} 数据进行 LoRA 微调，注入关键的感知先验。
- 再基于此 checkpoint，使用机器人轨迹数据进行 LoRA 预训练。
- 结果：这种组合在 RoboCasa 基准上达到了 55.2% 的成功率，比基线提升了 +5.7%，远超单独使用机器人数据或全量微调的方案。

### 给工程师的落地建议- 慎用全量微调：除非你有海量且高质量的对齐数据，否则在 VLM 到 VLA 的适配中，优先使用 LoRA。全量微调极易导致“灾难性遗忘”，丢失对控制至关重要的通用视觉特征。
- 精选数据领域：不要无脑堆砌所有具身数据集。优先关注 Grounding（空间定位） 和 Egocentric Understanding（自我状态感知）。这两个领域的信号与动作执行的关联度最高，且互不干扰。
- 分阶段训练：先让模型“看懂”场景中的关键物体和自身状态（VQA LoRA），再让它“学会”如何移动（Robot Data LoRA）。这种解耦训练能有效缓解感知目标与动作目标之间的竞争。
- 基座模型选择：LoRA 的效果依赖于基座模型的强度。如果预算允许，使用更强的 VLM（如 Qwen3-VL-4B 及以上）能获得更稳定的增益；弱模型微调后可能反而退步。
这篇论文的价值不在于提出了新架构，而在于通过严谨的消融实验，纠正了社区中“数据越多越好、微调越深越好”的错误直觉。在具身智能从实验室走向落地的阶段，这种对表示学习的精细化控制，才是提升鲁棒性的关键。
