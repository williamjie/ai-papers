论文 : Qwen-Image-2.0-RL Technical Report链接 : https://arxiv.org/abs/2606.27608扩散模型（Diffusion Models）在生成质量上已经卷到了天花板，但为什么我们总觉得 AI 生成的图“差点意思”？
这篇报告给出了答案：传统的监督微调（SFT）只能让模型学会“像”，却无法让它学会“好”。
Qwen-Image-2.0-RL 的核心价值在于，它展示了一套完整的、可落地的 RLHF（人类反馈强化学习）工程管线。
这不仅是一个算法改进，更是一份关于如何平衡多任务、多奖励信号的实战指南。
### 为什么 SFT 搞不定审美？
SFT 优化的是去噪分数匹配目标，它只关心像素级别的还原度。
但人类审美是主观的：构图和谐吗？光影自然吗？提示词里的细节都出现了吗？
这些高阶偏好无法通过简单的 L2 Loss 捕捉。
RLHF 在 LLM 领域的成功证明了其有效性，但在扩散模型中直接套用却面临三大工程挑战：
- 奖励信号难定义：文生图（T2I）看重美学，图像编辑看重身份保留，两者冲突。
- 训练不稳定：现有的 RL 框架多在 LoRA 微调上验证，全参数大规模训练极易崩溃。
- 模型分裂：专攻 T2I 的模型往往丧失编辑能力，反之亦然，难以统一部署。
### 核心 Insight 拆解#### 1. 奖励模型：绝对打分优于相对排序这是一个反直觉的发现。通常我们认为 Pairwise（成对比较）更符合人类偏好判断习惯。
但论文实验显示，Pointwise（点对点绝对打分）训练的奖励模型效果更好。
关键结论 ：Pointwise 标注提供了校准过的绝对质量信号（1-5分），而 Pairwise 只告诉模型“谁更好”，缺乏对“好多少”的感知。
Qwen 团队构建了分层奖励体系：
- 对齐奖励：确保提示词内容不遗漏（优先级最高）。
- 美学奖励：提升纹理和构图。
- 肖像奖励：专门针对人脸吸引力、皮肤质感进行优化。
对于图像编辑，则引入了基于模型的面部身份一致性评分器，弥补 VLM 在细微特征上的不足。
#### 2. RL 训练框架：混合 CFG 策略在扩散模型的 RL 训练中，Classifier-Free Guidance (CFG) 是个双刃剑。
论文对比了三种策略（见 Fig 3）：
- 全程使用 CFG：训练极不稳定，最终图像坍塌。
- 全程不用 CFG：奖励分数上升，但模型丢失风格化和世界知识（比如认不出名人）。
- 混合策略（Hybrid CFG）：仅在 Rollout（采样）阶段使用 CFG，在 Policy Optimization（策略优化）阶段排除无条件分支。
这是本文最关键的工程 Trick。
Rollout 时用 CFG 保证生成高质量候选样本，获得可靠奖励；训练时去掉 CFG 避免联合优化的梯度冲突，既稳定又省算力。
#### 3. 统一模型：On-Policy Distillation (OPD)
如何让一个模型既擅长画图又擅长修图？
简单的混合数据 RL 训练（Mix-RL）会导致目标冲突，性能不如专攻单项的模型。
Qwen 提出了 On-Policy Distillation (OPD) ：
- 分别训练 T2I 教师和编辑教师。
- 学生模型生成自己的轨迹（Trajectory）。
- 在轨迹上匹配对应任务教师的速度场（Velocity Matching）。

这种方法避免了多奖励联合优化的“跷跷板效应”，且无需依赖复杂的奖励模型推理，直接通过知识蒸馏融合能力。

### 工程启示对于正在尝试对扩散模型进行 RL 微调的工程师，这篇报告有三个直接建议：
- 奖励数据标注：如果资源允许，优先采用 Pointwise 绝对打分，而非 Pairwise。
- 训练稳定性：务必尝试“Rollout 用 CFG，Training 不用 CFG”的策略，这是防止模型崩溃的关键。
- 多任务融合：不要试图在一个 RL 循环里优化所有任务。先分头训练专家模型，再用 OPD 蒸馏合并，效果更稳。
### 局限与展望虽然 OPD 解决了多任务融合问题，但它依赖于高质量的教师模型。
如果教师模型本身存在偏差，学生也会继承这些偏差。
此外，异步奖励管道虽然解决了 I/O 瓶颈，但对网络延迟敏感，大规模分布式训练时需仔细设计同步机制。
未来，随着 VLM 奖励模型的进一步进化，我们有望看到更细粒度、更可控的图像生成与编辑能力。
