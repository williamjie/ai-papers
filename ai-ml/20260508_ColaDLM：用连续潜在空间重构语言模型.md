# Cola DLM：用连续潜在空间重构语言模型

**日期**: 2026-05-08

---

论文 : Continuous Latent Diffusion Language Model链接 : https://arxiv.org/abs/2605.06548如果语言模型的终极形态是“所见即所得”的并行生成，那么自回归（Autoregressive, AR）模型那强制的从左到右生成顺序就是最大的瓶颈。字节跳动种子团队（Seed）提出的 Cola DLM 试图打破这个枷锁。它没有简单地给 AR 模型加个 Diffusion 头，而是通过分层潜在变量（Hierarchical Latent Variable）将“全局语义组织”与“局部文本实现”彻底解耦。这对追求高吞吐、低延迟生成的工程场景来说，是一个极具启发性的方向。
## 为什么 AR 不够好？现有 Diffusion 的痛点自回归模型通过链式法则分解离散文本分布，虽然训练稳定，但推理必然串行，且强加了固定的顺序归纳偏置（Inductive Bias）。这导致它在填空（Infilling）、局部编辑等任务上表现不佳。
现有的替代方案各有硬伤：
- 离散 Diffusion 语言模型：去掉了显式的左右顺序，但在离散 token 空间进行观测恢复。中间状态缺乏稳定的语义表征，且多步采样速度慢。
- 连续 Diffusion 语言模型：如 Plaid，虽然引入了连续空间，但大多仍是在 token 对齐的表示空间里做“去噪恢复”，缺乏显式的分层潜在变量解释，本质还是观测恢复而非先验建模。
Cola DLM 的核心洞察在于： 扩散不应用于 token 级的观测恢复，而应用于潜在先验的迁移（Prior Transport）。 它利用连续空间的几何特性来压缩全局语义，再通过条件解码器实现局部文本。
## 方法拆解：分层潜在扩散架构Cola DLM 的设计可以概括为三个关键模块的协同工作，其核心在于“分层”与“块因果”（Block-Causal）。
### 1. Text VAE：稳定的映射基础首先，训练一个文本变分自编码器（Text VAE）。这一步的目的不是直接生成文本，而是建立文本与连续潜在变量（Continuous Latent Variable, z0z_0 ​ ）之间的稳定映射。
- 设计细节：VAE 的编码器和解码器都是严格因果的（Strictly Causal），以防止信息泄漏并支持流式生成。
- 关键损失：除了重建损失和 KL 散度，论文引入了类似 BERT 的掩码损失（Masking Loss, LmaskL_{mask}​）。这是为了防止编码器在语义上坍塌，避免解码器仅仅通过记忆表面文本来完成任务。
### 2. Block-Causal DiT：学习全局语义先验这是 Cola DLM 的灵魂。在稳定的潜在空间上，使用基于 DiT（Diffusion Transformer）的 Flow Matching 来学习潜在先验 pψ(z0)p_\psi(z_0) ​ ( z 0 ​ ) 。
- 为什么用 Block-Causal？ 潜在序列被分解为多个块（Blocks）。模型在每个块内使用双向注意力，但在块之间保持因果依赖。这种设计既保留了跨块的因果结构（符合语言逻辑），又允许块内并行计算，提升了效率。
- 联合训练策略：论文发现，固定 VAE 会导致性能饱和，而从头训练则不稳定。最佳策略是联合演化（Joint Evolution）：在预训练 VAE 的基础上，以 DiT 的学习率同步微调 VAE 和 DiT。这种“受控的共同适应”让潜在分布和先验模型协同进化。
### 3. 推理流程：潜在空间的并行生成在推理时，模型首先将前缀（Prefix）编码为干净的潜在条件 zprez_{pre} ​ 。随后，它不再逐个 token 生成，而是 逐块生成 响应潜在变量。每个块通过历史条件和噪声种子进行传输生成，最后通过条件解码器将潜在变量还原为离散文本。
## 关键实验结果论文在约 2B 参数规模下，与严格匹配设置（相同数据、相同随机种子）的 AR 基线（LLaMA 架构）和离散 Diffusion 基线（LLaDA）进行了对比。评估指标摒弃了不稳定的困惑度（Perplexity），采用多任务准确率。

更有趣的是 RQ1 的实验发现：随着潜在维度从 16 增加到 128，最佳的时间步偏移（Timeshift）从 1.0 系统性地漂移至 2.3。这证明了潜在空间中存在 跨维度的共享全局语义结构 ，而非局部的 token 特征。这也验证了 Cola DLM 理论框架中“低维全局语义+高维局部实现”假设的有效性。
## 工程启示- 潜在空间需要“活”着：不要冻结 VAE 后只训练 Diffusion 模型。实验表明，以预训练 VAE 为起点进行联合微调（Joint DiT x1），能获得最强的缩放潜力（Scaling Potential）。
- 评估指标需谨慎：Cola DLM 的估计对数似然（Log-likelihood）与实际生成质量存在巨大错位。在评估非自回归模型时，直接依赖困惑度或似然估计可能会产生误导，应更多依赖任务准确率等下游指标。
- 统一模态的潜力：由于 Cola DLM 在连续潜在空间进行建模，它天然地桥接了离散文本与连续模态（如视觉）。这为构建统一的文本-视觉生成模型提供了一条清晰的路径。
## 局限与展望尽管 Cola DLM 展示了良好的缩放行为，但它引入了变分推断间隙（Variational Inference Gap），即编码器 qϕ(z0∣x)q_\phi(z_0|x) ​ ( z 0 ​ ∣ x ) 与生成模型 pθ,ψ(z0∣x)p_{\theta,\psi}(z_0|x) ​ ( z 0 ​ ∣ x ) 之间的不匹配。如果数据本身缺乏低速率但高信息量的全局表示，这种瓶颈反而可能损害性能。未来的工作可能需要更智能的潜在维度选择机制，以及如何进一步加速块级生成的推理过程。
