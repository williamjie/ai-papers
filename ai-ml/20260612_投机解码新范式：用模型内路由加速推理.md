论文 : VIA-SD: Verification via Intra-Model Routing for Speculative Decoding链接 : https://arxiv.org/abs/2606.12243传统投机解码（Speculative Decoding, SD）就像一场非黑即白的审判：小模型起草的 token 要么被大模型全盘接受，要么被直接打回重算。这种二元决策忽略了大量“虽然不完美但勉强能用”的中间地带，导致计算资源浪费。
这篇论文提出了 VIA-SD ，核心直觉是引入一个“瘦验证器（Slim-verifier）”。它不是独立的小模型，而是从大模型内部通过路由机制截取出来的子网络。这个设计巧妙地处理了那些处于灰色地带的 token，既避免了全量重算的高昂成本，又比直接接受更可靠。
### 为什么现有方案不够好？
目前的 SD 方法大多停留在“起草-验证”的二元框架内。即使有分层验证（Hierarchical SD），往往也依赖额外的独立模型或复杂的训练策略来构建中间层。这带来了两个工程痛点：
- 显存开销大：加载多个不同大小的模型会显著增加内存峰值。
- 分布不一致：独立训练的中间模型与大模型的输出分布存在偏差，导致验证效率下降。
作者从信息几何角度指出，KL 散度（Kullback-Leibler Divergence）具有可分解性。与其让大模型直接处理所有拒绝的 token，不如引入一个中间分布 uu ，将验证过程拆解为 p→u→qp \to u \to q u → q 的多步路径。如果设计得当，这种阶梯式验证能显著降低整体计算成本。
### 方法拆解：动态模型内路由（DIMR）
VIA-SD 的核心创新在于如何构建这个中间分布 uu 。作者没有引入新模型，而是提出了 动态模型内路由（Dynamic Intra-Model Routing, DIMR） 。
- 瘦验证器的构造：从大验证器 qq 中选取部分层组成子模型 q′q'。关键在于，q′q' 与大模型共享嵌入层和输出头，保证了分布的一致性。
- 层级验证流程：
起草：小模型生成候选块。
- 初筛：瘦验证器 q′q' 进行第一道关卡。高置信度 token 直接通过。
- 再决断：对于 q′q' 拒绝的 token，如果其置信度处于中等水平，由 q′q' 重新生成；只有极低置信度的 token 才会触发大模型 qq 的全量重算。
这种设计的妙处在于，它利用大模型自身的结构作为“中间人”，无需额外训练，只需离线搜索一次最佳的路由掩码（Routing Mask）。
### 关键结果：速度与准确率的双赢实验覆盖了 Gemma2、LLaMA2 和 Qwen 等多个模型家族。在 QA 和推理任务上，VIA-SD 的表现令人印象深刻：

消融实验显示，相比随机跳过层或使用独立中间模型，DIMR 路由在保持峰值显存仅增加 1.04× 的情况下，实现了最高的加速比。离线搜索成本极低，对于 Gemma2 2B→9B 仅需 18 分钟（0.3 GPU-hours）。
### 工程启示与局限对于工程落地，VIA-SD 的最大价值在于 兼容性 。它不需要修改现有 SD 框架的训练流程，只需在推理阶段插入路由逻辑。这意味着你可以轻松将其集成到 vLLM 或 TGI 等主流推理引擎中。
- 适用场景：特别适合显存受限但需要高吞吐量的场景。瘦验证器复用了大模型的参数，避免了加载额外模型的开销。
- 超参敏感性：实验表明，路由比例（Skip Ratio）存在一个甜蜜点（约 45%）。跳过层数过多会导致瘦验证器能力不足，触发更多回退；过少则无法体现加速优势。
不过，该方法目前主要针对 Decoder-only 模型进行了充分验证。虽然 Encoder-Decoder 模型（如 T5）也有提升，但在翻译任务中的收益略低于 QA 任务。此外，离线路由搜索的时间随模型规模线性增长，对于超大模型（如万亿参数），预处理成本可能需要进一步优化。
总之，VIA-SD 证明了在投机解码中，“中间地带”值得被认真对待。通过简单的模型内路由，我们能在不牺牲准确率的前提下，榨干大模型的推理性能。
