# ⭐⭐⭐½ 世界模型幻觉：可预测且可预防

**日期**: 2026-06-26

论文 : Hallucination in World Models is Predictable and Preventable链接 : https://arxiv.org/abs/2606.27326做世界模型（World Model）的朋友肯定遇到过这种绝望：生成的视频看着挺流畅，但物理规律全崩了。球穿墙、物体瞬移，这种“幻觉”不仅视觉假，更致命的是它会误导下游的控制策略。这篇 UCSD 的新作给出了一个反直觉的结论： 幻觉不是架构问题，而是数据覆盖率问题。
### 痛点：为什么世界模型会“做梦”？
现有的观点倾向于认为，只要模型够大、算力够猛，幻觉就会消失。但作者指出，幻觉本质上是模型在状态-动作空间（State-Action Space）的低覆盖区域进行的错误外推。
论文将幻觉拆解为三种截然不同的模式，每种对应模型的不同阶段：
- 感知幻觉：Tokenizer 把未见过的场景强行映射成它见过的样子（比如把陌生迷宫重建为熟悉的布局）。
- 动作边际化：动态模型忽略了输入的动作，生成的视频像普通生成器，而非可控的世界模型。
- 场景发散：多步推理中误差累积，导致物理上不可能的事件发生（如乒乓球得分后瞬移回赛场）。
### 核心 Insight：用内部信号预测失败最工程化的价值在于，作者证明了 不需要额外标签或训练 ，仅凭模型内部的三个信号就能精准预测幻觉：
- Tokenizer 往返残差 (uru_r​)：解码后再编码，看 latent code 变化多大。如果变化大，说明当前帧超出了 Tokenizer 的流形分布。
- 流动不稳定性 (ufu_f​)：在去噪步骤中，干净目标预测值的震荡程度。震荡越大，模型越“犹豫”，越容易出错。
- 种子间方差 (usu_s​)：固定过去和动作，不同噪声种子生成的下一帧差异。差异大意味着认知不确定性高。
⚠️ 关键发现 ：这三个看似无关的信号，与实际 Rollout 的 Δ\Delta PSNR 误差具有高达 ρ≈−0.80\rho \approx -0.80 − 0.80 的强负相关。这意味着，模型在“撒谎”前，内部信号已经发出了警报。
### 实验验证：少样本微调的威力为了验证这一理论，作者构建了 MMBench2 数据集（427小时视频，210个任务），并训练了一个 350M 参数的 Dreamer 4 架构模型。
1. 覆盖感知训练（Coverage-aware Training）
简单调整采样策略，让训练数据在任务间均匀分布，而非按帧数加权。
- 结果：Rollout Δ\DeltaPSNR 提升 +0.88 dB，且所有三个幻觉预测指标均显著下降。
2. 针对性数据采集（Targeted Data Collection）
这是最惊艳的部分。作者将上述幻觉预测信号作为“好奇心奖励”，引导模型去探索它��易出错的区域。
- 场景：完全未见过的新环境。
- 数据量：仅收集 50 条轨迹。
- 结果：在未见任务上，基于好奇心的微调将 MPC 任务性能从基线的 0.118 提升至 0.325，达到了专家策略（0.362）的 90%。
相比之下，随机策略采集的数据几乎无效，因为世界模型需要的是“边界状态”的覆盖，而非均匀噪声。
### 工程启示：如何落地？
- 监控即防御：在部署世界模型时，不要只盯着 PSNR。实时监控 uru_r​ 和 ufu_f​，当信号超过阈值时，直接拒绝该 Rollout 或触发重规划。
- 数据比架构重要：如果你的模型在特定场景下频繁幻觉，别急着加层数。检查该场景在训练数据中的覆盖率，针对性补充少量高质量轨迹往往更有效。
- Tokenzier 的局限性：论文对比了现成的 Tokenizer（如 Wan 2.1 VAE），发现它们在未见任务上泛化更好，但在域内微调后，专用 Tokenizer 依然更强。结论：如果有算力，针对特定域微调 Tokenizer 是提升上限的关键。
### 局限与展望目前实验基于 350M 参数和模拟环境。在真实机器人场景中，传感器噪声和部分可观测性（Partial Observability）可能会干扰这些内部信号的稳定性。此外，计算这些预测信号本身也有开销，如何在实时系统中平衡检测成本与延迟，是下一步工程化的重点。
总之，这篇论文把“幻觉”从一个玄学问题变成了一个可量化、可干预的数据工程问题。对于正在调试 World Model 的工程师来说，这是一套即插即用的诊断工具箱。
