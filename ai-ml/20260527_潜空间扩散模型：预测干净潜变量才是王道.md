# ⭐⭐⭐½ 潜空间扩散模型：预测干净潜变量才是王道

**日期**: 2026-05-27

---

论文 : JLT: Clean-Latent Prediction in Latent Diffusion Transformers链接 : https://arxiv.org/abs/2605.27102在扩散模型的工程实践中，我们通常默认“预测噪声（ ϵ\epsilon ）”或“预测速度（ vv ）”是标准操作。但 JLT 这篇论文通过一个极其干净的对照实验告诉我们： 在潜空间（Latent Space）中，直接预测干净数据（Clean-Latent Prediction）的效果远超预测速度。
这不仅仅是换个损失函数那么简单，它揭示了潜空间几何结构对回归任务难度的深层影响。对于正在优化 DiT 架构或探索高效扩散模型的工程师来说，这是一个值得重新审视设计空间的信号。
### 为什么潜空间里的目标选择很重要？
DDPM 时代流行预测噪声 ϵ\epsilon ，后来的 Flow Matching 和 EDM 确立了速度 vv 的主流地位。理论上，给定时间步 tt ， ϵ\epsilon 、 xx （干净数据）和 vv 之间可以通过仿射变换互相转换。因此，很多人认为这只是“代数上的等价”，模型容量足够时，预测谁都一样。
然而，JiT 在像素空间已经证明，直接预测干净图像能让 Transformer 更专注于低维流形结构，而不是重建全维度的噪声。JLT 的核心问题是： 当图像已经被 VAE 压缩到潜空间后，这种“几何优势”是否依然存在？
直觉上，VAE 已经去除了大量冗余信息，潜空间的维度更低、结构更紧凑。但作者认为，即使经过压缩，潜空间的协方差矩阵仍然是各向异性的（Anisotropic）。预测不同的目标，实际上是在改变网络需要拟合的分布形状。
### 核心 Insight：几何视角下的目标差异JLT 没有发明新的 Backbone，而是基于 FLUX.2 VAE 构建了一个 130M 参数的 Base-scale Transformer（称为 JLT-B/1），并与同样架构但预测速度 vv 的 DiT-B/1 进行严格对照。
作者通过局部高斯近似（Local Gaussian Analysis）给出了一个非常直观的解释：
-协方差基底不同：
干净潜变量 xx 的协方差是 Σ\Sigma。
- 速度目标 v=x−ϵv = x - \epsilonx−ϵ 的协方差是 Σ+I\Sigma + II。
- 这意味着，预测速度会给每个潜变量方向都加上一个单位方差的“基底噪声”。在那些数据变化很小的低方差方向上，速度目标的信噪比反而更低。
-条件歧义性（Conditional Ambiguity）：
对于给定的含噪输入 ztz_t​，预测干净潜变量 xx 的贝叶斯残差方差随着数据方差 λi\lambda_i​ 减小而减小。
- 而预测速度 vv 的残差方差在低方差方向上会被放大。
- 结论：Clean-prediction 自动抑制了那些数据分布中不重要的低频/低方差方向，让模型聚焦于高方差的结构信息；而 Velocity-prediction 则迫使模型去拟合这些被放大的噪声基底。
### 实验结果：差距巨大在 ImageNet 256x256 数据集上，JLT 展示了惊人的性能提升。所有对比都在相同的 VAE、相同的 Transformer 架构（12层，768隐藏维度）、相同的训练步数（250K steps）下进行。
模型 预测目标 FID-50K ↓ IS ↑ JLT-B/1 Clean Latent ( xx ) 2.56 220.74 DiT-B/1 Velocity ( vv ) 6.56 132.12 JLT-B/2 Clean Latent ( xx ) 14.81 107.29 DiT-B/2 Velocity ( vv ) 28.71 58.46- FID 提升显著：在 /1 patch size 下，Clean-prediction 将 FID 从 6.56 降低到 2.56，提升了近 2.5 倍。
- 泛化性强：即使在更激进的 /2 patch size 下（Token 数量减半），Clean-prediction 依然以 14.81 vs 28.71 的优势胜出。
- 最终性能：经过进一步优化，JLT-B/1 在 Classifier-Free Guidance 下达到了 FID-50K 2.50，超过了像素空间的 JiT-L/16（FID 2.79），尽管参数量仅为后者的 1/3。
训练曲线也显示，Clean-prediction 模型在训练早期就进入了低 FID 区域，并且收敛更稳定。
### 工程启示- 重新评估 Loss 设计：如果你正在使用 DiT 或类似架构进行潜空间扩散建模，不要盲目沿用速度预测（Velocity Prediction）。尝试直接回归干净潜变量（Clean Latent），可能会获得显著的生成质量提升和更快的收敛速度。
- 几何直觉优于代数等价：在有限容量的网络中，目标的几何分布（协方差结构）决定了学习的难度。选择能“对齐”数据流形方向的目标，比单纯追求数学上的简洁更重要。
- 潜空间压缩并非万能：即使 VAE 已经去除了像素级的冗余，潜空间内部依然存在各向异性。预测目标的选择需要适配这种内在几何结构。
### 局限与展望JLT 目前主要在 ImageNet 256x256 上验证，且基于 FLUX.2 VAE。不同数据集、不同分辨率以及不同的 Tokenizer 可能会改变潜空间的协方差特性。此外，论文指出该分析基于局部高斯假设，真实分布的非高斯性可能引入额外复杂度。
尽管如此，JLT 提供了一个强有力的证据： 在潜扩散模型中，预测目标是一个独立的几何建模选择，而非简单的代数参数化。 对于追求极致生成质量的团队来说，这值得一次快速的 A/B 测试。
