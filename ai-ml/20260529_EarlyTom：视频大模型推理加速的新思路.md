# ⭐⭐½ EarlyTom：视频大模型推理加速的新思路

**日期**: 2026-05-29

---

论文 : EarlyTom: Early Token Compression Completes Fast Video Understanding链接 : https://arxiv.org/abs/2605.30010视频大模型（Video-LLM）落地难，核心痛点不在 LLM 生成慢，而在视觉编码器（Vision Encoder）处理海量帧的开销太大。
这篇来自阿里和西湖大学的论文 EarlyTom，提供了一个反直觉但极具工程价值的思路： 别在 LLM 阶段剪枝了，去视觉编码器内部做早期压缩 。
### 现有方案的“隐形瓶颈”
大多数现有的 Token 压缩方法（如 HoliTom、VisionZip）都在视觉编码完成后，进入 LLM 之前进行剪枝。
作者通过性能剖析发现了一个被忽视的事实：在基线模型中，视觉编码占首字延迟（Time-to-First-Token, TTFT）的 36.3%。
⚠️ 反直觉数据 ：当使用 HoliTom 或 VisionZip 等优化 LLM Prefill 的方法时，视觉编码在 TTFT 中的占比反而飙升至 55.8% 和 68.4% 。
这意味着，如果你只优化 LLM 部分，视觉编码器会成为越来越明显的短板，甚至引入额外的处理开销（HoliTom 的视觉 Token 处理时间增加了 121.9%）。
### EarlyTom 的核心设计直觉EarlyTom 的核心 Insight 是： 压缩越早发生，收益越大 。它通过两个阶段在视觉编码器内部完成压缩：
1. 视觉编码器内的帧合并（Inner-Vision Encoder Frame Merging）
视频帧之间存在大量时间冗余。EarlyTom 不直接丢弃帧，而是在编码器的中间层进行合并。
- 流式分段：利用指数移动平均（EMA）计算相邻帧的余弦相似度，当相似度低于阈值时划分段边界。
- 局部最优合并：在段内，如果两帧相似度高于阈值且高于下一对帧，则合并。
- 加权融合：合并后的特征通过相似度权重进行加权平均，保留语义关键信息。
2. 解耦的空间 Token 选择（Decoupled Spatial Selection）
传统的 Top-K 选择容易受“注意力下沉”（Attention Sink）现象影响，导致选出的 Token 分布偏差。EarlyTom 将帧分为动态和静态两类：
- 动态帧（段首尾帧，信息量大）：进行全局 Top-K 选择。
- 静态帧（中间帧，冗余高）：采用局部窗口 Top-K 选择，保持空间分布均匀性，避免偏差。
- 系统协同设计：将静态 Token 的选择卸载到 CPU，利用异构计算进一步降低延迟。
### 关键实验结果在 LLaVA-OneVision-7B 模型上，EarlyTom 展示了显著的加速效果（测试环境：NVIDIA A100）：

### 工程启示与局限对实际部署的指导意义：
- 关注全链路延迟：不要只盯着 LLM 的生成速度，视觉编码器的优化空间巨大，尤其是对于长视频理解任务。
- 无训练优势：EarlyTom 是 Training-free 的，这意味着它可以即插即用，无需重新微调庞大的多模模型，极大降低了落地成本。
- 异构计算利用：将部分 Token 选择逻辑卸载到 CPU，是提升端侧或边缘设备推理效率的有效手段。
局限与展望：
- 目前主要验证于 SigLIP 视觉编码器架构，对其他类型编码器的泛化性需进一步测试。
- 帧合并依赖于相似度阈值，对于剧烈运动或场景切换极快的视频，可能需要更动态的参数调整策略。
