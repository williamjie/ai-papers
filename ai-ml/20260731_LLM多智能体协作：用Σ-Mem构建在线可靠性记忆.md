# ⭐⭐⭐⭐ LLM多智能体协作：用Σ-Mem构建在线可靠性记忆

论文 : Σ-Mem: An Online Reliability Memory for LLM-based Multi-Agent Systems链接 : https://arxiv.org/abs/2607.27958在多智能体系统（Multi-Agent Systems, MAS）中，中心模型最头疼的不是“怎么干活”，而是“信谁”。现有方案大多把精力花在记录对话内容上，却忽略了动态评估 Agent 的可信度。南洋理工大学 DeCLaRe Lab 提出的 Σ-Mem 填补了这一空白，它不存文本，只存“信任证据”，让系统能在线适应 Agent 能力的漂移和失效。
### 痛点：为什么内容记忆不够用？
在长周期任务中，中心模型经常面临验证困境。比如在 RAG 场景下，如果支撑上下文缺失，多个 Peer 可能给出看似一致但实际错误的答案。
此时，单纯的内容回放毫无意义。因为“大家都这么说”往往意味着共同偏见或相关错误，而非独立证据。现有的内容记忆无法回答核心问题： 在当前任务类型下，哪个 Agent 是真正靠谱的？ Σ-Mem 的直觉很直接：与其让中心模型去死磕难以验证的答案，不如维护一份历史可靠性账本。
### 方法拆解：对称矩阵与 Weyl 不等式Σ-Mem 的核心设计非常巧妙，它抛弃了传统的向量检索或文本摘要，转而使用 实对称矩阵 来存储两种证据：
- 个体能力证据（Historical Competence Evidence）：为每个 Peer 维护一个对称矩阵 MpM_p​。
- 同伴关系证据（Peer Relationship Evidence）：维护一个全局图矩阵 GG，记录 Peer 之间的相关性。
为什么要用对称矩阵？ 这里有一个深刻的数学洞察。利用 Weyl 不等式 ，作者证明了每次更新带来的特征值变化是有界的。这意味着，单次的噪声或异常反馈不会瞬间扭曲整个记忆状态，只有持续、一致的证据才能在频谱中累积。这种设计天然具备了抗噪性和长期稳定性。
在推理阶段，Σ-Mem 通过**残差引导（Residual Steering）**将历史证据注入中心模型。它不修改模型权重，而是根据任务输入提取能力方向 ϕ(x)\phi(x) ，读取对应的可靠性向量并叠加到高层解码器的残差流中。这让中心模型在评估答案时，能“潜意识”地偏向那些历史上更靠谱的 Agent。
### 关键结果：反事实攻击下的表现论文在五个 Qwen 系列模型上进行了严格测试，最引人注目的是**反事实基准（Counterfactual Benchmark）**实验。该实验模拟了 Peer 可靠性发生剧烈漂移的场景。
模型 CF@90 (基线) CF@90 (+ Σ-Mem w/ G) 提升幅度 Qwen3-0.6B 46.22% 71.10% +24.88% Qwen3-4B 67.86% 73.30% +5.44% Qwen3.5-9B 70.99% 76.95% +5.96%⚠️ 反直觉发现 ：在 CF@50（一半历史支持原偏好，一半支持新偏好）的模糊场景下，Σ-Mem 的表现反而下降。作者指出这并非机制失效，而是记忆对模糊数据流的“忠实反映”。这也提示我们，在真实工程中，当历史信号冲突时，需要引入自适应平衡机制。
此外，Σ-Mem 还展现了极强的泛化能力：
- 跨领域：在未见过的 BBH 复杂推理任务上，Qwen3-4B 从 20.38% 提升至 28.66%。
- 新 Peer：训练时只用 3 个 Peer，测试时加入未见过的 Llama-3.2 等模型，系统依然能有效识别并路由任务。
### 工程启示与局限对工程师而言，Σ-Mem 的最大价值在于其 接口通用性 。同一个冻结的记忆状态，既可以用于引导中心模型评估（Steered Selection），也可以直接用于无响应路由（M-Route）或加权投票（M-Vote）。在 OOD 测试中，简单的 M-Route 甚至击败了多数投票基线。
落地建议：
- 反馈闭环是必须的：Σ-Mem 依赖外部正确性标签进行更新。如果你的系统没有自动评估器或人工标注流，这个方法无法启动。
- 小模型收益更大：数据显示，Qwen3-0.6B 的提升幅度远超 9B 模型。对于算力受限的边缘部署，这种基于记忆的协调机制性价比极高。
当然，它也有局限。目前主要依赖离散的 Correctness Label，对于部分正确的中间步骤尚难建模。但在多 Agent 协作日益复杂的今天，先解决“信谁”的问题，比追求完美的内容记忆更具工程优先级。
