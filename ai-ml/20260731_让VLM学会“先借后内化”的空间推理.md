论文 : SpatialCLI: Learning to Reason With Spatial Tools, Then Without Them链接 : https://arxiv.org/abs/2607.27703现在的视觉语言模型（VLM）有个尴尬的痛点：懂语义但“眼拙”。
面对复杂的物理空间任务，通用 VLM 能拆解指令，但在定位、分割或深度感知上经常掉链子。而 SAM、Depth Anything 等专家模型虽然精准，却缺乏任务级决策能力。SpatialCLI 的核心直觉非常工程化： 既然单靠模型学不会，不如先让它在推理时调用专家工具（Call），学会怎么调（Learn），最后把成功的调用轨迹“翻译”成自然语言思维链，让模型直接内化这种感知能力（Internalize）。
### 为什么需要“先借后内化”？
现有的 Agent 方案通常只做到前两步：挂载工具并微调使用策略。这导致模型永远依赖外部 API，推理延迟高且链路脆弱。SpatialCLI 试图解决一个更本质的问题： 如何将外挂的专家感知能力，转化为模型自身的原生参数？
它的核心洞察在于：成功的工具调用轨迹（Trajectory）本身就包含了高质量的感知证据和推理逻辑。如果能将这些结构化数据“口语化”，就能作为监督信号训练模型直接输出结果，从而实现从“依赖工具”到“自带技能”的跨越。
### 方法拆解：三阶段进化论SpatialCLI 的流程设计极其清晰，分为 Call、Learn、Internalize 三个阶段：
-Call（挂载工具）：
在推理时暴露四个专家视觉模型作为工具：Locate（定位）、Segment（分割）、Depth（深度）和 Pose（姿态）。VLM 扮演规划者，根据任务需求调用工具获取细粒度证据。
-Learn（代理微调）：
直接对初始模型进行强化学习（RL）容易陷入无效探索。SpatialCLI 采用“冷启动 SFT + 代理 RL”策略。先用大模型（Qwen3.5-397B）生成高质量的工具调用轨迹进行监督微调，建立基本行为模式；再使用 GRPO 算法通过任务反馈优化工具选择和参数生成。
-Internalize（能力内化）：
这是最精彩的部分。它将成功的 RL 轨迹转化为两种训练视图：
能力内化视图：将多轮工具交互“压缩”为单轮的自然语言思维链，监督模型直接输出答案，从而内化感知能力。
- 工具使用视图：保留原始交互结构，防止模型遗忘如何调用工具。
通过联合训练，模型既学会了“看”，也没丢掉“用”。
### 关键结果：数据不会撒谎SpatialCLI 在自建的 SpatialCLI-Bench（516 个样本）和 MindCube 等基准上表现优异。以下是基于 Qwen3-VL-8B-Instruct 的核心数据对比：
模型配置 SpatialCLI-Bench MindCube Qwen3-VL-8B (Baseline) 35.3% 29.3% + AlloSpatial Tools 43.2% (+7.9) 35.2% (+5.9) + SpatialCLI Tools 66.5% (+31.2) 47.2% (+17.9) SpatialCLI-8B (内化后) 72.7% (+37.4) 73.8% (+44.5) SpatialCLI-8B + Tools 91.3% (+56.0) 84.6% (+55.3)
⚠️ 反直觉发现 ：内化后的模型在不使用工具的情况下，性能远超基线，甚至超过了 GPT-5.6 Sol 挂载工具后的表现（72.1%）。更重要的是，内化并没有损害工具调用能力，挂载工具后得分反而进一步提升至 91.3%。
消融实验还揭示了一个关键细节： 结构化返回优于视觉返回 。在工具输出格式上，仅返回坐标和多边形结构数据（Structured Only）比附加可视化图像（Visual Only）效果好得多。这说明对于 VLM 而言，显式的几何约束比额外的像素信息更容易被内化和利用。
### 工程启示- 工具调用是高效的“教师”：与其花大力气收集复杂的 3D 标注数据，不如让大模型通过调用成熟的专家模型生成高质量轨迹。这是一种低成本、高信噪比的数据合成策略。
- 双重视图防止灾难性遗忘：在微调 Agent 时，直接追求“零延迟”往往会导致工具使用能力退化。SpatialCLI 的双视图联合训练证明了保留工具调用策略与内化原生能力可以并行不悖。
- 结构化数据优于多模态冗余：在构建内部推理链时，优先提取坐标、类别等结构化语义，而非堆砌图像上下文，能显著提升模型的泛化效率。
### 局限与展望SpatialCLI 目前仍受限于专家工具的覆盖范围，且主要针对感知类任务。论文指出，未来需要扩展到统一的多模态模型，并整合 VLA（视觉语言动作）工具，实现从“感知内化”到“行动内化”的闭环。对于工程师而言，这套“外挂转内生”的训练范式，为构建更轻量、更独立的具身智能体提供了一条可落地的路径。
