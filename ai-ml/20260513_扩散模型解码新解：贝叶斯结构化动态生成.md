# 扩散模型解码新解：贝叶斯结构化动态生成

**日期**: 2026-05-13

---

论文 : Dystruct: Dynamically Structured Diffusion Language Model Decoding via Bayesian Inference链接 : https://arxiv.org/abs/2605.09820扩散语言模型（Diffusion Language Models, DLMs）一直被视为自回归模型的高效替代方案，核心卖点在于其并行解码能力。但现实很骨感：现有的 DLMs 大多依赖固定的生成长度，要么截断长文本，要么产生冗余废话。更糟糕的是，现有的动态长度方案要么需要昂贵的重训（如 FlexMDM），要么依赖简单的局部置信度启发式规则，导致生成的文本结构破碎，逻辑连贯性极差。
这篇论文提出的 DyStruct 框架，直接切中痛点： 在不修改模型参数、无需重训的前提下，通过贝叶斯推断将“灵活长度生成”转化为一个“结构化推理”问题。 它不仅动态决定生成多少内容，还决定内容如何分块、按什么顺序解码。
## 痛点：为什么固定长度和简单启发式不行？
自回归模型虽然串行，但天然具备因果依赖；而扩散模型并行去噪时，token 之间是条件独立的，这导致分布漂移。为了缓解这个问题，研究者尝试让 DLMs 支持可变长度，但现有方案有两个致命缺陷：
- 成本高昂：像 DID 和 FlexMDM 需要重新训练前向过程或模型参数，工程落地门槛极高。
- 结构缺失：像 DAEDAL 这类免训练方法，仅依靠局部的置信度阈值进行单调扩展。一旦生成长度增加，缺乏全局结构指导，容易导致语义碎片化，特别是在代码生成或多步逻辑推理中，早期错误会迅速污染后续内容。
## 方法拆解：贝叶斯结构化解码DyStruct 的核心 Insight 在于： 不要盲目扩展窗口，而是先“规划”再“执行”。
它将每一步的解码过程建模为对三个潜变量联合后验的推断：
- 扩展长度 (LtL_t​)：下一步生成多少个 token？
- 块划分 (P(t)P^{(t)})：新窗口内的 token 如何分组为连续块（Blocks）？
- 解码调度 (τ(t)\tau^{(t)})：这些块按什么顺序解码？
### 1. 动态窗口扩展：基于不稳定性的泊松分布模型不会随机决定长度，而是观察上一步解码窗口的平均不稳定性（Mean Instability, hˉ\bar{h} ˉ ）。如果上一步很稳，就大胆扩展；如果不稳，就保守收缩。具体公式为泊松分布 Poisson(μt)Poisson(\mu_t) ​ ) ，其中 μt\mu_t ​ 由上一步的不稳定性动态缩放。
### 2. 块划分：CRP 先验解决“切哪里”
这是本文最精彩的设计。传统方法要么一刀切，要么随机切。DyStruct 引入了**中国餐馆过程（Chinese Restaurant Process, CRP）**作为先验。
- 直觉：每个新 token 像顾客，可以选择加入当前块（继续坐），或者开新桌（切分）。
- 机制：通过计算相邻 token 间的“边缘得分”（Edge Score），结合 CRP 的浓度参数 α\alpha，动态决定切割点。
- 优势：无需预设块数量，模型根据数据证据自动判断哪里该断句、哪里该连贯。
### 3. 上下文感知调度：先稳后难有了块之后，先解哪个？DyStruct 使用 Gibbs 分布进行调度排序。
- 优先级公式：ρ(B)=−H(B)+γC(B)\rho(B) = -H(B) + \gamma C(B)−H(B)+γC(B)。
- 含义：优先解码那些**不稳定度低（H(B)H(B) 小）且上下文锚定好（C(B)C(B) 高，即两侧已有确定 token）**的块。
- 效果：先确立稳定的结构锚点，再逐步解决高不确定性的逻辑中间层。这就像写文章先定开头结尾，再填中间内容，避免逻辑崩塌。
### 4. 边缘焊接（Edge-Welding）
块之间独立解码会导致边界处的 token 分布不一致。DyStruct 在块解码后，对边界附近低置信度的 token 进行局部重新掩码（Remask）和精细打磨，确保上下文连贯。
## 关键结果：无需重训，性能显著提升实验基于 LLaDA-8B-Base 和 Dream-7B-Base 两个基线模型，在数学推理、代码生成和逻辑推理三个领域进行评测。所有方法共享相同的计算预算（256 次去噪迭代上限）。

## 工程启示- 即插即用：DyStruct 完全在推理时运行，不修改模型权重。这意味着你可以直接将其应用到任何现成的 DLM 部署中，无需重新训练或微调，极大降低了工程改造成本。
- 计算资源重新分配：它不是简单地“生成更多 token”，而是将计算预算集中在“难”的地方。对于 Agent 或长文本生成任务，这种自适应计算分配能显著降低延迟并提升质量。
- 结构化生成的必要性：在复杂任务中，单纯增加并行度或长度是不够的，必须引入结构先验（如 CRP）来约束生成的连贯性。
## 局限与展望论文也坦诚了局限：目前仅依赖推理时的结构推断。未来若能将这些结构化约束融入训练过程（Training-time integration），可能会进一步提升性能。此外，CRP 的参数 α0\alpha_0 ​ 虽然鲁棒，但在极端长文本下可能需要更精细的调节。
总的来说，DyStruct 为扩散语言模型提供了一套优雅且高效的解码范式，证明了 贝叶斯结构化推断 在解决 DLMs 灵活性与连贯性矛盾上的巨大潜力。对于正在探索非自回归生成路线的团队，这是一篇值得深入研读的佳作。
