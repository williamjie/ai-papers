论文 : The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training via Single- and Multi-Teacher On-Policy Agentic Distillation链接 : https://arxiv.org/abs/2607.24720Agent 做长程任务（Long-Horizon Planning）总是“走两步就偏”，我们常归咎于模型不够强或 RL 没调好。但中科院自动化所的这篇论文直接掀了桌子：在可控环境中，他们证明了长程规划能力的获取、塑造和整合遵循一套严格的“物理定律”。
这不仅是理论突破，更是给工程实践的一剂清醒针： 盲目堆数据或无脑上 GRPO 可能正在毁掉你的 Agent。
### 痛点：黑盒训练下的盲目优化现有 Foundation Model 在 OSWorld 等基准测试中，短程任务尚可，长程规划依然拉胯。核心困境在于互联网训练数据不可控且不透明。我们不知道模型是在预训练（Pre-training）阶段就学会了规划，还是在后训练（Post-training）阶段被“激活”的。
这种黑盒状态导致我们无法回答三个致命问题：
- 预训练数据格式、分布和质量如何决定规划上限？
- RL 算法（如 GRPO vs OPD）在什么边界内有效？
- 多教师蒸馏（MOPD）如何整合能力而不发生灾难性遗忘？
### 核心洞察：世界模型是长程规划的“物理引擎”
论文构建了一个可控的多轮环境（Planning Gym），通过合成数据精确控制任务长度、数据质量和规划模式。
1. 预训练阶段：显式世界模型碾压直接预测直觉上，直接输出动作序列（Direct Action Prediction）应该更高效。但实验显示，通过思维链（Chain-of-Thought, CoT）显式构建状态转移的世界模型，泛化能力更强。
⚠️ 反直觉发现 ：直接回答收敛更快、Token 预算更低，但在长程任务上存在严格的上限瓶颈。引入世界模型后，中长程任务的 avg@8 准确率分别提升了 +39.3% 和 +45.8% 。
2. 数据质量陷阱：次优轨迹是毒药预训练数据中难免混杂次优（Suboptimal）轨迹。在短任务中，错误尚可容忍；但在长程决策中，误差会随时间累积并放大。论文指出，少量高质量长程数据比大量原子技能数据更能提升组合泛化能力，而次优轨迹会严重损害长期规划性能。
3. 后训练阶段：OPD 优于 GRPO 的边界在塑造通用规划模式时，论文对比了组相对策略优化（Group Relative Policy Optimization, GRPO）和在线策略蒸馏（On-Policy Distillation, OPD）。
- GRPO 的局限：依赖稀疏奖励分配，梯度方向不一致。
- OPD 的优势：在预训练数据质量低、规划视界长的情况下，OPD 提供了更一致、可靠的更新方向，拥有更宽的“有效区域”。
但在传递特定任务知识（Planning Knowledge）时，若师生模型底层知识冲突，强行蒸馏未见过的多路径知识反而会破坏学生原有的世界模型，导致性能下降。

- 清洗次优数据：在 Agent 预训练中，务必过滤掉逻辑错误或路径冗余的次优轨迹。它们在长程任务中的负面放大效应远超想象。
- 后训练算法选择：如果你的预训练数据不够干净，或者任务视界很长，优先尝试 OPD 而非 GRPO。OPD 的稠密监督能提供更稳定的梯度方向。
- 多教师蒸馏警惕冲突：在使用 MOPD 整合多个 Agent 能力时，先分析规划模式是否共享。完全冲突的模式会导致严重的灾难性遗忘，此时应放弃合并或进行解耦训练。
### 局限与展望该研究基于合成环境（Synthetic Environments），虽然控制了变量，但真实世界的噪声和非结构化程度远高于此。如何将这套“物理定律”迁移到开放域的真实 Agent 训练中，是下一步的关键。
