# 答案对了引用错了？CiteVQA 揭示 MLLM 归因幻觉

**日期**: 2026-05-18

---

论文 : CiteVQA: Benchmarking Evidence Attribution for Trustworthy Document Intelligence链接 : https://arxiv.org/abs/2605.12882在金融审计、法律咨询或医疗诊断等高风险领域，一个常见的误区是：只要模型给出的最终答案正确，推理过程就可以忽略。然而，北京大学与上海人工智能实验室最新发布的 CiteVQA 基准测试狠狠打脸了这种乐观情绪。它揭示了一个令人不安的现象： 多模态大语言模型（MLLMs）普遍存在“归因幻觉”（Attribution Hallucination） ——它们能给出正确答案，却经常将依据锚定在完全错误的文档区域。对于依赖可追溯性的工程落地而言，这是一个巨大的隐患。
### 现有评估体系的盲区传统的文档视觉问答（Doc-VQA）评估，如 DocVQA 或 InfoVQA，几乎完全聚焦于最终答案的准确率（Answer Accuracy）。这种“只看结果”的评估方式掩盖了模型的黑盒逻辑。模型可能凭借预训练知识“猜”出答案，或者在长篇文档中错误地引用了无关段落。在需要严格证据链的场景下，这种“伪忠实”行为是不可接受的。CiteVQA 的核心动机就是填补这一空白，强制模型在回答问题的同时，提供元素级（Element-level）的边界框（Bounding Box）引用。
### 核心设计：自动化标注与 SAA 指标构建这样一个细粒度引用数据集极其困难，人工标注成本高昂且一致性差。CiteVQA 的创新在于其 自动化标注流水线 。
- 证据消融（Evidence Ablation）：这是确定“关键证据”的核心 Insight。系统利用 MinerU 解析文档获取 OCR 文本和边界框，然后使用强大的 MLLM 作为 Agent 进行探索。为了验证某个边界框是否为核心证据，系统会逐个遮挡（Mask）这些元素并重新提问。如果遮挡后模型无法得出正确答案，该元素即被标记为“关键证据”。这种方法有效规避了主观偏差，确立了科学的评估基准。
- 严格归因准确率（Strict Attributed Accuracy, SAA）：这是 CiteVQA 的核心评估指标。只有当模型的答案正确且引用的证据区域准确（IoU ≥ 0.5 且相关性评分 ≥ 4）时，该样本才计为得分。这比单纯的答案准确率苛刻得多。
### 实验结果：开源模型的“悬崖式”差距论文对 20 个主流 MLLM 进行了全面审计，结果令人震惊。即使是最顶尖的闭源模型，其 SAA 分数也远低于答案准确率，揭示了严重的归因缺陷。

### 工程启示与局限对于工程师而言，CiteVQA 提供了明确的警示：
- 不要盲目信任开源小模型：在涉及合规、审计的场景中，SAA 低于 25% 的开源模型（如 Qwen3-VL-8B）存在极高的误引风险，直接部署可能导致严重的业务事故。
- 归因是推理的基础：论文发现，当证据质量（Recall/Relevance）提升时，答案准确率也随之上升（图 6）。这表明精确的证据定位不仅是事后解释，更是复杂推理的功能性基础。
- 多文档场景仍是瓶颈：在涉及多个黄金文档（Multi N-Gold）的场景下，所有模型的 SAA 均显著下降。跨文档的证据链接和空间导航仍是 MLLM 的短板。
CiteVQA 不仅是一个基准，更是一套“听诊器”。它迫使开发者从追求“答案正确”转向追求“过程可信”。在可解释性成为刚需的今天，解决“归因幻觉”将是下一代文档智能系统的核心战场。
