# ⭐⭐ 低资源医疗LLM：如何学会推荐与适时放弃

**日期**: 2026-07-07

---

论文 : Teaching LLMs to Recommend and Defer in Underrepresented Epilepsy Care链接 : https://arxiv.org/abs/2606.31036在医疗 AI 领域，我们常陷入一个误区：认为只要模型参数够大、医学知识够全，就能解决所有临床问题。这篇论文用乌干达癫痫治疗的真实数据打脸了这个假设： LLM 的失败往往不是因为“不懂医学”，而是因为“不懂当地” 。更关键的是，它展示了一种无需微调（Fine-Tuning）、仅靠提示词记忆（Prompt Memory）就能让 LLM 适应本地处方习惯，并具备“知难而退”能力的方法。
### 痛点：西方先验 vs. 本地现实现有的医疗 AI 基准测试大多基于高收入国家的数据（如 MIMIC-IV），药物可及性、成本和随访规范与中低收入国家（LMICs）截然不同。
作者发现，直接使用 LLM 进行零样本提示（Zero-shot Prompting），虽然能与医生处方达成一定的一致性，但神经科医生的审计显示， 错误主要源于模型应用了西方的处方先验（Prescribing Priors），而非缺乏医学知识 。
⚠️ 核心洞察 ：在资源受限场景下，LLM 的适配问题不是“知识检索”，而是“分布校准”。你需要让模型学会当地的用药逻辑，而不是背诵教科书。
### MANANA：不更新权重的“提示词学习”
为了解决这个问题，作者提出了 MANANA ，一个非参数化的提示词学习框架。它不更新模型权重，而是通过维护一个可审计的“提示词记忆”来适应本地数据。
MANANA 采用多智能体架构，核心逻辑非常清晰：
- 预测者（Predictor）：基于当前记忆状态，生成 3 个候选处方。
- 检查员（Inspector）：对比模型预测与医生实际处方，生成结构化错误报告和“候选教训”（Candidate Learnings）。
- 架构师（Architect）：这是最关键的角色。它不会立即采纳每一个教训，而是将教训存入只追加的证据缓冲区。只有当某个教训在不同患者中反复出现时，架构师才会将其固化为新的记忆规则或专家智能体指令。
这种设计避免了传统提示词优化方法（如 TextGrad）容易产生的“过拟合单个案例”的问题。 MANANA 学习的是跨患者的普遍模式，而非个案的特例。
### BPA：让模型学会“说不”
在医疗场景中， 知道何时该放弃（Defer）比盲目自信更重要 。稀缺的专家资源应该集中在模型最不确定的病例上。
作者提出了 贝叶斯提示词平均（Bayesian Prompt Averaging, BPA） 。它将学习过程中产生的不同记忆状态视为一个集成模型（Ensemble），通过验证集上的表现计算每个状态的权重，从而输出处方的概率分布。
这不仅提高了准确率，更关键的是生成了 置信度信号 ，实现了选择性预测（Selective Prediction）：
- 高置信度病例：系统自动处理，无需专家介入。
- 低置信度病例：标记并转交专科医生复核。
### 实验结果：数据说话作者在两个独立的乌干达癫痫队列（Cohort A 和 B）上进行了测试。主要指标是 Top-3 精确匹配率（EM@3），即模型推荐的三个处方中是否包含医生的实际处方。

### 工程启示- 本地化适配无需微调：对于数据量小、隐私敏感的场景，基于提示词记忆的非参数化学习（Non-parametric Prompt Learning）是一个极具性价比的方案。它保留了模型通用能力，同时注入了本地规则。
- 可审计性至关重要：MANANA 生成的记忆是文本形式的规则或专家指令，医生可以审查这些“学到的知识”，这在医疗合规中是巨大的优势。
- 不确定性即功能：不要只追求准确率。在资源受限系统设计中，置信度估计和拒绝机制（Deferral Mechanism） 是核心功能之一。BPA 提供了一种利用模型内部轨迹进行不确定性量化的实用路径。
### 局限与展望论文也坦诚了局限性：当前的 BPA 置信度是基于历史数据的回顾性评分，尚未在真实部署中验证其作为动态拒绝阈值的稳定性。此外，模型学习的是“符合当地习惯”的处方，这既包括临床判断，也包括资源限制（如药物短缺）。未来需要进一步分析这些学到的规则是否真正反映了最优临床路径，还是仅仅复制了资源约束下的妥协。
对于工程师而言，这篇论文提供了一个清晰的范式： 在垂直领域落地 LLM，不仅要让它“答对”，更要让它“懂行”且“知止”。
