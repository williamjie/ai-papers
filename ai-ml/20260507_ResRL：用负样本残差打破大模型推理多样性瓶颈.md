# ResRL：用负样本残差打破大模型推理多样性瓶颈

**日期**: 2026-05-07

---

论文 : ResRL: Boosting Reasoning via Negative Sample Projection Residual Reinforcement Learning链接 : https://arxiv.org/abs/2605.00380在强化学习验证奖励（RLVR）成为大模型推理增强的主流范式后，我们面临着一个尴尬的 trade-off：Pass@1（单次生成准确率）上去了，但 Pass@k（多次采样多样性）却掉了。DeepSeek-R1 带火的 GRPO 虽然高效，但容易引发模式崩溃（Mode Collapse）。这篇来自美团和中科院的 ResRL 论文，没有继续卷奖励函数本身，而是把刀口切向了“负样本梯度干扰”这个更底层的几何问题。
### 痛点：为什么 NSR 还不够好？
为了解决 GRPO 多样性差的问题，Negative Sample Reinforcement (NSR) 出现了。它的逻辑很直接：既然正样本奖励高，那就加大负样本的惩罚力度，强行压制错误路径。
但 ResRL 作者敏锐地发现，NSR 有一个致命缺陷： 语义重叠导致的梯度冲突 。
在推理过程中，正确的答案和错误的答案往往共享大量的前缀、语法结构甚至部分推理步骤。当 NSR 对负样本进行高强度惩罚时，它实际上是在惩罚这些“共享的语义分布”。这就好比你因为学生做错了最后一步，却把他前面正确的推导过程也一并抹杀掉。这种“误伤”导致了 Lazy Likelihood Displacement (LLD) 现象，即模型为了规避惩罚，反而不敢探索那些与正样本语义相近但尚未验证的路径，最终导致搜索空间过度收窄。
### 方法拆解：正交投影，只罚“异类”
ResRL 的核心 Insight 非常优雅： 只惩罚那些偏离正样本语义空间的负样本成分，保留重叠部分的语义。
具体怎么实现？作者引入了一个基于 SVD 的低秩正分子空间（Positive Subspace）概念：
- 构建正样本空间：提取正样本（高奖励回复）的隐藏层状态，通过中心化处理后，计算其主成分方向（Top-k Principal Directions），构成正样本的子空间 SS。
- 计算投影残差：对于负样本中的每一个 token，计算其隐藏状态 x−x^- 在正样本空间 SS 上的投影残差 Ri,tR_{i,t}​。
如果负样本 token 与正样本语义高度重合（即投影后残差很小），说明它可能是正确推理的一部分，只是最终结果错了，或者它本身是中性词。此时，降低对其的梯度惩罚权重。
- 如果负样本 token 远离正样本空间（残差很大），说明它是真正的“错误噪音”或“胡言乱语”。此时，给予更大的惩罚权重。
- 保守的重加权：利用这个残差动态调整负样本的 Advantage 权重。公式上，这相当于对输出头梯度内积中的表示项（Representation Component）进行了上界约束，从而从理论上缓解了 LLD。
这里有个工程上的巧思：为了节省算力，作者没有使用所有正样本，而是采样了一部分进行截断 SVD，并用分位数归一化来稳定权重分布。
### 关键结果：不仅准，而且多ResRL 在 12 个基准测试上全面超越了 GRPO 和 NSR。数据非常硬核：
数学推理（Qwen3-4B 基座）：
- Avg@16：ResRL 达到 57.0%，超越 NSR 的 53.6%（+3.4%），超越 FlowRL 的 46.2%。
- 高采样表现：在 AIME24/25 和 AMC23 上，ResRL 的 Pass@128 平均比 NSR 高出 7.0%，Avg@16 高出 9.4%。这直接证明了它在保持高准确率的同时，显著提升了多样性。
代码生成（Qwen3-34B 基座）：
- CodeForces：Rating 达到 1469.5，比 NSR 的 1340.9 高出 9.6%，百分位提升 13.9%。
- LiveCodeBench：Pass@16 达到 59.9，优于 NSR 的 52.3。
Agent 与函数调用：
- ALFWorld：成功率 86.7%，比 EMPG 高出 10.4%。
- BFCL (函数调用)：多轮整体准确率 41.25%，比 ResT 高出 2.8%。
### 工程启示- 不要盲目加大负样本权重：简单的 upweighting 会破坏语义结构。ResRL 告诉我们，应该通过表征几何（Representation Geometry）来区分“坏样本中的好部分”和“坏样本中的坏部分”。
- SVD 低秩近似是性价比之王：在 RL 训练中引入全量 SVD 计算量太大，但采样 + 低秩近似既能捕捉主要语义方向，又能将计算开销控制在可接受范围。
- KL 惩罚可以弱化：实验显示，在 ResRL 框架下，移除 KL 正则化反而能让模型在 AIME24 上提升 9% 的准确率，因为投影残差本身起到了隐式的正则化作用，防止了梯度爆炸，允许模型更自由地探索长程推理路径。
### 局限与展望ResRL 依赖于隐藏层状态的稳定性。论文消融实验指出，如果层归一化（LayerNorm）或中心化处理缺失，优化会迅速崩溃。这意味着该方法对模型架构的微小变化比较敏感。此外，秩 kk 的选择需要在“保护语义”和“区分错误”之间做权衡，过大或过小都会影响效果，需要针对具体任务进行调优。
总的来说，ResRL 为 RLVR 提供了一个更精细的梯度控制视角。它不再把负样本视为一个整体去惩罚，而是像手术刀一样，剔除其中的噪声，保留其潜在的语义价值。这对于追求高可靠性和多样性的工业级推理模型落地，具有重要的参考价值。
