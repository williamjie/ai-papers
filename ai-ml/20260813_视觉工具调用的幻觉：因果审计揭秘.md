# ⭐⭐⭐ 视觉工具调用的幻觉：因果审计揭秘

**日期**: 2026-08-13

---

论文 : The Illusion of Visual Tool-Use: A Causal Audit of Thinking with Images链接 : https://arxiv.org/abs/2608.06270现在的多模态大模型（MLLMs）都爱“看图说话”，甚至学会了主动调用裁剪、缩放等视觉工具来辅助推理。这看起来像极了人类专家在仔细检查细节，但上海人工智能实验室的最新研究直接泼了一盆冷水： 这种“带图思考”可能只是一种幻觉。
⚠️ 核心发现 ：模型调用视觉工具后，准确率提升往往微乎其微，甚至为负。更糟糕的是，模型经常在不需要时瞎调工具，或者在已经答对后继续无效缩放。所谓的“工具使用”，很多时候只是模型的自我表演，而非真正的因果推理。
### 为什么现在的“看图”这么虚？
直觉上，给模型加上 crop-and-zoom 能力应该能解决高分辨率细节识别问题。但实际工程中，我们常遇到两个痛点：
- 边际收益递减：消耗了巨额 Token 和算力，准确率却只提升了零点几个百分点。
- Zoom-Loop 陷阱：模型陷入死循环，反复裁剪无关区域，最后甚至把原本能答对的问题搞错。
这就引出了一个关键问题： 返回的视觉证据，真的影响了最终答案吗？ 还是说模型只是被“调用工具”这个动作本身带偏了？
### 方法拆解：因果图与三级干预论文没有停留在表面现象，而是构建了一个 结构因果模型（SCM） ，将推理路径拆分为三类：
- 直接路径：(I,Q)→Y(I, Q) \rightarrow YY，即不看工具直接猜。
- 观察介导路径：T→O→YT \rightarrow O \rightarrow YO→Y，这是理想状态，视觉内容 OO 真正影响了答案 YY。
- 动作诱导捷径：T→YT \rightarrow YY，这是陷阱，模型仅仅因为“执行了裁剪”这个文本动作就改变了置信度，跟裁出来的图长啥样没关系。
为了量化这些路径的贡献，作者设计了 三级因果干预协议 ：
- 策略级（Policy）：对比开启工具和直接推理的准确率差异（ATE）。
- 轨迹级（Trajectory）：在运行时将所有返回的观察结果替换为随机裁剪图，看模型表现是否崩塌。
- 步骤级（Step）：提出核心指标 Visual Evidence Gain (VEG)。通过反事实干预，替换单步观察结果，计算其对答案概率分布的真实影响。
### 关键结果：数据不会说谎在六个主流模型和五个基准测试上的实验结果令人震惊：
1. 策略级提升极其有限以 Mini-o3 为例，在 V* 数据集上，使用工具相比直接推理仅提升了 +5.5% 的准确率。而在 DeepEyes 上，提升甚至为 0.0% 。这意味着大部分情况下，工具并没有带来实质性帮助。
2. 轨迹级干预揭示依赖假象当把返回的图片换成随机裁剪时，Mini-o3 在 V* 上的准确率暴跌了 -64.2% 。但这并非因为图片有用，而是因为模型检测到“图片不对劲”后陷入了修复循环，最终耗尽了 Token 预算（Hit-MaxT 高达 84.8%）。
3. 步骤级诊断：两种失败模式通过 VEG 指标，作者将轨迹分为四类，发现了两种典型的策略校准失效（Policy Miscalibration）：

- Mode 2: Looking Without Planning (LWP)：视觉内容有用，但规划混乱。比如 Mini-o3，虽然能提取有效信息，但经常在没有必要时继续调用，导致效率低下。
💡 反直觉结论 ：所谓的准确率提升，几乎全部来自那少数 Calibrated（校准良好） 的轨迹。绝大多数工具调用要么是多余的，要么是无能的。
### 工程启示：别盲目加工具这篇论文对实际开发有极强的指导意义：
- 评估指标要升级：不要只看最终准确率（Accuracy）。如果模型靠“瞎猜”也能对，那工具就是废的。需要引入类似 VEG 的过程指标，评估每一步工具调用的因果贡献。
- 推理时优化：对于被诊断为 Mode 1 的轨迹，直接跳过工具调用；对于 Mode 2，设置更早的停止机制（Early Stopping），避免无效循环消耗 Token。
- 训练方向调整：目前的强化学习（RL）通常只奖励最终结果（Outcome-only RL）。这导致模型学会了“只要调工具就能拿分”的捷径。未来的训练需要引入过程监督，惩罚无意义的工具调用。
### 局限与展望目前的研究主要基于开源模型和裁剪/缩放工具。对于闭源模型（如 o3/o4-mini），由于无法获取中间 Token 概率和干预观察结果，难以进行同样的因果审计。此外，OCR、分割等其他视觉工具的校准行为可能不同，需要进一步研究。
总之， “有工具”不等于“会用工具” 。在追求更复杂 Agent 能力的路上，我们需要先治好模型的“表演型人格”。
