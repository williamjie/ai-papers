# VideoSeeker：让模型学会主动“看”视频

**日期**: 2026-05-19

---

论文 : VideoSeeker: Incentivizing Instance-level Video Understanding via Native Agentic Tool Invocation链接 : https://arxiv.org/abs/2605.16079现在的视频大模型（LVLM）有个尴尬的痛点：你让它描述视频，它给你一篇流水账；你让它找特定目标，它只能靠你写长篇大论的文字描述去猜。这种“盲猜”模式在长视频或多目标场景下，体验极差。
VideoSeeker 这篇论文提出了一种更直观的范式： 视觉提示（Visual Prompts）+ 智能体主动感知（Agentic Tool Invocation） 。简单说，就是允许用户直接框选视频帧中的目标，并让模型像人一样，主动调用工具去“拉近镜头”或“回看细节”，而不是被动地一次性吞下所有帧。
## 为什么现有方案不够用？
目前主流的 LVLM 视频理解存在两个核心缺陷：
- 感知与推理脱节：模型通常采用单次均匀采样（Single-pass uniform sampling），被动接收视觉信息。这导致模型无法主动捕捉关键证据，容易在长视频中产生幻觉。
- 交互效率低：现有的 Benchmark 和任务主要依赖纯文本查询。要定位视频中“穿黑衣服的第二个人”，用户必须用复杂的语言描述，既难写又易歧义。
VideoSeeker 的核心 Insight 在于： 将视觉提示作为查询入口，并通过工具调用实现“全局浏览 -> 局部细读”的认知循环。
## 方法拆解：从数据到训练### 1. 全自动数据合成流水线实例级视频数据稀缺，作者构建了一个四阶段全自动流水线：
- 低耗文本过滤：用轻量级 LLM 快速筛选出针对具体实体的 QA 对。
- 视频级验证：利用强大的视频模型（如 Gemini-3.1-Pro）验证目标唯一性，并生成语义标签。
- 像素级掩码生成：集成 SAM3 进行文本驱动的视频分割，生成精确的像素级 Mask。
- 渲染与重写：将 Mask 渲染为多种视觉提示（框、点、掩码），并改写 QA，使其依赖视觉提示而非纯文字描述。
### 2. 双阶段训练策略- SFT 冷启动：使用 34.2k 条高质量多轮工具调用轨迹进行监督微调（Supervised Fine-Tuning），让模型学会基本的工具调用格式和主动感知模式。
- Agentic RL 强化学习：采用 GRPO 算法进行强化学习。模型作为 Agent，自主决定何时查看视觉提示、何时裁剪视频片段。
奖励函数设计是亮点 ，包含三个维度：
- 答案准确性：由 Judge LLM 打分（1/0.5/0）。
- 格式合规性：确保输出结构符合解析要求。
- 简洁性（Parsimony）：惩罚过多的工具调用，鼓励模型用最少的步骤完成任务。
## 关键结果：超越闭源模型在专门针对实例级视频理解的 V2P-Bench 上，VideoSeeker 的表现令人印象深刻：
模型 Agent 模式 平均得分 (Avg.) 相比基线提升 GPT-4o ✗ 58.6 - Gemini-2.5-Pro ✗ 59.5 - Qwen3-VL-8B (Baseline) ✗ 60.8 - VideoSeeker-8B ✓ 74.5 +13.7%- VideoSeeker-8B 在 V2P-Bench 上平均提升了 +13.7%，全面超越了 GPT-4o 和 Gemini-2.5-Pro。
- 泛化能力强：尽管仅在实例级任务上训练，VideoSeeker 在通用视频基准（Video-MME, LongVideoBench, LongVT）上也实现了平均 +3.2% ~ +3.3% 的提升。
消融实验揭示的关键发现：
- 工具协同效应：单独使用 view_visual_prompt 或 crop_video 都有提升，但两者结合带来了超过单独贡献之和的收益。
- 奖励 hacking 陷阱：在多选题（MC）数据上进行 RL 训练会导致模型通过随机猜测获得高分，性能反而下降至 43.8%；而开放端（OE）训练配合 LLM Judge 更稳健，达到 74.5%。
- 教师模型悖论：更强的教师模型（如 Qwen3-VL-235B）并不总是带来更好的学生，异构蒸馏中模式差异过大会导致知识迁移效率降低。
## 工程启示- 视觉提示是未来交互趋势：对于需要精确定位的任务，让用户画框或点选比写 Prompt 更高效。工程上可考虑在 UI 层集成简单的标注工具。
- RL 奖励设计需警惕 Hacking：不要盲目使用选择题数据进行 RLHF/RLAIF，开放生成配合语义判断更可靠。
- 主动感知降低推理成本：VideoSeeker 通过稀疏的工具调用，避免了全视频帧的高昂计算开销。Figure 5 显示其推理延迟显著低于基线模型，这对部署成本敏感的应用极具价值。
- 数据合成自动化：利用 SAM3 等分割模型自动化构建实例级数据集，是低成本提升模型细粒度能力的可行路径。
## 局限与展望- 依赖外部工具：虽然推理效率提升，但多轮工具调用引入了额外的网络或计算延迟，需平衡实时性。
- 教师模型选择敏感：异构蒸馏的效果受教师-学生架构差异影响较大，需进一步探索更鲁棒的蒸馏策略。
VideoSeeker 证明了“主动看”比“被动读”更有效。对于需要高精度时空定位的视频应用，这种 Agentic 范式值得深入探索。
