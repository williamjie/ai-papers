# LLM进化搜索：好优化器的秘密

**日期**: 2026-04-22

---

论文 : What Makes an LLM a Good Optimizer? A Trajectory Analysis of LLM-Guided Evolutionary Search链接 : https://arxiv.org/abs/2604.19440我们都在用 LLM 做进化搜索——提示词优化、公式发现、启发式算法设计。但你有没有发现：同一套进化框架，换几个模型，效果天差地别？这篇论文回答了那个扎心的问题： 为什么零样本能力差不多的模型，在进化搜索中表现能差出天际？
他们跑了 15 个模型、8 个任务、72K 个候选解，结论有点反直觉。
## 问题：进化搜索的”黑箱”
现在把 LLM 嵌入进化循环已经很常见了。选精英、LLM 变异、评估适应度，一套下来确实能提升效果。但问题在于—— 我们不知道到底是什么在驱动这些提升 。
更具体地说，即使严格控制进化循环、选择规则和评估函数，不同 LLM 诱导的搜索轨迹和最终结果差异巨大。图 1 就给了一个经典案例：Gemini-1.5-Pro 和 Mistral-7B-Instruct 在 TSP-60 上的零样本性能差不多，但进化后 Gemini 持续改进、搜索逐渐收敛，而 Mistral 一直在语义空间里漂移，偶尔有点新意但就是不能转化为适应度提升。
这就引出了核心问题： LLM 的优化能力，到底取决于什么？
## 核心发现一：零样本能力只解释了一部分方差论文首先验证了直觉假设——零样本能力（zero-shot performance）强的模型，进化结果也应该好。结果如图 3 所示，确实存在正相关，但 解释力不够 。
在零样本分数约 0.4 的区域，一堆模型挤在一起，但进化后的最终性能却 spread 得很开。这说明 基座能力 ≠ 优化器能力 。
## 核心发现二：好优化器是”局部精炼器”
这才是论文最精彩的 insight。
他们定义了一个关键指标—— 突破率（Breakthrough Rate） ，即每一代中产生”优于历史最优解”的 offspring 的频率。结果如图 4 所示：
预测因子 标准化系数 解释力 突破率 (BR) 最大正系数 是零样本能力的 2 倍 零样本能力 (ZS) 正系数 基础但不足 平均新颖度 ≈ 0, 不显著 几乎为零关键结论：好优化器不是靠偶尔的大突破，而是靠频繁、持续的小改进。
这跟经典进化算法的行为完全不同——经典算法是”偶尔大突破 + 长期 plateau”，而强 LLM 优化器是”不断有小进步”。
## 核心发现三：新颖度不必然有益，甚至可能是失败的信号这真的是反直觉。在经典进化算法里，新颖度和多样性被视为探索的信号，越多越好。但在 LLM 引导的进化中， 新颖度与最终性能几乎无关 。
论文在语义空间里做了几何分析。他们用高斯核和熵来量化每一代候选解的分布：
- 空间熵 (Hspatial)：解在语义空间里扩散的程度- 适应度空间熵 (Hfitness)：高质量解是聚集还是分散图 5 的可视化一目了然：强优化器（Gemini-1.5-Pro）的搜索逐渐收敛到一个小区域，且该区域的高适应度解高度聚集；弱优化器（Mistral-7B-Instruct）一直在远处漂移。

## 工程启示### 1. 模型选择：便宜的不一定差图 8 的成本-收益图很有意思。 Mistral-24B-Instruct 在 Pareto 前沿上——用中等成本获得了大幅度的适应度提升。而最强的零样本模型并不一定是最优的搜索算子。
### 2. 训练方向：专精精炼，而非通用能力与其追求通用能力的最大化，不如训练模型做 可靠的局部精炼和错误修正 。论文提到，EvoTune 等工作已经在探索这个方向。
### 3. 系统设计：控制精炼行为精炼行为不是模型自带的固有属性，而是整个 agent 系统的产物——包括 prompt 策略和解码配置。这意味着我们可以通过系统设计来 调控 精炼行为。
## 局限论文也坦诚了一些边界：
- 实验只用了固定的进化协议，选择压力、后代大小等可能影响结果- 新颖度的度量主要基于最近邻距离，可以用更丰富的多样性指标- 模型混合干预不能完全隔离”局部精炼”这一单一因素## 一句话总结好优化器的秘密不在于”想得远”，而在于”走稳”。 在进化搜索中，频繁的小步改进 + 逐渐收敛的搜索，远比漫无目的的大跳跃有效。这或许也适用于我们日常用 LLM 做迭代优化的所有场景。
