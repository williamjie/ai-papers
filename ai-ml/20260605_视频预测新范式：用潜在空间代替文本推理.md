# ⭐⭐⭐½ 视频预测新范式：用潜在空间代替文本推理

**日期**: 2026-06-05

---

论文 : Imagine Before You Predict: Interleaved Latent Visual Reasoning for Video Event Prediction链接 : https://arxiv.org/abs/2606.05769让多模态大模型（MLLM）“预测未来”一直是个硬骨头。现有的主流做法是让模型生成一段长长的文本推理链（Chain-of-Thought），但这在视频场景下往往水土不服：一旦将视觉信息转化为文字，细粒度的运动轨迹、几何关系和交互细节就会大量丢失。
这篇来自上海 AI 实验室等机构的论文提出了 FUTURE-L1 ，核心思路非常反直觉： 别急着把看到的画面翻译成文字，先在潜在空间（Latent Space）里“脑补”出未来的视觉状态，再结合文本进行推理。
### 痛点：文本推理在动态预测中的“有损压缩”
视频事件预测（Video Event Prediction, VEP）要求模型根据前几帧推断接下来发生什么。现有的 Video-CoE 等方法虽然引入了思维链，但本质上是 纯文本的 。
作者指出一个关键问题：视觉证据转化为文字时，发生了严重的语义漂移。例如，“球手有空档”这种描述是合理的，但它丢失了防守球员的具体位置和相对速度。当正确预测依赖这些细微的动态线索时，纯文本推理就会陷入“听起来很有道理，但视觉上完全不对”的幻觉。
### 方法拆解：交织式潜在视觉推理FUTURE-L1 的核心设计在于 交替生成（Interleaved Generation） 。模型在自回归解码过程中，不再只输出离散的文字 Token，而是可以插入连续的 潜在视觉跨度（Latent Visual Spans） 。
- 动态潜在预算：模型遇到 <|latent_start|> 时，进入潜在空间模式。此时输出的不是文字，而是隐藏状态向量 hth_t​，这些向量被直接注入 KV Cache 作为后续推理的输入。
- 视觉增益数据筛选（Visual-Gain Curation）：这是工程落地的关键。作者从 TwiFF-2.7M 数据集中筛选出那些“提供未来帧提示能显著提升预测准确率”的样本，构建了 FUTURE-L1-50K。这确保了模型学习的是真正有用的视觉推理，而不是无效的信息堆砌。
- LA-DAPO 强化学习：在监督微调（SFT）之后，引入了一种潜感知强化学习目标。它包含两个关键奖励：
结果对比奖励（Outcome-Contrastive）：让预测正确的潜在轨迹相互靠近，错误的远离。
- 时间多样性奖励（Temporal-Diversity）：防止模型在不同步骤重复输出相同的潜在状态，强迫它进行动态更新。
### 关键结果：大幅超越纯文本基线实验数据非常硬核，证明了“保留视觉语义”比“强行文字化”更有效。
FutureBench 表现：

经过 LA-DAPO 强化学习后，FUTURE-L1-RL 在 FutureBench 上达到 85.4% ，超越了之前的 SOTA Video-CoE (75.0%) 多达 10.4 个点 。在更难的 3-Hop 和 Interp.（非连续未来状态推理）任务上，提升尤为显著。
### 工程启示：效率与效果的平衡对于工程师来说，这篇论文有两个极具价值的发现：
- 潜在跨度不需要太长：消融实验显示，最大潜在预算 Lmax=4L_{max}=4​=4 时效果最佳。当 LmaxL_{max}​ 增加到 64 时，准确率反而下降至 67.4%。这说明短而精的视觉更新优于冗长的潜在推理，工程实现上计算开销可控。
- 推理效率极高：FUTURE-L1-RL 平均每个样本仅使用 195.3 个 Token，延迟仅为 0.91 秒。相比之下，Video-R1 需要 398.5 个 Token 和 3.28 秒，Video-o3 更是高达 25.90 秒。这意味着我们可以在更低延迟的情况下获得更高的预测准确率。
### 局限与展望虽然效果显著，但该方法目前依赖于 Qwen3-VL 等特定架构的潜在空间对齐。此外，TwiFF-Bench 上的 CoT 分数略有下降（从 2.75 降至 2.62），说明模型在生成人类可读的解释性文字上可能有所妥协，更侧重于内部视觉状态的准确性。
总体而言，FUTURE-L1 为视频理解提供了一个新范式： 语言负责组织逻辑，潜在空间负责保留动态细节。 对于需要高精度动作预测或未来场景生成的 Agent 应用，这是一个值得深入探索的方向。
