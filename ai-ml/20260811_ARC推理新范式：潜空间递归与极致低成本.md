# ⭐⭐⭐⭐ ARC推理新范式：潜空间递归与极致低成本

**日期**: 2026-08-11

---

论文 : BDH-CQ: In-Context Learning with Recurrent Latent Reasoning链接 : https://arxiv.org/abs/2608.09888在 ARC-AGI 这种硬核视觉推理任务上，我们通常认为“大力出奇迹”：要么堆参数，要么靠 CoT（Chain-of-Thought）让模型多写点废话来凑算力。但 Pathway 团队这篇论文扔出了一个反直觉的结果： 1.5 亿参数的模型，单题成本不到 0.001 美元，却打破了 ARC-AGI-1 的成本-准确率帕累托前沿。
这不仅仅是省钱，它挑战了当前大模型推理的一个核心假设：中间推理过程必须被“语言化”。
### 为什么现有的 CoT 不够好？
现在的 LLM 做复杂任务，基本套路是 In-Context Learning（上下文学习）加上 CoT。
演示样例告诉模型做什么，生成的中间 Token 充当计算草稿纸。
但这有个致命伤： 串行叙事 。
每一个中间状态都要投影到离散词表，自回归生成，再被模型读回来。这导致 Token 消耗、延迟和推理算力随着推理深度线性甚至指数级增长。
BDH-CQ 的核心 Insight 是： 人类的抽象概念推理和语言表达可能是两个系统。
既然不需要向用户解释每一步，为什么非要让模型把中间状态“说”出来？如果能在连续的高维潜空间里直接迭代计算，只输出最终答案，效率会不会高几个数量级？
### 方法拆解：记忆与计算的解耦BDH-CQ 没有沿用 Transformer 的自回归生成模式，而是基于他们之前的 BDH（Dragon Hatchling）架构，设计了一套**递归潜空间推理（Recurrent Latent Reasoning）**机制。
其核心设计在于将“学习规则”和“执行计算”在时间轴上解耦：
-演示阶段（更新记忆）：
输入演示样例 DD，模型不生成任何 Token，而是通过线性注意力机制更新一个递归记忆状态 StS_t​。
St=Uθ(St−1,Dt)S_t = U_\theta(S_{t-1}, D_t)​=Uθ​(St−1​,Dt​)
这一步相当于把任务规则“写”进模型的短期记忆里，而不是靠注意力缓存去硬背。
-推理阶段（潜空间迭代）：
拿到查询输入 x∗x^* 后，模型初始化一个潜空间工作区 H0H_0​。
接着，它在高维连续空间里进行 RR 次迭代计算：
Hr+1=Fθ(Hr,SK)H_{r+1} = F_\theta(H_r, S_K)​=Fθ​(Hr​,SK​)
注意，这里没有 Token 生成。 模型只是在内部状态向量之间做变换，探索多条可能的解法路径。
-解码阶段（一次性输出）：
只有当迭代结束（达到 HRH_R​），模型才将最终状态解码为答案 y^\hat{y}^​。
这种设计的工程价值巨大： 它把推理从“生成 N 个 Token”变成了“执行 R 次矩阵乘法”。 对于视觉变换类任务，连续状态的表达能力远超离散 Token 的拼接。
### 关键结果：性价比的降维打击在 ARC-AGI-1 公开测试集（400 题）上，BDH-CQ 的表现令人印象深刻：
指标 BDH-CQ (150M) GPT-5.6 Luna (Low) Pass@2 准确率 29.5% 34.2% 单题成本 $0.00070 $0.040 相对成本优势 - 约 57 倍更便宜⚠️ 反直觉发现 ：即使 OpenAI 在 2026 年 7 月将 GPT-5.6 Luna 的 API 价格下调 80%，BDH-CQ 依然比它便宜约 11 倍。
更重要的是，这种低成本不是通过牺牲精度换来的“垃圾结果”。独立审计（Bielik AI 和 NYU）在盲测中复现了 29.5% 的 Pass@2 分数，证明了其有效性。
### 能力边界：它能学什么，不能学什么？
论文并没有止步于刷榜，而是通过 ConceptARC 数据集做了精细的能力画像。这给工程师提供了宝贵的调试直觉：
-强项：边界传播与复制在“延伸到边界”和“复制到锚点”任务中，模型在测试范围内的准确率高达 48/48。这说明潜空间迭代非常擅长处理具有明确几何规律的空间变换。
-弱项：排序与嵌套当任务涉及“对 8 个对象排序”或“5 层嵌套包含”时，准确率断崖式下跌（排序长度 8 时 Pass@2 仅为 1/24）。
-关键归因：是算不出来，还是没看懂？
通过控制变量实验发现，如果在演示样例中增加与测试难度匹配的样本（Support Context），5 层嵌套的准确率从 19/24 提升到 24/24。
结论：模型在复杂嵌套上的失败，主要源于上下文覆盖不足导致的泛化失效，而非潜空间计算能力的硬性瓶颈。
### 工程启示对于正在构建 Agent 或本地推理服务的工程师，BDH-CQ 提供了三个重要参考：
- 潜空间迭代是 CoT 的廉价替代品：在处理结构化、规则明确的任务（如数据清洗、代码转换、逻辑谜题）时，不要盲目增加 Token 预算。探索基于 Hidden State 反馈的非语言化推理路径，可能带来百倍的成本优化。
- 上下文质量 > 模型规模：在 In-Context Learning 中，演示样例的分布覆盖度直接决定了模型的泛化上限。对于复杂任务，精心构造 Few-Shot 示例比单纯增加模型参数更有效。
- 架构多样性：Transformer 不是唯一解。BDH 这种基于局部交互、稀疏激活和递归状态的架构，在特定推理场景下展现出优于标准 LLM 的能效比。未来可能会出现“语言模型负责沟通，潜空间模型负责计算”的混合架构。
这篇论文证明，在推理效率的尽头，可能不需要更多的语言，而是更深的状态迭代。
