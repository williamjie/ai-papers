# ⭐⭐ 抛弃 Token：用函数算子重构注意力机制

**日期**: 2026-06-05

---

论文 : Functional Attention: From Pairwise Affinities to Functional Correspondences链接 : https://arxiv.org/abs/2605.31559如果你正在处理偏微分方程（PDE）求解、物理仿真或连续场建模，这篇论文值得你停下来读一读。它挑战了 Transformer 架构的一个核心假设：我们真的需要把连续函数离散化成 Token 再计算注意力吗？作者给出的答案是否定的，并提出了一种基于“函数对应”的注意力机制，在保持精度的同时实现了分辨率不变性。
### 现有方案的痛点传统的神经算子（Neural Operator）方法如 FNO 依赖傅里叶基，这要求输入必须是规则的笛卡尔网格，且假设周期性边界条件。一旦遇到复杂几何形状或非结构化网格，FNO 就束手无策。
另一方面，基于 Transformer 的方法（如 Transolver）虽然灵活，但它们将连续场视为离散 Token 的集合。这种“逐点”处理方式带来了三个致命问题：
- 计算复杂度爆炸：标准注意力机制随采样点数量呈二次方增长 O(n2)O(n^2))。
- 忽略全局结构：Token 之间缺乏内在的物理或几何关联，导致参数冗余。
- 分辨率敏感：模型在训练分辨率之外泛化能力差，无法直接用于不同密度的网格。
### 核心 Insight：从点对点到函数空间Functional Attention (FUNCATTN) 的核心灵感来自几何处理中的“功能映射”（Functional Maps）。
⚠️ 关键直觉 ：不要计算两个点之间的亲和力，而是学习两个函数空间之间的线性算子。
作者认为，注意力的本质不是建立离散样本间的点对应关系，而是在查询空间和键值空间之间建立一个紧凑的线性映射。通过引入自适应基函数（Adaptive Bases），我们将高维的 n×nn \times n n 注意力矩阵压缩为低秩的 k×kk \times k k 算子（其中 k≪nk \ll n n ）。
具体实现上，FUNCATTN 做了两件事：
- 学习自适应基：不再使用固定的傅里叶基，而是通过一个简单的 MLP 和 Softmax 生成数据依赖的基函数。这类似于广义的分片常数元素，能自动适应输入的几何或语义结构。
- 最小二乘求解算子：在谱空间中，通过 Tikhonov 正则化的最小二乘法直接求解从 Key 到 Query 的最优线性映射矩阵 CC。这一步取代了传统的 Softmax 亲和力计算。
这种设计不仅将复杂度降为线性级别，还显式地捕捉了全局依赖关系，且天然具备分辨率不变性。

### 工程启示对于从事科学机器学习（Scientific ML）或物理信息神经网络（PINN）的工程人员，这篇论文提供了两个重要指导：
- 基函数可以学习：不要迷信固定基（如 FFT）。在复杂几何或非结构化数据上，学习数据自适应的基函数能显著提升表达能力。
- 算子比注意力更本质：当处理连续信号时，尝试将问题建模为函数空间之间的映射，而非离散序列的处理。这不仅能降低计算成本，还能获得更好的泛化性能。
### 局限与展望尽管 FUNCATTN 表现出色，但它依赖于最小二乘求解，这在极大规模数据集上可能仍面临内存瓶颈（尽管优于 O(n2)O(n^2) ) ）。此外，自适应基的学习需要额外的 MLP 层，增加了模型参数量。未来如何进一步优化谱空间中的算子估计效率，将是该方向的关键挑战。
