# ⭐⭐½ 字节 Bernini：用 MLLM 做语义规划的视频生成新范式

论文 : Bernini: Latent Semantic Planning for Video Diffusion链接 : https://arxiv.org/abs/2605.22344视频生成领域正在经历从“纯扩散”到“大模型引导”的范式转移。字节跳动最新发布的 Bernini 框架，不仅是一个高性能的视频生成与编辑模型，更提供了一个极具工程价值的架构思路： 让 MLLM（多模态大语言模型）负责“想”，让 DiT（扩散 Transformer）负责“画” 。这种解耦设计解决了传统端到端方案中语义理解与像素渲染互相干扰的痛点，为构建统一的多模态 Agent 提供了参考样板。
### 现有方案的痛点目前的视频生成模型主要分为两类：一类是纯扩散模型（如 Wan、Kling），擅长画质但缺乏复杂的逻辑推理能力；另一类是基于 LLM 的生成方案，往往将文本直接映射到噪声空间，导致长指令遵循和复杂编辑任务表现不佳。核心问题在于，现有的扩散模型难以直接理解“先移除物体 A，再改变背景 B”这种多步因果逻辑，而强行让扩散模型学习语义会导致训练效率低下且泛化能力差。
### 核心 Insight：ViT Embedding 作为语义接口Bernini 的核心创新在于重新定义了 MLLM 与扩散模型之间的“握手协议”。
- 语义规划器（Planner）：不再输出文本或离散 Token，而是直接在 ViT Embedding Space（视觉 Transformer 嵌入空间）中预测目标视频的语义表示。为什么选 ViT？因为 MLLM 本身就在用这个空间理解图像，复用这一表示最小化了适配成本，保留了预训练的知识。
- 掩码生成范式（Masked Generative Modeling）：训练时随机 Mask 部分目标 Token，让 MLLM 根据上下文推理缺失内容；推理时采用迭代式填充（Iterative Refinement），从全 Mask 逐步细化到完整语义图。这比自回归生成更适合视觉数据的并行特性。
- 渲染器（Renderer）：基于 DiT 的扩散模型接收 Planner 输出的语义 Embedding 作为 Cross-Attention 条件，并结合源视频的 VAE 特征以保持细节一致性。
这种设计的妙处在于 解耦 。Planner 和 Renderer 可以独立预训练，最后只需轻量级联合微调。这意味着你可以替换更强的 MLLM 来提升逻辑能力，而不必重新训练庞大的扩散模型。
### 关键技术细节- SA-3D RoPE（分段感知 3D 旋转位置编码）：在处理多模态输入（如参考图+源视频+文本）时，不同段落的 Token 可能共享相同的时空坐标 (t,h,w)(t, h, w)，导致注意力混淆。Bernini 引入了分段索引 ii 作为相位调制，公式为 r~t,h,w,i=rt,h,w⊙riseg\tilde{r}_{t,h,w,i} = r_{t,h,w} \odot r^{seg}_i~t,h,w,i​=rt,h,w​⊙riseg​，有效区分了不同来源的视觉 Token。
- 思维链（CoT）推理：Planner 在输出最终 Embedding 前，先在潜在空间进行推理步骤，显著提升了复杂编辑任务（如“一周后”的时间因果推理）的表现。
### 关键结果：SOTA 性能验证Bernini 在多个基准测试中展现了强大的通用性，特别是在需要逻辑理解的编辑任务上优势明显。

### 工程启示- 模块化架构是趋势：Bernini 证明了“规划-渲染”分离架构的可行性。对于企业级应用，这意味着可以独立升级语义理解模块（如接入更强的 LLM）和画质渲染模块，降低迭代成本。
- 数据构造的关键性：论文详细描述了如何从通用 T2V 语料中构建 2000 万对视频编辑数据，以及如何利用 Image-to-Video 技术合成高质量的视频编辑数据。这提示我们，高质量的多模态对齐数据是训练统一生成模型的核心壁垒。
- 推理效率优化：Planner 的迭代式掩码填充机制虽然增加了推理步数，但每一步都是并行计算，且只需轻量级微调即可适配新任务，适合部署在云端高并发场景。
### 局限与展望尽管 Bernini 表现优异，但其依赖 MLLM 进行语义规划，导致推理延迟高于纯扩散模型。此外，对于极端长视频（>10秒）的一致性保持仍有挑战。未来方向可能包括进一步优化 Planner 的推理速度，以及探索更高效的跨模态对齐表示。
总之，Bernini 不仅是一个强大的视频生成工具，更是多模态大模型与扩散模型融合的一次成功实践，值得工程师深入研读其架构设计与数据构造策略。
