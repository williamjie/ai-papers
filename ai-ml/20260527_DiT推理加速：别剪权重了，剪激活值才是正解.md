# ⭐⭐⭐ DiT推理加速：别剪权重了，剪激活值才是正解

**日期**: 2026-05-27

论文 : RT-Lynx: Putting the GEMM Sparsity In a Right Way for Diffusion Models链接 : https://arxiv.org/abs/2605.26632扩散模型（Diffusion Models）的推理瓶颈一直是工程落地的痛点，尤其是 DiT 架构下，几十步迭代带来的巨大算力开销让人头大。过去大家习惯从量化或蒸馏入手，但阿里团队这篇 RT-Lynx 提出了一个反直觉的思路：别盯着权重剪枝了，去剪激活值（Activation Sparsity）吧。这不仅能让模型“无损”加速，还能带来实打实的性能提升。
### 为什么传统剪枝在 DiT 上失效？
在 LLM 领域，基于权重的半结构化稀疏（如 Wanda、SparseGPT）已经非常成熟。但在 DiT 中，这套逻辑行不通。论文通过实验指出，DiT 的权重分布接近准高斯分布，缺乏天然的稀疏结构。强行对权重进行 2:4 剪枝，会直接破坏模型容量，导致生成质量断崖式下跌。
以 Qwen-Image 为例，原生权重稀疏（Sparse Weight）在 MJHQ 数据集上的 FID 从 21.98 暴涨到 51.63，图像奖励（IR）更是跌穿地心到了 -0.16。即便是最先进的 Wanda 或 Slim 方法，FID 也徘徊在 40 左右，远不如密集模型。
### 核心 Insight：激活值才是“天选之子”
RT-Lynx 的核心发现是：DiT 的 Token 级激活值具有内在稀疏性。由于 Transformer 的叠加机制（Superposition），每个 Token 只激活少量神经元，大量激活值趋近于零。对这些接近零的值进行结构化剪枝，引入的误差远小于权重剪枝。
数据不会撒谎：同样的 2:4 剪枝策略，直接作用于激活值时，FID 仅为 35.85，IR 为 0.5994，虽然仍有损失，但相比权重剪枝已是质的飞跃。这说明激活值更“皮实”，更适合做稀疏化操作。
### RT-Lynx 的工程落地三板斧既然方向对了，怎么解决剩下的精度损失和性能开销？RT-Lynx 给出了完整的工程解法：
- 范数补偿（Norm Compensation）：剪枝会改变激活值的 L2L_2​ 范数，导致信息量衰减。RT-Lynx 在运行时动态计算缩放因子 ss，将稀疏后的激活值重新缩放到原始范数大小。这一步几乎零开销，却大幅缓解了模糊问题。
- 轻量 LoRA 修复：剪掉的小数值虽然多，但包含了高频细节（如发丝、纹理）。论文引入秩为 64 的 LoRA 分支来补偿这些残差。训练只需 2k 步即可收敛，且推理开销极小。
- CUDA 内核融合：这是工程上的亮点。传统的在线稀疏化需要额外的内存搬运和同步，开销高达 40%。RT-Lynx 将 Top-K 选择、压缩和稀疏 GEMM 计算融合在一个 CUDA Kernel 中，利用寄存器级操作生成 2:4 布局，并将稀疏计算与密集 LoRA 计算交错执行，消除了中间存储开销。
### 关键结果：无损加速，还能叠加在 Qwen-Image 上，RT-Lynx 实现了惊人的效果：
- 精度超越原版：FID 降至 21.25（优于原版的 21.98），IR 升至 1.304（高于原版的 1.219）。
- 显著加速：线性层平均加速比达到 1.55x，端到端生成时间从 0.75s 降至 0.62s。
更令人兴奋的是其正交性。RT-Lynx 可以与蒸馏、量化、缓存等技术无缝叠加：
- Z-Image + 8步蒸馏：传统剪枝会导致模型崩溃（FID 360.2），而 RT-Lynx 保持 FID 26.17，端到端加速比从 9.91x 提升至 11.86x。
- Qwen-Image + W8A8 量化：FID 保持在 21.43，端到端加速比从 1.11x 提升至 1.32x。
### 工程启示与局限对于正在优化 DiT 推理的工程团队来说，RT-Lynx 提供了一个明确的信号： 激活值稀疏化是 DiT 加速的新大陆 。它不需要重新训练整个模型，仅需微调少量 LoRA 参数即可部署。
不过，该方法目前主要针对双流 DiT（如 Qwen-Image）效果最佳。对于单流模型（如 FLUX、Z-Image），论文指出需要跳过特定的线性层（如 attn.o_proj ）才能达到最佳效果，这表明不同架构对稀疏化的敏感度仍有差异，后续可能需要更通用的层选择策略。
总之，如果你受够了 DiT 慢如蜗牛的推理速度，不妨试试把目光从权重转向激活值。RT-Lynx 证明了，有时候换个角度，不仅能跑得更快，还能看得更清。
