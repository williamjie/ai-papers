论文 : AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents链接 : https://arxiv.org/abs/2607.02255做长程 Agent 的工程师都知道一个痛点：随着对话轮数增加，上下文窗口像无底洞一样膨胀。传统的“追加历史”方案不仅导致 Token 成本呈二次方增长，更让模型在海量噪声中迷失重点。这篇论文提出了一个反直觉但极具工程价值的思路： 记忆不应是文本堆砌，而应是一份结构化的契约 。
## 现有方案的死胡同目前主流的 Agent 架构（如 ReAct、Reflexion）倾向于将过去的观察、工具调用和反思直接追加到下一个 Prompt 中。这种“无限上下文”模式有两个致命缺陷：
- 注意力稀释：关键信息被淹没在无关的历史记录中，模型难以提取有效信号。
- 不可控增长：Prompt 长度随决策次数线性甚至二次方增加，导致推理延迟飙升且成本高昂。
## 核心 Insight：类型化检索契约 (Typed Retrieval Contract)
AgenticSTS 的核心创新在于彻底摒弃了原始历史追加，转而采用 每次决策时重新组装 Prompt 的策略。它定义了一个包含五个槽位的“有界记忆契约”，每个槽位都有明确的职责和更新机制：
- L1/L2 (固定协议)：不可变的角色指令和状态模式（如战斗、地图探索的法律动作格式）。
- L3 (游戏规则)：可枚举的规则数据（卡牌、遗物、敌人意图），随补丁刷新。
- L4 (情景记忆)：基于案例的回顾，存储对局后的总结（角色×难度×阶段×敌人类型）。
- L5 (战略技能库)：这是最大的亮点。它存储从日志中提炼出的触发式策略指南，具有明确的触发条件和文本策略。
这种设计的精妙之处在于 可消融性 (Ablatability) 。因为上下文是通过命名槽位检索组装的，你可以单独关闭 L4 或 L5，从而精确归因某个性能提升是来自“记住了过去”还是“学会了通用策略”。
## 关键结果：技能层是胜负手论文在《杀戮尖塔 2》(Slay the Spire 2) 这一高难度、长周期的 Roguelike 游戏中进行了验证。以下是固定难度 A0 下的消融实验数据（每组 10 局）：
配置 L5 (技能) L4 (情景记忆) 胜率 平均得分 No Scaffold ❌ ❌ 3/10 70.4 Prompt Only ❌ ❌ 4/10 69.6 Hand Skills (Mode A) ✅ ❌ 6/10 85.5 Template Skills (Mode B) ✅ ❌ 6/10 83.3 Skills + Episodes ✅ ✅ 6/10 82.1⚠️ 反直觉发现 ：在 A0 难度下，添加情景记忆 (L4) 并没有带来额外的胜率提升。真正让胜率从 30% 跃升至 60% 的是 L5 战略技能层 。这说明对于长程任务，提炼出的“通用战术”比“具体回忆”更有价值。
此外，与开源的无限上下文 Agent (STS2MCP, CharTyr) 相比，AgenticSTS 在相同 backbone 下实现了 6/10 的胜率 ，而对手均为 0/5 。更惊人的是效率优势：
- Token 成本：竞争对手每得分点消耗 66-90 倍于 AgenticSTS 的新鲜 Token。
- 推理速度：达到相同楼层数，竞争对手耗时约为 AgenticSTS 的 4 倍。
## 工程启示- 结构化优于堆砌：不要试图让模型自己从几千条历史消息里找重点。显式地定义记忆槽位（如规则、案例、技能），并控制每个槽位的检索量，能显著降低噪声。
- 技能库的价值：L5 层的成功表明，Agent 应该具备将具体经验提炼为可复用策略的能力。这不仅仅是 RAG，更是一种“程序化思维”的体现。
- 解耦接口与状态：通过类型化检索，Prompt 大小保持恒定（约 5k tokens/次），不再随游戏时长爆炸。这使得长程 Agent 在成本和延迟上变得可控。
## 局限与展望论文坦诚地指出，目前的样本量较小（N=10/cell），胜率差异在统计学上尚未达到显著水平 (p ≈ 0.37)。此外，技能库的迁移性依赖于 Backbone，Gemini 训练的技能直接迁移到 Qwen/DeepSeek 时效果不一。未来的方向是建立更严格的对照实验，比较“有界契约”与“无限上下文”在同一代码库下的表现。
总之，AgenticSTS 不仅是一个游戏测试集，更是一种 Agent 记忆架构的设计范式 。它提醒我们：在构建长程 Agent 时，如何组织信息比拥有多少信息更重要。
