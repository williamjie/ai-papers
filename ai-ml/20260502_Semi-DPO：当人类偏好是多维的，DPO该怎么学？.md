# Semi-DPO：当人类偏好是多维的，DPO 该怎么学？

**日期**: 2026-05-02

---

论文 : Learning from Noisy Preferences: A Semi-Supervised Learning Approach to Direct Preference Optimization链接 : https://arxiv.org/abs/2604.24952这篇论文干了一件事：把 Diffusion-DPO 训练中的梯度震荡问题，用半监督学习的方式给治了。
## 问题：为什么 DPO 越学越晕？
先说背景。Diffusion-DPO 是直接把 LLM 的 DPO 搬到文生图模型上，核心思想是：给定一对图片（A 胜 B 负），让模型提升 A 的生成概率，降低 B 的。公式很简单：
LDPO=−E[log⁡σ(βlog⁡pθ(xw∣x,c)pref(xw∣x,c)−βlog⁡pθ(xl∣x,c)pref(xl∣x,c))]L_{DPO} = -\mathbb{E}[\log\sigma(\beta\log\frac{p_\theta(x^w|x,c)}{p_{ref}(x^w|x,c)} - \beta\log\frac{p_\theta(x^l|x,c)}{p_{ref}(x^l|x,c)})] ​ = − E [ lo g σ ( β lo g p r e f ​ ( x w ∣ x , c ) p θ ​ ( x w ∣ x , c ) ​ − β lo g p r e f ​ ( x l ∣ x , c ) p θ ​ ( x l ∣ x , c ) ​ )]问题出在哪儿？人类偏好是 多维 的：构图、语义对齐、纹理细节、美学风格……但标注数据只有 一个二元标签 （A>B）。这就麻烦了：
- 图 A 可能构图好但纹理差- 图 B 可能纹理好但语义跑偏- 标注者被迫二选一，选了一个维度- 但模型收到的信号却是：A 的一切都好，B 的一切都差结果是，模型在学构图的时候收到错误信号（因为 A 的构图确实好），但在学纹理的时候又被带偏（因为 A 的纹理其实差）。 不同维度的梯度方向互相打架 ，训练自然震荡。

## 核心 insight：噪声样本其实是未标注数据论文把这个问题重新 framing 了：不是标签错了，而是标签 不完整 。那些存在多维冲突的样本，与其当错误标签硬学，不如当成 未标注数据 ，让模型自己生成伪标签。
这就转向了半监督学习（SSL）的老套路：先筛出一小部分“干净数据”做冷启动，然后用模型给“脏数据”打伪标签，迭代优化。
关键问题来了：模型自己的预测靠谱吗？论文的观察是： DPO 损失本身就在训练一个二分类器 。在每个时间步 t，模型其实在判断“哪张图更可能是胜者”。这个判断的置信度（logit 的绝对值）和方向（sign）正好可以当伪标签用。
## 方法：Semi-DPO 的两板斧### 1. Multi-Reward Consensus：筛出干净数据怎么找干净数据？论文用了 多个奖励模型投票 。选的是五个：PickScore、HPS v2、CLIP Score、LAION Aesthetics、ImageReward。一个偏好对（A>B）只有五个模型全票同意，才放进干净集合 D_labeled；否则扔进未标注集合 D_unlabeled。
效果如何？在 Pick-a-Pic V2 数据集上， 约 21% 的数据通过了全票过滤 （176,999 / 851,293）。这 21% 是各维度偏好高度一致的高质量样本，拿来当冷启动最合适。
### 2. Iterative Self-Training：用时间步解耦冲突这是最巧妙的部分。论文发现：扩散过程是分层的——早期管全局构图，晚期管局部细节。既然如此，一个“A 构图好但纹理差 vs B 纹理好但构图差”的冲突，可以 按时间步拆成非冲突信号 ：
- 早期 denoising：A 更优（构图维度）
- 晚期 denoising：B 更优（纹理维度）
这样，同一个样本在不同时间步可以有不同的“正确标签”。伪标签的生成 rule 是：
- 置信度：∣zθ(t)∣>τinterval|z_\theta^{(t)}| > \tau_{interval}(t)​∣>τinterval​（动态阈值，不同时间区间独立）
- 方向：sign(zθ(t))>0\text{sign}(z_\theta^{(t)}) > 0(zθ(t)​)>0 则保持原标签（A>B），否则翻转（B>A）
训练变成了两阶段迭代：
- Stage 0：只在 D_labeled 上训练，得到模型 pθ0p^0_\theta0​- Iteration i：

### 1. 伪标签的置信度阈值不能全局固定论文发现模型在不同时间步的置信度分布不同，所以用了 区间动态阈值 。这暗示：做自训练时，别用一个阈值糊弄所有样本，得分箱（bucket）处理。
### 2. 模型本身可以当分类器一个有趣的发现：DPO 训练本身就隐含了一个时间步级别的二分类器。这意味着 不需要额外 head 或奖励模型 就能做伪标签生成。省事。
### 3. 冷启动数据质量决定上限只有 21% 的数据是全票通过的，但就靠这 21% 训练出的初始模型，已经能生成相当靠谱的伪标签了。 数据质量 > 数据量 ，在偏好学习里尤其明显。
### 4. 迭代两三次就够了实验显示迭代收益快速衰减。实际部署时，与其搞十轮自训练，不如 把计算预算花在更好的共识过滤 上（比如加更多奖励模型，或用更强的模型）。
### 5. 时间步维度是天然的解耦信号扩散过程的时间层次结构（早期构图、晚期细节）不是bug是feature。利用这一点，可以把单个冲突标签拆成多个时序子任务。这思路可以迁移到其他时序生成模型（比如自回归文本生成的token级别偏好对齐）。
## 局限与后续方向论文没明说但隐含的几点：
- 计算成本：多奖励模型共识要跑 5 个模型做推理，数据量大时很贵。实际中可以用轻量级模型近似，或者用少量高置信样本主动查询。
- 奖励模型偏差：依赖现成的奖励模型（PickScore、HPS等）做共识，这些模型本身有偏见。如果它们集体犯错，干净数据也会脏。
- 时间步划分的粒度：论文没详说怎么划分时间区间（N 是多少），只是说实验发现不同区间置信度不同。这超参可能依赖任务。
- 文本到图像的领域限定：方法依赖扩散模型的时间步结构， KL;;换到 LLM 的 token 级别 DPO 还能不能用？不确定，需要重新设计伪标签生成策略（比如按层、按注意力头）。
## 一点评价Semi-DPO 的思路很“朴素”：梯度冲突是因为标签噪声，噪声样本别硬学，让模型自己重新想想。但 执行得很精致 ——用多模型共识找干净数据，用时间步条件伪标签解构冲突，用复合损失防止漂移。
对工程实践的启发是：在做偏好优化时，别迷信原始标注。花点成本筛一遍高质量子集，再用模型自训练扩展，往往比全量数据硬训更稳、效果更好。
一句话总结 ：当人类偏好是多维的，二元标签只是噪声；与其纠正噪声，不如让模型自己重新定义偏好。
