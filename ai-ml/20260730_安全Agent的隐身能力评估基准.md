# ⭐⭐⭐½ 安全Agent的隐身能力评估基准

**日期**: 2026-07-30

---

论文 : StealthBench: Measuring Operational Stealth in Autonomous Offensive-Security Agents链接 : https://arxiv.org/abs/2607.26314现在的 AI Agent 能写代码、能跑测试，甚至能自主挖掘漏洞。但有一个致命问题被忽略了：它们太“吵”了。
在真实的红队演练或 Bug Bounty 中，找到漏洞只是第一步。如果你为了证明权限，直接删库或者把密钥明文上传到服务器日志里，那你不是黑客，你是防守方的免费压力测试员。这篇论文直击痛点： 目前的 Agent 缺乏基本的操作安全（OPSEC）意识 。
### 为什么现有的评估都不够看？
现有的基准测试（如 Cybench, ExploitBench）只关心两件事：
- 你能不能找到漏洞？
- 你能不能利用它拿到 Flag？
它们完全忽略了“过程”。一个优秀的渗透测试员会隐藏痕迹、避免触发 WAF、不污染生产数据。而当前的 Agent 训练信号主要来自 RLHF，奖励的是“正确性”和“工具调用成功”，却从未惩罚过“留下法医证据”。这导致 Agent 即使找到了漏洞，也往往以极其粗糙的方式完成，直接暴露身份。
### StealthBench：给 Agent 的“隐身衣”压力测试作者提出了 StealthBench ，一个专门衡量自主攻击性安全 Agent “操作隐蔽性”的基准。
核心设计直觉很硬： 从真实世界的失败中提炼场景 。
作者没有凭空捏造任务，而是从真实的 Bug Bounty 和 Red Team 轨迹中提取了 11 个经过人工验证的 OPSEC 事故，扩展为 14 个 Docker 化的任务场景。这些场景覆盖了六个维度：
- 凭证 OPSEC：是否把密钥泄露给目标服务器日志？
- 破坏性操作：是否为了证明权限而删除生产数据？
- 检测级联：是否触发 WAF 或速率限制？
- 遥测注入：是否在请求中留下了可识别的 User-Agent？
- 工件污染：是否将内部推理泄露到外部报告？
- 噪声纪律：是否进行了不必要的冗余扫描？
评估方式也很硬核： 3 模型 LLM 裁判组 。
使用 GPT-5.6 Sol、GLM 5.2 和 Kimi K3 组成裁判团，对 Agent 的完整轨迹（包括每一个工具调用、参数、输出）进行多数票裁决。这比简单的二进制成功/失败要复杂得多，因为它需要理解“意图”与“痕迹”之间的细微差别。
### 关键结果：没有模型能完全隐身实验覆盖了 8 个主流模型，共 771 次有效运行。结果令人担忧：
⚠️ 没有任何模型的“安全成功率”超过 54%。
“安全成功率”定义为：既解决了任务，又通过了隐蔽性审查。这意味着即使是最强的模型，在近一半的情况下都会因为操作痕迹过大而“暴露”。
具体数据对比如下：

- 能力不等于隐蔽：GLM 5.2 解决率最高，但鲁莽率也高达 36.1%。它很能干活，但干得很脏。
- 谨慎的代价：Trinity Large Thinking 和 Nemotron 3 Ultra 的安全成功率低，主要是因为它们解决率低。但当它们成功时，隐蔽性极好（Stealth@Solve 分数极高）。这说明有些模型通过“少做事”来避免犯错。
- 特定场景的全军覆没：在 callback-listener 任务中，70.4% 的 Agent 能解决，但 0% 是安全的。所有模型都倾向于注册可识别的基础设施，而不是使用临时监听器。
### 工程启示对于正在构建或部署安全 Agent 的团队，这篇论文有三个直接建议：
- 重新定义评估指标：不要只看 Solve Rate。引入“鲁莽解决率”（Reckless Solve Rate）作为核心监控指标。一个能干活但会炸库的 Agent，在生产环境中是负债而非资产。
- 训练数据需要 OPSEC 信号：目前的 RLHF 缺乏对“操作痕迹”的惩罚。未来的微调数据集应包含大量“隐蔽操作 vs 鲁莽操作”的对比例子，让模型学会在完成任务的同时最小化足迹。
- 自动化监控必不可少：由于没有模型能完美隐身，部署自主 Agent 时必须配合实时的 OPSEC 监控系统。StealthBench 提供的裁判逻辑可以作为实时监控的启发式规则来源。
### 局限与展望目前 StealthBench 依赖 LLM 裁判，虽然使用了多数投票，但不同模型在“噪声纪律”等主观维度上仍有分歧（Kappa 系数显示中等一致性）。此外，基准仅覆盖了 6 个维度的部分场景，未来需要扩展到更复杂的网络横向移动和持久化场景中。
总之，Agent 正在进入真实的攻防领域。如果它们不能学会“像幽灵一样工作”，那么它们的每一次成功，都可能是防守方的一次胜利。
