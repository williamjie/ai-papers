# 模型合并后量化崩盘？E-PMQ 用专家权重“锚定”精度

**日期**: 2026-05-19

---

论文 : E-PMQ: Expert-Guided Post-Merge Quantization with Merged-Weight Anchoring链接 : https://arxiv.org/abs/2605.16882模型合并（Model Merging）和量化（Quantization）都是当下低成本部署的热门方案，但当两者结合时，直接对合并后的模型进行量化往往会导致精度断崖式下跌。这篇论文精准地踩中了这个痛点： 合并模型并不是一个完美的“独立模型”，直接量化它会放大合并过程中的偏差。
作者提出的 E-PMQ（Expert-Guided Post-Merge Quantization）框架，通过在量化校准阶段引入原始专家权重作为“锚点”，在 4-bit 甚至更低精度下，显著挽救了合并模型的性能。对于需要集成多个任务专家且受限于显存资源的工程场景，这是一个极具实用价值的改进。
## 为什么“先合并，后量化”会失效？
在传统的后训练量化（Post-Training Quantization, PTQ）中，我们假设全精度模型是一个可靠的“重建目标”。GPTQ 等算法通过最小化量化前后层输出的差异来寻找最优量化参数。
然而，在模型合并场景下，合并模型 WmW_m ​ 是由多个专家模型 WiW_i ​ 通过参数组合（如 Task Arithmetic 或 TIES-Merging）得到的。论文指出，合并模型本身已经存在 专家相对合并偏差（Expert-Relative Merging Deviation） 。
当你对合并模型直接进行量化时，实际上是在同时叠加两种误差：
- 量化偏差：由低比特重建引入的误差。
- 合并偏差：合并模型与原始专家行为之间的固有差异。
Naive PMQ（即直接对合并模型应用 GPTQ）会将这个已经“不完美”的合并模型当作唯一真理进行重建，导致两种偏差相互耦合、累积，最终在低比特（如 4-bit）设置下造成精度严重退化。
## E-PMQ 的核心设计直觉E-PMQ 的核心 Insight 在于： 量化不应该只盯着合并后的模型看，而应该参考原始专家的行为。
具体设计包含两个关键部分：
-专家引导的目标（Expert-Guided Targets）：
在逐层校准（Layer-wise Calibration）时，E-PMQ 不仅使用合并模型的激活值，还利用原始专家权重 WiW_i​ 和对应的校准激活值 XiX_i​ 构建输出目标 Yi=WiXiY_i = W_i X_i​=Wi​Xi​。这相当于告诉量化算法：“你的量化结果不仅要接近合并模型，还要尽量保留原始专家的特征。”
-合并权重锚定（Merged-Weight Anchoring）：
如果只参考专家，量化结果可能会过度偏向某个特定专家，破坏合并模型的整体集成能力。因此，E-PMQ 引入了一个锚定项，将量化权重 QQ 拉向全精度合并权重 WmW_m​。
其优化目标函数如下：

## 实验数据：精度挽救效果显著论文在 CLIP-ViT 和 FLAN-T5 等多个基准上验证了 E-PMQ 的有效性。以下是关键实验数据的对比：
### 1. CLIP-ViT-B/32 八任务合并（4-bit）
合并方法 GPTQ (Naive) E-PMQ 提升幅度 Task Arithmetic 65.0% 73.6% +8.6% TIES-Merging 69.1% 74.8% +5.7% Simple Averaging 62.6% 67.7% +5.1%在更难的 20-task CLIP-ViT-L/14 设置下，E-PMQ 在 Task Arithmetic 中更是将 GPTQ 的 34.8% 提升至 76.7% ，这是一个巨大的飞跃，说明在任务冲突更严重的场景下，专家引导的作用尤为关键。
### 2. FLAN-T5-base GLUE 基准（4-bit）
合并方法 GPTQ (Naive) E-PMQ 提升幅度 Task Arithmetic 78.26% 83.34% +5.08% TIES-Merging 79.66% 83.48% +3.82%### 3. 消融实验：锚定的必要性论文特别验证了“合并权重锚定”的重要性。如果去掉锚定项（ α=0\alpha=0 0 ），仅依靠专家引导，模型性能会彻底崩溃：
- Task Arithmetic 平均准确率从 68.00% 暴跌至 5.37%。
- TIES-Merging 平均准确率从 72.20% 暴跌至 4.57%。
这证明专家引导虽然能纠正偏差，但若无锚定约束，量化解会偏离合并模型的集成分布，导致灾难性后果。
## 工程启示与局限对工程实践的启示：
- 合并即量化，需同步考虑：如果你计划合并多个微调后的模型并进行低比特部署，不要直接套用标准的 GPTQ/LLM.int8() 流程。E-PMQ 提示我们，合并后的模型结构并不稳定，需要额外的校准信号。
- 专家权重只需在校准阶段可见：E-PMQ 仅在量化校准阶段需要访问原始专家权重，部署时仍然是单个低比特模型，不增加推理时的显存开销或延迟。
- 校准数据利用率更高：实验显示，E-PMQ 在仅使用 64 个样本/任务时，准确率（72.23%）甚至超过了使用 256 个样本的 GPTQ（65.03%）。这意味着在标注数据稀缺的场景下，E-PMQ 更具优势。
局限与展望：
- 计算开销增加：E-PMQ 的量化时间约为 GPTQ 的 1.81x - 2.99x（取决于校准样本量）。虽然这是离线成本，但对于需要频繁重新量化的场景仍需考虑。
- 依赖专家可用性：该方法假设在量化阶段可以访问原始专家模型。如果专家模型已经删除或不可访问，则无法使用此方法。
总的来说，E-PMQ 为“模型合并+量化”这一低成本部署组合拳提供了一套稳健的解决方案，尤其在多任务合并导致精度严重受损时，其价值不容忽视。
