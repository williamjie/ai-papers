# ⭐⭐⭐½ 全景生成新范式：几何感知预训练如何打破边界伪影

**日期**: 2026-07-10

---

论文 : Enhancing In-context Panoramic Generation via Geometric-aware Pretraining链接 : https://arxiv.org/abs/2607.08765全景图像生成一直是个“硬骨头”。
现有的扩散模型大多基于平面视角设计，直接套用到等距柱状投影（Equirectangular Projection, ERP）的全景图上，往往会导致两极扭曲严重、接缝处伪影频发。
这篇来自 Insta360 和清华大学的 Canvas360 论文，提出了一套“几何感知预训练 + 统一上下文微调”的两阶段框架。
它不只是修修补补，而是从数据构建到模型架构，重新定义了全景生成的基线。
### 痛点：平面模型不懂球面几何全景图的核心难点在于其内在的球面几何特性。
现有的方法通常尝试通过立方体贴图（Cube-map）或球形位置编码来缓解问题，但在处理复杂的空间结构时，往往难以保持几何一致性。
更致命的是数据瓶颈。高质量的全景上下文生成数据（如修复、外绘、风格迁移）极度稀缺，导致模型无法学习真正的空间先验。
Canvas360 的 Insight 很直接：与其在微调阶段硬教模型“这是什么球”，不如在预训练阶段就让模型“看懂”深度和几何结构。
### 方法拆解：让模型学会“看深度”
1. 并行深度生成（Parallel Depth Generation）
这是本文的核心创新点之一。
作者没有把深度图仅仅当作条件输入，而是让模型同时预测 RGB 图像和深度图。
通过序列拼接（Sequence Concatenation），将 RGB Token 和深度 Token 合并输入 Flow Transformer。
关键设计 ：为了区分模态，作者在 3D RoPE 位置编码中引入了时间偏移量 TdT_d ​ 。这比传统的通道拼接更优雅，能无缝兼容 FLUX 等大模型底座。
这种设计迫使模型在生成像素的同时理解空间深度，从而捕捉物体扭曲细节，提升全局几何一致性。
2. 速度循环填充（Velocity Circular Padding）
全景图左右边界是连续的，但 Transformer 的注意力机制默认它们是断开的。
传统的循环填充只是复制边界列，增加了优化权重，但未显式告知模型“这是相邻的”。
Canvas360 提出了“速度循环填充”：在预测速度场时，显式同步 0∘0^\circ 和 360∘360^\circ 边界的特征与目标速度。
这让模型在训练阶段就看到了跨越边界的局部邻接关系，从而生成无缝衔接的全景图。
3. 相似度损失正则化（Similarity Loss Regularization）
训练中发现，RGB 和深度分支容易收敛到退化的局部最优解，即两者预测结果过于相似。
作者引入了一个相似度损失 LsimL_{sim} ​ ，惩罚两个模态速度场之间的相关性。
这看似简单，却有效防止了模态坍塌，确保了 RGB 关注外观、深度关注几何的分工明确。
### 数据工程：100 万级全景数据集没有好数据，再好的模型也是空中楼阁。
作者构建了 Canvas360Dataset ，包含 100K 高质量 RGB-Depth 配对数据用于预训练。
更值得工程界关注的是其下游任务数据合成管线：
- 风格迁移：200K 样本- 外绘（Outpainting）：250K 样本- 修复（Inpainting）：250K 样本- 编辑（Editing）：200K 样本这套管线利用 FLUX.2-dev 和 VLMs 自动化生成，解决了全景编辑数据匮乏的行业难题。
### 实验结果：全面领先在文本到全景生成任务上，Canvas360 的表现令人印象深刻。
方法 FID ↓ FAED ↓ (全景特定) IS ↑ DiT360 42.88 50.88 24.77 Ours 44.17 2.33 25.96注：FAED 是专门针对全景图保真度的指标，数值越低越好。
Canvas360 在 FAED 指标上大幅领先 DiT360（从 50.88 降至 2.33），证明了其在几何一致性和细节保留上的巨大优势。
在用户研究中，Canvas360 在边界连续性（BC, 31.1%）、全景感知（PA, 34.1%）和整体质量（OQ, 35.9%）上均获得最高偏好率。
消融实验也证实了各组件的有效性：加入深度生成后，FAED 从 5.37 降至 4.74；加入位置偏移和相似度损失后，虽然 FID 略有波动，但显著减少了“过暗”等退化现象，提升了视觉稳定性。
### 工程启示- 几何先验的价值：在生成任务中，显式引入深度或结构信息作为辅助监督，能显著提升模型的几何理解能力，尤其适用于全景、3D 等非欧几里得空间数据。
- 统一框架的潜力：通过 Token 级拼接和位置偏移，可以将多种上下文任务（修复、编辑、风格迁移）统一到一个模型中。这降低了部署复杂度，提高了推理灵活性。
- 数据合成管线的重要性：Canvas360Dataset 的合成策略（如利用 VLM 生成局部提示词、利用 FLUX 进行风格化）为其他垂直领域的数据构建提供了可复用的模板。
### 局限与展望尽管 Canvas360 表现优异，但其预训练阶段依赖高质量的深度估计模型（如 DAP）。如果深度估计存在误差，可能会引入噪声。
此外，虽然 FAED 指标大幅改善，但 FID 略高于 DiT360，说明在整体感知质量上仍有微调空间。
未来，如何将这种几何感知预训练扩展到视频全景生成，将是极具价值的研究方向。
