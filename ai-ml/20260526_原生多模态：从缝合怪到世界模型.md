论文 : Toward Native Multimodal Modeling: A Roadmap链接 : https://arxiv.org/abs/2605.25343现在的多模态大模型（MLLM）大多还是“拼凑”出来的：一个冻结的视觉编码器，加上一个简单的投影层，再挂载到一个预训练好的语言模型上。这种**晚期融合（Late-Fusion）**架构虽然工程上容易落地，但本质上让语言模型对原始感官信号是“盲目”的。
腾讯优图实验室等机构发布的这篇路线图论文，不仅梳理了从 2023 到 2026 年的技术演进，更核心的是它重新定义了什么是 原生多模态建模（Native Multimodal Modeling, NMM） 。对于工程师而言，理解 NMM 的架构分层和训练范式，是构建下一代 Agent 和世界模型的关键。
### 为什么现有的“拼接”方案走不远？
早期的 LLaVa、Qwen-VL 等模型采用的是模块化组装策略。这种设计的最大痛点在于 跨模态交互的深度不足 。视觉特征被压缩成向量后注入文本空间，模型无法在底层特征层面进行真正的协同推理。
论文将 NMM 的演进划分为两个核心阶段：
- 中期融合（Mid-Fusion）：如 CogVLM、Qwen2.5-VL。特征通过交叉注意力或适配器注入联合主干网。模型具备了跨模态洞察力，但仍保留显式的模态边界。
- 早期融合（Early-Fusion）：如 Transfusion、Chameleon。这是真正的“原生”状态，所有模态通过统一的分词器映射到共享嵌入空间，由单一 Transformer 处理。这消除了架构上的不对称性，实现了真正的多模态对称建模。
### 方法拆解：输入输出对偶性的三种范式论文没有止步于架构分类，而是从**输入-输出对偶性（Input-Output Duality）**的角度，将 NMM 划分为三个功能类别，这对工程选型极具指导意义：
- 多模态到文本（M2T）：非对称理解。输入任意模态，输出纯文本。这是目前最成熟的领域，代表模型包括 MiniCPM-V-4.6、Nemotron3-Nano-Omni。核心挑战在于如何避免视觉 Token 爆炸导致的注意力饱和。
- 多模态到目标（M2G）：场景化生成。输入多模态，生成特定非文本模态（如视频、音频）。代表模型有 Kling-Omni、HunyuanVideo-1.5。关键在于通过原生表示直接解码目标模态，保证时空连贯性。
- 多模态到多模态（M2M）：对称建模。这是终极形态，理解与生成在单一网络中共存。代表模型包括 Emu3.5、Janus-Pro。它消除了感知器和渲染器的界限，实现了任意模态间的实时交互。
### 关键工程挑战与解决方案在深入架构细节时，论文揭示了几个具体的工程瓶颈及其解法：
-视觉 Token 爆炸：
极端压缩：Kimi K2.5 和 InternVL-3.5 使用视觉分辨率路由器（Visual Resolution Router），将语义丰富的区域分配 256 个 Token，而背景压缩至 64 个 Token，整体冗余减少 50%。
- 动态分配：Gemma-4-31B 允许用户根据任务复杂度手动设置 Token 预算，OCR 任务用高预算，简单识别用低预算。
-音频理解的语义-声学冲突：
MiMo-V2.5 采用 RVQ 系统，初始层优先保留语义结构，后续层细化声学细节，解决了离散 Token 空间中语义与声学的表示冲突。
- Nemotron-3-Nano-Omni 通过 Mamba2-Transformer 混合 MoE 架构，利用 Mamba2 的线性复杂度 O(N)O(N) 替代二次注意力 O(N2)O(N^2))，在保持低延迟的同时提升吞吐量。
-视频理解的时空一致性：
Qwen3-VL 将 RoPE 位置编码分解为三维交错维度，赋予每个 Token 唯一的 3D 时空坐标。
- GLM-5V-Turbo 插入显式时间 Token，让模型像阅读自然语言一样感知物理时间，这对长视频摘要至关重要。
### 工程启示：从静态基准到流式部署这篇论文对实际落地的最大启示在于 训练范式的统一 。传统的分阶段训练（先预训练编码器，再对齐）正在被端到端的原生训练取代。
- 数据层面：需要从 curated corpora 转向自生成的多模态流数据。
- 推理部署：必须解决长上下文下的序列爆炸问题。论文提到的动态稀疏注意力剪枝和模块化长期记忆（如 InternLM-XComposer2.5 的记忆池）是未来方向。
- 评估体系：静态基准已不足以衡量 NMM 能力，需要建立包含时序感知、实时交互的全方位评估协议。
### 局限与展望尽管 NMM 前景广阔，但早期融合架构在训练稳定性和数据配比上仍面临巨大挑战。目前大多数 SOTA 模型仍处于 Mid-Fusion 阶段，真正的 Early-Fusion M2M 模型（如 AnyGPT）在通用能力上尚未完全超越精心调优的 Late-Fusion 方案。
对于工程师来说，短期内关注 Mid-Fusion 架构下的视觉压缩算法 和 音频 Token 化策略 更具实用价值；而长期来看，构建统一的 Token 空间和端到端训练流水线，是通往世界模型的必经之路。
