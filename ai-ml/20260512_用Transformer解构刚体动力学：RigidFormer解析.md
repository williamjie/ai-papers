# 用Transformer解构刚体动力学：RigidFormer解析

**日期**: 2026-05-12

---

论文 : RigidFormer: Learning Rigid Dynamics using Transformers链接 : https://arxiv.org/abs/2605.09196在机器人控制和生成式AI领域，物理引擎的准确性至关重要。但传统仿真器依赖完美的网格和精确的物理参数，这在现实世界的点云输入面前往往捉襟见肘。MIT和Meta联合提出的 RigidFormer 提供了一种全新的思路：完全抛弃网格拓扑，直接用 Transformer 学习基于点的刚体动力学。这不仅是表示方式的转变，更是计算复杂度从 O(Nv2)O(N_v^2) 2 ​ ) 到 O(No2)O(N_o^2) 2 ​ ) 的降维打击。
## 痛点：网格依赖与顶点级交互的陷阱现有的学习式模拟器（如 MeshGraphNets、HopNet）大多绑定在网格连通性上。这意味着它们需要显式的边和面信息，无法直接处理点云（Point Clouds）这种拓扑自由、分辨率灵活的输入。更致命的是，顶点级的消息传递（Message Passing）导致计算成本随分辨率急剧上升，推理效率极低。
RigidFormer 的核心洞察在于： 刚体是一个整体 。刚体受到冲量时是作为一个 coherent whole 响应的，相互作用不需要像顶点级仿真器那样“扩散”传播。既然刚体运动本质上是低维的（每个物体仅6自由度），那么直接在顶点层面交互就是巨大的算力浪费。
## 方法拆解：对象中心主义与锚点机制RigidFormer 的设计围绕三个关键改进展开，旨在实现高效、稳定且通用的动力学模拟。
### 1. 对象中心交互（Object-Centric Interaction）
模型不再处理单个顶点，而是将每个物体的点云编码为一个紧凑的 Object Token 。
- 特征工程：对于物体 ii 的每个顶点，拼接最近邻位移、位置增量（近似速度）、参考偏移和物理参数（质量、摩擦、恢复系数）。
- 编码：使用共享的 Hierarchical Feature Extraction 将这些顶点特征聚合为固定维度的对象嵌入。
- 优势：Transformer 的注意力机制直接在对象 token 间交互，彻底避免了顶点级的密集计算。
### 2. 基于锚点的状态推进（Anchor-based State Advance）
这是本论文最精彩的工程巧思。虽然物体有数千个点，但刚体运动只需少量关键点即可描述。
- 锚点选择：使用 FPS（Farthest Point Sampling）为每个物体选取 Na=4N_a=4​=4 个锚点（Anchors）。
- 注意力降维：交互复杂度从 O((MNv)2)O((M N_v)^2)​)2) 降至 O((MNa)2)O((M N_a)^2)​)2)。
- 局部几何感知：为了不让锚点丢失碰撞相关的局部几何信息，论文设计了 Anchor-Vertex Pooling (AVP)。通过可学习的各向同性距离核，将锚点附近的顶点特征聚合到锚点上。这种聚合是顶点顺序不变（Order-invariant）的。
- 刚性投影：预测锚点的加速度后，使用 Verlet 积分更新锚点位置，然后通过 可微分的 Kabsch 对齐 将变换投影回刚体流形（Rigid-body Manifold）。这确保了更新后的点云严格保持刚性，同时保留了梯度流，极大提升了长时滚动的稳定性。
### 3. 基于锚点的旋转位置编码（ARoPE）
Transformer 需要位置信息来泛化。直接编码所有顶点冗余且破坏泛化能力。
- 设计：对每个锚点应用 3D 旋转映射，生成相位描述符，然后进行 Mean-pooling 聚合。
- 对称性：这种设计使得对象 Token 处理是排列等变的（Permutation-equivariant），而锚点描述符对锚点重索引是不变的（Invariant）。这完美契合了刚体几何与相对位置的核心需求。
## 关键结果：速度与精度的双重胜利RigidFormer 在 MOVi 基准测试中展现了惊人的性能，尤其是在推理速度上实现了数量级的提升。

- 泛化能力：模型能泛化到未见过的点分辨率（训练于 128-1024 点，测试于 768 点）和跨数据集迁移。
## 工程启示与局限对工程师的意义 ：
- 端到端感知-动作链路：RigidFormer 直接从点云输入，无需昂贵的 SDF 拟合或网格重建（SDF-Sim 需 5 小时预训练），适合实时机器人系统。
- 稀疏注意力是王道：在处理大规模物体交互时，将交互层级从“元素级”提升到“对象级”，是突破算力瓶颈的关键。
- 物理约束嵌入神经网络：通过可微分 Kabsch 对齐强制刚性约束，比直接回归旋转矩阵更稳定，这是将物理先验融入深度学习的有效范式。
局限与展望 ：
- 锚点数量敏感：虽然 4 个锚点平衡了效率与精度，但在极端几何形状下可能需要更多锚点（实验显示 8 个锚点在某些长视界下方向误差更低，但成本翻倍）。
- 部分点云处理：虽然论文展示了 25% 遮挡下的鲁棒性，但在严重遮挡或非刚性形变场景下的表现仍需验证。
- 扩展性：目前主要验证在刚体和初步的 articulated bodies，对于完全柔性体的模拟尚属空白。
总的来说，RigidFormer 证明了 Transformer 不仅能处理序列数据，也能高效解构物理世界。它用更少的计算资源，实现了更稳定的动力学预测，为具身智能（Embodied AI）提供了一条无需完美网格的新路径。
