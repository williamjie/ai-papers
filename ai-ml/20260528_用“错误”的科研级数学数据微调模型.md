论文 : ResearchMath-14K: Scaling Research-Level Mathematics via Agents链接 : https://arxiv.org/abs/2605.28003大多数开源数学数据集（如 MATH、GSM8K）本质上是“已解题”，它们训练的是解题套路，而非真正的科研思维。这篇论文提供了一个极具工程价值的反直觉结论： 即使没有标准答案，经过清洗的“失败尝试”也能显著提升模型在科研级数学上的表现。 对于正在构建垂直领域 Agent 或追求高阶推理能力的工程师来说，这是一份关于数据筛选和微调策略的重要参考。
### 痛点：开源数据的“天花板”太低目前开源界的数学训练数据主要分为两类：
- 竞赛/教科书级：如 NuminaMath（860k），量大但难度封顶在奥赛水平。
- 科研级基准：如 FrontierMath、HLE，通常作为评测集被严格保护，防止污染，且规模极小（<3k）。
真正的科研数学问题（Open Problems）往往缺乏已知解法，难以用于传统的监督微调（SFT）。作者指出，现有的开源生态无法支持模型在“前沿数学”上的持续进化。
### 方法拆解：Agent 流水线与“错误”的价值1. 数据构建：从文献中“挖”出问题团队没有依赖专家手动编写，而是设计了一个双阶段 Agent 流水线处理 arXiv、zbMATH 等来源的 1,233 篇文档：
- Extractor Agent：识别并提取原文中的开放性问题。
- Refiner Agent：这是关键一步。它通过搜索引用文献，补全缺失的定义和假设，将碎片化的问题重写为自包含（Self-contained）的研究问题。
最终得到 ResearchMath-14K（14,056 个问题），这是目前最大的科研级数学问题集。
2. 核心 Insight：利用“错误的尝试”
既然没有标准答案，怎么训练？作者让两个强模型生成推理轨迹，得到 220k 条数据（ResearchMath-Reasoning）。
- 发现：直接微调会导致模型退化（重复输出、放弃解题）。
- 分析：通过规则计数和 Agent Judge 分析，发现新模型倾向于“伪造引用”来掩盖不确定性。例如，DeepSeek V4-Pro 相比 R1，每条轨迹的引用提及增加了 5.6 倍，但虚假引用也增加了 5.0 倍。
- 策略：使用 Agent 验证引用的真实性，过滤掉包含虚假引用、未尝试解题或无依据假设的轨迹。最终得到 5,000 条高质量（虽不完全正确但逻辑合理）的训练数据。
### 关键结果：清洗后的“错误”依然有效在 Qwen3 系列模型（4B/8B/30B）上进行 LoRA 微调，对比基线模型和另一数据集 DASD-Thinking，结果如下：
指标 提升幅度 说明 平均增益 +9.2 pp 相比 Base 模型的平均提升 对比 DASD +2.6 pp 在 HLE 和 SOOHAK 上平均优于通用思维数据 30B @ HLE +4.4 pp 相比 DASD 的最大单点优势 引用造假率 54.0% 在未过滤的轨迹中，超半数包含至少一个假引用值得注意的是，在 AIME（较简单的竞赛题）上，通用数据 DASD 表现更好；但在 HLE 和 SOOHAK（科研级/高难度）上，经过清洗的 ResearchMath 数据优势明显。这证明 特定领域的“过程监督”比通用的“解题套路”更能迁移到复杂场景 。
### 工程启示- 数据质量 > 数量，但“正确性”可放宽：在缺乏 Ground Truth 的垂直领域（如法律、医疗、前沿科研），不必强求完美答案。只要通过 Agent 过滤掉明显的幻觉（如伪造引用、胡言乱语），剩余的“合理尝试”就是宝贵的 SFT 数据。
- 警惕新模型的“过度自信”：实验显示，模型越新、越强，在遇到未知问题越容易通过编造引用来“凑答案”。在构建 Agent 系统时，必须加入引用验证或事实核查环节，否则微调可能会强化这种幻觉。
- 自包含问题的重写价值：原始文献中的问题往往依赖上下文。Refiner Agent 补全定义的过程，本质上是在做高质量的 Prompt Engineering。对于内部知识库问答，类似的“上下文补全”步骤能显著提升回答质量。
### 局限与展望目前过滤后的数据量仅 5,000 条，主要受限于 Agent 验证的成本（调用搜索 API）。未来若能降低验证成本，扩大清洗后数据的规模，可能会进一步突破科研级推理的瓶颈。此外，论文未涉及强化学习（RL）在此类数据上的应用，这或许是下一个值得探索的方向。
