# ⭐⭐⭐ LLM的“思考”只是幻觉？四维公理实测

**日期**: 2026-06-29

---

论文 : Formalizing Latent Thoughts: Four Axioms of Thought Representation in LLMs链接 : https://arxiv.org/abs/2606.27378现在的 LLM 圈子里，“思维链（Chain-of-Thought, CoT）”已经快被玩烂了。为了省 Token、提速度，大家开始搞“隐式思考”，把推理过程压缩成连续的向量表示（Latent Thoughts）。听起来很美：不用输出废话，直接给答案，还保留了推理能力。
但这篇论文泼了一盆冷水： 如果你不看下游准确率，光看这些“思考向量”本身的质量，它们几乎全是垃圾。 作者提出了一套公理体系来审计这些向量，结果发现，目前主流的隐式思考方法，连最基本的“区分不同问题”都做不到。
### 为什么现有的评估在骗你？
我们通常怎么判断一个模型“想得好不好”？看它在 GSM8K 或 MATH 上的准确率。但这有个巨大的逻辑漏洞： 下游任务准确率高，不代表中间的表示（Representation）是好的。
这就好比一个学生考试得了满分，但他脑子里可能根本没理解公式，只是背下了答案。如果我们要把这个学生的“思维过程”提取出来传给另一个模型，或者用来做 Agent 的中间状态，这种“伪理解”就会崩盘。
现有的研究把“表示质量”和“模型容量”混为一谈。这篇论文的核心动机就是要把这两者拆开： 不管最后答对没，这个“思考向量”本身到底有没有意义？
### 核心 Insight：思考向量的四大公理作者没有搞花哨的新架构，而是定义了一个“功能性思考表示（Functional Thought Representation）”必须满足的四个公理。这不仅是理论推导，更是给工程师提供了具体的量化指标：
- 因果性（Causality）：
直觉：如果你把模型生成的中间推理文本替换成这个“思考向量”，后续的答案分布应该不变。
- 测量：KL 散度。如果替换后预测分布变了，说明向量没抓住推理的核心逻辑。
- 最小性（Minimality）：
直觉：好的思考应该只保留解题所需的信息，过滤掉无关噪声（比如题目里的天气描述）。
- 测量：信息瓶颈残差（IB Residual Gap）。向量越精简且相关性越高越好。
- 可分性（Separability）：
直觉：两个不同的问题（即使是同一类任务，比如“2+2”和“2+3”），它们的思考向量在空间里必须能被区分开。
- 测量：判别器准确率。如果向量挤在一起，说明模型根本没在针对具体问题思考，只是在泛泛而谈。
- 稳定性（Stability）：
直觉：同样的问题，不同的表述或采样路径，应该映射到相似的语义空间，反映不确定性而非随机噪声。
- 测量：分布一致性得分（DCS AUROC）。
### 残酷的实验结果作者在 Big Bench Extra Hard (BBEH) 的 23 个推理任务上，测试了 Llama-3.1/3.3、DeepSeek-R1-Distill、Skywork-OR1 等主流模型，以及 Soft Thinking、Latent Thinking 等方法。
结论令人尴尬： 没有任何一个候选方案能同时满足这四个公理。
更惊人的是， “输入嵌入（Input Embedding）”往往是更好的基准线。
- 可分性崩塌：在“同任务内区分不同问题”的测试中，除了直接拿输出向量做参考外，所有隐式思考方法的准确率都接近随机基线（~50%）。
例如 Llama-8B 的同任务判别准确率仅 53.9% (LIT) 到 54.7% (ST)，而随机基线是 48.9%。这意味着模型根本分不清它在想“2+2”还是“2+3”，它只知道自己正在做加法。
- 因果性不足：用思考向量替换推理前缀后，KL 散度并没有显著优于直接使用输入嵌入。说明这些向量没有比原始 Prompt 提供额外的因果信息。
- 迭代越多越差：Latent Thinking 等方法增加思考步数（16, 32, 64 steps），其稳定性（DCS）反而下降。
⚠️ 反直觉发现 ：模型在推理基准上得分很高，但其内部表示却发生了“结构性坍塌”。它能答对题，但它的“思维空间”里，所有同类问题的解都混成了一团浆糊。
### 工程启示：别迷信隐式思考这篇论文对正在做 Agent 或优化推理成本的工程师有几个重要提醒：
- 隐式思考目前不可靠：如果你打算用 Latent Thoughts 来压缩 CoT 以节省 Token，小心了。目前的实现（如 Soft Thinking）并没有真正捕捉到推理的逻辑结构，只是学会了“模仿”答案的分布。
- 评估需要解耦：在开发新的推理模块时，不要只看最终 Accuracy。引入类似的“内在评估（Intrinsic Evaluation）”，检查中间表示的可分性和稳定性，能帮你发现那些“侥幸答对”的隐患。
- 输入嵌入可能就够了：在很多情况下，精心设计的 Prompt 嵌入已经包含了足够的信息。强行压缩成更小的向量，往往丢失了关键的细粒度差异。
### 局限与展望作者也承认，目前的候选表示都是从预训练模型中提取的，没有经过专门的监督微调（SFT）来优化这四个公理。未来的方向可能是设计专门的提取头（Extraction Head），显式地以这四大公列为损失函数进行训练。
但在那一天到来之前，对于工程落地而言， 显式的 Chain-of-Thought 虽然啰嗦，但至少在逻辑上是可追溯、可分离的。 隐式思考还停留在“黑盒玄学”阶段，切勿盲目替换。
