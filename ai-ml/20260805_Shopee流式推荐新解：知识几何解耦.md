论文 : Knowledge-Geometry Decoupling: Refreshable Pretrained Transfer for Streaming Recommendation链接 : https://arxiv.org/abs/2608.02738工业界推荐系统正从“单次预训练”转向“持续刷新”。但行为数据分布时刻在变，如何既学到高质量知识，又能在模型每日更新时不破坏下游任务？Shopee 与厦门大学联合提出的 KGD（Knowledge-Geometry Decoupling） 给出了一个极具工程价值的解法：把“知识”和“几何”拆开存。
## 痛点：预训练在流式场景下的“水土不服”
传统推荐模型直接照搬 NLP 的 Next-Token Prediction (NTP)。但在电商里，用户行为是碎片化的（比如先买自行车配件，再买裤子）。
⚠️ 反直觉发现 ：相邻不代表相关。强行让模型预测下一个物品，会把“跨会话”的噪声写进 Embedding，导致几何结构污染。
更麻烦的是 梯度冲突 。预训练学的是行为共现（Collaborative），下游任务（如 CTR）学的是判别边界。两者的优化方向近乎正交（余弦相似度接近 0）。
- 全量微调：任务梯度会覆盖掉预训练的通用知识。
- 冻结参数：任务无法调整几何结构，表现受限。
## 核心 Insight：读写分离与正交残差KGD 的核心逻辑很简单： 让预训练编码器（Encoder）和任务学习者（Task Learner）互不干扰。
### 1. 学什么？BMTP（行为多 Token 预测）
NTP 只看时间相邻，BMTP 只看 语义或协同相关 。
- 过滤噪声：只保留与当前物品在协同图谱或文本语义上相似的未来物品作为监督信号。
- 效果：学到的 Embedding 几何结构更干净，不受无关会话干扰。
### 2. 怎么传？知识-几何解耦这是本文最精彩的设计。KGD 将参数所有权彻底拆分：
- 预训练编码器（只读）：负责提供行为知识，每日刷新，但下游任务无法修改其权重。
- 任务学习者（只写）：通过两个接口读取编码器状态：
ACR（锚定校准残差）：在 Embedding 层叠加一个正交残差。
e_task = s * e_pre + Δe，其中 Δe ⊥ e_pre。
- 为什么正交？ 保证任务学到的判别结构不会“抵消”预训练的行为方向，两者共存于互补空间。
- 只读 Cross-Attention：任务 Transformer 通过 Query 读取编码器的 Hidden States，但 Key/Value 被 stop-gradient 冻结。
这意味着： 编码器可以每天用新数据重新训练（Refresh），而下游任务的几何结构（ACR + Task Transformer）保持稳定，无需重训。

- 正交残差是解决冲突的好手：当预训练目标和任务目标不一致时，不要试图让同一组参数兼顾两者。使用正交约束（Orthogonal Constraint）叠加残差，既能利用通用知识，又能保留任务特异性。
- 刷新与适配必须解耦：在流式数据场景下，“每日刷新编码器” + “稳定任务头” 是最佳实践。通过 stop-gradient 实现单向信息流，能极大降低维护成本，避免灾难性遗忘。
## 局限与展望- 计算开销：KGD 引入了额外的 Task Transformer 和 Cross-Attention，参数量增加约 20%，但延迟控制在可接受范围内。
- 适用范围：主要面向基于行为的序列推荐（Sequential Rec），对于依赖文本理解的 LLM4Rec 场景，BMTP 的语义过滤策略可能需要调整。
KGD 证明了： 好的预训练迁移，不是参数的简单复制，而是几何结构的优雅共存。 这套“读写分离”的设计范式，值得所有面临数据漂移问题的工程师参考。
