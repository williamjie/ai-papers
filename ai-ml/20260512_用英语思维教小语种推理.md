# 用英语思维教小语种推理

**日期**: 2026-05-12

---

论文 : Crosslingual On-Policy Self-Distillation for Multilingual Reasoning链接 : https://arxiv.org/abs/2605.09548大语言模型（LLM）在英语上的数学推理能力已经很强，但一旦切换到斯瓦希里语、豪萨语等低资源语言，性能往往断崖式下跌。慕尼黑大学团队提出的 Crosslingual On-Policy Self-Distillation (COPSD) 解决了一个工程痛点： 如何在没有目标语言高质量推理数据的情况下，让模型用低资源语言进行有效推理？
这篇论文的核心洞察很直接：既然模型在英语上推理很强，那就利用英语作为“特权信息”，通过自蒸馏的方式，把英语的推理逻辑迁移到低资源语言上。
## 为什么现有方案不够用？
提升多语言推理通常有两条路，但都有硬伤：
- 监督微调（Supervised Fine-Tuning, SFT）：把英语推理轨迹翻译到低资源语言。
痛点：机器翻译会引入噪声，数学表达式和逻辑依赖容易出错。更重要的是，翻译出来的轨迹和模型实际生成的轨迹分布不一致（Train-inference distribution mismatch），导致模型学不到东西。
- 基于结果的强化学习（Outcome-based RL）：比如 GRPO，答对给奖励。
痛点：奖励太稀疏。在低资源语言下，模型很难生成正确答案，二元奖励（对/错）无法指导中间步骤该改哪里。样本效率极低，甚至不稳定。
COPSD 试图结合两者的优点：既要有 SFT 的密集反馈，又要有强化学习的策略对齐。
## COPSD 方法拆解：怎么做到“自蒸馏”？
COPSD 的核心是 On-Policy Self-Distillation (OPSD) 的跨语言扩展。它让同一个模型同时扮演“学生”和“老师”，但输入不同。
### 1. 角色分工- 学生（Student）：只看到低资源语言的问题 x(L)x^{(L)}。它必须独立生成推理轨迹。这模拟了推理时的真实场景。
- 老师（Teacher）：看到低资源问题 x(L)x^{(L)}，同时拥有高资源语言（英语）的问题 x(H)x^{(H)} 和参考解 y∗y^*。这些信息作为“特权上下文”，帮助老师生成更高质量的推理分布。
### 2. 训练流程- 采样：学生从低资源问题出发，生成一条推理轨迹 y^(L)\hat{y}^{(L)}^​(L)。
- 评估：老师和学生都基于这条学生生成的轨迹进行评估。
- 蒸馏：最小化学生在每个 token 上的分布与老师分布之间的差异（使用 Reverse KL 散度）。

## 工程启示- 格式遵循的重要性：分析显示，Pass@12 与答案格式遵循率（Format Rate）高度相关（Pearson ρ≈0.8\rho \approx 0.80.8）。低资源语言推理失败，往往不是因为算不对，而是因为模型没能在规定时间内输出正确格式。COPSD 改善了这一点。
- 测试时扩展（Test-Time Scaling）：COPSD 训练的模型在增加推理 Token 预算时，性能提升更稳定。例如 Qwen3-8B 在 1024 到 4096 Token 下，COPSD 提升 30%，而 GRPO 仅提升 13.8%。这意味着 COPSD 让模型更擅长利用长推理。
- 减少重复：COPSD 显著降低了 n-gram 重复率，避免了多语言推理中常见的“车轱辘话”死循环。
## 局限与展望- 依赖英语：目前假设英语是高质量特权语言。如果英语数据不可用，效果可能打折。
- 教师信号饱和：当模型在目标语言非常弱时，即使有英语辅助，教师生成的分布也可能不够完美，导致训练后期过拟合或性能下降。
- 翻译噪声：虽然不用翻译推理轨迹，但问题本身的翻译仍有噪声。
总的来说，COPSD 提供了一种无需目标语言推理标注，即可提升多语言推理能力的有效路径。对于需要部署多语言 Agent 的工程团队，这是一个值得尝试的低成本优化方案。
