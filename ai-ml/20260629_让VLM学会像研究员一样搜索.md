# ⭐⭐⭐⭐ 让 VLM 学会像研究员一样搜索

**日期**: 2026-06-29

---

论文 : ProMSA:Progressive Multimodal Search Agents for Knowledge-Based Visual Question Answering链接 : https://arxiv.org/abs/2606.27974KB-VQA（基于知识的视觉问答）一直是多模态大模型的短板，因为模型很难在“看图”和“查资料”之间灵活切换。OPPO 联合清华大学提出的 ProMSA 提供了一个极具工程参考价值的思路：把检索过程从固定的 RAG 管道，重构为具有显式预算约束的强化学习（Reinforcement Learning, RL）代理。
### 为什么固定 RAG 搞不定长尾实体？
现有的 KB-VQA 方案大多遵循“检索-重排-生成”的静态流程。这种设计在常见实体上表现尚可，但在面对长尾分布时存在致命缺陷：
- 缺乏适应性：模型无法根据当前推理状态决定是否需要检索，或者该用图像还是文本检索。
- 无法自我纠错：如果第一步图像检索错了（比如把 A 湖认成 B 湖），固定管道会强行基于错误证据生成答案，没有机制让模型“回头重查”。
- 多跳推理困难：静态 Top-K 注入无法支持逐步填补事实链条的需求。
ProMSA 的核心直觉是：KB-VQA 应该被建模为一个 带预算的渐进式搜索与推理问题 。模型需要像研究员一样，在不确定时检索，证据不足时继续搜索，证据充足时停止并回答。
### 方法拆解：从格式学习到策略优化ProMSA 的训练分为两个阶段，这种“冷启动 + RL”的路径非常务实。
1. 拒绝采样 SFT（Cold Start）
直接对 Agent 进行 RL 训练极不稳定，因为早期探索空间大，容易因格式错误导致零奖励。作者首先通过拒绝采样构建一个小规模数据集：
- 从初始策略采样轨迹。
- 仅保留满足三个条件的轨迹：工具调用格式有效、可执行、最终答案正确。
- 用这些数据做监督微调（Supervised Fine-Tuning, SFT），让模型先学会“怎么正确地调用工具”。
2. TN-GSPO：解决序列长度偏差这是本文最大的技术亮点。标准的序列级策略优化（如 GSPO）通常只按生成 token 数量归一化更新幅度。但在 Agent 场景中，轨迹难度主要取决于 工具交互深度 。如果只按文本长度归一化，模型会倾向于输出更短的文本以获得更稳定的梯度信号，从而产生长度偏差。
作者提出了 Tool-Normalized GSPO (TN-GSPO) ，将归一化因子 D(τ)D(\tau) 定义为：
D(τ)=L(τ)(1+c⋅H(τ)α)D(\tau) = L(\tau) \big(1 + c \cdot H(\tau)^{\alpha}\big) L ( τ ) ( 1 + c ⋅ H ( τ ) α )
其中 L(τ)L(\tau) 是生成 token 数， H(τ)H(\tau) 是工具交互深度。这意味着更新规模同时取决于文本长度和决策深度，更好地匹配了预算搜索的结构，使学习过���更稳定。
### 关键结果：精度与效率的平衡在 E-VQA 和 InfoSeek 基准测试上，ProMSA 展现了显著优势。以下是基于 Qwen2.5-VL-7B 的核心对比数据（E-VQA All 指标）：
方法类型 代表模型 E-VQA Accuracy Zero-shot MLLM Qwen3-VL-8B 25.3% Search-Agent MMSearch-R1 40.6% RAG Pipeline REAL 45.5% ProMSA (Ours) Qwen2.5-VL-7B 49.7%⚠️ 反直觉发现 ：增加检索 Top-K 或工具调用预算并不总是带来收益。实验显示，当 Image Search 和 Text Search 各限制 3 次时效果最佳（E-VQA 52.6%）。进一步增加到 4 次反而导致精度微降（52.4%），原因是引入了更多噪声，增加了证据压缩和推理的难度。
此外，ProMSA 在 OK-VQA 上也达到了 82.7% 的准确率，优于 Wiki-PRE-7B (77.8%)，证明了其泛化能力。
### 工程启示- RL 是 Agent 进化的必经之路：SFT 只能让模型学会“格式”，而 RL（特别是带有显式成本惩罚的奖励函数）能让模型学会“权衡”。ProMSA 在奖励中引入了工具成本项 C(τ)C(\tau)，迫使模型在有限预算内最大化信息增益。
- 去重机制至关重要：ProMSA 维护了一个已访问页面集合 Pt\mathcal{P}_t​，并在每次检索时作为排除列表传入。这防止了模型在错误路径上重复打转，是解决“漂移”问题的低成本有效手段。
- 摘要即观察：直接注入原始网页内容会导致上下文爆炸。ProMSA 使用 Qwen3-VL-8B 对检索结果进行问题相关的短摘要压缩，这不仅节省了 Token，还起到了初步的信息过滤作用。
### 局限与展望尽管 ProMSA 效果显著，但其推理时间（1.8秒/样本）略高于传统 RAG（1.2秒/样本）。对于实时性要求极高的场景，这种多轮交互的延迟仍需优化。此外，模型在第二轮检索后仍有一定比例（43.8%）在错误检索后停止，说明其对证据可信度的判断仍有提升空间。
ProMSA 证明了，通过精心设计的 RL 目标和渐进式搜索架构，我们可以让 VLM 从“被动接收信息”转变为“主动探索知识”，这是构建真正智能多模态 Agent 的关键一步。
