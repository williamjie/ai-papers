# ⭐⭐⭐½ 长视频生成加速：免训练的稀疏注意力方案

**日期**: 2026-06-02

论文 : LVSA: Training-Free Sparse Attention for Long Video Diffusion链接 : https://arxiv.org/abs/2605.31057做长视频生成的同学，肯定被两个问题折磨过：显存爆炸和画面“冻结”。这篇来自华为的研究提出了一种无需重新训练（Training-Free）的稀疏注意力机制 LVSA，不仅把推理速度提升了 3 倍，还意外解决了长序列下的质量崩塌问题。对于想要低成本部署 Wan 或 HunyuanVideo 等模型的工程师来说，这是一个极具落地价值的方案。
### 痛点：稠密注意力的双杀视频扩散模型（Video DiTs）如 Wan 2.1 和 HunyuanVideo 虽然画质惊艳，但其核心瓶颈在于自注意力机制的计算复杂度随序列长度呈二次方增长。
- 算力与显存墙：在 14B 参数规模下，生成长视频时 KV Cache 极易突破 80GB GPU 的极限。例如 HunyuanVideo 1.5 在生成 257 帧（2× 训练长度）时，稠密注意力直接 OOM（Out-Of-Memory）。
- 质量崩塌：超过训练 horizon（如 Wan 的 81 帧），模型倾向于输出静态或重复的画面。这是因为稠密注意力在全局范围内过度平滑了特征，导致运动信息丢失，生成“假”的一致性。
现有方案要么需要昂贵的重新训练，要么像 RIFLEx 那样只改 RoPE 频率而不减少计算量，无法从根本上解决算力瓶颈。
### 方法拆解：旋转锚点与动态窗口LVSA 的核心直觉是： 每个帧不需要关注所有帧，但必须关注“关键帧”和“邻近帧” 。它通过两个设计实现了这一点：
-全局锚点 + 局部窗口：
全局集 GG：选取等间隔的关键帧作为全局注意力目标，确保长程依赖不丢失。
- 局部窗 W(t)W(t)：每个帧只关注其前后固定大小的时间窗口，保证细节和运动的连贯性。
- 扩展窗口逻辑：这是工程上的亮点。当局部窗口与全局锚点重叠时，传统方法会浪费注意力预算。LVSA 动态扩展窗口边界，确保每个查询帧实际关注的唯一帧数恒定在目标预算 CC（通常等于训练时的帧数），既不超支也不亏待边缘帧。
-旋转周期性全局帧（Rotating Global Anchors）：
Why? 如果全局锚点固定不变，非锚点帧在多次去噪步骤中会被系统性地“忽视”，导致身份漂移或重复。
- How? LVSA 在每个去噪步骤 ss 移动全局锚点的位置（模运算）。经过 TperT_{per}​ 步后，每一帧都至少充当过一次全局锚点。这消除了固定网格带来的偏差，确保所有帧在长程表示上被平等对待。
⚠️ 反直觉发现 ：通常认为稀疏注意力会损害质量，但 LVSA 在扩展长度下反而比稠密注意力质量更高。因为稠密注意力的“全局平均”效应抑制了运动，而 LVSA 的局部窗口保留了动态变化。

- 质量评估：引入 VQeval 指标专门惩罚循环/静态视频。在 Wan 2.1 1.3B 6× 长度下，稠密注意力的 VQeval 得分从 56.5 跌至 48.2，而 LVSA 保持在 60.2。稠密注意力因为画面变静止，反而在 VBench 的“主体一致性”上得分虚高（0.991 vs 0.917），这是一个典型的评估陷阱。
### 工程启示- 无需微调即可部署：LVSA 是模型无关的插件。你可以直接把它集成到 vLLM-Omni 等推理框架中，无需重新训练任何权重。
- 显存优化首选：对于 HunyuanVideo 这种双流架构（文本参与自注意力），显存压力极大。LVSA 能将峰值显存控制在 60GB 左右，让单卡 80GB GPU 也能跑通 257 帧长视频。
- NPU 支持：论文展示了在 NPU 上的加速效果（Wan 2.1 1.3B 达 3.24×），说明其稀疏模式适合异构硬件加速。
### 局限与展望LVSA 目前主要针对单场景视频生成。多场景切换可能需要更复杂的注意力掩码设计。此外，虽然 VQeval 能更好反映动态质量，但行业标准仍主要看 VBench，这需要社区进一步推广对“动态一致性”的重视。
