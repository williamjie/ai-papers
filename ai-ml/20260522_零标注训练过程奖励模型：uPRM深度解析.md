# ⭐⭐⭐⭐ 零标注训练过程奖励模型：uPRM深度解析

**日期**: 2026-05-22

论文 : Unsupervised Process Reward Models链接 : https://arxiv.org/abs/2605.10158在强化学习（Reinforcement Learning, RL）对齐大语言模型的过程中，过程奖励模型（Process Reward Model, PRM）是提升推理能力的关键组件。然而，PRM 的训练长期受制于一个昂贵的瓶颈：需要人工对每一步推理进行细粒度标注。这篇来自 EPFL 的论文提出了一种完全无监督的 PRM 训练方法（uPRM），无需任何步骤级标注，甚至不需要最终答案的真值验证，却能达到与监督式 PRM 相当的效果。对于想要低成本构建高质量推理模型的工程师来说，这是一个极具吸引力的突破。
### 痛点：昂贵的“步骤级”监督目前的奖励模型主要分为两类：结果奖励模型（ORM）和过程奖励模型（PRM）。ORM 只给最终答案打分，信号稀疏且容易误导模型（例如模型瞎蒙出了正确答案，却得到了正向反馈）。PRM 则对每一步推理打分，能提供密集的监督信号，显著提升了测试时扩展（Test-Time Scaling, TTS）和 RL 训练的效果。
但 PRM 的代价极高。现有的自动化标注方法（如 Math-Shepherd）通常依赖蒙特卡洛模拟或最终答案的真值进行信用分配，这不仅计算量大，而且依然依赖于“知道正确答案”这一前提。在开放域或复杂推理场景中，获取这些真值往往不现实。
### 核心 Insight：利用 LLM 的隐式判断力uPRM 的核心直觉非常巧妙： 预训练的大语言模型（LLM）本身就已经内嵌了对逻辑正确性的某种“直觉”，我们可以通过挖掘其下一个 token 的概率分布来提取这种信号。
具体实现分为两步：
-构建评分函数：
作者没有让 LLM 生成显式的判断文本，而是构造了一种特殊的序列格式。对于一条推理轨迹，假设第 jj 步是第一个错误步骤，他们将前 j−1j-11 步标记为 +（正确），第 jj 步标记为 -（错误）。
s(τ,j)=[x,y1,+,…,yj−1,+,yj,−]s(\tau, j) = [x, y_1, +, \dots, y_{j-1}, +, y_j, -][x,y1​,+,…,yj−1​,+,yj​,−]然后，提取 LLM 在这些标记位置生成 + 或 - 的下一个 token 概率。通过计算这些对数概率的和，定义了一个评分函数 S(j;s)S(j; s)，用于衡量某个位置作为“第一个错误步骤”的可能性。
-批量联合评估（Joint Scoring）：
这是提升信号质量的关键。单独评估一条轨迹时，LLM 的判断可能不稳定。作者利用 LLM 的上下文学习能力（In-Context Learning），将多条轨迹及其候选错误位置拼接在一起，让 LLM 在上下文中相互参照进行评分。这种“群体投票”式的机制显著提高了评分的可靠性。
最后，使用强化学习优化一个小的 PRM 模型，使其预测分布尽可能拟合这个由大模型生成的联合评分信号。整个过程完全不需要人工标注。
### 关键结果：不输监督模型论文在三个维度验证了 uPRM 的有效性，数据表现令人印象深刻：
1. 错误定位能力（ProcessBench）
在识别第一个错误步骤的任务上，uPRM 相比基础的 LLM-as-a-Judge 基线有显著提升，尤其是在高难度数据集上：
数据集 LLM-as-a-Judge F1 uPRM F1 提升幅度 GSM8K 49.8% 58.3% +8.5% MATH 42.8% 52.6% +9.8% OlympiadBench 29.4% 42.7% +13.3% Omni-MATH 26.6% 39.8% +13.2%可以看出，在推理越复杂的场景下，uPRM 的收益越大。
2. 测试时扩展（Test-Time Scaling）
在使用 uPRM 进行 Best-of-N 采样时，其表现与多个知名的监督式 PRM 相当：
PRM 模型类型 MATH-500 MinervaMath OlympiadBench Avg. Math-Shepherd-PRM-7B (监督) 86.8% 47.3% 47.1% 60.4% Skywork-PRM-7B (监督) 87.4% 46.6% 48.4% 60.8% uPRM (无监督) 86.5% 46.7% 47.1% 60.1%尽管 uPRM 是完全无监督训练的，其平均准确率达到了 60.1%，与使用专家标注训练的模型差距极小。此外，在 Llama-3.2-1B-Instruct 上，结合 DVTS 采样策略，uPRM 比多数投票基线提升了 6.9% 。
3. 强化学习训练中的鲁棒性这是 uPRM 最意外的优势。在使用 PRM 进行 RL 微调时，监督式 PRM（sPRM）极易发生奖励黑客（Reward Hacking），导致模型崩溃。而 uPRM 表现出更强的鲁棒性：
- Qwen2.5-Math-1.5B：使用 uPRM 训练后，在三个基准测试上的平均准确率比使用可验证结果奖励（VR）提升了 4%。
- 抗黑客能力：sPRM 在训练初期往往迅速崩溃，而 uPRM 能够支持更长时间的政策优化，且最终性能更优。
### 工程启示- 降低数据门槛：如果你没有预算去标注步骤级的推理数据，uPRM 提供了一条可行的路径。只需利用现有的未标注推理轨迹，配合一个足够强大的基础模型（如 Qwen2.5-14B）作为评分器，即可训练出实用的 PRM。
- RL 训练更稳定：如果你的 RL 训练经常遇到奖励黑客问题，尝试使用这种基于概率分布蒸馏的无监督 PRM，可能会比直接使用 SFT 训练的 PRM 更稳健。
- 计算成本可控：虽然训练涉及联合评分，但作者指出在 8 张 H200 GPU 上，uPRM 的训练时间仅比监督式 SFT 多约 1.25 小时（5.5h vs 4.25h）。相比于人工标注的成本，这点计算开销几乎可以忽略不计。
### 局限与展望uPRM 的效果依赖于基础评分模型的能力。如果基础模型的上下文窗口不够长或推理能力不足，联合评分的效果会大打折扣。此外，虽然 uPRM 在下游任务中表现优异，但在纯错误定位指标上仍略逊于顶级监督模型。未来的方向可能包括解耦评分模型与 PRM 骨干网络，利用更强的模型提供信号，同时保持最终部署模型的轻量化。

亮点：
