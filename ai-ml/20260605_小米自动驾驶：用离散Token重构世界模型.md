论文 : Discrete-WAM: Unified Discrete Vision-Action Token Editing for World-Policy Learning链接 : https://arxiv.org/abs/2606.05645端到端自动驾驶正陷入“黑盒困境”：模型能跑，但很难解释为什么这么跑。小米汽车最新提出的 Discrete-WAM 试图打破僵局，它不再把视觉和控制当作两个独立的连续向量处理，而是将它们统一编码为 离散 Token 。这种设计让模型不仅能预测未来，还能像编辑文本一样“修改”驾驶决策，实现真正的反事实推理。
### 为什么现有方案不够好？
目前的端到端（End-to-End, E2E）自动驾驶主要依赖两种路径：
- 直接映射：通过行为克隆（Behavior Cloning）建立从图像到动作的统计关联。这就像背题库，缺乏对物理世界的因果理解。
- 连续潜在空间：使用连续扩散模型生成轨迹。虽然平滑，但表示高度纠缠，难以进行组合式推理。
⚠️ 核心痛点 ：在连续空间中，你很难区分“稍微向左打轮”和“变道到左侧车道”这两个截然不同的语义单元。缺乏明确的语义边界，导致模型无法可靠地比较不同未来的后果。
Discrete-WAM 的核心 Insight 是： 离散表示天然具有组合语义 。通过将视觉观测、自车动作和未来状态映射到同一个对齐的离散词汇表中，模型可以像处理语言一样处理驾驶决策，实现跨模态的结构化推理。
### 方法拆解：统一离散空间与分层策略Discrete-WAM 的架构设计非常巧妙，主要包含三个关键创新：
1. 动作的软量化（Soft Quantization）
传统方法将连续轨迹硬编码为离散索引，会引入巨大的量化误差。Discrete-WAM 采用了一种基于加速度的网格词汇表。
- 做法：计算自车中心的纵向和横向加速度，构建 Nx×NyN_x \times N_y​×Ny​ 的网格。
- 创新：不使用硬分配（Hard Assignment），而是使用软标签插值。连续加速度向量被表示为周围四个网格原型的加权分布。
- 好处：训练时优化交叉熵损失，推理时通过加权求和精确还原连续加速度。这消除了确定性量化误差，保留了物理一致性。
2. 统一的世界-策略建模（Unified World-Policy Modeling）
模型在一个 Transformer 骨干网络上同时处理三种任务：
- 世界建模：给定动作，预测未来视觉 Token。
- 策略建模：给定场景，预测高层决策骨架，再生成具体动作 Token。
- 联合建模：同时预测动作和视觉，捕捉“动作如何改变世界”的因果联系。
这种统一框架避免了传统方法中预测模块和规划模块割裂的问题，实现了状态、动作和未来的对齐。
3. 分层决策与迭代编辑为了防止多模态决策崩溃（例如在“保持车道”和“变道”之间犹豫不决），Discrete-WAM 引入了 高层决策骨架（Decision Skeleton） 。
- 高层：预测稀疏的决策意图（如目标车道、速度趋势）。
- 底层：在决策条件下，通过离散扩散生成平滑的动作序列。
- 理论支撑：论文证明，引入决策骨架能显著降低动作 Token 之间的残差相关性，使模型更专注于局部修正而非全局重构。
### 关键结果：性能与可控性的双赢在 NAVSIM-v2 基准测试上，Discrete-WAM 展现了强大的竞争力，尤其是在安全指标和生成质量上。

- 可控性：得益于离散 Token 编辑机制，模型支持反事实推理。你可以“编辑”某个决策 Token（如将“直行”改为“左转”），并观察模型如何生成相应的视觉未来和动作轨迹，这在连续潜空间中几乎无法实现。
### 工程启示与局限对工程师的价值：
- 调试友好：离散 Token 是可解释的。你可以检查模型在哪些 Token 上置信度低，从而定位感知或规划的薄弱环节。
- 模块化潜力：统一的 Token 接口意味着视觉编码器、动作解码器和策略头可以解耦开发，便于后续针对特定场景进行微调（LoRA）。
- 安全兜底：分层决策结构允许在高层插入规则约束（如禁止闯红灯），而底层负责平滑执行，比纯端到端黑盒更安全。
局限与展望：
- 计算开销：离散扩散过程需要多轮迭代编辑，推理延迟可能高于直接回归模型。
- 词汇表大小：加速度的网格划分粒度直接影响精度和效率，需仔细权衡。
- 泛化能力：虽然论文展示了良好的基准表现，但在极端长尾场景（Corner Cases）下的鲁棒性仍需大规模路测验证。
Discrete-WAM 代表了自动驾驶从“拟合数据”向“理解世界”迈进的重要一步。它证明了离散表示在复杂时序决策中的巨大潜力，为构建可解释、可控的具身智能提供了新范式。
