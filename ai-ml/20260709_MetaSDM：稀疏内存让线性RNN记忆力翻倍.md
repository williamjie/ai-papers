论文 : Sparse Delta Memory: Scaling the State of Linear RNNs through Sparsity链接 : https://arxiv.org/abs/2607.07386Linear RNN（如 Mamba、GDN）推理快，但“记性”差。Meta 这篇论文用稀疏化手段把记忆容量拉高了三个数量级，在同等算力下，长文本召回能力直接碾压 Transformer。
### 为什么线性 RNN 总是“失忆”？
Transformer 的 KV Cache 随序列长度线性增长，吃显存如虎。Linear RNN 为了省显存，强行把历史信息压缩进固定大小的隐状态（Hidden State）。
这就导致了一个死结：状态太小，装不下长上下文；强行增大状态，计算量（FLOPs）随之爆炸，推理速度优势归零。
Meta 团队发现，Gated DeltaNet (GDN) 的更新规则其实可以“稀疏化”。他们提出了 Sparse Delta Memory (SDM) ，核心直觉是： 不需要每个 Token 都去更新整个巨大的记忆矩阵，只需动态读写最相关的几个槽位。
### 方法拆解：用 PKM 换大内存SDM 的设计非常巧妙，它保留了 GDN 的门控机制，但把底层的密集矩阵替换成了 Product-Key Memory (PKM) 风格的稀疏显式内存。
- 稀疏寻址：利用 PKM 的外积特性，模型只需计算两个小向量的外和，就能从数百万个记忆槽位中高效选出 Top-K 个相关索引。
- 动态读写：每个 Token 只写入 WW 个槽位，读取 RR 个槽位。未选中的槽位保持不变。
- 算力守恒：通过调整 WW 和 RR，SDM 可以在保持与 GDN 相同 FLOPs 的前提下，将记忆容量扩大上千倍。
关键 Insight ：记忆容量（State Size）是长上下文性能的根本瓶颈。只要能用稀疏操作低成本访问大内存，Linear RNN 就能兼顾速度与回忆能力。
此外，SDM 允许初始化状态 M0M_0 ​ 可学习。这意味着模型不仅能记住上下文，还能在预训练阶段把“常识”存进这块大内存里，推理时直接复用，无需额外计算开销。
### 实验结果：不仅是快，更是强Meta 在 1.4B 和 8B 规模上进行了严格对比（Iso-FLOP 约束）。数据不会撒谎：

- 短文本也受益：得益于可学习的初始状态 M0M_0​，SDM 在常识推理（如 MMLU、GSM8K）上也优于 GDN。8B 模型上，SDM 的平均准确率甚至超过了 Full Attention 基线。
- 扩展性极佳：Scaling Law 显示，随着计算量增加，SDM 的损失下降曲线始终低于 GDN，且在 8B 规模下预测损失更低。
### 工程启示与局限这对我们有什么实际意义？
- Agent 的长期记忆：SDM 固定大小的状态使其非常适合需要维持长时间交互的 Agent 场景。它不需要像 Transformer 那样随着对话变长而无限膨胀显存。
- 代码与长文档处理：在百万 Token 级别的代码库或长文档检索中，SDM 的困惑度（Perplexity）显著低于 Mamba2 和 GDN，尤其在序列后半段优势明显。
⚠️ 注意性能瓶颈 ：目前 SDM 的主要短板是 内存带宽 。
由于记忆矩阵巨大（8B 模型状态约为 7.9GB），无法完全放入 GPU SRAM，必须访问较慢的 HBM。这导致当前实现的 MFU（模型浮点运算利用率）远低于优化良好的 GDN。在 8B 规模下，SDM 的训练吞吐量比 GDN 慢约 1.49x 。
### 总结SDM 证明了“稀疏化”是突破 Linear RNN 记忆瓶颈的关键钥匙。虽然当前工程实现受限于内存带宽，但其架构潜力巨大。如果你正在寻找一种既能处理超长上下文、又具备恒定推理成本的模型架构，SDM 是目前最值得关注的方向之一。
