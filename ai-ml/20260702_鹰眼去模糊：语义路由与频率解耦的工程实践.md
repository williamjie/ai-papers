论文 : CogSENet: Blind Image Deblurring with Blur-Conditioned Semantic Routing and Explicit Frequency Fusion链接 : https://arxiv.org/abs/2606.30030传统图像复原往往陷入“像素回归”的陷阱，把去模糊当成简单的映射问题。CogSENet 另辟蹊径，模仿鹰眼视觉系统，将任务重构为 动态、语义对齐的重建过程 。这种设计不仅解决了空间变化模糊的难题，更在保持极低参数量（仅 8.9M）的同时，刷新了多个基准测试的性能上限。
### 痛点：为什么现有方法不够用？
目前的去模糊方案主要面临两个核心矛盾：
- 全局建模与计算成本的权衡：Transformer 能捕捉长距离依赖，但计算开销呈二次方增长；CNN 效率高，却缺乏全局视野，难以处理非均匀模糊。
- 语义感知缺失：现有方法通常对图像特征一视同仁，无法区分“有效纹理”和“模糊伪影”。在真实世界的空间变化模糊中，这种“盲目处理”极易导致细节丢失或噪声放大。
CogSENet 的核心 Insight 在于： 网络需要理解它在修复什么（语义），才能决定如何修复它（频率与物理先验） 。
### 方法拆解：鹰眼机制的工程化落地论文提出了三个关键模块，分别对应鹰眼的不同生理机制，设计逻辑非常清晰：
1. 语义驱动状态空间模块 (SDSSM)：模仿“主动扫视”
传统 SSM 进行均匀的 2D 扫描，效率低下且缺乏重点。SDSSM 引入了**可微分的硬路由（Differentiable Hard Routing）**机制：
- 设计直觉：利用 Gumbel-Softmax 将 Token 动态分组到语义簇中。
- 技术细节：通过排序操作将语义相关的 Token 重新排列成连续序列，再进行选择性扫描。这实现了非因果的全局感知，让网络只关注语义相关的上下文，抑制了错误传播。
2. 双频融合块 (BFFB)：模仿“视网膜分化”
模糊恢复本质上是频率恢复问题。BFFB 显式地将特征解耦：
- 低频分支：使用轻量级 U-Net 结构处理全局结构。
- 高频分支：使用密集卷积增强局部细节。
- 频域细化：引入傅里叶变换进行自适应频谱滤波，抑制伪影。
- 关键设计：通过可学习标量 β\beta 动态平衡小波域和傅里叶域的贡献，确保物理可解释性。
3. 连续模糊场 (CBF) + CLIP 先验：模仿“焦点适应”
这是该论文最具创新性的部分。它摒弃了离散的模糊核估计，转而预测一个 连续的 2D 位移场 。
- 联合调制：在瓶颈层，将 CBF 与冻结的 CLIP 语义嵌入结合。
- 作用机制：通过余弦相似度计算空间注意力图，动态引导网络优先修复严重模糊且具有语义信息的区域，避免在平滑区域过度放大噪声。

### 工程启示- SSM 的语义化改造：SDSSM 展示了如何将 SSM 从“盲目扫描”转变为“语义引导”。在视频理解或长序列处理中，这种基于 Token 分组的扫描策略值得借鉴。
- 频率解耦的必要性：BFFB 证明了显式分离高低频信号对于复原任务的重要性。在处理压缩伪影或噪声时，直接回归往往不如分频处理稳定。
- 冻结大模型的轻量接入：通过冻结 CLIP 提取全局语义，并在瓶颈层进行注意力调制，是一种低成本引入高层先验的有效手段，避免了全量微调的巨大开销。
### 局限与展望论文坦诚指出了方法的边界： 极端运动模糊 会导致语义线索丢失，此时 CLIP 无法提取有效特征，导致注意力图趋于均匀，去模糊效果下降。未来方向包括集成对退化更鲁棒的语义提取器，以及扩展到视频复原领域。
