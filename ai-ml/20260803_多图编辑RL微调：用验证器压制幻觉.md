# ⭐⭐⭐½ 多图编辑RL微调：用验证器压制幻觉

**日期**: 2026-08-03

---

论文 : Evaluation-Verification Reward for Consistent Multi-Reference Image Editing链接 : https://arxiv.org/abs/2607.29025多参考图像编辑（Multi-Reference Image Editing）一直是生成式 AI 的深水区。
现有的统一模型如 Qwen-Image-Edit 虽然能听懂指令，但在处理“把 A 图中的物体无缝融合进 B 图场景”时，往往顾此失彼：要么物体变形，要么光影违和。
这篇论文的核心价值在于，它没有去魔改底层的 Diffusion Transformer（DiT）架构，而是通过强化学习（Reinforcement Learning, RL）引入了一套**“评估-验证”**奖励机制，让开源模型在多图一致性上直接追平了闭源巨头 NanoBanana。
### 痛点：MLLM 当裁判会“瞎编”
在图像编辑领域引入 RL 的关键瓶颈是 Reward Model（奖励模型）。
直接用多模态大语言模型（Multimodal Large Language Models, MLLMs）做零样本评估，面临一个死结：
- 长链推理（Chain-of-Thought, CoT）导致幻觉：让 MLLM 写长篇大论的分析，它容易脱离图像像素，开始“文本自嗨”，产生基于内部先验的虚假判断。
- 短判断缺乏逻辑：如果不让 MLLM 推理，直接打分，它又无法处理多图之间复杂的语义约束（比如物体遮挡关系、透视一致性）。
现有的单图编辑奖励模型（如 EditScore）根本不适用于多图场景，因为它们没受过跨图像关系约束的训练。
### 核心设计：EVR 评估-验证机制作者提出了 Evaluation-Verification Reward (EVR) ，其核心直觉是： 把“打分”和“验真”拆开 。
这套机制包含两个角色，均基于同一个 MLLM（如 Qwen3-VL）：
- Evaluator（评估者）：针对五个维度（参考一致性、场景一致性、视觉和谐度、指令一致性、整体质量），生成 KK 个独立的假设（Rationale + Score）。因为允许短 CoT，它能捕捉到细微的视觉洞察，但也难免混入幻觉。
- Verifier（验证者）：这是关键创新。它不看总分，而是拿着 Evaluator 生成的每一个具体主张（Claim），去图像像素里找证据。如果找不到视觉支撑，直接标记为无效（v=0v=00）。
为什么这么设计？
因为“判断一个具体事实是否在图中存在”比“对复杂图像进行开放式评估”要简单得多，也更具视觉 grounding 能力。通过这种“生成-过滤”机制，EVR 有效压制了 MLLM 的文本诱导偏差。
最终奖励采用几何平均（Geometric Mean）聚合，防止模型在某个维度刷高分而其他维度崩盘（Reward Hacking）。
### 实验结果：小模型也能打大模型论文基于 Qwen-Image-Edit 进行 RL 微调，使用 DiffusionNFT 算法优化。数据来自一个合成的、语义对齐的多图指令数据集（10K 样本）。
关键对比数据（Table 1）：

反直觉发现 ：配备 EVR 验证机制的小模型（8B），其奖励信号可靠性甚至优于未经验证的大模型。这意味着， 推理质量不在于模型参数量，而在于是否有严格的视觉 grounding 约束 。
在人类偏好测试中，该方法对基线模型的胜率高达 67% 。更惊人的是，在 Out-of-Distribution (OOD) 的真实世界数据上，它甚至在一致性和和谐度上超越了 NanoBanana。
### 工程启示- RLHF 不需要改架构：对于成熟的 DiT 模型，通过 LoRA + RL 微调即可显著提升特定能力（如多图一致性），无需重新训练主干网络。
- 奖励模型要“去幻觉”：直接用 MLLM 打分是不可靠的。引入一个独立的“验证步骤”来过滤虚假推理，是提升 Reward Model 信噪比的有效手段。
- 合成数据闭环：论文构建了一个从对象生成到场景匹配再到指令生成的自动化数据管道。这表明，高质量的多图编辑训练数据可以通过程序化方式低成本规模化，不再依赖昂贵的人工标注。
### 局限与展望虽然效果显著，但该方法目前主要验证于 N=2N=2 2 （一物一景）的场景。尽管在 N>2N>2 2 的泛化测试中表现良好，但在极端复杂的多人物、多物体交互场景中，Verifier 的计算开销和推理延迟仍需优化。
此外，EVR 依赖于 MLLM 的视觉识别能力。如果参考物体极其微小或纹理极度复杂，验证者可能会误判。未来结合更细粒度的视觉特征对齐（如 DINOv2 特征匹配）可能进一步提升鲁棒性。
