# ⭐⭐⭐½ 预训练决定上限：RL 强化学习的算力分配法则

**日期**: 2026-07-20

---

论文 : Understanding Reasoning from Pretraining to Post-Training链接 : https://arxiv.org/abs/2607.16097在 LLM 开发中，我们常纠结于算力分配：是花在预训练（Pretraining）上让模型更“聪明”，还是花在 RL 后训练（Post-training）上让它更“会做题”？
这篇来自 NYU 等机构的新论文给出了一个反直觉但极其硬核的答案： 预训练损失直接预测了 RL 的最终性能上限。
如果你还在盲目堆 RL 算力，这篇论文可能帮你省下不少电费。作者没有用昂贵的自然语言大模型做实验，而是选择了一个被低估的“控制变量”实验场——国际象棋（Chess）。
### 为什么选国际象棋？
研究预训练与 RL 的交互很难，因为自然语言的预训练数据太杂乱，且推理过程不可见。
但国际象棋不同：
- 动作空间明确：每一步棋都有标准答案，奖励信号是二元的（对或错）。
- 数据可控：可以精确控制预训练数据的数量和质量（如按 Elo 等级过滤）。
- 推理可见：模型输出的“思考过程”就是具体的走法序列，便于分析策略演变。
作者构建了完整的 LLM 训练流水线：从人类棋局预训练 -> 合成思维链（CoT）监督微调（SFT）-> 基于可验证奖励的 RL。模型规模从 5M 到 1B 参数，覆盖了 36 种预训练-RL 组合。
### 核心发现：联合缩放定律（Joint Scaling Law）
这是本文最工程化的贡献。作者发现， 预训练阶段的性能指标，可以精准预测 RL 阶段的表现。
具体分为两个维度：
- 最终性能由预训练损失决定：在固定 RL 算力下，预训练验证集损失越低，RL 后的 pass@1 得分越高。两者相关性极强（Spearman ρ\rho 从 -0.93 提升至 -0.99）。
- 提升速度由预训练数据量决定：RL 奖励曲线的斜率（即每增加 10 倍 RL 算力带来的性能增益）与预训练 Token 数量呈近似线性正相关。
⚠️ 关键洞察 ：RL 并不是在“无中生有”，它更像是在挖掘预训练模型中已存在的潜力。如果预训练没学好，RL 再努力也推不上去。
### 算力怎么分？Pareto 前沿分析作者绘制了不同总算力下的 Pareto 前沿，揭示了算力分配的最优策略：
- 低算力阶段：预训练是瓶颈。此时增加 RL 算力收益甚微，因为初始化策略太差。应优先保证预训练数据量。
- 高算力阶段：随着总算力增加，最优的 RL 算力占比逐渐上升。例如在 680M 模型中，最优 RL 算力占比从低算力时的 ~5% 上升至 ~28%。
这意味着： 不要一开始就搞 RL。 只有当预训练达到一定阈值，RL 才开始发挥显著作用。
### RL 到底改变了什么？机制分析很多人认为 RL 只是让模型的输出分布更“尖锐”（Sharpening），即把原本概率最高的正确选项概率提得更高。但作者通过细粒度分析发现情况更复杂：
题目难度 RL 的主要行为 效果描述 简单题 放大已有偏好 SFT 阶段模型已经倾向于正确走法，RL 进一步强化了这一趋势。 困难题 尾部发现 (Tail Discovery) SFT 阶段正确走法概率极低（<5%），RL 成功将其提升为高概率选项。
这解释了为什么 RL 能显著提升 pass@1（单次回答准确率），但对 pass@k（多次采样中至少一次正确）的提升有限。因为在简单题上，SFT 模型本来就能靠采样蒙对；RL 的作用是 把那些原本藏在长尾里的正确解法“捞”出来 。
### 工程启示- 监控预训练损失：如果你发现 RL 效果不佳，不要只调 RL 超参。先检查预训练损失是否收敛良好。预训练损失是 RL 性能的强预测因子。
- 动态调整算力预算：在资源有限时，优先投资预训练数据清洗和规模。只有当模型基础能力足够强时，才大规模投入 RL。
- SFT 不能省：实验表明，带有合成思维链的 SFT 能显著提升所有 pass@k 指标。没有好的 SFT 初始化，RL 很难在复杂推理任务上起步。
### 局限与展望虽然结论很有说服力，但国际象棋与自然语言推理仍有差异。作者在数学领域（Math）的 1B 模型上也验证了类似规律：预训练更长的检查点在相同 RL 算力下表现更好，且提升斜率更陡。这增强了结论的普适性，但在开放域对话中的具体表现仍需进一步探索。
总之，这篇论文为“经验时代”（Era of Experience）提供了一张清晰的导航图： 预训练划定天花板，RL 负责逼近它。
## 📝 AI 点评点评时间：2026-07-20 10:05 ｜ reviewer: DeepSeek V4 Flash核心贡献: 该论文通过国际象棋作为受控测试平台，研究了预训练与RL后训练的交互，建立了联合缩放定律（pretraining loss预测post-RL性能水平，pretraining tokens预测RL提升斜率），并揭示了RL在不同难度题目下对策略的不同影响（放大已有正确、发现尾部正确、强化错误模式）。
亮点: 博文准确捕捉了联合缩放定律的核心结论，即预训练损失与RL性能的强相关性，以及算力分配中RL占比随总算力增加而上升的趋势。同时，博文将机制分析提炼为简单题“放大已有偏好”和困难题“尾部发现”的对比，直观地传达了RL在pass@1和pass@k上的差异，工程启示部分（监控预训练损失、动态调整算力预算）也具有实用价值。
挑刺:
- 博文称“预训练损失直接预测了RL的最终性能上限”，但原文明确指出该预测关系是针对固定RL计算量下的pass@1水平（Rref），且采用log-linear局部拟合，并未断言“最终上限”；原文还提到sigmoid渐近线需更长RL训练才能识别，博文将“水平”替换为“上限”属过度解读。
- 博文说“RL奖励曲线的斜率与预训练Token数量呈近似线性正相关”，而原文实际拟合的是与log10 T的线性关系（原文Fig. 3b: “B = -0.1221 + 0.0156 log10 T”，Pearson r=+0.84），遗漏了对数变换，可能误导读者认为斜率随原始Token数线性增长。
- 博文机制分析仅列举了“放大已有偏好”和“尾部发现”，完全遗漏了原文重点讨论的“Wrong-mode amplification”（强化错误模式），原文Fig. 5显示在困难题B5上wrong-mode amplification占比高达15%以上，这一遗漏导致对RL负面效应的描述不完整。
