论文 : Token-Based Dual-view Fusion and Adaptation of Large Vision Models for Breast Cancer Classification链接 : https://arxiv.org/abs/2607.06309在医疗影像分析中，多视角（如乳腺X光的CC和MLO视图）融合一直是个痛点。传统方法往往把特征简单拼接或相加，导致视角间信息纠缠，难以有效利用互补的解剖结构信息。这篇论文提出了一种基于Token的双视角融合框架，不仅提升了分类精度，更提供了一种在冻结大模型下高效进行跨模态/跨视角交互的工程范式。
### 为什么现有方案不够好？
现有的多视角学习通常依赖特征级聚合或单阶段交叉注意力（Cross-Attention）。
主要存在两个工程缺陷：
- 信息纠缠：直接将注意力输出作为残差加到特征上，导致视角特有信息与共享信息混杂，深层网络难以区分。
- 交互受限：多数方法仅在单一网络深度进行融合，无法捕捉不同层级（从浅层纹理到高层语义）的互补关系。
### 核心设计：Token化交互与分层提示作者的核心 Insight 是将“视角间交互”重构为结构化的 Token 级通信，而非直接的特征融合。
1. 深度共享提示学习 (Deep Shared-View Prompt Learning)
- 设计直觉：为了在冻结视觉基础模型（如 MedSigLIP）的同时适应特定任务，作者在多个 Transformer 层注入可学习的 Prompt Token。
- 关键点：CC 和 MLO 视图共用同一组 Prompt Token。这迫使模型在统一的特征空间中对齐两个视角的表示，同时保留预训练知识。
2. 基于 Token 的跨视角融合 (Token-Based Cross-View Fusion)
这是本文最大的创新点。
- 传统做法：Output=Input+Attention(Input,OtherView)Output = Input + Attention(Input, OtherView)Input+Attention(Input,OtherView)。这会导致信息污染。
- 本文做法：
计算双向交叉注意力，提取互补信息。
- 通过平均池化（Mean Pooling）将注意力输出压缩为紧凑的融合 Token (Fusion Token)。
- 将这些 Fusion Token 插入到原始 Token 序列中，作为后续 Transformer 层的输入。
- 优势：Fusion Token 充当了跨视角依赖的“中间载体”。它们被后续层进一步细化，实现了分层的信息传播，同时保持了原始视图结构的独立性。
### 实验数据：效果如何？
在 VinDr-Mammo 和 CMMD 数据集上，该方法展现了显著优势。
1. 与基线对比 (VinDr-Mammo 5类 BI-RADS)
方法 F1-Score (%) AUC Linear Probe (Avg) 38.95 0.7548 Stage 1: Shared Prompt 47.66 0.7887 Stage 2: Fusion Only 47.85 0.7692 Full Framework 50.40 0.8090- 解读：完整框架比线性探测（Linear Probing）的 AUC 提升了近 0.05，F1 提升了 11.45%。这表明 Prompt 适应和显式融合是互补的。
2. 与 SOTA 对比 (VinDr-Mammo 二分类)
方法 F1-Score (%) AUC-ROC DIVF [20] 75.98 0.7486 本文方法 (2 Fusion Blocks) 77.88 0.8593- 解读：相比现有的双视角融合基线 DIVF，本文方法在 AUC 上提升了约 0.11，这是一个非常显著的增益。
3. 消融实验的关键发现⚠️ 反直觉发现 ：在 VinDr-5 任务中，使用专用的 Fusion Token 比残差融合（Residual Fusion）的 F1-Score 高出 5.22% ，AUC 高出 0.0521 。
这证明了“显式保留跨视角信息作为独立 Token”远比“直接相加”有效。
此外，作者发现 Prompt 深度对性能影响巨大。在 MedSigLIP 中，Prompt 深度为 12 时效果最佳，过深（如 20+）反而导致性能下降。这提示我们在工程落地时，需仔细调优注入层数。
### 工程启示对于从事多模态或多视角大模型微调的工程师，本文有几点直接可用的建议：
- 解耦交互信息：在处理多源输入（如图文、多摄像头视频）时，不要急于将特征相加。尝试生成专门的“交互 Token”，让后续层去消化这些跨模态依赖，能避免信息纠缠。
- 分层融合优于单层：在 Transformer 架构中，在不同深度插入多个融合模块，比仅在最后一层融合更能捕捉多层次互补信息。
- Parameter-Efficient Fine-Tuning (PEFT) 的扩展：共享 Prompt 是一种高效的域适应手段。在多视角任务中，共用 Prompt 可以强制模型学习视角不变的特征表示，减少参数量同时提升对齐效果。
### 局限与展望论文主要基于 MedSigLIP 这一特定视觉基础模型，其在其他架构（如 CNN 或不同规模的 ViT）上的泛化能力未做详细验证。此外，Fusion Token 的数量和聚合方式（目前最优为 Mean Pooling）可能因任务而异，需要针对具体场景进行调优。
