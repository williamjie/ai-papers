# ⭐⭐⭐½ 视频深度研究：打破模态偏见的新范式

**日期**: 2026-08-05

论文 : Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent链接 : https://arxiv.org/abs/2608.03979当多模态大模型（VLM）开始处理连续视频流时，我们以为它们已经准备好了。但现实很骨感：现有的 Agent 在面对视频任务时，往往表现出严重的“偷懒”倾向——要么完全依赖内部记忆瞎猜，要么绕过视觉工具直接去搜文本。这篇来自中科大的论文《Video-DeepResearch》直击这一痛点，提出了一套强制模型进行“视觉 grounding + 网页探索”的完整框架，并在最新基准上超越了 Claude-4.5-Sonnet。
### 现有方案的两大致命伤作者在对现有主流模型（如 GPT-5、Qwen3.5）进行初步评估时，发现了两个极具破坏性的现象：
- 严重的模态偏见（Modality Bias）：即使是最强的开源模型 Qwen3.5-397B，每个任务平均只调用 0.10 次视觉工具，却调用了 1.27 次文本搜索。这意味着 Agent 根本不愿意去“看”视频，而是试图通过纯文本捷径解决问题。
- 参数知识泄漏（Parametric Knowledge Leakage）：GPT-5 在几乎不调用任何工具（视觉 0.00，文本 0.12）的情况下，仍能取得 57% 的准确率。这说明现有基准过于简单，模型靠“背诵”训练数据中的世界知识就能蒙对答案，而非真正理解了视频内容。
⚠️ 反直觉发现 ：单纯的模型规模扩大并不能解决 Video-DR 问题。拥有 397B 参数的 Qwen3.5 在工具使用上反而不如经过专门训练的 30B 模型。
### 核心设计：解耦感知与探索为了解决上述问题，Video-DeepResearch 提出了一套“分阶段解锁”的训练范式，其核心 Insight 是： 必须先强迫模型看懂视频，才能让它去搜答案。
具体流程如下：
- 数据合成引擎：通过多阶段过滤（规则+Agent）从海量视频中筛选出高信息量片段。利用 CLIP 和 VLM 提取关键帧、裁剪实体，并生成必须依赖外部知识才能回答的多跳问题。
- 轨迹生成与工具解锁：这是最关键的设计。在训练初期，Agent 的动作空间被限制为仅包含 Select_Keyframe（选择关键帧）和 Crop_Search（裁剪搜索）。它无法直接进行网页搜索，必须先在视频中进行穷尽式的跨帧视觉 grounding。只有当视觉上下文足够丰富或达到最大感知步数时，动作空间才会解锁 Search 和 Visit 等文本工具。
- 两阶段训练：
SFT（监督微调）：使用合成的 7K 高质量轨迹 + 7K 纯文本 QA 数据，让模型学习“先视觉后文本”的思维链。
- GRPO（组相对策略优化）：引入强化学习，通过稀疏奖励（答对得 1，否则得 0）激励模型自主探索更优的工具调用序列，打破模仿学习的性能天花板。
### 关键结果：小模型击败大巨头在提出的 VideoDR-Bench （200 个复杂多跳 VQA 实例）上，Video-DeepResearch 展现了惊人的效果：

- 行为矫正：经过训练的 30B 模型，视觉工具调用频率从基线的 0.10 飙升至 2.33，文本调用也增至 4.24。这表明模型真正学会了“主动视觉探索”，而非被动回忆。
- 消融实验验证：仅使用视频轨迹 SFT 带来 +12.5% 的提升；加入文本数据再提升 +3.8%；最后 RL 阶段进一步提升 +2.5%。每一步都不可或缺。
### 工程启示与局限这篇论文对构建实际可用的多模态 Agent 有重要指导意义：
- 工具使用需要“强制”：不要指望模型天生会平衡多模态输入。通过限制动作空间（Stage-wise Tool Unlocking）来引导行为，比单纯的 Prompt Engineering 更有效。
- RL 是突破瓶颈的关键：SFT 只能让模型模仿正确路径，而 GRPO 能让模型在复杂环境中自主发现更优的探索策略，特别是在需要长程推理的任务中。
- 基准测试必须防作弊：如果一个问题模型不调用工具就能答对，那它就不是一个好的 Agent 评估问题。VideoDR-Bench 通过严格的“无工具正确率过滤”确保了评估的真实性。
当然，该方法仍有局限。例如在新闻类（News）视频上，35B 模型的表现反而不如 30B 模型，且整体提升幅度较小，这可能与新闻视频中动态性强、时序依赖高有关，值得后续深入研究。
总之，Video-DeepResearch 证明了：通过精心设计的数据管道和训练策略，中等规模的开源模型完全可以在复杂的视频深度研究任务上挑战甚至超越顶级闭源模型。
