# ⭐⭐⭐½ DOPD：破解强化学习蒸馏中的特权幻觉

**日期**: 2026-07-01

论文 : DOPD: Dual On-policy Distillation链接 : https://arxiv.org/abs/2606.30626在强化学习（Reinforcement Learning, RL）的浪潮中，On-policy Distillation (OPD) 正在取代传统的监督微调（Supervised Fine-Tuning, SFT），成为提升模型推理和代码能力的核心手段。但大多数工程师忽略了一个致命陷阱：给老师或学生“开小灶”（Privileged Information）并不总能带来线性收益，反而可能引发“特权幻觉”，导致模型崩溃。这篇来自京东探索研究院与 CUHK 的论文 DOPD，给出了极具工程价值的解法。
### 痛点：为什么加了提示词，模型反而变笨了？
在 OPD 中，我们通过学生模型采样轨迹，再让老师模型提供 Token 级别的监督信号。直觉上，如果我们给老师或学生额外的“特权信息”（如解题步骤、视觉标注），性能上限应该更高。
然而，论文揭示了一个反直觉的现象： Privilege Illusion（特权幻觉） 。
当引入特权信息时，老师与学生之间的表现差距被混淆了：
- 能力差距：老师确实更聪明，这部分可以通过蒸馏转移。
- 信息不对称差距：老师看到了学生看不到的“答案”，这部分无法复制，只能模仿结果。
如果盲目地让所有 Token 都去拟合老师的分布，学生会陷入死记硬背特权结果的陷阱。这不仅导致探索能力下降（熵坍塌），还会让模型在脱离特权环境时表现暴跌。现有的 Vanilla OPD 缺乏区分这两种差距的能力，因此难以稳定收敛。
### 核心洞察：动态路由，而非一刀切DOPD 的核心 Insight 非常优雅： 不是所有 Token 都需要同等强度的监督，也不是所有时候都应该听老师的。
作者提出了一个**优势感知双重蒸馏（Advantage-aware Dual Distillation）**机制。它通过计算“特权优势差距”（Privilege Advantage Gap, A），将每个 Token 动态分类，并匹配不同的学习目标：
- 高优势 + 老师自信：这是真正的“能力高地”。老师比学生强且确信，说明这里有可转移的核心逻辑。此时采用全词汇表 JS 散度进行强监督，确保学生吸收深层分布信息。
- 低优势 + 双方自信：这说明任务简单，或者差距仅源于信息差。强行模仿可能导致过拟合特权捷径。此时采用轻量级 Top-K KL 散度，保守地吸收知识。
- 低优势 + 双方不自信：这是模糊地带，老师也不确定。此时不应听老师的，而应使用弱自我正则化（以学生自身的特权版本为锚点），防止策略漂移。
- 高优势 + 学生自信：学生自己觉得没问题，但老师分歧大。这可能是一次有效的探索。此时采用轻量级自我蒸馏，保护学生的探索行为，避免被老师过度约束。
这种设计本质上是在做“信号降噪”：只在该学的时候狠学，在不确定时稳住，在信息不对称时克制。
### 实验结果：全面超越 SOTA论文在 Qwen3-8B -> Qwen3-1.7B 和 Qwen3-VL-8B -> Qwen3-VL-2B 的设定下进行了广泛测试。数据非常硬核：
LLM 场景（Table 1）：
- 平均提升：DOPD 在 8 个基准测试上的平均分达到 51.4，相比 Vanilla OPD (43.9) 提升了 7.5 分。
- 超越老师：在 MATH500 (81.5 vs 86.9)、AIME25 (23.3 vs 20.2) 等推理任务上，DOPD 甚至部分缩小了与老师的巨大差距，并在某些指标上逼近或超越原始学生基线。
- 对比竞品：相比最强的自适应基线 EOPD (46.1)，DOPD 提升了 5.3 分。
VLM 场景（Table 2）：
- 平均提升：DOPD 平均分达到 58.4，相比 Vanilla OPD (52.4) 提升了 6.0 分。
- 视觉理解：在 MMMU-Pro 上从 36.4 提升至 53.9，增幅显著。
⚠️ 关键发现 ：去除高优势 Token 的消融实验显示，性能仅剩 Vanilla OPD 的 50%。这证明了“高优势差距”确实是能力转移的关键信号，而非噪声。
### 工程启示对于正在落地 RLHF 或 OPD 的工程团队，DOPD 提供了三个关键指导：
- 不要迷信特权数据：引入解题步骤或标注时，必须警惕信息不对称带来的过拟合。简单的 KL 散度最小化可能是在教模型“作弊”而非“思考”。
- 动态监督强度：在实现 OPD 时，可以尝试根据 Log-probability 的差距来加权 Loss。对于老师学生都确定的简单 Token，降低权重；对于分歧大的关键决策点，增加权重。
- 自我蒸馏的价值：在不确定性高的区域，利用模型自身的特权版本进行正则化（Self-regularization），比盲目跟随老师更能保持模型的鲁棒性和探索能力。
DOPD 不仅是一个算法改进，更是对“如何有效转移智能”这一本质问题的深刻回应。它证明了，聪明的蒸馏不在于喂得更多，而在于喂得更准。
