# 让大模型自己"思考"：LoopUS后训练框架拆解

**日期**: 2026-05-13

---

论文 : LoopUS: Recasting Pretrained LLMs into Looped Latent Refinement Models链接 : https://arxiv.org/abs/2605.11011在推理扩展（Test-Time Compute, TTC）的大潮中，大多数方案都在往序列长度（Token数量）上堆算力，试图通过”想得更久”来提升逻辑能力。但 LoopUS 提出了一个更优雅的思路： 不改参数，不改架构，只改循环 。它通过后训练（Post-training）将一个标准的预训练 LLM 直接改造为”循环潜空间细化模型”（Looped Latent Refinement Model），在固定参数下通过内部状态的反复打磨来提升推理性能。
### 痛点：直接循环会”漂移”
现有的循环 LLM 方案主要有两类：从头训练递归模型，或者对预训练模型进行破坏性改造。前者成本太高，后者往往因为直接复用中间层导致”隐藏状态漂移”（Hidden-state drift）。
为什么会出现漂移？因为预训练模型的中间层原本是为”单次前向传播”设计的，而不是为了”反复迭代”。如果强行把同一个块循环 B 次，状态会像醉汉走路一样偏离正确的语义空间，最终导致性能下降甚至崩溃。
### 核心拆解：LoopUS 的四大组件LoopUS 的核心 Insight 在于： 预训练模型的隐藏状态演化具有明显的阶段性 。
作者通过 PCA 可视化发现（Figure 1），早期层快速转换词嵌入， 中间层 在一个稳定区域内缓慢演化（Plateau），而 最后层 则急剧指向输出词汇表。基于此，LoopUS 将模型拆解为三部分：
- Encoder（编码器）：一次性处理输入，生成初始隐藏状态 h(0)h^{(0)}。
- Reasoning Block（推理块）：即中间层，作为循环主体，负责反复细化状态。
- Decoder（解码器）：接收最终细化后的状态，生成 logits。
为了让这个循环稳定运行，LoopUS 引入了三个关键技术：
#### 1. 选择性门控（Selective Gate）：防止状态漂移这是 LoopUS 最精彩的设计。它借鉴了 Mamba 中的输入依赖选择性衰减机制。在每次循环中，推理块提出一个更新方向 δ\delta ，但不会直接跳跃过去，而是通过一个门控系数 α\alpha 进行 凸插值 ：
h(b+1)=α(b)⊙M(h(b))+(1−α(b))⊙h(b)h^{(b+1)} = \alpha^{(b)} \odot M(h^{(b)}) + (1 - \alpha^{(b)}) \odot h^{(b)} = α ( b ) ⊙ M ( h ( b ) ) + ( 1 − α ( b ) ) ⊙ h ( b )
其中 α\alpha 由一个可学习的衰减系数控制，始终在 (0, 1) 之间。
直觉上 ：这就像给更新加了阻尼。如果当前状态已经很接近答案， α\alpha 会变小，保留旧状态；如果需要大幅调整， α\alpha 会变大。这种”小步快跑”的阻尼更新，强制状态轨迹向收敛方向移动，避免了无约束跳跃导致的发散。
#### 2. 随机深度监督（Random Deep Supervision）：解决训练爆炸如果对所有 B 层循环进行完整的 BPTT（随时间反向传播），不仅显存爆炸，梯度也极易消失或爆炸。
LoopUS 采用”随机深度监督”：在训练时，虽然展开 B 步，但只对随机采样的 K 个步骤计算梯度，其余步骤 detached（切断梯度流）。
工程意义 ：这极大地降低了显存占用，同时迫使模型学会在任何深度都能保持合理的状态，而不是依赖最后一步的”抢救”。
#### 3. 置信度头（Confidence Head）：自适应早停为了在推理时动态分配算力，LoopUS 增加了一个轻量级的置信度头。在每个循环步骤后，模型预测当前状态是否”足够好”。如果置信度超过阈值 qthq_{th} ​ ，则提前停止循环。
这使得模型在简单问题上快速通过，在复杂问题上多转几圈，实现了 自适应推理 。
### 关键结果：小步快跑，效果显著LoopUS 在多个基准上展示了其有效性，且训练效率极高。

### 工程启示与局限为什么值得工程师关注？
- 即插即用的推理增强：你不需要重新训练整个模型，只需要在现有 checkpoint 上做少量的后训练，就能获得更强的逻辑推理能力，尤其是对 ARC-C、OBQA 等需要多步推理的任务提升明显。
- 显存友好：随机深度监督 + 选择性门控的设计，使得训练长循环变得可行，避免了传统 RNN 训练的痛苦。
- 动态算力分配：置信度早停机制允许在资源受限的边缘设备上，根据问题难度动态调整计算量，平衡延迟与精度。
局限与展望- 任务依赖性：论文指出，LoopUS 在需要”推理细化”的任务（如 ARC-C）上提升大，而在依赖”广博知识检索”的任务（如 MMLU 某些子项）上提升有限甚至持平。这意味着它不是万能药。
- 训练数据敏感：虽然比从头训练省数据，但仍需要一定质量的后训练数据（论文使用 FineWeb-Edu）来学习门控和置信度。
总之，LoopUS 证明了**“深度”可以转化为”循环”**。它没有发明新的架构，而是通过精妙的工程手段，让预训练模型内部的中层”活”了起来，学会了自我修正。对于追求极致推理性价比的团队，这是一个非常值得尝试的后训练策略。
