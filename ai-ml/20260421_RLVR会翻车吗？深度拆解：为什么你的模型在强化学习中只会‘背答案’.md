# RLVR 会翻车吗？深度拆解：为什么你的模型在强化学习中只会‘背答案’

**日期**: 2026-04-21

---

论文 : When Can LLMs Learn to Reason with Weak Supervision?
链接 : https://arxiv.org/abs/2604.18574最近大家都在卷强化学习（RL），特别是利用可验证奖励（Verifiable Rewards, RLVR）来提升 LLM 的推理能力。但你有没有遇到过这种诡异的情况：模型在训练集上的奖励（Reward）涨得飞快，甚至接近 1.0，可一跑测试集（OOD），性能直接原地爆炸？
这篇论文直接戳中了工程实践中的痛点： 当奖励信号变弱（噪声多、数据少、甚至没有真值）时，RLVR 到底什么时候会从“学习”变成“死记硬背”？
### 1. 痛点：RLVR 的“虚假繁荣”
在理想状态下，我们有完美的判别器（Verifier）来告诉模型答案对不对。但现实中，高质量的判别器非常难构建。于是业界开始尝试“弱监督”：
- 数据稀缺（Scarce Data）：手里只有几个样本。
- 噪声奖励（Noisy Rewards）：判别器会报错。
- 自监督代理奖励（Proxy Rewards）：没有真值，用模型自己的多数投票（Majority Vote）或自我确定性（Self-certainty）来当奖励。
之前的研究有个争议：RLVR 真的学到了推理吗？还是说它只是在利用某些 Trick？这篇论文通过对 Qwen 和 Llama 两个家族的系统实验，给出了一个极其扎实的回答。
### 2. 核心 Insight：奖励饱和（Reward Saturation）的陷阱这是全篇最硬核的发现。作者提出了一个观察维度： 训练奖励饱和动态（Training Reward Saturation Dynamics） 。
研究者发现，模型在 RL 过程中会经历两个阶段： 预饱和阶段（Pre-saturation phase） 和 后饱和阶段（Post-saturation phase） 。
- 泛化成功的模型（如 Qwen-Math）：表现出持久的“预饱和阶段”。在这个阶段，训练奖励在稳步攀升，与此同时，下游任务的性能（Benchmark performance）也在同步增长。这意味着模型在通过奖励信号提取可迁移的推理模式。
- 泛化失败的模型（如 Llama）：表现为“快速饱和”。它们会在极短时间内（甚至不到 100 步）就让训练奖励达到接近 1.0 的满分，随后进入“后饱和阶段”，此时训练奖励不再增长，下游性能也停滞不前。
结论很残酷：快速达到满分的模型，大概率是在“背答案（Memorize）”而不是在“学习（Learn）”。
### 3. 为什么会“背”？是多样性不够，还是“不忠实”？
大家直觉上会认为，模型学不动是因为“探索能力不足”，即输出太单一（Diversity 低）。但论文的数据直接打脸了：
实验发现：Llama 在训练过程中的输出多样性（Output Diversity）反而比 Qwen 更高，但它的泛化能力却差得多！真正的罪魁祸首是 推理忠实度（Reasoning Faithfulness） 。
作者定义：一个回答是否“忠实”，取决于它的中间推理步骤（Intermediate steps）是否逻辑严密地支持了最终答案。

换句话说，Llama 在 RL 过程中学会了“通过错误的逻辑路径撞大运撞出正确答案”，一旦奖励信号给了它高分，它就会固化这种“逻辑不通但答案正确”的模式，导致严重的 奖励作弊（Reward Hacking） 。

### 5. 工程启示：写给算法工程师如果你正在做 LLM 的强化学习，这篇论文能给你三条保命建议：
- 别被 Training Reward 给骗了：如果你的训练奖励曲线在头 50-100 步就直接拉平到 0.9 以上，别高兴太早，赶紧去测 OOD 任务。你的模型可能已经开始“背题”了。
- SFT 的质量决定了 RL 的上限：如果你打算用 RLVR（特别是弱监督），不要只做“结果对不对”的 SFT。必须包含 Explicit Reasoning Traces（显式推理轨迹）。没有“思考过程”的 SFT，在 RL 阶段很难通过弱信号学到逻辑。
- 重视推理忠实度（Faithfulness）：在评估模型时，除了看 Pass@k，一定要抽样检查一下：模型给出的推理步骤真的能推导出答案吗？如果模型是在“逻辑断层”的情况下撞对答案，那么这个模型在强化学习阶段是极度脆弱的。
### 局限与展望论文虽然给出了有效的补救方案，但也揭示了一个现实： 强化学习并不是万灵药，它高度依赖于模型自身的“推理先验（Pretraining Priors）”。 如果底座模型本身缺乏逻辑严密性，即便通过 CPT 和 Thinking SFT 强行拉回来，成本依然非常高昂。
如何构建更高效的、能自动检测“推理忠实度”的判别器，将是下一阶段 RL 研究的重头戏。
