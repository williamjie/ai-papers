### 为什么现有方案搞不定长视频？
目前的长视频生成主要面临两个死胡同。
一是 显式记忆（Explicit Memory） 。这类方法依赖 3D 几何重建来维持一致性，但 3D 估计误差会随着时间累积，导致后期画面崩坏。
二是 隐式记忆（Implicit Memory） 。现有的注意力机制要么受限于帧级粒度，无法捕捉细粒度的空间对应关系；要么采用滑动窗口，直接丢弃了长距离的历史信息。
最直观的问题在于 注意力分散（Attention Dispersion） 。当上下文无限增长时，Query 的注意力会被海量历史 Token 稀释。那些真正关键的旧场景信息，其权重被大量无关噪声拉低，导致模型“记不住”之前的细节。
⚠️ 反直觉发现 ：常见的训练免费策略（如机械地衰减远距离 Token 权重）虽然缓解了短期失真，但代价是彻底切断了长程依赖，牺牲了全局一致性。这并非最优解。
### DecMem 的核心 Insight：解耦记忆DecMem 的核心设计哲学非常清晰： 将“全局检索”与“局部锚定”解耦 。它不试图用一个注意力头解决所有问题，而是设计了两个互补模块：
-稀疏全局记忆（Sparse Global Memory, SGM）
设计直觉：不需要对所有历史帧做密集注意力。我们将每帧 latent 划分为多个 Block，通过 Pooling 聚合特征后，进行 Top-K 的稀疏检索。
- 优势：实现了细粒度的长程记忆访问，同时计算复杂度不再随序列长度线性增长。
-锚定局部记忆（Anchored Local Memory, ALM）
设计直觉：相邻帧具有最强的视觉相关性。ALM 严格限制注意力在最近几帧（如 w=8）内滑动。
- 优势：提供一个高置信度的“锚点”，防止注意力分布因长尾噪声而漂移，稳定短期生成的保真度。
最后，通过一个可学习的门控机制（Gating Mechanism），自适应地融合 SGM 的全局一致性和 ALM 的局部细节。

### 工程启示与落地建议对于正在开发长视频 Agent 或交互式世界模型的工程师，DecMem 提供了几个关键指导：
- 不要迷信密集注意力：在长序列场景下，全量 Attention 是计算和质量的灾难。Block-level 的稀疏检索是平衡精度与效率的有效手段。
- 局部锚定不可少：单纯依靠全局检索会导致短期细节模糊。ALM 的设计提醒我们，必须显式保留短期上下文的高权重，以对抗注意力分散。
- 超参数敏感性：论文发现 Top-K 并非越大越好。K=80 时效果最佳，K=100 反而导致 PSNR 和 FID 下降。过多的检索块会稀释有效信号，削弱与局部锚点的互补性。
### 局限与展望尽管 DecMem 实现了分钟级的高一致性生成，但其依赖预训练视频骨干网络（如 HunyuanVideo），且主要在 Minecraft 等结构化环境中验证。在开放世界、非结构化场景中的泛化能力仍需进一步探索。此外，门控机制的自适应融合策略在不同类型动作下的鲁棒性，也是后续优化的方向。
