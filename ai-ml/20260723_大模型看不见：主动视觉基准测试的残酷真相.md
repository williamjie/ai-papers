论文 : An Exam for Active Observers链接 : https://arxiv.org/abs/2607.16165我们总以为多模态大语言模型（MLLMs）已经“看懂”了图片，但 USC 团队最新的 ActiveVision 基准测试给了所有人一记重锤：当前的前沿模型根本不具备人类那种“主动观察”的能力。它们只是在被动地接收一次性的视觉编码，一旦任务需要反复回看、追踪或精细比对，所有花哨的推理技巧都会瞬间失效。
### 为什么现有 Benchmark 骗了我们？
目前的 MLLM 评测大多集中在静态描述或单次问答上。只要模型能把图片转成一段准确的文字描述，它就能在很多榜单上拿高分。但这掩盖了一个致命缺陷： 感知与推理的闭环断裂 。
人类视觉是一个封闭回路：眼睛会根据假设不断调整注视点，反复确认细节。而现在的 MLLM 是一次性编码（One-shot Encoding），图像被压缩成固定的 Token 序列后，模型只能在记忆中进行推理，无法像人一样“回头再看一眼”。这篇论文的核心洞察在于： 如果任务的视觉信息量超过了单次语言描述的无损承载极限，被动观察者必败。
### ActiveVision：让模型无处可逃的设计为了测试这种能力，作者设计了 17 个任务，分为三大认知维度：
- 分布式扫描（Distributed Scanning）：比如数图中有多少个分离的区域。这要求模型必须 exhaustive coverage（全覆盖），不能漏看。
- 顺序遍历（Sequential Traversal）：比如沿着一条曲线追踪经过的点。这需要维持当前位置和方向的记忆，防止在交叉点迷失。
- 视觉属性转移（Visual Attribute Transfer）：比如比对两个区域的轮廓是否完全一致。这要求提取精细特征并在不同区域间进行零误差比对。
关键设计技巧 ：
- 任意位置与形状：不使用网格或标准几何图形，而是通过程序生成随机坐标和傅里叶谐波调制的边界。这意味着没有任何“三角形”、“圆形”等语言捷径可用。
- 照片级真实渲染：先用代码生成精确的几何骨架，再用 GPT-image-2 渲染成带有噪点、纹理的真实照片。这消除了卡通渲染带来的偏差，也模拟了真实应用场景（如卫星图、显微镜图像）的复杂性。
### 残酷的结果：前沿模型全面崩盘实验结果令人震惊。在 85 个测试项中，最强模型 GPT-5.5 (xhigh) 的准确率仅为 10.6% ，且在 17 个任务中有 11 个得分为零。即使是擅长推理和编码的 Claude Fable 5 ，准确率也只有 3.5% 。
相比之下，三名人类参与者的平均准确率为 96.1% ，几乎是最佳模型表现的 9 倍 。

### Agent 救不了场：工具使用的局限性既然看不准，那让模型写代码（如 OpenCV）来处理行不行？作者测试了 Codex 和 Claude Code 等自主编程 Agent。
结果虽然有所提升（Fable 5 Agent 达到 50.6%），但依然远不及人类。更致命的是， 工具在真实纹理上极其脆弱 。
- 工具失效：在计数任务中，颜色掩码被鹅卵石纹理干扰，导致节点识别错误。
- 验证缺失：当代码输出错误结果（如迷宫路径追踪错误）时，Agent 缺乏足够的视觉感知能力去发现并纠正这些错误。它们盲目信任代码输出，因为“看”的能力本身就缺失了。
### 工程启示与未来方向这篇论文对工程实践有明确的警示意义：
- 不要迷信推理深度：对于需要精细视觉交互的任务（如工业质检、医疗影像分析），单纯增加 CoT（Chain-of-Thought）或延长思考时间无法解决根本问题。
- 架构需变革：我们需要从“被动编码”转向“主动感知”架构。未来的模型可能需要显式的感知-动作循环（Perception-Action Loop），允许模型在推理过程中动态请求图像的不同局部视图或进行迭代式特征提取。
- Agent 的边界：在构建视觉 Agent 时，必须意识到代码工具并非万能。如果底层视觉感知不可靠，上层逻辑再完美也会因“垃圾进，垃圾出”而失败。
ActiveVision 揭示了一个被忽视的事实： 看见（Seeing）不仅仅是接收像素，而是一个主动的、迭代的认知过程。 在这一点上，今天的 MLLM 还远未成熟。
