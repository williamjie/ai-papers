# ⭐⭐⭐½ Minecraft探路：MLLM Agent的长程探索有多难？

**日期**: 2026-06-02

---

论文 : MineExplorer: Evaluating Open-World Exploration of MLLM Agents in Minecraft链接 : https://arxiv.org/abs/2605.30931做具身智能（Embodied AI）或游戏 Agent 的朋友，一定对 Minecraft 不陌生。但现有的评测大多像是在“考背诵”——模型靠记住特定合成表就能通关，这真能代表通用探索能力吗？这篇来自美团和上交大的论文提出了 MineExplorer ，试图剥离游戏特有的“死记硬背”，真正测试 MLLM 在动态开放世界中的长程推理与规划能力。
### 痛点：别把“背攻略”当智能现有 Minecraft 基准（如 MCU、Minedojo）存在一个核心缺陷： 领域知识混淆 。
很多任务的成功依赖于 Minecraft 特有的机制（比如特定方块的掉落逻辑），而非通用的物理常识或逻辑推理。这导致评测结果反映的是模型对游戏规则的熟悉度，而非其在开放世界中的感知与决策能力。此外，现有任务多为短视距（Short-horizon）操作，缺乏对隐含多跳依赖（Implicit Multi-hop Dependencies）的考察。
### 方法拆解：如何构建“干净”的探索基准？
MineExplorer 的核心 Insight 在于 解耦通用世界知识与游戏特定知识 ，并引入 多智能体协同合成 流程来保证数据质量。
-知识过滤（Knowledge Filtering）
作者从 3,382 个原子任务中，利用 LLM Judge 筛选出仅依赖 Minecraft 特有先验的任务。最终保留了 1,497 个符合通用常识的原子任务。这一步确保了评测的是“探索能力”而非“游戏攻略记忆”。
-隐含多跳任务构建（Implicit Multi-hop Tasks）
这是该基准的精髓。任务指令并不直接列出所有前置步骤，而是要求 Agent 从环境中推断出隐藏的先决条件。
设计直觉：真正的探索中，目标往往是隐式的。例如，“战斗蜘蛛”隐含了“先制作剑”这一前置任务。
- 难度量化：作者通过潜藏依赖图（Latent Dependency Graph）计算任务难度 d(τ)d(\tau)，公式为 ∥Φ⊤Bτ∥F/∣Vτ∣∣C∣\|\Phi^\top B_\tau\|_F / \sqrt{|V_\tau||C|}Bτ​∥F​/∣Vτ​∣∣C∣​。简单来说，前置路径越长、所需能力维度越杂，任务越难。
-多智能体合成工作流（Multi-Agent Synthesis）
单个 LLM 生成复杂场景容易出错。MineExplorer 采用了一个包含任务选择、场景设计、里程碑设定、专家审计和验证器的多智能体辩论流程。
效果显著：人类评估显示，相比单 Agent 基线，多 Agent 工作流使有效实例率提升了约 30%（从 44.25% 提升至 78.25%），平均质量评分提高了 0.5 分。
### 关键结果：模型在“长程规划”上依然脆弱作者在 MineExplorer 上测试了包括 Claude-Opus-4.6、GPT-5.4、Gemini-3.1-Pro 等在内的顶级 MLLM。结果令人警惕：

- 感知强于推理：大多数模型的感知（Perception）得分远高于推理（Reasoning）。模型能看清眼前有什么，却很难决定下一步该做什么。
- 思维链失效：更大的参数规模或开启“思考模式”（Thinking Mode）并不能稳定提升表现。例如，Qwen-3-VL 的 Thinking 版本并未显著优于 Instruct 版本。这说明在动态环境中，单纯的逻辑推演若不能与视觉 grounding 紧密耦合，价值有限。
- 记忆并非越多越好：实验发现，当历史帧缓冲区从 20 增加到 50 时，性能反而下降。过多的历史信息引入了过时观测，干扰了当前决策。
### 工程启示对于正在开发 Agent 的工程师，这篇论文提供了三个重要信号：
- 评估体系需去偏：如果你的基准测试严重依赖领域特定知识（如 API 文档、游戏机制），你可能高估了模型的通用推理能力。尝试剥离这些“捷径”，考察模型在信息不全时的推断能力。
- 长程规划是硬骨头：当前 SOTA 模型在多跳任务上的成功率断崖式下跌（从 ~78% 降至 ~24%）。这意味着现有的 ReAct 或简单的 CoT 策略不足以支撑复杂开放世界的探索，需要更强大的状态跟踪和计划修正机制。
- 视觉记忆要精简：不要盲目增加上下文窗口。在动态环境中，保持最近、最相关的视觉快照（如 20 帧）比保留长视频流更有效，且能降低 Token 消耗和幻觉风险。
### 局限与展望MineExplorer 仍局限于 Minecraft 环境，无法完全覆盖真实物理世界的多样性。此外，基准主要侧重于评估，未来可进一步作为训练数据，通过强化学习提升 Agent 的长程探索能力。
总之，这篇论文是一记警钟： 我们离真正的“通用开放世界探索”还有很长的路要走。 模型或许能看懂世界，但还远未学会如何在这个世界中持续生存与规划。
