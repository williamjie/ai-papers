# Agent检索新范式：多面评估与互补证据训练

**日期**: 2026-05-07

---

论文 : Rethinking Reasoning-Intensive Retrieval: Evaluating and Advancing Retrievers in Agentic Search Systems链接 : https://arxiv.org/abs/2605.04018在 DeepResearch 等 Agentic Search 系统大行其道的今天，我们往往过于关注 LLM 的推理能力，却忽略了检索器（Retriever）在复杂多步搜索中的真实表现。这篇论文直击痛点：现有的检索评估体系存在严重偏差，且训练数据缺乏对“互补证据”的建模。作者通过构建更精细的基准和训练数据，揭示了静态评估与 Agent 实际表现之间的巨大鸿沟，并给出了切实可行的改进方案。
### 现有方案的痛点：评估失真与训练偏差目前的推理密集型检索（Reasoning-Intensive Retrieval）面临两个核心问题。
首先是 评估的狭隘性 。主流基准如 BRIGHT 仅提供少量“黄金段落”，且通常只评估单次检索的排序质量。这种静态视角忽略了 Agent 在迭代搜索中需要的是 互补的证据组合 ，而非单一的高分文档。如果一个检索器总是返回同一类信息，它在静态指标上可能表现良好，但在 Agent 的多轮搜索中会导致“视角隧道效应”，无法覆盖推理所需的全部侧面。
其次是 训练的单一性 。现有的合成训练数据通常为每个查询只生成一个正样本（Positive），导致模型优化的是“单篇文档相关性”，而非“证据组合的完整性”。这造成了一种假象：模型在单跳检索上很强，但在需要多步推理的复杂场景中，往往无法提供支撑完整论证所需的多样化证据。
### 方法拆解：从“找一篇”到“找一套”
为了解决这些问题，论文提出了两方面的创新： BRIGHT-PRO 基准 和 RTriever-Synth 训练数据 。
1. BRIGHT-PRO：多维度、Agent 感知的评估BRIGHT-PRO 并非简单增加数据量，而是重构了评估逻辑：
- 多面标注（Multi-aspect）：专家将每个查询分解为多个非重叠的推理方面（Reasoning Aspects），并赋予权重。例如，“为什么猫盯着墙看”可能涉及“行为原因”（50%权重）和“健康问题”（20%权重）。
- Agent 协议：除了静态检索，还引入基于 LLM Agent 的迭代搜索协议。评估指标从单纯的 NDCG 扩展到推理完整性（Reasoning Completeness）和效率-质量奖励（AER）。AER 公式为 AER=OQ×e−γ(R−1)AER = OQ \times e^{-\gamma(R-1)}OQ×e−γ(R−1)，其中 OQ 是整体质量，R 是搜索轮数。这迫使模型在追求准确率的同时，尽量减少搜索轮数以节省算力。
2. RTriever-Synth：互补正样本与条件硬负样本训练数据的构造逻辑发生了根本转变：
- 互补正样本：不再为查询生成单一答案，而是先生成完整的专家级回答，再将其分解为 2-3 个非重叠的推理方面。每个方面对应一个独立的“正样本”段落。这使得模型学习到：单个段落只能回答部分问题，只有组合起来才是完整答案。
- 正样本条件硬负样本：生成的负样本在主题上与查询相似，但刻意遗漏了关键的推理方面。这种设计迫使模型区分“看似相关但缺失核心证据”的陷阱，而非仅仅匹配关键词。
基于此，作者使用 LoRA 微调 Qwen3-Embedding-4B，得到了 RTriever-4B 。
### 关键结果：静态指标与 Agent 表现的脱节实验结果令人深思，静态评估强的模型在 Agent 环境中不一定好用，反之亦然。
静态检索表现（Table 2）：
- BGE-Reasoner-8B 以 68.0 的 α\alpha-nDCG@25 得分领先。
- RTriever-4B 得分 55.3，虽低于顶级专用模型，但显著优于通用嵌入模型（如 Qwen3-8B 的 49.5 和 OpenAI text-embedding-3-Large 的 45.8）。

- 训练数据要模拟“组合”：如果你的检索器用于复杂推理，训练数据不应只关注单篇文档的相关性，而应构建“查询-多正样本-负样本”的三元组，强调证据的互补性。
- 混合策略有效：BM25 在 Agent 环境中的表现提示我们，结合语义检索与关键词检索，或者让 LLM 在后续轮次中修正搜索策略，可以弥补单一检索器的不足。
### 局限与展望BRIGHT-PRO 目前仅覆盖了 StackExchange 的七个领域，专家标注成本高昂，限制了数据规模。未来可探索半自动化标注流程以扩展覆盖面。此外，RTriever-Synth 目前仅使用单正样本对比学习，未来可探索多正样本目标或更复杂的负样本课程学习，以进一步提升检索器的推理支持能力。
