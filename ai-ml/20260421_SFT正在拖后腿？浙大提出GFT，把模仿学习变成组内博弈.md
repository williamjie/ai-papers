# SFT 正在拖后腿？浙大提出 GFT，把模仿学习变成组内博弈

**日期**: 2026-04-21

---

论文 : GFT: From Imitation to Reward Fine-Tuning with Unbiased Group Advantages and Dynamic Coefficient Rectification链接 : https://arxiv.org/abs/2604.14258大家都在卷强化学习（Reinforcement Learning, RL）微调，但很多团队发现一个尴尬的现象：先做一轮 SFT（Supervised Fine-Tuning，监督微调）再上 RL，效果反而不如直接上 RL。浙大 OmniAl 组这篇论文，没急着提新模型，而是先给 SFT 做了个”尸检”，然后提出了一个 GFT（Group Fine-Tuning，组微调）方案。
这对我们这种既要 SFT 又要 RL 的工程团队来说，值得细看。
## SFT 的本质：一个被低估的 RL论文最狠的洞察在于，它从训练动力学（Training Dynamics）的角度证明了： SFT 本质上是一种特殊的 RL，但病得不轻。
具体来说，如果把 SFT 的交叉熵损失写成策略梯度的形式，它会暴露出两个致命缺陷：
- 单路径依赖（Single-path Dependency）：SFT 的奖励是极度稀疏的——只有当模型生成的输出 yy 和专家答案 y∗y^* 完全一致时，才给奖励。这意味着模型只能沿着专家那条”独木桥”走，没有其他反馈信号。
- 梯度爆炸（Gradient Explosion）：SFT 的更新权重是逆概率加权 1/πθ(y∣x)1/\pi_\theta(y|x)​(y∣x)。当模型对某个 token 的概率很低时，这个权重会无限增大。结果就是，模型为了拟合专家数据，会机械地死记硬背，导致分布急剧偏移，也就是我们常说的灾难性遗忘（Catastrophic Forgetting）。
这就解释了为什么 SFT 经常导致模型在特定任务上变强，但在通用推理上变傻——因为它把策略分布压得太窄了。
## GFT 的核心：组内对比 + 动态截断既然 SFT 的病根是”太独”和”太猛”，GFT 的药方就是”开放”和”克制”。它由两个核心组件构成：
### 1. 组优势学习（Group Advantage Learning, GAL）
GAL 的核心直觉是： 别只盯着专家答案，搞个群来比一比。
对于每个查询（Query），GFT 构造一个包含 KK 个候选回复的混合组 GxG_x ​ ：
- 专家演示（Expert）：确保方向正确。
- 教师蒸馏（Teacher Distillation）：引入不同推理范式。
- 自生成样本（Self-generated）：提供在线反馈。
然后，它不直接计算损失，而是计算组内的标准化优势（Normalized Advantage）：
A(yk)=R(yk)−μ(Gx)σR(Gx)+ϵA(y_k) = \frac{R(y_k) - \mu(G_x)}{\sigma_R(G_x) + \epsilon} ​ ) = σ R ​ ( G x ​ ) + ϵ R ( y k ​ ) − μ ( G x ​ ) ​这步设计很妙。它把绝对奖励变成了 相对排名 。在一个组里，比平均分高的就是正优势，比平均分低的就是负优势。这样，模型学到的不再是”模仿专家”，而是”在群体中表现得更好”。这保留了早期训练的探索能力，避免了单一路径依赖。
### 2. 动态系数修正（Dynamic Coefficient Rectification, DCR）
GAL 解决了”看哪里”的问题，DCR 解决”怎么走”的问题。
针对 SFT 中逆概率 1/πθ1/\pi_\theta ​ 导致的梯度爆炸，DCR 引入了一个动态阈值 τ\tau （论文中实验发现 τ≈0.7\tau \approx 0.7 0.7 最佳）：
- 当 token 概率 πt≥τ\pi_t \geq \tau​≥τ 时，保持原样，确保知识高效注入。
- 当 πt<τ\pi_t < \tau​<τ 时，使用停止梯度算子截断，防止极端低概率 token 引发梯度爆炸。
这本质上是一种 自适应的梯度截断 。它允许模型在不确定时”保守更新”，在确定时”大胆学习”。
## 关键结果：数据效率与鲁棒性双杀GFT 在多个数学推理基准上进行了测试，结果很有说服力。
1. 数据效率极高GFT 只需要 10k 条训练数据，就能匹配甚至超越使用 100k 数据的基线。以 Qwen2.5-Math-1.5B 为例：

SFT + GFT + GRPO 的组合在 SAT Math 上展现了最平滑的训练动态和最高的性能天花板。
## 工程启示- 别盲目迷信 SFT：如果你的下游计划是 RL 微调，SFT 可能会把策略分布压得太死，导致 RL 初期探索受限。考虑用 GFT 或类似的组内对比方法替代纯 SFT。
- 组内对比是低成本的探索：GAL 不需要额外的奖励模型（Reward Model），只需要对回复进行规则打分（比如数学题的对错），就能生成有价值的对比信号。这在开源场景下极具可操作性。
- 注意组内样本构成：论文消融实验显示，教师蒸馏:自生成样本 = 2:6 时效果最佳。纯专家演示（8:0）效果最差，纯自生成（0:8）也不够稳。保持一定的”噪声”和”多样性”对模型泛化很重要。
## 局限与展望GFT 目前主要在数学推理这种有客观正确答案的任务上验证过。对于开放式生成、创意写作等主观奖励场景，GAL 的组内对比是否依然有效，还有待观察。此外，构建响应组会引入一定的数据准备开销，虽然远低于在线 RL，但在极端轻量级场景下仍需权衡。
总的来说，GFT 提供了一个清晰的思路： 微调不应该只是模仿，而应该是比较。 在 SFT 和 RL 之间，我们完全有更好的选择。
