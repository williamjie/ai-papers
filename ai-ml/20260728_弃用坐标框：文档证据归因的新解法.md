# ⭐⭐⭐ 弃用坐标框：文档证据归因的新解法

**日期**: 2026-07-28

---

论文 : Evidence Attribution in Visual Document Understanding without Coordinates or Region Labels链接 : https://arxiv.org/abs/2607.24651在金融、法律等长文档场景中，模型不仅要给出答案，还得精准指出“证据在哪”。目前主流做法是让视觉语言模型（VLM）输出边界框坐标。但这篇论文揭示了一个反直觉的事实： 这种坐标接口本身可能就是导致幻觉的元凶 。作者提出用“原文引用+检索”替代直接输出坐标，不仅大幅降低了归因幻觉，还无需昂贵的区域标注数据即可进行强化学习训练。
### 为什么坐标接口行不通？
现有的文档理解基准（如 CiteVQA）要求模型输出边界框坐标来标记证据。然而审计发现，即使答案正确，模型引用的区域往往也是错的，这种现象被称为“归因幻觉”（Attribution Hallucination）。
⚠️ 核心洞察 ：这并非模型缺乏定位能力，而是“坐标格式”限制了模型的表达能力。
就像让一个擅长文字描述的人去画精确的几何图形，他可能知道东西在哪，但画不准坐标。
作者对比了两种接口：
- 坐标接口：模型直接生成 [x1, y1, x2, y2] 数值。
- 语言接口：模型输出原文引用（Quote），再由外部检索器将引用匹配到布局解析器划分的语义块上。
### 方法拆解：用“说”代替“画”
该方法的核心直觉是： 利用 VLM 强大的文本生成能力，而非薄弱的坐标预测能力。
- 自然语言证据接口：模型不再输出坐标，而是以 JSON 格式输出答案和若干段原文引用。对于表格或图片，引用其标题或说明文字。
- 全文档语义块检索：使用布局解析器（如 MinerU）将页面划分为段落、表格等语义块。通过多模态编码器将“引用文本”与“图像裁剪块”进行嵌入匹配，利用匈牙利算法解决一对一分配问题。
- 无区域标签的强化学习：传统训练需要人工标注每个证据的坐标，成本极高。作者设计了基于 GRPO 的训练流程，奖励信号仅来自对答案正确性和检索到的图像块的判断，完全不需要区域级监督标签。
### 关键结果：性能翻倍，幻觉减半作者在经过验证的双语 CiteVQA 子集（719 个问题）上，对比了六种开源 VLM（涵盖 Qwen、Gemma 系列，8B-31B 参数）。数据说话，提升显著：

消融实验证实，性能提升主要归功于 语言生成的定位信息 ，而非检索器本身。当仅使用问题作为查询时，召回率远低于使用模型生成的引用；而强制将坐标框“吸附”到最近语义块，召回率依然低下，证明模型在坐标模式下确实丢失了细粒度定位能力。
### 工程启示- 重构 Agent 设计：在构建文档分析 Agent 时，不要强迫 VLM 输出坐标。让模型“引用原文”，再由后处理模块解析位置，能获得更可靠的溯源结果。
- 低成本微调路径：如果你希望提升模型的归因能力，无需收集昂贵的边界框标注数据。利用现有的 QA 对，通过多模态 Judge 提供奖励信号进行强化学习，是一条可行且高效的路径。
- 注意解析器瓶颈：该方法的效果上限受限于布局解析器的质量。如果解析器无法正确切分语义块，检索匹配就会失败。
### 局限与展望该方法目前主要针对单文档场景。对于纯图形证据（无标题或说明的图片），由于无法生成文本引用，该方法暂时失效。此外，检索步骤增加了延迟，且依赖于预计算的文档嵌入缓存。未来方向包括探索端到端的区域定位能力，以及扩展到多文档检索场景。
