# ⭐⭐⭐ 冻结大模型内部状态：UniProbe如何实现低成本幻觉检测

**日期**: 2026-08-17

---

做多模态应用的朋友都知道，LVLM（Large Vision-Language Models）虽然聪明，但“一本正经地胡说八道”是常态。现有的幻觉检测方案要么需要微调整个大模型（成本高、易破坏原能力），要么依赖外部验证器（延迟高、忽略生成过程）。UniProbe 提供了一种新思路： 不动大模型参数，只读它的内部计算痕迹 。
### 痛点：为什么现有方法不够用？
目前主流的检测手段分为三类，各有硬伤：
- 全量微调：如 HaloDet，更新数十亿参数，不仅训练昂贵，还可能让原本正常的模型变得“神经质”。
- 外部验证：如 HalLocalizer，需要额外的视觉语言模型对比图像和文本，完全忽略了大模型是如何生成这些字的。
- 扁平探针：直接读取隐藏状态（Hidden States）或注意力分数做统计。但这丢弃了数据的关键结构——图像是二维网格，文本是一维序列，而注意力连接两者。
UniProbe 的核心 Insight 在于： 幻觉证据分布在异构结构中 。如果你把内部信号拍扁成一个向量，就丢掉了“这个 Token 到底在看图像的哪个角落”以及“它和前面哪个词产生了关联”这些关键信息。
### 方法拆解：图 + ViT + GRU 的交替处理UniProbe 从冻结 LVLM 的中间层提取隐藏状态和注意力矩阵，构建一个有向计算痕迹图（Computational-trace Graph）。
- 节点：包括图像 Patch、查询 Token 和响应 Token。为了轻量化，只保留注意力权重最高的 Top-K 图像 Patch。
- 边：直接由注意力权重定义，表示 Token 之间的依赖关系。
接着，UniProbe 使用三个模块交替处理这个图，每个 Block 包含：
- GNN（图神经网络）：混合跨模态证据。它让响应节点从图像和查询邻居那里“吸取”信息，并区分是“看图像”还是“看问题”。
- ViT（视觉 Transformer）：专门处理图像节点的二维几何结构。因为 GNN 只能处理拓扑关系，无法感知 Patch 在画面中的空间位置。
- BiGRU（双向门控循环单元）：处理响应序列的顺序依赖。捕捉“前文说了什么”对当前 Token 是否幻觉的影响。
这种 交替设计 非常巧妙：GNN 建立关联，ViT 修正空间感知，GRU 修正时序逻辑。三者通过残差连接叠加，让空间、关系和顺序证据在网络深处充分交互。
⚠️ 反直觉发现 ：检测信号并非在最后一层最强。实验显示，GLM-4.1V 的最佳读取层是第 20 层（共 32+ 层），LLaVA-1.5 是第 14 层。靠近输出的层已经特化为“预测下一个词”，反而丢失了“视觉接地”的信息。
### 关键结果：冻结模型打败微调模型UniProbe 在多个基准上刷新了 SOTA，且大模型完全冻结。

此外，UniProbe 支持 流式解码（Streaming Decoding） 。在生成过程中实时检测，如果某个 Token 被标记为幻觉，直接拒绝并重采样。
- 效果：物体幻觉率降低 55%。
- 代价：延迟仅增加 6%（1.06× vanilla）。
- 质量：SPICE 分数不降反升（0.214 -> 0.222），说明模型没有为了“安全”而变得啰嗦或保守。
### 工程启示与局限对工程师的价值：
- 零侵入部署：不需要重新训练大模型，只需训练一个轻量级的 UniProbe 头。适合无法微调的闭源或超大模型（只要有 API 能拿到中间层）。
- 实时性高：1.06x 的延迟开销意味着它可以嵌入到现有的 Agent 循环中，作为 Guardrail 使用。
- 自适应性：论文提出用目标模型自己生成的数据做少量微调（Self-adaptation），可以显著缓解训练集与测试集分布不一致的问题。
局限：
- 需要访问中间层激活值和注意力矩阵，这意味着只能用于开源模型或提供内部状态 API 的服务。
- 每个 Backbone 需要单独训练一个 UniProbe，目前不支持跨模型迁移。
UniProbe 证明了： 大模型的“思维过程”本身就是最好的幻觉检测器 。只要我们能正确地读懂它的结构化痕迹，就能在不改变模型本质的情况下，大幅提升其可靠性。
