# 无需额外奖励：用熵调控做多轮Agent强化学习

**日期**: 2026-05-11

---

论文 : AEM: Adaptive Entropy Modulation for Multi-Turn Agentic Reinforcement Learning链接 : https://arxiv.org/abs/2605.00425多轮强化学习（Agentic RL）现在是大模型落地的核心战场，但“稀疏奖励”这个老问题依然让人头秃。百度和清华联合推出的 AEM 方法，提供了一个非常优雅的视角： 不需要引入过程奖励模型（PRM），也不需要复杂的树搜索，仅靠调整策略本身的熵动态，就能显著改善信用分配（Credit Assignment）。
对于工程师来说，这意味着你可以用极低的算力开销，直接插件式地提升现有 RL 框架（如 GRPO）的效果。
## 为什么现有的“稠密奖励”方案不够好？
在多轮 Agent 场景中，环境只在轨迹结束时给出一个稀疏的结果奖励（Sparse Outcome-only Reward）。这就导致了一个核心痛点： 信用分配模糊 。
现有的解决思路主要有两类，但都有明显缺陷：
- 引入外部监督：如过程奖励模型（Process Reward Models）。这需要额外的标注或训练额外的模型，增加了系统复杂度和推理成本，且容易在不同任务间泛化失败。
- 结构化的内部信号：如 TreeGRPO 或 ATPO。通过构建搜索树来细化信用传播，但在多轮长轨迹中，这种树状结构会导致巨大的计算开销。
- 自监督信号：如 GiGPO。依赖轨迹结构假设，容易产生上下文不一致或分组偏差。
AEM 的核心洞察在于： 策略自身的熵（Entropy）已经包含了信用分配的内在信号。 高熵通常对应探索性决策，低熵对应自信行为。既然环境对完整的“响应（Response）”做出反应，那么我们应该在 响应级别 而非 Token 级别来利用这种不确定性。
## AEM 的核心机制：响应级熵调控AEM（Adaptive Entropy Modulation）是一个无监督、轻量级的插件方法。它不改变基础的 RL 优化器（如 GRPO），而是通过一个**不确定性代理（Uncertainty Proxy）**来重缩放响应级别的 Advantage。
### 1. 理论直觉：熵漂移由“优势”和“ surprisal ”共同决定论文通过信息几何分析证明（Theorem 3.2.2），在自然梯度更新下，响应级熵的漂移方向（Entropy Drift）取决于两个因素的交互：
- 采样响应的优势值 A(a,s)A(a, s)：该响应相对于组内平均水平的优劣。
- 相对 surprisal S(a∣s)−Hresp(s)S(a|s) - H_{resp}(s)Hresp​(s)：该响应的意外程度与其平均意外程度的差值。
简而言之：
- 如果一个好的响应（高优势）也是低 surprisal（符合预期），它应该进一步降低熵（巩固行为）。
- 如果一个坏的响应（低优势）是高 surprisal（意外发生），它应该增加熵（避免过早收敛到错误路径）。
### 2. 工程实现：如何计算 α\alpha？
由于真实的响应级熵难以直接计算，AEM 使用 预测的 Token 级熵之和 作为代理。具体步骤如下：
- 组内归一化：在同一个 Prompt 生成的 KK 个响应组内，计算每个响应长度的归一化平均熵 Hˉi,t\bar{H}_{i,t}ˉi,t​。
- 计算调制系数 αi,t\alpha_{i,t}​：
αi,t=exp⁡(−λH~i,t)∑exp⁡(−λH~j,n)×∣G∣\alpha_{i,t} = \frac{\exp(-\lambda \tilde{H}_{i,t})}{\sum \exp(-\lambda \tilde{H}_{j,n})} \times |G|​=∑exp(−λH~j,n​)exp(−λH~i,t​)​×∣G∣其中 H~\tilde{H}~ 是 min-max 归一化后的熵。
低熵响应（α>1\alpha > 11）：被上采样（Upweight）。这意味着模型被鼓励去重复这些“确定且正确”的行为。
- 高熵响应（α<1\alpha < 11）：被下采样（Downweight）。这意味着模型被鼓励探索其他可能性，或者放弃这些不确定的路径。
### 3. 自适应的探索-利用转换AEM 最精妙的地方在于它的 自适应性 。
- 训练早期：正样本少，负样本多。AEM 会对负样本施加熵增加压力（鼓励探索），防止早期熵坍缩（Entropy Collapse）。
- 训练后期：正样本增多。AEM 会自动转向对正样本施加熵减少压力（促进利用），帮助策略收敛到更优解。

## 工程启示与局限### 为什么值得接入？
- 零额外模型开销：AEM 不需要训练 PRM 或额外的价值网络。它复用了前向传播中计算旧策略 log-probabilities 的过程，额外计算成本仅占 1.1%（见 Figure 6），几乎可以忽略不计。
- 即插即用：只需修改 Advantage 的计算逻辑，即可接入现有的 GRPO、PPO 等框架。
- 缓解熵坍缩：对于长轨迹 Agent，早期熵坍缩是导致训练失败的主因。AEM 通过动态调整，有效保持了探索能力。
### 局限与展望- 超参数敏感：调制温度 λ\lambda 需要针对特定任务调整。论文未给出通用的自动调参策略。
- 组大小依赖：AEM 的效果依赖于组内样本的多样性。如果 KK（每组采样数）过小，归一化后的 α\alpha 可能会受噪声影响剧烈波动（论文提到当组内熵差异小于 0.1 时，α\alpha 置为 1 以避免噪声）。
## 总结AEM 告诉我们，在 Agentic RL 中，我们不需要总是向外寻找更复杂的奖励信号。 策略自身的不确定性分布，就是最丰富的信用分配线索。 对于正在做 Agent RL 的工程师来说，花半小时接入 AEM，可能比去调试一个复杂的 PRM 性价比更高。
