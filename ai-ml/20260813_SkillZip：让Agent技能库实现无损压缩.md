# ⭐⭐⭐½ SkillZip：让 Agent 技能库实现无损压缩

**日期**: 2026-08-13

---

论文 : SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries链接 : https://arxiv.org/abs/2608.05604现在的 LLM Agent 越来越像程序员，需要调用外部工具库（Skill Library）来干活。但有个致命痛点：技能包太大，塞不进上下文窗口；强行压缩又容易丢失执行逻辑，导致 Agent “断片”或报错。
这篇论文提出了 SkillZip ，它不玩虚的文本摘要，而是把技能拆解成可执行的图结构，通过“保合同压缩”实现 3.46 倍 的压缩率，同时保持极高的执行成功率。
### 为什么现有方案不行？
目前的 Agent 技能管理系统存在严重的 粒度错配（Unit Mismatch） ：
- 检索太粗：通常以整个 Skill Package 为单位检索。哪怕你只需要“清洗 CSV”这一小步，系统也会把包含该步骤的整个大技能包加载进来，浪费大量 Token。
- 压缩太糙：现有的文本压缩（Summarization）只保留语义大意，却丢失了前置条件、验证钩子（Verifier Hooks）等关键执行契约。这就像把菜谱摘要成“做红烧肉”，却没写清楚要放多少糖，Agent 根本没法跑。
- 图结构不持久：有些系统在运行时动态构建执行图，但压缩后的库本身仍是文档格式，无法复用已验证的通用逻辑块。
### 核心洞察：把技能当成“可执行代码”而非“文本”
SkillZip 的核心直觉是： 技能不是文章，而是带有输入输出契约（Contract）的程序模块。
为此，它设计了一套四步走的流水线：
-Sec2Graph（结构化拆解）：
不再把技能看作纯文本，而是解析为 Section-Level Procedural Graph。每个节点都有明确的角色标签（如 Intent, Operation, Verifier）。
⚠️ 关键点：它不仅提取操作，还显式记录了“前置条件”和“验证逻辑”。这意味着压缩后的模块依然知道“什么时候能跑”以及“怎么算跑对”。
-MotifZip（保合同压缩）：
这是最硬核的部分。它在图中挖掘重复出现的子图模式（Motifs），但只有满足以下三个条件才会被压缩为宏（Macro）：
接口稳定：输入/输出签名一致。
- 依赖闭合：内部依赖不泄露，外部依赖通过端口暴露。
- 验证可达：每个操作都能追溯到其对应的验证节点。
这种压缩是 可逆的（Reversible） 。宏只是一个指针，需要时能瞬间展开回原始源码，确保执行无误。
-PathHydrate（按需水合）：
推理时，系统根据任务查询，从压缩图中检索最小的、依赖闭合的子图。
如果宏的契约足够满足当前任务，只加载宏名和接口。
- 如果需要细节，才逐步展开宏的内容。
这实现了真正的 最小充分上下文（Smallest Sufficient Executable Context）。
-ReZip（动态维护）：
随着新技能加入或执行轨迹反馈，系统会自动更新宏字典。如果某个宏经常导致验证失败，它会被降级或拆分；如果新技能揭示了通用模式，旧模块会被提升为新宏。
### 实验结果：既省 Token，又强性能在技术类和具身智能基准测试中，SkillZip 表现优异：
指标 数值/对比 说明 压缩率 3.46× 相比原始技能库体积大幅缩减 存储减少 71.0% 活跃存储空间显著降低 依赖保留率 99.2% 几乎无损地保留了执行依赖关系 验证可达性 98.7% 压缩后仍能正确触发验证逻辑 性能提升 +12.2 pts 在 ALFWorld 基准上超越最强基线 SkillDAG更重要的是，它在技能库规模从 200 扩展到 100,000 时，检索鲁棒性依然保持良好，证明了其扩展能力。
### 工程启示- 别再用摘要压缩代码逻辑：对于 Agent 的技能调用，文本相似度不等于执行等价性。必须保留结构化的契约信息（预条件、后置断言）。
- 图数据库是技能管理的未来：将技能拆解为节点和边，能更精细地控制上下文暴露粒度。这比简单的 RAG 向量检索更适合复杂任务规划。
- 可逆压缩是关键：Agent 需要确定性。SkillZip 的“宏”机制允许在紧凑表示和完整源码间无缝切换，兼顾了效率与可靠性。
### 局限与展望虽然 SkillZip 解决了压缩和执行契约的问题，但它依赖于对技能包的初步结构化解析（Sec2Graph）。对于非结构化或模糊的技能描述，解析准确率可能会影响最终效果。此外，宏的构建和维护需要额外的计算开销，在超大规模实时场景下可能需要进一步优化索引策略。
总体而言，SkillZip 为构建大规模、高精度的 Agent 技能库提供了一条可行的工程路径： 用结构换压缩，用契约保执行。
