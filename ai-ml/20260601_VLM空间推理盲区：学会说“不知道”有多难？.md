# ⭐⭐⭐⭐ VLM 空间推理盲区：学会说“不知道”有多难？

**日期**: 2026-06-01

---

论文 : Seeing Isn’t Knowing: Do VLMs Know When Not to Answer Spatial Questions (and Why)?
链接 : https://arxiv.org/abs/2605.30557做具身智能或视觉 Agent 的同学都知道，模型“一本正经胡说八道”是常态。但这篇论文戳破了一个更隐蔽的泡沫：现有 VLM 不仅容易幻觉，甚至 完全不具备对观察局限性的认知 。当视角被遮挡或透视产生误导时，它们不是选择“放弃”，而是强行给出一个自信的错误答案。对于需要安全决策的机器人系统来说，这种过度自信比单纯的错误更致命。
### 现有基准的致命假设目前的空间推理基准（如 SpatialEval）大多默认视觉输入是 充分且可靠 的。模型的任务只是从清晰图像中提取几何关系。
然而，现实世界的 2D 观测本质上是 3D 世界的投影，存在两个天然缺陷：
- 遮挡（Occlusion）：关键物体不可见，信息缺失。
- 透视歧义（Perspective Ambiguity）：近大远小导致几何属性失真，信息误导。
论文指出，当证据不足时，理想行为应是 拒绝回答（Abstain） 或 主动寻求新视角 。但现有评估体系缺乏对这种“不确定性感知”能力的测试。
### Spatial Uncertain：控制变量的压力测试作者构建了 Spatial Uncertain 框架，基于 3D 模拟环境（Holodeck + AI2-THOR），通过严格控制相机位姿和物体布局，制造出两种挑战场景：
- 遮挡注入：在相机与目标间插入物体，造成部分或完全遮挡。
- 透视偏移：将相机靠近物体对中的一侧，利用透视效应制造大小/形状的视觉错觉。
核心设计直觉在于： 同一组空间问题，在清晰视角下可答，在干扰视角下应判为“无法确定” 。这迫使模型必须判断当前观测的可靠性，而非盲目推理。
### 实验结果：主流模型全面翻车作者在 GPT-4o、GPT-5.4、Gemini-3.0-Flash 等 8 款前沿模型上进行了零样本测试。结果令人沮丧：
模型类型 典型表现 (遮挡/透视) 核心问题 开源模型 (Qwen2.5-VL, InternVL3) 准确率 ~48% / ~57% 难以识别不可答情况，强行猜测 闭源模型 (GPT-4o, Gemini-Flash) 准确率 ~48-57% 同样存在过度自信，缺乏统一的不确定性感知具体数据揭示了两个严重现象：
-过度自信（Overconfident Answering）：
在遮挡场景下，平均准确率仅约 30%；在透视歧义下，低于 10%。模型即便面对完全被挡住的物体，也会基于上下文猜测位置，而不是说“我看不到”。
-视角选择能力崩塌：
即使提供多个候选视角让模型选择“哪个视角能看清”，表现也极差。
ViewSel（直接选视角）：GPT-5.4 能达到 70.9%。
- AbstainViewSel（先判断不可答，再选视角）：GPT-5.4 暴跌至 22.6%，Gemini-3.0-Flash 甚至跌至 2.4%。
⚠️ 反直觉发现 ：视觉输入在透视歧义下是“毒药”。
实验显示，当加入视觉输入时，模型识别不可答情况的能力反而大幅下降（GPT-5.4 下降 21.7%，Gemini-3.0-Flash 下降 35.8%）。误导性的视觉线索主动抑制了模型的拒答倾向。
### 工程启示：Prompt 救不了，微调才行面对这种系统性缺陷，作者尝试了两种补救方案，结论对工程师极具指导意义：
-结构化 Prompt 无效且有害：
虽然引导模型先评估可见性能略微提升拒答率（如 GPT-5-mini 从 7.8% 升至 30.4%），但代价是可答问题的准确率显著下降（64.7% → 54.7%）。这表明 Prompt 无法解决根本的认知偏差，只会制造“回答 vs 拒绝”的零和博弈。
-多样化微调是唯一解：
使用 LoRA 对 Qwen2.5-VL-7B 进行微调，结果截然不同：
单一场景微调（仅遮挡或仅透视）：无法泛化，甚至产生负迁移。
- 混合场景微调（LoRA-Mixed）：同时训练遮挡和透视数据，模型在可答准确率（70.3%）和不可答识别率（62.8%-76.9%）上均实现大幅提升。
结论很明确 ：不确定性感知是一种 可学习的技能 ，但必须通过暴露于多样化的歧义信号来习得。单纯依赖基座模型的零样本能力或简单的 Prompt 工程，无法构建可靠的视觉 Agent。
### 局限与展望目前 Spatial Uncertain 主要基于合成数据，真实世界中的光照变化、动态遮挡更为复杂。此外，模型在识别“需要何种视角”方面的表现仍接近随机猜测，说明其对 3D 几何结构的内在理解依然薄弱。
对于正在构建视觉 Agent 的团队，建议不要盲目信任 VLM 的空间推理输出。在关键决策链路中，应引入明确的 不确定性检测模块 ，或通过收集包含遮挡、模糊视角的负样本数据进行针对性微调，让模型学会“知之为知之，不知为不知”。
