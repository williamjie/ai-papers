# 用语言重塑思维：LLM 智能的下一块拼图

**日期**: 2026-05-12

---

论文 : Shaping Schema via Language Representation as the Next Frontier for LLM Intelligence Expanding链接 : https://arxiv.org/abs/2605.09271很多工程师有个误区，觉得 LLM 不行就是模型不够大，或者提示词（Prompt Engineering）写得不够好。但这篇来自港科大、小米、东京大学等机构的新论文直接泼了一盆冷水： 瓶颈不在参数规模，也不在提示词技巧，而在“语言表征”本身。
简单来说，自然语言（Natural Language）就像是一个带宽极低、充满歧义的旧电话线。当你试图用这根线传输复杂的物理定律或逻辑电路时，信息损耗是巨大的。这篇论文的核心观点非常激进且实用： 通过设计更严谨的语言表征（Language Representation），可以直接重塑模型内部的认知架构（Schema），从而在不增加任何参数的情况下，显著提升复杂任务的推理能力。
### 为什么自然语言是瓶颈？
论文引用了维特根斯坦的名言：“我的语言之界限，即我的世界之界限。”
作者指出，自然语言在表达复杂世界时存在巨大的信息鸿沟。例如，一个数值天气模型包含约 101410^{14} 比特的信息，而一段自然语言天气预报仅能承载约 10210^2 比特。这种**表达贫困（Expressive Poverty）**导致 LLM 即使“知道”答案，也无法通过自然语言准确激活和组织相关知识。
为此，论文提出了一个从 Level 0 到 Level 3 的表征设计光谱：
- Level 0 (自然语言基线)：自由文本，充满歧义。
- Level 1 (消除歧义)：结构化字段、规范引用，确保实体精准映射。
- Level 2 (逻辑约束)：形式化语法、逻辑算子、结构化推理链，强制思维路径。
- Level 3 (科学形式化)：代码、数学公式、物理动力学模型，直接构建世界模型。
核心 Insight 在于： 语言不仅仅是沟通工具，它是模型内部“Schema”（知识激活与组织框架）的触发器。 不同的语言结构会激活不同的内部神经元连接模式。
### 核心实验：同一道题，15种问法为了验证这一假设，团队没有做复杂的模型训练，而是设计了一个极其巧妙的对照实验： 逻辑电路模拟任务 。
他们构建了 100 个完全相同的逻辑电路问题，但将其编码为 15 种不同语言表征 （从自然语言到布尔表达式、Lisp 树、Petri 网等）。关键在于，这些表征在语义上是等价的，唯一变量是“语言形式”。
结果令人震惊。使用 Qwen3-32B 模型测试，不同表征下的准确率差异巨大：
语言格式 (Language Format) 准确率 (Accuracy %) 平均耗时 (s) 关键指标 (KOI / KAI) 标准布尔表达式 (Canonical Boolean Expression) 100.00 32.42 0.407 / 0.370 Lisp 树表示法 (Lisp Tree Notation) 93.75 34.34 0.350 / 0.388 自然语言 (Natural Language) 88.75 37.89 0.364 / 0.348 矩阵表示法 (Matrix Representation) 27.50 53.24 0.379 / 0.247 佩特里网 (Petri Net Notation) 13.75 38.16 0.337 / 0.111注：KOI 代表知识组织指数，KAI 代表知识激活指数，越高越好。
数据解读：
- 结构化表征碾压自然语言：标准布尔表达式达到 100% 准确率，而自然语言仅为 88.75%。更关键的是，自然语言不仅准确率低，Token 消耗还最高（Prompt + Completion 约 2300 tokens vs 布尔表达式的 1300 tokens）。
- 语法结构决定推理效率：布尔表达式和 Lisp 树能自然编码电路的拓扑排序，引导模型按信号流向顺序生成，内部激活稳定（高 KOI）。相反，Petri 网等非顺序结构导致模型注意力频繁跳跃，内部 Schema 震荡，准确率暴跌至 13.75%。
这证明了： 语言表征的设计直接决定了模型内部“思考路径”的流畅度。
### 工程启示：我们该怎么做？
这篇论文对实际工程落地有极强的指导意义，它提示我们在构建 Agent 或复杂推理系统时，不要只盯着 Prompt 的措辞，而要升级“交互协议”：
- 从 NL 到 DSL 的迁移：在涉及逻辑推理、代码生成、数学证明等任务时，尽量避免让 LLM 直接输出自然语言。强制模型使用中间表示（Intermediate Representation, IR），如 JSON Schema、SQL、或特定的 DSL（领域特定语言）。这相当于给模型提供了“草稿纸”，降低了其内部 Schema 的构建难度。
- 显式约束优于隐性提示：Level 1 和 Level 2 的表征（如结构化槽位、逻辑算子）比自然语言中的“请一步步思考”更有效。因为它们消除了歧义，强制模型遵循特定的逻辑拓扑。
- 未来的方向：机器自创语言：论文展望了 Level 3，即 AI 构建自己的形式化语言。目前我们还在用人类设计的语言（代码、逻辑）约束 AI，未来模型可能会学习出更贴合其内部神经机制的“机器语言”，从而突破人类语言的表达极限。
### 局限与展望当然，这种方法并非万能。首先，它依赖于领域专家设计合适的语言表征（Q1），这需要投入成本。其次，当前模型可能并未完全适配这些新表征，可能需要针对性的对齐微调（Representation-Aware Alignment, Q2）。
但无论如何，这篇论文指出了一个被忽视的真理： 在 Scaling Law 边际效应递减的今天，优化“输入/输出的语言结构”是性价比极高的智能增强手段。 别只想着堆算力，先想想怎么给你的 LLM 换一副更清晰的眼镜。
