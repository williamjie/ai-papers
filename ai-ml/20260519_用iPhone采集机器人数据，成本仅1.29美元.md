# 用 iPhone 采集机器人数据，成本仅 1.29 美元

**日期**: 2026-05-19

---

论文 : MobileEgo Anywhere: Open Infrastructure for long horizon egocentric data on commodity hardware链接 : https://arxiv.org/abs/2605.05945机器人领域的 Scaling Law 已经明确：数据量决定模型上限。但 VLA（Vision Language Action）模型的训练瓶颈始终在于：高质量、长时序（Long-horizon）的第一人称（Egocentric）数据太贵、太难采。
这篇论文提供了一个极具工程价值的解法： 把消费级 iPhone 变成机器人数据采集终端 。它不仅开源了采集 App 和处理管线，还发布了一个包含 200 小时数据的数据集，且自动化标注成本极低。
### 痛点：现有数据“短”且“贵”
目前主流的 Ego 数据集（如 Ego4D, EPIC-KITCHENS）要么缺乏精确的 6DoF 位姿，要么片段过短（平均仅几分钟）。对于需要理解复杂任务逻辑（如“先切菜再炒菜”）的机器人策略来说，短片段无法提供足够的时序依赖信息。
虽然 UMI（Universal Manipulation Interface）等方案降低了门槛，但仍需专用硬件。传统 SLAM 方案在室内动态环境中容易漂移，导致长期轨迹失效。
### 核心 Insight：复用手机的 VIO 能力作者的核心直觉非常直接： 现代智能手机已经是成熟的视觉惯性里程计（VIO）设备。
不需要重新发明 SLAM 算法，直接调用 iOS 的 ARKit 框架，就能获得高保真、低漂移的 6DoF 相机位姿和深度图。配合 WiLoR 进行 3D 手部姿态估计，再结合 LLM 进行自动化语义标注，形成了一套完整的“采集-处理-标注”闭环。
关键设计拆解：
- 硬件极简：头戴式手机支架 + iPhone Pro（需 LiDAR）。无需额外传感器。
- 长时序追踪：利用 ARKit 的闭环检测能力，解决了传统视觉 SLAM 在长时间录制中的累积漂移问题。实验显示，在长达 108 分钟的录制中，重访 ArUco 标记点的误差小于 1.5 cm。
- 自动化层级标注：
原子动作（Atomic Spans）：VLM 对视频片段生成细粒度描述（如“将面团从金属碗转移到大盘子”），平均每个标签 7.95 个词，富含物体属性和空间关系。
- 层级结构（Hierarchical Tree）：LLM 将原子动作聚合成 Episode（约 42 秒）和 Sub-goals（约 3.9 分钟），最终形成 Session 级目标。这种结构完美匹配分层强化学习的需求。

### 工程启示- 数据民主化：任何拥有 iPhone 的研究者或爱好者都可以参与数据贡献。这为构建更大规模的 VLA 预训练数据提供了可能。
- 标注管线复用：其开源的 Python 处理套件（STERA）展示了如何从原始传感器数据中提取机器人可用的状态空间（State Space）和动作空间（Action Space）。特别是利用 ARKit 位姿将 2D 手部关键点反投影到 3D 世界坐标系的方法，具有很高的参考价值。
- 层级监督信号：生成的三层指令树（Session -> Sub-goal -> Episode）为分层策略网络提供了天然的多尺度监督信号，有助于解决长尾任务中的规划难题。
### 局限与展望- 硬件依赖：目前方案依赖 iPhone 的 LiDAR 和 ARKit，Android 设备虽可通过 ARCore 实现类似功能，但需额外适配。
- 手部遮挡：尽管 WiLoR 在遮挡鲁棒性上表现良好，但在极端第一人称视角下，手部完全遮挡仍可能导致轨迹中断（虽然论文指出可通过阈值过滤异常值）。
- 物理交互缺失：当前数据主要包含视觉和位姿信息，缺乏力控（Force/Torque）反馈。对于需要精细力控的任务（如拧螺丝），仍需结合其他传感器。
总之，这篇论文不仅是一个数据集发布，更是一套 低成本、可扩展的机器人数据基础设施 。它证明了在消费级硬件上获取高质量、长时序机器人数据是完全可行的，为 VLA 模型的下一步 Scaling 铺平了道路。
