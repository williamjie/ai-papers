论文 : 3D HAMSTER: Bridging Planning and Control in Hierarchical Vision Language Action Models through 3D Trajectory Guidance链接 : https://arxiv.org/abs/2606.31329现在的具身智能圈有个尴尬的现状：大脑（VLM）活在二维像素里，手脚（控制器）却在三维空间干活。
这篇论文直击痛点：既然底层策略已经全面转向点云和 3D 空间，为什么还要让高层规划器输出 2D 轨迹，然后强行“拔高”成 3D？
作者提出的 3D HAMSTER 框架，通过让 VLM 直接输出带深度信息的 3D 轨迹，彻底抹平了这种表示层面的错位。
## 痛点：被扭曲的“涂鸦效应”
传统的分层架构（如早期的 HAMSTER）通常用 VLM 预测图像上的 2D 关键点序列。
为了喂给底层的 3D 策略，这些 2D 点必须通过场景深度图反投影到 3D 空间。
这就带来了一个致命缺陷： “涂鸦效应”（Graffiti Effect） 。
因为规划器本身不知道深度，每个路点的深度完全取决于它落在背景物体的哪个表面上。
轨迹就像被强行吸附在物体表面一样，失去了原本应有的空中运动路径。
这种几何畸变让底层控制器无法区分“指引轨迹”和“场景几何”，导致执行失败。
## 核心直觉：共享度量空间3D HAMSTER 的核心 Insight 很简单： 规划器和控制器必须说同一种语言——三维度量坐标。
与其费力地做 2D 到 3D 的映射，不如让 VLM 直接输出 (u,v,d)(u, v, d) 格式的轨迹序列。
为了实现这一点，作者对 Qwen3-VL-8B 做了三个关键改造：
- 引入深度编码器：除了 RGB 特征，单独增加一个处理深度图的分支，提取几何特征并与视觉 Token 融合。
- 密集重建损失（Dense Reconstruction Loss）：这是最精彩的设计。
单纯预测稀疏轨迹点不足以让模型理解全局几何。
作者加了一个辅助任务：要求模型能根据内部表征还原出完整的深度图。
这相当于给 VLM 装上了一个“空间标尺”，强迫它理解场景的真实尺度，而不仅仅是语义位置。
- 两阶段训练策略：先冻结主干对齐深度特征，再微调轨迹预测头，防止灾难性遗忘。
## 实验结果：不仅是更准，更是更稳在 DroidSpatial-Bench 基准测试中，3D HAMSTER 的表现相当惊艳。
模型 Start Acc. (5cm) End Acc. (5cm) Both Acc. (5cm) Gemini-3.0-Pro 29.1% 44.0% 16.2% RoboBrain-2.5-8B 61.5% 58.1% 39.2% 3D HAMSTER 63.5% 66.2% 41.9%即便是闭源巨头 Gemini，在严格的 5cm 精度要求下也只有 16.2% 的成功率。
而在 Colosseum 仿真环境下的扰动测试中，优势更加明显：
- 光照变化：3D 引导比 2D 引导高出 +15.6%。
- 背景纹理变化：高出 +8.7%。
⚠️ 反直觉发现 ：在没有任何扰动的基准测试中，使用 2D 轨迹引导的 HAMSTER 成功率（49.5%）竟然比完全不引导的基线（53.8%）还要低！这说明错误的 2D 转 3D 映射不仅没帮忙，反而引入了噪声，干扰了底层控制器的判断。
在真实世界的 Franka Panda 机械臂测试中，这种优势延续到了长尾场景：
- 倒水任务：需要精确的高度控制，3D HAMSTER 达到 68%，而 2D 版本仅 45%。
- 空间泛化：面对未见过的物体高度和相对位置描述时，3D 引导依然稳健，而单体 VLA 模型（如 π0.5\pi_0.5​.5）性能断崖式下跌至 15%。
## 工程启示对于正在落地具身智能的工程师，这篇论文给出了明确的信号：
- 抛弃“2D 规划 + 3D 控制”的混合架构：这种妥协方案在分布外场景（OOD）极其脆弱。
- VLM 需要几何监督：不要指望 VLM 仅靠 RGB 就能猜对深度，必须显式地注入深度信息并进行几何一致性训练。
- 分层架构依然有效：相比于端到端的单体模型，将语义推理和运动控制解耦，并在 3D 空间对接，能更好地利用大规模预训练数据的泛化能力。
## 局限与展望目前 3D HAMSTER 强依赖于 RGB-D 传感器，在单目摄像头下无法直接工作。
此外，它仅支持单视角规划，面对严重遮挡的场景依然力不从心。
未来如果结合多视图融合或单目深度估计技术，这套“3D 原生规划”的范式有望成为具身智能的标准配置。
