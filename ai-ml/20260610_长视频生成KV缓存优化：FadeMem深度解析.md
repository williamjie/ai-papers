论文 : FadeMem: Distance-Aware Memory Consolidation for Autoregressive Video Diffusion链接 : https://arxiv.org/abs/2606.10671在自回归视频生成的工程落地中，KV Cache（键值缓存）随视频长度线性膨胀是阻碍长视频生成的核心瓶颈。FadeMem 提出了一种基于“距离感知”的内存整合机制，在不修改模型架构的前提下，通过动态调整历史信息的存储粒度，显著提升了长视频的时空一致性。
### 现有方案的痛点：固定角色分配的局限性目前的长视频生成主要依赖自回归范式，即逐段生成后续帧。为了维持上下文连贯性，模型需要保留历史 KV 状态。现有的有界缓存策略通常采用固定的时间角色分配：
- 局部窗口：仅保留最近几帧，保证短期运动流畅，但丢失长期身份。
- Sink Tokens/压缩记忆：保留起始帧或全局锚点，维持场景布局，但缺乏对近期动态的精细捕捉。
这种“非黑即白”的设计忽略了视频信息的时间衰减特性。 核心 Insight 在于：视频不同频率的信息随时间衰减的速度是不同的。 高频细节（如纹理、微小运动）迅速去相关，而低频结构（如主体身份、场景布局）能保持更长的相关性。
### 方法拆解：近细远粗的记忆层级FadeMem 的核心设计是将这一观察转化为 距离感知的内存整合（Distance-Aware Memory Consolidation） 。它在一个固定预算的缓存中构建时间层级，而非使用独立的局部或全局模块。
-幂律时间分配调度：
引入参数 β\beta (0<β≤10 < \beta \le 1β≤1) 将物理时间距离映射到扭曲的时间空间 u(di)=diβu(d_i) = d_i^\beta​)=diβ​。
直觉：这确保了靠近当前生成步的条目在缓存中保持分离（细粒度），而远处的条目被压缩得更紧密（粗粒度）。
- 操作：当缓存满时，算法选择在扭曲空间中距离最近的相邻历史条目进行合并。
-渐进式合并算子：
合并不仅仅是丢弃旧数据，而是将相邻的 KV 块加权平均为一个代表性的 KV 块，并更新其时间跨度元数据。
RoPE 兼容性处理：由于 RoPE（旋转位置编码）将位置信息嵌入 Key 中，直接合并会导致相位混乱。FadeMem 在存储前移除原始 RoPE 相位，在使用时根据代表的时间位置重新编码。
⚠️ 反直觉发现 ：实验表明，简单的加权平均（Weighted Average）比选择单一代表性帧或 Max Pooling 更有效。Max Pooling 虽然保留了极端特征，但严重破坏了动态程度和图像质量，说明硬聚合过度压缩了缓存状态。

### 工程启示与局限对工程落地的指导意义：
- 零成本升级：FadeMem-TF 变体无需额外训练即可直接替换现有自回归视频生成器的缓存管理逻辑，适合快速集成。
- 内存预算控制：通过固定条目数（如 M=12），实现了 O(1) 的内存增长，使得生成分钟级视频在消费级硬件上成为可能。
- 位置编码解耦：其移除并重建 RoPE 相位的技巧，为处理长序列位置编码冲突提供了通用参考方案。
局限与展望：
- 固定调度策略：当前的幂律分配是固定的，对于包含剧烈场景切换或快速运动的视频，可能无法自适应调整记忆密度。
- 非位置外推机制：FadeMem 仅解决缓存组织问题，不解决 RoPE 的长程位置外推问题，超长效生成仍需结合 RoPE Reset 等技术。
