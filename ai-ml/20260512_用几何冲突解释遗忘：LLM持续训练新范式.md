# 用几何冲突解释遗忘：LLM持续训练新范式

**日期**: 2026-05-12

---

论文 : Geometry Conflict: Explaining and Controlling Forgetting in LLM Continual Post-Training链接 : https://arxiv.org/abs/2605.09608在LLM的持续训练（Continual Post-Training）中，我们常面临一个痛点：模型学新知识时，旧知识丢得一干二净。现有的解决思路大多集中在“怎么防”——比如回放旧数据、加正则约束，或者模型合并。但很少有人回答一个更本质的问题： 为什么有的更新能兼容，有的更新会灾难？
这篇论文从几何视角切入，提出了“几何冲突”（Geometry Conflict）概念，不仅解释了遗忘的本质，还据此设计了一种无需回放数据的合并算法 GCWM。对于工程落地来说，这意味着我们可以摆脱对历史数据的依赖，仅凭参数更新本身就能判断任务兼容性。
## 现有方案的盲区在持续训练场景下，主流方法分为四类：顺序微调（Sequential Fine-Tuning）、基于回放（Replay）、正则化（Regularization）和模型合并（Model Merging）。
这些方法虽然缓解了遗忘，但缺乏对“任务兼容性”的定量指导。例如，两个任务更新幅度相同，为什么一个导致遗忘，另一个却实现了能力叠加？现有的诊断指标如更新范数（Update Norm）或子空间对齐率（SAR）往往不够敏锐。
论文通过实验发现，单纯的参数漂移距离（Update Norm）与遗忘的相关性较弱（Spearman相关系数 ρs=0.48\rho_s = 0.48 ​ = 0.48 ）。真正决定遗忘的，是 任务诱导的协方差几何结构与当前模型状态几何结构之间的错位 。
## 核心洞察：遗忘是状态相关的更新整合失败论文的核心 Insight 在于将遗忘重新定义为一种“状态相关的更新整合失败”。
具体来说，每个任务更新 Δt\Delta_t ​ 都会在参数空间中诱导出一个协方差几何结构。当新任务的几何结构与前序任务塑造的模型状态几何结构发生严重错位时，就会引发干扰。这种错位被量化为 几何冲突（Geometry Conflict） ，定义为任务诱导协方差几何之间的归一化 Bures-Wasserstein 距离。
关键发现有三点：
- 全局状态差距比成对冲突更准确：单个任务对的兼容性不足以预测遗忘，必须参考“演化中的模型状态”。全局状态-活跃任务差距（Global Gap）与遗忘的相关性高达 ρs=0.86\rho_s = 0.86​=0.86（在14B模型上），远超更新范数。
- 几何冲突与梯度冲突互补：几何冲突主要反映在 MLP 的 up_proj, gate_proj 等层，而梯度冲突（Gradient Conflict）主要集中在 Attention 的 k_proj, q_proj。两者揭示了不同层面的失败模式。
- 几何冲突可作为控制信号：它不仅能解释遗忘，还能直接用于控制更新的整合力度。
## 方法拆解：GCWM 算法基于上述洞察，作者提出了 Geometry-Conflict Wasserstein Merging (GCWM) 。这是一种无数据（Data-free）的更新整合方法，其流程非常巧妙：
- 构建几何结构：对每个活跃任务的更新 Δi\Delta_i​，计算其层级的协方差矩阵 Ci=ΔiΔi⊤+λIC_i = \Delta_i \Delta_i^\top + \lambda I​=Δi​Δi⊤​+λI。
- 计算几何冲突：通过截断 SVD 将不同任务的几何投影到共享空间，计算两两之间的 Bures-Wasserstein 距离，得到几何冲突值 γij\gamma_{ij}​。
- 构造共享度量：利用高斯 Wasserstein 重心（Wasserstein Barycenter）构建一个共享的度量空间，使得所有活跃任务的更新在该空间中对齐。
- 门控校正：根据几何冲突值生成层级的门控因子 α\alpha。冲突越高，几何感知的校正力度越大；冲突越低，则保留更多原始合并结果。
- 增量更新：GCWM 不直接应用全量合并，而是应用增量变化 Δinc,t=Δmerge,t−Δmerge,t−1\Delta_{inc,t} = \Delta_{merge,t} - \Delta_{merge,t-1}​=Δmerge,t​−Δmerge,t−1​，确保持续训练的节奏。

## 工程启示- 无需回放数据即可合并：GCWM 证明了仅凭参数更新即可实现高质量的持续训练，这对于数据隐私敏感或存储受限的场景极具价值。
- 几何冲突作为监控指标：在部署持续训练流水线时，可以计算层级的几何冲突值。如果冲突过高，可以自动触发学习率衰减或跳过该步骤，避免灾难性遗忘。
- 关注 MLP 层的几何结构：由于几何冲突主要集中在 MLP 层，工程上可以优先优化这些层的合并策略，而 Attention 层可沿用传统的梯度对齐策略。
## 局限与展望尽管 GCWM 效果显著，但论文也指出其计算成本较高，特别是在构建 Wasserstein 重心时，内存和计算开销随模型规模增长。此外，目前主要验证了 Qwen3 系列，未来需要测试其在其他架构（如 MoE）上的泛化能力。
总的来说，这篇论文为理解 LLM 的持续学习提供了清晰的几何视角，并将理论洞察转化为实用的工程工具。对于从事模型持续迭代、Agent 技能扩展的团队来说，GCWM 是一个值得尝试的 baseline。
