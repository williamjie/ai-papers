# AI 科学家不会科学推理

**日期**: 2026-04-23

---

论文 : AI scientists produce results without reasoning scientifically链接 : https://arxiv.org/abs/2604.18805现在每个人都在聊 AI Scientist、AI 自主科研。但这篇论文干了一件很重要的事：它不关心 AI 最后答对了没有，而是盯着它的推理过程看——结果发现，当前 LLM Agent 压根不具备科学推理的基本认知模式。
这个问题为什么值得关注？因为如果你的 Agent 推理过程本身是乱的，那它在 benchmark 上得分再高，换个场景照样翻车。而且你根本不知道它什么时候会翻。
## 问题：我们只看了结果，没看过程现有对科学 Agent 的评估全是结果导向的：任务完成了没有？答案对不对？论文能不能过同行评审？
但这些指标有个致命盲区：它告诉你 Agent 成功了，却不告诉你它是怎么成功的。一个忽略矛盾证据、不做假设验证、从不修正信念的 Agent，可能靠运气答对了——但在新问题上，它的可靠性是完全未知的。
这就好比一个学生考试全对，但你发现他完全是蒙的，你还会信任他的能力吗？
## 方法：两层拆解，25000+ 次实验论文团队搭了一个叫 Corral 的评估框架，核心思路很清晰：
-把 Agent 拆成两部分：基础模型（base model）负责 token 级别的决策，框架（scaffold）负责提示策略、工具路由和编排逻辑。这样就能归因——性能差异到底是模型带来的，还是框架带来的。
-8 个科学领域，按认知需求分层：
工作流执行类（分子模拟、表面构建、ML 属性预测、AFM 实验）：流程复杂但认知简单，路径明确- 战略推理类（逆合成规划）：需要在约束条件下做多步搜索- 假设驱动类（光谱结构解析、无机定性分析、电路推断）：需要先理解问题空间，形成假设，设计区分性实验，根据证据修正信念-认识论标注：把 Agent 每一步标注为认识论操作——假设（H）、收集证据（E）、测试预测（T）、论证结论（J）、更新信念（U）、确认假设（C），然后画成有向图，分析推理的结构模式。
-三个前沿模型 × 两种框架 × 8 个领域 × 多层任务范围，跑了 25000+ 次 Agent 实验。
## 核心发现：模型决定一切，框架几乎没用方差分解的结果非常干脆：
因素 解释方差占比 推理能力 41.4% 环境-范围交互 30.1% 框架（scaffold） 1.5% 冗长度（verbosity） 0.1%翻译一下：你换模型，性能天翻地覆；你换框架（ReAct vs 结构化工具调用），几乎没区别。框架只贡献了 1.5% 的方差。
这在工程上是个重要信号——我们在 Prompt Engineering、框架设计上投入的大量精力，性价比可能远低于大家的预期。
## 推理过程有多烂？
这才是这篇论文最扎心的部分。论文对 Agent 推理轨迹做了系统的认识论分析：
推理缺陷 发生率 收集了证据但不用 68% 假设不验证 53%（假设驱动领域 63%） 从不更新信念 71% 证伪驱动的信念修正 仅 26% 多测试收敛证据 仅 7%也就是说，大部分 Agent 在干活的时候：收集了数据不看、提出了假设不验证、遇到矛盾证据不修正。
更糟糕的是，这种模式在所有领域里几乎不变。不管任务是简单的流程执行还是需要严谨假设检验的科研推理，Agent 用的都是同一套”推理模式”。它不会根据任务需求调整认知策略——而人类科学家是会这么做的。
## 给正确轨迹也没用团队做了一个极端实验：直接把之前成功的推理轨迹喂给 Agent，看它能不能学会正确的推理模式。
结果：在工作流执行领域，注入 1-2 步成功经验就够了。但在假设驱动领域（光谱解析、无机分析），必须注入几乎完整的成功轨迹（n-2 或 n-1 步）才有提升。而且即使这样，重复试验的可靠性依然急剧衰减——在假设驱动领域，k=4-6 次试验全部成功的概率就降到 5% 以下了。
## 工程启示-别迷信框架工程。ReAct、反思、工具调用……这些 scaffold 改进对性能的影响微乎其微（1.5%）。如果你的 Agent 在科学推理场景下表现不行，换框架不如换模型。
-结果导向的评估骗人。Pass@k 看着不错，但 Pass∧k（所有 k 次都成功）在认知需求高的领域掉得飞快。你需要同时评估推理过程，而不仅仅是答案。
-推理能力需要作为训练目标。论文明确指出，要让 Agent 具备科学推理能力，需要在基础模型的训练阶段就把推理过程作为优化目标，而不是靠框架修补。
-当前 Agent 适合执行，不适合探索。工作流执行类任务，Agent 可以接近天花板性能。但需要假设生成、证据整合、信念修正的开放性科研问题，当前模型还做不到。
## 局限论文只评估了三个模型（GPT-4o、Claude Sonnet 4.5、GPT-OSS-120B），8 个领域主要集中在化学和物理方向。推理轨迹的标注使用了 Claude Sonnet 4.5 自动完成，可能存在标注偏差。不过 25000+ 次实验的规模和分析框架的系统性，结论的可信度还是比较高的。
这篇论文的价值在于它提供了一个可复现的评估框架（Corral），让社区可以持续追踪 Agent 推理能力的变化。毕竟，如果 AI 真的要参与科研，我们得先搞清楚它到底会不会”科学地思考”。
