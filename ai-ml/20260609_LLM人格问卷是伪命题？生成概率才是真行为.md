# ⭐⭐⭐½ LLM人格问卷是伪命题？生成概率才是真行为

**日期**: 2026-06-09

---

论文 : Human Psychometric Questionnaires Mischaracterize LLM Behavior链接 : https://arxiv.org/abs/2509.10078如果你还在用 BFI 或 PVQ 这类人类心理量表给 LLM 做“人格画像”，这篇论文会直接打碎你的幻想。它揭示了一个残酷事实：LLM 在问卷上表现出的“稳定人格”，本质上是文字游戏，而非真实行为倾向。对于构建 Agent 或进行模型对齐的工程师来说，这意味着现有的评估基准可能完全失效。
### 为什么现有方案不可靠？
目前业界习惯通过让 LLM 回答李克特量表（Likert scale）来量化其价值观和性格。这种做法假设模型有稳定的内在特质，且问卷分数能预测其在真实交互中的行为。
但首尔国立大学的研究团队指出，这种评估缺乏生态效度（Ecological Validity）。问卷是反思性的自我报告，而 LLM 的核心能力是生成性响应。更致命的是，传统问卷题目往往带有极强的语义线索，模型只要读懂了题目在测什么，就能通过“社会期望偏差”给出完美答案，这与它在面对真实用户模糊提问时的表现截然不同。
### 核心 Insight：文本透明度陷阱论文的核心洞察在于区分了“问卷一致性”与“生成概率分布”。
传统量表（如 BFI-44）的题目具有极高的 文本透明度（Textual Transparency） 。例如，“我是一个宽容的人”直接包含了“宜人性”的词汇信号。LLM 并非拥有稳定的宜人性特质，而是识别出了题目意图，并基于对齐训练给出的社会可接受答案进行响应。
相比之下，真实用户查询缺乏这种显式线索。为了捕捉模型的真实行为倾向，作者提出了**生成概率画像（Generation Probability Profiling）**方法：
- 使用经过心理测量验证的 Value Portrait 数据集，包含 520 个真实场景-回复对。
- 不依赖模型的自我报告，而是计算模型生成特定价值观回复的 Log-probability。
- 通过比较不同价值观回复的概率分布，推导模型在真实交互中的潜在倾向。
⚠️ 反直觉发现 ：在问卷中表现高度一致的“人格结构”，在生成概率中完全消失。这意味着 LLM 并没有稳定的心理构念，它只是在玩文字匹配游戏。
### 关键结果：数据不会撒谎研究对比了 8 个开源模型（Gemma3, Qwen 2.5/3, GPT-OSS），结果令人震惊：
1. 问卷与生成行为严重脱节自报告画像之间的相关性很高（Spearman ρ\rho 约 0.74-0.77），但与生成概率画像的相关性极低。
- 价值观（Schwartz Values）：生成概率 vs 问卷的 ρ\rho 仅为 0.31。
- 人格特质（Big Five）：相关性更低，ρ\rho 为 0.26，部分模型甚至出现负相关（-0.50）。
2. “稳定结构”是幻觉通过计算构念间区分度（ η2\eta^2 ）和内部一致性（WMV），发现：
- 问卷数据：η2\eta^2 高达 0.526，说明题目确实能聚类出特定人格。
- 生成概率：η2\eta^2 仅为 0.070，与随机基线无异。
这证明问卷上的“一致性”源于模型识别题目意图的能力，而非内在特质的稳定性。
3. Persona Prompting 的失效当注入人口统计学 Persona（如“老年人”、“右翼”）时：
- 问卷响应：会显著向人类真实数据偏移（Cosine Similarity 高达 0.95），模型成功扮演了刻板印象。
- 生成行为：几乎无规律可循，平均 Cosine Similarity 为 -0.03。
这表明 Persona 仅影响了模型的“答题策略”，并未改变其在真实场景下的生成逻辑。
### 工程启示- 停止迷信量表分数：在评估模型安全性、价值观对齐时，不要只看 BFI/PVQ 分数。高分可能只是模型擅长做阅读理解，而非真正具备该特质。
- 采用概率分布评估：对于高风险场景（如情感支持、伦理建议），应构建基于真实交互场景的测试集，通过分析模型对特定回复的 Log-probability 来评估倾向性。这种方法对 Prompt 扰动更鲁棒。
- 警惕 Persona 模拟：不要指望通过 System Prompt 注入 Persona 就能让模型在复杂任务中表现出特定人群的行为特征。它在封闭问卷中有效，但在开放生成中无效。
### 局限与展望该方法目前依赖 Token-level Log-probabilities，主要适用于开源模型或提供底层概率的 API。对于黑盒商业模型，需寻找替代的概率估计方法。此外， Value Portrait 数据集虽经验证，但覆盖的场景范围仍有扩展空间。
总之，这篇论文提醒我们：LLM 不是人，没有内心戏。它的“人格”是上下文和概率分布的产物。工程师应转向更贴近真实生成行为的评估范式，而非沉迷于心理量表的虚假一致性。
