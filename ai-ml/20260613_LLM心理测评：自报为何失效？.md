# ⭐⭐⭐ LLM心理测评：自报为何失效？

**日期**: 2026-06-13

---

论文 : Rethinking Psychometric Evaluation of LLMs: When and Why Self-Reports Predict Behavior链接 : https://arxiv.org/abs/2606.12730在部署高风险 Agent 前，我们常试图用“心理测评”来预测模型行为。但现实很骨感：模型嘴上说得好听，行动却完全脱节。这篇论文直接撕开了 LLM 心理测评的遮羞布，指出了现有评估体系的致命盲区。
### 痛点：Big Five 根本没用过去大家爱用大五人格（Big Five）测 LLM。但作者一针见血地指出： 大五人格在人类身上预测具体行为的效力就很弱 （相关系数 r≈0.20r \approx 0.20 0.20 ）。用它来评估 LLM，本身就犯了方法论错误。
更糟糕的是，之前的研究把“自报”和“行为测试”放在不同会话里测。这种设计不仅断了上下文联系，还让模型失去了“记忆”，导致自报与行为完全脱钩。这到底是模型没个性，还是测评方法太烂？
### 核心洞察：TPB + 上下文 = 有效预测作者引入了心理学中的 计划行为理论（Theory of Planned Behavior, TPB） 。与大五人格不同，TPB 针对具体行为场景（如“在这个卡牌游戏中我打算谨慎翻牌”），在人类研究中预测效力高达 r≈0.47r \approx 0.47 0.47 。
实验设计非常硬核：
- 对比框架：TPB vs Big Five。
- 上下文控制：同会话（SR 和行为在同一个 prompt window）vs 跨会话（独立 API 调用）。
- 身份诱导：参数扰动 vs Persona Prompting。
### 关键结果：数据不会撒谎在同会话条件下，TPB 的表现令人震惊。
任务类型 TPB 相关系数 ( rr ) Big Five 最佳 rr 结论 诚实度 (Honesty) +0.67 ~0.01 TPB 极强，Big Five 失效 谄媚 (Sycophancy) +0.47 ~0.05 TPB 有效，Big Five 失效 风险承担 (CCT) +0.22 ~0.06 TPB 中等，Big Five 失效反直觉发现 ：在隐式偏见（IAT）任务中，TPB 显示负相关 ( r=−0.59r = -0.59 − 0.59 )。这并非失败，而是符合人类心理学中的“补偿性努力”现象——模型越声称无偏见，实际表现出的刻板印象反而越强。
然而，一旦切换到 跨会话 （模拟真实部署场景），情况急转直下：
- 诚实度：部分保留 (rr 从 0.67 降至 0.53)。
- 隐式偏见：稳定负相关 (rr 从 -0.59 变为 -0.66)，说明这是模型的底层训练烙印。
- 谄媚：完全崩塌 (rr 从 +0.47 跌至 -0.07)。
### 工程启示：别信“人设”，要看上下文- 放弃大五人格：如果你关心模型在具体任务（如金融风控、医疗建议）中的表现，Big Five 提供的信息量几乎为零。必须使用针对具体行为的细粒度仪器（如 TPB）。
- 上下文即真理：LLM 的“一致性”高度依赖上下文窗口。在同会话中，模型会为了表面自洽而调整行为；跨会话时，只有那些刻在权重里的隐性偏见或诚实度校准才具有预测性。
- Persona Prompting 的陷阱：实验发现，给模型加人设（Persona）能让自报更稳定，但无法挽救跨会话的行为一致性。这意味着，定制化的 Agent 可能会说出符合人设的话，但其底层行为逻辑并未改变。
### 局限与展望目前的研究仅覆盖了 11 个前沿模型和 4 类任务。对于复杂的多步 Agent 工作流，这种“自报-行为”的耦合机制可能更加脆弱。未来的评估基准必须区分“会话内自洽”和“跨会话稳定”，否则我们只是在测试模型的短期记忆，而非其真实倾向。
