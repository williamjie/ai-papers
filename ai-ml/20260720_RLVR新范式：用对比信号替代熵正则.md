论文 : Beyond Entropy: Correctness-Aware Advantage Shaping via Contrastive Policy Optimization链接 : https://arxiv.org/abs/2607.14614在可验证奖励强化学习（RLVR）的实践中，我们常陷入一个误区：认为高熵（Entropy）就代表模型在“探索”，低熵就是“自信”。这篇来自港中文和华工团队的新作直接戳破了这个泡沫： 熵无法区分“有价值的探索”和“有害的困惑” 。作者提出了一种名为对比策略优化（Contrastive Policy Optimization, CPO）的新方法，利用参考答案引导下的概率分布差异来重塑优势函数，在数学推理任务上实现了显著的性能跃升。
### 为什么现有的熵正则不够用？
GRPO 等主流 RLVR 算法依赖组内相对奖励，但存在两个致命伤：
- 粒度粗糙：它只关心最终答案对错，忽略了中间推理步骤中哪些 Token 是关键的。
- 零优势浪费：当一组回答全对或全错时，优势值为 0，大量训练数据被白白丢弃。
为了解决这些问题，社区普遍引入熵正则化。但熵本质上衡量的是不确定性，而非正确性。模型可能在尝试新颖解法时产生高熵（好事），也可能在逻辑混乱时产生高熵（坏事）。这种信号的对齐偏差，导致现有方法在探索与利用之间难以平衡。
### CPO 的核心直觉：像学生订正作业一样学习CPO 的设计灵感来自人类的学习过程：学生独自做题时很难发现错误，但一旦看到参考答案，错误的步骤会立刻显现。

- 理论支撑：作者证明，这个对数比值与 Token 级别的正确性概率单调相关。负的不一致性可靠地指示了错误倾向的 Token，而正的则指示正确倾向。
- 工程实现：无需额外训练教师模型，只需在推理时让模型“参考标准答案重新思考”，计算前后概率分布的差异即可。
这种设计巧妙地将轨迹级奖励（Trajectory-level Reward）与 Token 级对比信号结合。通过裁剪操作确保方向一致性，CPO 不仅解决了零优势问题，还为每个 Token 提供了细粒度的信用分配。

### 工程启示与落地建议- 探索与利用的平衡：消融实验显示，仅对错误回答进行塑形会损害泛化能力，仅对正确回答塑形则削弱推理深度。1:1 的权重比例（α+:α−\alpha^+ : \alpha^-:α−）效果最佳。这意味着在工程实现中，不要丢弃“全对”或“全错”的样本，它们分别对应着探索新路径和利用最优路径的需求。
- Prompt 设计至关重要：作者测试了多种 Prompt 格式，发现“单轮第一人称模拟解题”的效果最好。这要求我们在实现 CPO 时，精心设计引导模型参考标准答案的 Prompt，避免模型直接抄写答案，而是激发其内部概率分布的修正。
- 计算开销可控：CPO 仅需额外一次前向传播（生成参考条件下的概率），相比引入外部教师模型的蒸馏方法，其工程成本极低，且能实现自我迭代改进。
### 局限与展望尽管 CPO 表现优异，但其核心依赖于“参考答案”的存在。对于没有明确标准答案的开放域任务（如创意写作、复杂对话），如何构建有效的 πpost\pi_{\text{post}} ​ 仍是一个开放问题。此外，作者提到对比信号在极端低概率区域可能不稳定，虽然通过裁剪缓解了，但在超大规模模型训练中仍需关注数值稳定性。
总体而言，CPO 为 RLVR 提供了一个更精细、更具解释性的优化视角。它告诉我们： 不要盲目崇拜熵，正确的对比信号才是提升推理能力的钥匙。
