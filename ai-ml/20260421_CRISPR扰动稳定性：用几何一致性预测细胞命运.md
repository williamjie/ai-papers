# CRISPR 扰动稳定性：用几何一致性预测细胞命运

**日期**: 2026-04-21

---

基因编辑越来越精准，但我们仍然无法准确预测一个细胞在被编辑后会变成什么样子。即使编辑操作完美无缺，细胞仍可能漂向意外 fate。这篇论文提出了一个几何视角的度量 Perturbation Stability (Shesha) ，用来衡量单细胞 CRISPR 扰动后细胞群体是否”一起行动”，揭示了调控架构中一个被长期忽视的维度。
## 问题：我们只测”走了多远”，没测”怎么走”
单细胞 CRISPR 筛选的标准评估只关心一个数字： Effect Magnitude（效应幅度） ——扰动细胞与对照组之间的欧氏距离。它回答了一个工程师的问题：“代码改对了吗？“但没回答生物学家的核心问题：“细胞最终处于稳定状态吗？”
两个效应幅度相同的扰动，可能产生截然不同的后果：一个让细胞沿共同轨迹迁移，另一个让细胞在表达空间中四散。PCA、UMAP 等降维方法进一步掩盖了这个差异——它们把高维流形拍扁成平面，抹去了区分深吸引子和浅山脊的曲率信息。
## 方法：Shesha 稳定性的几何直觉核心 insight 很简单： 看每个细胞的位移向量与群体平均方向的夹角 。
具体做法：
- 对每个扰动 p，计算每个扰动细胞 i 的位移向量 dᵢ = xᵢ - μ_ctrl（xᵢ 是细胞在 PCA 空间的位置，μ_ctrl 是对照组中心）
- 计算平均扰动方向 d̄ = (1/nₚ) Σ dᵢ- Shesha 稳定性 Sₚ = 平均余弦相似度：每个个体位移向量与平均方向之间的余弦相似度的均值Sₚ 接近 1 意味着所有细胞朝同一方向移动（高相干性）；接近 0 意味着细胞四散（低相干性）。
这个度量的关键设计直觉是： 几何一致性本身就是一个信号 。它不依赖任何监督标签，纯粹从数据几何中自然涌现，却能够区分不同类型的调控架构。
## 关键结果：相关性背后的生物学### 稳定性与效应幅度强相关，但解耦处才是干货在五个数据集（2,200+ 扰动）中，稳定性与效应幅度的 Spearman 相关系数 ρ = 0.75–0.97，跨数据集校准后 ρ = 0.968。
数据集 模态 扰动数 Spearman ρ 95% CI Norman 2019 CRISPRa 236 0.953 [0.934, 0.965] Adamson 2016 CRISPRi 8 0.929 [0.407, 1.000] Dixit 2016 CRISPRi 153 0.746 [0.641, 0.827] Papalexi 2021 Pooled 25 0.985 [0.939, 0.997] Replogle 2022 CRISPRi 1,832 0.970 [0.966, 0.972]相关性本身不难理解——大位移自然要求向量方向更一致。真正有意思的是 相关性断裂的地方 ：
- 多效性调控因子（CEBPA、GATA1）：效应大但稳定性低，产生”几何税”（geometric tax）。它们激活多条竞争通路，每个细胞以不同方式解析竞争，导致群体层面的不连贯。
- 谱系特异性因子（KLF1）：效应适中但稳定性极高。KLF1 的目标基因协调指向单一发育结果（红细胞成熟），细胞沿既定轨迹一致移动。
在 Replogle 全基因组 CRISPRi 筛选中，GATA1 的 discordance = 2.15（大效应、低稳定性），而核糖体生物合成因子 LSG1、ISG20L2 则呈现高相干性。
### 几何不稳定性与细胞应激独立相关控制效应幅度后，Shesha 稳定性与内质网分子伴侣 HSPA5 (BiP) 的表达仍显著负相关：
- Dixit 数据集：偏相关 ρ = -0.338（p = 1.9×10⁻⁵）
- Replogle 数据集：偏相关 ρ = -0.206（p = 5.2×10⁻¹⁹）
更重要的是 象限耗尽分析 ：在高稳定性/高应激象限（HH），扰动数量显著低于独立性期望。Replogle 数据中仅 301 个扰动落入 HH 象限（期望 458，p < 10⁻¹⁸，OR = 0.24）。 高稳定性与高应激几乎互斥 。
对比之下，常用的应激标记 DDIT3 (CHOP) 在控制效应幅度后相关性崩溃或翻转符号，说明 DDIT3 的信号主要由效应幅度驱动，而非几何不稳定性本身。
### 非线性嵌入中关系依然成立用 scGPT 基础模型（预训练于 3300 万个人类细胞）的非线性嵌入替代 PCA，magnitude-stability 关系依然稳健：
- Norman: scGPT ρ = 0.935 vs PCA ρ = 0.953- Dixit: scGPT ρ = 0.712 vs PCA ρ = 0.746- Replogle: scGPT ρ = 0.851 vs PCA ρ = 0.970scGPT 相关性略低是合理的——非线性嵌入解析了 PCA 压平的额外流形结构（如分叉轨迹）。关系在非线性空间中仍然存在，证明这是 生物状态空间的固有属性 ，而非线性投影的伪影。
### 组合扰动比单基因扰动更稳定在 Norman CRISPRa 数据集中，组合扰动（n=131）的稳定性显著高于单基因扰动（n=105，Mann-Whitney U test p < 10⁻⁹），且这一差异不能用效应幅度解释——两类扰动在 magnitude-stability 散点图中回归斜率相似。
直觉：同时扰动两个基因更可能参与既定的发育轨迹，将细胞推入更深的吸引子盆地；单基因扰动可能只激活多因子程序的一部分，产生缺乏协调方向性的部分位移。
## 工程启示1. 筛选评估需要第二个维度。 效应幅度 alone 不够。一个扰动可能幅度很大但几何上极不稳定——细胞看似”被改变了”，实际上处于脆弱、易漂移的状态。Shesha 稳定性提供了互补的评估轴。
2. 细胞治疗质量控制的新指标。 当前细胞治疗评价聚焦于序列保真度和标志物表达（“语法”层面），但忽略了细胞状态是否几何相干（“语义”层面）。一个在所有传统指标上得分良好的扰动，可能产生几何不连贯的细胞群体，随时漂向意外 fate。
3. 多效性调控因子的”几何税”是可量化的。 CEBPA、GATA1 等多效性因子产生大但散射的细胞响应，这种成本可以用稳定性指标精确测量。在设计基因回路时，需要考虑这种相干性代价。
4. 基础模型嵌入可以作为流形检验。 如果扰动稳定性-幅度关系在 scGPT 等非线嵌入中依然保持，说明模型学到了几何上忠实于细胞动力学的表征。这提供了一个评估基础模型表征质量的实用标准。
## 局限与展望论文主要局限在于：
- 分析基于 PCA 和 scGPT 两种嵌入，其他降维方法（如 PHATE、自编码器）下的表现未验证- HSPA5 在 Norman CRISPRa 数据中偏相关接近零（ρ = -0.006），激活与干扰扰动对应激通路的engagement可能存在模态差异- 象限耗尽分析使用简单中位数分割，更精细的流形分析可能揭示更复杂的结构但总的来说，这篇论文的价值不在于提出了什么复杂的新算法，而在于 把一个被长期忽略的问题正式化 ：细胞扰动后是”一起走”还是”各自为政”，这个几何差异有明确的生物学含义和功能后果。在 Waddington 表观遗传景观的框架下，深度山谷中的扰动代价小（细胞被通道化到稳定吸引子），而山脊上的扰动代价高——这个”几何税”现在可以量化了。
