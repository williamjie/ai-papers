论文 : Learning to Act under Noise: Enhancing Agent Robustness via Noisy Environments链接 : https://arxiv.org/abs/2605.27209现在的 LLM Agent 在基准测试（Benchmark）里表现优异，但一部署到生产环境就“水土不服”。用户指令模糊、工具调用报错、上下文缺失……这些现实中的“脏数据”让精心训练的模型瞬间降智。这篇来自新加坡国立大学与美团的论文 NoisyAgent 提供了一个非常工程化的解法：既然现实充满噪声，不如在训练时就把噪声作为常态。
### 为什么现在的 Agent 这么“脆”？
现有的 Agent 强化学习（Reinforcement Learning, RL）范式存在一个根本性的错位： 训练环境过于理想化 。
目前的训练流程通常假设用户指令清晰明确，且外部工具（Tools）永远稳定返回正确结果。这种“无菌室”训练出来的模型，一旦面对真实世界中用户的随意提问或 API 的偶发超时，就会因为缺乏容错机制而崩溃。论文指出，这种分布偏移（Distribution Shift）是导致 Agent 在实际应用中性能大幅衰减的核心原因。
### NoisyAgent：核心设计直觉NoisyAgent 的核心 Insight 很简单： 鲁棒性不是调出来的，是“练”出来的 。与其指望模型在推理时自动适应噪声，不如在训练阶段显式地引入环境不完美性（Environmental Imperfections）。
作者将现实噪声拆解为两类，并设计了自动化注入管道：
- 用户侧噪声（User Noise）：模拟真实用户的非理想交互。
模糊（Ambiguous）：意图未完全指定。
- 不一致（Inconsistent）：需求中途变更或冲突。
- 冗余（Redundant）：包含无关信息。
- 工具侧噪声（Tool Noise）：模拟外部系统的不可靠性。
失败（Failures）：API 返回错误。
- 不完整（Incomplete）：输出被截断。
- 误导（Misleading）：返回错误或过时信息。
关键工程技巧：混合训练与自适应调度直接在全量数据中加噪声会导致训练崩溃（Training Collapse）。NoisyAgent 采用了两个关键策略来稳定优化过程：
- 混合 Rollout（Hybrid Training）：在每组采样中，只有一部分轨迹注入噪声，其余保持干净。优势值（Advantage）分别计算，防止噪声样本主导梯度更新。
- 自适应课程学习（Adaptive Scheduling）：通过监控干净环境与噪声环境下的性能差距 Δ\Delta 来动态调整噪声难度。当模型适应当前噪声水平（Δ<θ\Delta < \thetaθ）时，才增加噪声比例或复杂度。这确保了训练始终处于“最近发展区”，既不过于简单也不至于不可学习。
### 实验数据：不仅抗噪，还更强论文在 AgentNoiseBench （噪声环境）和标准基准（ τ2\tau^2 -Bench, VitaBench）上进行了对比。以 Qwen3-8B 为基座，NoisyAgent 的表现令人印象深刻：

### 工程启示对于正在构建生产级 Agent 的工程师，这篇论文提供了三条直接可用的建议：
- 不要迷信干净数据：在微调或 RL 阶段，刻意引入“坏数据”（如模拟 API 超时、用户语病）是提升鲁棒性的低成本高回报手段。
- 噪声注入需要克制：全量加噪必崩。采用“混合 Rollout”策略，保持一定比例的干净样本作为锚点，能显著稳定训练曲线。
- 动态难度是关键：静态的噪声比例无法兼顾收敛速度与最终性能。实现一个简单的基于性能差距（Performance Gap）的课程调度器，能让模型逐步适应复杂环境。
### 局限与展望目前 NoisyAgent 主要依赖合成环境中的结构化噪声，真实世界中的噪声可能更具组合性和动态性。此外，实验主要在合成基准上进行，未来需要在更多真实业务场景（如复杂的电商客服系统）中验证其泛化能力。
总之，NoisyAgent 提醒我们： 完美的训练数据是幻觉，拥抱噪声才是通往鲁棒 Agent 的必经之路。
