论文 : Joint Training of Multi-Token Prediction in Reinforcement Learning via Optimal Coefficient Calibration链接 : https://arxiv.org/abs/2605.28184如果你正在用强化学习（Reinforcement Learning, RL）训练带多 Token 预测（Multi-Token Prediction, MTP）头的大模型，这篇论文是你必须看的。它解决了一个长期困扰工程界的痛点：为什么把 MTP 梯度传回主干网络会导致性能崩塌？更重要的是，它给出了一个几乎零成本的修复方案。
### 现有方案的死胡同MTP 在预训练阶段能显著提升推理速度（通过投机采样），但在后训练（Post-training）的 RL 阶段，主流框架如 veRL、slime 甚至 GLM-5 都选择“断梯”（Detach）：让 MTP 参与前向传播，但切断反向传播。
直觉上，联合优化应该能利用多 Token 的监督信号提升推理能力。但现实很骨感：
- CE Loss 方案：直接用交叉熵损失回传梯度。结果？性能暴跌。在 AIME24 上，准确率从 Detach 的 45.3% 跌至 16.1%，跌幅高达 -29.2%。
- Policy Loss 方案：让 MTP 使用与主干相同的 RL 目标。初期表现不错（30 step 时达 48.9%），但后期迅速衰退，最终降至 38.9%，低于 Detach 基线。
为什么？因为现有的固定系数无法应对训练过程中的动态变化。
### 核心 Insight：一阶相关 vs 二阶惩罚论文作者从优化理论出发，推导了一个每步改进的下界公式。MTP 对 RL 目标的影响被分解为两项：

- CE Loss 失败原因：RL 梯度基于优势函数（Advantage），均值为零；而 CE 梯度对所有样本平等对待。两者方向几乎不相关（相关项 ≈0\approx 00），导致负面的二阶惩罚项主导，引入噪声，破坏训练。
- Policy Loss 失败原因：初期模型远离收敛点，RL 和 MTP 梯度方向一致，相关项占优，性能上升。但随着训练进入平坦区域，梯度方向发散，相关项衰减，而 MTP 梯度的范数（惩罚项）依然很大。固定系数无法适应这种“相位转换”，导致后期性能崩塌。
### 解决方案：OCC 自适应校准既然问题出在固定系数跟不上动态变化，那就让系数动起来。论文提出了 Optimal Coefficient Calibration (OCC) 。
核心思想是每一步都计算理论上的最优系数 λ∗\lambda^* 。但在全量分布式训练中计算全模型梯度太贵（慢 5.6 倍）。作者巧妙利用了对数概率变化作为代理变量：
λt=λ+⋅c^tv^t2+ϵ\lambda_t = \lambda_+ \cdot \frac{\hat{c}_t}{\hat{v}_t^2 + \epsilon} ​ = λ + ​ ⋅ v ^ t 2 ​ + ϵ c ^ t ​ ​其中 c^t\hat{c}_t ^ t ​ 是 RL 与 MTP 对数概率变化的内积（代理相关项）， v^t2\hat{v}_t^2 ^ t 2 ​ 是 MTP 对数概率变化的范数平方（代理解罚项）。
这个设计极其优雅：
- 零额外开销：只需利用前向传播已生成的 log-prob，无需反向传播计算梯度。
- 动态适应：初期相关性强，λt\lambda_t​ 较大，充分利用 MTP 信号；后期相关性弱，λt\lambda_t​ 自动衰减至接近 0，避免惩罚项干扰。

### 工程启示与局限对于正在构建 RL 后训练流水线的工程师，这篇论文提供了明确的指导：
- 不要断梯：除非你完全放弃 MTP 的联合优化潜力，否则 OCC 是更好的选择。它能让你在保持推理速度优势的同时，提升模型能力。
- 实现极简：OCC 不需要修改底层算子，只需在数据加载或 loss 计算环节加入几行代码统计 log-prob 的变化即可。
- 通用性强：实验表明 OCC 在不同 RL 算法（DAPO, GSPO）和不同模型架构（Dense, MoE）上均有效。
当然，方法也有边界。理论推导基于 L-smoothness 假设，在非凸深度学习中仅为定性指导。此外， λ+\lambda_+ ​ 这个全局缩放因子需要少量超参搜索（论文建议设为 1.0）。对于非数学推理任务（如 RLHF 中的开放域生成），其有效性仍需进一步验证。
但毫无疑问，OCC 是目前解决 MTP-RL 联合训练不稳定性最优雅、最高效的方案。
