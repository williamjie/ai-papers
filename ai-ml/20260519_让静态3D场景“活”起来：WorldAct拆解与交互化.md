# 让静态3D场景“活”起来：WorldAct拆解与交互化

**日期**: 2026-05-19

---

论文 : WorldAct: Activating Monolithic 3D Worlds into Interactive-Ready Object-Centric Scenes链接 : https://arxiv.org/abs/2605.15843现在的 3D 世界模型（如 Marble、LucidDreamer）确实能生成逼真的 3D 场景，但它们本质上是一堆“凝固”的视觉资产——物体和背景死死粘在一起，既不能单独拎出来修改，也无法进行物理交互。WorldAct 的出现，就是为了解决这个痛点：它把这种“单体”（Monolithic）的 3D 场景，拆解成一个个可独立编辑、具备碰撞体积的“物体中心”（Object-Centric）场景。
### 为什么静态 3D 场景是个麻烦事？
现有的 3D 生成模型大多输出 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）格式。3DGS 渲染极快，但它是非结构化的点云集合。在这种格式里，桌子、椅子、墙壁在数学上没有任何区别，只是一堆高斯分布。如果你想让具身智能机器人（Embodied AI）去抓取一个杯子，它根本不知道杯子是个独立的实体；如果你想换个沙发，你只能把整个房间重新生成一遍。
WorldAct 的核心直觉非常务实： 不要试图去修改 3DGS 的内部结构，而是把 3DGS 当作“视觉参考”，重新构建一套结构化的资产。
### 方法拆解：Agent 驱动的自动化流水线WorldAct 的 pipeline 设计得很巧妙，它没有发明新的底层生成模型，而是把现有的 SOTA 工具（VLM、SAM3、SAM3D）串联了起来。
-Agent 发现可交互物体系统首先让一个视觉语言模型（如 Qwen3.6-Plus）遍历场景的关键帧。Agent 的任务不是简单的语义分割，而是找出“可操作”（Interactable）的物体。这一步过滤掉了墙壁、地板等静态背景，只保留如“花瓶”、“枕头”等独立物体。
-2D 到 3D 的掩码提升（Mask Lifting）
利用 SAM3 对视频帧进行分割，得到 2D 掩码。然后通过优化可学习的软分配分数（Soft Assignment Score），将这些 2D 掩码“投影”回 3D 空间，从而在原始 3DGS 中分离出属于每个物体的高斯点集。注意，这里分离出来的 3DGS 并不完美，它们只是用来定位物体空间位置的“代理”（Proxy）。
-背景修复与碰撞几何重建物体被移除后，背景会留下“洞”。WorldAct 使用 DiffuEraser 对视频帧进行修复，再通过 DepthLab 估计深度，用 Infusion 方法将修复后的内容升维到 3D，填补背景空洞。更重要的是，它从修复后的背景中提取了水密网格（Watertight Mesh），并通过 RANSAC 算法规整平面，生成了轻量级的碰撞代理（Collision Proxy）。这是实现物理交互的关键。
-高质量物体资产再生既然原始分离的 3DGS 不完整，WorldAct 干脆直接用 SAM3D，根据 Agent 挑选的最佳视角（考虑遮挡和语义置信度）重新生成干净、完整的 3D 物体资产（包含网格和纹理）。
-两阶段对齐（Alignment）
最后，通过 ICP（迭代最近点）和基于 DINOv2 特征的可微渲染优化，将新生成的物体精准放回修复好的场景中，确保视觉连贯且无穿透。
### 关键结果：不仅是好看，更是可用论文在 Marble 生成的 6 个室内场景（MWM 数据集）上进行了测试。数据非常有说服力：
- 物体发现率大幅提升：在没有 Agent 引导的基线方法中，可交互物体的召回率仅为 25.40%；引入 WorldAct 的 Agent 引导后，这一数字飙升至 83.98%。即使在更具挑战性的 MWM-hard 子集上，也从 20.49% 提升到了 68.43%。
- 视觉质量无损甚至提升：根据 ReMOVE 指标，背景修复后的场景干净程度（0.7951）略高于原始 3DGS（0.7933）。MANIQA 指标显示，整体感知质量从 0.3338 提升到了 0.3621。
- 用户主观评价：在 MOS（平均意见得分）测试中，虽然整体场景的自然度略有下降（从 4.20 降至 3.78），但物体级别的质量显著改善。原始物体因为粘连导致得分较低（如表面完整性 2.58），而 WorldAct 生成的独立物体得分高达 3.93。

- 解耦视觉与物理：不要指望生成模型直接输出完美的物理属性。WorldAct 证明了“先生成视觉参考，后提取结构化资产”的路线是可行的。
- Agent 的价值：在 3D 理解中，大模型（VLM）不仅仅是用来聊天，它能提供关键的语义筛选和视角选择，大幅降低了纯视觉算法的噪声。
- 工具链集成：WorldAct 本身是一个框架，它依赖 SAM3、SAM3D、DiffuEraser 等工具。这提示我们，未来的 3D 工作流将是多模型协作的，关键在于如何设计稳定的数据流转和对齐机制。
### 局限与展望目前 WorldAct 主要处理静态场景，对于 动态场景 、 铰接物体 （如开门、抽屉拉出）以及 物理属性 （质量、摩擦系数）的支持还不完善。此外，整个过程单张场景耗时约 1 小时，距离实时交互还有距离。但作为从“看”到“用”的第一步，WorldAct 已经铺平了道路。
