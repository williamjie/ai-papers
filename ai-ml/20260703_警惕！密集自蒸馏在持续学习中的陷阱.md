# ⭐⭐½ 警惕！密集自蒸馏在持续学习中的陷阱

**日期**: 2026-07-03

论文 : Denser neq Better: Limits of On-Policy Self-Distillation for Continual Post-Training链接 : https://arxiv.org/abs/2607.01763大模型后训练领域最近有个热门趋势：用“在线自蒸馏”（On-Policy Self-Distillation）来替代传统的强化学习。直觉上，这似乎是个完美方案——既保留了在线数据的分布优势，又通过 Token 级别的密集监督提高了样本效率。但如果你正在做持续学习（Continual Learning），这篇论文可能会让你停下手中的代码。
作者通过大量实验揭示了一个反直觉的结论： 更密集的监督信号并不总是更好。 在持续后训练场景下，自蒸馏策略优化（SDPO）虽然能加速当前领域的特化，却会导致严重的灾难性遗忘，甚至模型崩溃。相比之下，看似“低效”的序列级强化学习（如 GRPO）反而更能保留旧知识。
### 为什么我们会误以为“密集监督”是万能药？
现有的研究普遍认为，在线策略数据（On-Policy Data）能减少遗忘，而自蒸馏将稀疏奖励转化为密集的 Token 级监督，理应兼具两者优点。
但作者指出，这里混淆了两个关键因素： 数据来源 和 更新目标 。
- 数据来源：在线采样决定了训练历史的分布。
- 更新目标：决定在每个历史节点上强化哪种延续分布。
SDPO 的问题在于，当每个 Token 都成为训练目标时，教师模型（Teacher）的漂移、噪声推理链以及格式伪影会被反复放大。这就像老师自己也在边学边教，一旦老师犯了错，学生立刻学会并固化这个错误。
### 核心 Insight：稳定性比新鲜度更重要作者首先探究了教师模型的更新频率。直觉上，教师应该越“新”越好，以反映学生的最新进步。但实验显示，高频更新（EMA α=5%\alpha=5\% 5% ）反而导致性能暴跌。
反直觉发现 ：在数学任务中，使用 α=5%\alpha=5\% 5% 的快速 EMA 教师，AIME 得分仅为 34.38%，而冻结教师（ α=0\alpha=0 0 ）能达到 56.42%。
这是因为高频更新引入了“时间不稳定性”。SDPO 在每个 Token 上进行监督，微小的教师波动会在单次生成中被反复强化。
为了解决这个问题，作者提出了 StableSDPO ：周期性重启并冻结教师。
- 机制：每隔 kk 步从学生复制权重作为新教师，然后在接下来 kk 步内保持冻结。
- 效果：在 α=5%\alpha=5\%5% 的对比实验中，AIME 得分从 34.38% 回升至 55.00%，平均性能提升 6.50 分。
这证明了： 新鲜度是有用的，但前提是信号必须稳定。
### 持续学习中的“中间距离干扰”
在单领域训练中，SDPO 表现强劲（例如 Math500 提升至 84.29%）。但在多领域持续训练（Math -> Science -> Tool Use -> Coding）中，情况急转直下。
方法 当前阶段表现 (Current) 最终阶段表现 (Last) GRPO Math: 44.67% Math: 57.29% (+12.62%) SDPO0 Math: 56.42% Math: 34.38% (-22.04%) SDPO5% Math: 34.38% Math: 0.00% (崩溃)
- GRPO：适应较慢，但稳步提升，最终在所有领域均优于基线。
- SDPO：初期特化能力强，但随着新任务加入，旧任务性能断崖式下跌。Tool Use 任务在 SDPO0 下从 61.77% 暴跌至 9.93%。
作者发现，SDPO 的遗忘模式是非单调的： “中间距离干扰” 。
- 极相似任务：受益，因为特化方向一致。
- 极遥远任务：不受影响，因为扰动未触及。
- 部分对齐任务（如 GPQA）：受害最深。它们足够近以受到参数漂移的影响，又足够不同而无法从新监督中获益。
### 工程启示：别盲目追求 Dense Supervision- 持续学习慎用 SDPO：如果你的场景涉及多技能迭代，SDPO 的累积漂移会导致灾难性遗忘。GRPO 虽然慢，但其序列级奖励信号更保守，保留了 KL 最小化的隐式正则化效应。
- 教师模型需“稳”：如果必须用自蒸馏，避免每步更新教师。采用“重启-冻结”策略，或确保教师信号在时间上是稳定的。
- 警惕 CoT 噪声：对于长推理链任务（如 Math），蒸馏中间步骤会引入大量无关伪影。实验显示，带 CoT 的 SDPO 在数学和科学任务上反而表现更差，仅在短结构化的 Tool Use 中有效。
- 监控参数漂移：SDPO 会导致更大的奇异值谱偏移和响应流形变化。在工程中，应监控这些内部指标，而非仅看最终准确率。
### 局限与展望论文指出，SDPO 的失败源于其目标分布并非 KL 最小化的成功策略，而是包含特定推理痕迹的教师投影。未来的方向不在于让信号更密集，而在于 选择性监督 ：通过 Token 加权、教师控制或数据平衡，过滤掉有害伪影。
对于工程师而言，这篇论文是一个重要的警示： 在持续学习场景下，“快”不一定等于“好”。有时候，慢一点的 GRPO 才是更稳健的选择。
