这不仅仅是又一个注意力变体。如果结论成立，它意味着我们可以把复杂的注意力网络替换为一个静态缓存张量，彻底改变推理架构。
### 痛点：固定度量的局限性SDPA 的核心缺陷在于其度量空间的僵化。Query 和 Key 通过固定的线性投影计算相似度，这意味着模型无法根据输入上下文动态调整“相似”的定义。
现有的改进方案如 Talking-Heads Attention 或 Dynamic Bilinear Attention 尝试引入数据依赖的参数，但往往增加了巨大的计算开销，且缺乏数学上的收敛保证。我们需要一种既能保留 SDPA 效率，又能拥有动态度量能力的机制。
### 核心 Insight：从固定双线性到幂律图算子PLGA 的核心直觉是：注意力分数不应该只是点积，而应该是一个由输入生成的、经过幂律变换的双线性算子。
设计链条如下：
- 密度算子：计算 Query 的 Gram 矩阵 DQ=Q⊤QD_Q = Q^\top Q​=Q⊤Q，捕捉全局二阶统计量。
- 生成器：通过一个深层残差网络 Φres\Phi_{res}​（包含 iSwiGLU 激活）将 DQD_Q​ 映射为生成张量 AA。
- 幂律变换：对正定张量 ALMA_{LM}​ 进行逐元素幂运算 AP=ALM⊙PA_P = A_{LM}^{\odot P}​=ALM⊙P​，引入尺度不变性。
- 最终算子：线性组合得到双线性分数算子 GLMG_{LM}​，用于计算注意力分数。
⚠️ 关键设计细节 ：PLGA 牺牲了“历史行前缀一致性”（Historical-Row Prefix Consistency）。它使用全局 Query Gram 生成单一算子，共享给所有行。这与 Fast-Weight Programmer 等逐 token 更新状态的方法截然不同，旨在换取更强的全局结构感知能力。
### 惊人发现：推理时的经验坍缩论文最震撼的发现并非新架构本身，而是训练后的行为异常。
在预训练收敛后，原本应该随输入变化的生成器 AA 和最终算子 GLMG_{LM} ​ ，表现出了极端的 输入不变性 。

这意味着，对于训练好的模型，复杂的非线性子网络在推理时可以完全被一个 缓存的静态张量 替代。
