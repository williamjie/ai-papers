# 从网页到像素：让视觉感知具备搜索推理能力

**日期**: 2026-05-13

---

论文 : From Web to Pixels: Bringing Agentic Search into Visual Perception链接 : https://arxiv.org/abs/2605.12497在传统的多模态视觉感知任务中，我们通常假设模型要么能“看见”答案，要么模型内部的知识库（Frozen Knowledge）足以回答问题。但这在真实世界的开放场景中往往行不通：比如问“图中哪辆车是2026年CES展上发布的那款概念车？”，光看像素和模型参数，根本无从下手。这篇论文提出了一个极具工程落地价值的视角： Perception Deep Research ，即让视觉感知系统具备主动搜索外部事实、解决身份歧义，最后才进行像素级定位的能力。
### 痛点：当“所见”不足以“所知”
现有的 grounding 和 segmentation 模型（如 RefCOCO 系列或 LISA）主要依赖视觉线索（Visual Cues）或模型内部知识。然而，现实中的查询往往涉及最新事件、长尾实体或复杂的逻辑链条。例如，要找到“三星Galaxy Z TriFold在美国发售当月成为某护肤品牌全球大使的人”，这既不是纯视觉能解决的，也不是简单内部知识能覆盖的。
论文指出，现有的搜索增强方法（如 MMSearch）通常止步于文本答案，而真正的挑战在于 如何将搜索到的证据（Web Evidence）转化为具体的视觉输出（Box/Mask） 。这就是本文的核心洞察：视觉感知不仅仅是识别，更是“证据到像素”的绑定过程。
### 方法拆解：Pixel-Searcher 的双阶段工作流为了解决这个问题，作者提出了 Pixel-Searcher ，这是一个基于 Agent 的“搜索-推理-定位”工作流。它不再试图让大模型一次性完成所有任务，而是将问题拆解为两个关键阶段：
-Agentic Search & Target Resolution（搜索与身份解析）
这是最关键的一步。Agent 接收图像和问题，首先进行查询规划，将复杂问题分解为可搜索的子目标。接着进入“搜索-推理”循环：
Search：调用搜索引擎获取外部证据。
- Reason：连接事实，检查证据是否充足。
- Resolve：输出一个结构化的假设 h={e,c,K}h = \{e, c, K\}{e,c,K}，其中 ee 是解析出的实体名，cc 是视觉类别，KK 是可用于图像验证的关键线索。
设计直觉 ：这里的核心在于 去噪 。Agent 必须过滤掉无关的推理路径，只保留那些能在图像中通过视觉特征验证的线索。如果直接拿着原始问题去定位，模型极易被干扰项误导。
-Agentic Grounding & Tool Use（定位与工具调用）
一旦获得了明确的实体假设 hh，Agent 再利用这些线索在图像中定位目标。
Grounding：使用 hh 中的线索（如“黑色屏幕、双控制器”）在图像中匹配候选区域。
- Refinement：对于分割任务，将定位到的 Box 作为 Prompt 输入给 SAM3 等分割工具进行精细化掩码生成。
设计直觉 ：这一步将“语义匹配”转化为“视觉验证”。模型不再猜测“哪个是目标”，而是验证“哪个区域符合搜索到的事实”。
### 关键结果：开源模型在 WebEyes 上的突破为了评估这一设定，作者构建了 WebEyes 基准测试，包含 120 张图像、473 个标注对象和 1,927 个任务样本。实验结果显示，Pixel-Searcher 在开源模型中取得了最强性能，显著优于直接使用 Qwen3-VL-8B 基线模型。
表 1：Search-based Grounding (IoU / R@0.5) 对比Method Overall IoU Overall R@0.5 Qwen3-VL-8B (Baseline) 26.81 32.61 Pixel-Searcher (Ours) 34.17 41.30 GPT-4o (Closed-source) 6.59 2.60 Gemini-3.1-Pro 30.52 35.09表 2：Search-based Segmentation (gIoU / cIoU) 对比Method Overall gIoU Overall cIoU Qwen3-VL-8B (Baseline) 35.78 25.94 Pixel-Searcher (Ours) 39.17 32.41 LISA-7B 35.60 25.94 Seg-R1-7B 23.72 17.64从表中可以看出，引入搜索机制后，Open-source 模型在 Grounding 和 Segmentation 上均有显著提升（IoU 提升约 7.36%，gIoU 提升约 3.39%）。而在 Search-based VQA 中，准确率也从 36.34% 提升至 42.24%。值得注意的是，Pixel-Searcher 在开源模型中表现最佳，虽然与 GPT-4o 等闭源模型仍有差距，但证明了 Agentic Workflow 对通用多模态模型能力的放大作用 。
### 工程启示与局限1. 错误分析揭示瓶颈消融实验和失败分析表明， 78% 的错误发生在搜索和实体解析阶段 （304/389 failures），而非最后的掩码生成阶段（仅 10 例）。这意味着，如果搜索到的证据错误，或者实体解析偏差，后续的视觉定位将毫无意义。这提示我们在设计视觉 Agent 时， 证据链的可靠性比分割工具的精度更重要 。
2. 对工程落地的指导- 不要试图用端到端模型解决所有问题：对于知识密集型视觉任务，显式的“搜索-解析-定位”流程比端到端预测更鲁棒。
- 结构化中间表示：将搜索到的非结构化文本转化为结构化的视觉线索（KK），是连接 NLP 和 CV 的关键桥梁。
- 验证闭环：必须引入“矛盾检查”（Contradiction Checking），确保解析出的实体与图像中的视觉特征不冲突。
3. 局限当前方法严重依赖搜索 API 的可用性和时效性（论文设定为6个月内的数据）。此外，对于极度模糊或遮挡严重的图像，即使证据正确，视觉实例绑定（Visual Instance Binding）仍可能失败。
### 总结这篇论文不仅提出了一个新基准，更提供了一套**“从网页到像素”**的系统化解决方案。它告诉我们，在开放世界中，视觉感知不再是封闭的识别游戏，而是与外部世界实时交互的认知过程。对于开发者而言，构建具备搜索和推理能力的视觉 Agent，是迈向真正通用人工智能（AGI）视觉模块的重要一步。
