论文 : Demystifying Hidden-State Recurrence: Switchable Latent Reasoning with On-Policy Reinforcement Learning链接 : https://arxiv.org/abs/2606.13106潜空间思维链（Latent CoT）一直被视为压缩推理成本的关键路径，但现有方案要么无法兼容主流强化学习算法，要么像黑盒一样难以调试。这篇来自 HKUST(GZ) 等机构的论文提出了 Switch 框架，通过引入显式的边界 Token，巧妙地解决了这两个工程痛点，让潜空间推理既可用 GRPO 训练，又能被机制分析“看透”。
### 痛点：隐式边界的代价现有的隐藏状态循环（Hidden-State Recurrence）方法（如 Coconut）将推理过程隐藏在连续向量中。这带来两个致命问题：
- RL 失效：标准 On-Policy RL（如 GRPO）依赖 Token 采样概率计算策略梯度。潜空间步骤不输出 Token，导致策略密度未定义，GRPO 无法直接应用。
- 不可解释：没有明确的起止标记，分析师无法确定模型是在进行有效计算，还是仅仅在“假装思考”以补偿上下文。
### 核心 Insight：用显式边界重构问题Switch 的核心设计直觉非常简洁： 引入一对显式的离散边界 Token <swi> （进入）和 </swi> （退出） 。
这一设计一举两得：
- 兼容 RL：边界 Token 是普通离散符号，使得 GRPO 的策略比率在每个决策点都有定义。潜空间步骤本身不贡献策略梯度项，但整个轨迹的似然分解依然成立。
- 可解释性锚点：边界 Token 为机制分析提供了抓手。我们可以直接测量 p(<swi>)p(\text{<swi>}))，甚至对潜状态进行因果干预。
训练分为三阶段：
- SFT 定位：标记高熵 CoT 片段，教会模型何时使用 <swi>。
- 课程学习：逐步用 <latent> 占位符替换边界内的文本，强制模型在潜空间进行计算。
- Switch-GRPO：基于答案正确性和格式奖励进行强化学习。
### 实验结果：性能与效率的双赢在 Qwen3-8B 基座模型上，Switch 的表现显著优于同类方法。

### 机制分析：潜空间到底在干什么？
借助边界 Token，作者进行了深入的机制探针实验，揭示了三个反直觉事实：
- <swi> 是真正的控制策略：在标注位置，p(<swi>)p(\text{<swi>})) 高达 0.532（GRPO后），而在随机位置仅为 10−310^{-3} 级别。这不是风格化标记，而是清晰的决策信号。
- 潜步骤具有因果重要性：通过因果干预实验，将潜状态置零会导致诊断子集准确率从 100% 暴跌至 33.3%；而跳过潜步骤则下降 19.0%。证明潜空间确实在执行关键计算，而非冗余填充。
- 计算集中在入口处：Logit Lens 分析显示，模型在第一个潜步骤后几乎立即准备好退出（p(</swi>)≈1p(\text{</swi>}) \approx 1)≈1）。实际的推理工作主要发生在进入潜空间的那一次隐藏状态转换中，后续步骤更多是维持状态而非新增信息。
### 工程启示对于致力于降低推理延迟的工程师，Switch 提供了明确的落地路径：
- 架构改造成本低：只需扩充词表并修改 Embedding 注入逻辑，无需改变 Transformer 主体结构。
- RL 兼容性好：可以直接复用现有的 GRPO/RLHF 基础设施，无需重新发明训练轮子。
- 可解释性优势：显式边界使得调试成为可能。你可以明确知道模型何时“思考”，并通过探针验证其内部状态是否合理，这对于 Agent 系统的可靠性至关重要。
### 局限与展望目前实验仅限于 8B 模型和数学推理任务。论文指出，潜表示主要由 SFT 阶段塑造，RL 主要优化文本部分。未来工作可探索让潜 Token 本身也可采样，以进一步融合隐藏状态循环与词汇混合方法的优势。
