## 模型 Top 5### 1. unsloth/Kimi-K3Unsloth 又来了，这次给 Kimi-K3 套了个“压缩张量”的马甲。原模型是月之暗面的多模态大模型，Unsloth 只是做了量化/剪枝，但标签里既没写基础模型也没给 benchmark 对比，README 大概率就一行“we compressed it”。167 个点赞搭配 410 下载，热度全靠 Unsloth 的品牌光环——这波操作跟当年给 Llama 3 出 4-bit 版本如出一辙，技术含量约等于跑了个 bitsandbytes 脚本。
### 2. unsloth/Kimi-K3-GGUF同一个模型，换了个 GGUF 壳再发一次，下载量直接挂零——连刷榜都懒得刷全。GGUF 版本给 llama.cpp 用户用，但既然原版量化都没人下，这个版本纯粹是占个位。Unsloth 能不能学学人家 prism-ml，搞点真·三值量化出来？这种“同一个模型拆成两个 repo”的骚操作，除了污染 trending 榜单，我看不出任何技术价值。
### 3. prism-ml/Ternary-Bonsai-27B-gguf三值量化的 27B 模型，下载量 66 万，点赞 1095——这才是真热门。Ternary（三值）把权重约束到 {-1, 0, 1}，相当于 1.58-bit，理论推理速度暴增。但注意标签里写了“2-bit”，说明实际实现可能用了混合精度或做了校准，不是纯粹的 1.58-bit。不过 27B 参数用三值量化后存储不到 5GB，确实适合边缘部署。唯一要吐槽的是名字“Bonsai（盆景）”——你一个 27B 模型叫盆景，那 70B 是不是叫“巨树”？营销味有点重，但技术底子硬，该夸。
三值量化是当前最激进的压缩方向，但 benchmark 里只跑了一堆小测试，没见到 MMLU 或 HumanEval 结果——别又是“压缩了但智商也压缩了”的翻车现场。
### 4. baseten/GLM-5.2-Vision-NVFP4Baseten 把 GLM-5.2 视觉模型用 NVFP4（NVIDIA 4-bit 浮点量化）压了一刀。NVFP4 是硬件亲儿子，在 H100/B200 上能白嫖加速。但问题在于 GLM-5.2 本身是多模态，量化后视觉编码器的精度损失有没有评估？136 个点赞，2756 下载，说明大家还是想试试。不过 README 里大概率只写了“我们用 NVFP4 量化了”，连个消融实验都没有——这种“一键量化”的 repo 看多了，真以为自己是技术贡献者？
### 5. nota-ai/Solar-Open2-250B-Nota-NVFP4250B 的稀疏专家（MoE）模型量化到 NVFP4，这操作够猛。Solar-Open2 原本就是韩国 nota 的 MoE 模型（注意不涉及地缘），现在被自家再量化一遍。下载 6189，点赞 137，热度还行。但 250B MoE 激活参数可能只有 30-40B，量化后性价比确实高。唯一槽点：标签里有 vllm 和 safetensors ，但没看到推理速度对比——你量化完总得给个 QPS 提升吧？不然我凭什么相信 NVFP4 比 FP8 好？
## 数据集 Top 3### 1. Glint-Research/Fable-5-tracesAgent 轨迹数据集，点赞 684 但 trendingScore 只有 27，说明这是个老数据集被翻上来了。Fable 系列是用于训练 agent 推理的轨迹数据，5-traces 指每个任务 5 条轨迹？标签写“machine-generated”，大概率是拿 GPT-4 或 Claude 跑的合成数据。这种数据质量取决于采样策略，但 README 里大概率只说了“我们收集了……”，没有去重和清洗的详细说明。下载 5.5 万，说明大家缺 agent 数据——但合成数据的“幻觉传递”问题，你们考虑过吗？
### 2. AlicanKiraz0/Turkish-CoT-Instruct-Dataset土耳其语思维链（Chain-of-Thought）指令数据集，规模 1K-10K，点赞 18，下载 122。土耳其语资源稀缺，这个方向值得鼓励，但 1K 样本能干啥？训练一个 7B 模型都容易过拟合。大概率是从英文 CoT 数据集机器翻译加人工校验搞出来的，但翻译质量没公布 BLEU 分数。建议作者把样本量做到 10K 以上，否则只能当玩具。
### 3. NVEagle/LocateAnything-Data视觉定位数据集，用于“定位任何物体”，对应论文 arxiv:2605.27365。下载 7888 但点赞只有 18，说明大家默默下载但不想点赞——可能是因为数据格式是 webdataset，处理起来麻烦。标签里包含 document-layout-analysis、GUI-grounding 等，覆盖面广。但 18 个点赞暴露了问题：这种通用定位数据往往质量参差不齐，没有人工校验的 bounding box 你敢直接用？不如去用 Grounding DINO 的官方数据。
