# ⭐⭐⭐½ 闭源带开源：用结构化协议解决蒸馏风格漂移

**日期**: 2026-07-28

---

论文 : From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search链接 : https://arxiv.org/abs/2607.24280让开源小模型学会闭源大模型的“搜索+推理”能力，是当下的热门需求。但直接模仿往往适得其反：学生模型不仅没学到本事，反而染上了老师的啰嗦毛病。这篇论文提出的 MAPD 框架，通过一种巧妙的“中间层”设计，真正实现了跨模型的认知迁移。
### 为什么直接蒸馏行不通？
在 Agentic Search（智能体搜索）场景中，现有的强化学习（RL）往往只给最终结果打分，信号太稀疏。于是大家想引入知识蒸馏来提供密集的监督信号。但这里有两个硬伤：
- 黑盒不可见：闭源模型没有 Logits，且 Tokenizer 不兼容，传统的分布对齐数学上就不成立。
- 风格漂移（Style Drift）：这是最致命的坑。如果直接让开源模型模仿闭源模型的自由文本轨迹，学生会过度拟合老师的语言风格（比如特定的啰嗦句式）。结果就是：学生模型变得冗长、幻觉增多，核心推理能力却没提升。
⚠️ 反直觉发现 ：论文实验显示，直接用闭源模型的原始自然语言轨迹进行蒸馏，效果甚至不如完全不使用闭源模型的基线！因为“学坏了”比“没学”更糟糕。
### 核心 Insight：结构化协议作为中间表示MAPD 的核心直觉是： 剥离语言外壳，只提取认知骨架 。
作者没有直接传递文本，而是引入了一种**结构化 JSON 协议（Structured Protocol）**作为中间表示。这个协议包含五个关键维度：
- 任务类型：单跳、多跳还是对比？
- 推理计划：分解后的子目标数组。
- 事实依据：从检索结果中提取的确凿证据。
- 部分发现：即使最终失败，中间的有效信息也要保留。
- 答案验证：布尔值标记答案是否被证据支撑。
这种设计的妙处在于，它将“核心策略”与“语言风格”解耦了。学生模型不再需要模仿老师怎么说话，只需要对齐这个结构化的认知流程。
### 方法拆解：离线多智能体 + 在线联合训练整个流程分为两步：
-离线合成（MAS Pipeline）：
利用闭源大模型驱动一个多智能体系统（MAS）。包括编排者、搜索者和修复者。它们负责拆解问题、检索证据，甚至利用 Ground Truth 进行错误诊断和修复。最终输出高质量的 JSON 协议。这一步完全离线，不增加推理延迟。
-在线训练（Joint Training）：
采用 GRPO（强化学习）+ OPSD（在线策略自蒸馏）的联合目标。
特权分支：看到 JSON 协议，提供密集的监督信号。
- 学生分支：看不到协议，只根据环境反馈和自身生成分布进行优化。
通过最小化这两个分支之间的 KL 散度，学生模型在保持自身语言风格的同时，内化了老师的搜索策略。
### 关键结果：小模型也能有大智慧作者在 Qwen3-1.7B 和 Qwen3-4B 上进行了广泛测试，结果令人印象深刻：

关键发现：
- 多跳推理提升显著：在复杂的 MuSiQue 和 Bamboogle 数据集上，MAPD 相比最强的基线 SDAR 分别提升了 +5.7% 和 +15.0%。这证明了结构化协议对复杂逻辑拆解的有效性。
- 跨模型泛化能力强：无论是用 Claude、GPT 还是 Gemini 作为老师，只要生成 JSON 协议，学生模型的性能波动很小（在 ±2% 以内）。这意味着你可以随意切换底层的闭源 API 以优化成本，而无需重新调整训练管线。
### 工程启示与局限对工程师的价值：
- 不要直接模仿文本：在做知识蒸馏时，尤其是跨 Tokenizer 或跨风格时，引入结构化的中间表示（如 JSON、思维链图谱）能极大缓解风格漂移。
- 离线合成，在线轻量化：MAPD 将昂贵的多智能体协作放在离线阶段，训练时只依赖简单的自蒸馏目标。这种“重离线、轻在线”的思路非常适合资源受限的部署场景。
- 平衡蒸馏强度：论文指出，蒸馏权重 λ\lambda 过大（如 0.1）会导致模型退化，变成“只检索不推理”。找到那个 Sweet Spot（文中为 0.05）至关重要。
局限与思考：
- 依赖高质量协议：如果离线生成的 JSON 协议本身质量不高（比如证据提取错误），学生模型会学到错误的逻辑。论文中提到的 99.33% 的质量通过率虽然高，但构建这样的质检管线本身也有成本。
- 仅适用于可结构化任务：对于高度创造性或无法清晰分解为“计划-执行-验证”的任务，这种结构化协议可能难以设计。
总的来说，MAPD 提供了一套优雅的解决方案，证明了在蒸馏过程中，“形式”往往比“内容”更需要被规范。
