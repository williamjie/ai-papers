# ⭐⭐⭐½ 告别长程幻觉：用信念熵给 Agent 记忆做 RLVR

**日期**: 2026-06-05

---

论文 : Meta-Cognitive Memory Policy Optimization for Long-Horizon LLM Agents链接 : https://arxiv.org/abs/2605.30159让大模型（LLM）处理超长上下文任务，核心痛点不在“读不懂”，而在“记不住”。
现有的记忆增强 Agent 通常采用递归摘要策略：每轮对话后压缩历史为紧凑记忆。
但这就像玩“传话游戏”，信息在多次转述中必然丢失或扭曲，导致长程推理崩溃。
这篇来自腾讯、中科大和浙大的联合工作，提出了一种新颖的强化学习（Reinforcement Learning, RL）思路： 不仅看最终结果对错，更要看中间记忆是否清晰。
### 痛点：稀疏奖励无法定位“记忆污染”
目前的 Agent 训练多依赖基于可验证奖励的强化学习（RLVR）。
简单说，就是任务做对了给 +1，错了给 -1。
这种**稀疏奖励（Sparse Reward）**存在严重的信用分配问题：当任务在 50 步后失败时，模型根本不知道是哪一步的记忆摘要引入了噪声。
作者将长程推理建模为部分可观测马尔可夫决策过程（POMDP）。
核心 Insight 是： 递归摘要中的语义噪声，本质上是 Agent 对潜在任务状态的“信念偏差”（Belief Deviation）。
如果中间记忆模糊不清，Agent 就无法准确估计当前任务进度，最终导致推理脱轨。
### 方法：用“元认知探针”量化记忆清晰度为了解决上述问题，作者提出了 MMPO（Meta-Cognitive Memory Policy Optimization） 。
其核心创新在于引入了一个自监督信号—— 信念熵（Belief Entropy, HBEH_{BE} ​ ） 。
由于潜在任务状态不可直接观测，作者受认知科学启发，设计了一个“元认知探针”：向模型抛出一个锚点问题（Anchor Question）。
“基于当前记忆，我们的任务进度如何？还需要哪些信息？”
模型对这个问题的回答不确定性（即预测熵），就被定义为信念熵。
- 低熵：回答集中、自信，说明记忆清晰，信念稳定。
- 高熵：回答犹豫、发散，说明记忆模糊或存在幻觉。
在训练时，MMPO 不再仅依赖最终奖励，而是将信念熵转化为密集的中间步骤奖励。
具体公式中，通过 Sigmoid 函数归一化熵值，并与最终结果奖励加权结合。
这意味着： 即使最终任务成功，如果中间记忆混乱（高熵），模型也会受到惩罚；反之，清晰的记忆过程会得到正向激励。
这种细粒度的监督迫使记忆策略（Memory Policy）在每一步都努力保持信息的保真度。
### 实验：长上下文下的显著增益作者在 RULER-HotpotQA 基准上进行了详尽测试，对比了 MemAgent 等基线。
数据非常直观地展示了 MMPO 的优势，尤其是在极端长上下文中。

- 探针设计至关重要：消融实验显示，“进度+缺口”双重探针效果最佳（准确率 82.98%），单纯询问答案会导致模型过早自信，反而降低性能。
### 工程启示与局限对工程师而言，这篇论文提供了两个重要信号：
- 过程监督优于结果监督：在训练 Agent 的记忆模块时，不要只盯着最终 Answer。引入中间状态的“清晰度”评估（如困惑度、熵），能显著抑制幻觉累积。
- 低成本自监督信号：信念熵的计算无需外部标注，仅通过模型自身的预测分布即可获得。这使得该方法易于集成到现有的 RLVR 流水线中，且计算开销可控。
当然，方法也有边界。
锚点问题的设计需要针对具体任务类型进行调整（如 QA 类 vs 工具调用类）。
此外，该方法主要优化记忆策略，对于底层推理模型的改进是间接的。
但在长程任务日益普及的今天， “记住什么”比“怎么推理”更决定下限。 MMPO 为构建稳定、可靠的长程 Agent 提供了一条极具工程价值的路径。
