## 模型 Top 5### 1. Qwen/Qwen-AgentWorld-35B-A3B世界模型 + Agent 环境模拟，这组合拳打出来确实唬人。35B 总参、3B 激活的稀疏专家（MoE）架构，理论上推理效率不错，但 223 次下载对上一个刚发的新模型来说，连尝鲜的都嫌少——可能是 README 里把“世界模型”吹得太大，大家怕跑不起来。另外 tags 里挂着 image-text-to-text ，但看描述更像纯文本 agent 环境生成，多模态能力有没有兑现？建议先把 demo 跑通再画饼。
### 2. krea/Krea-2-Raw171 个点赞换 1205 下载，转化率还行，说明大家还是想看看“Raw”到底有多 raw。Krea-2 本身是文本到图像生成器，但 Krea2Pipeline 这名字跟闹着玩似的，生怕别人不知道你套了 diffusers 壳。更诡异的是 region:us 标签——一个开源模型还搞区域限制？要么是训练数据有版权地雷，要么是作者不想让欧洲人用。建议把 license 写清楚，别让社区猜谜。
## 数据集 Top 3### 1. Qwen/AgentWorldBenchAgentWorld 模型的亲儿子 benchmark，21 个点赞、87 次下载，热度 20，惨淡得像是内部测试数据硬塞到 HF 上凑数。数据量才 1K-10K 条，做文本生成评估勉强够用，但想测 agent 泛化能力？洗洗睡吧。更离谱的是 modality 同时标了 tabular 和 text，到底是结构化表格还是自由文本？你俩先打一架再发布行吗。
### 2. allenai/olmOCR-bench244 点赞、5929 下载，这数据量才是 benchmark 该有的样子。作为 OCR 的官方评估集，有论文支撑（arxiv:2502.18443），可信度比那些拍脑袋的 benchmark 高一个数量级。但热度才 15，说明 OCR 这赛道现在是真的凉——大家都在卷多模态大模型，谁还专门调 OCR 啊？不过做文档理解的朋友可以捡漏，数据质量看着比那些从 PDF 乱抓的干净。
### 3. Crownelius/Complete-FABLE.5-traces-2M200 万条机器生成的 FABLE.5 轨迹数据，13 个点赞、674 下载，热度 13。名字里带“Complete”却只标了 MIT license，感觉像是某个 RL 项目的副产品，作者随手丢上来刷存在感。机器生成的数据，标注者又是 machine-generated，这闭环里有多少噪声？建议先跑一个小的 probing 实验再决定要不要全量喂给模型，不然容易学出一堆“幻觉轨迹”。
