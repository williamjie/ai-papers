# ⭐⭐⭐½ 让大模型学会“找路”：主动探索视角的复现

**日期**: 2026-06-02

---

论文 : Where to Look: Can Foundation Models Reach a Target Viewpoint Through Active Exploration?
链接 : https://arxiv.org/abs/2606.01247现在的多模态大模型（MLLM）大多是“被动观察者”，给定图片问你看到了什么。但真实世界里，智能体需要主动移动、转头去寻找目标。这篇论文提出了 Target Viewpoint Reproduction (TVR) 任务：给模型一张目标视角的图片，让它通过身体平移和头部旋转，在 3D 环境中复现这个视角。这不仅是视觉匹配，更是闭环的感知-行动控制。
### 为什么现在的模型连“找路”都做不到？
研究者构建了 TVRBench 基准，涵盖单房间和多房间场景。结果令人沮丧：最强的开源模型（Qwen3.5-27B）成功率仅 7.8% ，闭源最强（Gemini-3.1-Pro）也只有 12.0% 。相比之下，人类在子集上的成功率高达 93.0% 。
⚠️ 反直觉发现 ：模型失败的主要原因不是“看不懂图”，而是“不会走路”。
实验显示，如果只允许旋转头部（不移动身体），Qwen3.5-9B 的成功率能从 2.8% 飙升至 80.5% 。这说明模型擅长静态视角匹配，但极难将空间差异映射为身体的平移动作。
此外，模型存在严重的“记忆幻觉”。在长序列中，包含完整视觉历史的上下文（Visual-Action Memory）反而比仅记录动作摘要（Action-Only Memory）表现更差，平均低 3.8% 。未训练的 9B 模型平均每集只访问 3.5 个不同网格位置，且 83% 的动作是原地打转或来回走动。
### 怎么训练？SFT 是主力，RL 需小心为了提升性能，论文对比了四种后训练策略：专家轨迹监督微调（SFT）、思维链 SFT、单步 GRPO 强化学习、以及多步在线 GRPO。
核心结论非常明确：
- 视觉-动作 SFT 是基石：使用包含完整视觉历史的专家轨迹进行微调，且不加思维链（CoT），Qwen3.5-9B 的成功率从 2.8% 提升至 50.8%。
- CoT 反而有害：加入思维链监督后，成功率反而下降至 35.6%。这暗示当前的 CoT 标注未能提供有效的控制策略，甚至干扰了动作学习。
- 多步 RL 精调长程任务：在 SFT 基础上，使用在线滚动的多步 GRPO（Multi-turn GRPO），整体成功率微增至 51.4%。其最大价值在于修复了 SFT 在多房间长距离探索中的短板（Multi-easy 从 27.2% 升至 34.4%）。
- 单步 RL 是灾难：使用离线单步数据进行的 GRPO 训练，导致性能大幅退化（从 44.2% 降至 26.2%）。这是因为 TVR 是多步闭环任务，单步奖励无法捕捉长期的空间推理逻辑。
### 工程启示：做具身智能 Agent 的三个坑- 别迷信 CoT：在需要精确动作控制的场景中，中间推理过程可能引入噪声。直接学习“状态-动作”映射（SFT）往往比让模型“想清楚再动”更有效。
- 记忆管理至关重要：对于长程探索任务，全量视觉历史不仅增加 Token 成本，还降低性能。工程上应设计更紧凑的记忆结构（如仅保留关键帧或动作摘要），而非简单堆砌图像。
- RL 的奖励粒度要匹配任务结构：如果任务是单步决策（如分类），单步 RL 有效；如果是多步规划（如导航、复现视角），必须使用轨迹级（Trajectory-level）的奖励信号，否则模型会过拟合局部最优而失去全局目标感。
### 局限与展望目前 TVRBench 仍基于离散网格和模拟器（AI2-THOR/ProcTHOR）。真实物理世界是连续的，且存在传感器噪声。此外，研究仅在 9B 模型上验证了后训练框架，更大规模模型的表现仍有待探索。但这篇论文提供了一个清晰的测试床，证明让基础模型从“看图说话”转向“主动探索”，仍需跨越巨大的空间-动作映射鸿沟。
