论文 : Augmenting Attention with Exponentially Decaying Memory Improves Query-Aware KV Sparsity链接 : https://arxiv.org/abs/2605.28640长文本推理的算力瓶颈主要在 KV Cache 和注意力计算。目前的工程界主流做法是“下游优化”：在模型训练完成后，通过 Quest、SnapKV 等算法动态剪枝或压缩 KV Cache。
但这篇论文提出了一个反直觉的观点： 与其死磕剪枝算法，不如改造上游架构。
作者发现，如果在标准 Attention 基础上增加一个轻量级的指数衰减记忆模块（即 RAT+ 架构），现有的稀疏推理方法准确率会大幅提升。这不仅是架构创新，更是给工程落地指了一条新路。
### 痛点：稀疏推理在极端预算下“崩盘”
现有查询感知的稀疏推理方法（如 Quest、MoBA、SnapKV）虽然有效，但在高稀疏度下表现不佳。
例如，当 KV Cache 压缩到 1/16 时，标准 Attention 架构下的 SnapKV 准确率会断崖式下跌。这是因为稀疏选择往往依赖局部注意力分数，一旦关键 Token 被错误丢弃，信息就永久丢失了。
### 核心 Insight：用“记忆”弥补“稀疏”的损失论文的核心方法是引入 RAT+ (Recurrence-Augmented Attention) 架构。
它并不改变标准 Attention 的计算逻辑，而是增加了一个轻量级的循环模块，对 Key 和 Value 状态进行指数衰减更新：

- 信息平滑：记忆模块充当了“缓冲池”，即使某个关键 Token 未被当前查询选中，它的信息也会通过衰减记忆保留在上下文中。
- 选择增强：经过记忆增强的 KV 状态包含更丰富的历史信息，使得稀疏选择器（Selector）能更准确地识别出真正重要的 Block 或 Token。
### 实验数据：提升幅度令人震惊作者在 RULER 基准的 Needle-in-a-Haystack (NIAH) 任务上进行了测试，对比了标准 Attention 和 RAT+ 架构在三种主流稀疏方法下的表现。

### 工程启示：架构即优化这篇论文对 LLM 推理优化的指导意义在于：
- 上游改造优于下游修补：与其在推理时不断调优剪枝阈值，不如在预训练或继续预训练阶段引入轻量级记忆模块。
- 低成本高回报：RAT+ 仅增加 O(1)O(1) 的计算和存储开销，但能显著提升稀疏推理的鲁棒性。
- 适用场景：对于需要极端压缩 KV Cache 的场景（如边缘设备部署、超长上下文 Agent），采用具备记忆增强能力的模型架构是更优解。
### 局限与展望目前实验主要基于 4K 上下文长度和合成 NIAH 任务。在实际的自然语言理解和代码生成任务中，这种增益是否依然显著，仍需进一步验证。此外，RAT+ 需要额外的继续预训练（Continued Pretraining），对于闭源模型无法直接应用。
但对于自研模型团队而言，这是一个值得尝试的架构改进方向： 用极小的计算代价，换取稀疏推理的巨大容错率。
