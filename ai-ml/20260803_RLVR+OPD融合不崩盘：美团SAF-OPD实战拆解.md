论文 : SAF-OPD: Stable Advantage Fusion for On-Policy Distillation链接 : https://arxiv.org/abs/2607.29209在强化学习（RL）微调大模型时，把可验证奖励（RLVR）和在线蒸馏（OPD）结合起来是提升推理能力的热门路径。但直接相加往往导致训练崩溃或性能封顶，美团 LongCat 团队提出的 SAF-OPD 提供了一套轻量且稳定的融合方案。
### 为什么简单相加会翻车？
直觉上，RLVR 提供稀疏但经过验证的全局奖励，OPD 提供密集但依赖教师模型的对齐信号，两者互补。然而，直接将 GRPO 的响应级优势（Advantage）与 OPD 的 Token 级优势相加，存在两个致命错配：
- 幅度错配（Magnitude Mismatch）：GRPO 的优势经过组内归一化，是有界的；而 OPD 基于对数概率差计算，无界且呈重尾分布。实验显示，部分极端 Token 的 OPD 优势值可达 20.35，远超 GRPO 的最大值 2.47。这导致少数 Token 主导梯度更新，引发策略熵（Entropy）过早坍塌。
- 时间错配（Temporal Mismatch）：训练初期需要强教师引导，但后期若持续高强度蒸馏，学生会过度拟合教师分布，丧失探索能力，导致性能天花板低于纯 RLVR 方法。
### SAF 核心设计：四阶段轻量流水线SAF（Stable Advantage Fusion）不引入额外模型或损失函数，仅对 OPD 优势信号进行预处理，通过四个可独立开关的阶段解决上述问题：
1. 幅度控制：稀疏化 + 压缩- Top-k% 稀疏化：保留每条序列中绝对值最大的前 k% Token（默认 k=20），其余置零。这利用了 OPD 优势集中在少数关键 Token 的特性，过滤噪声。
- Tanh 压缩：对剩余信号应用 c⋅tanh⁡(x)c \cdot \tanh(x)tanh(x) 变换（默认 c=0.1）。将无界信号映射到有限区间，防止极端值淹没 GRPO 信号。
2. 时间控制：预热 + 退火- KL 触发预热：OPD 系数从 0 线性增长至 1。当学生与教师的 KL 散度下降超过阈值 δ\delta（默认 0.2）时，提前结束预热。这确保在有效差距缩小后停止强化模仿。
- 线性退火：预热结束后，OPD 系数线性衰减至最小值 cminc_{min}​（默认 0）。让 GRPO 重新主导后期训练，鼓励超越教师模型的探索。
### 实验结果：稳定且全面领先在 Qwen3-1.7B/4B/8B 模型上，SAF 在所有数学推理和代码生成基准测试中均优于固定系数融合基线。

### 工程启示- 信号量纲必须对齐：在融合不同来源的优势函数时，务必检查其分布范围。无界信号必须经过归一化或截断处理，否则梯度更新会被噪声主导。
- 动态调整信任度：教师模型并非全知全能。训练策略应随学生能力提升而动态降低对教师的依赖，从“模仿”平滑过渡到“探索”。
- 低成本改进：SAF 仅需修改优势计算逻辑，无需额外前向传播或辅助损失，可直接集成到现有 GRPO 训练中，工程落地成本极低。
### 局限与展望该方法目前仅在 Qwen3 系列模型和特定数学/代码数据集上验证。对于其他架构或领域（如长文本生成），其超参数（如 k, c, δ\delta ）可能需要重新调优。此外，如何更精确地量化“教师错误”并动态调整蒸馏强度，仍是值得探索的方向。
