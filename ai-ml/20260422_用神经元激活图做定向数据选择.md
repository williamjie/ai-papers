# 用神经元激活图做定向数据选择

**日期**: 2026-04-22

---

论文 : Target-Oriented Pretraining Data Selection via Neuron-Activated Graph链接 : https://arxiv.org/abs/2604.15706预训练数据选择早就过了”挑高质量数据就完事”的阶段了。Wikipedia 和 FineWeb-Edu 确实干净，但干净不等于有用——你想让模型学会数学推理，喂它再多的科普文章也白搭。这篇论文的核心洞察很直接：让数据选择和目标任务对齐，而不是靠启发式规则盲选。
关键问题来了：怎么判断一段文本和某个目标能力”对齐”？现有方案要么靠最后一层 embedding 的相似度（BETR），要么靠蒸馏出黑盒分类器。问题在于，最后一层 embedding 容易混淆语义和风格特征，黑盒蒸馏则彻底失去了可解释性。
这篇论文给出了第三条路： 看神经元，不看向量。
## 痛点：高质量 ≠ 目标相关图 1 把问题画得很清楚。通用质量筛选（比如 FineWeb-Edu）选出来的数据，跟数学推理能力根本不是一回事。而基于 embedding 相似度的方法，找到的也只是”表面相似”的数据——定义最大值是什么，不等于会求最大值。
真正需要的是：能触发模型内部 相同神经元模式 的数据。
## 方法：Neuron-Activated Graph (NAG)
NAG 的核心设计直觉是： 不同任务依赖不同的神经元子集，同一任务会激活相似的神经元组合。
具体怎么做？分三步：
第一步：量化神经元影响力（Neuron Impact）
对每个输入，计算每个神经元对层输出的贡献大小。具体做法是：把投影矩阵的某一列（即一个神经元）置零，看层输出的变化量。公式很简单：
Imp(N_k | h_in) = ||h_in^T W_{:,k}||²本质就是看该神经元的列向量对输出的模长贡献。不需要算最终 loss，局部近似就够了——论文在附录 C 验证了这个 proxy 和 loss 变化高度相关。
第二步：构建神经元激活图（NAG）
对每一层，按影响力排序，取 Top-K 个高影响力神经元。整个 NAG 就是跨层的神经元索引集合：
NAG(c) = { (ℓ, k) | ℓ ∈ {1,...,L}, k ∈ 第ℓ层的Top-K神经元 }这相当于给每个输入画了一张”神经元使用热力图”，极其稀疏但高度结构化。
第三步：基于 NAG 相似度的数据排序给定一组目标样本 D_target，计算每个神经元在所有层上的激活频率，形成目标 profile：
w_{ℓ,k}(D) = (1/|D|) Σ_{c'∈D} 1[(ℓ,k) ∈ NAG(c')]然后对候选数据 c，计算它与目标 profile 的相似度：
Sim(c, D) = Σ_ℓ Σ_{k∈NAG_ℓ(K)(c)} w_{ℓ,k}(D) / Σ_ℓ Σ_k w_{ℓ,k}(D)
简单说： 候选数据的神经元如果跟目标数据的神经元高度重叠，就排在前面。
最骚的是—— 全程不需要训练任何额外模型 。纯 inference-time 的分析，零训练成本。
## 为什么这么设计？关键直觉-稀疏性是关键。论文发现 0.12% 的神经元就包含了绝大部分任务相关信号。Tab. 3 显示，只停用 NAG 选出的 0.12% 神经元，模型性能直接崩塌 23.5%（从 60.6% 掉到 37.1%），而随机停用同等数量的神经元几乎没影响。这说明 NAG 选中的不是普通神经元，而是功能主干（functional backbone）。
-跨层聚合比单层强。Tab. 4 对比了全层 NAG 和仅最后一层 NAG，后者平均下降 4.1%。在 TriviaQA 和 MMLU 这种难任务上，仅最后一层甚至不如随机选择。说明任务相关信号分布在整层网络中，不是最后一层就能捕捉到的。
-FFN UP 投影层最有用。Fig. 5 对比了不同投影类型的神经元，FFN 的 UP 投影效果最好（60.6%），down proj 和 k proj 分别只有 58.0% 和 56.7%。作者认为 up proj 在高维潜空间中更好地隔离了任务相关信号。
-最优稀疏度是 0.3%。Fig. 6 显示，跨 1.7B/4B/8B 三种模型，层神经元比例 rk = 0.3% 时性能达到峰值。再增加神经元数量收益递减，说明真正有用的信号集中在极小的神经元子集中。
## 实验结果：数字说话Tab. 1 是核心对比。单目标设置下，NAG 相比随机采样平均提升 4.9% ，相比 BETR 平均提升 5.3% （HellaSwag 上达到 +9.0%）。

## 工程启示-定向预训练不需要蒸馏。想让你的模型在某类任务上更强，不需要训练额外的分类器来筛选数据。直接用目标样本在现有 LLM 上做 NAG 分析，零训练成本。
-0.3% 的神经元就够用了。如果你要做神经元层面的分析，不用看全网络。每层取 Top-0.3% 的高影响力神经元，信号密度最高。
-FFN UP 投影层是最佳信号源。Fig. 5 的实验明确表明，up proj 神经元比 attention 投影和 down proj 更有效。实际部署时直接锁定 FFN UP 层就行。
-跨层聚合不可省。Tab. 4 的 -4.1% 差距很明确——只用最后一层会丢掉大量任务相关信号。
-本地模型的”能力定向”路径。如果你有 1.7B-8B 的开源模型，可以用它做 NAG backbone，从海量数据中挑出能强化特定能力的样本，然后用 30B tokens 做定向预训练。成本可控，效果可量化。
## 局限与展望论文承认实验只训练了 1.2B 模型在 30B tokens 上。扩展到更大模型和更多样化语料（多语言、领域特定数据）是未来工作。多目标设置目前用的是简单等比例混合，没有做加权去重，还有很大提升空间。
但整体而言，NAG 提供了一个干净、可解释、零训练成本的数据选择框架。在”数据决定上限”的今天，这种直接利用模型内部计算信号的方法，比黑盒蒸馏路线更值得关注和跟进。
