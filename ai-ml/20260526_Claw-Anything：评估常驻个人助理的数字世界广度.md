论文 : Claw-Anything: Benchmarking Always-On Personal Assistants with Broader Access to User’s Digital World链接 : https://arxiv.org/abs/2605.26086现在的 Agent 评测大多还停留在“单次任务、干净环境”的温室里。但真实的个人助理（Personal Assistant）需要 7x24 小时在线，面对的是几个月积累的数字垃圾、跨设备碎片信息以及复杂的后台服务依赖。这篇来自华为等机构的论文 Claw-Anything ，直接撕开了这个差距：它构建了一个模拟用户数月数字生活的评测基准，结果发现即便是最强的闭源模型 GPT-5.5，通过率也仅有 34.5%。
### 为什么现有的评测不够看？
现有的 Agent 基准（如 ClawBench, WildClawBench）通常只暴露静态的、狭窄的用户状态切片。它们缺乏三个关键维度：
- 长周期事件流：没有过去几个月的活动记录，Agent 无法理解“我昨天搜索过的那个相机降价了吗？”这种依赖历史上下文的请求。
- 跨服务依赖：真实任务往往需要协调邮件、日历、Slack 等多个后端服务，而现有评测多为单服务或无服务调用。
- 多设备异构交互：用户同时在桌面（CLI）和手机（GUI）上操作，Agent 需要整合分散在不同界面上的信息。
Claw-Anything 的核心 Insight 是： 个人助理的能力边界，取决于它能感知和操作的用户数字世界的广度。 如果评测环境不能模拟这种“广度”和“噪声”，我们就无法衡量 Agent 是否真的具备常驻助理的潜力。
### 方法拆解：如何构建一个“活”的数字世界？
论文没有手动编写任务，而是设计了一套 自动化数据生成管道（Automated Data Generation Pipeline） ，通过 LLM 模拟器迭代构建用户数字环境。这个过程分为四步，极具工程借鉴意义：
- 迭代式环境合成：从一个初始人设（Persona）开始，LLM 模拟用户在数月内的日常活动（如发邮件、查日历、社交互动）。每一步都更新持久化状态（Fixture）和动态事件日志（Event Stream）。
- 噪声注入：为了模拟真实世界，管道会注入无关事件和冲突信号。这迫使 Agent 必须从大量噪音中筛选出与当前任务相关的线索，而不是简单地检索所有信息。
- 任务与验证器生成：在特定的时间切片，基于当前的环境状态生成自然语言查询、可执行的验证器（Verifier）以及参考解。
- 自动过滤与人机协同验证：通过规则检查和 LLM 判断剔除无效实例，最后由强 Agent 执行参考解以验证任务的可解性，确保评测质量。
这种设计的关键在于 上下文扩展 。Claw-Anything 的评估集包含 200 个任务，每个任务的上下文长度高达 19.17 万词 （对比 Claw-Eval 的 5,300 词），涉及平均 10.1 个服务 ，并支持 CLI + GUI 的跨设备交互。
### 关键结果：即使是 GPT-5.5 也力不从心实验结果揭示了当前模型在处理复杂数字环境时的巨大短板。以下是核心数据对比（Pass@1）：

- 上下文是瓶颈：消融实验显示，当移除事件流（Event Stream）时，成功率大幅下降；随着历史长度增加，性能持续衰减。这说明当前模型在处理长周期、高噪声上下文时依然吃力。
- 跨服务协调极难：当屏蔽跨服务工具时，任务成功率接近零。这表明许多真实任务本质上是多服务协同的，单点能力无法解决。
- 主动式协助（Proactivity）是硬骨头：在无需用户明确指令、Agent 需主动推荐的任务中，Pass@1 仅为 6.7%，远低于被动响应任务的 25.9%。这揭示了当前 Agent 缺乏真正的“意图预判”能力。
- 数据微调有效：使用管道生成的 1,500 条成功轨迹对 Qwen3.5-27B 进行监督微调（SFT），Pass@1 提升了 +23.7%，证明了该数据管道不仅可用于评测，也是高质量的训练数据来源。
### 工程启示对于正在构建或评估 Agent 系统的工程师来说，Claw-Anything 提供了三个明确的方向：
- 重视上下文管理：不要假设模型能完美处理数万词的混合噪声。你需要设计更高效的检索机制（RAG）或摘要策略，帮助 Agent 聚焦关键信号。
- 跨设备/跨服务集成是下一阶段重点：单一的 CLI 或 GUI 操作已无法满足需求。构建统一的工具接口层（如 OpenHarness），让 Agent 能无缝切换桌面和移动端、协调多个 SaaS 服务，是提升实用性的关键。
- 利用自动化管道生成训练数据：手动构造复杂场景成本太高。Claw-Anything 的迭代式环境合成方法可以复用于其他领域，通过模拟用户行为轨迹来生成高质量的微调数据，显著提升 Agent 在真实环境中的鲁棒性。
### 局限与展望尽管 Claw-Anything 大幅扩展了评测维度，但它仍主要基于文本化的事件流和模拟环境。未来可能需要引入更多模态（如真实的屏幕截图、语音交互）以及更复杂的实时反馈机制。此外，如何平衡上下文广度与推理延迟，也是工程落地中必须解决的难题。
