# ⭐⭐⭐½ ILLUME-X：7B参数实现自由图文交错生成

**日期**: 2026-07-01

---

论文 : Illuminating Unified Multimodal Model for Free-form Interleaved Text-Image Generation链接 : https://arxiv.org/abs/2606.30054现在的多模态模型大多只能“看图说话”或“文生图”，一旦要求生成“图-文-图-文”的交错序列（比如写故事配插图、拆解步骤），效果往往支离破碎。华为诺亚方舟实验室与哈工大联合提出的 ILLUME-X，用 7B+7B 的小参数模型，在自由形式图文交错生成任务上追平了闭源巨头 Gemini 3 Pro，且推理速度极快。
### 痛点：现有统一模型的“伪”交错能力现有的统一多模态模型（如 Chameleon、Janus-Pro）大多基于自回归架构。虽然它们能生成文本和图像，但通常被限制为“单输入到单输出”。
即使部分模型声称支持交错生成，也面临两个核心问题：
- 数据匮乏：缺乏高质量、逻辑连贯的 N-to-M（多输入到多输出）训练数据。
- 评估缺失：现有基准（如 ISG-Bench）严重依赖预设模板，一旦模型输出结构微调，评分机制就会失效，导致无法客观衡量真实能力。
### 核心 Insight：用“视频流”思维重构训练数据ILLUME-X 的最大贡献不在于网络结构的激进创新，而在于对 数据管道 和 训练目标 的精细化设计。
1. 从视频中挖掘因果逻辑作者认为，视频天然包含时间维度的语义演变。他们提出了一套多阶段视频数据提取流水线：
- 混合采样：摒弃简单的关键帧或均匀采样，采用多区间滑动窗口，捕捉不同时间尺度的视觉动态。
- 双重过滤：利用 MANIQA 评估美学质量，利用 RAFT 光流和 DINOv2 特征差异剔除冗余静态帧。
- 多层级描述：不仅描述单帧内容，更强调“跨帧描述”（Cross-frame Descriptions），捕捉动作、交互和环境的光影变化。
这种设计让模型学会了“时间演变”的逻辑，而不仅仅是静态图像的拼接。
2. 交错注意力与双目标优化在架构上，ILLUME-X 采用 Decoder-only Transformer。关键在于其 交错注意力掩码（Interleaved Attention Mask） ：
- 文本/特殊 Token：使用因果注意力，保持自回归特性。
- 视觉 Token：使用双向注意力，捕捉全局空间信息。
同时，训练目标被拆分为两部分：
- 交叉熵损失（CE Loss）：用于文本和特殊控制 Token（如 BOI/EOI），确保模态切换的流畅性。
- 整流流 MSE 损失：用于视觉 Token，保证图像生成的高保真度。
⚠️ 关键设计 ：为了解决噪声累积问题，作者在生成下一组样本时，会对噪声图像 Token 进行掩码操作。这种细节处理显著提升了长序列生成的稳定性。
