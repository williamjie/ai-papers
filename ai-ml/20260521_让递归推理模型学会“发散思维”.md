**日期**: 2026-05-21

论文 : Generative Recursive Reasoning链接 : https://arxiv.org/abs/2605.19376现在的 AI 推理主流是“写长链”（Chain-of-Thought），但另一条路——递归推理模型（Recursive Reasoning Models, RRMs）——试图通过内部状态的迭代精炼来提升推理能力。然而，现有的 RRM（如 HRM、TRM）有个致命缺陷： 太“独断”了 。它们每次只走一条确定性的路径，一旦陷入局部最优，就彻底卡死。这篇论文提出的 GRAM（Generative Recursive reAsoning Models）核心直觉很性感： 把递归过程变成概率采样，让模型在隐空间里“发散思维”，并行探索多条路径。
### 为什么确定性递归不够用？
想象你在解数独。确定性 RRM 就像是一个固执的解题者，每一步都只选它认为最确定的数字。如果第一步选错了，后面的 99 步再努力也是错的。
GRAM 的核心 Insight 是： 推理不仅仅是深度的延伸，更是宽度的探索。
作者将递归隐状态更新从确定性函数 zt=f(zt−1)z_t = f(z_{t-1}) ​ = f ( z t − 1 ​ ) 改造为随机过程：
zt=ut+ϵtz_t = u_t + \epsilon_t ​ = u t ​ + ϵ t ​其中 utu_t ​ 是模型学到的确定性更新方向，而 ϵt\epsilon_t ​ 是从高斯分布 N(μθ(ut),σθ2(ut)I)\mathcal{N}(\mu_\theta(u_t), \sigma_\theta^2(u_t)I) ​ ( u t ​ ) , σ θ 2 ​ ( u t ​ ) I ) 中采样的“随机引导信号”。
这个设计非常精妙：
- 保留确定性骨架：均值 μθ\mu_\theta​ 保证了推理的大方向是正确的，不会乱跑。
- 注入可控随机性：方差 σθ2\sigma_\theta^22​ 允许模型在关键节点探索备选方案。
- 分层架构：随机性只加在“高层”隐状态（抽象推理），而“低层”隐状态（细节计算）保持确定性。这既避免了噪声干扰细节计算，又让宏观策略具备多样性。
### 关键结果：并行采样带来性能飞跃GRAM 的最大工程价值在于它开启了 基于宽度的推理缩放（Width-based Inference Scaling） 。以前我们提升推理能力只能增加步数（深度），现在可以多采样几个轨迹（宽度）。
1. 结构化推理任务（Sudoku-Extreme）
在极度缺提示的数独任务上，GRAM 展现了惊人的优势。
- 深度 vs 宽度：当采样数 N=20N=2020 且迭代 16 次时，GRAM 准确率达到 97.0%。
- 对比基线：相比之下，最强的确定性基线 TRM 即使迭代到 320 次，准确率也仅为 90.5%。
- 结论：GRAM 用更少的计算步数（16 vs 320），通过并行采样实现了更高的准确率。这在延迟敏感的 Agent 场景中极具吸引力。
2. 多解约束满足任务（N-Queens）
对于有多个合法解的问题，确定性模型会发生严重的“模式崩溃”（Mode Collapse）。
- 覆盖率：在 8x8 N-Queens 任务中，确定性模型 TRM 的覆盖率最高仅 36.1%。
- GRAM 表现：GRAM 的覆盖率高达 90.3%，且单次采样准确率达到 99.7%。
- 对比生成模型：虽然自回归模型（AR）覆盖率也不错（84.8%），但其约束满足精度较低。GRAM 证明了“递归精炼 + 随机探索”能同时兼顾多样性和严谨性。
3. 无监督生成能力GRAM 甚至能作为一个无条件生成模型。在二值化 MNIST 上，随着递归步数从 8 增加到 256，FID 从 84.08 单调下降至 73.34 ，接近扩散模型（D3PM）的效果，但计算效率更高。
### 工程启示- Agent 的“思维分支”：在处理复杂规划或代码生成时，不要只依赖单条 CoT。借鉴 GRAM 的思路，让模型在关键决策点并行生成多个隐状态轨迹，再用一个轻量级的奖励模型（LPRM）进行投票选择。
- 推理缩放的替代方案：当增加推理步数导致延迟不可接受时，尝试“少量步数 + 多轨迹采样”。论文显示，16 步并行 20 次采样比 320 步串行效果更好。
- 避免“伪随机”：消融实验显示，简单的随机初始化或解码采样无效。关键在于变分推断框架下的可学习随机引导（Learnable Stochastic Guidance）。这意味着你需要专门训练这种随机性，而不是简单加噪声。
### 局限与展望GRAM 目前主要在控制良好的逻辑谜题上验证。对于开放域的自然语言推理，其有效性尚待观察。此外，由于使用了深度监督（Deep Supervision）和截断梯度，训练效率低于标准 Transformer，这在大规模预训练阶段是一个瓶颈。
但这篇论文提供了一个清晰的信号： 未来的推理模型，不应该只是“想得更深”，还应该“想得更宽”。
