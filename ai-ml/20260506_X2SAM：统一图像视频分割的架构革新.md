# X2SAM：统一图像视频分割的架构革新

**日期**: 2026-05-06

---

论文 : X2SAM: Any Segmentation in Images and Videos链接 : https://arxiv.org/abs/2605.00891现在的多模态大模型（MLLM）大多擅长“看图说话”，但真要让它干点细活——比如精准抠图，尤其是视频里的动态目标，表现往往拉胯。SAM系列虽然分割强，但只会响应点或框，听不懂复杂指令；现有的分割型MLLM要么只管图，要么只管视频，没法在一个接口里同时搞定文本和视觉提示。
这篇论文提出的 X2SAM 试图解决这个割裂问题。它不仅仅是一个新模型，更是一套将图像分割范式扩展到视频的完整架构设计。对于想构建通用视觉Agent的工程师来说，理解它如何处理“时间一致性”和“多模态提示融合”非常有价值。
## 现有方案的痛点：为什么不能直接用 SAM2 + LLM？
目前的解决方案大致分为两派：
- 基础分割模型（如 SAM2）：分割精度高，但依赖低级视觉提示（点/框），无法理解“那个穿红衣服走路的人”这种自然语言指令。
- 分割型 MLLM（如 LISA, VISA）：能听懂话，但通常只针对静态图像或仅针对视频，且缺乏统一的架构来同时支持文本和视觉提示（V-Prompts）。
X2SAM 的核心洞察是： 不需要把图像和视频当成两个完全不同的任务。 只要引入一个能够存储和传递时空特征的机制，就能用统一的框架处理所有分割任务。
## 方法拆解：三个关键设计X2SAM 并非简单的模块堆砌，它在架构上做了三个关键调整，直接针对视频分割的难点。
### 1. 统一的提示集成与输出格式模型输入不仅包含图像/视频，还混合了文本指令（如“分割那只狗”）和视觉提示（如点击某区域）。X2SAM 使用特殊的 <SEG> token 作为分割指令的锚点。LLM 生成的 <SEG> 对应的隐向量，直接作为 Mask Decoder 的条件嵌入。这种设计让语言理解和掩码生成在同一个自回归过程中紧密耦合。
### 2. Mask Memory：解决视频时序一致性的核心这是全篇最关键的工程创新。视频分割最大的难点不是单帧识别，而是跨帧的目标漂移和一致性。
X2SAM 引入了 Mask Memory 模块，采用 FIFO（先进先出）缓存策略：
- Memory Attention：让当前帧的特征去关注之前帧存储的“引导视觉特征”。
- Mask Encoder：将当前帧的视觉特征和生成的掩码日志编码成新的引导特征，存入 Memory Bank。
- 直觉：这就像给模型装了一个“短期记忆”，它不再是逐帧独立推理，而是带着上一帧的“经验”来预测这一帧，从而保持对象身份的一致性。
### 3. Zero-Initialization 的 Token-to-Image Attention在 Mask Decoder 中，X2SAM 设计了 Token-to-Image Attention 来注入 LLM 的语义信息。为了防止训练初期语义信息破坏已有的空间先验，作者使用了 Zero-Initialization（零初始化） 策略。这意味着初始阶段，语义信息几乎不干扰空间特征，随着训练进行，语义引导逐渐增强。实验证明，随机初始化会导致性能下降，而零初始化则能稳定提升视频分割效果。

视频分割性能（超越现有 MLLM 通用模型）：
- V-Ref (视频指代分割): 在 YT21 数据集上，J &F 达到 66.8，显著优于 VISA-7B (60.3) 和 VideoLISA (61.5)。
- V-GCG (视频接地对话生成): mIoU 达到 75.8，比 VideoGLaMM (54.3) 高出 +21.5，这是一个巨大的提升。

图像分割性能（保持竞争力）：
- I-Ref (图像指代分割): 在 RefCOCO/+/g 上 cIoU 分别达到 81.6/76.2/78.7，与专门的图像分割模型 X-SAM 相当甚至略优。
- I-OV (开放词汇分割): PQ 达到 54.7，比 X-SAM (54.1) 有所提升。
训练效率：
- 通过统一联合训练策略，X2SAM 将训练时间从简单联合训练的 ~5.2K GPU 小时减少到 3.3K GPU 小时，节省了 36.5% 的计算成本。
## 工程启示- Mask Memory 是视频分割 MLLM 的标配：如果你正在开发视频理解模型，单纯依靠逐帧推理是不可行的。引入类似 FIFO 的记忆机制来传递时空特征，是解决目标漂移的低成本高效方案。
- 统一架构优于级联：不要试图先让 LLM 理解，再调用 SAM2 分割。X2SAM 证明了端到端的联合优化（Grounding, Decoding, Memory）能更好地保持语义和空间的一致性。
- 初始化策略影响巨大：在多模态融合中，引入新的注意力机制时，Zero-Initialization 是一种稳健的初始化手段，可以避免破坏预训练权重中已有的空间感知能力。
## 局限与展望尽管 X2SAM 表现强劲，但它并非完美。论文指出，与专门的视频对象分割（VOS）专家模型（如 SAM2-H）相比，X2SAM 在纯 VOS 任务上仍有差距（Table 6 中 SAM2-H 的 J &F 为 88.8，而 X2SAM 为 78.5）。这说明通用接口必然牺牲一部分极致性能。此外，增加 Memory 大小并非越多越好，实验发现超过 6 帧后性能反而饱和或下降，提示我们需要更智能的记忆更新机制，而非简单堆叠帧数。
总的来说，X2SAM 为构建“既能看懂话，又能精准抠图，还能跟踪视频对象”的通用视觉模型提供了一个扎实的基线。
