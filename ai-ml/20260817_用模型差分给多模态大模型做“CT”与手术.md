# ⭐⭐⭐½ 用模型差分给多模态大模型做“CT”与手术

**日期**: 2026-08-17

---

论文 : Multimodal Model Diffing for Feature Discovery and Control链接 : https://arxiv.org/abs/2608.09928在 Agent 和多模态应用爆发后，我们常面临一个尴尬局面：模型能看图、能读字，但一旦出错（比如空间关系搞反、OCR 识别错），工程师只能靠“玄学”调 Prompt 或重新微调。这篇来自牛津大学的工作 MMDiff 提供了一套硬核方案： 不重训模型，直接通过内部特征定位问题并实施“手术” 。
### 痛点：为什么现有的 SAE 不够用？
稀疏自编码器（Sparse Autoencoders, SAEs）是拆解大模型内部表征的利器，能把隐藏状态分解为可解释的特征方向。但直接训练在多模态大语言模型（MLLMs）上的 SAE 有个致命缺陷： 它分不清哪些特征是语言基座自带的“旧货”，哪些是多模态训练后新长出来的“器官” 。
如果你拿一个混杂了基础语法和视觉理解特征的 SAE 去做干预，很容易误伤通用能力。我们需要一种机制，能精准隔离出 仅由多模态训练改变的特征 。
### 核心方法：MMDiff 的三步走MMDiff 的核心 Insight 是引入**模型差分（Model Diffing）**思想：对比“纯语言基座”和“多模态适配后”两个阶段的 SAE，找出那些方向发生剧烈旋转、且对视觉输入有响应的特征。
具体流程如下：
-训练多模态 SAE：
不从零开始，而是用基座 LM 的预训练 SAE 初始化（Warm Start），然后在 MLLM 的激活值上微调。这里有个关键设计：只使用文本 Token 进行训练。因为多模态能力本质上是文本 Token 在 Attention 机制中“看”到了视觉上下文，文本层的激活既保留了语言基础，又反映了多模态变化，比直接重建视觉 Token 更稳定。
-识别“适配特征”（Adapted Features）：
通过两个信号筛选：
几何旋转：计算基座 SAE 和 MLLM SAE 中同一索引特征的解码器向量余弦相似度。低相似度意味着该特征被多模态训练“重新分配”了语义。
- 视觉能量：该特征在视觉输入下的平均激活强度必须显著高于阈值。
两者交集即为“适配特征”，占比通常仅为总特征的 5%-20%。
-任务特定特征发现：
在适配特征集中，利用对比触发分析（Contrastive Firing）。比如要找空间推理特征，就对比“包含空间线索的 VQA 问题”和“普通 VQA 问题”中特征的触发频率差异。同时加入词汇不变性过滤，排除那些仅仅因为 Prompt 里出现了“左边”、“右边”等词汇才触发的假阳性，确保特征是真正由图像内容驱动的。
### 关键结果：精准打击，无副作用作者在 LLaVA-MORE、PaliGemma 2 和 InternVL3.5 三个模型上验证了 MMDiff 的效果，重点展示了 因果移除（Causal Removal） 和 特征引导（Steering） 。
1. 空间推理控制通过移除特定的空间特征方向：
- VSR（视觉空间推理）准确率下降：平均 -12% 到 -14.6%。
- 通用 VQA 影响：几乎为零（|ΔVQA| ≤ 1.5%）。
- 对照组：对非空间关系的控制组无影响。
⚠️ 反直觉发现 ：跨阶段消融实验显示，指令微调（Instruction Tuning）放大了这些特征的因果贡献约 3倍 。这意味着许多空间能力是在多模态微调阶段“习得”的，而非预训练继承的。
2. 多模态安全防御针对 VLSBench 中的不安全攻击：
- 攻击成功率（ASR）降低：平均 -24%，单个特征移除最高可达 -28%。
- 误伤率：通用 VQA 和良性输入控制组几乎无变化。
3. OCR 能力增强使用 MMDiff-CAA（结合多层骨干引导和特征方向注入）：
- OCR 准确率提升：平均 +1.8%，峰值 +10.58%。
- 对比基线：比单层标准 CAA 引导高出 +3.6%（空间任务）和 +1.8%（OCR 任务）。

### 工程启示- 免重训的“热修复”：在生产环境中，如果模型在特定视觉任务（如读取特定格式票据）上表现不佳，你可以用 MMDiff 找到相关特征，通过**引导（Steering）**直接增强该方向，而不需要昂贵的全量微调。
- 安全审计新范式：对于多模态越狱攻击，传统的 Prompt 过滤往往滞后。MMDiff 允许你在推理时动态移除“不安全意图”相关的内部特征，实现底层的安全拦截。
- 归因定位：论文还展示了 Attribution Patching，能定位到具体是哪些 Attention Head 在驱动这些视觉特征，为后续的模型剪枝或优化提供了地图。
### 局限与展望- 计算成本：需要训练多套 SAE（基座+多模态），虽然比微调模型便宜，但仍有开销。
- 覆盖范围：目前主要在 2B-8B 规模的模型上验证，更大规模或 MoE 架构的效果待考。
- 生成崩溃：少数安全特征移除会导致生成质量彻底崩溃（而非礼貌拒绝），需要额外的后处理过滤。
MMDiff 证明了多模态 SAE 不仅是解释工具，更是 控制接口 。对于追求极致可控性的多模态 Agent 开发者来说，这是一个值得关注的底层技术栈补充。
