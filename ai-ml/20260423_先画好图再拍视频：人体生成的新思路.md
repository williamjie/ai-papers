# 先画好图再拍视频：人体生成的新思路

**日期**: 2026-04-23

---

论文 : ReImagine: Rethinking Controllable High-Quality Human Video Generation via Image-First Synthesis链接 : https://arxiv.org/abs/2604.19720做可控人体视频生成，最头疼的是数据。多视角、高质量、带精确姿态标注的视频数据集，规模和质量都不够。ReImagine 的作者们做了一个反直觉的决定：干脆不直接训视频模型，先把每一帧的图像质量拉到最高，再用一个零训练的时序模块把它们串起来。
这个思路的核心 insight 很简单——现代预训练图像生成模型（如 FLUX Kontext）已经编码了极强的人体外观先验。在有限多视角数据下，微调图像模型学姿态和视角条件远比直接训视频模型靠谱。
## 现有方案的痛点当前人体视频生成方法基本分两派：
- 姿态可控但视角固定：AnimateAnyone、MagicAnimate 这类用 2D 骨架序列做条件，固定视角下效果不错，但镜头一动就崩。
- 视角可控但姿态弱：MV-Performer 能从单目输入做新视角合成，但没有显式的姿态控制。
Human4DiT 离目标最近，做姿态驱动的 360 度 4D 生成，但训练数据是网络抓取的单目视频，视角变化在训练时没有被显式控制，精确的联合控制还是做不到。
根本原因：多视角人体视频数据太稀缺。最大的 MVHumanNet++ 也只有 5000 个体、4 个视角，远不足以支撑高质量视频模型的联合训练。
## 方法拆解：两阶段解耦设计ReImagine 把问题拆成两件事，分别用最适合的工具解决。
第一阶段：姿态和视角引导的图像合成- 输入：正面 + 背面标准人体图像（外观参考）+ SMPL-X 参数序列（姿态 + 形状）
- 关键设计 1：用 SMPL-X 渲染表面法线图（surface normal map）作为姿态条件。法线图编码了世界坐标系下的像素级表面法向，同时携带了姿态和视角信息，比轮廓图或深度图更适合联合控制。
- 关键设计 2：正面和背面图像通过 VAE 编码为 token，和姿态 token、噪声 token 拼接成统一序列，输入 DiT 骨干网络。
- 关键设计 3：条件感知的位置编码（Condition-aware RoPE）。每个 token 带三维坐标 (x, y, c)，其中 c 是条件类型索引（姿态/正面/背面/噪声），用旋转位置编码（Rotary Positional Embedding, RoPE）区分不同类型的 token，同时保留空间结构。
- 训练：冻结 VAE 和 ControlNet，只微调 DiT 的 LoRA 层（rank=128），flow matching 损失，4 张 A100、10 个 epoch。
第二阶段：零训练的时序一致性这是这篇论文最巧妙的部分。不需要额外的视频训练数据，纯推理阶段操作：
- 低噪声重去噪（Low-noise re-denoising）：把图像模块生成的帧编码为 latent，注入少量高斯噪声，从低噪声时间步重新开始扩散去噪。利用预训练视频扩散模型（Wan 2.1 I2V-14B）的强时空先验，修正帧间的高频不一致。
- 动态时空谱正则化：在去噪的前 35% 步骤中，对 latent 做 3D 傅里叶变换（时间 × 高度 × 宽度），用高斯滤波器衰减高频分量。时间频率衰减更强（τt=0.06），空间频率衰减较弱（τs=0.12），在平滑时序抖动的同时保留空间细节。第一帧作为时间锚点保持不变。

## 工程启示- 解耦是王道。当联合建模的数据不够时，把问题拆成子问题分别用最强的工具解决，比硬上端到端模型更有效。这个思路不只适用于人体生成。
- 预训练图像模型的先验价值被低估了。FLUX Kontext 这种模型已经”见过”海量高质量人体图像，微调时主要学的是几何条件映射，外观质量天然有保障。
- 零训练时序模块值得复用。低噪声重去噪 + 3D 傅里叶频谱正则化这个组合，理论上可以套用到任何逐帧生成再串视频的场景。
- 法线图比骨架更 expressive。SMPL-X 渲染的法线图同时编码姿态和视角，比 OpenPose 关键点或 2D 骨架传递更多信息，这是视角控制能做的更好的关键。
## 局限- 输入需要正面 + 背面的标准人体图像，实际应用中不总是容易获取。作者虽然用 GPT-4o 构建了约 1600 个身份的解耦数据集（脸、衣服、鞋子），但这对普通用户来说还是有门槛。
- 背面输入缺失时，模型会把正面元素传播到背面，视角可控性明显下降。
- 时序模块依赖 Wan 2.1 视频模型，推理成本不低。
这篇论文的价值不在于提出了什么复杂的架构，而在于对问题的重新审视。数据不够的时候，换个思路往往比加模块更有效。先画好每一帧，再让视频模型帮你串起来——这个范式在人体生成领域可能是一个值得跟进的方向。
