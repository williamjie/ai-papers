# ⭐⭐⭐½ AsySplat：长短腿架构如何重塑3DGS效率

**日期**: 2026-07-17

---

论文 : AsySplat: Efficient Asymmetric 3D Gaussian Splatting for Long-Sequence Scene Modeling链接 : https://arxiv.org/abs/2607.10995通用化 3D 高斯泼溅（Generalizable 3DGS）在处理长序列、高分辨率输入时，往往陷入算力黑洞。这篇来自 HKUST 和华为诺亚方舟实验室的论文 AsySplat，用一种极其“不对称”的设计思路，把推理速度拉到了亚秒级，同时保持了 SOTA 级别的画质。
### 痛点：一刀切导致的算力浪费目前的通用化 3DGS（如 LongLRM）通常采用堆叠网络层的方式，直接对图像 Patch 进行 Token 交互来预测深度和外观。
这种设计有一个巨大的假设缺陷： 它默认几何结构和外观纹理需要同等精度的计算资源。
但在实际渲染中，这完全是伪命题。为了保留细节，Patch 必须切得很小（Fine-grained），导致 Token 数量爆炸。而昂贵的跨帧交互（Inter-frame interaction）复杂度随 Token 数量呈二次方增长。把大量算力花在不需要高频细节的几何结构上，是典型的资源错配。
### 核心洞察：不对称才是最优解AsySplat 的作者提出了两个反直觉但极其务实的观察：
- 高精度几何并非刚需：3DGS 的高质量渲染主要依赖高斯球的 Alpha 混合（Alpha Compositing），而非精确的表面几何。即使几何预测稍显粗糙，只要位置大致正确，渲染效果依然出色。
- 外观学习比几何容易：一旦有了多视角深度约束，将像素 RGB 映射到高斯外观属性是一个相对简单的任务，不需要复杂的跨帧匹配。
基于此，AsySplat 设计了**“长短腿”架构（Asymmetric Architecture）**，将几何和外观解耦到两个分支：
-几何分支（Geometry Branch）：
输入：大 Patch Size 生成的粗粒度 Token（Coarse-grained）。
- 策略：集中主要参数量（约 90%），进行复杂的跨帧交互以恢复多视角一致深度。
- 组件：混合了双向 Mamba 和稀疏注意力（Sparse Attention）模块，后者通过网格划分将注意力计算复杂度从二次方降为线性级别，大幅降低训练开销。
-外观分支（Appearance Branch）：
输入：小 Patch Size 生成的细粒度 Token（Fine-grained）。
- 策略：极少参数量（约 10%），仅进行帧内交互（Intra-frame）。
- 组件：轻量级 MambaVision，专注于捕捉高频纹理细节。
⚠️ 关键设计 ：两个分支通过“双向连接模块”通信。外观分支把高频细节注入几何分支，几何分支提供深度线索指导高斯尺度预测。这种分工让细粒度 Token 避开了昂贵的跨帧计算，是提速的核心。
### 性能对比：用更小的模型打更强的对手在 DL3DV-140 数据集上（32 视图，540x960 分辨率），AsySplat 的表现令人印象深刻：
方法 参数量 (M) 前向推理时间 PSNR (DL3DV) Gaussians 数量 LongLRM 142M <1s 24.10 8M AsySplat 98M <1s 24.00 4M- 参数量减少 30%：从 142M 降至 98M。
- 高斯球数量减半：预测出的 Gaussians 仅为 LongLRM 的一半（4M vs 8M）。
- 训练效率提升：总训练时间从 76 小时降至 54 小时，单步迭代时间在高分辨率阶段减少了约 30%。
在零样本泛化测试中，AsySplat 同样表现强劲。例如在 MipNeRF-360 上，其单次前向推理的 PSNR 比 LongLRM 高出近 0.7。若允许少量后优化（Post-optimization），AsySplat 仅需 10 次迭代（18秒）即可超越 LongLRM 30k 次迭代的传统 3DGS 效果，实现近 800倍 的速度提升。
### 工程启示：计算资源应“按需分配”
AsySplat 给工程师的最大启发在于： 不要对所有特征一视同仁。
在构建多模态或 3D 重建模型时，识别任务中的“硬骨头”（如几何一致性）和“软柿子”（如纹理映射），并据此分配不同的计算粒度（Token Granularity）和参数量，是提升效率的关键。
此外，其提出的**稀疏注意力模块（Sparse Attention Module）**非常值得借鉴。通过将 Token 序列重塑为 2D 地图并进行网格化分区，既保留了局部上下文完整性，又规避了全量 Attention 的算力灾难。这种设计对于处理高分辨率视频或长序列图像具有极高的落地价值。
### 局限与展望尽管效率惊人，AsySplat 在 LPIPS（感知相似度）指标上略逊于传统优化型方法，这主要是因为缺乏基于误差的高斯球密集化机制。未来若能结合自适应高斯球生成策略，有望在保持高效的同时进一步逼近物理真实感。
