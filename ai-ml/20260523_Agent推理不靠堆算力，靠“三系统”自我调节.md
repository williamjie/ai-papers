论文 : Efficient Agentic Reasoning Through Self-Regulated Simulative Planning链接 : https://arxiv.org/abs/2605.22138现在的 Agent 有个通病：为了把问题答对，不惜一切代价地“想”。Chain-of-Thought (CoT) 越长越好？不一定。CMU 这篇新论文直接指出，这种无差别的端到端训练会导致 Token 消耗爆炸，且准确率提升边际效应递减。他们提出了一套**自我调节模拟规划（SR2 AM）**框架，核心直觉是把 Agent 的决策拆解为三个独立系统：反应、模拟、调节。这不仅是理论创新，更是对工程落地中“推理成本失控”痛点的直接回应。
### 痛点：为什么现在的 Agent 这么“费”？
主流做法是将 Agent 视为一个带有自适应计算能力的反应策略（Reactive Policy）。模型通过海量数据和算力训练，期望规划能力能从 CoT 中自然涌现。但问题是，这种“黑盒”推理缺乏对规划存在性、结构和视野的控制。结果就是：训练过程中推理长度剧烈增加，Token 消耗飙升，但更长的思考并不必然带来更高的准确率 [28, 92]。
### 方法拆解：向人类学习“三系统”架构作者借鉴人类决策机制，将 Agent 的推理过程分解为三个交互系统：
- 反应执行（System I）：处理细粒度推理和直接动作，相当于直觉反应。
- 模拟推理（System II）：基于世界模型预测未来状态，进行深思熟虑的规划。不同于无约束的 CoT，它提供结构化的“行动-状态”预测序列。
- 自我调节（System III）：这是核心创新点。一个学习到的**配置器（Configurator）**决定何时、多深地进行规划。它根据当前状态的紧急程度、不确定性等因素，动态选择是“制定新计划”、“继续执行旧计划”还是“跳过规划直接行动”。
这种设计的精妙之处在于 解耦 。以往的方法要么强制每一步都规划（成本高），要么只在任务开始选模式（缺乏灵活性）。SR2 AM 让模型学会在推理过程中自主调节：简单步骤直接反应，复杂节点才启动模拟规划。
### 关键结果：小模型吊打大基线论文实现了两个版本： v0.1 （基于多模块提示记录决策）和 v1.0 （从预训练推理 LLM 轨迹中重构结构化计划）。实验覆盖了数学、科学、表格分析和网络搜索四大类共 11 个基准测试。

- 效率碾压：SR2 AM-v1.0-30B 在保持竞争力准确率的同时，比同类 Agent LLM 少消耗 25.8%–95.3% 的推理 Token。
- RL 的作用：强化学习（RL）并没有让模型“更频繁”地规划（频率仅增 2.0%），而是让模型学会“看得更远”。平均规划视野提升了 22.8%，说明 RL 优化的是规划质量而非数量。
- 组件消融：移除自由推理（System I）导致准确率从 66.6 暴跌至 46.8；移除选择性规划（System III）则导致 Token 消耗激增。证明三者缺一不可。
### 工程启示- 结构化思维优于自由发散：在 Agent 开发中，不要指望模型自发产生完美的 CoT。显式地引入“状态预测”和“计划结构”，能显著提升推理的可控性和效率。
- 动态调节是降本关键：对于长链路任务，全量规划是资源浪费。实现一个轻量级的“配置器”来判断何时需要深度思考，能大幅降低 API 成本或本地推理延迟。
- 数据构建新范式：v1.0 展示了如何从现有强模型（如 DeepSeek-V3.2）的轨迹中重构结构化规划数据。这意味着我们可以利用开源大模型的思维链，通过标注转化为高效的 Agent 训练数据，无需从头构建昂贵的多模块系统。
### 局限与展望目前方法在 Web 搜索等高不确定性场景下，规划视野仍较短（受限于环境噪声）。此外，配置器何时停止规划仍有优化空间，偶尔会出现简单任务过度规划的现象。但这套“三系统”框架为未来 Agent 的自我学习和适应提供了清晰的理论路径：不仅是推理时的调节，更是学习过程中的自主治理。
