# 大模型的角色颗粒度：从微观个体到宏观制度

**日期**: 2026-05-08

---

论文 : The Granularity Axis: A Micro-to-Macro Latent Direction for Social Roles in Language Models链接 : https://arxiv.org/abs/2605.06196在构建基于大语言模型（Large Language Models, LLMs）的多智能体社会模拟时，我们常面临一个隐蔽的陷阱： 颗粒度混淆（Granularity Confusion） 。当让模型扮演“焦虑的家长”或“央行行长”时，文本风格可能截然不同，但底层的推理逻辑是否真的区分了“微观个体经验”与“宏观制度视角”？如果模型只是换皮不换骨，模拟的有效性将大打折扣。
港大与哈工大团队的新研究《The Granularity Axis》给出了一个令人惊讶的答案： 是的，LLM内部确实编码了这种颗粒度，且它不是分散的特征，而是一条主导的几何轴。
## 核心洞察：角色不是模板，而是连续谱传统观点认为，角色提示（Role Prompting）是通过激活特定的“角色扮演模板”来改变输出风格。但这篇论文指出，社会角色的差异本质上是**社会尺度（Social Scale）**的差异：微观角色关注即时、局部、个人体验；宏观角色关注协调、程序、长期战略。
作者提出，这种差异在模型的激活空间（Activation Space）中表现为一条单一的、有序的、可因果操控的潜在方向—— 颗粒度轴（Granularity Axis） 。
## 方法拆解：如何找到这条“隐形的轴”？
研究的核心直觉非常优雅： 对比即方向 。
-构建有序角色集：
作者构建了75个社会角色，分为5个颗粒度层级（L1-L5）：
L1 (Micro): 焦虑的家长、担忧的患者- L2 (Group): 体育教练、PTA主席- L3 (Meso): 大学院长、NGO组织者- L4 (Systemic): 军事将军、监管官员- L5 (Macro): 世界银行行长、联合国大使-提取与定义：
针对每个角色，使用5种提示变体和240个通用问题，生成超过9万个响应。提取隐藏层状态，计算宏观角色均值减去微观角色均值，得到向量 g\mathbf{g}。
-几何验证：
对75个角色向量进行主成分分析（PCA）。如果假设成立，这条人工定义的 g\mathbf{g} 应该与第一主成分（PC1）高度对齐，且角色投影应随层级单调递增。
## 关键结果：52.6% 的方差被这条轴解释实验在 Qwen3-8B 和 Llama-3.1-8B-Instruct 上验证，结果极具说服力：
- 主导性：在 Qwen3-8B 中，颗粒度轴与 PC1 的余弦相似度高达 0.972，解释了角色空间 52.6% 的方差。
- 单调性：角色在轴上的投影从 L1 到 L5 严格单调递增。有趣的是，L4 和 L5 在表示空间发生了饱和（Saturation），说明模型将两个最高层级视为同一类宏观视角。
- 鲁棒性：该结构在不同层（Layer 18 最稳定）、不同提示变体甚至不同模型家族中均保持稳定。

## 工程启示：从“描述”到“因果控制”
最让工程师兴奋的是，这条轴不仅是 描述性 的，更是 因果性 的。通过 激活引导（Activation Steering） ，我们可以直接操控模型的思维尺度：
h^t=ht+αg\hat{h}_t = h_t + \alpha \mathbf{g} ^ t ​ = h t ​ + α g- α>0\alpha > 00：推动模型向宏观视角（更系统、更战略化）。
- α<0\alpha < 00：推动模型向微观视角（更个人、更局部）。
实验发现：
- Llama-3.1 对引导响应强烈：在微观定向提示下，α=+4\alpha=+4+4 使颗粒度评分从 2.00 升至 3.17。但其负向引导（α=−4\alpha=-4−4）会导致 42.5% 的输出退化（Degeneration），说明控制不够稳定。
- Qwen3-8B 更保守但稳定：默认状态下已偏向宏观（评分接近 5.0），因此正向引导空间小，但在微观提示下仍能观察到 +0.5 的提升，且无退化。
对 Agent 开发的指导意义：
- 审计多智能体系统：在模拟中，如果不同角色的 Agent 在潜在空间中聚集在同一端，说明发生了“颗粒度混淆”，模拟失效。
- 动态尺度控制：在需要政策推理时，施加正向引导以抑制过于琐碎的个人情绪；在心理咨询场景中，施加负向引导以增强共情和微观视角。
- 不要只看文本：角色一致性不能仅靠文本相似度衡量，必须检查其潜在表示是否落在预期的颗粒度区间。
## 局限与展望论文也坦诚，单轴模型可能掩盖了其他相关维度（如正式程度、时间视野），且 L4-L5 的饱和现象暗示了更高阶社会结构的复杂性。此外，控制效果高度依赖模型默认的“基准位置”，Qwen 默认偏宏观，Llama 默认偏中观，这要求在实际部署前必须对特定模型进行基线校准。
总结 ：这篇论文将社会角色从“风格表面现象”提升到了“表示原语”的高度。对于从事社会模拟、对齐控制和可解释性研究的工程师来说， 颗粒度轴 是一个既好用又深刻的工具。
