**日期**: 2026-05-28

论文 : Lost in Sampling: Assessing Lexical Reachability in LLMs via the Word Coverage Score (WCS)
链接 : https://arxiv.org/abs/2605.27268你是否觉得现在的 LLM 写出来的东西越来越“平庸”？不是模型变笨了，而是我们的**解码策略（Decoding Strategy）**正在系统性地抹杀语言的多样性。这篇论文抛出了一个扎心的结论：我们常用的 Top-p、Top-k 等采样参数，实际上充当了“无意的审查机制”，将人类语言中那些丰富但低频的表达直接数学化地剪枝掉了。
### 痛点：被折叠的“博尔赫斯花园”
LLM 在预测下一个 token 时，潜空间里其实存在着成千上万种可能性，就像博尔赫斯笔下的《小径分岔的花园》，充满了平行时空般的丰富分支。然而，为了保证生成的连贯性（Coherence），工业界标准的采样器（如 Top-p）会激进地截断概率分布的长尾部分。
这就引出了一个核心矛盾： 局部文本的连贯性 vs 全局词汇的多样性 。现有的研究多关注模型训练数据或对齐技术（如 RLHF/DPO）对内容的影响，却忽视了 推理时的解码机制 本身就在抑制语言丰富度。这篇论文的核心洞察在于：即使模型“知道”某个词（它存在于概率空间中），标准的采样器也可能在数学上让它变得“不可达”。
### 方法拆解：词汇覆盖率分数（WCS）
为了量化这种“词汇丢失”，作者提出了 Word Coverage Score (WCS) 。这不仅仅是一个静态的评估指标，而是一个动态的行为审计工具。其设计逻辑非常精妙，分为四步：
- 目标锁定：选取频率排名在 10,000 到 40,000 之间的“中长尾”词汇。避开高频功能词（太简单）和极低频噪声（训练不足），聚焦那些代表人类高级表达能力的词汇。
- 语境还原：从 PG-19 数据集（1919年前的书籍）中提取这些词的真实上下文，确保评估发生在合法的 linguistic environment 中。
- 强制路径审计（Forced-Path Audit）：这是最关键的一步。给定前缀上下文，作者不直接让模型采样，而是提取每一步的完整概率分布，检查目标词及其子词 token 是否会被当前的采样器（Top-k, Top-p, Min-p）剪枝掉。
- 计算可达性：如果一个词的所有子 token 在每一步都存活下来，才算“可达”。WCS 就是所有测试样本的平均可达率。
这种设计的直觉在于： 我们关心的不是模型是否“认识”这个词，而是在实际生成时，采样器是否允许这个词被选中。
### 关键结果：默认参数下的词汇大屠杀实验结果令人震惊。在常见的采样参数下，大量本应出现的词汇被彻底“擦除”（即在所有测试上下文中都无法被采样到）。

### 工程启示：如何拯救语言的丰富性？
对于从事 LLM 应用开发的工程师，这篇论文提供了明确的行动指南：
- 重新审视采样参数：默认的 top_p=0.9 或 top_k=50 可能过于保守。如果你需要更具创意或文学性的输出，尝试略微放宽采样限制（如提高 top_p 至 0.95+），或者结合 Min-p 采样器，后者在保持多样性和连贯性之间取得了更好的平衡。
- 警惕“同质化”陷阱：如果你的应用场景对语言多样性敏感（如创意写作、角色扮演），不要盲目依赖 Instruct 模型或高蒸馏程度的模型。Base 模型往往保留了更丰富的词汇潜空间。
- 超越采样器的解决方案：论文指出，根本解决之道在于开发语义引导的解码器（Semantic-guided decoders）。未来的推理引擎不应仅仅基于概率截断，而应能区分“低概率噪声”和“低概率但高信息量的人类表达”。在训练阶段，也可以考虑将词汇多样性作为损失函数的一部分进行优化。
### 局限与展望WCS 目前主要是一个二元指标（可达/不可达），它无法捕捉“软性侵蚀”——即词汇虽然可达，但概率被大幅压低的情况。此外，实验仅针对英文和 <20B 参数的开源模型，对于闭源大模型或中文场景的普适性还需进一步验证。
但这篇论文的价值在于它揭示了一个被忽视的工程现实： 我们以为在控制生成质量，实际上可能在无意中修剪掉语言的灵魂。 下次调整 generation_config 时，不妨多想一想：你剪掉的究竟是胡言乱语，还是博尔赫斯花园里的一条美丽小径？
