论文 : Recursive Harness Self-Improvement链接 : https://arxiv.org/abs/2607.15524还在死磕 Test-Time Scaling（测试时扩展），指望靠增加推理步数来提升 Agent 性能？Sakana AI 这篇新论文给了个反直觉的答案： 与其让模型“想”得更久，不如让它的“工作流”更聪明。
通过一种轻量级的递归自我改进算法，他们仅用几次迭代就优化了 Agent 的 Prompt 级脚手架（Harness），不仅性能超越了最强推理模式，还省下了高达 60% 的成本。这对于工程落地来说，简直是降维打击。
### 痛点：Provider 的脚手架太通用，用户的定制太昂贵在当前的 Model-Harness 协同进化范式中，基础模型（Foundation Models）越来越强，但配套的 Harness（即 Agent 的工作流、角色定义、交互协议）往往滞后。
Provider 提供的内置脚手架必须兼顾所有场景，导致在特定任务上效率低下。而用户若想定制专属工作流，传统方法（如基于种群的搜索或代码级进化）计算成本极高。每次评估一个新候选方案，都需要完整的 Agent 执行和昂贵的 LLM 评判。这种“暴力搜索”在需要频繁适配不同 Open-Ended 任务的工程场景中，根本不可持续。
### 核心 Insight：把 Harness 当作 Prompt 对象进行局部优化RHI（Recursive Harness Self-Improvement）的核心直觉非常巧妙： 不要全局搜索，只要比上一个版本好就行。
传统方法试图在全局分布中寻找最优解，而 RHI 将其简化为 轨迹局部（Trajectory-Local） 优化。在每一轮迭代中，它只将当前 Harness 与 紧邻的前一个版本 进行两两对比。
这种设计带来了两个关键优势：
- 极低的计算开销：每轮迭代只需一次新的 Agent 执行和一次评判调用。相比传统种群搜索的 Θ(m2)\Theta(m^2)) 复杂度，RHI 的成本仅为 Θ(1)\Theta(1)。
- Prompt 级表示：RHI 不修改可执行代码，而是将 Harness 定义为 Prompt 级别的规范，包括角色（Roles）、指令（Instructions）、契约（Contracts）和跳数（Hops）。这使得优化过程完全解耦于底层逻辑，更加灵活且轻量。
更妙的是，RHI 引入了 偏好历史（Preference History） 。它不只看单次胜负，而是积累过往的对比反馈，作为“动量信号”指导下一轮修订。这解决了单次对比噪声大的问题，确保在极少迭代次数内收敛。
### 关键结果：性能天花板被打破，成本反而下降论文在 30 个涵盖量化金融、机器人和制药领域的合成 ML 研究任务上进行了评估。结果令人印象深刻：
模型配置 基线策略 (Max Reasoning) RHI 改进后 (High Reasoning) 胜负关系 (Wins/30) Sonnet-4.6 xhigh / max High + RHI 显著胜出 Opus-4.7 xhigh / max / ultracode High + RHI 显著胜出 Opus-4.8 ultracode High + RHI 显著胜出，成本降 60%⚠️ 反直觉发现 ：RHI 的性能提升 并非 来自更长的推理轨迹。实验显示，随着迭代进行，输出 Token 数量几乎保持不变，甚至缓存读写（Cache Read/Write）和推理成本大幅下降。
这意味着什么？意味着 RHI 通过优化“契约”和“跳数”，实现了更高效的 上下文管理 。它让 Agent 之间只传递最关键的信息，减少了冗余传播，从而在相同甚至更低的算力下，挤出了更高的性能上限。
### 工程启示：信息论视角下的工作流优化从工程角度看，RHI 提供了一个可落地的框架： 不要盲目增加推理深度，先检查工作流的信息流转效率。
论文进一步提出一个信息论假设：RHI 隐式地在最大化每个组件与任务之间的互信息（Mutual Information），同时惩罚组件间的冗余。这解释了为什么优化后的工作流更“紧凑”且高效。
对于正在构建 Agent 系统的工程师来说，启示很明显：
- Harness 是可优化的资产：不要硬编码工作流，将其视为可迭代的 Prompt 对象。
- 局部改进优于全局搜索：利用历史反馈进行递归优化，比维护庞大的候选种群更经济。
- 关注上下文稀疏性：通过明确定义 Agent 间的通信契约（Contract），可以显著降低 KV-Cache 压力，提升推理速度。
### 局限与展望当然，RHI 目前主要在合成任务上验证，且依赖于 LLM-as-a-Judge 的偏好反馈。在真实世界中，如何确保评判器的可靠性、如何处理更复杂的代码依赖关系，仍是待解之题。但作为一种轻量级的“数据飞轮”启动器，RHI 无疑为 Model-Harness 协同进化提供了一条极具性价比的路径。
