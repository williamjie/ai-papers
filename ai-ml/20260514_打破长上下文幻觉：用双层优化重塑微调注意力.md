# 打破长上下文幻觉：用双层优化重塑微调注意力

**日期**: 2026-05-14

---

论文 : FocuSFT: Bilevel Optimization for Dilution-Aware Long-Context Fine-Tuning链接 : https://arxiv.org/abs/2605.09932很多工程师有个误区：只要模型上下文窗口够大（比如 128K），长文本任务就能搞定。但现实很骨感，Qwen2.5-7B 明明支持 128K 上下文，在 4K-32K 的推理任务中依然表现糟糕。这篇来自港中大和华为的论文指出了核心病灶： 不是模型“看不见”长文本，而是在微调（SFT）阶段，注意力机制被“稀释”了。
## 为什么现有微调会失效？
传统观点认为，长文本能力的缺失主要发生在推理阶段（Inference-time），比如著名的“中间丢失”（Lost in the Middle）现象或注意力汇（Attention Sinks）问题。但 FocuSFT 团队提出一个反直觉的观点： 微调过程本身就在制造缺陷。
在标准的监督微调（Supervised Fine-Tuning, SFT）中，模型的前向传播同样受限于位置偏差和注意力汇。这意味着：
- 注意力预算浪费：大量注意力被分配给首尾的“位置特权”Token，而非语义相关的中间内容。
- 梯度信号污染：模型基于一个“被稀释”的上下文表示计算 Loss，导致梯度更新无法教会模型如何聚焦关键信息。
- 恶性循环：训练时学不到聚焦能力 -> 推理时依然聚焦失败 -> 长上下文能力无法提升。
论文数据显示，在标准 SFT 下，前 5 个 Token 的注意力汇吸走了 30.1% 的预算，而整个上下文内容仅获得 13.5% 的注意力。这就是典型的“注意力稀释”（Attention Dilution）。
## 方法拆解：双层优化与双向注意力FocuSFT 的核心思路是 在训练时注入一个“聚焦预览”机制 ，通过双层优化（Bilevel Optimization）强行矫正注意力的分布。
### 1. 内层循环：构建参数化记忆作者引入了轻量级的 Fast-Weights（即 LoRA 适配器），在每一个训练步中执行 KK 步梯度更新。
- 直觉：这相当于在正式学习之前，让模型快速“阅读”一遍上下文，形成一个针对当前样本的“参数化记忆”（Parametric Memory）。
- 设计细节：这个内层循环的目标与外层一致（预测 Response），但它是为了优化中间表示。通过快速适应，LoRA 权重迫使注意力从位置偏差转移到语义相关内容上。
### 2. 外层循环：基于“锐化”表示的微调外层循环使用内层优化后的 Fast-Weights 产生的表示来计算 SFT Loss。
- 关键 Insight：因为内层已经“锐化”了注意力，外层接收到的梯度信号不再是稀释后的近似值，而是反映了真实的内容相关性。
- 一致性原则：内层和外层共享相同的注意力掩码和 FFN 层，确保内层学到的“聚焦模式”能无缝迁移到外层。
### 3. 双向上下文注意力为了解决注意力汇的根源（因果掩码导致的可见性不对称），论文在上下文 Token 间应用了 双向注意力 （Bidirectional Attention），仅在 Response 部分保留因果掩码。
- 效果：打破了首 Token 的全局可见特权，从结构上抑制了注意力汇的形成。
## 关键结果：数字不会撒谎在 Qwen2.5-7B 基座上，FocuSFT 带来了显著的性能提升，尤其是在长上下文和多跳推理任务中。

- CWE（聚合任务）：从 72.9% 提升至 81.1%（+8.2pp）。这是最考验长程信息整合的能力，提升最为明显。
- NIAH-MV：从 94.6% 提升至 95.6%。

- 在需要多轮工具调用的复杂推理中，pass@1 提升了 24% 的相对增益（从 15.6% 到 19.4%）。

- 注意力汇质量减少了 529 倍（从平均 30.1% 降至 0.06%）。
- 上下文参与度提升了 3.1 倍（从 13.5% 升至 41.4%）。
## 工程启示与局限对于工程师而言，FocuSFT 提供了几个重要的实践指导：
- 微调数据的质量重于数量：如果微调数据中的长上下文结构导致模型学会“忽略中间内容”，那么增加数据量只会加剧过拟合这种坏习惯。使用 FocuSFT 可以在相同数据下学到更鲁棒的注意力模式。
- 推理零开销：这是一个纯训练阶段的改进。训练完成后，内层的 LoRA 权重被丢弃，推理时只需使用标准模型，无需像 Test-Time Training (TTT) 那样承担每样本的计算延迟。
- 计算成本可控：虽然训练时间增加了 1.71 倍（主要来自内层梯度步），但考虑到 BABILong 上高达 14.2pp 的提升，这个性价比对于长文本垂直领域模型来说是可以接受的。
局限性 ：
- 目前实验仅基于 Qwen2.5-7B 和 3K 样本，更大规模模型和数据集的扩展性有待验证。
- 双向注意力引入了训练-推理的掩码差异（虽然通过双层优化缓解了，但消融实验显示单纯加双向注意力反而因分布偏移导致性能下降），需要严格的内层-外层一致性设计。
## 总结FocuSFT 揭示了一个常被忽视的事实： 长上下文能力的瓶颈往往始于训练。 通过双层优化和双向注意力，它不仅仅是在“处理”长文本，而是在“教”模型如何正确地“看”长文本。对于正在构建 RAG 后端或长文档处理 Agent 的团队，这是一个值得在微调阶段尝试的高效手段。
