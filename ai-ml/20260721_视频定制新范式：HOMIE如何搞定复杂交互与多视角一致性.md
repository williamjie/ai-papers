# ⭐⭐⭐½ 视频定制新范式：HOMIE 如何搞定复杂交互与多视角一致性

**日期**: 2026-07-21

论文 : HOMIE: Human-object Centric Video Personalization via Multimodal Intelligent Enchancement链接 : https://arxiv.org/abs/2607.18217做人物-物体（Human-Object）视频定制，最头疼的不是脸不像，而是“手不知道往哪放”。
现有方案要么把人当贴图硬拼，导致动作僵硬；要么在 Logo 等抽象概念上完全失控。HOMIE 这篇论文提供了一个优雅的解法：别把 MLLM 当编码器替换掉，把它当成一个全局的“语义导游”，直接注入到 DiT 的自注意力机制里。
这种设计思路非常务实，既保留了文本编码器的可控性，又利用了大模型的推理能力。对于想落地高保真视频生成的工程师来说，这是一个值得深究的架构参考。
### 痛点：现有方案的“水土不服”
目前主流的视频个性化方法在处理多主体交互时，往往陷入两难。
一是**跨主体（Inter-subject）**场景下，随着参考图数量增加，模型很难平衡身份保真度和交互准确性。比如让人拿着特定 Logo 的杯子喝水，很多模型要么把 Logo 糊在脸上，要么干脆忽略这个细节。
二是**同主体（Intra-subject）**场景下，虽然输入多视角图片或 OCR 地图能提升一致性，但现有模型缺乏理解这些“潜在对应关系”的机制。它们往往把同一物体的不同视角当成独立个体处理，导致生成结果出现重复或空间错乱。
更关键的是，现有的 MLLM 集成策略主要有两种缺陷：
- 对齐到文本空间：将 MLLM 特征强行对齐到 UmT5 嵌入空间，这会削弱文本编码器的原有控制力，且限制了 MLLM 推理视觉关联的能力。
- 完全替换文本编码器：虽然引入了多模态理解，但带来了巨大的重新对齐成本，且让 MLLM 背负了重建通用文生视频控制的沉重负担。
### 核心 Insight：保留文本编码器，注入全局语义HOMIE 的核心直觉是： 文本编码器负责“指令控制”，MLLM 负责“关系推理” 。
论文提出了一种统一的输入范式，将视频 Token、参考图像 Token 和 MLLM 提取的多模态特征直接拼接。为了不让这些异构 Token 互相干扰，作者设计了两个关键模块：
#### 1. 全局多模态引导（GMG）
这是本文最亮眼的部分。GMG 并不改变参考图像的自注意力模式，而是专门针对 视频 Latent 和 MLLM 特征 进行交互。
具体做法是：
- 在计算 Query (Q) 和 Key (K) 后，对 MLLM 部分的 Q 和 K 进行时间维度上的 Pooling，得到全局语义表示。
- 通过轻量级投影网络生成缩放（Scaling）和平移（Shifting）参数。
- 利用仿射变换将这些参数广播到视频 Token 的 Q 和 K 上。
这种设计的精妙之处在于，它让 MLLM 提取的高层语义（如“人拿着杯子”的逻辑关系）能够全局性地调制视频生成的注意力分布，而不是仅仅作为局部特征存在。
#### 2. 模态-参考嵌入（MRE）
为了解决 Token 混淆问题，HOMIE 引入了可学习的嵌入模块。
- 模态嵌入：区分视频、图像和 MLLM 特征，防止模型搞不清数据来源。
- 参考嵌入：为不同的主体分配唯一的 ID Embedding。如果是同一物体的多视角图（Intra-subject），它们共享同一个 Reference Embedding；如果是不同物体（Inter-subject），则分配不同的 Embedding。
这使得模型能够明确知道：“这两张图是同一个东西的不同角度”，从而在生成时保持空间一致性。

### 工程启示与局限对落地的指导意义：
- 不要盲目替换 Text Encoder：在视频生成中，文本编码器的控制力是经过大规模数据验证的。MLLM 更适合做“外挂”的知识增强器，而非基础编码器。
- 解耦模态与身份：在处理多参考图任务时，显式地引入 Modality 和 Reference Embedding 是低成本低收益极高的手段，能有效缓解特征串扰。
- 全局调制优于局部拼接：GMG 的设计表明，通过 Affine Transformation 对 Q/K 进行全局调制，比简单的 Concat 更能保留原始模型的特征分布稳定性。
局限与展望：
- 计算开销：虽然避免了重新对齐整个 Text Encoder，但引入 MLLM 推理和额外的 GMG 模块仍会增加一定的显存和延迟。
- 长尾交互：论文主要关注了手持、展示等常见交互，对于更复杂的物理接触（如穿脱衣物、剧烈碰撞）可能仍需更多数据支持。
HOMIE 证明了，在视频生成中引入 MLLM 不需要“推倒重来”，巧妙的特征注入和嵌入设计足以带来质的飞跃。对于正在构建复杂场景视频生成应用的团队来说，这套架构思路值得借鉴。
