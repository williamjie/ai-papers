# ⭐⭐⭐⭐ 告别前缀衰减：无需训练的注意力状态记忆

论文 : Context Memorization for Efficient Long Context Generation链接 : https://arxiv.org/abs/2605.18226在处理长上下文生成时，我们常面临两个令人头疼的工程痛点：随着生成 token 增多，前缀（Prefix）的影响力会逐渐衰减（Prefix Decay）；同时，注意力机制对前缀的计算开销随长度线性增长，严重拖慢推理速度。现有的解决方案要么是通过梯度训练将前缀“内化”到模型参数中（成本高、更新慢），要么是压缩 KV Cache（仍保留注意力计算，未彻底解决延迟问题）。
这篇来自东京科学大学与帝国理工学院的论文提出了一种名为 Attention-State Memory (ASM) 的创新方案。它的核心直觉非常巧妙： 既然注意力输出是可以无损分解的，为什么不提前算好前缀对各类查询的“注意力状态”，存成一张查表字典，推理时直接检索合并？ 这种方法既不需要微调模型，也不需要推理时重新计算前缀注意力，实现了真正的“即插即用”。
### 核心 Insight：Online-Softmax 的身份认同ASM 的设计基石是 Online-Softmax Identity 。在标准注意力机制中，对一个长序列的注意力计算可以分解为对多个子块的注意力加权平均。论文指出，对于任意查询向量 qq ，存储其针对前缀子块的注意力输出 a(q)a(q) 和归一化因子 Z(q)Z(q) 就足够了。这两个值构成了所谓的“注意力状态”。
关键在于 Composability（可组合性） ：如果我们将前缀切成块，分别计算每块的注意力状态，可以在推理时通过一个简单的合并算子（Merge Operator）无损地恢复出完整的注意力结果。这意味着，我们可以离线计算这些状态，并将其聚类压缩成一个轻量级的记忆库。推理时，只需找到当前查询最相似的聚类中心，检索对应的状态并合并即可，完全绕过了对前缀 KV Cache 的读取和计算。
### 方法拆解：从离线校准到在线检索-离线校准（Construction）：
收集：使用前缀和一批代表性的响应轨迹运行前向传播，收集每个查询向量及其对应的前缀注意力状态。
- 聚类：使用 K-means 对查询向量进行聚类。这里有一个精妙的设计：Attention-Aware Aggregation。在合并聚类中心的注意力状态时，不仅简单平均，还保留了注意力合并的结构，避免了因注意力尺度不匹配导致的性能下降。
- 分块处理：为了降低峰值显存，长前缀可以被切分成多个小块独立编码，最后合并。实验显示，4个 4K 的块合并后的效果几乎等同于单次处理 16K 前缀，但显存占用大幅降低。
-在线推理（Inference）：
检索：对于每个生成的 token，计算其查询向量，通过余弦相似度在记忆库中查找最近的中心。
- 合并：将检索到的前缀注意力状态与当前查询的自注意力状态合并。
- 加速：通过分层索引（Hierarchical Lookup），将检索复杂度从 O(K)O(K) 降低到 O(log⁡K)O(\log K)K)，使得记忆库规模扩大时，延迟增长极慢。
### 关键结果：精度与速度的双赢论文在 LLaMA-3.1-8B 上进行了详尽的评估，结果令人印象深刻：
- 上下文学习（ICL）：在 ManyICLBench 上，当记忆库大小为 1K-8K 时，ASM 的准确率优于标准的 In-Context Learning（ICL）。特别是在 8K 预算下，注意力延迟降低了 1.36×。
- 检索增强生成（RAG）：在 NBA 规则基准测试中，ASM 仅使用 20% 的记忆库 footprint，就超越了使用完整 20K 规则库的全注意力 RAG 性能。
- 效率对比：随着记忆库条目增加，全注意力方法的延迟线性增长，而 ASM 的延迟增长极其平缓。在 16K 条目时，ASM 相比全注意力实现了 1.8× 的速度提升。

- 显存友好：通过分块校准和紧凑的记忆库存储，ASM 显著降低了峰值显存需求，使得在消费级显卡上处理超长上下文成为可能。
- 避免前缀衰减：由于前缀信息被“固化”在注意力状态中，并通过检索直接注入，它不受生成过程中注意力分散的影响，从而保持了更强的指令遵循能力。
### 局限与展望ASM 的性能依赖于聚类中心的质量。论文指出，当记忆库过大（如 16K）而训练数据不足时，聚类效果会变差，导致性能下降。因此，记忆库的大小需要根据任务数据和前缀长度进行调优，而非盲目增大。此外，该方法目前主要适用于静态或半静态的前缀场景，对于频繁动态变化的前缀，需要重新进行离线校准，这在实际部署中需要权衡更新成本与收益。
总体而言，ASM 为长上下文推理提供了一条“不微调、不压缩、只查表”的新路径，是 LLM 推理优化领域中一个极具潜力的方向。
