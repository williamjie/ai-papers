论文 : Struct-Searcher: Agentic Structural Thinking Advances Multimodal Deep Information Seeking链接 : https://arxiv.org/abs/2606.07689现在的深度研究 Agent（Deep Research Agents）大多还活在“线性累加”的旧梦里。
遇到多模态冲突时，它们往往因为缺乏纠错机制而陷入死胡同。
这篇论文提出了 Struct-Searcher，用结构化的信念修正理论重构了搜索流程。
它不是简单的提示词工程，而是从认知底层解决了多模态信息打架的问题。
### 痛点：为什么现在的 Agent 容易“一本正经胡说八道”？
现有的主流 Agent 工作流（如 ReAct）本质上是证据累加模型（Evidence Accumulation Models, EAM）。
它们像贪吃蛇一样，线性地收集证据直到置信度达标。
致命缺陷 ：一旦早期视觉感知出错（比如把东京塔看成埃菲尔铁塔），后续所有推理都会基于这个错误前提 cascading failure（级联失效）。
在多模态场景下，文本说“耐用”，视频却显示“破损”，这种跨模态冲突会让线性模型彻底懵圈。
它们缺乏“撤回”和“修正”先前信念的认知机制。
### 核心 Insight：引入 AGM 信念修正理论Struct-Searcher 的核心直觉是：搜索不是收集，而是 信念的动态修正 。
作者引入了经典的 AGM（Alchourrón–Gärdenfors–Makinson）信念修正理论。
Agent 不再盲目搜索，而是维护一个多模态结构图（ Multimodal Structural Graph, MSG）。
这个图包含查询、目标、假设和证据节点，并明确标记“支持”或“反驳”关系。
关键设计在于三个操作：
- 信念扩张：新证据支持假设，加入信念集。
- 信念修正：新证据反驳假设，从信念集中移除该假设。
- 剪枝：消除冲突路径，只保留最大无冲突子图。
这意味着 Agent 会并行探索多个假设（如“是埃菲尔铁塔” vs “是东京塔”），通过工具获取证据进行验证，最后剔除错误分支。
### 实验结果：不仅是 SOTA，更是 Plug-and-Play论文在 MM-BrowseComp、HLE-VL 和 BrowseComp-VL 三个基准上进行了测试。
核心数据对比（基于 GPT-5 骨干）：
数据集 Struct-Searcher 第二优方法 (Flash-Searcher) 提升幅度 MM-BrowseComp 32.7% 28.8% +3.9% (相对+13.5%) HLE-VL 17.3% 16.8% +0.5% (相对+3.0%) BrowseComp-VL 48.6% 47.9% +0.7% (相对+1.5%)
亮点 ：Struct-Searcher 是模型无关的（Model-Agnostic）。
在五个不同骨干模型上，它带来了平均 17.2% 的相对准确率提升。
即使在 GPT-4o 这种较老的模型上，也能显著优于原生表现。
与 Flash-Searcher 的细粒度对比显示，除了地理类任务略逊一筹，Struct-Searcher 在其他所有领域均持平或胜出。
### 工程启示：如何落地这套“结构化思维”？
- 状态外置：不要只靠 LLM 的内部上下文记忆。显式地维护一个图结构（Graph）来记录假设和证据的关系。
- 允许犯错与回溯：设计 Agent 时，必须包含“反驳”机制。当新证据与旧假设冲突时，要有逻辑去否定旧假设，而不是强行融合。
- 并行验证：对于模糊的多模态输入，生成多个竞争性假设并并行搜索证据，比单一路径线性搜索更鲁棒。
### 局限与展望目前该方法依赖强大的 VLM 作为骨干进行图操作和推理。
论文提到未来计划通过强化学习（Reinforcement Learning）对 Agent 基础模型进行后训练。
这意味着结构化思维有望从“外挂框架”内化为模型的“原生能力”。
对于工程师来说，现在就可以尝试在现有 Agent 架构中引入简单的“假设-验证-剪枝”逻辑，尤其是在处理图文不一致的复杂查询时。
