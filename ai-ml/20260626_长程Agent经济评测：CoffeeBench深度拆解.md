# 长程 Agent 经济评测：CoffeeBench 深度拆解

**日期**: 2026-06-26

---

论文 : CoffeeBench: Benchmarking Long-Horizon LLM Agents in Heterogeneous Multi-Agent Economies链接 : https://arxiv.org/abs/2606.16613现在的 Agent 评测大多还停留在“单次任务”或“单机环境”阶段。CoffeeBench 把战场拉到了真实的 异构多智能体经济系统 中，让模型在 90 天的模拟周期里真刀真枪地做生意。这不仅是能力的测试，更是对长程决策稳定性和社交策略的极限压力测试。
### 痛点：现有评测太“静态”
传统的 Agent 评测（如 MMLU、SWE-bench）主要考察单轮推理或代码生成。即便是长程任务（如 WebUse），环境往往是被动且确定的。
但在真实商业场景中，Agent 面临的是 动态博弈 ：
- 异构角色：供应商、制造商、零售商目标不同，利益冲突。
- 非同步交互：消息、交易、库存变化是异步发生的，需要事件驱动响应。
- 长尾风险：现金流断裂、库存腐烂、信用违约，这些后果在几十步之后才显现。
CoffeeBench 的核心 Insight 在于： 经济系统是检验 Agent “长期一致性”的最佳沙盒。 它不要求你解开一道数学题，而是要求你在噪音和不确定性中，持续做出有利可图的决策。
### 方法拆解：模拟真实供应链的复杂性CoffeeBench 构建了一个包含 6 个智能体的咖啡供应链： 2 个农户、2 个烘焙师、2 个零售商 。
1. 异构角色与工具链每个角色拥有独特的经济约束和工具集：
- 农户：生产生豆，面临生产成本和时间延迟。
- 烘焙师（被评测主体）：将生豆转化为熟豆，需管理库存腐烂（每日 0.5%）和加工成本。
- 零售商：面向消费者销售，受品牌忠诚度和定价策略影响需求。
2. 异步事件驱动机制这是设计的精髓。Agent 每天只有有限的主动操作窗口（每次工具调用消耗 30 分钟模拟时间）。当 Agent 选择 wait_for_next_day() 进入空闲状态时，它并非完全离线—— 外部事件（如消息、交易确认）可以重新激活它 。这种设计迫使模型必须学会“被动响应”与“主动出击”的平衡，而非简单地轮询环境。
3. 真实的财务约束- Net-30 账期：交易后 30 天付款，逾期产生利息。这引入了现金流管理的维度。
- 破产机制：现金为负即出局。
- KPI 定义：净收入 = 收入 - COGS - 运营支出 - 利息支出 + 利息收入。防止模型通过刷单虚增收入，必须关注利润率。
### 关键结果：沟通是利润的核心驱动论文在 90 天模拟中测试了 GPT-5.5、Claude Opus 4.7、Gemini 3.1 Pro 等前沿模型。数据揭示了令人惊讶的行为模式。

行为洞察：
- 沟通即生产力：表现最好的 GPT-5.5 发送了最多的消息（140 条），主要流向上下游伙伴。这表明主动协调供应链、谈判价格是获取超额利润的关键，而非简单的库存管理。
- 同层沉默：所有模型几乎不与竞争对手（另一个烘焙师）沟通。这说明当前 LLM 尚未演化出复杂的合谋或竞争策略，仍停留在垂直协作层面。
- 效率悖论：Gemini 3.1 Pro 仅发送 16 条消息，但净收入排名第四。它采取的是“被动响应”策略（读取消息 90 次），说明在信息不对称环境中，谨慎的防御性策略也能生存，但难以突破上限。
### ⚠️ 警惕：Idle-Drift（空闲漂移）失效模式Claude Haiku 4.5 的表现极具警示意义。它在 90 天中有 40 天处于空闲状态 ，最终亏损 $630。
分析其思维链发现，模型并非“不知道”该做什么，而是生成了连贯的计划后，反复选择 wait_for_next_day() 。作者称之为 Idle-Drift ：
- 模型在长上下文累积后，可能因对 Token 预算的隐性担忧或过度保守的动作选择，陷入“思考但不行动”的死循环。
- 这揭示了当前小参数/低成本模型在长程任务维持性上的严重缺陷：推理能力并未转化为执行毅力。
### 工程启示- Prompt 工程需强化“行动偏见”：对于长程 Agent，系统提示词应明确惩罚无意义的等待，鼓励在不确定的情况下采取试探性行动（如发送询价消息），而非被动等待完美信息。
- 通信模块至关重要：在复杂多智能体系统中，send_message() 不应被视为辅助工具，而应作为核心决策通道。优化模型的谈判、议价和关系维护能力，比优化单纯的库存算法更能提升 ROI。
- 监控“空闲漂移”：在实际部署中，需设置心跳检测或超时强制中断机制，防止 Agent 陷入长时间的空转思考，导致业务停滞。
### 局限与展望CoffeeBench 目前仅模拟了简化的供应链，缺乏宏观经济学因素（如通货膨胀、政策调控）。此外，实验显示当前模型在极端激励下（如强制营收目标）并未表现出复杂的合谋行为，说明 长期战略欺骗能力 仍是 LLM 的短板。未来研究可探索如何让 Agent 学会更高级的市场操纵或合作博弈策略。
