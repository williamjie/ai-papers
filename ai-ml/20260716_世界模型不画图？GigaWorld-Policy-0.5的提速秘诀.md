论文 : GigaWorld-Policy-0.5: A Faster and Stronger WAM Empowered by AutoResearch链接 : https://arxiv.org/abs/2607.13960机器人控制领域最近有个共识：世界模型（World Models）能显著提升策略的泛化能力。但痛点也很明显——推理时还要生成未来的视频帧，计算量太大，根本没法实时部署。清华 GigaAI 团队这篇论文给出了一个极其实用的解法： 训练时画图，推理时只算动作 。
### 为什么现有方案跑不动？
传统的 World Action Models (WAMs) 在推理时需要联合预测动作和未来视觉观测。这意味着模型不仅要算“手往哪动”，还要生成“动起来后画面变成啥”。视频 Token 的数量远超动作 Token，导致推理延迟极高，难以满足闭环控制的实时性要求。
GigaWorld-Policy-0.5 的核心洞察是： 未来视觉动力学在训练时提供密集监督，但在推理时其实是冗余的。 只要模型学会了物理规律，它就能直接输出正确的动作，而不需要真的把画面“画”出来。
### 方法拆解：MoT 架构与解耦设计为了实现这一目标，作者引入了 Mixture-of-Transformers (MoT) 架构。这不仅仅是换个名字，而是将视觉动力学建模和动作生成拆分为两个独立的专家模块：
- 视觉专家 (Visual Expert)：负责处理视频 Token，学习场景演化规律。它从预训练的世界模型 GigaWorld-1 初始化，继承了强大的视觉先验。
- 动作专家 (Action Expert)：专注于动作 Token 的去噪和预测。为了极致压缩推理延迟，其隐藏层维度仅为 1024（相比视觉专家的 3072），参数量大幅减少。
关键设计 ：采用因果掩码（Causal Masking）策略。训练时，未来视觉 Token 可以关注动作 Token，但动作 Token 严禁关注未来视觉 Token。这种单向信息流确保了模型在推理时可以直接跳过视觉生成部分，仅通过动作专家解码输出。
此外，预训练阶段采用了混合策略，结合 Action-Conditioned World Modeling (AC-WM) 和 WAM 训练。这迫使模型不仅理解“世界怎么变”，还要理解“动作如何导致变化”，从而学到更具迁移性的动作表征。
### 关键结果：快且强实验数据非常硬核，直接对比了主流基线（如 π0.5\pi0.5 , Motus, FastWAM）。
1. 推理延迟大幅降低在本地 RTX 4090 上，通过 C++ 运行时优化，GigaWorld-Policy-0.5 的推理延迟仅为 85 ms 。
- 对比 FastWAM：快了 53%。
- 对比 π0.5\pi0.5：快了 23%。
这在边缘设备上实现实时闭环控制至关重要。
2. 操控成功率领先在真实机器人抓取任务中，GigaWorld-Policy-0.5 表现优异：
- 水果抓取任务：平均成功率 0.85，优于最强的基线 Motus (0.80)。
- 物体放置任务：平均成功率 0.89，比 Motus 高出 6%。
- 长程任务：在涉及多步骤依赖的“食物加热”等任务中，平均成功率达到 0.77，比 Motus 提升了 35%（绝对值 +0.20）。

对于工程师而言，这篇论文传递了两个重要信号：
- 不要为了“好看”而牺牲速度：如果推理不需要视频输出，就坚决在架构上做解耦。MoT 的轻量级动作专家设计值得借鉴。
- 自动化实验是标配：面对多目标优化问题，手动调参已不可行，引入自动化搜索管线能显著降低试错成本。
### 局限与展望虽然效果出色，但该模型仍依赖于大规模视频预训练数据（GigaWorld-1）。对于数据稀缺的特定垂直领域，如何高效迁移这种世界模型先验仍是挑战。此外，85ms 的延迟在极高动态场景下可能仍有优化空间，但已足够应对大多数桌面级操作任务。
