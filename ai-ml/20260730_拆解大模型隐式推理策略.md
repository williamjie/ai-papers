论文 : Uncovering Latent Reasoning Strategies in Language Models链接 : https://arxiv.org/abs/2607.17674大模型解题时其实有“套路”，比如证明题用反证法还是归纳法，但模型内部这些策略是纠缠在一起的。这篇论文试图把这些隐式策略显式化，拆解成可控制的潜在变量。这对我们理解模型决策逻辑、甚至未来做 Agent 的策略路由都有直接启发。
### 痛点：标准 VAE 在这里会“摆烂”
通常我们用变分自编码器（VAE）提取特征，但在大模型场景下有个致命陷阱。基座模型 pθ(y∣x)p_\theta(y|x) ​ ( y ∣ x ) 已经能完美生成响应，它根本不需要潜在变量 zz 。
如果你直接用标准的条件 ELBO 目标函数训练，模型会发现一个“全局最优解”：让生成器忽略 zz ，直接复刻基座模型的分布。结果就是 后验崩溃（Posterior Collapse） —— zz 变成了废变量，虽然输出分布没变，但策略信息完全丢失。
⚠️ 核心洞察 ：问题不在于拟合能力，而在于目标函数缺乏“激励”。如果 zz 不提供额外信息，模型就没动力去用它。我们需要强迫 zz 去解释那些基座模型原本不确定的部分。
### 方法：基于困惑度的定向重构压力作者提出了一种 模型导向的重构（Model-Directed Reconstruction） 目标函数。核心直觉很巧妙：基座模型在哪些 token 上最不确定，哪里就是策略分歧点。
具体设计包含两个关键机制：
- 困惑度加权（Surprisal Weighting）：计算基座模型在每个 token 上的困惑度（surprisal）。困惑度高意味着模型对下一步预测犹豫，这通常是策略选择的分支点。重构损失在这些位置赋予更高权重，迫使 zz 去解释这些不确定性。
- 相对信息增益：重构项不是绝对损失，而是相对于基座模型损失的分数形式。这让 zz 的目标变得清晰——只解释基座模型没搞定的那部分变异，而不是重复劳动。
架构上，他们在 Transformer 中插入了一个伪 token 来嵌入 zz ，并用 LoRA 轻量适配生成器和路由器，确保不破坏基座能力。
### 实验：策略真的被分离了吗？
作者在六个算法任务（如排序、路径规划）上构建了基准测试，这些任务有明确的“参考策略”标签。
1. 隐式信息确实存在线性探针实验显示，基座模型的隐藏层里其实早就编码了策略信息（图 5）。但在标准 ELBO 训练下，这些信息无法被提取到 zz 中。
2. 方法对比在 Qwen2.5 (0.5B/1.5B) 上的表现如下：
方法 分布保真度 (Fidelity) 策略对齐度 (Alignment) Standard ELBO 高 (~1.0) 低 (<0.2) β\beta -ELBO 高 (~1.0) 低 (<0.3) 本文方法 高 (~0.95+) 高 (>0.8)
标准基线虽然保住了输出分布，但策略对齐度极低。本文方法在保持高保真度的同时，显著提升了策略对齐。
3. 跨输入语义一致性更强的测试是“类比一致性”：用问题 A 采样出的 zz ，应用到相似的问题 B 上，能否复现相同策略？实验表明，经过定向重构压力训练的 zz 具有稳定的语义含义，能跨问题复用策略。
### 工程启示- 可解释性新工具：如果你想分析模型为什么选某种解法，可以尝试这种分解方法，把黑盒决策拆解为“策略选择 + 策略执行”。
- Agent 控制：未来可能通过干预 zz 来强制模型使用特定策略（如“必须用动态规划”），而不是靠 Prompt 工程碰运气。
- 训练稳定性：在处理已有强先验的模型微调时，注意目标函数的设计。简单的重构损失容易导致潜在变量失效，引入不确定性加权可能更有效。
### 局限与展望目前方法主要在合成算法任务上验证，对于开放域自然语言推理（如复杂的数学证明或代码生成），策略边界模糊，提取难度会大增。此外，理论分析部分仅提供了初步的充分条件，实际训练动力学仍需更多探索。
