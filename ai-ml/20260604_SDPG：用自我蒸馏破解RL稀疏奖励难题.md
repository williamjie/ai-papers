论文 : Self-Distilled Policy Gradient链接 : https://arxiv.org/abs/2606.04036当前大模型推理能力的提升，严重依赖强化学习（Reinforcement Learning, RL）。但 GRPO 等主流算法面临一个死穴：奖励信号太稀疏。只有最后答案对错的二元反馈，让模型在长链条推理中难以定位具体哪一步出了错。这篇来自 UCLA 的论文提出 SDPG，巧妙地将“自我蒸馏”引入策略梯度更新，用稠密的 Token 级监督填补了 RL 的空白，效果显著且工程实现极简。
### 痛点：RLVR 的“黑盒”困境GRPO 是目前 RL with Verifiable Rewards (RLVR) 的标准范式。它通过组内相对优势（Group Relative Advantage）来优化策略，省去了 Value Network 的训练成本。
然而，这种序列级奖励存在两个致命问题：
- 信用分配稀疏：整个生成长度共享同一个标量奖励，模型很难知道是第一步推导错了，还是最后计算失误。
- 早期训练不稳定：在训练初期，负优势（Negative Advantages）往往占主导，导致 PPO 裁剪机制失效，模型基础语言能力退化。
现有的 On-Policy Distillation (OPD) 试图通过引入 Teacher 模型提供 Token 级指导来解决稀疏性。但传统 OPD 需要更大的外部 Teacher，不仅显存开销巨大，且异构模型间的分布差异会破坏训练平滑度。
### 核心洞察：Self-Distillation 即 Policy GradientSDPG 的核心直觉非常精妙： 既然 RLVR 缺乏中间信号，为什么不让模型自己当自己的老师？
作者提出，On-Policy Self-Distillation 本质上就是一种辅助的全词汇表反向 KL 散度损失。
- Student：在普通 Prompt xx 下生成的策略 πθ(⋅∣x,y<t)\pi_\theta(\cdot | x, y_{<t})​(⋅∣x,y<t​)。
- Teacher：在包含特权上下文（如参考答案、解题思路）的 Prompt (c,x)(c, x) 下生成的策略 πθ(⋅∣c,x,y<t)\pi_\theta(\cdot | c, x, y_{<t})​(⋅∣c,x,y<t​)。
作者证明了，固定前缀下的反向 KL 散度梯度，在数学上等价于一个具有中心化对数比率优势的 Policy Gradient 更新。这意味着我们不需要复杂的近似，可以直接最小化全词汇表的 KL 散度来获得高质量的 Token 级监督信号。
### 方法拆解：三合一的稳定器SDPG 的目标函数由三部分组成，每一部分都针对 RLVR 的痛点进行了设计：
-基于奖励的策略梯度 (LoutL_{out}​)
保留 GRPO 的二元验证器奖励，提供全局正确性约束。这里直接使用 REINFORCE 风格的代理损失，去除了 PPO 的重要性采样裁剪，因为 Rollout 策略就是当前策略本身（On-Policy）。
-全词汇表自我蒸馏 (LOPDL_{OPD}​)
计算 Student 和 Teacher 分布之间的反向 KL 散度。这是稠密信号的主要来源，引导模型在每一步都向“已知正确路径”靠拢。
-参考策略 KL 正则化 (LKL_K​)
为了防止模型在追求高分时偏离基础语言分布，引入固定参考策略 πref\pi_{ref}​ 的未归一化 KL 散度（Unnormalized KL）。作者特别指出，使用未归一化 KL 能带来更优雅且对称的梯度形式。
关键工程技巧：正优势门控与动态调度纯粹的自我蒸馏有一个风险：如果 Teacher 本身在错误路径上给出了看似合理的局部 Token，模型会“学坏”。为此，SDPG 引入了两个稳定器：
- 正优势门控 (Positive Advantage Gating)：只有当组内相对优势 Aout>0A_{out} > 0​>0（即该样本在当前批次中表现较好）时，才启用蒸馏损失。这确保了蒸馏信号只来自“被验证者认可”的轨迹。
- β\beta 调度器：蒸馏系数 β(k)\beta(k) 采用 Warmup-Decay 策略。训练初期让二元奖励主导探索，后期逐渐增强蒸馏信号以细化推理，最后阶段再衰减以避免过度约束导致模式崩溃。

### 工程启示对于正在落地推理模型微调的团队，SDPG 提供了几个极具价值的指导：
- 低成本获取稠密信号：不需要训练庞大的 Teacher 模型，只需在 Prompt 中注入参考答案或解题步骤（Privileged Context），即可利用同一模型生成高质量的蒸馏目标。
- 稳定性优先：正优势门控机制简单有效，建议在实现任何混合监督策略时，都考虑将“全局奖励”作为“局部监督”的开关。
- 警惕模式崩溃：在引入强监督信号（如蒸馏）时，务必监控模型熵值。SDPG 的动态 β\beta 调度器是防止过拟合和模式崩溃的有效手段。
SDPG 证明了，通过巧妙的数学等价性转换和工程上的信号门控，我们可以用极低的额外成本，显著提升大模型在复杂推理任务中的表现。这不仅是算法的改进，更是 RLVR 范式的一次重要补完。
