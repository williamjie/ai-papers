# ⭐⭐⭐ PBSD：用贝叶斯证据解决长程Agent信用分配

**日期**: 2026-06-09

---

论文 : PBSD: Privileged Bayesian Self-Distillation for Long-Horizon Credit Assignment链接 : https://arxiv.org/abs/2606.09348在训练长程搜索 Agent 时，最头疼的不是模型不会搜，而是“不知道哪一步搜对了”。最终答案对了，中间可能混着无效查询；答案错了，前面可能全是高质量推理。这种稀疏奖励下的信用分配难题，直接决定了 RLVR（Reinforcement Learning with Verifiable Rewards）的上限。
PBSD 提出了一种优雅的解法：不引入额外的过程监督标签，也不依赖昂贵的树搜索，而是利用贝叶斯法则，把“最终答案”作为特权信息，反推每一步动作对结果的支持度。
### 为什么现有方案不够用？
目前的长程 Agent 训练主要面临三个痛点：
- 稀疏奖励噪声大：GRPO 等算法将整个轨迹的优势值平均分摊给每个 Token。在长达数百轮、数万 Token 的搜索中，这等同于“平均主义”，无法区分关键步骤和废话。
- 过程监督成本高：基于规则或 LLM-as-a-judge 的过程奖励需要精心设计的 Rubric，且容易引发 Reward Hacking（模型学会刷分而非真思考）。
- 自蒸馏存在信息泄露风险：直接模仿带有答案条件的教师模型（Privileged Policy），会导致学生模型在推理时依赖不存在的答案先验，造成训练与推理分布不一致。
PBSD 的核心洞察在于： 不要让学生去“模仿”带答案的教师，而是让教师的回答作为“证据”，来校准学生的信用分配。
### PBSD 方法拆解：从后验到似然比PBSD 的设计逻辑非常清晰，分为三步走：
- 定义轨迹质量：一个高质量的轨迹 τ\tau 应该能提高正确答案 y∗y^* 的后验概率。即我们要最大化 p(y∗∣x,τ)/p(y∗∣x)p(y^* | x, \tau) / p(y^* | x)∣x,τ)/p(y∗∣x)。
- 贝叶斯转换（核心 Trick）：直接计算上述后验比需要遍历所有可能的未来路径，这在工程上不可行。PBSD 利用贝叶斯定理将其转化为似然比：
p(τ∣x,y∗)p(τ∣x)\frac{p(\tau | x, y^*)}{p(\tau | x)}p(τ∣x,y∗)​这意味着，我们只需要比较同一个轨迹 τ\tau 在“已知答案”和“未知答案”两种条件下的生成概率。前者由特权教师模型计算，后者由学生模型计算。
- Turn-Level 信用分配：通过自回归分解，得到每一步（Turn）的贝叶斯证据分数 si,ts_{i,t}​。如果某一步在已知答案下概率显著更高，说明它支持最终结果；反之则可能是误导步骤。
⚠️ 关键设计细节 ：PBSD 并不直接用这个分数做 Loss，而是用它作为权重 wi,tw_{i,t} ​ ，去调制原有的 GRPO 优势值 AiA_i ​ 。
Ai,t′=wi,t×AiA'_{i,t} = w_{i,t} \times A_i ′ ​ = w i , t ​ × A i ​这种“加权”而非“替代”的策略，保留了最终奖励的全局导向，同时细化了中间步骤的梯度信号。
### 实验结果：少数据，高性能论文在 30B MoE 模型上进行了验证，对比了 GRPO、OPSD 等基线方法。结果非常扎实：
方法 In-Domain Validation BC(300) Overall BC(Hard) GRPO 38.25 32.33 2.25 PBSD 40.87 35.83 4.50- 精度提升：在 BrowseComp (BC) 基准上，PBSD 整体得分比最强的 GRPO 基线高出 3.50 分。
- 难例突破：在 Hard 难度子集上，PBSD 达到 4.50，而 GRPO 仅为 2.25，提升超过一倍。这说明细粒度的信用分配对解决复杂问题至关重要。
- 训练效率：PBSD 仅需 8K 条轨迹进行 SFT+RL 训练，就在多个基准（BrowseComp, GAIA, xBench）上超越了使用数万甚至十万级数据训练的竞品模型。
### 工程启示与避坑指南对于正在落地 Agent RL 的工程师，PBSD 提供了几个极具价值的实践建议：
- MoE 模型的 Routing 噪声：在 MoE 架构下，教师和学生模型的专家路由（Expert Routing）可能不同，导致似然比计算失真。PBSD 发现，必须关闭 Replay 机制，重新计算 Routing 以获取干净的似然分数，否则性能会从 40.87 暴跌至 27.75。
- 低信噪比过滤：并非所有步骤的证据分数都可靠。论文引入了阈值过滤（ϵ+=0.001,ϵ−=0.003\epsilon_+ = 0.001, \epsilon_- = 0.003​=0.001,ϵ−​=0.003），剔除那些接近零、由噪声主导的分数。不加过滤会导致性能下降 6 分。
- 行为重塑：PBSD 训练后的 Agent 倾向于“少说话，多搜索”。实验显示，PBSD 增加了交互轮数（Turns），但大幅减少了生成的 Token 总量。这意味着模型学会了更聚焦的证据收集策略，而非冗长的无效推理。
### 局限与展望PBSD 的前提是存在可验证的最终答案（Verifiable Rewards）。对于开放式创作、代码生成等没有唯一标准答案的场景，该方法难以直接应用。此外，方法依赖于模型似然值的校准程度，若模型本身置信度偏差较大，信用分配信号也会随之失真。
总体而言，PBSD 为长程 Agent 的 RLVR 训练提供了一条低成本、高效率的路径。它证明了在不引入复杂外部评估器的情况下，仅靠贝叶斯自蒸馏就能显著提升模型的推理质量。
