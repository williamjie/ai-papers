# ⭐⭐⭐⭐ 多智能体如何搞定可验证的多模态深度研究？

**日期**: 2026-05-29

---

论文 : Towards Verifiable Multimodal Deep Research: A Multi-Agent Harness for Interleaved Report Generation链接 : https://arxiv.org/abs/2605.29861现在的 AI 搜索工具大多只能给出简短的事实性答案，或者生成一篇纯文本报告。
但真正专业的研究报告（Deep Research）需要图文并茂，且每一张图表都必须有确凿的来源支撑。
这篇论文提出的 PTAH 框架，通过多智能体协作和严格的验证机制，解决了“图文混排”中的幻觉和引用错位问题，工程落地价值极高。
## 痛点：现有方案为何做不好图文报告？
目前的 Deep Search 系统（如 ReAct、WebThinker）主要解决的是封闭域内的确定性问答。
一旦进入开放域的长文报告生成，两个核心难题就暴露了：
- 缺乏阶段性验证：噪声在早期检索阶段引入后，会像滚雪球一样积累，导致最终报告事实不可靠。
- 图文割裂：现有框架通常把图片当作“事后装饰”，而非研究过程的核心证据，导致图片与文字论证脱节。
## 核心洞察：将视觉作为一等公民PTAH 的核心直觉是： 不要把多模态报告生成看作一个黑盒生成任务，而要将其拆解为可验证的工作流。
它引入了三个关键设计：
- 视觉感知规划（Visual-Aware Planning）：规划阶段不仅定义文本结构，还明确指定每个章节需要的视觉证据类型（如图表、截图）。
- 视觉工作记忆（Visual Working Memory）：研究智能体在收集证据时，同步提取网页图片并存储其来源 URL 和上下文。这确保了图片不是随机生成的，而是“源对齐”的。
- 声明式多模态写作：写作智能体通过工具调用插入图片，而不是在文本中硬编码图片路径。
⚠️ 关键机制 ：Verifier Agent（验证器）作为整个系统的“接受函数”，在每个阶段（规划、研究、写作）结束后进行基于规则和 LLM 的校验，确保事实依据、引用保真度和跨模态一致性。
## 实验数据：碾压式领先论文在 DeepResearch Bench 和 DeepConsult 基准上进行了全面评估，结果非常有说服力。

### 2. 多模态呈现质量 (PTAHEval)
这是本文提出的新评估协议，专门针对图文混排质量：
- 图像内容质量 (ICQ)：PTAH 在跨模态对齐（CMA, 4.79）和信息互补性（IC, 4.35）上接近满分。
- 多模态呈现质量 (MPQ)：PTAH 在密度-可读性平衡（DLB, 3.72）和视觉人体工学（VE, 3.71）上显著优于基线。
相比之下，现有的多模态基线 LLM-I 在 ICQ 上的平均分仅为 1.97，几乎不可用。
### 3. 事实可信度方法 引用准确率 (C.Acc.) 有效引用数/任务 WebThinker 60.74% 2.32 PTAH w/o Verifier 30.29% 4.75 PTAH (Ours) 87.53% 9.64去除验证器后，引用准确率暴跌至 30%，这证明了 Verifier Agent 对于保证事实准确性的决定性作用。
## 工程启示- 分阶段验证优于端到端生成：在复杂 Agent 系统中，引入中间状态的校验（如 JSON 格式、事实核查）能显著降低最终输出的错误率。
- 视觉证据需要显式管理：不要依赖模型“顺便”找图。建立独立的视觉工作记忆，强制要求图片与文本段落关联，是提升报告专业度的关键。
- 测试时缩放（Test-Time Scaling）：PTAH 在生成后还进行了六步精化（Section Refine, Image Refine 等），去除了无效图片并优化了 HTML 布局。这种“生成-反思-渲染”的闭环对提升用户体验至关重要。
## 局限与展望论文指出，由于开源模型的推理能力限制，目前仍需要手动定义阶段边界（规划、研究、写作），而非完全自主的单次生成。
此外，PTAH 依赖大量的工具调用和验证步骤，导致延迟较高。未来如何优化这一流程的实时性，是工程落地的下一个挑战。
