# ⭐⭐½ VLM后训练新范式：感知与推理解耦

**日期**: 2026-05-25

---

论文 : From Seeing to Thinking: Decoupling Perception and Reasoning Improves Post-Training of Vision-Language Models链接 : https://arxiv.org/abs/2605.20177现在的多模态大模型（VLMs）训练圈有个迷思：只要 Chain-of-Thought (CoT) 够长，推理能力就能无限拔高。但现实很骨感——很多时候模型算不对，不是因为逻辑不行，而是第一步“看错了”。这篇论文直接点破了这个痛点： 视觉感知（Visual Perception）才是 VLM 的阿喀琉斯之踵 。作者提出了一套“从看到想”的分阶段后训练框架，通过解耦感知与推理，不仅提升了准确率，还让模型的思考过程更精简。
### 痛点：长思考救不了瞎子在几何题或图表理解中，模型经常犯一个致命错误：感知层读错了图中的数值或关系，然后在推理层基于这个错误前提进行长达数百 token 的自我纠错和反复验证，最终依然给出错误答案。
论文通过 Claude-Haiku-4.5 分析发现，在 Qwen3-VL-8B 的错误样本中， 86.9% 的失败根源在于视觉感知错误。一旦感知出错，后续的长链推理不仅无法修正，反而会基于错误假设“一本正经地胡说八道”。这揭示了一个关键 Insight： 更长的思考不能补偿错误的感知 。因此，现有的混合训练（Merged Training）——即把感知数据和推理数据混在一起喂给模型——效率极低，甚至会产生干扰。
### 方法拆解：能力维度的课程学习作者的核心策略是将后训练过程拆分为三个独立的阶段，形成一种正交于传统“难度递增”的 能力维度课程学习（Capability-based Curriculum Learning） ：
-视觉感知阶段（Stage 1）：
数据构造：这是最巧妙的部分。利用 DOCCI 数据集的图片-描述对，让强 LLM（如 Qwen2.5-72B）生成针对图像细节和空间关系的 QA 对。
- 过滤机制：引入“感知敏感度过滤”。只有当模型仅看图片答错、但看了描述能答对时，该样本才被保留。这确保了数据真正挑战的是模型的视觉识别能力，而非推理短板。
- 训练方式：弃用传统的监督微调（SFT），采用基于可验证奖励的强化学习（RLVR）。因为 SFT 容易引入低质量数据的噪声，而 RL 能让模型在策略上更稳健地对齐视觉事实。
-文本推理阶段（Stage 2）：
使用纯文本数学数据集（如 ORZ-Math-13k），强化模型的逻辑推导能力，此时不依赖视觉输入。
-视觉推理阶段（Stage 3）：
结合视觉与文本的复杂推理任务（如 GeoQA, CLEVR-Math），让模型在稳固的感知和文本逻辑基础上，处理多模态综合问题。
顺序至关重要 ：实验表明， 感知 → 文本推理 → 视觉推理 的顺序效果最佳。如果颠倒顺序（先练视觉推理），由于缺乏坚实的感知基础，Qwen2.5-VL-7B 的数学平均分直接从 42.3% 暴跌至 37.7%。
### 关键结果：准且快这套分阶段训练在多个基准上实现了“既要又要”的效果：
指标 Qwen3-VL-8B (Staged) Qwen3-VL-8B (Merged) 提升幅度 WeMath 准确率 56.1% 54.6% +1.5% RealWorldQA 准确率 74.5% 71.0% +3.5% 推理轨迹长度 445 tokens 562 tokens -20.8%- 感知决定上限：在 WeMath 基准上，加入专门的视觉感知训练阶段，使 Qwen2.5-VL-7B 的准确率提升了 7.43%。
- RL 优于 SFT：在感知阶段使用 RLVR 替代 SFT，Qwen2.5-VL-7B 在 WeMath 上的准确率提升了 8.1%（从 30.1% 到 38.3%），证明了 RL 在视觉对齐上的优势。
- 效率提升：由于感知准确，模型不再需要反复“回看图片”来纠错，推理轨迹缩短了 20.8%，这意味着更低的延迟和推理成本。
### 工程启示对于正在微调 VLM 的工程团队，这篇论文提供了明确的行动指南：
- 不要混合喂养：如果你发现模型的幻觉或错误源于“看图不准”，不要试图用更多的 CoT 数据去覆盖它。单独开辟一个感知训练阶段，效果立竿见影。
- 重视数据清洗：感知数据的构造需要精细的过滤（如文中提到的 Answer(img) != Answer(cap)），确保训练样本真正针对视觉缺陷。
- 尝试 RLVR 进行对齐：在视觉对齐阶段，RL 可能比 SFT 提供更干净的梯度信号，减少模型对错误描述的过拟合。
- 关注推理成本：提升感知能力不仅能提高准确率，还能显著缩短生成长度。在生产环境中，这意味着更低的 Token 消耗和更快的响应速度。
### 局限与展望目前该方法主要基于开源数据集合成感知 QA，对于极度专业或罕见领域的视觉概念，数据覆盖度可能不足。此外，虽然 RLVR 效果更好，但其训练成本和稳定性挑战高于 SFT，在实际落地中需要权衡资源投入。未来，如何将这种“能力解耦”思想扩展到更复杂的 Agent 任务流中，值得进一步探索。
