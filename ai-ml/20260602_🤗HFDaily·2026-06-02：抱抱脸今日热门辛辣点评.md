## 模型 Top 5### 1. nvidia/LocateAnything-3BNVIDIA 又来刷榜了，这次搞了个 3B 参数的“定位一切”模型。名字起得比 SAM 还狂，但 pipeline 居然是 image-text-to-text ——你到底是做视觉定位还是多模态对话？标签里既有 object-detection 又有 feature-extraction ，感觉像是个大杂烩。建议 README 先解释清楚：这东西和 Grounding DINO 比到底哪里更强？别光靠 NVIDIA 的招牌骗赞。
### 2. openbmb/MiniCPM5-1B1B 参数硬塞长上下文和工具调用，OpenBMB 这是要把大模型塞进微波炉里跑？MiniCPM 系列向来以“小钢炮”著称，但 1B 真的能 hold 住 tool-calling 吗？我怀疑 benchmark 上的分数全靠精心构造的 prompt 撑场面。不过下载量 4.5 万说明大家还是买账的——毕竟谁不想在树莓派上跑个会调 API 的模型呢。
### 3. LiquidAI/LFM2.5-8B-A1BLiquidAI 的 MoE 模型，8B 总参数但激活只有 1B，这命名方式简直是在跟用户玩猜谜游戏。 LFM2.5 这个版本号让我想起了手机系统更新——每次都是小修小补。Edge 部署是亮点，但实际推理延迟有没有比同尺寸 Dense 模型快？建议别光吹稀疏专家（MoE）的省显存特性，把端侧实测数据贴出来。
### 4. HauhauCS/Qwen3.6-35B-A3B-Uncensored-HauhauCS-Aggressive名字越长，模型越野。253 万下载量说明社区对“无审查”的热情远超对模型架构的尊重。
这个模型集齐了所有流量密码：Qwen3.6 基座、MoE（35B 参数激活 3B）、Uncensored、还带个 Aggressive 后缀。我猜 README 里八成写着“本模型未经任何安全对齐，请谨慎使用”。但说实话，这种社区魔改版通常就是拿原版模型跑一遍 DPO 把拒绝回答删掉，再吹一波“脱缰”效果。技术上没什么新意，倒是给 GGUF 社区贡献了巨大的下载量。
### 5. meituan-longcat/LongCat-Video-Avatar-1.5美团也来卷视频数字人了， LongCat 这名字是“长猫”还是“长上下文”？看标签支持音频、图像、文本多种模态驱动，功能堆得挺全。但下载量 0 是个危险信号——要么是刚发布还在审核，要么就是 README 里藏着“需要申请权限”这种劝退条款。视频生成赛道已经挤成沙丁鱼罐头了，美团这个要是没有差异化优势，恐怕连 demo 都活不过下周。
## 数据集 Top 3### 1. openbmb/UltraData-SFT-2605OpenBMB 又双叒叕放数据集了，这次是 10B~100B token 的 SFT 数据，名字里带 2605 不知道是不是内部版本号。这么大的 SFT 数据集，清洗质量是最大疑点——很多大厂的经验是：数据量翻倍不如把清洗流程重写一遍。不过 Apache-2.0 许可证值得点赞，至少不像某些公司把数据当传家宝。
### 2. openbmb/Ultra-FineWeb-L3FineWeb 的变体， L3 听着像某个神经网络层的名字。1B~10B token 的规模不算大，但号称是“精炼版”。如果真是从 FineWeb 里蒸馏出来的高质量子集，那对中小团队训练小模型很有价值。就怕只是简单切分了一下就拿出来刷存在感——毕竟 OpenBMB 最近发数据集的频率比发论文还高。
### 3. jasperai/monetMonet ？这名字让我以为是风格迁移数据集，结果标签里写着 text-to-image 、 image-feature-extraction 、 zero-shot-image-classification ，好家伙，一个数据集想通吃所有多模态任务？下载量 27 万说明大家还是被名字骗进去试了。建议作者在 README 里写清楚：你到底是个啥？别让用户下载完才发现是个大杂烩。
## Spaces Top 2### 1. webml-community/bonsai-image-webgpu一个静态 Space 能冲上热门，说明 WebGPU 跑图像处理还是戳中了大家的痒点。 Bonsai （盆景）这名字挺禅意，但实际效果估计就是几个滤镜的 demo。WebML 社区一直想推浏览器端 AI，可惜目前 GPU 加速的覆盖率和性能都还差口气。这个 Space 更多是象征意义：看，我们能在浏览器里跑模型了！——虽然跑的是个玩具。
### 2. nvidia/LocateAnything和模型配套的 Gradio 演示，没什么好说的，就是给 LocateAnything-3B 搭了个展示台。热度 122 比模型低不少，说明大家更关心能不能下载模型自己玩，而不是在线体验。不过 NVIDIA 好歹给了个能跑的 demo，比某些只放论文链接的厂商强点——至少证明这个模型不是 PPT 产物。
总结 ：今天的榜单里，社区魔改的 uncensored 模型依然是流量担当，OpenBMB 在数据集领域疯狂刷存在感，NVIDIA 和 LiquidAI 则在推“小而美”的模型。唯一让人眼前一亮的是 WebGPU 的静态 Space，虽然功能简陋，但代表了浏览器端 AI 的一个小里程碑。至于那些名字越取越长的模型——建议厂商们学学苹果的命名哲学：别让用户猜你的模型到底能干嘛。
