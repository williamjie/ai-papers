# 零参外挂：LLM的N-Gram记忆补丁

**日期**: 2026-05-19

---

论文 : NGM: A Plug-and-Play Training-Free Memory Module for LLMs链接 : https://arxiv.org/abs/2605.16893给大模型加“外挂记忆”通常意味着两件事：要么训练额外的参数（如 MoE），要么搞一套复杂的检索系统（RAG）。但南京大学这篇论文提出了一个极简方案： 完全不训练、不加参，直接复用模型已有的词嵌入（Embedding）空间，构建一个 N-Gram 记忆模块 。
对于不想做全量微调、又希望提升代码生成和知识密集型任务表现的工程师来说，这种“即插即用”的思路极具吸引力。
### 痛点：Transformer 的“重复造轮子”
Transformer 擅长动态推理，但在处理命名实体、固定术语、公式化短语等 静态局部模式 时，效率并不高。它必须通过注意力机制和前馈网络重新“推导”这些已知信息，而不是直接“查找”。
现有的解决方案如 Engram 或各类 Embedding Scaling 方法，虽然引入了显式查找（Lookup）机制，但都需要训练独立的记忆表或额外的参数。这不仅增加了训练成本，还限制了灵活性。
核心 Insight ：既然模型的词嵌入层（Token Embedding Layer）已经包含了丰富的语义信息，我们能不能直接把这些嵌入向量当作“本地记忆”？如果在推理时，将局部窗口内的 Token 嵌入进行平均聚合，能否得到一个有用的 N-Gram 特征？
### 方法拆解：两个非参数组件NGM（N-gram Memory）的设计极其简洁，由两部分组成：
-因果 N-Gram 编码器（Causal N-gram Encoder）：
不训练任何新参数。
- 直接取 Backbone 模型预训练好的 Token 嵌入。
- 在局部因果窗口（如最近 2 个或 3 个 Token）内进行平均池化（Average Pooling）。
- 这相当于把“词袋”思想引入嵌入空间，构建出多尺度的局部记忆向量。
-余弦门控记忆注入器（Cosine-Gated Memory Injector）：
关键直觉：作者发现，聚合后的 N-Gram 嵌入与解码器隐藏状态（Hidden States）在几何空间上存在显著对齐（Qwen3-8B 中平均余弦相似度为 0.312，远高于随机对照组的 0.014）。
- 利用余弦相似度作为门控信号，计算当前隐藏状态与 N-Gram 记忆的匹配度。
- 引入 ReLU 过滤负向对齐的信号，只注入“有用”的记忆。
- 最后通过残差连接（Residual Connection）将记忆注入到特定的中间层。
整个过程在推理阶段完成，无需修改模型权重，无需额外存储。
### 关键结果：代码与知识任务显著提升作者在 Qwen3 系列（0.6B 到 14B）上进行了广泛测试。结果如下：

### 工程启示与局限为什么值得尝试？
- 零成本升级：不需要重新训练，不需要微调，甚至不需要加载额外的权重文件。只需在推理代码中插入几行逻辑。
- 延迟极低：在 RTX 5090 上测试，Prefill 阶段开销仅增加 3.4%-7.3%，Decode 阶段增加 1.9%-2.3%。这对于实时应用完全可接受。
- 特定场景优化：如果你的 Agent 或应用大量涉及代码生成、固定术语问答，NGM 是一个低成本的性能增益点。
局限性- 指令遵循可能受损：在 IFEval 基准上，部分模型表现下降。因为固定的注入规则可能干扰模型对指令细微差别的敏感度。
- 顺序不敏感：平均池化丢失了窗口内的词序信息，对于高度依赖语序的长难句可能引入噪声。
- 超参数敏感：注入层的选择（如 L1, L14）和缩放因子 λ\lambda 需要针对模型调优，目前缺乏自适应机制。
总结 ：NGM 证明了预训练嵌入空间中蕴含了可被直接复用的“局部记忆”结构。对于追求极致推理效率和轻量级优化的工程团队，这是一个值得纳入工具箱的 Trick。
