# ⭐⭐⭐ 小模型RL大模型用：Direct-OPD弱强蒸馏实战解析

**日期**: 2026-07-14

---

论文 : Weak-to-Strong Generalization via Direct On-Policy Distillation链接 : https://arxiv.org/abs/2607.05394大模型推理能力的提升越来越依赖强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）。但痛点也很明显：模型越大，RL 训练越贵。跑一次 RL 的 rollout 耗时惊人，让后训练阶段成了算力瓶颈。这篇论文提供了一个极其务实的思路： 与其在大模型上死磕昂贵的 RL，不如在小模型上跑 RL，然后把学到的“改进方向”低成本地迁移给大模型。
### 为什么不能直接模仿小模型？
直觉上，既然小模型经过 RL 变强了，让大模型去模仿它（On-Policy Distillation, OPD）不就行了吗？
论文给出了一个反直觉的结论： 直接模仿会让大模型变弱。
原因在于，小模型的最终策略混合了两部分信息：
- RL 带来的有效改进（我们想要的）。
- 小模型自身的容量局限（我们不想要的噪音）。
当学生模型（大模型）初始能力已经强于老师模型（小模型）时，强行模仿老师的分布会覆盖掉大模型原本更优的行为。例如，R1-Distill-7B 初始 AIME 2024 分数为 56.7%，而经过 RL 的小模型 JustRL-1.5B 只有 51.3%。如果用传统 OPD 让 7B 模仿 1.5B，分数会直接掉到 50% 左右。
### Direct-OPD 的核心直觉：迁移“变化量”而非“最终值”
论文提出的 Direct On-Policy Distillation (Direct-OPD) 核心 insight 非常巧妙： 不要看老师变成了什么，要看老师改变了什么。
作者定义了一个 策略偏移（Policy Shift） ΔT\Delta_T ​ ，即 RL 后的小模型与 RL 前的小模型的 log-ratio：
ΔT(y∣x)=log⁡πT(y∣x)−log⁡πTref(y∣x)\Delta_T(y|x) = \log \pi_{T}(y|x) - \log \pi_{Tref}(y|x) ​ ( y ∣ x ) = lo g π T ​ ( y ∣ x ) − lo g π T r e f ​ ( y ∣ x )
这个差值剔除了小模型原本就有的偏好，只保留了 RL 带来的“增量”。在数学上，这个策略偏移等价于训练小模型时使用的 隐式奖励（Implicit Reward） 。
Direct-OPD 的做法是：
- 让学生模型在自己的 on-policy 状态下采样。
- 计算老师模型的策略偏移 ΔT\Delta_T​ 作为密集奖励信号。
- 优化学生模型，使其在自身分布上最大化这个奖励，同时用 KL 散度锚定初始状态防止崩溃。
简单来说，就是告诉大模型：“小模型在 RL 过程中增加了哪些 token 的概率，你也跟着增加；减少了哪些，你也跟着减少。”
### 实验效果：便宜且高效论文在 AIME 2024/2025 数据集上进行了大量对比，结果非常有说服力。
1. 跨规模提升显著使用 JustRL-1.5B 作为老师，Direct-OPD 成功提升了多个更强的学生模型：
学生模型 初始分数 (AIME 24) Direct-OPD 后分数 提升幅度 Qwen3-1.7B 48.3% 58.3% +10.0% Qwen3-4B 72.5% 77.6% +5.1% R1-Distill-7B 56.7% 63.1% +6.4%注意，R1-Distill-7B 和 Qwen3-4B 的初始分数都远高于老师模型，但依然获得了显著提升。这证明了迁移的是“RL 方向”而非“绝对能力”。
2. 算力成本碾压直接 RL这是工程落地最关心的部分。
- 传统路径：在 Qwen3-1.7B 上直接跑 RL，需要 32 张 A100 GPU 运行至少一周。
- Direct-OPD 路径：先用小模型跑 RL（成本低），然后迁移到 Qwen3-1.7B。仅需 8 张 A100 GPU 运行约 4 小时，即可达到甚至超越直接 RL 的效果。
在匹配 RL step 数的对比中，先在小模型上跑 RL 再迁移，其性能也优于直接在对应步数的大模型上跑 RL。因为小模型探索更快，能更稳定地找到改进方向。
反直觉发现 ：Direct-OPD 不需要学生和老师有高的 token 重叠度（Top-k Overlap）。传统蒸馏依赖老师教学生“选什么词”，而 Direct-OPD 利用的是老师“相对之前的变化”，即使两者思维模式不同，只要 RL 带来的改进方向一致，就能生效。
### 工程启示与局限对实际应用的指导意义：
- 小模型是廉价的 RL 探针：你可以定期在小模型上跑 RLVR，提取其策略偏移作为“补丁”，低成本地更新生产环境中的大模型。
- 无需重新训练 Reward Model：Direct-OPD 直接从 checkpoint pair 中提取信号，省去了训练显式奖励模型的步骤。
- 短序列训练足够：实验发现，训练时截断到 2k token 的响应长度就能捕捉到有效的 RL 方向，并能泛化到长推理过程，进一步降低训练成本。
局限与注意事项：
- KL 系数敏感：由于隐式奖励的尺度不可知，需要自适应控制 KL 惩罚系数（Adaptive KL Control），否则容易过拟合或欠拟合。
- 长尾噪音：如果训练 horizon 过长（如 6k+），可能会引入小模型在长序列末端的不可靠信号，导致验证集分数下降。建议保持在中等长度（如 2k）。
这篇论文为“低成本后训练”提供了一条清晰的路径。对于算力有限但追求推理能力的团队， “小模型探路 + Direct-OPD 迁移” 可能比直接上大模型 RL 更具性价比。
