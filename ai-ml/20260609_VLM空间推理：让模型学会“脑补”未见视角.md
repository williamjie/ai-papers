# ⭐⭐ VLM空间推理：让模型学会“脑补”未见视角

**日期**: 2026-06-09

---

论文 : Imaginative Perception Tokens Enhance Spatial Reasoning in Multimodal Language Models链接 : https://arxiv.org/abs/2606.03988现有的视觉语言模型（VLM）在识别物体时表现优异，但在处理空间推理任务时往往显得笨拙。这篇论文的核心洞察是：许多空间问题无法仅通过观察当前输入解决，需要模型具备“想象”能力——即在脑海中模拟未见视角或整合碎片信息。作者提出了一种名为 Imaginative Perception Tokens (IPT) 的中间表示方法，强制模型在回答前生成一个符合物理规律的“脑补”图像，从而显著提升空间推理性能。
### 痛点：为什么文本 CoT 搞不定空间问题？
传统的思维链（Chain-of-Thought, CoT）试图用自然语言描述空间变换，但这存在严重的模态错配。
当要求模型描述“向左转90度后冰箱在左边还是右边”时，文本必须序列化复杂的几何约束和遮挡关系。这不仅冗长，而且容易引入噪声。论文指出，强制模型通过语言进行空间计算往往是有害的，因为它分散了模型用于预测答案的容量，且文本难以精确表达视觉上的相对位置。
### 方法拆解：把“想象”变成可训练的 TokenIPT 的核心设计直觉是： 与其让模型用文字描述看不见的东西，不如让它直接画出那个视角。
作者基于统一架构模型 BAGEL 实现这一目标。BAGEL 是一个解码器仅（decoder-only）Transformer，原生支持图文交错理解与生成。其关键组件包括：
- 双专家混合（MoT）：一个专家负责多模态理解，另一个负责图像生成，两者通过共享自注意力机制交互。
- 双流 Token：图像被编码为理解 Token（来自 SigLIP2 ViT）和生成 Token（来自 FLUX VAE 潜在空间）。
在训练阶段，模型执行两步生成过程：
- 想象阶段：根据输入图像和问题，生成一个“想象中的感知 Token”（例如，从新视角看到的场景渲染图）。这通过流匹配损失（Flow-Matching Loss）优化，确保生成的潜在变量符合地面真值。
- 回答阶段：将生成的想象图像重新编码并附加到上下文中，模型基于此预测最终答案。
这种设计的关键在于，生成的图像不是随意的艺术创作，而是受输入约束的、物理一致的空间重构。它外部化了模型内部对未观测结构的假设。
### 关键结果：视觉中间态胜过文本思考作者在三个需要空间想象的任务上进行了评估：视角转换（Perspective Taking, PET）、路径追踪（Path Tracing, PT）和多视图计数（Multiview Counting, MVC）。实验数据极具说服力：
模型变体 PET (AI2-THOR) PT (AI2-THOR) MVC (AI2-THOR) Bagel (Base) 40.3% 29.9% 35.4% + Label Only 97.5% 65.7% 63.9% + Text CoT 83.1% 49.7% 62.3% + IPT 96.8% 49.0% 67.3% + Mixed Training 97.8% 66.7% 87.7%⚠️ 反直觉发现 ：在推理阶段，即使不显式生成想象图像（Answer-only mode），经过 IPT 训练的模型性能依然优于纯标签训练。例如在 PT 任务中，IPT 训练后的 Answer-only 模式准确率为 61.1%，而显式生成图像的模式仅为 50.4%。
这说明 IPT 的主要价值在于 监督信号 。它迫使模型在微调过程中学习更鲁棒的内部空间表示，而不是依赖推理时的即时生成功能。此外，文本 CoT 在 PET 和 PT 任务上表现显著低于标签仅训练（分别为 83.1% vs 97.5% 和 49.7% vs 65.7%），证实了语言在空间计算上的局限性。
### 工程启示：如何落地？
对于致力于提升 Agent 空间感知能力的工程师，这篇论文提供了几个实用建议：
- 利用模拟器数据微调：使用 AI2-THOR 等仿真环境生成带有地面真值中间态的数据进行监督微调（SFT），能显著增强模型在真实世界中的泛化能力。
- 混合训练策略：结合 IPT 数据和纯标签数据进行混合训练，能在保持生成能力的同时最大化推理精度。
- 警惕文本 CoT 的陷阱：在处理涉及视角变换、遮挡或几何计数的任务时，不要盲目依赖文本思维链。尝试引入视觉中间表示或结构化感知 Token 可能更有效。
- 分辨率即性能：消融实验显示，想象图像的潜在分辨率直接影响下游准确率。从 Latent-4 (64x64) 提升到 Latent-64 (1024x1024)，PET 任务准确率从 87.4% 提升至 96.8%。清晰的视觉细节是空间推理的基础。
### 局限与展望尽管 IPT 效果显著，但其依赖高质量的中间态标注数据，这在真实世界中获取成本极高。目前主要依赖仿真环境生成数据，并尝试通过跨环境迁移（如从 AI2-THOR 到 Habitat）来缓解分布偏移问题。未来，如何降低对完美地面真值想象的依赖，以及如何将这种“想象”能力扩展到更动态的时序空间推理中，是值得探索的方向。
