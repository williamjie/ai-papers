# UniT：用统一物理语言架起人类到人形机器人的桥梁

**日期**: 2026-04-24

---

论文 : UniT: Toward a Unified Physical Language for Human-to-Humanoid Policy Learning and World Modeling链接 : https://arxiv.org/abs/2604.19734人形机器人要真正走进家庭、工厂，最大的瓶颈是什么？不是硬件，是 数据 。机器人的行为数据稀缺、昂贵，且难以规模化。与此同时，人类的动作视频——不管是第一视角的日常生活记录，还是网络上的运动教学——几乎是无限的。但直接把人类视频”翻译”成人形机器人动作， kinematic（运动学）不匹配这个问题就像一堵高墙：人类有32个关节自由度，人形机器人动辄40+，骨骼长度、关节类型、身体比例全都不一样。UniT这篇工作给出的思路很干脆： 别硬去对齐关节角度，先找到动作背后那个”物理意图”的统一表征 。
## 问题与动机：跨形态数据对齐的困境现有方案无非两条路：
- 直接模仿学习：用人类视频的2D关键点或3D姿态估计结果，直接监督机器人动作。问题在于估计误差会累积，而且人类的”抬手”和人形机器人的”抬手”在动力学和约束上根本不是一回事。
- 跨模态检索/匹配：在人类视频库中检索与机器人当前状态最相似的片段。但视觉相似 ≠ 物理意图相似——人类擦桌子和人形机器人擦桌子，手的轨迹、身体重心移动完全是两码事。
根本矛盾在于： 我们试图对齐的是”动作表示”（关节角度序列），但真正需要对齐的是”物理后果”（物体位移、接触力变化、环境状态改变） 。UniT的核心假设是： 异构的运动学（heterogeneous kinematics）共享统一的视觉后果（universal visual consequences） 。换句话说，不管你是人是机器人，推动一个杯子，杯子就应该往那个方向移动。那就从这里入手。
## 方法拆解：三叉戟交叉重建UniT的全称是 Unified Latent Action Tokenizer via Visual Anchoring，名字已经说清楚了——要做 统一的离散潜在动作tokenizer ，而且用 视觉锚定 来保证这个统一性不是空中楼阁。
### 核心架构：三个分支的协同模型分成三个平行分支，训练目标是一个 交叉重建 的循环：
人类动作 ──→ 预测视觉 ──┐├→ 融合分支（共享离散潜在空间）
人形动作 ──→ 预测视觉 ──┘↑ ↑人类视觉 ──→ 重建动作 ──┘人形视觉 ──→ 重建动作 ──┘-动作→视觉分支：给定一个动作序列（人类或机器人的关节角度），通过一个时空编码器预测未来几帧的视觉观测。这个任务强制模型学习”这个动作会在世界里造成什么变化”。这是UniT的锚点——把动作锚定在物理结果上，而不是关节角度的表面相似性。
-视觉→动作分支：给定一段视觉观测（人类或机器人的第一视角），重建对应的动作序列。这是过滤器——如果某个视觉变化对所有动作预测都是无关的”confounder”（比如背景光影变化），这个任务会迫使模型忽略它，只保留与动作相关的视觉特征。
-融合分支：将上述两个分支提取的”纯化后”的视觉特征和动作特征，通过向量量化（VQ）映射到同一个离散token空间。这个空间里的每个token代表一个”物理意图原子”，不带有任何特定形态的印记。
训练时，两个模态（人类、人形）的数据一起喂给这个三路架构。t-SNE可视化显示，经过训练后，人类动作和人形动作的潜在表示确实收敛到了 同一个流形 上——这正是”统一物理语言”的实证。
### 为什么这个设计管用？
- 视觉锚定解决了”形似神不似”的问题。人类抬手可能因为手臂长，机器人抬手因为关节扭矩限制，但如果是去拿同一个杯子，视觉后果应该相似。动作→视觉任务逼模型抓住这个相似性。
- 双向过滤避免了各自模态的confounder污染对方。人类视频里的非动作视觉变化（比如镜头运动、环境光线）不会影响token空间；机器人动作里的非物理相关关节波动也不会污染人类表示。
- 离散化提供了可组合、可索引的原子单元。不像连续表征那样难以跨模态对齐，离散token天然具有”符号”属性，适合做迁移学习的桥梁。
## 关键结果：数据效率与零样本迁移论文在两个方向上验证了UniT：
### 1. VLA-UniT：策略学习设置 ：在仿真benchmark（DeepMind的HumanoidBench）和真实人形机器人（TESS、Unitree H1）上，用 人类动作捕捉数据 （如AMASS数据集）预训练，然后在少量机器人数据上微调策略。
结果 ：
指标 VLA-UniT (本文) 基线方法 (行为克隆+数据增强) 提升 仿真任务成功率 78.3% 62.1% +16.2% 真实世界零样本成功率 62.7% 41.5% +21.2% 数据效率（10%机器人数据） 71.4% 53.8% +17.6% OOD（未见物体）成功率 58.2% 36.9% +21.3%重点看 零样本任务迁移 ：在训练中从未见过的任务（比如用不熟悉的工具），UniT策略的成功率比基线高出20%以上。这意味着人类数据里学到的通用物理意图，真的泛化到了新场景。
### 2. WM-UniT：世界建模与动作迁移设置 ：训练一个视频生成世界模型，输入是人类第一视角视频 + 统一token，输出是人形机器人第一视角视频。相当于”人类动作 → UniT token → 人形机器人视频”的直接通道。
结果 ：
- 人类动作通过UniT token，可以直接驱动人形机器人视频生成，成功率（视频符合物理规律的比例）达 73.4%，而直接映射baseline只有 48.9%。
- token空间的对齐质量通过跨形态动作相似度验证：人类动作序列A和人形动作序列B，如果在同一个任务下，它们的token序列余弦相似度平均为0.81，而随机配对只有0.23。
## 工程启示：我们能拿走什么？
-数据稀缺的破局思路：如果你在训练某种机器人但缺乏任务数据，先看看有没有相关的人类示范数据。关键不是对齐关节角度，而是找到那个”统一物理意图”的表示。UniT的三路交叉重建架构是个可复用的pattern——任何跨模态迁移问题，都可以用”模态A预测模态B + 模态B重建模态A + 共享潜在空间”来尝试对齐核心语义。
-离散化作为对齐工具：连续表征很容易在跨模态迁移时丢失关键信息。向量量化（VQ）虽然会损失细节，但恰好过滤掉形态特有的噪声，留下语义核心。工程上，VQ-VAE或VQ-GAN这类工具可以低成本地在你的数据上尝试。
-世界模型作为对齐验证器：如果你不确定两个模态是否真的对齐了，可以训练一个跨模态生成模型（这里是从人类token生成机器人视频），看生成质量。生成质量越高，说明token蕴含的动作语义越纯、跨形态迁移越有效。
-实际部署的注意事项：
UniT在真实机器人上的零样本成功率超过60%，但依然有~40%失败率。这意味着token空间对齐后，仍然需要少量机器人数据（论文用10%）做 finetune 来适应具体硬件的执行偏差。
- 当前实验聚焦上肢操作任务（抓取、推、拉等），全身运动（走路、跑步）的token化可能需要不同的架构设计，比如加入动力学约束。
## 局限与展望论文在讨论部分明确承认了几个边界：
- 任务范围：当前验证的主要是手部操作任务。全身协调动作（如踢球、爬行）的token对齐可能需要更复杂的时空建模，或者引入动力学模型作为正则。
- 感知依赖：UniT的”视觉锚定”严重依赖视觉观测质量。如果在低光照、遮挡严重的环境下，视觉预测任务本身就会出错，进而污染token质量。未来可加入多传感器融合（触觉、力觉）来增强锚定的鲁棒性。
- 计算成本：三路架构加上 VQ 离散化，训练成本比单模态模仿学习高不少。论文没有给出具体训练时长，但提到用了 8×A100 训练 3 天。对于资源有限的团队，可以考虑预训练 + 轻量化微调的流水线。
后续方向论文提到了几个 interesting 的点：
- 将 UniT token 作为通用接口，连接不同形态的智能体（比如无人机、机械臂、人形机器人）到同一个策略网络。
- 探索 token 的可解释性：能不能给每个物理意图 token 贴个”语义标签”（比如”推”、“旋转”、“精细抓取”），从而让策略更可控？
- 扩展到多智能体协作场景：统一token能否编码”与人交互”的意图？
## 一点判断UniT 的思路其实很”物理”：先不管你怎么动， 看最后世界变成什么样 。动作和视觉互为锚点，最终在离散空间里找到那个动作的”本质”。这不是什么花哨的深度学习 trick，而是对”什么是动作”这个问题的一个优雅的形式化。
工程上最值得借鉴的是那个 三叉戟交叉重建 的架构——它本质上是在做 去混杂 （confounder removal）：视觉分支去掉动作无关的视觉噪声，动作分支去掉视觉无关的形态噪声，剩下的才是真正的物理意图。这种filter思路在任何跨域迁移问题里都值得试试。
不过，论文在真实机器人上只展示了 上肢任务 的零样本迁移。人形机器人最难的部分永远是 全身协调与平衡 ，而这恰恰需要动力学层面的对齐，光靠视觉锚定的token可能不够。想知道 UniT 能不能 handle 走路、跑步这类需要强动力学约束的任务——那是下一个真正的硬仗。
