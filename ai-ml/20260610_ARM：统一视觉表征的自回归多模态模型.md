**日期**: 2026-06-10

论文 : ARM: An AutoRegressive Large Multimodal Model with Unified Discrete Representations链接 : https://arxiv.org/abs/2606.11188目前的多模态大模型（LMM）大多还在搞“拼装车”：理解用 CLIP，生成接 Diffusion。这种架构不仅推理成本高，而且因为视觉表征不统一，编辑任务经常翻车。ARM 论文试图证明，只要搞定一个 统一的离散视觉 Tokenizer ，自回归模型完全可以同时拿下理解、生成和编辑，甚至还能通过强化学习实现跨任务的正向协同。
## 痛点：为什么现在的方案不够好？
现有主流方案存在明显的结构性割裂：
- 表征不匹配：理解任务需要高层语义（Semantic），生成任务需要底层细节（Appearance）。大多数模型被迫维护两套视觉编码器，导致上下文冗余且推理开销巨大。
- 编辑能力弱：基于纯语义 Token 的模型（如 NextGPT）丢失了像素级细节，无法进行精细编辑；而基于 VQ-GAN 的模型虽然能生成，但语义对齐差，理解能力受限。
- 训练割裂：理解、生成、编辑往往需要不同的数据配比和训练策略，难以在一个框架内平衡。
## 核心设计：如何用一个 Tokenizer 搞定所有事？
ARM 的核心 Insight 在于： 视觉表征不需要二选一，可以通过多目标监督让离散 Token 同时具备语义性和细节保真度。
### 1. 统一离散视觉 Tokenizer作者基于冻结的 SigLIP2 编码器，通过投影层映射到紧凑潜空间，并使用有限标量量化（FSQ）生成 65K 大小的 Codebook。关键在于训练时的四个互补损失函数：
- Caption Loss (Lcap\mathcal{L}_{cap}​)：让 Token 对齐语言模型，保证语义可理解。
- Pixel Reconstruction Loss (Lpix\mathcal{L}_{pix}​)：引入轻量级 Diffusion Transformer 解码器，直接在像素空间优化速度场。这避免了传统 VAE 瓶颈带来的信息丢失，保留生成所需的细节。
- Sigmoid Loss (Lsig\mathcal{L}_{sig}​) & Feature Distillation (Lfeat\mathcal{L}_{feat}​)：强制量化后的 Embedding 与原始 SigLIP2 特征保持高相似度，防止离散化过程中的语义漂移。
### 2. 自回归主干与偏好对齐基于上述 Tokenizer，ARM 训练了一个 7B 参数的自回归模型，处理交错的多模态序列。更有趣的是其强化学习（RL）阶段：
- 使用 GRPO (Group Relative Policy Optimization) 进行偏好优化。
- 奖励模型采用 GPT-o3（针对生成）和 GPT-4.1（针对编辑）。
- 反直觉发现：作者发现，对文本到图像（T2I）或图像编辑进行 RL 优化，不仅提升了目标任务，还带来了显著的跨任务协同效应。例如，仅做 T2I RL 就能提升编辑基准 GEdit-Bench 的分数。

## 工程启示- 简化推理链路：ARM 证明了自回归模型可以大幅降低对 Classifier-Free Guidance (CFG) 的依赖。实验显示，关闭 CFG 后图像依然保持语义连贯，这意味着推理时可以减少一次前向传播，显著加速生成过程。
- 解码器即渲染器：作者对比了 SANA1.5 和 FLUX.1 作为解码器，发现视觉 Token 已经编码了大部分布局和高阶语义，Diffusion 解码器主要承担“渲染”角色。这暗示我们可以用更轻量的解码器来换取更高的吞吐量，只要 Token 质量够高。
- RL 的通用性：在离散 Token 空间进行 RL 优化是可行的，且能带来跨任务的正向迁移。对于希望统一多模态能力的团队，优先优化共享的视觉表征空间比单独微调各个子模块更高效。
## 局限与展望尽管 ARM 表现优异，但其依赖强大的 Diffusion 解码器（如 FLUX.1）来保证最终像素质量，这在一定程度上继承了扩散模型的慢速生成特性。此外，RL 阶段依赖 GPT 系列作为奖励模型，增加了计算成本和外部依赖。未来如何进一步压缩解码器体积，或探索无需外部大模型奖励的自监督对齐方法，将是工程落地的关键方向。
