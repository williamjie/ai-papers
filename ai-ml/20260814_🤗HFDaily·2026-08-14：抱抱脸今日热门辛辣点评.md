## 模型 Top 5### 1. meta-models/Muse-Glimmer-30BMeta 的 Muse-Glimmer，30B 参数，Apache-2.0 开源，点赞 1419 下载 12 万，热度第一。名字挺文艺，但仔细一看 tags：两个 arxiv 编号，一个 2504 一个 2602 —— 合着是把两篇论文缝合到一个模型里？多模态路线不新鲜，30B 在视觉语言模型里也算不上大，能火纯粹靠 Meta 的招牌。建议 README 多写点 benchmark，别光放几个 demo GIF 就交差。
### 2. Qwen/Qwen3.8-2.4T-A95B通义千问的 MoE 版本，总参数 2.4T，激活 95B，数字游戏玩得比 DeepSeek 还花哨。但下载量只有 1012，点赞 783，比例严重失调——说明要么刚发布门槛高（比如需要申请），要么大家被“2.4T”吓退了。更关键的是 license 写的是 other ，大概率又是个“学术研究可免费，商用请谈”的套路。开源精神呢？学学隔壁 Apache-2.0 不好吗？
### 3. Lightricks/LTX-2.5Lightricks 的 LTX-2.5，一个模型塞了 image-to-video、text-to-video、video-to-video、audio-to-video……标签多到像在刷关键词。下载 5.7 万，热度 623，中规中矩。功能全面是好事，但样样通往往样样松。对比专门的视频生成模型（比如 Sora 或 CogVideo），LTX-2.5 的输出质量有没有竞争力？我看 README 里一个对比表格都没有，全靠用户自己试。
### 4. lightx2v/Minimax-h3-TurboMinimax H3 的 Turbo 版，下载量 9.1 万，点赞却只有 462，说明下载多但用户懒得点赞——可能是被批量脚本刷了，也可能是模型本身没亮点。Turbo 后缀暗示推理加速，但 base_model 还是 MiniMax-H3，本质是微调优化而非全新架构。tag 里的 r2v （reference to video）倒是挺有意思，但 README 里只字不提实现细节，差评。
### 5. unsloth/Muse-Glimmer-30B-GGUF原版下载 12 万，量化版下载 35 万——大家宁可损失精度也要跑得动。
Unsloth 的 GGUF 量化版本，35 万下载量碾压原版，说明社区的真实需求：别跟我谈 30B 参数多牛，我只关心我的 8GB 显存能不能跑。Unsloth 的优化确实给力，但量化后的精度损失有多大？README 里只给了 perplexity 对比，没给下游任务评测，建议补上。
