# 用双曲几何重构3D场景图

**日期**: 2026-04-22

---

论文 : HSG: Hyperbolic Scene Graph链接 : https://arxiv.org/abs/2604.17454做 3D 视觉或具身智能（Embodied AI）的同学都知道，场景图（Scene Graph）是连接“看见”和“理解”的桥梁。但大多数方法只关注物体之间的共现关系，忽略了场景本身固有的层级结构——比如“客厅”必然蕴含“沙发”、“桌子”等对象。
北大团队最新提出的 HSG (Hyperbolic Scene Graph) 直接指出了现有欧氏（Euclidean）方法的死穴：欧氏空间无法高效编码这种层级蕴含关系。他们的解法很硬核——把整个场景图嵌入到双曲空间（Hyperbolic Space）里。
结果？图级别的指标（Graph IoU）比最强基线提升了 8.14% 。
## 为什么欧氏空间不够用？
现有主流方案（如 MSG、AoMSG）都在欧氏空间里做对比学习。问题在于，现实世界的场景是树状层级结构：Place（场景）是父节点，Object（物体）是子节点。
欧氏空间的体积增长是多项式级别的，要表达指数级增长的层级结构，要么维度高到爆炸，要么结构关系就会崩塌。简单说， 在欧氏空间里，你很难让“客厅”和“沙发”的距离，比“客厅”和“马桶”的距离更近，同时还能保持整个图的结构一致性。
双曲空间不一样。它的体积随半径指数增长，天然适合做层级建模。离原点越远，能容纳的节点越多。这就像一棵树，根部紧凑，枝叶发散，完美匹配 Place-Object 的蕴含关系。
## 方法拆解：HSG 到底做了什么？
HSG 的架构并没有大改，它是在 AoMSG 的基础上做了三个关键替换：
### 1. 从欧氏到双曲的映射HSG 使用 Lorentz 模型 作为双曲空间的实现。核心操作是把解码器输出的欧氏向量 vdecv_{dec} ​ 通过指数映射（Exponential Map）投射到双曲流形上。

### 3. 蕴含损失（Entailment Loss）
这是 HSG 最聪明的设计。它引入了 双曲蕴含锥（Hyperbolic Entailment Cones） 来显式建模 Place-Object 的层级关系。
每个 Place 定义一个锥形区域，合法的 Object 必须落在锥内。锥的半角 ω\omega 由 Place 的抽象程度决定：越抽象的 Place（离原点越近），锥越宽；越具体的 Place，锥越窄。

## 关键结果在 ARKitScenes 数据集上的实验结果很能说明问题：
Metric SepMSG-Linear AoMSG-4 (best Euclidean) HSG (Ours) Recall@1 97.30 98.33 98.39 PP IoU 20.02 21.02 33.17 PO IoU 55.67 42.79 45.52 Graph IoU 20.48 21.32 33.51几个观察：
- PP IoU 和 Graph IoU 是 HSG 的主场。相比最强欧氏基线 AoMSG-4，Graph IoU 从 21.32 提升到 33.51，增幅达 +8.14%。这直接证明了双曲几何在建模层级结构上的优势。
- Recall@1 保持竞争力。98.39% 的检索召回率，仅次于 AoMSG-B-4（98.61%），说明双曲嵌入没有牺牲检索精度。
- PO IoU 不是 HSG 的最强项。SepMSG-Linear 在 PO IoU 上达到 55.67，高于 HSG 的 45.52。论文承认，PO IoU 更依赖物体级关联和检测质量，而非全局层级结构。
## 工程启示### 曲率初始化是关键超参HSG 的曲率 cc 是可学习参数，初始值设为 80.0 。实验显示：
- c≤20c \leq 2020：图指标崩溃，几何退化为欧氏，失去层级表达能力。
- 30≤c≤25030 \leq c \leq 250c≤250：性能稳定，c=80c=8080 时达到峰值。
- c≥300c \geq 300300：数值不稳定，嵌入集中在双曲流形边界，梯度消失。
这提醒我们：用双曲空间不是随便设个曲率就行， 曲率决定了层级容量和训练稳定性的平衡点 。

- 固定 c=1：PP IoU 暴跌至 15.5，蕴含损失坍缩为零，层级约束失效。
- 换成欧氏 InfoNCE：图指标大幅下降，即使 Recall@1 仍然很高。说明欧氏对比学习能学到实例区分，但学不到层级结构。
### 投影维度敏感性HSG 在投影维度 1024 时表现最佳。512 欠拟合，2048 反而下降（PP IoU 降至 29.5）。欧氏基线在不同维度下变化不大。这意味着 双曲投影质量对容量更敏感 ，不能盲目缩小维度。
## 局限与展望论文也坦诚了几个边界：
- 曲率优化仍有改进空间。当前是单值曲率，未来可以尝试自适应或多阶段曲率优化，适配非均匀的几何结构。
- 性能强依赖编码器质量。DINOv2-Base 表现最好，但 DINOv2-Small 虽然 Recall@1 高，图指标却很差。说明检索精度不等于结构质量。
- PO IoU 仍有提升空间。双曲几何在 Place-Object 层级上优势明显，但在细粒度物体关联上，仍需更好的检测器和多视图融合策略。
## 总结HSG 的核心贡献不是提出了一个新架构，而是 换了几何 。它证明了在场景图建模中，几何选择比模型复杂度更重要。当你的数据天然具有层级结构时，双曲空间不是可选项，而是必选项。
对于做 3D 理解、空间推理、或任何涉及层级语义建模的任务，值得认真考虑双曲嵌入。毕竟， 有时候问题不在模型不够深，而在空间不够“弯”。
