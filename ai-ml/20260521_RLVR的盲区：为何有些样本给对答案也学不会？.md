# ⭐⭐⭐½ RLVR的盲区：为何有些样本给对答案也学不会？

**日期**: 2026-05-21

---

论文 : The Unlearnability Phenomenon in RLVR for Language Models链接 : https://arxiv.org/abs/2605.16787在基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Reward, RLVR）中，我们常有一个直觉假设：只要模型在采样中碰巧生成了正确答案，强化学习算法就能通过梯度更新“记住”这个解法。然而，这篇论文揭示了一个反直觉的现象： 对于一部分困难样本，即使训练过程中不断出现正确 rollout，模型依然无法学会。 这种现象被称为“不可学习性”（Unlearnability），它直接挑战了当前 RLVR 优化的核心假设，也为工程落地中的瓶颈提供了新的解释视角。
### 痛点：正奖励信号失效的“黑盒”
目前主流的大模型推理能力提升方案多采用 GRPO（Group Relative Policy Optimization）。其核心逻辑依赖于组内奖励方差：即同一 prompt 下既有正确也有错误回答，从而形成梯度信号。
但在实际训练中，作者发现困难样本（Hard Examples）并非都能被攻克。他们将样本分为三类：
- Easy：初始成功率 ≥\ge 10%，迅速收敛。
- Learnable：初始难，但随训练稳步提升。
- Unlearnable：初始难，且在整个训练过程中，即便观察到正奖励，性能也几乎无提升。
这就引出了核心问题： 为什么有了正确的反馈，模型还是学不会？ 是优化器的问题？还是数据的问题？
### 方法拆解：从优化器到表示层的深度归因为了找到根源，作者采取了一种“排除法 + 梯度分析”的策略，层层剥开不可学习性的本质。
1. 排除优化器层面的“锅”
首先，作者测试了常见的优化假设：
- 正样本稀缺？ 通过 Experience Replay 强制增加正确 rollout 的比例（保证每个 batch 都有固定数量的正样本）。结果：Learnable 样本的学习速度变慢（因为负样本减少导致梯度方向单一），但 Unlearnable 样本依然学不会。
- 梯度被裁剪或 KL 惩罚抑制？ 尝试移除 KL 损失或使用更高的 Clipping 阈值。结果：Unlearnable 样本的表现没有任何改善，梯度分布也没有显著变化。
这些负结果强烈暗示： 问题不在 RL 算法的超参数或正则化机制上，而在模型对数据的“理解”层面。
2. 核心 Insight：梯度离群与表示缺陷作者引入了跨样本梯度相似度（Cross-example Gradient Similarity）分析。他们计算了不同样本在正确 rollout 下的梯度向量与整体训练集梯度的余弦相似度。
- 现象：Unlearnable 样本的梯度与其他样本的相似度极低（Figure 1c）。这意味着，模型在处理这些样本时，其参数更新方向与主流知识体系是“割裂”的。
- 本质：这反映了模型内部表示（Representation）的缺陷。对于这些样本，模型缺乏通用的推理模式，只能依赖某种不可泛化的“捷径”或启发式规则来碰对答案。
3. 验证：推理质量的崩塌为了佐证“表示缺陷”，作者使用 GPT-5-mini 对正确回答的推理过程进行评分。
- 结果：Unlearnable 样本的推理质量显著低于 Learnable 和 Easy 样本（Figure 1d）。
- 案例：模型可能在中间步骤出现严重逻辑错误，甚至自相矛盾，仅靠最后一步“蒙对”答案。这种“虚假推理”导致梯度信号充满噪声，无法形成有效的技能迁移。
4. 补救尝试与 Mid-training 的价值既然 RL 阶段修不好，能不能通过数据增强（Data Augmentation）来修复？作者尝试生成相似问题和子问题，但发现：
- 语义相似的样本，在梯度空间中依然距离遥远。
- 数据增强无法提高 Unlearnable 样本的梯度相似度。
相反， Mid-training（中期训练） 被证明是有效的。经过 Mid-training 的模型（如 OctoThinker），其困难样本的梯度相似度显著提升。这说明， 修复表示缺陷必须在 RL 之前完成，RL 阶段只能强化已有的表示，无法重构错误的表示。

- 重视 Mid-training 阶段：论文明确指出，Mid-training 能有效提高困难样本的梯度相似度。在构建推理模型流水线时，应在 RL 之前投入资源进行高质量的 SFT 或 Mid-training，确保模型具备正确的“推理骨架”。
- 警惕“虚假正确”：在评估模型能力时，不能只看 Pass@1 或最终答案。对于 Unlearnable 样本，模型可能只是“运气好”。引入过程奖励（Process Reward）或推理质量评估，有助于识别这些高风险样本。
- 数据筛选的新维度：除了难度，还可以考虑“梯度相似度”作为数据筛选指标。那些在梯度空间中过于离群的样本，可能在 RL 阶段性价比极低，应优先通过 SFT 修复或剔除。
### 局限与展望目前研究主要基于数学推理任务（MATH）和小规模模型（0.5B-3B）。未来需要验证这一现象是否在代码生成、Agent 规划等更复杂的任务中普遍存在。此外，如何自动化地识别并修复这些“表示缺陷”，仍是开放的研究方向。
