# Muon微调Adam预训练模型？

**日期**: 2026-05-13

---

论文 : Can Muon Fine-tune Models Pretrained with Adam?
链接 : https://arxiv.org/abs/2605.10468大模型训练圈最近有个热门话题：Muon 优化器在预训练阶段表现优异，效率甚至能比肩 Adam，但到了微调（Fine-tuning）阶段却频频翻车。如果你手头有个用 Adam 预训练好的开源模型（比如 Llama 系列），直接换 Muon 去微调，结果往往不如预期。这篇论文不整虚的，直接深挖这个“优化器失配（Optimizer Mismatch）”现象，并给出了一个非常落地的解决方案。
## 痛点：为什么换了优化器就变笨？
大多数开源模型都是 Adam 预训练的。工程师们发现，如果用 Muon 去微调 Adam 预训练的模型，或者反过来，性能都会下降。这就是论文核心关注的“优化器失配”。
直觉上，大家可能觉得优化器只是更新权重的工具，换汤不换药。但论文通过控制实验证明，Adam 和 Muon 有着截然不同的 隐式偏差（Implicit Bias） ：
- Adam：基于元素级的自适应学习率，它倾向于收敛到具有最大 max-norm margin 的解。简单说，它让权重矩阵的元素分布更分散。
- Muon：通过牛顿-舒尔茨迭代（Newton-Schulz iteration）对动量矩阵进行正交化，它倾向于收敛到具有最大 spectral-norm margin 的解。这意味着它让权重矩阵的奇异值分布更均匀。
这种结构上的根本差异，导致预训练出来的权重“骨架”不同。当你用不匹配的优化器去微调时，实际上是在用错误的“工具”去修改原本由另一种“结构”支撑的知识，从而破坏了预训练学到的知识。实验显示，失配会导致模型对更新强度（Update Strength）更敏感，更强的更新意味着更严重的知识破坏。
## 解法：用 LoRA 限制更新幅度既然失配是因为更新幅度太大、破坏了原有结构，那能不能限制更新？论文提出了一个极其巧妙的假设： 通过 LoRA（Low-Rank Adaptation）约束更新范围，可以缓解失配。
LoRA 冻结预训练权重，只训练低秩矩阵。这天然地限制了权重变化的空间。论文的理论推导和实验都证实，当秩（Rank）较低时，LoRA-Muon 能显著缩小与 LoRA-Adam 的性能差距。

可以看到，在全量微调（Full Fine-tuning）中，失配导致的性能损失明显（如 Adam 预训练模型用 Muon 微调，PPL 从 0.710 升至 0.719）。但在 LoRA 设置下，LoRA-Muon 的表现几乎追平了 LoRA-Adam，甚至在某些任务上略胜一筹。
在更复杂的 GLUE 基准 （T5-Base）和 Llama 2-7B 指令微调任务中，结论一致：
- NLU 任务：全量微调时 Muon 仍略逊于 Adam，但 LoRA-Muon 平均准确率 88.97%，略高于 LoRA-Adam 的 88.93%，甚至超过了 Full-Adam 的 89.14（注意：这里 LoRA-Muon-PE 达到了 89.20，超越了 Full-Adam）。
- 生成任务：在代码生成（HumanEval）和常识推理上，LoRA-Muon 匹配或超越了 LoRA-Adam。
- 视觉任务：在 CLIP ViT-B/32 的微调中，LoRA-Muon 同样表现出对失配的鲁棒性。
## 工程启示对于正在使用或考虑迁移到 Muon 的工程师，这篇论文给出了几个明确的操作建议：
- 微调首选 LoRA：如果你必须用 Muon 微调现有的 Adam 预训练模型，请务必使用 LoRA。全量微调的失配风险太高。
- 控制 LoRA Rank：实验显示，低秩（如 r=8, 16）时 Muon 的优势最明显。当 Rank 过高（如 >64）时，LoRA 的行为趋近于全量微调，失配效应重新显现，性能反而下降。
- 不要盲目套用 LoRA 变体：论文测试了 rsLoRA、PiSSA 等改进版 LoRA，发现它们对 Adam 有效，但对 Muon 未必。例如，rsLoRA 增加了有效缩放因子，反而放大了更新幅度，加剧了 Muon 的失配问题。
- 计算成本可控：在 LoRA 设置下，Muon 相比 Adam 仅带来 1.1-1.2 倍的时间开销，但省去了二阶矩缓存，内存占用减少约 50%，这在显存受限场景下极具吸引力。
## 局限与展望论文也承认，目前对失配的理论解释仍停留在经验层面，缺乏严格的数学表征。此外，实验主要集中在 7B 以下模型，更大规模的模型表现仍需验证。未来可能需要专门的初始化策略或热身（Warmup）机制来进一步弥合两种优化器的结构差异。
总的来说，这篇论文不仅解释了“为什么不行”，还给出了“怎么行”的具体路径。对于追求极致训练效率的团队，LoRA-Muon 是一个值得尝试的组合。
