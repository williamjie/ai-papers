论文 : AVTok: 1D Unified Tokenization for Holistic Audio-Video Generation链接 : https://arxiv.org/abs/2606.30811多模态生成模型正面临一个尴尬的工程瓶颈：音频和视频往往被塞进两个独立的分支处理。这种“双轨制”不仅计算资源翻倍，更致命的是造成了语义层面的割裂——生成的画面和声音经常对不上拍。AVTok 这篇论文提出了一种激进的解法：用一套统一的 1D Tokenizer 把音视频压缩进同一个离散潜空间。这不仅是架构的简化，更是为构建真正通用的多模态大模型扫清了障碍。
### 为什么现有方案行不通？
目前的音视频生成主流做法是“各管一段”。视频用 VAE 或 DiT 处理空间信息，音频用 Codec 处理波形。
这种做法有两个核心痛点：
- 表征鸿沟：视觉通常是 3D 时空数据，而音频本质是 1D 时间序列。强行拼接两个不同维度、不同语义空间的 Embedding，会导致模型难以捕捉跨模态的细粒度同步信号。
- 算力冗余：维护两套独立的 Tokenizer 和生成器，参数量爆炸，训练成本极高。
AVTok 的核心 Insight 非常直接： 既然 LLM 时代证明了 1D 离散 Token 是通用的“语言”，那为什么不把视频也强行拉平到 1D，和音频共用一个 Codebook？
### 方法拆解：双流架构与渐进式训练AVTok 并没有简单地把音视频数据拼在一起喂给 Transformer，而是设计了一套巧妙的 双流查询机制（Dual-Stream Query-based Architecture） 。
- 统一潜空间：视频输入被 Patchify 后，通过一组可学习的“全局查询向量”（Holistic Queries）编码为 1D 离散 Token。音频则转换为 Mel-spectrogram，同样被视为图像进行 Patchify 和编码。最终，两者共享同一个量化器（Quantizer）和解码器参数。
- 模态特异性保留：为了防止视频的高信息密度“淹没”音频信号，AVTok 为每种模态保留了独立的归一化层（Normalization Layers）和查询向量。这是一种“参数共享，特征隔离”的设计，既保证了跨模态隐式融合，又避免了梯度冲突。
⚠️ 关键训练技巧：VFAL 策略直接端到端训练会导致模型偏向视频模态。作者提出了 Video-First-Audio-Later (VFAL) 分层训练策略：
- 第一阶段：只训练视频流，建立强大的视觉潜空间基础。
- 第二阶段：冻结视频部分，仅训练音频流，让模型学习如何在这个已有的空间里“听懂”声音。
- 第三阶段：联合微调解码器，实现真正的音视频协同重建。
此外，为了强化语义对齐，作者引入了预训练的音视频基础模型（如 Cav-MAE）作为教师模型，通过表示对齐损失（Representation Alignment Loss）强制 AVTok 的中间特征与强语义空间保持一致。
### 关键结果：效率与质量的双赢AVTok 在重建质量和下游生成任务上都展现了惊人的竞争力，尤其是考虑到它极其精简的参数规模。

### 工程启示与局限对于工程师而言，AVTok 的价值在于它提供了一条 低门槛的多模态生成路径 。
- 架构简化：你不再需要维护两套复杂的 Diffusion 或 Codec 管线。一个统一的 Tokenizer 意味着更简单的数据管道和推理逻辑。
- 自回归友好：通过将音视频统一为 1D 离散序列，AVTok 天然适配 LLM 式的自回归生成模型。这意味着你可以直接用训练好的语言模型架构来做音视频联合生成，无需重新发明轮子。
- 微调潜力：由于引入了表示对齐损失，该模型在少量数据下的跨模态泛化能力可能更强，适合垂直领域的微调。
当然，目前的方法仍有局限。音频重建主要依赖 Mel-spectrogram，虽然通过 HiFi-GAN 可以还原波形，但在极端高频细节上可能不如原生波形 Codec。此外，VFAL 训练策略增加了训练的复杂性，对于资源有限的团队来说，调试三个阶段的比例和损失权重需要一定的经验。
总的来说，AVTok 证明了“统一表征”不仅是理论上的优雅，更是工程上的可行解。随着多模态大模型向更通用的方向演进，这种 1D 统一的 Tokenization 思路很可能成为未来的标准范式。
