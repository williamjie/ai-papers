# ⭐⭐⭐½ 表格基础模型真的通用吗？BeyondArena 基准测试深度解析

论文 : Beyond IID: How General Are Tabular Foundation Models, Really?
链接 : https://arxiv.org/abs/2606.30410最近表格基础模型（Tabular Foundation Models, TFMs）在学术界和工业界火得一塌糊涂。但大家发现一个尴尬现象：TFM 们在标准基准上刷分很猛，一到真实业务场景就拉胯。这篇论文直接掀了桌子，指出之前的评测大多局限于独立同分布（IID）数据，完全忽略了非 IID、大规模和高维度的真实挑战。作者构建了 BeyondArena，这是首个统一涵盖 IID、时间序列和分组数据的 holistic 基准，彻底检验 TFM 的“通用性”成色。
### 痛点：为什么现有评测骗了所有人？
现有的表格机器学习评测存在严重的“幸存者偏差”。大多数基准（如 TabArena）只关注 IID 任务，即训练集和测试集来自同一分布，随机划分即可。
但在真实工程中，数据往往是非 IID 的：
- 时间序列（Temporal）：预测未来交易是否欺诈，测试集必须在训练集之后，防止时间泄露。
- 分组数据（Grouped）：预测新客户群体行为，测试集中的“客户组”在训练中从未出现过。
如果非要用随机划分去测时间数据，模型会利用时间相关性作弊，导致性能虚高。之前的研究缺乏统一的工具链，导致 TFM 研究者只能在自己擅长的 IID 小数据集上卷精度，而忽略了更严峻的泛化挑战。
### 方法拆解：BeyondArena 的设计直觉BeyondArena 的核心创新不在于提出新模型，而在于 重新定义评测协议 。其设计直觉非常硬核：
-严格的数据策展（DataFoundry）：
作者从 1128 个候选数据集中手动筛选出 142 个高质量数据集。这不仅仅是下载 CSV，而是通过 DataFoundry 框架统一元数据、预处理和划分协议。例如，对于分组数据，强制要求测试集中的组 ID 在训练中完全不可见。
-多样化的任务类型：
基准覆盖了三种任务类型：
IID (103个)：随机划分。
- Temporal (21个)：基于时间索引划分，模拟未来预测。
- Grouped (18个)：基于组索引划分，模拟新实体泛化。
-公平的对比基线：
对比了 11 种模型，包括传统树模型（XGBoost, CatBoost）、深度学习 MLP（RealMLP, TabM）以及三大 TFM（TabPFN-2.6, TabDPT, TabICLv2）。关键在于，传统模型允许调参和集成（Tuned + Ensembled），而 TFM 仅评估其上下文学习（In-Context Learning, ICL）能力，不进行微调。这模拟了开发者直接使用预训练模型的现实场景。
### 关键结果：TFM 的“通吃”神话破灭了？
实验结果非常直观，甚至有点残酷。以下是基于 Elo 评分（1000 为默认 XGBoost 水平）的核心发现：
子基准类型 最佳模型家族 TFM 表现 备注 IID (全部) TFM 领先 在小到中等规模 IID 数据上，TFM 确实强大 Tiny (<1k) TFM 显著领先 TabICLv2 和 TabPFN-2.6 统治级表现 Large (>100k) GBDT / MLP 落后 TFM 无法处理大规模数据，推理成本过高且精度低 Temporal GBDT / MLP 落后 传统树模型在时间序列任务上更稳健 Grouped GBDT / MLP 落后 分组泛化能力弱，易过拟合组 ID High Card. GBDT 落后 高基数类别特征处理不如 CatBoost 等专用模型⚠️ 反直觉发现 ：在 142 个数据集中，TFM 仅在 70% 的数据集上能达到“峰值性能”（Rank 1）。但在 Grouped、Temporal 和 Large 这三个最具挑战性的子基准中，TFM 达到 Rank 1 的比例极低。传统经过调优的树模型和 MLP 在这些场景下依然占据主导。
具体来看，TabICLv2 在 19% 的数据集上排名第一，TabPFN-2.6 占 10.5%。但在非 IID 任务中，它们的 Elo 评分显著低于调优后的 XGBoost 或 LightGBM。这说明 TFM 目前更像是一个“小数据专家”，而非真正的通用基础模型。
### 工程启示：实际项目中该怎么选？
这篇论文对工程师的选型策略有直接指导意义：
- 小数据 IID 场景：如果你只有几百到几千条样本，且数据分布稳定，直接使用 TabPFN-2.6 或 TabICLv2。它们的 ICL 能力无需调参即可达到 SOTA，节省大量开发时间。
- 大规模/非 IID 场景：如果数据量超过 10 万，或者涉及时间序列、新用户群体预测，请回归传统树模型（CatBoost/XGBoost）或 MLP。不要迷信 TFM 的泛化能力，它们在大规模数据上的推理成本极高（如 TabDPT 需要数百万次前向传播），且精度反而下降。
- 预处理至关重要：论文消融实验显示，对于分组数据，正确的预处理（如丢弃组 ID 列或进行组编码）能显著影响模型排名。对于文本特征，使用 Qwen3-Embedding 等现代编码器比传统 TF-IDF 更有效，但在长文本上差异不大。
### 局限与展望BeyondArena 也有其边界：
- 未评估微调：目前仅测试 TFM 的 ICL 能力，未探索监督微调（SFT）是否能在非 IID 任务上弥补差距。
- 计算预算限制：传统模型仅进行了 25 次随机搜索调参，可能未完全发挥其潜力。
- 数据覆盖：虽然涵盖了 142 个数据集，但在特定垂直领域（如医疗生存分析）仍显不足。
总的来说，TFM 还没有“统一天下”。在可预见的未来，传统树模型与 TFM 将长期共存：TFM 负责小数据快速原型验证，树模型负责大规模生产环境的核心推理。
