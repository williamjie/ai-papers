# ⭐⭐⭐½ LLM 的随机性幻觉：为何它们无法模拟真实世界？

**日期**: 2026-06-09

---

论文 : UnpredictaBench: A Benchmark for Evaluating Distributional Randomness in LLMs链接 : https://arxiv.org/abs/2606.06622当我们把 LLM 当作“数字人类”放入经济仿真或流行病学模型时，我们默认它们能像真人一样做出不可预测的随机决策。但新论文 UnpredictaBench 揭示了一个残酷事实： 大多数顶级模型根本不懂什么是真正的随机分布。 它们只是在重复几个看似合理的值，这种“确定性幻觉”会让基于 LLM 的系统模拟彻底失效。
### 为什么“多样性”不等于“随机性”？
过去大家觉得 LLM 输出太单一，就调高 Temperature 或加 Prompt 要求“多样化”。但这治标不治本。仿真需要的不是杂乱无章的多样性，而是**校准到目标分布（Calibrated to Target Distribution）**的样本。
比如掷骰子，你不能只因为结果不全是 6 就说它随机。如果模型生成的数字集中在 1-3，虽然多样，但完全偏离了均匀分布。UnpredictaBench 的核心洞察在于： 评估 LLM 的随机能力，不能看单次回答，必须看大量样本的统计分布是否拟合真实世界。
### UnpredictaBench：用统计学“照妖镜”测试 LLM作者构建了一个包含 448 个问题的基准测试，涵盖经典统计分布、随机代码执行、列表洗牌以及现实世界的并发场景（如竞态条件）。
为了量化模型表现，他们提出了一个新指标 KS@N 。
- 原理：使用 Kolmogorov-Smirnov (KS) 检验，比较模型生成的 NN 个样本与真实分布的 10,00010,000 个参考样本。
- 定义：KS@N 是模型样本未被拒绝（即无法区分于真实分布）的问题比例。
- 直觉：NN 越大，统计检验越敏感，难度越高。如果模型只是运气好猜中几个点，在 N=100N=100100 时就会原形毕露。
### 结果炸裂：没有模型能及格在标准的 KS@100 测试下， 没有任何模型得分超过 40% 。这意味着即使是最强的模型，生成的 100 个样本中，也有超过 60% 的情况被统计学判定为“不符合目标分布”。
具体表现分层明显：
- 领头羊：Nemotron-3-super-120B 以 32.64% 的得分勉强领先，但这依然意味着近七成的任务失败。
- 主流旗舰：GPT-4o (23.90%) 和 DeepSeek-V3.2 (21.73%) 紧随其后。
- 意外掉队者：Claude Sonnet 4.6 仅得 4.70%，GPT-5.4 得 15.18%。有趣的是，小模型 Qwen-3.5-2B (17.67%) 竟然吊打了许多百亿参数的大模型。
⚠️ 反直觉发现 ：Claude Sonnet 4.6 在 KS@2（仅生成 2 个样本）时得分高达 97.73%，但在 KS@100 时暴跌至 5.04%。这说明它能生成“看起来合理”的单次答案，但完全缺乏维持长期分布一致性的能力。
### 推理（Reasoning）能救场吗？
作者测试了开启深度推理（Chain-of-Thought）的效果。结果喜忧参半：
- 表面繁荣：对于 Nemotron 和 DeepSeek，最终输出的 KS@20 略有提升。
- 思维陷阱：当提取模型在“推理过程”中产生的数字时，Nemotron 的得分反而暴跌 -33.17%。这说明模型在思考时陷入了局部最优，反复纠结于几个候选值，而非探索整个分布空间。
- 隐藏知识：Qwen-3.5-35B-a3b 的最终输出几乎零改进，但其推理 token 中蕴含的多样性极高（KS@20 提升 +35.18%）。结论是：模型知道该怎么做，但它的“说话”机制抑制了随机性。
### 工程启示：别把 LLM 当随机数发生器这篇论文给工程师敲响了警钟：
- 仿真慎用原生 LLM：如果你在做 Agent 仿真、A/B 测试生成或蒙特卡洛模拟，直接让 LLM “生成一个随机值”是不可靠的。它的输出往往坍缩到均值附近，导致方差低估。
- MoE 架构的副作用：作者推测 Claude 和 Mistral 等 MoE 模型表现较差，可能是因为专家路由（Expert Routing）倾向于激活固定的稀疏子集，限制了计算路径的多样性。
- 正确姿势：需要随机性时，请使用传统 PRNG（伪随机数生成器），然后让 LLM 基于随机种子进行逻辑推理，而不是让 LLM 直接输出随机结果。
### 局限与展望UnpredictaBench 目前主要关注单变量分布。现实中的系统往往是多维耦合的（如多变量高斯、马尔可夫链）。此外，指令微调（Instruction Tuning）被证实往往会 降低 模型的输出多样性，这在追求保真度仿真的场景下是一个负面信号。
未来，我们需要更复杂的基准来测试 LLM 在动态环境中的随机决策能力。在此之前，请对任何声称能“模拟人类行为”的 LLM 保持怀疑——它们可能只是穿着随机外衣的决定论机器。
