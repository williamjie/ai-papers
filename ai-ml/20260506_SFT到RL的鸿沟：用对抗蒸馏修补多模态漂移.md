# SFT到RL的鸿沟：用对抗蒸馏修补多模态漂移

**日期**: 2026-05-06

---

在大型多模态模型（LMMs）的后训练（Post-training）流程中，工程师们似乎达成了一种默契：先做监督微调（Supervised Fine-Tuning, SFT）打底，再做可验证奖励的强化学习（RLVR）拔高。但这篇来自港科大（广州）和清华大学团队的论文指出，这个“标准配方”里藏着一个被忽视的坑： SFT 会引入分布漂移（Distributional Drift），而直接进 RLVR 往往修不好这个坑。
论文提出了 PRISM 框架，在 SFT 和 RLVR 之间插入一个显式的“预对齐”阶段。通过黑盒对抗式在线蒸馏（On-Policy Distillation, OPD），用混合专家（MoE）判别器分别纠正视觉感知和逻辑推理的漂移。实验显示，在 Qwen3-VL-8B 上，这种方法比传统 SFT→RL 基线平均提升 +6.0 个百分点。
## 痛点：SFT 不仅是“打底”，还是“污染源”
大家可能觉得 SFT 是把模型往高质量数据上拉，这没错。但论文敏锐地指出，SFT 优化的是 token 级别的模仿，它并不区分“过程”和“结果”。
对于强基座模型（比如已经具备一定推理能力的 8B 模型），SFT 往往会带来两个负面效应：
- 能力丢失：模型偏离了原本良好的原生分布。
- 幻觉固化：在多模态场景下，视觉 grounding 的微小偏差会被 SFT 强化，进而导致后续推理前提错误，这种错误在 RL 阶段很难被纠正，因为 RL 主要优化最终答案的准确性，而不是推理过程的忠实度。
简单来说，SFT 后的模型处于一种“既不像老师，也不像自己”的尴尬状态。如果直接把这种状态扔给 RLVR，RL 的优化起点就是扭曲的，增益自然大打折扣。
## 方法拆解：PRISM 的核心 InsightPRISM 的核心思路很直接： 别急着做 RL，先花点时间把 SFT 搞歪的分布拉回来。
### 1. 为什么是“对抗式”而不是“模仿学习”？
传统的知识蒸馏需要知道 Teacher 的 logits，但在多模态领域，高质量的推理数据往往来自闭源模型（如 Gemini 3 Flash），拿不到 logits。PRISM 采用 Black-Box On-Policy Distillation ，即不需要老师模型的内部信息，只需要对比“模型生成的回答”和“参考答案”的质量。
### 2. MoE 判别器：解耦感知与推理多模态漂移是异构的：有时候是看图看错了（感知漂移），有时候是逻辑推错了（推理漂移）。用一个单一的判别器很难同时精准捕捉这两类错误。
PRISM 设计了一个 Mixture-of-Experts (MoE) Discriminator ，包含两个专门专家：
- Perception Expert (DvD_v​)：只看视觉描述部分，判断是否忠实于图像。
- Reasoning Expert (DrD_r​)：只看推理链条，判断逻辑是否自洽。
最终奖励是两者的加权组合：
r(x,y)=α⋅Dv(x,c)+(1−α)⋅Dr(x,t)r(x, y) = \alpha \cdot D_v(x, c) + (1 - \alpha) \cdot D_r(x, t) α ⋅ D v ​ ( x , c ) + ( 1 − α ) ⋅ D r ​ ( x , t )
这种设计的关键在于 Decoupled Feedback（解耦反馈） 。如果模型视觉变好了但逻辑变差了，单一判别器可能会给出混乱的信号，而 MoE 能让两个专家各自收敛，提供 sharper 的梯度。
### 3. 训练流程：Minimax Game对齐阶段是一个极小极大游戏：
- 判别器：通过 Bradley-Terry Loss 学习区分“参考答案”和“模型当前生成的回答（Rollouts）”。
- 策略模型：通过策略梯度最大化判别器给出的奖励。
注意，这里去掉了常见的 KL 正则项。因为我们的目标就是让模型 偏离 SFT 后的漂移分布，去匹配高质量的监督分布，所以不应该用 KL 把它绑在 SFT 参数附近。

更有趣的发现是：
- 对齐本身不直接提分：只看 Align 后的 checkpoint（未做 RL），准确率甚至可能比 SFT 略低或持平。因为对齐目标是分布匹配，而非答案正确。
- RL 收益爆发：一旦进入 RLVR 阶段，PRISM 初始化的模型表现出更强的收敛性和更高的上限。
- 强模型受益更大：8B 模型受 SFT 漂移影响更严重，传统 RLVR 很难找回分数，而 PRISM 成功修复了这一损失并大幅超越。
## 工程启示- SFT 数据量要足：消融实验显示，如果 SFT 数据太少（仅 107K 而非 1.37M），对齐阶段无法有效工作，因为初始分布差距太大，判别器会迅速饱和。SFT 负责“拉近”，对齐负责“校准”，两者互补。
- 判别器必须看图像：如果去掉视觉输入，只用文本判别器，模型会出现“鹦鹉学舌”——学会模仿推理的格式和语气，但视觉 grounding 依然错误。这对需要高精度视觉定位的任务（如 OCR、复杂几何）是致命的。
- 对齐阶段不可或缺：去掉对齐阶段直接退化为 SFT→RLVR，性能下降明显。对于追求极致性能的 Agent 或推理模型，建议在生产环境的训练管线中保留这一中间步。
## 局限与展望PRISM 需要额外构建一个 MoE 判别器，增加了训练复杂度和显存开销。虽然它不需要 Teacher 的 logits，但需要高质量的监督数据（论文使用了 113K 经过筛选的 Gemini 3 Flash 生成数据）。未来方向可能在于如何自动化生成这些高保真监督数据，或者进一步简化判别器的架构，使其更轻量化。
总的来说，PRISM 提醒我们： 在多模态强化学习之前，先检查一下模型的“脑子”是不是被 SFT 带偏了。
