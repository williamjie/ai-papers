# ⭐⭐⭐½ 一个模型搞定3D重建与空间推理

**日期**: 2026-08-17

论文 : SPARGen: Unifying Spatial Perception and Reasoning through Native Multimodal Generation链接 : https://arxiv.org/abs/2608.14138现在的多模态大模型（MLLM）有个尴尬的现状：懂语义的不懂几何，懂几何的不会聊天。
想搞 3D 重建？用 VGGT 或 DUSt3R。想做空间推理问答？用 SpatialVLM 或 GPT-4o。两者之间通常隔着专门的回归头或者外部几何编码器，导致知识无法互通。
SPARGen 提出了一种更“原生”的解法：把 3D 重建、稠密对应和空间推理，全部统一到一个指令条件生成框架里。
它不挂载任何外挂模块，而是直接复用多模态大模型底层的图像生成和自回归路径。这种设计不仅简化了架构，更重要的是让几何监督和语义监督在同一个表征空间里互相促进。
### 痛点：为什么现有方案不够好？
目前的“统一”方案大多还是拼凑出来的。
比如 G2 VLM 虽然结合了语言理解和几何预测，但它引入了专门的几何 Transformer 专家。这意味着模型内部存在两套并行的处理逻辑，知识迁移效率有限。
大多数 MLLM 缺乏对稠密几何（如深度图、光流）的直接监督，导致它们在回答“沙发左边是什么”这类需要精确空间关系的问题时，往往靠猜而不是靠算。
SPARGen 的核心洞察是： 空间智能本质上是一个从观测构建表征，并利用表征回答查询的过程。
既然都是生成任务，为什么不能把深度图、点云和光流也当成“图像”来生成？把相机位姿和文本答案当成“序列”来预测？
### 方法拆解：原生生成的两种路径SPARGen 基于 Bagel 的混合专家（MoT）架构，巧妙地利用了其原有的两条生成通路，分别处理不同类型的空间输出。
1. 稠密场作为图像对齐输出对于深度图、点图和光流这些像素级任务，SPARGen 不回归数值，而是将其编码为类图像的表示。
- 设计直觉：利用预训练 VAE 的潜在空间。模型通过 Rectified Flow（整流流）路径，在 VAE 潜空间中生成几何场。
- 具体操作：深度图被归一化为相对深度并复制三通道；点图共享全局坐标系和缩放比例以保持一致性；光流则经过符号平方根变换处理位移。
- 优势：这允许模型直接复用强大的图像生成先验，无需从头学习复杂的几何回归头。
2. 结构化输出作为序列生成对于相机位姿（四元数、偏移量）和空间问答文本，SPARGen 将其序列化为离散 Token。
- 设计直觉：利用自回归路径。数值被量化并映射到专用数字 Token，按固定顺序排列。
- 优势：保持了标准的大语言模型解码能力，同时引入了稀疏的几何监督信号。
关键细节 ：在推理光流时，SPARGen 引入了一个“预测-扭曲-再预测”的细化步骤。先预测初始光流，将第二帧对齐到第一帧，再预测残差光流。这一招显著提升了稠密对应的精度。
### 实验结果：全能且专精SPARGen 在视觉几何、光流估计和空间推理三个维度上都展现了极强的竞争力。以下是关键数据对比：
1. 空间推理（SOTA 级别）
在开源模型中，SPARGen-7B 的表现遥遥领先。
模型 MindCube Avg OmniSpatial Avg SPAR Avg Qwen2.5-VL-72B 41.71 52.03 36.84 G2 VLM-2B 28.48 42.62 31.27 SPARGen-7B 76.04 54.00 79.25它在 SPAR 基准测试中比最强竞争对手高出近 43 个百分点，特别是在中高难度问题上优势明显。即使面对参数量大得多的 Qwen2.5-VL-72B，SPARGen 依然完胜。
2. 视觉几何（媲美专用模型）
虽然 VGGT 等专用模型在部分重建指标上仍占优，但 SPARGen 作为统一模型，差距已经很小。
- 深度估计 (Sintel): AbsRel 0.235，优于 G2 VLM (0.257)，接近 VGGT (0.265)。
- 相机位姿 (CO3D v2): AUC@30 达到 74.32%，大幅领先 G2 VLM 的 56.85%。
3. 光流估计（零样本迁移）
在 KITTI 数据集上，SPARGen 实现了 EPE 4.09，优于 RAFT (5.03) 和 GMFlow (7.77)。这证明通过原生生成路径学习稠密对应是可行的。
### 工程启示与局限1. 监督信号的互补性消融实验揭示了一个反直觉的发现：移除几何监督会损害空间推理，移除光流监督会降低重建精度，而移除推理监督甚至会轻微改善光流性能（可能是容量竞争）。
这意味着： 几何、对应和语义任务之间存在正迁移效应。 在训练具身智能或 Agent 时，联合训练这些任务可能比单独微调更有效。
2. 架构简化的价值SPARGen 证明了不需要外挂几何编码器也能实现高精度感知。对于工程落地而言，这意味着更少的维护成本、更统一的推理管线，以及更容易的微调流程。
3. 局限性：VAE 的瓶颈论文明确指出，依赖冻结的 VAE 进行空间压缩，会导致几何边缘和高精度物理量的损失。VAE 是为自然图像设计的，对细微的深度变化可能不敏感。未来可能需要专门针对几何场优化的编码器。
### 总结SPARGen 展示了一条清晰的路径：通过原生多模态生成统一感知与推理。
它不再将几何视为需要特殊处理的“异类”，而是将其融入大模型的生成范式。对于希望构建具备强空间理解能力的 Agent 的工程师来说，这种“一个模型走天下”的思路极具参考价值。
