# ⭐⭐⭐½ RxBrain：让机器人学会“边想边看”的具身规划

**日期**: 2026-07-18

---

论文 : RxBrain: Embodied Cognition Foundation Model with Joint Language-Visual Reasoning and Imagination链接 : https://arxiv.org/abs/2607.14187现在的具身智能模型大多有个通病：要么只会用语言瞎指挥（VLM），要么只会预测下一帧画面（World Model）。腾讯机器人 X 团队发布的 RxBrain 试图打破这种割裂，它让模型在同一个序列里，既输出“下一步该做什么”的文字逻辑，又生成“做完后世界长什么样”的视觉想象。
这不仅仅是架构上的拼接，而是认知层面的耦合。对于工程师来说，这意味着我们可能不再需要单独训练一个视觉预测头和一个决策大脑，而是用一个统一的基础模型搞定规划闭环。
### 为什么现有方案不够用？
在复杂任务中，纯文本推理缺乏空间细节，纯视觉预测缺乏因果逻辑。
- VLM 的局限：擅长任务分解和约束满足，但无法显式表达目标物理状态。比如“把杯子放稳”，VLM 知道要放，但不知道“稳”在视觉上是什么样子。
- World Model 的短板：擅长预测未来观测，但缺乏抽象的任务理解和因果推理能力。
RxBrain 的核心洞察是： 语言提供计划的抽象结构（分解、约束、时序），视觉想象负责 grounding（落地） 。两者互补，共同构成一个可执行的具身计划。
### 方法拆解：MoT 架构与联合生成RxBrain 基于 HY-Embodied-0.5，采用了一种模态感知的混合 Transformer（Mixture-of-Transformers, MoT）架构。
1. 视觉通路的巧妙复用模型没有为生成和理解分别建立独立的视觉塔。相反，它让视觉理解 Token 和视觉生成 Token 共享注意力投影层（QKV） ，但通过路由机制进入不同的前馈网络（FFN）。
- 理解 FFN：处理输入图像的特征提取。
- 生成 FFN：维度扩大至 12,288，专门负责在 VAE 潜空间中进行流匹配（Flow Matching）生成。
这种设计减少了参数量冗余，同时强制感知和想象在同一个语义空间中对齐。
2. 交错生成（Interleave Generation）
这是 RxBrain 最核心的创新点。模型不是先输出一堆文字再画图，而是采用自回归的交错模式：
<assistant> r1 <Image> z1 </Image> r2 <Image> z2 </Image> ...
- r_i 是第 i 步的文字推理（如：“拿起眼镜”）。
- <Image> 是一个可学习的模态转换 Token。
- z_i 是生成的视觉潜变量，代表该步骤完成后的世界状态。
生成完一张图后，模型会立即将其重新编码为视觉输入，作为下一步推理的上下文。这种“边想边看”的机制，确保了每一步的文字决策都有对应的视觉结果支撑。
### 数据构造：自动化视频拆解联合规划数据极其稀缺，人工标注成本高昂。RxBrain 构建了一个全自动流水线，从 50,177 小时的多源视频中提取监督信号。
- 时间片段标注：利用 MLLM 采样关键帧，识别出具有清晰视觉状态变化的“原子规划步骤”。
- 质量验证：通过语义质量、视觉接地性和一致性检查，过滤掉模糊序列。最终保留了约 2150 万个训练片段，通过率 75.18%。
- 分层结构化：将数据组织为 L0-L3 四个层级，从单步状态预测到完整任务规划，覆盖了不同粒度的监督需求。
### 关键结果与工程价值RxBrain 在 RxBrain-Bench 上展示了联合语言-视觉规划的能力。更重要的是，它在真实机器人部署中表现出了潜力：
- 无需大规模动作预训练：直接将 RxBrain 扩展为连续动作生成器，在没有大量动作数据预训练的情况下，依然取得了有前景的真实机器人性能。
- 统一架构优势：62 亿参数的基座模型，整合了语言、图像理解和生成能力。对于工程落地而言，这意味着维护成本的大幅降低——只需部署一个模型即可处理感知、规划和想象。
⚠️ 注意 ：虽然论文提到了真实机器人性能，但具体成功率数字未在摘要中详细列出。其核心价值在于证明了“联合规划表示”的可行性，而非单纯的 SOTA 刷榜。
### 局限与展望- 计算开销：交错生成涉及多次视觉编码和解码，推理延迟可能较高。论文附录提到了推理加速策略，但在实时性要求极高的场景下仍需优化。
- 幻觉风险：视觉想象虽然能 grounding 计划，但如果模型“想象”出了错误的物理状态（如物体穿模），后续的动作执行可能会失败。如何保证生成图像的物理一致性，仍是待解难题。
RxBrain 代表了一种新的具身智能范式：不再将规划视为纯符号推理或纯像素预测，而是两者的动态交织。对于正在构建 Agent 系统的工程师来说，这种“文本+视觉”双轨输出的思路，值得深入借鉴。
