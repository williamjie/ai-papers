# ⭐⭐⭐⭐ 视频模型也能做任务规划？WMSD自蒸馏实战拆解

**日期**: 2026-06-11

---

论文 : World Model Self-Distillation: Training World Models to Solve General Tasks链接 : https://arxiv.org/abs/2606.12072现在的视频生成模型（Video Generative Models）很强，但有个致命短板：它们只能“看图说话”，不能“听令行事”。
你想让它“切胡萝卜”，它只会生成一张切好的图，或者一段毫无逻辑的乱动视频。
因为现有的预训练模型依赖详细的文本描述（Caption）作为条件，缺乏从高层指令到具体动作序列的内部推理能力。
这篇来自伯尔尼大学的论文提出了 WMSD（World Model Self-Distillation） ，试图解决这个痛点。
它不收集昂贵的任务-视频配对数据，而是通过“自蒸馏”+“强化学习”，让视频模型学会像 Agent 一样执行通用任务。
### 为什么现有方案不够好？
要让视频模型具备规划能力，通常有两条路：
- 外挂大脑：用 VLM（视觉语言模型）生成详细步骤，再喂给视频模型。这增加了推理延迟，且 VLM 生成的描述往往过于冗长或细节错误。
- 监督微调（SFT）：收集大量“任务指令+成功执行视频”的数据进行微调。但这数据太贵了，尤其是长尾任务和复杂交互场景，几乎无法规模化获取。
WMSD 的核心洞察是： 利用 VLM 的“生成-验证不对称性” 。
让 VLM 生成一个详细的解决方案（Solution）很难，但判断一个视频是否完成了任务（Verification）相对容易且廉价。
### 方法拆解：老师教学生，学生超老师WMSD 的设计非常巧妙，分为两个角色：
- Demonstrator（老师）：一个预训练的视频扩散模型，条件是“图像 + 详细步骤描述”。它拥有强大的物理动力学知识。
- Executor（学生）：我们要训练的模型，条件只有“图像 + 简短任务指令”（如“切胡萝卜”）。
第一步：自蒸馏（Self-Distillation）
VLM 根据初始图像生成一个简短任务 TT 和一个详细步骤 DD 。
Demonstrator 用 DD 生成视频，Executor 试图模仿这个视频，但只能看到 TT 。
这里的关键不是简单的像素级复制，而是 On-policy Distillation（策略内蒸馏） 。
论文指出，传统的 Off-policy 蒸馏会导致误差累积。WMSD 采用 On-policy 方式，在 Executor 自己的轨迹上计算与 Demonstrator 的速度场差异。
这确保了学生不仅模仿老师的动作，还继承了老师对物理世界的理解。
第二步：强化学习（RL）突破上限如果只做蒸馏，Executor 永远超不过 Demonstrator。
因为 Demonstrator 本身也可能犯错，或者生成的步骤不够优化。
WMSD 引入 VLM 作为奖励模型（Reward Model）。
VLM 评估 Executor 生成的视频是否真正完成了任务 TT 。
总奖励函数为：

这种设计让 Executor 可以在保持物理合理性的前提下，探索出比老师更优的任务执行策略。
### 关键结果：数据不说谎论文在自建的 WorldTasks-Bench 上进行了测试，包含导航、物体交互、空间定位等任务。
1. 超越基线模型以 LTX-2 为底座，WMSD 的表现显著优于直接微调（SFT）和纯 RL。
方法 Task Score (任务完成) Agent Score (主体正确) Consist. (物理一致) Avg. LTX-2 (Base) 0.315 0.395 0.690 0.467 LTX-2 + SFT 0.292 0.389 0.682 0.454 LTX-2 + WMSD 0.452 0.500 0.693 0.548注意看，SFT 甚至出现了性能下降（Task Score 从 0.315 降到 0.292）。
作者认为这是因为自动标注的数据质量低，任务过于简单重复，导致模型过拟合了无效模式。
而 WMSD 无需配对视频数据，仅靠自蒸馏和 RL 反馈，就实现了全面超越。
2. 特定任务提升巨大在细分任务上，WMSD 的效果更惊人：
- 导航任务：从 31.1% 提升到 75.6%- 物体交互：从 17.6% 提升到 55.9%- 第一人称视角主体识别：从 42.1% 提升到 86.0%这说明模型不仅学会了“做什么”，还学会了“谁来做”。
3. 机器人任务泛化在 DreamGen 机器人基准测试中，WMSD 在没有见过任何机器人数据的情况下（Zero-shot），表现接近经过 SFT 微调的 Cosmos 模型。
虽然细节上仍有差距（如机械臂外观），但证明了其规划能力的可迁移性。
### 工程启示与局限对工程师的价值：
- 降低数据依赖：如果你没有高质量的“指令-视频”配对数据，WMSD 提供了一条低成本路径。利用现有的预训练视频模型和 VLM，就能开启任务导向的训练。
- On-policy 的重要性：在蒸馏生成模型时，务必考虑策略内（On-policy）的误差校正，否则误差会随时间步累积，导致生成的视频后期崩坏。
- 一致性奖励不可少：单纯优化 VLM 的任务完成度会导致“作弊”行为（如物体突然消失）。必须加入与老师轨迹的一致性约束，才能保证物理合理性。
局限与思考：
- VLM 的噪声：VLM 作为裁判并不完美，对于模糊任务的判断可能存在偏差。论文提到需要结合一致性奖励来稳定信号。
- 领域特定动态缺失：在机器人任务中，模型缺乏对特定机械臂运动学的深入理解。这意味着对于高度专业的领域（如手术、精密装配），仍需少量真实数据进行微调。
WMSD 展示了一种新的范式： 视频模型不仅是内容生成器，更是潜在的通用世界模拟器。
通过自蒸馏和强化学习，我们或许能离“让 AI 看懂并操作世界”更近一步。
