论文 : VideoGAIA: A Benchmark for General AI Assistants on Agentic Video Understanding链接 : https://arxiv.org/abs/2608.14718在 Video-MME 等经典榜单上，前沿多模态大模型（MLLMs）的准确率已逼近 90%，传统单轮视频问答任务趋于饱和。VideoGAIA 的出现标志着评估范式的根本转变：从“被动观看并回答”转向“主动调用工具、多轮交互以解决现实问题”。对于正在构建 AI Agent 的工程团队，这是一个极具参考价值的测试床。
### 痛点与动机现有基准如 Video-MME 和 MLVU 主要考察封闭世界内的单轮感知能力。然而，随着模型向通用生产力助手演进，核心挑战已变为长程推理、工具调用及跨模态信息整合。传统问答无法评估模型在证据缺失时主动检索、在多源信息冲突时进行验证的能力。VideoGAIA 旨在填补这一空白，将视频视为解决具体任务的“证据源”，而非唯一的考察对象。
### 方法拆解：如何构建高难度智能体任务VideoGAIA 的核心 Insight 在于 强制依赖多模态证据与外部工具的联合推理 。其数据构建管线采用了严格的“人机协同”过滤机制，确保每个任务都无法通过单一路径解决：
- 锚点驱动生成：从 10 万条视频中提取视觉锚点（如 Logo、文字），结合 GPT-5.5 生成需外部知识才能解答的问题。
- 多阶段去伪存真：
跨模态过滤：若仅靠视频或仅靠网页内容即可解题，该任务被剔除。
- 工具必要性评估：禁用所有工具后，若模型仍能凭世界知识答对，则视为“伪智能体任务”并移除。
- 人工三重验证：15 名标注员投入超 100 小时，每个任务需至少 3 名专家独立验证，确保答案唯一且正确。
这种设计迫使模型必须执行完整的 ReAct 循环：感知视频 -> 识别缺失信息 -> 搜索网页 -> 回访视频验证细节 -> 综合推理。
### 关键结果：前沿模型的集体“翻车”
在统一的 Agent Loop 设置下（包含 Web Search、Page Visit、Video Thinking 三个工具），20 个前沿模型的表现远低于预期。 没有任何一个模型的准确率超过 60% 。

误差分析揭示瓶颈 ：
- 视频感知错误占比最高（36.8%-48.0%）：错误的视觉锚点会污染后续所有搜索步骤。
- 工具调用效率低下：Gemini-3.1-Pro 进行了 2557 次调用（90.6% 为搜索），而 GPT-5.5 仅 262 次，但后者准确率更高。盲目增加工具预算无效，关键在于“何时停止”和“选对证据”。
### 工程启示- 视频感知是首要瓶颈：在构建 Video Agent 时，优先优化细粒度视觉定位（Visual Grounding）比单纯增强搜索逻辑更重要。
- 不确定性管理至关重要：成功轨迹（如 Seed2.0-Pro 案例）显示，模型需保持假设开放，通过二次验证排除歧义，而非急于给出答案。
- 评估范式迁移：企业级视频应用应从“问答准确率”转向“任务完成度”，关注模型在多轮交互中的证据整合能力。
### 局限与展望VideoGAIA 目前仅包含 271 个任务，且 Economics 类别样本极少（6 个），统计显著性有限。此外，评估依赖 GPT-5.5 作为裁判，可能存在偏差。未来，随着更多模型针对 Agentic Video Understanding 进行专门训练，该基准有望成为衡量下一代多模态智能体真实生产力的核心标尺。
