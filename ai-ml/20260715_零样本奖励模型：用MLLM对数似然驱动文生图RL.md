# ⭐⭐⭐ 零样本奖励模型：用 MLLM 对数似然驱动文生图 RL

**日期**: 2026-07-15

---

论文 : Read It Back: Pretrained MLLMs Are Zero-Shot Reward Models for Text-to-Image Generation链接 : https://arxiv.org/abs/2607.11886让多模态大语言模型（MLLM）直接给文生图结果打分，往往因为“幻觉”或评分噪声导致强化学习（Reinforcement Learning, RL）训练崩溃。这篇论文提出了一种极其优雅的解法： 别问 MLLM 觉得图片好不好，让它把图片“读”回提示词。
作者提出的 SpectraReward 利用预训练 MLLM 的图文对齐能力，通过计算**图像条件下的提示词对数似然（Log-Likelihood）**作为奖励信号。这种方法无需任何偏好标签、无需微调奖励模型，甚至不需要复杂的问答分解管道。更令人兴奋的是，在统一多模态模型（Unified Multimodal Models, UMMs）中，这种“自指”机制能实现闭环自我进化。
### 现有方案的痛点：为什么我们要换个思路？
目前的文生图 RL 奖励建模主要有两条路，但都有硬伤：
- 基于人类偏好的奖励模型：需要海量标注数据，训练成本高，且容易陷入对美学细节的过度拟合，忽略了指令遵循（Instruction Following）。
- 零样本 MLLM 裁判：
直接打分：让 MLLM 输出 1-5 分。这极度依赖模型的校准能力，评分噪声大，RL 训练极不稳定。
- 分解验证（VQA）：把提示词拆成原子问题逐个验证。虽然准确率高，但工程复杂度爆炸，且严重依赖分解器的质量。
SpectraReward 的核心 Insight 是： 预训练 MLLM 最扎实的能力不是“评判”，而是“理解”。 如果一张图真的符合提示词，那么给定这张图，MLLM 应该能大概率预测出原始的提示词 token。
### 方法拆解：把“理解”变成“奖励”
SpectraReward 的操作非常简单，却直击本质：
- 输入：生成的图像 yy 和原始提示词 xx。
- 前向传播：将图像作为视觉条件输入冻结的 MLLM，执行一次教师强制（Teacher-Forced）的前向传播，计算提示词每个 token 的条件概率 p(xt∣x<t,y)p(x_t | x_{<t}, y)​∣x<t​,y)。
- 奖励计算：取所有 token 对数似然的平均值作为标量奖励：

这个“语义频谱”（Semantic Spectrum）反映了图像中视觉证据对文本语义的支持程度。
Self-SpectraReward：闭环自我进化对于统一多模态模型（如 BAGEL），生成分支和理解分支共享 Tokenizer、视觉编码器和预训练分布。作者提出用模型的 理解分支 作为 生成分支 的奖励模型。
- 优势：消除了外部依赖，且奖励信号与策略分布天然对齐（Reward-Policy Alignment）。
- 直觉：模型用自己的“眼睛”检查自己画的画，比让一个完全陌生的大模型来检查更懂它的“语言”。
### 关键结果：小模型也能打败大裁判？
实验覆盖了 SD3.5-M 和 BAGEL 两个基线，以及 GenEval、TIIF-Bench 等五个基准。数据非常扎实：

⚠️ 反直觉发现：奖励模型越大越好？错！实验显示，使用 Qwen3-VL 系列作为奖励模型时，从 8B 升到 30B 性能提升，但升到 235B 时，GenEval 分数反而从 88.3 下降 到 86.8。
作者推测：过大的 MLLM 可能将容量分配给了高级推理任务，而基础的“图像-文本对齐”能力在中等规模（如 30B）已饱和。更重要的是， Self-SpectraReward（使用 BAGEL 自身分支）的表现甚至超过了 30 倍参数的外部大模型 。这证明了 分布对齐 比单纯追求奖励模型的参数规模更重要。
### 工程启示：如何落地？
- 首选预训练阶段模型：实验发现，Gemma3-12B-Pretrain 的效果优于 Gemma3-12B-Instruct。因为 SpectraReward 依赖的是基础的图文对齐能力，而非指令跟随能力。如果你在工程上部署奖励模型，优先考虑未经过深度指令微调的预训练权重。
- 统一多模态模型的天然优势：如果你正在开发类似 BAGEL、Show-o 或 JanusPro 的统一模型，Self-SpectraReward 是免费的性能提升方案。无需引入外部服务，只需在 RL 步骤中复用理解分支的前向计算。
- 避免复杂的 VQA 管道：SpectraReward 仅需一次前向传播，计算开销远小于分解验证（Decompositional Verification），且鲁棒性更强。对于追求训练效率的团队，这是更优解。
### 局限与展望- 语言先验干扰：虽然论文指出在组相对优势（Group-Relative Advantage）计算中语言先验会被抵消，但在绝对奖励校准上可能存在偏差。
- 粒度问题：Token 级别的奖励并未表现出比序列级别更稳定的训练效果，默认使用序列平均似然是更安全的选择。
这篇论文提供了一个极具启发性的视角： 奖励模型不需要是“法官”，它可以是“读者”。 通过复用预训练知识中的对齐信号，我们可以在零成本下获得高质量的 RL 监督信号。对于正在探索文生图 RL 落地的工程师来说，SpectraReward 是一个值得立即尝试的基线方案。
