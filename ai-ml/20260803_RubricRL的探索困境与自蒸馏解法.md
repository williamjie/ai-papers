# ⭐⭐⭐½ Rubric RL 的探索困境与自蒸馏解法

**日期**: 2026-08-03

---

论文 : Enhancing Rubric-based RL via Self-Distillation链接 : https://arxiv.org/abs/2607.18082在医疗咨询、长文写作等开放域任务中，基于评分标准（Rubric-based）的强化学习（Reinforcement Learning, RL）正成为提升大模型能力的热门范式。然而，现有方案往往陷入“训练时作弊、推理时翻车”的困境，或者因奖励信号聚合不当而丢失关键行为。这篇来自浙江大学与字节跳动的论文提出了 CriPO ，通过策略内的自蒸馏（Self-Distillation），在不引入训练 - 推理分布偏差的前提下，同时解决了探索不足和信号被抑制两大痛点。
### 现有方案的两个致命缺陷基于评分标准的 RL 通常将多维度的评估标准聚合为一个标量奖励（Scalar Reward）用于优化。作者敏锐地指出，这种机制在实际训练中会导致两种严重的失败模式：
- 未探索的标准（Unexplored Criteria）：在采样的一组回复中，没有任何一条满足某些特定标准。由于 GRPO 等算法仅对现有行为进行优化，这些标准完全收不到梯度信号。
- 被抑制的标准（Suppressed Criteria）：模型其实已经生成了满足某些标准的行为，但由于其他维度表现不佳，导致整体优势值（Advantage）为负或零。这使得原本正确的局部行为被错误地惩罚或忽略。
⚠️ 反直觉发现 ：在 Qwen3-4B 的训练数据中，超过 57% 的样本存在“被抑制的标准”，平均每样本有 1.8 个此类标准。这意味着现有方法大量浪费了模型已有的正确行为信号。
为了解决探索问题，之前的工作（如 HeRL）常在生成阶段引入外部引导信息。但这引入了严重的 训练 - 推理不匹配（Train-Inference Mismatch） ：训练时模型依赖额外提示，推理时却只能靠自己，导致自回归解码中的误差累积。
### CriPO：策略内自蒸馏的精妙设计CriPO 的核心洞察是：利用 On-Policy Self-Distillation (OPSD) 框架，让模型在自身生成的回复基础上，通过“自我对话”提取细粒度的 token 级监督信号，从而避免分布偏差。
1. 针对未探索标准：行为注入（Behavior Injection）
对于未被满足的标准，CriPO 构建了一个“准则注入自教师”。它选取当前组中表现最好的回复，让模型在附加未满足准则的提示下重新生成。
- 设计直觉：使用 前向 KL 散度（Forward-KL） 作为损失函数，鼓励学生模型覆盖教师模型的偏好分布，从而注入全新的行为模式。
- 关键细节：并非所有 token 都参与蒸馏。作者发现仅约 34.6% 的 token 贡献了 95% 的 KL 散度。因此，CriPO 采用“贡献引导的 Token 过滤”，只对这些高信息量的位置进行蒸馏，有效去除了噪声。
2. 针对被抑制标准：优势翻转（Advantage Flipping）
对于已满足但被整体负优势压制的位置，CriPO 构建了一个“反事实自教师”。它要求模型移除或修改满足特定准则的部分，生成一个对比版本。
- 设计直觉：通过比较原始分布与反事实分布，定位那些因该准则而概率显著变化的 token。
- 关键操作：一旦定位到这些关键 token，直接将其对应的优势值从负数翻转为正数（默认 τflip=0.1\tau_{flip}=0.1​=0.1）。这样既保留了全局优化的稳定性，又局部纠正了错误惩罚。
### 实验结果：效率与性能双提升在 RaR-Medicine 和 RaR-Science 基准测试上，CriPO 展现了显著优势。以 Qwen3-1.7B 为例：
方法 RaR-Medicine HealthBench LLMEval-Med Science Avg. GRPO 49.2 60.5 58.5 59.2 (Avg) HeRL 50.2 60.8 60.6 60.4 (Avg) CriPO 51.6 65.6 62.2 62.4 (Avg)
- 性能提升：相比 GRPO，CriPO 在 Qwen3-1.7B 上平均提升 +3.2%，在 Qwen3-4B 上平均提升 +1.4%。
- 收敛效率：CriPO 仅需约 175 步 即可达到 GRPO 的最佳性能，优化步骤减少约 2 倍。这意味着在实际工程中，可以大幅节省算力成本。
消融实验进一步验证了设计的有效性：移除 Token 过滤会导致性能下降（从 66.4 降至 65.5），证明全量蒸馏会引入噪声；随机选择翻转 token 则导致性能暴跌至 64.9，证实了精准定位关键 token 的重要性。
### 工程启示对于从事大模型 RL 微调的工程师，这篇论文提供了两个极具价值的指导：
- 警惕标量奖励的副作用：在多标准评估中，简单的加权求和会掩盖局部优秀行为。在实现 RL 时，应考虑如何解耦不同维度的信号，避免“一损俱损”。
- 自蒸馏是解决探索难题的低成本方案：相比修改生成逻辑引入外部引导，利用现有 rollouts 进行策略内自蒸馏，既能保持训练 - 推理一致性，又能提供密集的 token 级监督。这在长文本生成等对误差累积敏感的场景中尤为重要。
CriPO 展示了一种优雅的混合优化思路：以稳定的 GRPO 为骨架，用 OPSD 进行精准的局部修正。这种“全局稳定 + 局部精细”的范式，值得在更多复杂奖励场景下探索。
