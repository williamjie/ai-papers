# ⭐⭐ 机器人WAM轻量化：参数量砍13倍，推理仅72ms

**日期**: 2026-06-09

论文 : Light-WAM: Efficient World Action Models with State-Fusion Action Decoding链接 : https://arxiv.org/abs/2606.08242World Action Model（世界行动模型，WAM）最近很火，但现有方案大多依赖庞大的生成式架构，导致训练成本高、推理延迟大，根本没法在真实机器人上跑闭环。Light-WAM 提出了一套轻量化方案，将可训练参数量从 6.02B 压缩到仅 0.44B，同时保持了极具竞争力的任务成功率。
### 痛点：WAM 太“重”了目前的 WAM（如 Fast-WAM）通常耦合了大规模的视频预测和行动生成模块。虽然视频预测能提供时间结构上的监督信号，帮助策略网络理解物体运动和交互动态，但这种“全家桶”式的架构带来了巨大的算力负担。
对于工程落地而言，推理延迟是致命伤。现有的大模型往往需要数秒才能输出一组动作，这在需要高频反馈的机器人操控中是不可接受的。Light-WAM 的核心洞察在于： 视频预测的主要价值在于训练时的表征学习，而非推理时的实时生成 。既然推理时不需要“想象”未来，那为什么还要保留沉重的生成模块？
### 方法拆解：做减法与精准融合Light-WAM 的设计哲学非常清晰：保留训练收益，剔除推理冗余。
1. 潜空间降采样视频监督为了降低视频协同训练的 Token 成本，作者在训练阶段对视频潜在变量（Latent）进行了空间降采样。这意味着视频分支在较低分辨率的潜空间中学习未来的动态变化。
- 直觉：视频预测是为了让 Backbone 学会“世界是如何变化的”，不需要像素级的完美重建，低分辨率足以捕捉运动趋势和任务进度。
2. StateFusionActionExpert：直接解码动作这是本文最核心的创新模块。传统方法往往使用复杂的生成式行动专家（Generative Action Expert）来逐步去噪生成动作。Light-WAM 则引入了一个轻量级的“状态融合行动专家”。
- 多层级读取：它不只看 Backbone 的最终输出，而是从第 8、16、24 层稀疏地读取经过适配的状态。不同层级捕捉的信息粒度不同（如高层语义 vs 底层细节）。
- 可学习查询池化（Learned-Query Pooling）：通过一组可学习的 Query Token 对密集的视频 Token 进行注意力汇聚，将海量视觉信息压缩为固定宽度的状态向量。
- 单次前向传播：融合后的状态直接映射为动作块（Action Chunks），无需迭代去噪。
### 关键结果：效率与性能的平衡实验数据证明，Light-WAM 在大幅削减资源消耗的同时，并没有牺牲太多性能。

消融实验还显示，将视频监督分辨率从降采样恢复至原始分辨率，LIBERO-Spatial 的成功率从 98.2% 提升至 99.0%，但训练成本显著增加。因此，2倍降采样是一个极佳的性价比平衡点。
### 工程启示- 推理时不需要“世界模型”：如果你关注的是机器人控制策略的实时性，完全可以抛弃推理时的视频生成分支。利用视频预测作为训练时的辅助监督信号（Auxiliary Loss）即可提升表征质量。
- 多层级特征融合优于单点输出：直接取 Transformer 最后一层往往丢失了空间细节。通过稀疏采样中间层并结合 Query Pooling，可以在不增加过多计算量的前提下，保留更多对操控至关重要的视觉线索（如夹爪位置、物体边缘）。
- 小模型也能干大事：0.44B 的可训练参数意味着你可以在消费级显卡甚至边缘设备上微调自己的机器人策略。对于资源受限的团队，Light-WAM 提供了一个极具参考价值的架构模板。
### 局限与展望尽管效率惊人，Light-WAM 在更复杂的长视野任务（LIBERO-Long）上仍略逊于超大模型（93.0% vs 97.6%+）。这表明在需要极强推理能力的复杂场景中，大模型的容量优势依然存在。此外，该方法目前主要基于现有的仿真基准，未来在真实世界中的泛化能力仍需更多数据增强和鲁棒性训练来验证。
对于工程师而言，Light-WAM 证明了 WAM 并非只能是“实验室里的玩具”，通过精心的架构设计，它完全有能力成为高效、实用的机器人控制核心。
