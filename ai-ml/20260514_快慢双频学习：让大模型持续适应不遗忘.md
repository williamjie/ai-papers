# 快慢双频学习：让大模型持续适应不遗忘

**日期**: 2026-05-14

---

论文 : Learning, Fast and Slow: Towards LLMs That Adapt Continually链接 : https://arxiv.org/abs/2605.12484如果你正在做推理模型（Reasoning LLMs）的微调或强化学习（RL），这篇论文会戳中你的痛点：为什么模型学完一个任务后，再学新任务就完全“失忆”甚至性能崩塌？
UC Berkeley 和 Mila 等机构的研究团队提出了 Fast-Slow Training (FST) 框架。核心观点很直觉：人类学习分“快系统”和“慢系统”，大模型也该如此。别把所有适应信号都硬塞进参数里，让“文本提示（Prompt）”承担快速适应，“模型参数”承担长期记忆。
## 为什么现有方案不够用？
目前主流的推理增强手段，无论是监督微调（SFT）还是基于可验证奖励的强化学习（RLVR），本质上都是 只更新慢权重（模型参数） 。
这种单一通道的代价是巨大的：
- 灾难性遗忘：为了提升特定任务奖励，参数必须大幅偏离基座模型，导致泛化能力下降。
- 塑性丧失（Plasticity Loss）：参数被“固化”在当前任务分布上，对后续新任务的梯度信号不再敏感。
- 数据低效：所有启发式规则、任务特定技巧都必须通过昂贵的梯度更新才能被模型吸收。
FST 的核心 Insight 在于 解耦 。它认为 adaptation 应该由两个互补渠道共同完成：
- 慢权重（Slow Weights）：模型参数 θ\theta。昂贵、持久、编码通用行为。
- 快权重（Fast Weights）：文本上下文 ϕ\phi（如 Prompt）。廉价、高频、捕捉任务特定信息。
## FST 方法拆解：怎么做到“双频”协同？
FST 不是先训练模型再调 Prompt，而是让两者 共同进化（Co-evolve） 。
### 1. 架构设计- 慢循环（Slow Loop）：使用标准的 RLVR（如 CISPO 算法），仅利用标量奖励（Scalar Reward）更新参数 θ\theta。
- 快循环（Fast Loop）：使用 GEPA（Reflective Evolutionary Prompt Optimization）优化文本上下文 ϕ\phi。GEPA 不仅看奖励，还利用完整的 Rollout 文本（包括思维链、代码错误、工具调用反馈）进行反思和变异。
### 2. 关键技巧：保持多样性FST 不维护一个“最佳 Prompt”，而是维护一个包含 KK 个 Prompt 的 帕累托前沿（Pareto Frontier）种群 。
- 为什么？ 不同的 Prompt 在不同类型的子任务上表现最好。
- 怎么做？ 在 RL 更新时，每次采样一组 Rollout，其中 G/KG/K 次使用种群中的每个 Prompt。这样，优势函数（Advantage）的计算混合了“Prompt 差异”和“采样差异”，迫使参数 θ\theta 学习适应多种上下文条件，而不是过度拟合某一种特定的 Prompt 诱导的行为。
### 3. 训练节奏交替进行：
- 固定当前 θ\theta，用 GEPA 更新 Φ\Phi（快权重）。
- 固定新 Φ\Phi，用 RL 更新 θ\theta（慢权重）。
- 重复直到收敛。

## 工程启示- Prompt 是廉价的“快速权重”：不要忽视 Prompt 优化的潜力。在 RL 训练中引入动态 Prompt 种群，可以显著减少梯度更新次数，节省算力。
- 警惕“过度微调”：如果你发现模型在特定任务上表现极好，但泛化能力骤降，可能是因为所有压力都施加在参数上。引入文本层面的适应，可以保护参数的“塑性”。
- 持续学习的新思路：对于需要不断吸收新知识的应用场景（如 Agent），FST 证明了通过快慢双频机制，模型可以在不遗忘旧知识的前提下，快速适应新任务分布。
## 局限与展望- 计算开销：GEPA 需要维护 Prompt 种群并进行反射优化，增加了每步训练的额外开销（尽管减少了 RL 步数，但单步成本增加）。
- 依赖反馈质量：快权重的进化依赖于高质量的文本反馈（如 GEPA 使用的反射模型）。如果反馈噪声大，快权重可能误导慢权重。
- 未来方向：如何更高效地在快慢权重间蒸馏知识？如何结合更先进的 Prompt 优化器？这些都是值得探索的工程落地点。
总的来说，FST 提供了一个更符合认知科学的 LLM 训练范式： 让文本做它擅长的事（快速适配），让参数做它擅长的事（长期记忆） 。
