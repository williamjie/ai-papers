# 抛弃 OCR：视觉预训练重塑科学推理

**日期**: 2026-07-13

---

论文 : Scalable Visual Pretraining for Language Intelligence链接 : https://arxiv.org/abs/2607.09657现在的 LLM 都在卷文本，但科研文档里的公式、图表和排版结构在转成纯文本时往往丢失了大量关键信息。这篇来自上海 AI 实验室的工作直接挑战了“语言模型必须基于文本预训练”的假设，证明直接用原始视觉页面进行预训练（Visual Pretraining, VP），不仅能提升科学推理能力，还能大幅压缩训练 Token 量。
## 痛点：OCR 是信息的“粉碎机”
我们习惯认为，把 PDF 转成 Text 再喂给模型是最优解。但认知科学早就指出，人类理解复杂知识时，高度依赖空间布局、几何约束和符号拓扑。
现有的主流方案（如 MinerU2.5）通过解析 HTML/LaTeX 或 OCR 提取文本，这个过程本质上是 有损压缩 。
- 公式丢失：复杂的数学排版被扁平化为线性字符串，失去了结构美感与逻辑关联。
- 图表失效：物理示意图、数据表格的空间关系在纯文本中难以忠实还原。
论文指出，这种“先提取、后训练”的范式，让模型永远无法接触到文档最原始的丰富结构。
## 方法拆解：Next Visual Latent PredictionVP 的核心 Insight 非常直接： 既然文本是视觉信息的投影，为什么不直接从源头（原始页面）学习？
作者设计了一个自回归的视觉预训练框架，关键设计如下：
- 稀疏前景提取：
不处理整张图片，而是通过像素方差和亮度统计，过滤掉空白背景。
- 仅保留包含内容的“前景 Patch”，并按光栅扫描顺序排列。这既保留了空间布局，又大幅缩短了序列长度。
- Next Visual Latent Prediction (NVLP)：
冻结视觉编码器（Vision Tower），提取视觉潜在特征（Latents）。
- 将这些特征投影到 LLM 的隐藏空间。
- 核心目标：让 LLM 像预测下一个 Text Token 一样，预测下一个视觉 Latent。
- 使用 InfoNCE 损失函数，在批次内进行对比学习，迫使模型理解页面元素间的因果与空间关系。
⚠️ 反直觉设计 ：不需要任何图像-文本配对数据（Image-Text Pairs）。完全无监督地利用原始文档页面进行自回归预测。
## 关键结果：更少 Token，更强推理实验在 Qwen3.5、Qwen3、Llama3.2 Vision 等多个基座上验证了 VP 的有效性。以下是核心数据对比（基于 Qwen3.5）：

- Token 预算：处理相同的科学 PDF 语料，TP 消耗约 80B 文本 Token，而 VP 仅需 20B 视觉 Token。
- 性价比：VP 仅用 TP 25% 的 Token 预算，就在 GPQA 和 AIME 等硬核推理任务上实现了反超。
跨模态对齐 ：
即使没有配对数据监督，VP 也显著提升了图文对齐能力。在 100 对科学文档图像-文本对上：
- 质心分离度（Centroid Separation）从 1.665 降至 0.661。
- 余弦相似度从 0.631 升至 0.907。
## 工程启示- 科学文档处理的范式转移：对于包含大量公式、图表的垂直领域（如医疗、物理、金融报告），直接对原始页面进行视觉预训练可能比昂贵的 OCR+清洗流程更具性价比。
- 混合预训练策略：VP 并非要取代文本预训练，而是作为补充。在 Continued Pretraining (CPT) 阶段引入少量视觉数据，能显著修复因 OCR 丢失的结构信息。
- 压缩即力量：通过稀疏前景提取，视觉 Token 被高度压缩。这意味着我们可以用更低的计算成本，让模型“看”到更多高质量文档。
## 局限与展望- 依赖文本基座：VP 是建立在已有强大语言能力的 LLM 之上的增量预训练，并非从零开始。
- 适用场景狭窄：目前主要在科学 PDF 上验证。对于自然图像或视频，这种基于页面布局的稀疏化策略是否有效，仍需探索。
- 解码协调：如何更好地协调视觉 Latent 解码与文本 Token 解码，仍是后续优化的重点。
这篇论文提醒我们： 不要低估“看”的力量。 在追求更大文本规模的同时，保留原始数据的模态完整性，可能是突破当前推理瓶颈的关键钥匙。
