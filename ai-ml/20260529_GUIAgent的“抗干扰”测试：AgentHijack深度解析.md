论文 : AgentHijack: Benchmarking Computer Use Agent Robustness to Common Environment Corruptions链接 : https://arxiv.org/abs/2605.25707现在的 GUI Agent（计算机操作智能体）在干净、理想的实验室环境里表现确实惊艳，但在真实办公场景中，它们往往脆弱得不堪一击。这篇论文抛出了一个极其务实的问题： 当弹窗突然跳出、分辨率意外改变或网络闪断时，Agent 还能不能干活？ 作者不仅造了一个专门测试这种“抗干扰能力”的基准测试 AgentHijack，还顺带提了一套能显著提升鲁棒性的框架方案，对正在落地自动化办公场景的工程团队极具参考价值。
### 为什么现有的评测不够用？
目前的主流评测集（如 OSWorld、WebArena）大多假设环境是完美的：没有无关弹窗，分辨率固定，网络稳定。但这与真实世界相去甚远。
作者将干扰分为两类，并指出当前研究的盲区：
- 对抗性鲁棒性：针对恶意攻击（如提示词注入），已有不少研究。
- 常见环境腐蚀（Common Corruptions）：非恶意的、随机的环境噪声，如误触、应用最小化、网络错误等。
现有工作要么只关注干净环境下的成功率，要么缺乏可配置的真实执行环境。AgentHijack 填补了这一空白，它基于 OSWorld 构建了 3,321 个任务，引入了 9 种可配置的常见腐蚀类型 ，覆盖视觉干扰（弹窗、分辨率变化）、意外操作（误触、应用最小化）和环境错误（断网、需验证登录）。
### 核心 Insight：Agent 为什么容易“翻车”？
通过大量 Case Study，作者发现了当前 MLLM-based Agent 的三大致命弱点：
- 视觉定位脆弱：面对弹窗或分辨率变化，Agent 的 Grounding（ grounding）能力大幅下降。例如，目标按钮明明可见，Agent 却去点击无关弹窗；或者因分辨率缩放导致点击坐标偏移。
- 归因错误与注意力分散：当发生误触或应用最小化时，Agent 往往将环境变化错误地归因于自己的上一步操作，甚至被新弹出的无关内容吸引，偏离原始任务轨迹。
- 缺乏初始状态感知：Agent 倾向于假设环境初始化正常。如果一开始就断网或需要登录，它们不会报错重试，而是陷入无限期的无效尝试（Meaningless Attempts）。
### 方法拆解：AgentHijack-Agent 框架针对上述痛点，作者提出了 AgentHijack-Agent 框架，核心由两部分组成：
-增强型动作生成器（Action Generator）：
采用 数据增强组相对策略优化（DA-GRPO）。不同于传统只在干净环境下的强化学习，DA-GRPO 在训练 rollout 时主动引入不同的腐蚀环境。
- 关键设计：由于成功轨迹稀疏，作者引入了经验回放缓冲区（Experience Replay Buffer），缓存成功的轨迹。如果一批次全是失败样本，随机替换一个历史成功样本，确保梯度信号不消失。
-旁观者机制（Onlooker）：
初始环境检查：在执行任务前，Onlooker 先验证环境是否正常（如网络连通性、登录状态）。若异常，直接请求重置，避免 Agent 浪费算力在无效探索上。
- 行为总结与环境监控：Onlooker 持续观察屏幕变化，将每一步的环境变更总结为简短描述 dtd_t​。这不仅帮助 Agent 理解“发生了什么”，还将其从单纯的视觉识别中解放出来，专注于逻辑决策。
### 关键结果：数据不会说谎实验数据显示，当前 SOTA 模型在腐蚀环境下性能断崖式下跌。以 UI-TARS-1.5-7B 为例：

引入 AgentHijack-Agent 后，性能显著提升：
- 整体平均提升：相比最强的基线 UI-TARS-1.5-7B，平均成功率提升了 +3.59%（从 20.84% 到 24.43%）。
- 特定场景大幅改善：在“弹窗”干扰下，成功率从 10.28% 提升至 21.51%（+11.23%）；在“身份验证”错误处理上，从 7.81% 提升至 20.15%（+9.67%）。
### 工程启示- 不要迷信 SFT：单纯的监督微调（SFT）只能让 Agent 模仿干净数据，无法泛化到噪声环境。强化学习结合环境扰动（如 DA-GRPO）是提升鲁棒性的必由之路。
- 引入“元认知”模块：在 Agent 架构中增加一个轻量级的“旁观者”或“校验器”，专门负责环境状态检查和异常捕获，能极大减少无效推理开销。
- 基准测试必须包含噪声：如果你的自动化流程要在生产环境部署，必须在测试集中加入随机弹窗、网络抖动等干扰项，否则上线即事故。
### 局限与展望目前 AgentHijack 主要基于桌面端 OSWorld，移动端（Android/iOS）的腐蚀场景尚未覆盖。此外，DA-GRPO 的训练成本较高，如何降低强化学习在 GUI 领域的门槛，仍是工程落地的挑战。但毫无疑问，这篇论文为构建“可信”GUI Agent 指明了方向： 鲁棒性不是锦上添花，而是生存底线。
