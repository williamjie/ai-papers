# ⭐⭐⭐⭐ 用Transformer重构人生：瑞典个税模拟中的长程预测

**日期**: 2026-05-20

论文 : SAGA: A Sequence-Adaptive Generative Architecture for Multi-Horizon Probabilistic Forecasting with Adaptive Temporal Conformal Prediction链接 : https://arxiv.org/abs/2605.19014在金融风控、保险精算乃至国家财政规划中，预测一个人的“终身收入”不仅是学术问题，更是决定政策成败的工程难题。传统的参数化模型（如 Guvenen-Karahan-Ozkan-Song, 简称 GKOS）虽然经典，但往往忽略了海量的行政特征（职业、行业、家庭结构等）以及长程的非线性依赖。这篇发表在 TPAMI 上的论文提出了 SAGA，一个基于 Decoder-only Transformer 的架构，它在瑞典 214 万人的真实面板数据上，实现了对未来 30 年收入路径的高精度概率预测。对于需要处理不规则时间序列、多模态特征且对预测区间有严格校准要求的工程场景，SAGA 提供了一套极具参考价值的范式。
### 痛点：参数模型的“信息丢失”
现有的主流方案通常将收入分解为固定效应、永久成分和暂态成分。这种参数化过程虽然能拟合出厚尾分布，但存在三个致命缺陷：
- 特征利用不足：仅依赖历史收入，忽略了职业、行业、地理位置等强预测性特征。
- 交互关系简化：将复杂的跨截面依赖压缩为单一固定效应，丢失了大量预测信息。
- 结构僵化：函数形式固定，无法灵活捕捉冲击的持久性或非线性交互。
### 方法拆解：SAGA 的核心直觉SAGA 的核心 Insight 在于将不规则的面板数据转化为 Transformer 可处理的 Token 序列，并引入保序校准机制。
-结构化 Token 化（Structured Tokenization）：
作者没有简单拼接特征，而是设计了五个子向量：连续特征（15维）、分类特征（嵌入后76维）、缺失值掩码（16维）、年龄位置编码（64维）和年份位置编码（32维）。
为什么分开？ 年龄反映人力资本积累，年份反映宏观经济周期。合并两者会混淆这两类独立的预测信号。
- 维度提升：拼接后维度为 252，通过线性层投影到 384 维。这给自注意力机制提供了更高的工作维度，同时保留了特征类型的结构信息。
-双头输出（Dual Output Heads）：
模型共享 Transformer 骨干，末端分为两个分支：
点预测头：输出对数收入的点估计，使用 MSE 损失。
- 分位数头：输出 5%, 10%, …, 95% 七个分位数的预测值，使用 Pinball Loss。
这种设计允许模型同时提供精确的点预测和完整的概率分布描述。
-自适应保序预测（Adaptive Conformal Prediction）：
为了提供具有有限样本边际覆盖率保证的预测区间，SAGA 采用了 Split Conformal Calibration。
关键设计：在自回归预测中，不是简单加宽区间，而是在每个预测步骤从经验非一致性分布中抽取残差。这确保了即使是在多步自回归生成的长序列中，边际覆盖率依然得到保证。
### 关键结果：碾压传统基线在瑞典 LISA 注册数据（1990-2022年，214万人，6128万人年）上，SAGA 的表现令人印象深刻。以下是对比 GKOS 基线的核心指标（10年预测 horizon）：
指标 SAGA GKOS (基线) 相对提升/差距 CRPS 0.318 0.467 降低 31.9% MAE (20年) 0.631 1.013 降低 37.7% Gini 系数 0.327 0.378 更接近真实值 0.341 Top 1% 份额 8.3% 11.2% 更接近真实值 8.9%- 校准性：在 90% 的名义覆盖率下，SAGA 的边际覆盖率误差小于 0.5 个百分点，最差子群体（最低收入五分位）的覆盖率也达到了 87.6%，偏差仅 2.4 个百分点。
- 消融实验：移除 Transformer 骨干改用全连接网络，CRPS 恶化 55.0%；移除年龄/年份嵌入，CRPS 分别增加 15.4% 和 7.2%。这证明了序列建模和独立位置编码的重要性。
### 工程启示- 不规则序列的处理范式：SAGA 展示了如何处理缺失值和稀疏特征。通过显式的 Missingness Subvector 和独立的 Age/Year 嵌入，模型能够优雅地处理面板数据中的不规则采样和缺失问题，这对金融风控中的用户行为序列建模极具参考价值。
- 概率预测的工程落地：在业务中，仅有“点预测”往往不够，我们需要知道“不确定性”。SAGA 的分位数头 + 保序校准的组合，为构建具有统计保证的置信区间提供了标准流程。
- 下游任务评估：论文不仅看预测误差，还将其接入瑞典个税计算器，评估终身税负和基尼系数。这提醒我们，在评估预测模型时，应尽可能模拟下游业务逻辑（如现金流折现、税务计算），而不仅仅看 MAE 或 RMSE。
### 局限与展望SAGA 并非完美。在自回归解码时，分类特征（如职业、行业）需要通过辅助模型进行填补，这种误差会随着预测 horizon 的延长而累积。此外，虽然边际覆盖率有理论保证，但终身聚合后的覆盖率保证仍是经验性的。未来工作可探索联合建模收入与职业转换，以减少特征填补带来的误差传播。
