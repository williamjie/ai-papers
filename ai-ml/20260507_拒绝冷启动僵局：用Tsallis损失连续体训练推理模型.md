# 拒绝冷启动僵局：用Tsallis损失连续体训练推理模型

**日期**: 2026-05-07

---

论文 : How Fast Should a Model Commit to Supervision? Training Reasoning Models on the Tsallis Loss Continuum链接 : https://arxiv.org/abs/2604.25907在推理模型（Reasoning Models）的后训练阶段，工程师们常遇到一个令人头疼的“冷启动”困境：当模型初始对齐度较低、初始成功率 p0p_0 ​ 极低时，基于可验证奖励的强化学习（RLVR）往往陷入停滞，梯度信号微弱到几乎无法推动模型进步。这篇来自 Google 的论文直击这一痛点，提出了一种基于 Tsallis qq -对数的损失连续体（Tsallis Loss Continuum），通过调整参数 qq 来控制模型对监督信号的“承诺程度”，从而在冷启动逃逸速度和噪声鲁棒性之间找到完美的平衡点。
### 为什么现有方案会失效？
目前的 SFT-then-RL 流水线存在天然的两难：
- SFT（q=1q=11 极点）：收敛极快，能迅速逃离冷启动，但容易过拟合噪声标签。
- RLVR/REINFORCE（q=0q=00 极点）：对噪声鲁棒，但在冷启动阶段，逃逸时间随 1/p01/p_0​ 线性增长。如果 p0p_0​ 很小，模型可能需要天文数字般的步数才能“醒过来”。
论文指出，这两者并非不可调和。通过引入 Tsallis qq -logarithm，作者构建了一个从 q=0q=0 0 到 q=1q=1 1 的连续损失家族 JqJ_q ​ 。核心 Insight 在于： 所有 qq 值共享相同的梯度方向，仅相差一个标量放大因子 Pθ−qP_\theta^{-q} − q ​ 。这个因子就是解决冷启动的关键——它动态地重加权每个样本，让模型在面对低成功率样本时“更用力”地更新。
### 方法拆解：双端点与两种估计器论文的理论推导证明了梯度几何的统一性：
∇θℓq=Pθ−q∇θℓ0=Pθ1−q∇θℓ1\nabla_\theta \ell_q = P_\theta^{-q} \nabla_\theta \ell_0 = P_\theta^{1-q} \nabla_\theta \ell_1 ​ ℓ q ​ = P θ − q ​ ∇ θ ​ ℓ 0 ​ = P θ 1 − q ​ ∇ θ ​ ℓ 1 ​基于此，作者提出了两种互补的蒙特卡洛估计器，分别对应强化学习和微调视角：
-GARL (Gradient-Amplified RL)：
视角：从 q=0q=00 端点出发，采样前验轨迹，然后放大 RL 梯度。
- 机制：使用 Pθ−qP_\theta^{-q}−q​ 放大梯度。在冷启动时，PθP_\theta​ 很小，放大因子极大，强制模型快速逃离低概率区域。
- 代价：混合了错误的推理轨迹，方差较大（尽管通过 RLOO 降低了部分方差）。
-PAFT (Posterior-Attenuated Fine-Tuning)：
视角：从 q=1q=11 端点出发，近似采样后验轨迹（即与答案一致的轨迹），然后运行标准 SFT。
- 机制：使用 Pθ1−qP_\theta^{1-q}1−q​ 衰减梯度。它先通过重要性重采样过滤掉不相关的轨迹，只保留“语义连贯”的正确路径。
- 代价：引入了重采样的噪声，但在热启动阶段更稳定。
理论预测 ：冷启动逃逸时间， q=0q=0 0 时为 Θ(1/p0)\Theta(1/p_0) ​ ) ，而 q=1q=1 1 时仅为 Θ(log⁡(1/p0))\Theta(\log(1/p_0)) ( 1/ p 0 ​ )) 。这意味着提高 qq 能指数级加速冷启动，但也会加速噪声记忆。
### 关键结果：数据不会撒谎作者在 FinQA, HotPotQA, MuSiQue 三个推理基准上进行了验证，结果极具说服力：
1. 冷启动场景（无提示，纯指令）
这是 GARL 的高光时刻。GRPO（一种流行的 RL 变体）在冷启动下完全无法收敛，而 GARL 在 q=0.75q=0.75 0.75 时成功逃逸：

2. 热启动场景（有提示，模型已具备基础能力）
此时 GARL 在部分数据集上因高方差导致训练不稳定（Collapse）。PAFT 展现了其稳定性优势：
- HotPotQA: GARL 在所有 qq 值下均崩溃，而 PAFT (q=0.75q=0.750.75) 取得最佳结果，maj@16 达到 47.9，比 GRPO 的 33.5 高出 +14.4 个点。
- FinQA: 训练稳定，GARL (q=0.25q=0.250.25) 表现最佳，maj@16 为 38.7，优于 GRPO 的 26.9。
### 工程启示- 冷启动首选 GARL (q≈0.75q \approx 0.750.75)：如果你的模型是随机初始化或对齐度极低，不要直接用 RLVR。使用 GARL 并设置较高的 qq 值，利用梯度放大机制强行打破对称性，快速获得初始的成功轨迹。
- 热启动慎用高 qq GARL：一旦模型具备一定能力，高 qq 的 GARL 可能会因为过度关注少数高分样本而导致模式坍塌（Mode Collapse）。此时应切换到低 qq 的 GARL 或转向 PAFT。
- PAFT 是稳定的“兜底”方案：当 RL 训练出现剧烈震荡时，PAFT 通过后验采样过滤噪声，提供了语义连贯的梯度，虽然每一步计算稍慢（需要重采样），但整体训练曲线更平滑，最终性能往往更优。
- qq 是推理时的“温度”模拟：qq 参数在训练时扮演了类似推理温度 τ\tau 的角色。q→0q \to 00 是贪婪解码（Mode-seeking），q→1q \to 11 是均匀覆盖（Mode-covering）。
### 局限与展望论文指出，GARL 和 PAFT 在有限样本下均有偏差，且偏差随 qq 增大而增加。此外，该方法目前仅针对 exact-match 奖励，扩展到更复杂的奖励函数（如代码执行反馈、人类偏好排序）仍是有趣的方向。但无论如何，这篇论文为理解 RL 与 SFT 的统一性提供了坚实的理论框架，并为工程实践提供了可操作的“旋钮”。
