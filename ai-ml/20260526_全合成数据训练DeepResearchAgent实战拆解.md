论文 : QUEST: Training Frontier Deep Research Agents with Fully Synthetic Tasks链接 : https://arxiv.org/abs/2605.24218做 Deep Research Agent（深度研究智能体）最头疼的不是模型够不够聪明，而是怎么让它在长链路搜索中不迷路、不胡扯。这篇来自俄亥俄州立大学和 Amazon AGI 的 QUEST 论文，给出了一个极具工程落地价值的解法：完全依赖全合成数据，通过“规则树（Rubric Tree）”和结构化上下文管理，把开源模型调教成了能媲美甚至超越闭源顶尖系统的通用研究助手。
### 为什么现有的方案不够用？
目前的 Deep Research Agent 大多面临两个死胡同：
- 能力单一：很多开源 Agent 只擅长“事实查找（Fact Seeking）”，比如回答“某本书的作者住在哪里”，一旦遇到需要综合多篇文献、生成结构化报告的“开放型任务（Open-ended Tasks）”，表现就断崖式下跌。
- 训练数据匮乏且难标注：长链路搜索轨迹极难人工标注，现有的合成数据往往只有单一正确答案，缺乏对推理过程、引用准确性等多维度的细粒度奖励信号。
QUEST 的核心洞察是： 与其死磕难以获取的高质量人类标注数据，不如构建一套能自动生成“可验证任务+细粒度评分规则”的合成流水线。
### 核心方法拆解：不仅仅是 SFT + RLQUEST 的训练配方包含三个阶段：中间训练（Mid-Training, MT）、监督微调（SFT）和强化学习（RL）。其真正的设计亮点在于数据合成与上下文管理。
#### 1. 基于规则树（Rubric Tree）的数据合成这是全文最硬核的部分。传统合成数据只有“问题-答案”，QUEST 引入了层级化的 规则树 。
- 设计直觉：一个复杂的研究任务（如“评估苹果折叠屏手机的市场前景”）不能只用一个分数评价。规则树将任务拆解为多个子节点（如指令遵循、全面性、可读性、洞察力），每个叶子节点对应可自动验证的约束（如是否包含特定来源 URL）。
- 工程价值：这解决了 RL 阶段的奖励稀疏问题。模型不再只收到“对/错”的二元反馈，而是获得基于规则树根节点的细粒度分数，甚至能定位到哪个子任务没做好。对于开放型任务，它还引入了参考报告对比机制，计算候选报告相对于参考报告的相对质量得分。
#### 2. 结构化上下文管理（Context Management）
长链路搜索最大的敌人是 Context Window 爆炸和注意力分散。QUEST 没有简单截断历史，而是设计了一个 Context State JSON 结构，将历史信息压缩为三类：
- Trusted：已验证的事实，可直接复用，无需重复搜索。
- Untrusted：被其他来源证伪的声明，标记原因并降权。
- Uncertain：待验证的线索，附带后续行动建议（如重新搜索）。
这种设计让 Agent 在每次上下文压缩后，能带着“知识状态”重启，而不是从零开始，极大提升了长程推理的连贯性。
#### 3. 三阶段训练流水线- MT (Mid-Training)：专门训练模型理解 Context State 结构，并从嘈杂 HTML 中提取相关信息。这一步不需要额外标注数据，直接利用合成过程中的副产品。
- SFT (Supervised Fine-Tuning)：使用教师模型（Tongyi DeepResearch）生成的轨迹进行模仿学习。关键创新是按“会话（Session）”切分训练单元，即两次上下文压缩之间的交互片段，使训练分布与推理时的有效工作窗口对齐。
- RL (Reinforcement Learning)：采用 GRPO 算法，奖励函数由 0.75 * 规则树得分 + 0.25 * 事实核查得分 组成。事实核查得分为引用 URL 的有效率，且被规则树得分上限约束，防止模型为了刷引用而生成垃圾内容。

### 工程启示与局限对工程师的启发：
- 奖励函数设计比模型规模更重要：QUEST 证明了通过精心设计的规则树和事实核查奖励，可以用较少的合成数据（仅 8K 任务用于 SFT/RL）撬动高性能。
- 上下文压缩是长程 Agent 的标配：不要指望无限长的 Context Window 能解决所有问题，结构化的状态记忆（Trusted/Uncertain）才是保持推理一致性的关键。
- 异步基础设施至关重要：论文提到 RL 训练中的评估耗时极长（平均 4 分钟，最长 30 分钟），他们通过完全异步的 Rollout-Evaluation-Training 流水线消除了瓶颈。这在工程落地时是必须考虑的成本点。
局限与展望：
- 小模型在开放型任务上仍吃力：2B/4B 模型在报告合成上表现远不如事实查找，说明知识综合能力对参数规模仍有依赖。
- 合成数据的偏见风险：虽然使用了自动验证，但规则树本身由 LLM 生成，可能存在系统性偏差。
QUEST 不仅是一个 SOTA 模型，更是一套可复现的 Deep Research Agent 训练范式。对于想要构建私有化、高可靠性研究助手的团队来说，其开源的代码、数据和脚本具有极高的参考价值。
