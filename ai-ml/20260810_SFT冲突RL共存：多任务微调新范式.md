论文 : SFT Conflicts, RL Coexists: A Theoretical and Empirical Analysis of Multi-Task Learning for LLMs链接 : https://arxiv.org/abs/2608.03573如果你正在尝试让大模型同时掌握数学、代码和逻辑推理，这篇论文可能会颠覆你的微调直觉。它揭示了一个被长期忽视的工程事实：监督微调（SFT）在多阶段训练中会导致灾难性的性能崩塌，而强化学习（RL）却能实现能力的稳定叠加。这不仅仅是算法优劣的问题，更是参数更新几何性质的根本差异。
## 痛点：为什么多阶段 SFT 会失效？
在构建全能型 LLM 时，我们通常面临两种策略：混合数据训练（Mixed-Data）或多阶段训练（Multi-Stage）。
直觉上，SFT 应该能像 RL 一样，通过分阶段学习不同任务来逐步增强能力。然而，论文实验给出了残酷的现实：
- 多阶段 SFT：性能平均下降 23.1%，甚至低于基线模型。
- 多阶段 RL：性能平均提升 24.9%，实现稳定增长。
这种巨大的反差引出了核心问题：为什么 SFT 在学新任务时会“遗忘”旧能力（SFT Conflicts），而 RL 却能做到“兼容并蓄”（RL Coexists）？
## 核心 Insight：正交更新与方差限制作者深入参数层级，发现了两种范式在梯度方向上的本质区别。
1. SFT 的冲突源于“范数限制”
SFT 是 Off-policy 学习，模型必须拟合外部专家分布。这导致参数更新向量（ ΔW\Delta W ）具有巨大的绝对范数（Norm）。不同任务的 SFT 更新方向高度重叠，甚至相反。例如，Math 和 Code 任务的梯度余弦相似度高达 10−110^{-1} 级别。这种密集的、大范围的参数扰动，直接破坏了模型在其他任务上已形成的优化景观。
2. RL 的共存源于“方差限制”
RL（特别是 GRPO）是 On-policy 学习，且引入了 Advantage 函数。这带来了两个关键特性：
- 稀疏性：RL 更新极其微小，平均范数比 SFT 小两个数量级（3×10−23\times10^{-2}10−2 vs 7.47.4）。
- 正交性：Advantage 函数的零和性质过滤掉了梯度的均值部分，只保留组内残差。由于不同任务的数据分布独立，这些微小的残差向量在高维空间中几乎完全正交（余弦相似度 ∼10−5\sim 10^{-5}10−5）。
⚠️ 反直觉发现 ：RL 之所以能多任务共存，不是因为它更“聪明”，而是因为它更新得更“克制”。它只在极小的参数子空间内做微调，且不同任务的微调方向互不干扰。
## 关键结果：Parallel-RL 的工程价值基于“RL 更新近似正交”这一理论洞察，作者提出了 Parallel-RL 范式。与其串行训练或混合训练，不如让不同任务并行独立训练，最后合并参数。

## 工程启示对于正在构建多模态或多技能 Agent 的工程师，这篇论文提供了明确的指导：
- 慎用多阶段 SFT：如果你需要分阶段注入不同领域的知识，SFT 会导致严重的负迁移。除非使用复杂的正则化手段，否则混合数据训练仍是 SFT 的唯一解。
- 拥抱 RL 的正交性：RL 不仅是提升推理能力的手段，更是多任务学习的天然解耦器。利用 RL 进行并行微调（Parallel-RL），可以大幅缩短训练周期，并避免任务间的相互干扰。
- 合并策略的选择：简单的参数相加（Sum）在 RL 场景下已经足够有效。如果追求极致性能，可以在合并后加入少量的适配数据（Adaptation），以极低的成本换取额外的性能增益。
## 局限与展望目前 Parallel-RL 主要验证于推理密集型任务（Math, Code, Logic）。对于需要大规模知识记忆的任务（如开放域 QA），RL 的正交性假设是否依然成立仍需验证。此外，如何自动判断哪些任务适合并行训练、哪些必须串行，也是未来工程落地的关键挑战。
