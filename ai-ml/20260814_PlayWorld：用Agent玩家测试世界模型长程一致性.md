# ⭐⭐⭐⭐ PlayWorld：用 Agent 玩家测试世界模型长程一致性

**日期**: 2026-08-14

---

论文 : PlayWorld: Benchmarking World Models with Long-Horizon Objectives链接 : https://arxiv.org/abs/2608.13552现有的世界模型（World Models）评测大多像“开卷考试”：给定固定轨迹，看视频是否崩坏。但这完全偏离了真实场景——人类玩家是在动态交互中探索世界的。PlayWorld 提出了一个极具工程价值的思路：引入多模态 Agent 作为“玩家”，在长程目标下自适应调整操作，从而公平地评估不同模型的真实物理与几何一致性。
### 为什么现有评测失效？
传统基准（如 WorldScore, MemoBench）依赖预定义的相机轨迹或动作序列。这导致两个致命问题：
- 粒度不匹配：不同模型对同一指令（如“右转”）的响应幅度不同，固定轨迹可能导致一个模型转了 360 度，另一个只转了 90 度，使得几何一致性得分无法横向对比。
- 缺乏闭环反馈：真实交互中，玩家会根据视觉反馈实时调整（如“没看到目标，继续走”）。固定脚本无法模拟这种适应性，也无法评估模型在复杂长程任务中的状态维持能力。
### 核心设计：Agent Player 的闭环控制PlayWorld 的核心创新在于引入了 Agent Player 。它不是从头规划轨迹，而是基于人类标注的基础动作序列（Basic Action Sequence）进行在线自适应调整。
- 决策机制：Agent 观察生成的帧和历史动作，做出五种决策：Keep（保持）、Stop（提前停止）、Extend（延长持续时间）、Correct（修正下一步）、End（结束）。
- 设计直觉：完全在线规划（Agent Only）延迟高且轨迹差异大；纯预设脚本（Preset Only）无法适配不同模型的响应特性。Preset + Agent 策略在保持评测意图一致性的同时，允许针对模型特性微调执行时长和路径。实验显示，该策略在 Genie 3 上的人均偏好得分达到 65.6%，远超纯预设的 39.6%。
### 四大核心维度与关键发现PlayWorld 包含 171 个场景，覆盖四个核心能力维度，并引入了基于 VQA 的规则验证器（Rubric Verifier）进行打分（1-5 分）：
- 几何一致性（Geometry Consistency）：测试相机旋转或移动后，环境结构（如建筑、文字）是否保持不变。
- 交互保真度（Interaction Fidelity）：测试物理交互，如走进水中是否有涟漪、碰撞墙壁是否穿透。
- 视野外演化（Out-of-sight Evolution）：测试目标移出视野后，其状态是否合理演化（如苹果皮是否继续增加）。
- 洞察演化（Insight Evolution）：静态观察长时场景变化（如排队人群的自然流动）。

### 工程启示- 评测即应用：PlayWorld 的 Agent Player 架构可直接复用于自动化测试其他交互式生成模型。开发者无需手动编写复杂脚本，只需定义高层目标（Objective），Agent 即可自动探索边界情况。
- 关注长程一致性：在优化世界模型时，不要只盯着前几帧的画质。论文指出，当前瓶颈在于“持续的世界演化”。训练数据应增加包含长时间因果逻辑的视频片段，而不仅是短时的动作响应。
- 闭环控制的必要性：对于任何交互式生成系统，固定输入输出的评测都是片面的。引入基于视觉反馈的动态调整机制，是衡量模型真实可用性的唯一途径。
PlayWorld 不仅是一个基准，更是对当前世界模型技术边界的一次清醒审视：我们离真正的“开放世界”模拟，还有很长的路要走。
