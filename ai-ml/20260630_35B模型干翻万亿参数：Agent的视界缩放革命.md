论文 : Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent链接 : https://arxiv.org/abs/2606.30616在 Agent 领域，我们常陷入一个误区：以为只有把模型参数堆到万亿级别，才能搞定复杂的长程任务。上海人工智能实验室的这篇新作直接打破了这个“参数量迷信”。他们用仅 35B 参数的混合专家（Mixture-of-Experts, MoE）模型 Agents-A1，在多项长视界基准测试中追平甚至超越了 Kimi-K2.6 和 DeepSeek-V4-pro 等万亿参数巨头。
这不仅仅是性能的胜利，更是工程范式的转变： 从“缩放参数”转向“缩放视界” 。
### 痛点：为什么大模型做不好长程任务？
现有的 Agent 训练主要面临两个瓶颈：
- 缺乏过程监督：公开语料只有最终答案，没有中间的动作、观察和验证信号。模型像是在黑盒里猜谜，无法从失败中吸取教训。
- 能力冲突：搜索、编码、科学推理等不同领域的专家能力难以融合。强行塞进一个大模型，往往导致“样样通，样样松”，或者出现灾难性遗忘。
### 核心 Insight：知识-动作图（KAG）与多教师蒸馏Agents-A1 的核心创新在于构建了一套 长视界知识-动作基础设施 。
#### 1. 知识-动作图（Knowledge-Action Graph, KAG）
传统知识图谱只存实体关系，而 KAG 记录的是 过程 。它将证据、动作、观察和验证结果链接起来，形成平均长度达 45K tokens 的轨迹。
- 原子能力分解：将复杂任务拆解为信息获取、工具调用、可执行迭代、证据验证和约束跟踪五个原子能力。
- 自我博弈扩展：通过“提议者-求解者-验证者”的游戏机制，自动生成高质量的多步交互数据。只有当轨迹具备可验证性、过程信息丰富且无捷径时，才会被保留。
#### 2. 三阶段训练流水线- 全领域监督微调（SFT）：基于 Qwen3.5-35B-A3B，对齐广泛的 Agent 行为。
- 领域教师模型训练：针对搜索、机器学习工程（MLE）、科学推理等六个异构领域，分别训练专家教师模型。
- 多教师在线策略蒸馏（OPD）：这是最关键的一步。通过显著词汇对齐（Salient Vocabulary Alignment, SVA），将不同领域的专家知识无损地蒸馏到一个统一的 35B 学生模型中。SVA 只关注教师分布中的高概率词汇子集，避免了跨域推理模式的冲突。
### 关键结果：小马拉大车Agents-A1 在长视界任务上的表现令人震惊，以下是与万亿参数模型的对比数据：

### 工程启示：如何落地？
- 数据重于模型规模：如果你的应用涉及复杂工作流，不要盲目追求更大的基础模型。构建包含工具调用、代码执行和验证信号的过程级数据，才是提升 Agent 能力的捷径。
- 模块化训练优于端到端：对于多领域任务，先训练领域专家教师，再通过蒸馏融合，能有效解决能力冲突问题。SVA 技术值得在微调中借鉴，它能让模型更专注于关键决策点。
- 验证即监督：在 Agent 系统中，引入自动验证器（Verifier）并将其反馈写入训练数据，能显著提升模型的自我纠错能力。
### 局限与展望论文也指出，当前方法依赖于构建复杂的 KAG 基础设施，这在通用场景下可能成本较高。此外，虽然 Agents-A1 在长视界任务上表现优异，但在一些需要极强常识或即时响应的短对话场景中，可能仍不如经过大规模预训练的巨型模型流畅。
未来，随着“视界缩放”技术的成熟，我们可能会看到更多中小参数模型通过强化过程监督，在垂直领域超越通用大模型。 对于工程师而言，现在就是开始构建高质量 Agent 轨迹数据的好时机。
