论文 : Unlocking Feature Learning in Gated Delta Networks at Scale链接 : https://arxiv.org/abs/2606.04048大模型训练最烧钱的地方，往往不是算力本身，而是每次调整模型宽度都要重新做超参数搜索。对于线性注意力架构如 Gated Delta Network (GDN)，这一痛点尤为突出。这篇来自 UCLA 的论文提供了一个关键解法：通过推导最大更新参数化（Maximal Update Parametrization, µP），实现了学习率在不同宽度模型间的零样本迁移，直接省去了昂贵的调参成本。
### 为什么标准方法行不通？
线性模型（如 Mamba、DeltaNet）正在挑战 Transformer 的统治地位，因为它们能提供 O(1)O(1) 的推理复杂度。然而，现有的参数化理论主要针对前馈神经网络设计。
当我们将模型宽度扩展时，标准参数化（Standard Parametrization, SP）会导致网络陷入“懒惰训练”（Lazy Training），即特征表示几乎不更新，导致无法学习新特征。虽然 µP 理论解决了 Transformer 的这一问题，但 GDN 拥有复杂的循环状态更新机制和门控结构，直接套用旧的公式会导致梯度爆炸或消失。
### 核心 Insight：非对称的门控缩放律论文的核心贡献在于严格推导了 GDN 在前向传播中的坐标尺度（Coordinate Size）。作者发现，GDN 的投影权重和门控权重在训练动态上存在本质差异。
关键发现 ：在 SGD 优化器下，门控权重矩阵 WαW_\alpha ​ 和 WβW_\beta ​ 的学习率缩放律必须设为 Θ(1/d)\Theta(1/\sqrt{d}) ​ ) ，而标量参数 aloga_{log} ​ 和 bb 则需要 Θ(d)\Theta(\sqrt{d}) ​ ) 。这与标准 µP 中所有权重统一缩放的直觉完全相悖。
这种差异源于门控机制对梯度的非线性影响。如果强行使用统一的学习率，随着宽度增加，门控参数要么更新过慢导致无法激活，要么更新过快破坏状态稳定性。论文通过详细的梯度分解证明，只有采用这种非对称的缩放策略，才能保证特征更新量 ∥Δh∥2\|\Delta h\|_2 ​ 在无限宽极限下保持有界且非零。
### 实验验证：零样本迁移成真作者在 FineWeb-Edu 数据集上进行了预训练实验，对比了 SP、原始 µP 和本文提出的新 µP 配置。模型宽度从 256 扩展到 1536（参数量约 21M 至 342M）。
优化器 配置方式 最佳学习率表现 AdamW 标准参数化 (SP) 随宽度显著漂移，无法迁移 本文 µP 完美零样本迁移 ，各宽度最优 LR 一致 SGD 原始 µP 表现不稳定，方差大 本文 µP 完美零样本迁移 ，各宽度曲线重合实验结果显示，在使用本文推导的 µP 配置时，无论是 AdamW 还是 SGD，小模型（Width=256）找到的最佳学习率可以直接用于大模型（Width=1536），验证损失曲线几乎完全重叠。这证明了理论推导的工程有效性。
### 工程启示与局限对于正在探索线性注意力架构的工程师来说，这篇论文的价值在于提供了一套“开箱即用”的初始化与调参指南。你不再需要为每个新宽度的 GDN 模型重新跑 Grid Search，只需按照论文给出的表格设置初始方差和学习率缩放因子即可。
不过需要注意，目前的推导基于“短有效记忆长度”（Short effective memory length）假设。如果模型在长文本场景下表现出极慢的遗忘速度（即 αt→1\alpha_t \to 1 ​ → 1 ），BPTT 尾部梯度可能会累积，此时可能需要根据有效记忆长度 LeffL_{eff} ​ 进一步调整学习率。此外，论文主要关注预训练阶段的特征学习，对于下游任务的微调（Fine-Tuning）是否适用同样的缩放律，仍需社区进一步验证。
