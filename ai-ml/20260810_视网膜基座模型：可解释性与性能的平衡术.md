**日期**: 2026-08-10

论文 : Towards Interpretable Foundation Models for Retinal Fundus Images链接 : https://arxiv.org/abs/2603.18846在医疗影像领域，“黑盒”诊断是悬在头顶的达摩克利斯之剑。医生不仅要知道模型判了什么，更要知道它 为什么 这么判。这篇论文提出的 Dual-IFM 试图解决一个核心矛盾：如何在保持基座模型（Foundation Model）强大泛化能力的同时，提供原生的、可信的可解释性。
### 痛点：事后归因的不可靠性现有的视网膜基座模型如 RETFound 性能强劲，但缺乏内置的解释机制。工程师通常依赖 Grad-CAM 或 LRP 等**事后归因（Post-hoc Attribution）**方法生成热力图。然而，研究表明这些局部解释往往与模型真实的决策过程脱节，甚至产生误导性的高亮区域。
此外，理解高维表示空间的全局结构也是难题。常用的 t-SNE 是非参数化的，每次加入新数据都需要重新拟合，这在大规模临床部署中计算成本极高且无法实时响应。
### 核心设计：双管齐下的可解释性Dual-IFM 的设计直觉非常清晰： 与其事后修补，不如原生构建。 它通过两个关键组件实现了这一目标：
-BagNet 骨干网络（局部可解释性）
设计逻辑：传统 CNN 的感受野随层数加深迅速扩大，导致特征与输入像素的对应关系模糊。BagNet 限制每个空间位置的感受野仅为一个小 patch（如 33×3333 \times 3333 像素）。
- 效果：这意味着特征图中的每一个点只依赖图像的局部区域。当我们在最后添加分类头时，生成的“类证据图”直接反映了哪些局部区域对预测贡献最大。这不是近似解释，而是模型决策的内在组成部分。
-t-SimCNE 预训练（全局可视化）
设计逻辑：在自监督对比学习（SSL）中引入一个参量的 2D 投影层。不同于 SimCLR 使用 128D 投影，Dual-IFM 直接学习将高维嵌入映射到 2D 空间。
- 优势：这使得模型能够直接将新图像嵌入到已学习的 2D 表示空间中，无需像 t-SNE 那样重新计算全局结构。这为数据集级别的异常检测和语义聚类提供了实时视图。
### 关键结果：小模型击败大巨头？
最让人惊喜的是，Dual-IFM 仅使用 18.3M 参数，却能在多项任务上与拥有 303.3M 参数的 RETFound（ViT-Large）抗衡，甚至超越。
指标 Dual-IFM (BagNet-33) RETFound (ViT-Large) 参数量 18.3M 303.3M 推理延迟 (V100) 81 ms / batch 140 ms / batch 显存占用 1.12 GB 1.31 GB 预训练数据量 802,360 张 ~1.6M 张在具体的下游任务表现上（线性探针 Linear Probing）：
- EyePACS (DR检测): Dual-IFM AUC 达到 0.849，显著高于 RETFound 的 0.794。
- AREDS (AMD分类): Dual-IFM AUC 为 0.919，略高于 RETFound 的 0.871。
- 可解释性精度: 在 IDRiD 数据集上，Dual-IFM 的证据图与真实病灶的重合度（Precision）为 0.674，而 RETFound 使用 LRP 方法仅为 0.384。
⚠️ 反直觉发现 : 尽管 BagNet 参数量少，但由于其保留了高分辨率的空间特征图，其显存占用并不低（1.12 GB），接近巨大的 ViT-Large。这意味着“轻量化”不等于“低资源消耗”，工程部署时需关注内存带宽而非仅看 FLOPs。
### 工程启示与落地建议- 医疗场景首选原生可解释模型：如果业务强依赖医生审核，Dual-IFM 的 BagNet 架构比 RETFound + Grad-CAM 更值得信赖。证据图是决策过程的一部分，而非事后贴皮。
- 2D 投影用于数据质检：利用 t-SimCNE 学习的 2D 投影层，可以在推理时快速将新病例映射到全局空间。如果某个样本落在已知疾病簇之外，可作为潜在的新型病变或标注错误进行人工复核。
- 微调策略：论文指出，微调后编码器表示会发生漂移，导致 2D 投影失效。建议在微调后仅重新训练投影头（Projector），这是一个计算成本极低的操作，即可恢复可视化的准确性。
### 局限与展望Dual-IFM 目前仅针对彩色眼底照片（CFP）。BagNet 的小感受野设计虽然利于可解释性，但在捕捉长距离依赖（如血管拓扑结构）上可能不如 Transformer。未来工作可能需要探索多模态扩展或混合架构，以平衡局部细节与全局上下文。
对于医疗 AI 工程师而言，这篇论文提供了一个清晰的范式： 在高风险领域，可解释性不应是附加功能，而应是模型架构的第一性原理。
