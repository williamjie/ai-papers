# ⭐⭐⭐½ 扩散模型时间切分：从暴力搜索到数学平衡

**日期**: 2026-06-05

---

论文 : Complexity-Balanced Diffusion Splitting链接 : https://arxiv.org/abs/2606.06477如果你正在部署大型扩散模型，一定遇到过这个尴尬：为了提升画质，我们无脑堆参数，导致推理延迟爆炸；但如果把大模型拆成几个小专家（Expert），怎么切分时间步长（Timestep）就成了玄学。
这篇来自耶路撒冷希伯来大学的工作提出了一种名为 复杂度平衡切分（Complexity-Balanced Splitting, CBS） 的方法。它不靠试错，而是用近似理论中的“等分布原理”，算出哪里最难学，就在哪里多给算力。
### 痛点：单一大模型的低效与切分的盲目性目前的扩散模型（Diffusion Models）通常是一个单体架构（Monolithic Architecture），从纯噪声到清晰图像，全程由同一个大网络处理。
这很不经济。去噪过程早期是粗结构形成，后期是高频细节修复，不同阶段的“难度”截然不同。用同一套巨大算力覆盖所有阶段，显然是浪费。
现有的解决方案是训练多个子网络，每个负责一段时间段。但问题来了： 切分点定在哪？
- 以前的做法：凭经验均匀切分（如 0.33, 0.66），或者通过昂贵的网格搜索去试错。
- 后果：缺乏理论依据，效率低下，且难以泛化到不同架构。
### 核心 Insight：让每个子网络承担相等的“认知负担”
CBS 的核心直觉来自 de Boor 的等分布原理（Equidistribution Principle） 。
在样条近似理论中，为了最小化最大误差，节点应该密集分布在函数变化剧烈的区域，稀疏分布在平滑区域。
作者将这个思想迁移到扩散模型的时间轴上：
- 定义一个监控函数 m(t)m(t)，用来量化每个时间步的局部近似难度（Approximation Burden）。
- 将时间轴切分成 NN 段，使得每段的 ∫m(t)dt\int m(t) dt 相等。
- 结果：复杂的阶段被切得更细，分配给专门的子网络；简单的阶段切得粗，节省算力。
### 方法拆解：如何量化“难度”？
论文提出了两种可计算的监控函数，用来估算 m(t)m(t) ：
-空间复杂度：Dirichlet 能量基于 Barron 定理，函数的近似误差与其频谱复杂度相关。
- 作者用流场的 Dirichlet 能量（即梯度的平方积分）作为代理指标。能量越高，说明空间变化越剧烈，网络越难拟合。
- 工程技巧：通过随机迹估计器（Randomized Trace Estimators）高效计算高维 Jacobian，避免显式构建巨大矩阵。
-几何复杂度：路径加速度（Path Acceleration）
关注采样轨迹的几何形状。一阶导数是速度，二阶导数是加速度。
- 加速度反映了轨迹的“弯曲程度”。直线运动简单，剧烈转弯复杂。
- 直觉：这直接对应了 ODE 求解中的局部截断误差来源。
⚠️ 关键发现 ：虽然两种方法都有效，但实验表明 路径加速度（Acceleration） 作为监控函数效果更好。因为它更直接地衡量了最终采样轨迹的准确性，而 Dirichlet 能量只关注流场本身，忽略了积分过程的累积误差。
### 实验结果：零成本提升画质作者在 SiT、JiT 和 UNet 三种架构上进行了广泛测试。最核心的优势是： 不增加单步推理成本（Per-step FLOPs），只增加总参数量。
以下是 ImageNet-256 上 SiT-XL/2 的对比数据（Table 1）：
模型配置 FID (无 CFG) ↓ FID (有 CFG) ↓ Monolithic Baseline 18.04 6.53 Naive Split (0.33, 0.66) 17.97 6.24 CBS Ours (0.4, 0.77) 15.81 4.03- 无 CFG 时：FID 从 18.04 降至 15.81，提升约 12%。
- 有 CFG 时：FID 从 6.53 降至 4.03，提升高达 38%（论文摘要称 ~35%）。
这意味着，在保持单步推理速度不变的前提下，通过更聪明的切分，画质有了质的飞跃。特别是在使用 Classifier-Free Guidance (CFG) 时，由于引导项引入了更复杂的空间梯度，CBS 的优势被进一步放大。
### 工程启示：如何落地？
- 无需昂贵搜索：你不需要训练多个大模型去试错切分点。
- 轻量级辅助模型即可：论文证明，用一个小型网络（如 SiT-S/2），在少量数据（10% ImageNet）上训练极少步数（50K iterations），就能估算出非常准确的复杂度曲线和切分点。
- 即插即用：CBS 是一种训练策略。一旦确定了切分点，你可以独立训练各个子网络。推理时，根据时间步切换对应的模型权重即可。
这对于端侧部署或云端 API 服务非常有价值：你可以在不增加峰值内存占用的情况下，通过“时间换空间”的策略，获得接近更大模型的生成质量。
### 局限与展望- 当前仅限时间切分：论文提到未来可以扩展到空间切分（Spatial Splitting），即不同 token 路由到不同网络，但这需要定义新的监控函数。
- 依赖辅助模型：虽然辅助模型很轻，但仍需额外的预计算步骤。对于快速迭代的小项目，可能略显繁琐。
总的来说，CBS 为扩散模型的容量分配提供了一个数学上严谨、工程上可行的新范式。它告诉我们： 不要均匀地撒胡椒面，要把算力用在刀刃上。
