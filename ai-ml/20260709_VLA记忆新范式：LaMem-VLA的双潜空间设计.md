论文 : Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation链接 : https://arxiv.org/abs/2607.07608现有的视觉-语言-动作（Vision-Language-Action, VLA）模型大多基于马尔可夫假设，只盯着“当前这一帧”做决策。这导致它们在长周期任务中经常“失忆”，无法理解之前的操作进度。LaMem-VLA 提出了一种将历史记忆直接编织进模型潜空间（Latent Space）的新架构，解决了传统外挂式记忆的痛点。
### 为什么现有的记忆机制不够用？
目前处理 VLA 记忆主要有两种思路：一是直接拼接历史帧或视频序列，二是从外部记忆库检索历史作为策略的辅助上下文。
这两种方案都有明显的工程缺陷：
- 计算开销爆炸：拼接历史帧会导致上下文窗口无限增长，显存和推理延迟随时间线性增加。
- 割裂的推理过程：外挂式记忆（External Memory Conditioning）是在 VLA 完成多模态推理后，才作为辅助条件输入策略头。这意味着记忆无法参与模型内部的感知、指令理解和动作意图形成，导致“想”和“记”是两回事。
LaMem-VLA 的核心洞察是： 机器人的历史经验应该被视为原生上下文（Context-Native Latent Memory），与当前观测、语言指令在同一个连续的潜嵌入空间中进行交互。
### 方法拆解：双潜记忆架构LaMem-VLA 设计了四个协同模块，将记忆从“外挂”变成了“内嵌”：
-策展人（Curator）：维护两个互补的记忆库。
短期记忆库：存储视觉感知证据（如物体位置、细微状态变化），通过 SE-bottleneck 压缩当前视觉 Token。
- 长期记忆库：存储动作隐藏状态，追踪任务进度和动作连续性。
- 关键设计：当记忆库满时，通过余弦相似度合并相邻冗余单元，保持容量恒定（L=16L=1616）。
-搜寻者（Seeker）：基于当前的多模态认知状态（视觉+指令）构建查询向量 QtconQ^{con}_tcon​，从两个库中检索最相关的 Top-K 证据。这确保了记忆提取是任务驱动的，而非盲目读取。
-压缩器（Condenser）：这是防止上下文膨胀的关键。检索到的原始证据往往冗长且未对齐，压缩器将其重构为固定长度的潜记忆 Token（短期 Ls=8L_s=8​=8，长期 Ll=4L_l=4​=4）。这使得注入的记忆与 VLA 的嵌入空间完全兼容。
-编织者（Weaver）：将压缩后的记忆 Token 直接拼接到当前图像和指令之前，形成统一的输入序列 St=[Mshort;Mlong;Xt;I;Qaction]S_t = [M^{short}; M^{long}; X_t; I; Q^{action}]​=[Mshort;Mlong;Xt​;I;Qaction]。
⚠️ 核心差异 ：传统方法是将检索结果作为外部条件（Conditioning）；LaMem-VLA 是让记忆 Token 参与自注意力机制（Self-Attention），与当前观测共同生成动作查询。

### 工程启示与局限对于正在落地 VLA 模型的工程师，这篇论文提供了两个关键指导：
- 固定长度上下文的重要性：通过 Condenser 将可变长度的历史压缩为固定数量的 Token，可以在不牺牲推理速度的前提下引入长期记忆。这在实时控制场景中极具价值。
- 记忆的粒度分离：短期视觉细节和长期语义进度需要分开存储和处理。混合在一起可能导致关键信息被稀释。
局限性 ：目前验证仅在仿真环境中进行，真实世界的物理噪声和延迟尚未测试。此外，检索模块引入了额外的计算步骤，虽然压缩器减轻了负担，但在高频控制下仍需评估端到端延迟。
LaMem-VLA 证明了将记忆“内化”到模型潜空间是解决 VLA 长周期依赖的有效路径，为构建更智能的具身智能体提供了新的架构参考。
