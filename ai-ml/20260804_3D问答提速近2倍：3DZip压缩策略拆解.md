### 痛点：为什么现有的压缩方法在 3D 领域失效？
目前的 3D VLMs（如 LLaVA-3D）通常将多视角的 2D 视觉特征投影到世界坐标系中。这带来了两个层面的严重冗余：
- 点级别冗余：同一物理表面被多个视角重复观测，导致空间位置上几乎重合的 Token 大量堆积。
- 对象级别冗余：这是更隐蔽的问题。一个大物体（如沙发）的不同表面区域会产生大量 Token，即使经过空间聚合，这些 Token 依然分散在物体的不同几何位置上。
⚠️ 反直觉发现 ：论文指出，仅靠基于空间的采样策略（如 XYZ-DPP），Token 会过度集中在少数大物体上，导致对象覆盖率仅为 51%。相比之下，基于特征多样性的选择能将覆盖率提升至 70%。这意味着， 空间距离近不代表语义冗余，特征差异才是关键。
### 方法拆解：3DZip 的三阶段压缩逻辑3DZip 的设计非常克制且逻辑严密，分为三个阶段逐步去重：
1. 粗略体素化（Coarse Voxelization）
首先解决“点级别冗余”。通过设定体素大小（如 δ=0.2m\delta=0.2m 0.2 m ），将空间位置相近的 Token 进行平均池化。这一步能快速剔除多视角带来的重复观测，大幅减少 Token 基数。
2. 特征多样性引导的锚点选择（Feature-Diversity Guided Anchor Selection）
这是核心创新点。在体素化后的 Token 集中，使用行列式点过程（Determinantal Point Process, DPP）选择 KK 个“锚点”。
- Why DPP?：DPP 能够最大化选中集合的特征多样性，确保选出的锚点代表场景中语义截然不同的物体，避免 Token 集中在同一类背景或大物体上。
3. 空间约束下的 Token 合并（Spatially-Constrained Token Merging）
剩下的非锚点 Token 并非直接丢弃，而是根据特征相似度分配给最近的锚点。
- 关键约束：只有当非锚点与锚点的网格空间距离小于阈值 τg\tau_g​ 时，才允许合并。这保证了语义补充不会破坏几何结构的一致性。

### 工程启示- 别迷信空间聚合：在处理 3D 点云或体素数据时，如果直接按空间距离聚类，可能会丢失细粒度的物体区分度。引入特征空间的多样性约束是必要的补充。
- 分步去重更稳健：先做粗粒度的空间聚合（降低计算量），再做细粒度的语义选择，最后做几何一致性合并。这种“漏斗式”设计比端到端的压缩更容易调试且效果更佳。
- 适用场景：该方法特别适用于对延迟敏感且需要保留空间推理能力的具身智能 Agent，例如需要在复杂室内环境中快速定位物体的机器人。
### 局限与展望论文也诚实地指出了局限性：粗粒度体素化可能会模糊小物体的边界；且超参数（如体素大小 δ\delta ）目前是固定的，未根据场景复杂度自适应调整。未来若能实现基于场景密度的动态压缩，效果或许会更好。
