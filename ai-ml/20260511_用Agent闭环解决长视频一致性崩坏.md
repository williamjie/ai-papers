# 用Agent闭环解决长视频一致性崩坏

**日期**: 2026-05-11

---

长视频生成的核心痛点不是“画得美”，而是“记得住”。A^2RD 提出了一个无需训练的 Agent 闭环架构，通过多模态记忆和层级自改进，将长视频生成从“开环瞎猜”变成了“闭环纠错”，在一致性上大幅超越了现有基线。
## 问题与动机：开环生成的“遗忘症”
目前的长视频生成主流方案分为两类：基于帧的自回归（Frame-based AR）和基于片段的生成（Segment-based）。
前者（如 Rolling KV Cache）虽然局部连贯，但一旦早期帧出错，错误会无限累积，导致语义漂移（Semantic Drift）。后者（如 SAR）虽然叙事控制力更强，但片段间的衔接往往生硬，且缺乏跨片段的实体一致性追踪。
A^2RD 的核心洞察是： 长视频生成不应是单向的流水线，而应是一个“检索-生成-反思-更新”的闭环过程。 既然扩散模型在长视野下容易“断片”，那就引入一个“记忆系统”和一个“纠错 Agent”来强制维持一致性。
## 方法拆解：A^2RD 的三大支柱A^2RD (Agentic AutoRegressive Diffusion) 完全无需微调，其威力来自推理时的架构设计。
### 1. 多模态视频记忆 (MVMem)
传统方法只存参考图，A^2RD 建立了一个结构化的记忆库，包含三个维度：
- 文本状态 (Textual States)：不仅记录“有什么”，还记录“发生了什么”。通过 MLLM 提取实体身份、空间关系三元组、相机轨迹等结构化信息。
- 关键帧 (Frames)：存储全局参考背景和每段的起止帧。
- 视频片段 (Videos)：存储已生成的片段，用于后续的动作连续性校验。
这种设计让 Agent 不仅能“看”到画面，还能“理解”画面的逻辑状态（比如：主角的衣服从红变蓝了）。
### 2. 自适应片段生成 (Adaptive Segment Generation)
这是解决“连贯性”与“进展性”矛盾的关键。
- 外推 (Extrapolation)：只基于起始帧生成，适合场景连续、无跳切的情况。
- 插值 (Interpolation)：基于起始帧和结束帧生成，适合场景切换或需要强一致性的情况。
A^2RD 的 Agent 会根据剧情上下文，动态选择模式。如果下一段是同一场景的延续，就用外推；如果涉及环境跳变，就强制插值，从而避免外推导致的细节丢失。
### 3. 层级测试时自改进 (HITS)
这是本文最硬核的工程创新。传统方法生成完就结束，A^2RD 引入了 HITS (HIerarchical Test-time Self-improvement) ：
- 帧级自改进：生成起止帧后，立即用 MLLM 依据 8 项指标（如实体一致性、空间逻辑）进行评分。如果分数低，通过 MAPO (Memory-Augmented Prompt Optimization) 优化提示词并重绘。
- 视频级自改进：生成完整片段后，再次依据 10 项指标（包括跨片段一致性）评分。若失败，联合优化提示词和边界帧，重新生成。
这意味着，每一段视频在“入库”前都经过了 Agent 的严格审查和修正，极大抑制了误差传播。

## 工程启示- Agent 是提升生成质量的杠杆：在扩散模型能力固定的情况下，通过引入 MLLM 作为“裁判”和“规划者”，可以在推理阶段显著改善输出质量。这种“测试时缩放”（Test-Time Scaling）思路比单纯加大模型参数更具性价比。
- 结构化记忆优于隐式记忆：显式地维护实体状态、空间关系和相机运动，比单纯依赖模型的隐式注意力机制更可靠。这对于需要强剧情逻辑的应用（如广告、教育视频）至关重要。
- 闭环优于开环：生成-验证-修正的闭环流程虽然增加了计算开销，但换来了质量的质变。在允许稍长推理时间的场景下，这是值得的。
## 局限与展望A^2RD 依赖于强大的 MLLM 和 TI2I/TI2V 模型，推理成本较高。虽然 A^2RD-Par 提供了并行版本，但牺牲了部分环境一致性。未来工作可探索更轻量级的记忆压缩方法，以及如何在更长的视频（如 10 分钟+）中保持这种一致性。
