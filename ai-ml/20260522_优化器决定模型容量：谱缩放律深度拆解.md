**日期**: 2026-05-22

论文 : Same Architecture, Different Capacity: Optimizer-Induced Spectral Scaling Laws链接 : https://arxiv.org/abs/2605.21803我们常认为，只要算力和数据够多，优化器（Optimizer）只是个“加速收敛”的工具。但 NYU 的这篇新论文直接打脸了这个直觉： 同样的架构、同样的宽度，换掉优化器，模型内部表征的“有效容量”会发生质的改变。 这不是效率问题，而是几何结构问题。对于追求极致参数效率的工程团队来说，这意味着优化器选择应被提升为与架构设计同等重要的决策维度。
### 痛点：损失相同，不代表“脑子”一样传统 Scaling Laws（缩放律）关注的是验证集 Loss 随规模变化的趋势。现有观点认为，不同优化器之间的差异主要体现在乘法效率因子（Efficiency Factor）上，即收敛速度或常数项差异。
但这留下了一个巨大的盲区： 如果两个模型达到了相同的 Perplexity（困惑度），它们的内部表征结构是否一致？ 论文指出，Loss 匹配绝不意味着几何结构匹配。优化器不仅决定你跑多快，更决定了 FFN（前馈网络）中增加的宽度是如何转化为“可用维度”的。
### 核心洞察：硬秩 vs 软秩，揭示容量真相为了量化这种差异，作者没有看 Loss，而是盯着 FFN 的特征空间谱分布。他们引入了两个关键指标：
- Soft Rank（软秩）：基于 Shannon 熵，衡量特征在多少个方向上分散。
- Hard Rank（硬秩）：基于参与比（Participation Ratio），对主导特征方向更敏感，衡量“真正有效”的维度。
核心 Insight 在于两者的不对称性（Asymmetry）：
如果增加 FFN 宽度，Soft Rank 涨得很快，但 Hard Rank 涨得很慢，说明新增的维度只是产生了“噪声”或弥散的能量，并没有形成强有力的表征方向。
### 关键结果：Muon 完爆 AdamW 的容量利用率在 GPT-2 160M 架构下，固定宽度调度，对比 AdamW、Muon、NorMuon 等优化器，结果令人震惊：
1. 罕见词（TAIL）表征能力的巨大鸿沟语言模型最难学的是低频词。在 TAIL 区域：
- AdamW 的 Hard Rank 缩放指数仅为 βhard=0.44\beta_{hard} = 0.44​=0.44。这意味着 FFN 宽度翻倍，有效主导维度只增加了约 20.44≈1.352^{0.44} \approx 1.35≈1.35 倍。
- Muon 实现了近乎线性的缩放，βhard=1.02\beta_{hard} = 1.02​=1.02。宽度翻倍，有效维度几乎翻倍。
- 差距：Muon 在 hardest regime 下的容量利用率是 AdamW 的 2.3 倍（指数比）。
2. “假性”收敛陷阱有人可能会说：“我让 AdamW 多训一会儿不就行了？”
实验显示，当 AdamW 训练步数加倍（12K steps）以匹配 Dion(1/16) 的 Loss 时：
- AdamW 的 Hard Rank 缩放指数从 0.29 暴跌至 0.03。
- Hard-Soft 不对称性从 +0.37 恶化到 +0.55。
- 结论：延长训练无法弥补优化器几何带来的容量缺陷。AdamW 即使 Loss 达标，其表征结构依然是“虚胖”的，新增宽度未能转化为有效方向。
3. 更新秩（Update Rank）是关键旋钮通过 Dion 优化器控制更新矩阵的秩，发现：
- 当秩分数 r=1/2r=1/21/2 时，接近 Muon 效果 (βhard=0.88\beta_{hard}=0.88​=0.88)。
- 当秩分数降至 r=1/16r=1/161/16 时，Hard Rank 缩放跌至 0.40，重回 AdamW 水平。
- 这说明：正交化更新本身不够，高秩的更新矩阵才是解锁 FFN 宽度的钥匙。

论文对比了增加 Attention Rank（架构改动）和切换优化器的效果。结果显示，换优化器带来的谱缩放变化，在 28/30 的场景下超过了改架构的影响。 如果你在调优模型结构，先确认你的优化器是否锁死了容量上限。
-低频知识建模需关注 Hard Rank：
如果你的应用场景涉及大量长尾实体或罕见指令（如垂直领域 Agent），AdamW 可能在 Loss 上表现尚可，但在表征空间的“硬度”上严重不足。Muon 类优化器能更有效地将 FFN 宽度转化为对罕见 Token 的强表征。
-不要迷信 Perplexity：
在模型压缩或蒸馏时，仅匹配 PPL 可能掩盖内部表征的低效。监控 Hard-Soft Rank 的不对称性，可能是比 Loss 更敏感的“健康指标”。
### 局限与展望目前实验主要在 GPT-2 160M/350M 规模进行，虽然趋势在更大模型上保持一致，但在千亿参数级别的 LLM 中，这种谱缩放律是否依然线性成立仍需验证。此外，Muon 等优化器对显存和计算复杂度的要求更高，工程落地时需权衡收益与成本。
