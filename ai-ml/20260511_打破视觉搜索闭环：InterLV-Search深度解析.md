# 打破视觉搜索闭环：InterLV-Search 深度解析

**日期**: 2026-05-11

---

论文 : InterLV-Search: Benchmarking Interleaved Multimodal Agentic Search链接 : https://arxiv.org/abs/2605.07510在构建多模态大语言模型（MLLM）智能体时，我们常陷入一个误区：只要模型能“看懂”图，就能解决视觉相关问题。然而，现实世界中的信息检索往往不是单次查询，而是 文本与视觉证据的交替迭代（Interleaved Search） 。这篇论文指出了一个被长期忽视的工程痛点：现有的基准测试大多将视觉证据视为“终点”，而忽略了它作为“搜索线索”驱动下一步行动的核心价值。
## 现有方案的盲区目前主流的 multimodal agentic search 基准（如 VisBrowse、BrowseComp-V）存在两个显著缺陷：
- 视觉证据被动化：视觉信息通常仅作为用户输入的初始上下文，或者在找到相关图片后直接用于回答局部问题，被视为答案的终点。
- 缺乏动态引导：真实场景中，一张图片里的细节（如 Logo、地标、文字）往往是触发下一轮搜索的关键线索。现有基准无法评估模型是否具备“视觉控制搜索”的能力。
InterLV-Search 的核心 Insight 在于： 视觉证据不仅是用来回答问题的，更是用来决定“接下来搜什么”的。
## 方法拆解：三级递进的能力评估为了量化这种“交互能力”，作者设计了三个难度递增的 Level，这不仅是数据集划分，更是对 Agent 能力栈的解构。
### Level 1：主动视觉证据寻求 (Active Visual Evidence Seeking)
这是基础能力。模型需要根据文本描述，反向寻找对应的视觉证据。
- 构造逻辑：基于 MMKG-W 知识图谱，生成“隐式实体搜索”+“细粒度 VQA”的组合。
- 关键约束：答案必须是图像依赖的属性（如颜色、材质、空间关系），不能通过元数据直接获取。
- 工程意义：测试模型是否具备“根据文本线索去检索图片”的原语能力。
### Level 2：离线交互式多模态搜索 (Controlled Offline Interleaved Multimodal Search)
这是核心难点。模型需要在受控的离线环境中，完成多跳搜索。
- 构造逻辑：利用知识图谱路径，构建两类样本：
初始视觉探测：起点无实体名，仅有视觉线索，需先定位实体再沿图谱推理。
- 中间视觉探测：在推理链中间插入“视觉断点”，模型需先进行图像检索找到相似实体，再继续文本推理。
- 核心挑战：要求模型在“文->图”和“图->文”之间反复横跳，任何一步的视觉定位错误都会导致后续链条断裂。
### Level 3：开放网络交互式搜索 (Open-Web Interleaved Multimodal Search)
这是落地场景。在噪声极大、动态变化的真实互联网环境中进行测试。
- 构造逻辑：引入“多分支（Multi-branch）”样本。模型需要并行探索多个实体，收集证据后进行比较，选择最优分支继续深入。
- 工程意义：评估 Agent 在复杂拓扑结构下的非线性的搜索控制能力，这是现有单链基准完全缺失的维度。
## 关键结果：现状依然严峻使用 InterLV-Agent 框架对主流闭源和开源模型进行评估，结果令人深思。即使拥有强大的工具调用能力，当前 SOTA 模型的整体准确率仍 低于 50% 。

- 工具增益差异巨大：闭源模型在 Level 2 和 Level 3 上通过工具调用获得了显著增益（如 GPT-5.4 在 Level 3 提升 +26.59%），而部分开源搜索专用 Agent（如 MMSearch-R1）甚至出现性能退化（-1.85%）。这说明现有开源 Agent 在搜索规划和多模态证据整合上存在严重短板。
- 视觉定位是主要瓶颈：分解分析显示，一旦成功检索到目标视觉证据，回答准确率很高（Level 2 中 Acc.|Ret. 高达 73.75%）。但在 Level 2 中，目标实体的检索召回率（Ret. R@5）仅为 35.56%。这意味着**“找不到图”比“看不懂图”更致命**。
- 多分支搜索是噩梦：在 Level 3 的多分支样本中，所有模型性能均大幅下降（GPT-5.4 从 44.25% 跌至 33.82%）。这揭示了当前 Agent 在处理并行探索、证据筛选和分支决策时的脆弱性。
## 工程启示- 不要忽视视觉线索的“导航”作用：在构建 Agent 时，不仅要训练模型从图像中提取答案，更要训练模型从图像中提取下一跳的查询词（Query）或实体名。Visual Pivot 是提升多跳搜索成功率的关键。
- 记忆模块至关重要：消融实验显示，移除记忆模块对 Level 3（开放网络）影响显著。在长轨迹、多分支搜索中，Agent 必须维护短期记忆（最近交互）和长期记忆（历史观察摘要），否则极易迷失在噪声网页中。
- 开源 Agent 的差距不在推理，而在检索：闭源模型的领先优势主要体现在更鲁棒的工具调用序列和多模态 grounding 能力上。开源模型若想追赶，需在 Search-to-VQA 的耦合训练和混合检索策略上发力。
## 局限与展望InterLV-Search 虽然覆盖了丰富的领域，但 Level 2 依赖离线知识图谱，可能与真实互联网的动态性有偏差。Level 3 虽贴近真实，但网页内容的时效性和噪声仍是挑战。未来工作可关注如何让模型在视觉证据缺失时进行 不确定性推理 ，以及如何在多分支搜索中引入更高效的 剪枝策略 。
