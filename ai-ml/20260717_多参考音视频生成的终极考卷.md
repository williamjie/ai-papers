# ⭐⭐⭐½ 多参考音视频生成的终极考卷

**日期**: 2026-07-17

---

论文 : MultiRef-Compass: Towards Comprehensive Evaluation of Multi-Reference-to-Audio-Video Generation链接 : https://arxiv.org/abs/2607.14189现在的视频生成模型越来越强，但大多还停留在“单图驱动”或“纯文本驱动”。
当你试图用三张不同角度的照片、一个场景图和一段音效去控制生成时，现有的评测体系就失效了。
这篇来自南京大学和 Kling 团队的论文提出了 MultiRef-Compass ，专门针对多参考音视频生成（MR2AV）这一复杂场景。
它不仅仅是一个榜单，更是一套能诊断模型“是否真的理解”多参考关系的体检表。
### 为什么现有评测不够用？
现有的视频评测基准（如 VBench, T2AV-Compass）主要关注两个点：指令遵循和音视频同步。
但在 MR2AV 任务中，核心难点在于 跨参考理解 和 组合绑定 。
模型需要判断多张图是同一主体的不同视角，还是不同的实体。
更致命的是，现有指标容易作弊。如果模型直接把参考图“复制粘贴”进视频里，传统的相似度分数会很高，但这根本不是生成能力。
### 核心设计：防作弊的评测逻辑MultiRef-Compass 的设计直觉非常工程化： 不仅要像，还要自然；不仅要同步，还要对位。
1. 数据集构建：可控的资产组合论文构建了 350 个样本，通过“资产包”（Asset-Pack）重组实现。
分为三个主要板块：
- B1: 同一主体的多视角参考（测试身份一致性）。
- B2: 人、物、场景的异构组合（测试实体绑定）。
- B3: 多主体交互（测试复杂角色分配）。
这种构建方式确保了每个样本的“标准答案”是明确的，避免了开放式生成的模糊性。
2. 防粘贴系数 PpasteP_{paste} ​这是本文最精彩的工程改进。
传统方法用 SigLIP 计算实体相似度 EFbaseEF_{base} ​ 。为了惩罚“复制粘贴”行为，引入 MLLM 评估的“粘贴自然度”系数 Ppaste(r)∈[0,1]P_{paste}(r) \in [0, 1] ​ ( r ) ∈ [ 0 , 1 ] 。
最终得分公式为：
EFfinal=EFbase×Ppaste(r)EF_{final} = EF_{base} \times P_{paste}(r) ​ = E F ba se ​ × P p a s t e ​ ( r )
如果模型只是把图贴上去， PpasteP_{paste} ​ 会很低，从而拉低总分。这直接戳破了开源模型 SkyReels-V3 的“高分幻觉”。
3. 重判机制（Rejudging）
MLLM-as-a-Judge 最大的问题是评分标准漂移。
MultiRef-Compass 引入了一个轻量级的“重判”阶段。它不重新打分，而是横向对比所有模型对同一问题的判决理由。
如果发现某个模型因为语义理解偏差被误判，重判器会修正这种不一致性，提升评估的可审计性。
### 实验结果：谁在裸泳？
论文评测了 8 个主流模型（6 个闭源，2 个开源）。数据揭示了几个反直觉的事实。
1. 闭源模型的全面优势在整体排名中，Seedance 2.0 凭借均衡的能力位列第一。Gemini-Omni 和 Kling 3.0 紧随其后。
开源模型 SkyReels-V3 和 Wan2.1-VACE 虽然进步明显，但在“参考一致性”和“指令遵循”上仍有巨大差距。

- Gemini-Omni: 唇形同步（SLS）最强，音视频一致性最好。

### 工程启示对于正在接入视频生成 API 的开发者，这篇论文提供了三个关键建议：
- 不要迷信单一相似度分数。如果你的业务涉及多角色或多视角，必须引入“自然度”或“绑定正确性”的检查，否则会被模型的“复制粘贴”行为欺骗。
- 细分指令遵循维度。实验显示，模型在“基本场景设置”上表现稳定，但在“动作执行”和“穿戴细节”上差异巨大。在设计 Prompt 时，应将复杂动作拆解，或选择在该子维度更强的模型（如 Wan 2.7 在时序任务上更强）。
- 重判机制值得借鉴。在使用 LLM 评估生成结果时，引入横向对比的“重判”步骤，可以低成本解决评分标准不一致的问题，提升线上监控的可靠性。
### 局限与展望尽管 MultiRef-Compass 很全面，但它目前主要依赖 MLLM 进行细粒度判断，计算成本较高。
此外，对于长视频（超过 10 秒）的多参考一致性维持，目前的评测覆盖尚显不足。
随着多模态大模型能力的提升，未来的 MR2AV 系统将不再仅仅是“拼接”参考，而是真正理解物理交互和因果逻辑。这套基准将是衡量这一跃迁的重要标尺。
