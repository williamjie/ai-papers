# ⭐⭐⭐½ 不训辅助模型，用反事实回放做 Token 级奖励分配

论文 : CoRT: Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization链接 : https://arxiv.org/abs/2607.25659在基于规则（Rubric）的强化学习训练中，我们常面临一个尴尬局面：虽然奖励模型能给出结构化的评分，但在 GRPO 等算法中，这些细致的反馈最终被压缩成一个标量，均匀广播给回复中的每一个 Token。这导致“关键约束词”和“废话填充词”获得了相同的更新信号。
这篇来自南京大学与字节跳动的论文提出了一种极简但高效的解法：CoRT（Counterfactual Replay）。它不训练额外的辅助模型，仅通过一次“反事实回放”，就能在 Token 级别重新分配奖励权重，显著提升指令遵循能力。
### 痛点：结构化反馈的“平均主义”陷阱现有的 GRPO 风格流水线虽然简单可扩展，但存在严重的信用分配（Credit Assignment）错配。
当 Rubric 判定回复满足“格式正确”或“包含特定关键词”时，GRPO 计算出的 Advantage 是针对整个回复的。这意味着，无论某个 Token 是核心逻辑的关键部分，还是无关紧要的连接词，它们都受到同等力度的强化或抑制。
这种“平均主义”忽略了 Rubric 中蕴含的结构化信息。理想的训练应当让那些直接响应特定约束的 Token 获得更强的梯度信号，而让通用内容保持相对稳定。
### 核心 Insight：利用策略内部的概率差CoRT 的核心直觉非常巧妙： 如果去掉提示词中的具体规则，模型生成相同回复的概率分布会发生什么变化？
论文指出，对于依赖规则生成的 Token（如特定格式符号、强制包含的词汇），其概率会显著下降；而对于通用内容，概率变化较小。这种“反事实对比”天然地暴露了哪些 Token 真正依赖于 Rubric 上下文。
具体实现分为三步：
- 正向打分：在包含规则的提示词 x+x^+ 下，计算采样回复的 Log-Probability ℓt+\ell^+_t+​。
- 反事实回放：固定相同的回复序列，但在去除规则的提示词 x−x^- 下重新打分，得到 ℓt−\ell^-_t−​。
- 权重映射：计算差值 Δt=ℓt+−ℓt−\Delta_t = \ell^+_t - \ell^-_t​=ℓt+​−ℓt−​，通过 Sigmoid 映射为有界的信用权重 wi,tw_{i,t}​。
⚠️ 关键设计 ：CoRT 不改变奖励的方向（正负），只重新分配幅度。它保留了 GRPO 的群体归一化优势，仅修改了 Token 级的系数。
这种方法避免了训练独立的 Token 相关性判别器（如 RTT 方法所需），无需额外的标注数据或复杂的对齐阶段，工程侵入性极低。
### 实验结果：稳定超越基线在 Qwen3-4B 和 Qwen2.5-7B 上的实验显示，CoRT 在绝大多数指令遵循基准上优于标准 GRPO，平均提升 4.4 个百分点 。

此外，CoRT 与 DAPO、GSPO 等其他优化目标兼容，进一步证明了其通用性。在 Qwen3-14B 上也观察到类似增益，表明该方法具备规模扩展性。
### 工程启示：低成本提升训练效率对于正在落地 RLHF 或 GRPO 的工程团队，CoRT 提供了两个重要参考：
- 无需额外模型：相比训练 Token-level Relevance Model，CoRT 只需在 Forward Pass 中增加一次无规则提示词的打分。计算开销极小，且易于集成到现有代码库。
- 稳定性控制：论文强调了“响应归一化”和“平滑启动（SmoothStep）”的重要性。直接应用反事实权重可能导致训练震荡，通过逐步引入权重并限制其范围，可以保持梯度范数的稳定。
### 局限与展望CoRT 依赖于策略内部的对数概率对比。如果某些规则对 Token 概率的影响微乎其微（例如规则与默认行为高度重合），或者奖励信号本身噪声较大，该方法的效果可能会减弱。
未来工作可探索更细粒度的干预，或将此思想扩展到多轮对话和 Agent 工具调用场景中的长期信用分配。但对于当前的指令遵循任务，CoRT 无疑是一个高性价比的改进方案。
