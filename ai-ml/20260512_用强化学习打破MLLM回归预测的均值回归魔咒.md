# 用强化学习打破MLLM回归预测的均值回归魔咒

**日期**: 2026-05-12

---

论文 : Injecting Distributional Awareness into MLLMs via Reinforcement Learning for Deep Imbalanced Regression链接 : https://arxiv.org/abs/2605.01402多模态大语言模型（Multimodal Large Language Models, MLLMs）在处理数值回归任务时，一直有一个隐痛： 长尾分布下的“均值回归”（Regression-to-the-Mean）现象 。简单说，模型倾向于把预测值都往数据密集区（众数）靠，导致稀有但重要的尾部样本预测崩盘。
这篇论文没有去改模型架构，也没有搞复杂的推理链，而是通过引入一种 基于批次级关系的强化学习（Reinforcement Learning, RL）框架 ，直接给模型注入“分布感知”能力。对于正在微调视觉-语言模型做量化预测的工程师来说，这是一个极具启发性的后训练（Post-training）方案。
## 痛点：为什么 SFT 在长尾回归中失效？
现有 MLLM 处理回归任务，主流做法是监督微调（Supervised Fine-Tuning, SFT）。其核心逻辑是将连续数值离散化为 Token，通过交叉熵损失进行下一个 Token 预测。
这里有两个致命缺陷：
- Token 级监督缺乏数值敏感度：预测 18 和 19 在 Token 层面可能是完全不同的序列，但在数值上非常接近。标准 SFT 无法区分“数值接近但 Token 不同”的错误，导致模型无法学习数值的连续性和全局量级。
- 点对点优化的偏差：SFT 和现有的逐样本回归奖励（Point-wise rewards）都是独立评估每个样本。在长尾分布下，高概率区域的样本占据主导，梯度更新自然偏向于拟合高频值。这导致模型在面对稀疏的尾部样本时，信号极其微弱，最终表现为所有预测都向均值坍塌。
## 核心 Insight：从“点对点”到“批次级分布感知”
论文的核心洞察是： 深度不平衡回归（Deep Imbalanced Regression, DIR）不应被视为独立的点对点预测，而应被视为一个分布感知问题。
既然逐样本优化会向高密度区坍塌，那就引入 批次内（Batch-level）的相对比较 。作者提出了 CCC-GRPO 框架，其关键设计如下：
### 1. 批次级关系比较向量在 GRPO（Group Relative Policy Optimization）的基础上，模型对每个输入生成 KK 个预测轨迹。对于输入 xix_i ​ 的第 kk 个预测 qk(xi)q_k(x_i) ​ ( x i ​ ) ，作者不是单独拿它和真值 yiy_i ​ 比，而是构建一个 批次级比较向量 ：
qi,k=[qk(xi),{μ(xj)}j≠i]q_{i,k} = [q_k(x_i), \{\mu(x_j)\}_{j \neq i}] ​ = [ q k ​ ( x i ​ ) , { μ ( x j ​ ) } j  = i ​ ]其中 μ(xj)\mu(x_j) ​ ) 是同一批次中其他样本 xjx_j ​ 的预测均值。
为什么要这么做？
通过引入批次内其他样本的预测均值作为上下文锚点，模型不再孤立地看一个数字，而是看“在当前批次分布中，这个数字处于什么位置”。这种相对关系迫使模型去拟合整个批次的联合分布结构，而不仅仅是单个点的误差。
### 2. 一致性相关系数（CCC）作为奖励传统的回归奖励（如 MAE）只关注绝对误差，对分布形状不敏感。作者选用 一致性相关系数（Concordance Correlation Coefficient, CCC） 作为奖励函数：
CCC(q,y)=2Cov(q,y)Var(q)+Var(y)+(μq−μy)2CCC(q, y) = \frac{2 Cov(q, y)}{Var(q) + Var(y) + (\mu_q - \mu_y)^2} V a r ( q ) + V a r ( y ) + ( μ q ​ − μ y ​ ) 2 2 C o v ( q , y ) ​CCC 的优势在于它同时衡量 线性相关性 、 尺度一致性 和 均值对齐 。
- 如果模型预测出现方差坍塌（所有预测都接近均值），CCC 会大幅惩罚。
- 如果预测均值发生偏移，CCC 也会惩罚。
- 这使得奖励信号能够显式地约束预测分布与真实分布在统计特性上的一致性，从而有效抵抗均值坍塌。
## 实验结果：尾部样本的显著增益作者在统一的长尾回归基准测试（涵盖年龄估计、电影评分、骨骼年龄等 12.9k+ 样本）上进行了评估，主要对比对象包括 SFT、SFT-SOFT、Visual Quality、Regression Reward 等 MLLM 基线，以及经典的 CNN 回归方法。
以下是在 AgeDB-DIR 数据集上，基于 Qwen2.5-VL-3B 模型的关键对比数据（MAE 越低越好）：
方法 Many-shot Medium-shot Few-shot All (Overall) SFT 5.78 7.67 8.36 6.37 Regression Reward 5.48 6.52 7.58 5.85 Ours (CCC-GRPO) 5.62 5.62 6.40 5.42数据解读：
- 头部区域（Many-shot）：CCC-GRPO 保持了与 SFT 相当的竞争力（5.62 vs 5.78），说明没有牺牲高频区域的精度。
- 中部与尾部（Medium/Few-shot）：这是 CCC-GRPO 发力的地方。在 Few-shot 区域，MAE 从 8.36 大幅降至 6.40，降幅显著。这直接证明了批次级分布感知对稀疏样本的有效纠正。
- 整体性能：在 IMDB-Movie-DIR 和 BoneAge-DIR 上，CCC-GRPO 同样在稀疏区域展现出最大优势，尤其在更具挑战性的 BoneAge-DIR 上，整体 MAE 相比 SFT 提升了 23.55%。
## 工程启示- 无需修改架构：CCC-GRPO 是一个即插即用的后训练框架。你不需要像 Rex-Omni 那样扩展词表，也不需要像 GEODE 那样增加回归头。只需在现有的 MLLM 上运行 RL 微调即可。
- 奖励设计决定上限：对于数值型任务，简单的 MAE 或 Cross-Entropy 是不够的。引入能捕捉分布特性（如 CCC、Spearman 等）的奖励函数，并配合批次级的相对比较，是解决长尾回归的关键。
- 关注 GM 指标：除了 MAE，论文强调了几何平均误差（Geometric Mean, GM）的重要性。GM 对稀疏区域的错误更敏感，能更好地反映模型在长尾分布下的鲁棒性。
## 局限与展望尽管效果显著，但该方法仍有一些边界：
- 计算开销：GRPO 需要生成多个轨迹（K generations），相比单次前向传播的 SFT，训练成本更高。
- 基准局限性：目前实验主要集中在年龄估计和评分等自然图像回归任务，对于更复杂的结构化数值预测（如物理仿真参数）是否同样有效，尚待验证。
- Batch Size 敏感性：虽然论文做了消融实验显示对不同 Batch Size 有一定鲁棒性，但在极端小的 Batch 下，批次级比较的统计意义可能会减弱。
总的来说，这篇论文为 MLLM 的数值感知能力提供了一个优雅且有效的解决思路： 不要只盯着单个数字猜，要看它在整个数据分布中的位置。
