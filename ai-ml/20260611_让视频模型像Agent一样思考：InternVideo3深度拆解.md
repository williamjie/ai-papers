论文 : InternVideo3: Agentify Foundation Models with Multimodal Contextual Reasoning链接 : https://arxiv.org/abs/2606.12195现在的开源多模态大模型（MLLMs）大多还停留在“看一眼、答一题”的单次预测阶段。但在真实的长视频分析或监控场景中，我们需要的是能像 Agent 一样具备记忆、工具调用和自我修正能力的系统。上海 AI 实验室提出的 InternVideo3，通过引入多模态上下文推理（MCR）和高效的注意力机制，试图填补这一空白。
### 痛点：为什么现有方案搞不定长视频？
现有的开源进展主要集中在文本主导的 Agent 场景（如代码、搜索），而视觉领域的长期推理依然薄弱。传统 MLLMs 在处理长视频时，通常采用激进的关键帧采样或检索摘要。这种做法虽然节省了计算资源，但往往会丢弃后续推理或验证所需的关键细节。
核心矛盾 ：为了效率牺牲信息完整性，导致模型在需要回溯证据或进行复杂时空推理时“失忆”或产生幻觉。
### 方法拆解：从单次映射到闭环推理InternVideo3 的核心洞察是将长视频理解重构为一个**多模态上下文推理（ Multimodal Contextual Reasoning, MCR）**的闭环过程。在这个框架下，观察、指令、中间推理、工具动作和反馈都被统一表示在一个随时间演化的共享上下文中。
为了支撑这种长序列的 Agent 行为，论文提出了 M2LA（ Multimodal Multi-head Latent Attention） 。这是一种保留 token 流的注意力重参数化技术。它不通过丢弃 token 来压缩上下文，而是通过压缩 KV-cache 状态来实现效率提升。具体设计包含三个关键点：
- RoPE 感知的位置聚合：将多头位置键聚合为共享表示，避免在缓存中重复存储相似的位置通道。
- 内容通道的低秩潜变量分解：将键和值投影到紧凑的潜在空间进行缓存，并在注意力计算时动态重建头特定的表示。这使得 KV-cache 的大小与原始头数解耦。
- 模态感知的适配：针对文本和视频 token 分布差异大的问题，在重建前应用轻量级的模态特定映射。
工程直觉 ：M2LA 巧妙地将长上下文效率问题从“模型外的 token 减少”转移到了“模型内的状态压缩”，从而在保持全量多模态证据的同时大幅降低显存占用。
### 训练策略：分阶段的能力构建为了让模型适应新的注意力结构并掌握长期推理，InternVideo3 采用了一套精心设计的训练流程：
- 持续预训练（CPT）：在 M2LA 转换后，使用 1600 万样本（约 135 亿 token）进行轻量级预训练，恢复语言能力和多模态对齐。
- 短到长的监督微调（SFT）：采用课程学习策略。第一阶段使用 2fps、512 帧的视频建立基础时间理解；第二阶段提升至 4fps、2048 帧，支持高达 256k token 的上下文推理。
- 基于规则的强化学习（RL）：在可验证任务（如视频 QA、时间定位）上应用组序列策略优化（GSPO），通过规则奖励提升模型的校准能力和时间定位精度。
- 在线策略蒸馏（On-Policy Distillation）：从更强的教师模型（Qwen3-235B）进行蒸馏，特别关注学生模型表现不佳而教师模型正确的样本，以缓解长推理轨迹中的暴露偏差。
### 关键结果与 Agent 实例化实验表明，InternVideo3 在短视频和长视频基准测试中均表现出色，特别是在 Video-MME、MLVU 和 EgoSchema 等长视界任务上取得了显著提升。
论文进一步将模型实例化为一个视频 Agent，具备以下能力：
- 分层记忆：构建包含采样帧、场景边界和时间戳的记忆结构。
- 工具调用：支持 ASR、分割、时间定位和网络搜索等工具。
- 递归验证：在终止前进行自我检查，确保证据充分性，减少幻觉。
### 工程启示对于正在构建多模态 Agent 的工程师来说，InternVideo3 提供了几个重要的实践指导：
- 上下文效率至关重要：不要仅仅依赖外部检索来压缩视频信息，模型内部的注意力机制优化（如 M2LA）能更好地保留推理所需的细节。
- 闭环推理优于单次预测：将工具调用、反馈和记忆纳入统一的上下文窗口，能让模型具备自我修正和证据积累的能力。
- 训练策略需循序渐进：从短到长的课程学习以及基于规则的 RL 微调，是提升长视频推理稳定性的有效手段。
### 局限与展望尽管 InternVideo3 展示了强大的长期推理能力，但其对硬件资源的要求依然较高，尤其是在处理极长视频时。此外，M2LA 的转换过程需要细致的校准以维持性能，这在工程落地中可能需要额外的调优成本。未来，如何进一步降低 Agent 行为的延迟并提高工具调用的鲁棒性，将是该方向的重要挑战。
