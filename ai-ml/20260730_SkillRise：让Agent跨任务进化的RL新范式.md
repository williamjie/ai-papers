# ⭐⭐⭐½ SkillRise：让 Agent 跨任务进化的 RL 新范式

**日期**: 2026-07-30

论文 : SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution链接 : https://arxiv.org/abs/2607.26784大模型 Agent 在实际落地中常面临一个尴尬：面对相似但不同的任务，它总是“从零开始”探索，完全浪费了之前的经验。
这篇来自美团、浙大等机构的论文提出了 SkillRise，一种端到端的强化学习框架。它让 Agent 在解决一系列相关任务时，自动提炼并更新一份“技能文档”，实现跨任务的自我进化。
## 现有方案的痛点目前提升 Agent 能力主要有两条路，但都有明显缺陷：
- 单任务重复尝试：如 Reflexion 或 LaMer，Agent 反复试错同一个任务直到成功。这导致学到的知识往往局限于特定实例，难以迁移到新任务。
- 多阶段技能管道：如 SkillRL，涉及提取、存储、检索、执行等多个模块。这种设计不仅工程复杂，更致命的是信用分配（Credit Assignment）混乱——最终效果好，到底是检索准了，还是执行对了？很难归因。
SkillRise 的核心直觉是： 简化流程，明确信号 。用一个策略同时处理“解题”和“写笔记”，并通过时间上的解耦来精准奖励每一步。
## 方法拆解：为什么这么设计？
SkillRise 的设计极其精简，核心在于三个关键机制：
### 1. 渐进式任务序列（Progressive Sequences）
它不随机采样任务，而是将同一类任务按难度从易到难排序。
- Insight：简单任务中积累的通用交互模式，天然能辅助解决更复杂的同类任务。这为技能迁移提供了天然的“坡度”。
### 2. 单一策略的双角色切换同一个 Policy πθ\pi_\theta ​ 在两个阶段交替工作：
- 解题阶段：利用当前的技能文档 Si−1S_{i-1}​ 尝试解决任务 xix_i​。
- 策展阶段：任务结束后，根据轨迹 τi\tau_i​ 和奖励 rir_i​，重写技能文档生成 SiS_i​。
- 关键点：SiS_i​ 是跨任务的唯一信息通道。之前的原始轨迹不保留，迫使 Agent 必须提炼出可复用的抽象知识，而不是死记硬背。
### 3. 解耦的信用分配（Decoupled Credit Assignment）
这是最精妙的设计。传统 RL 给整个序列一个总奖励，导致模型不知道哪一步该优化。SkillRise 将奖励拆分：
- 解题奖励：仅看当前任务是否成功 (rir_i​)。
- 策展奖励：看后续任务的加权回报 (∑γj−irj\sum \gamma^{j-i} r_jrj​)。
⚠️ 反直觉发现 ：策展行为（写笔记）本身不产生直接收益，它的价值完全体现在 未来 任务的表现上。通过折扣因子 γ\gamma ，模型学会了“为了下道题而总结这道题”。
## 关键结果：性能与效率的双重碾压实验在 ALFWorld、WebShop 和 ScienceWorld 上进行，基线包括 PPO、GRPO 以及专门的技能学习方法 LaMer 和 SkillRL。
1. 绝对性能领先SkillRise 在所有基准测试中均取得最高 Pass@1 成功率：
数据集 SkillRise 最强基线 (GiGPO) 提升幅度 ALFWorld 85.9% 83.6% +2.3 pp WebShop 84.4% 77.3% +7.1 pp ScienceWorld 54.6% 46.1% +8.5 pp2. 跨任务测试时缩放（Test-Time Scaling）
随着测试时提供的关联任务序列变长，SkillRise 的性能持续上升。
- 在 ALFWorld 上，序列长度从 K=2K=22 增加到 K=6K=66，准确率从 83.6% 升至 87.5%。
- 相比之下，LaMer 和 GRPO 没有这种增长趋势。这证明 SkillRise 真的学到了可迁移的技能，而非仅仅靠重复采样刷分。
3. 极高的工程效率对比复杂的多阶段管道（如 RetroAgent, SkillRL）：

## 工程启示- 技能内化优于外部检索：对于同构任务流，让 Agent 自己维护一个轻量级的“上下文笔记”比搭建庞大的向量数据库更高效，且避免了检索噪声。
- 奖励信号的时间解耦是关键：在训练需要长期记忆或知识积累的 Agent 时，不要给全局奖励。明确区分“当下执行”和“未来收益”的监督信号，能显著提升策略的收敛质量。
- 小模型也能受益：即使在 Qwen3-1.7B 上，SkillRise 依然比基线高出 3.1%。随着模型增大到 4B，优势扩大到 6.2%，说明这种范式具有良好的扩展性。
## 局限与展望- 依赖任务元数据：目前需要人工或预设规则将任务按难度和类别分组。在完全开放的场景中自动发现任务关联仍是挑战。
- 规模限制：实验仅在 4B 参数模型上进行，更大规模模型（如 70B+）的表现尚待验证。
SkillRise 证明了，简单的端到端设计配合精准的信用分配，足以让 Agent 实现高效的跨任务自我进化。对于追求落地效率的团队来说，这是一个值得深入研究的范式。
