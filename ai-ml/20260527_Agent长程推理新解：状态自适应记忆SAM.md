论文 : SAM: State-Adaptive Memory for Long-Horizon Reasoning Agent链接 : https://arxiv.org/abs/2605.24468Agent 在长时间任务中“记不住事”或“记错事”，一直是工程落地的痛点。这篇来自中国人民大学与北京智源人工智能研究院的论文，提出了一种名为 SAM (State-Adaptive Memory) 的新框架。它不再简单粗暴地截断上下文，而是把记忆看作一个 随状态自适应 的外部模块。对于正在构建复杂 Agent 系统的工程师来说，这套“线索-页面”架构及配套的强化学习优化策略，极具参考价值。
### 现有方案的痛点：为什么摘要不够用？
在长程交互（如多轮搜索、代码调试）中，历史信息不仅长，而且异构（包含思考、工具调用、观察结果）。现有的上下文管理方案主要有三类：
- 截断：直接丢弃旧历史，导致信息永久丢失。
- 压缩/摘要：将早期步骤折叠成简短摘要。问题在于，摘要是有损的，且无法预知未来哪部分细节会变得关键。
- 检索：从历史中检索片段。但传统检索往往基于静态语义相似度，缺乏对 Agent 当前“决策状态”的理解。
论文指出，核心挑战不在于上下文太长，而在于 当前决策所需的信息可能散落在遥远的步骤中，且其重要性随任务推进而变化 。因此，我们需要一种能根据 Agent 当前意图（Intent）动态重构历史的方法，而非静态压缩。
### SAM 的核心设计：线索与页面的解耦SAM 的直觉非常清晰： 记忆不应是历史的替代品，而应是访问历史的“手柄” 。它由两个耦合部分组成：
-基于页面的情景巩固（Page-based Episodic Consolidation）
当上下文达到预算限制时，SAM 将最近的交互片段打包成一个“页面”（Page），保留原始轨迹细节到外部存储中。
- 同时，生成一个紧凑的**记忆线索（Memory Cue）**留在当前上下文中。这个线索不是摘要，而是一个轻量级的指针，标记该页面包含了什么关键进展（如已确立的事实、未解决的问题）。
-意图驱动的情景召回（Intent-driven Episodic Recall）
当 Agent 需要回溯时，它会根据当前意图 qtq_t​ 从记忆库中选择相关线索。
- SAM 不会直接返回线索，而是根据意图，从对应的原始页面中重构出最相关的信息片段 ρt\rho_t​。
- 关键 Insight：这种设计实现了“写时轻量固化，读时按需重构”。Agent 不需要在上下文窗口里塞满所有细节，而是在需要时，通过意图精准提取所需证据。
### 训练策略：从专家模仿到树状强化学习SAM 的优化过程分为两步，这也是其工程价值所在：
- 专家引导的监督微调（SFT）：使用 Claude-4.5-Opus 和 GPT-5.4 等前沿模型生成高质量轨迹，提取巩固线索和召回内容作为标签，训练 Qwen3.5-9B 作为记忆模型。
- OAT-GRPO 强化学习：这是论文的创新点。传统的 GRPO 难以处理记忆动作的信用分配问题（因为记忆的质量要等到任务结束才能验证）。SAM 引入了 Oracle-Anchored Tree GRPO：
树状结构：在每次记忆调用处分支，生成多个回忆样本，继续执行直到得到最终结果。这使得奖励可以回溯到具体的记忆动作上。
- 预言机锚定奖励：使用多个前沿模型组成的委员会作为“预言机”，评估回忆内容的相关性和覆盖度，提供密集的信号，弥补稀疏的任务成功/失败奖励。
### 实验结果：显著的性能提升在 BrowseComp、BrowseComp-ZH、WideSearch 和 HLE 四个长程基准上，SAM 展现了强大的通用性。以下是基于 GLM-4.7 作为 Agent 骨干时的对比数据（表格源自论文 Table 1）：

- 跨模型泛化：同一个基于 Qwen3.5-9B 训练的 SAM 模块，也能让开源骨干 Qwen3.5-35B-A3B 的性能从 44.5 (Avg) 提升到 48.8，证明了记忆模块的解耦优势。
- 消融实验：移除 SFT 或 OAT-GRPO 任一阶段都会导致性能下降，说明专家模仿提供了良好的初始化，而强化学习进一步对齐了轨迹级的效用。
### 工程启示与局限对工程实践的启发：
- 记忆即服务：SAM 证明了可以将记忆能力从 Agent 骨干中解耦出来。你可以用一个较小的模型（如 9B）专门处理记忆管理，服务于不同的主推理模型，降低整体成本。
- 意图优于摘要：不要试图用静态摘要覆盖所有未来需求。设计“按需重构”机制，让 Agent 自己决定何时、如何回溯历史，效果更好。
- RL 在记忆中的价值：对于延迟奖励明显的任务（如长程搜索），树状结构的强化学习能有效解决信用分配问题，值得在其他多步决策场景中尝试。
局限与展望：
- SAM 依赖于强大的前沿模型作为“预言机”来生成训练数据和评估奖励，这在计算资源上仍有门槛。
- 目前主要验证在搜索和科研推理场景，对于实时性要求极高或交互频率极高的场景（如高频交易、即时游戏），页面固化和重构的延迟可能需要进一步优化。
总之，SAM 为长程 Agent 的记忆管理提供了一套简洁且高效的范式： 不压缩历史，而是索引历史；不静态存储，而是动态重构。

亮点:

- 术语表述不够精确：博文称记忆线索“不是摘要，而是一个轻量级的指针”，但原文明确cue是由记忆模型生成的紧凑摘要（mk = Msum(pk)），其作用是作为页面的轻量级句柄（handle），并非完全不是摘要。原文写道“the cue is not meant to replace the page or to function as a self-sufficient substitute for history; it serves as a lightweight handle”，博文的“不是摘要”可能引起误解。
