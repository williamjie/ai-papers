# 给离散扩散模型做RL训练，直接上GRPO会崩

**日期**: 2026-04-22

---

论文 : UDM-GRPO: Stable and Efficient Group Relative Policy Optimization for Uniform Discrete Diffusion Models链接 : https://arxiv.org/abs/2604.18518GRPO 在大语言模型推理能力上的成功大家都不陌生，但把它搬到视觉生成领域，尤其是离散扩散模型（Uniform Discrete Diffusion, UDM）上，会怎样？北京智源研究院的那帮人试了一下——直接套用，500步之后reward剧烈震荡，KL散度爆炸，训练直接崩盘。
然后他们找到了两个关键原因，修了修，居然把 GenEval 从 69% 干到了 96%。
## 为什么离散扩散 + RL 是个坑离散扩散模型（UDM）和连续扩散不同，它的状态空间是离散的 token 序列，每个 timestep 更新所有 token。代表工作 URSA（Deng et al., 2025）在这方面做得不错，但预训练模型面对复杂构图、文本渲染、人类偏好对齐这些任务时，表现并不理想。
RL 天然适合这类优化——reward 可以是非可微的（比如 GenEval 分数、PickScore），不需要重新设计损失函数。Flow-GRPO（Liu et al., 2025）已经在连续扩散模型上验证了这条路走得通，但 UDM 不一样。
作者先做了一个 baseline：直接套用 Flow-GRPO 到 UDM 上。具体来说，把每一步去噪的中间预测值 x1tx^t_1 t ​ 当作 action，沿着反向采样轨迹 XbackwardX_{backward} ​ 做策略优化。理论上是通的，因为 UDM 的网络直接输出 logits，可以精确计算概率。
但实际训练曲线（Figure 1）很打脸：前 500 步 reward 确实涨了，然后直接崩了。
## 崩在哪？两个根本性问题### 问题一：中间预测值太烂，拿它当 action 就是害模型在反向去噪过程中，早期 timestep 的预测 x1tx^t_1 t ​ 熵值极高，生成的东西又糊又乱（Figure 4 第一行）。但 GRPO 的 advantage 信号来自最终干净样本 x11x^1_1 1 ​ 的 reward。
这就产生了一个矛盾：最终预测对了，reward 是正的，但策略网络却被迫使去模仿早期那些高熵、无意义的中间预测 x1tx^t_1 t ​ 。相当于老师给了你高分，但让你模仿自己犯的错误——模型学的方向是歪的。
### 问题二：反向轨迹偏离了预训练分布预训练的时候，模型学习的是从真实前向扩散轨迹 XpretrainX_{pretrain} ​ 中加噪的样本还原原图。RL 微调的时候，模型沿着自己采样的反向轨迹 XbackwardX_{backward} ​ 做优化。
这两条轨迹的差异有多大？作者用 FID 量化了一下（Figure 4 顶部）， XbackwardX_{backward} ​ 在早期 timestep 和 XpretrainX_{pretrain} ​ 的距离显著大于 XforwardX_{forward} ​ 。模型在 OOD（Out-of-Distribution）状态上学东西，概率路径本身就是偏的，训练不稳是必然的。
## UDM-GRPO 的两招### 招一：action 统一为最终干净样本把每个 timestep 的 action 从 x1tx^t_1 t ​ 改为 x11x^1_1 1 ​ ，即策略网络学习的是 pθ(x11∣xt,c)p_\theta(x^1_1 | x^t, c) ​ ( x 1 1 ​ ∣ x t , c ) 。
这个改动很直觉——reward 本身就是对最终结果的评分，那优化目标就应该直接指向最终结果。中间过程的噪声预测不需要作为 action。效果立竿见影：Table 3 显示，仅这一个改动，GenEval 从 0.69 升到 0.84，PickScore 从 21.79 到 21.99，KL 散度也更低了。
### 招二：用前向轨迹替代反向轨迹不再用模型自己采样的 XbackwardX_{backward} ​ ，而是用前向扩散过程 XforwardX_{forward} ​ ：从模型预测的干净样本 x11x^1_1 1 ​ 出发，按预训练时的前向扩散过程加噪得到 xtx^t 。
这样训练时模型看到的中间状态和预训练时一致，概率路径没有偏移。Table 3 的 ablation 对比了 backward vs forward（action 都是 x11x^1_1 1 ​ ）：forward 在 GenEval 上稳定到 0.95，backward 在 0.89 就停滞甚至崩溃了。
两招叠加，GenEval 直接到 0.94。
## 两个提速技巧### Reduced-Step：只优化前半段扩散过程的噪声是随时间递减的——早期 timestep 探索空间大、预测误差也大，是优化的关键区域。作者发现对整个 t 范围做优化会分散梯度，收敛慢。
策略：每个样本随机选前半个 diffusion timestep 中的三个连续 timestep 做优化。Table 3 和 Figure 6(d1-d3) 证明，这个策略在 GenEval 和 PickScore 上明显优于全步骤优化和随机采样。
### CFG-Free：训练时不用无分类器引导大多数 Diffusion-RL 方法训练时需要同时优化 condition 和 unconditional 两个分支（CFG 训练），计算开销大。UDM-GRPO 直接在训练时去掉 CFG。
初期效果会差一点（采样质量低），但随着训练推进反而超越 CFG 训练，而且收敛更快、KL 散度更低。Table 3 中 CFG-Free 版本 GenEval 达到 0.96，是全方法的 SOTA。OCR 任务上 CFG-Free 反而更好，作者解释为移除 CFG 拓宽了策略分布，利于 RL 探索。
## 关键结果方法 GenEval PickScore OCR URSA (base) 0.69 21.79 0.08 URSA (w/o CFG) 0.36 20.46 0.04 URSA + UDM-GRPO 0.96 23.81 0.57注意几个数字：
- GenEval 从 69% 到 96%，比 FLUX.1 Dev（12B 参数）的 0.66 高出一大截，也超过了 SD3.5-L（8B 参数）的 0.71。关键是 URSA 只有 1.7B 参数，这个提升效率惊人- PickScore 23.81，在离散和连续模型中都是 SOTA- OCR 从 8% 到 57%，说明方法不只提升了图像质量，还让模型学到了文本渲染能力对比其他 RL 方法（Table 1），UDM-GRPO 是唯一一个在离散模型上做到 GenEval 0.96 的，而且参数量远小于 Emu3.5（34B）和 SANA-1.5（4.8B）。
## 工程启示-给扩散模型做 RL，action 的设计决定生死。如果你把中间噪声预测当 action，模型就会学噪声。最终 reward 对齐的 action 才靠谱。
-训练轨迹和预训练分布要对齐。用模型自己采样的反向轨迹做 RL 优化，本质上是在 OOD 数据上学东西。用前向过程重建轨迹是个简洁的解法。
-不需要优化所有 timestep。扩散过程的早期阶段才是 RL 该发力的地方，Reduced-Step 策略省计算还更好用。
-CFG-Free 在 RL 微调中值得试试。虽然牺牲了初期采样质量，但收敛更快、探索空间更大，最终效果反而更好。
## 局限与展望论文本身提到了几个方向：扩展到文本生成视频（text-to-video）、多 reward 联合优化。另外，CFG-Free 虽然最终效果更好，但训练初期的低质量采样意味着需要更长的 warmup 或者某种 curriculum 策略来弥补。
总的来说，UDM-GRPO 解决了一个很实际的问题——离散扩散模型和 RL 之间的适配。它的两个核心 insight（action 对齐、轨迹对齐）虽然直觉上不难理解，但在论文发表之前，几乎没人系统性地做过这个探索。对于做离散生成 + RL 对齐的人来说，这篇是一个值得精读的 baseline。
