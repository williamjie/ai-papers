论文 : Beyond Final Answers: Auditing Trajectory-Level Hallucinations in Multi-Agent Industrial Workflows链接 : https://arxiv.org/abs/2605.24219如果你正在构建生产级的多智能体（Multi-Agent）系统，这篇论文是一剂清醒剂。它揭示了一个残酷事实：只看最终输出（Final Output）的评估方式，会漏掉近一半的严重故障。在工业场景中，Agent 的“幻觉”往往不是胡说八道，而是中间步骤的逻辑断裂或流程违规，这些错误具有极强的隐蔽性和破坏力。
### 为什么现有方案失效？
目前的 Agent 评估基准（如 AgentBench, WebArena）大多沿用静态 LLM 的评估范式：输入一个问题，检查最终答案对不对。这种“黑盒”视角完全忽略了 Agent 的核心特征—— 轨迹（Trajectory） 。
在 ReAct 或 Plan-and-Execute 架构中，Agent 通过 Thought-Action-Observation 循环逐步推理。幻觉可能发生在中间步骤：比如引用了一个从未发生的观察结果（Referential Hallucination），或者跳过了必要的安全检查步骤（Procedural Hallucination）。如果最终答案碰巧对了，这些致命缺陷就被掩盖了。论文指出，48.7% 的幻觉轨迹同时包含多种错误类型，单一标签评估根本无法捕捉这种复杂性。
### Trajel：基于结构的幻觉分类学IBM 和哥伦比亚大学的研究团队提出了 Trajel ，一个专门针对多智能体工业工作流的轨迹级审计框架。其核心创新在于将幻觉定义为 结构化谓词（Structural Predicates） ，并划分出五种具体类型：
- 事实型 (Factual)：单步断言与真实数据矛盾。
- 引用型 (Referential)：引用了历史轨迹中不存在的实体或结果（“记忆”了没发生过的事）。
- 逻辑型 (Logical)：前提正确，但推理链条断裂。
- 程序型 (Procedural)：跳过、重排或伪造工作流中的必要步骤。这是工业场景中最常见的故障，占比达 38.5%。
- 范围型 (Scope)：Agent 执行了超出其角色权限的操作（内容可能正确，但由错误的 Agent 发出）。
这种分类的设计直觉非常清晰：不同类型的幻觉需要不同粒度的上下文才能检测。事实错误看单步即可，引用和逻辑错误需要回溯历史，而程序和范围错误必须结合工作流规范（Workflow Specification）来判断。
### 关键实验结果：监督模型打不过轻量信号？
论文在 AssetOpsBench 的 225 条专家标注轨迹上进行了详尽测试，结果令人意外且极具工程指导意义：
1. LLM-as-a-Judge 的局限性虽然 LLM 裁判在二进制检测上的 F1 达到了 0.855，但在细粒度分类上表现糟糕。对于复杂的逻辑和引用型幻觉，LLM 裁判的召回率（Recall）分别仅为 0.190 和 0.176 。这意味着近 80% 的深层逻辑错误被自动评估器漏掉了。
2. 监督分类器的瓶颈研究团队尝试了三种监督检测范式：
- BERT (子任务级)：AUC = 0.613- NLI (轨迹级自然语言推理)：AUC = 0.689（最佳）
- Longformer (长上下文建模)：AUC = 0.599即使是最强的 NLI 模型，AUC 也未超过 0.7。这表明，仅靠训练小模型来识别复杂的轨迹幻觉是非常困难的，数据量（225条）和任务复杂度构成了巨大挑战。
3. 轻量执行信号才是王道最震撼的发现来自对运行时执行质量信号的分析。论文发现，不需要复杂的模型推理，简单的二元标志位就能极强地预测幻觉：

### 工程启示：如何落地？
- 放弃纯事后审计：不要等任务结束再检查答案。在 Agent 循环中集成轻量级监控器（Monitor）。
- 利用运行时信号作为“熔断器”：论文建议，当“清晰度与论证”和“结果验证”两个信号同时缺失时，幻觉率高达 97.1%。这可以直接作为编排器（Orchestrator）的 Kill-Switch 条件，实时终止高风险任务。
- 区分错误类型：如果你的 Agent 经常跳过步骤，重点检查程序型幻觉；如果经常引用错误数据，重点加强引用型检测。通用的“对不对”评估没有意义。
- 人工复核不可替代：对于逻辑和引用型幻觉，自动检测器失效率高（Kappa < 0.211）。在高价值工业场景，必须保留专家对复杂轨迹的人工审核环节。
### 局限与展望Trajel 目前仅覆盖资产管理领域（AssetOps），样本量较小（225条）。不同领域（如医疗、金融）的工作流规范差异巨大，幻觉模式可能不同。此外，Inter-judge agreement（Cohen’s κ = 0.456）仅为中等水平，说明幻觉定义本身仍有模糊地带，需要更精细的标注协议。
总之，这篇论文告诉我们：在 Agent 时代， 过程比结果更重要 。与其训练一个昂贵的检测模型，不如先把你系统里的运行时信号用好。
