论文 : Rethinking the Divergence Regularization in LLM RL链接 : https://arxiv.org/abs/2606.09821大模型强化学习（Reinforcement Learning, RL）训练中，策略崩溃是工程师最头疼的问题。PPO 和 GRPO 虽然流行，但其核心的“重要性采样比率截断”在长尾词汇面前经常失效。这篇来自腾讯混元团队的工作提出了一种新方案 DRPO ，通过平滑的散度正则化替代了传统的硬截断机制，显著提升了训练的稳定性和最终性能。
### 为什么现有的 PPO/GRPO 不够好？
LLM 的 RL 训练本质上是离策略（Off-policy）的，因为推理引擎和训练引擎存在数值差异，且数据通常被拆分成多个 Mini-batch 使用。为了防止策略更新过大导致崩溃，我们需要“信任区域”（Trust Region）。
PPO 和 GRPO 使用 重要性比率 （Importance Ratio, rtr_t ​ ）来近似分布偏移。但在 LLM 巨大的词表中，这个指标有严重缺陷：
- 长尾词汇误导：低概率 token 的微小变化会导致极大的比率波动，从而被过度约束。
- 高频词汇失控：高概率 token 即使发生显著的概率质量转移，比率变化也可能很小，导致约束不足。
之前的工作 DPPO 试图用基于散度的掩码（Mask）来解决这个问题，但它依然使用“硬截断”：一旦 token 超出信任区域，梯度直接归零。这虽然防止了进一步偏离，但切断了任何将策略拉回正常范围的修正信号。
### DRPO 的核心 Insight：平滑且受控的修正DRPO 的核心直觉非常清晰： 不要切断梯度，而是平滑地重新加权。
作者保留了 DPPO 中基于 Binary-TV（绝对概率偏移）的信任区域几何形状，但将其从“硬掩码”替换为 优势加权的二次正则项 。其关键设计如下：
- 绝对概率偏移约束：不再看比率 rtr_t​，而是直接监控采样 token 的绝对概率变化 ∣π(yt∣st)−μ(yt∣st)∣|\pi(y_t|s_t) - \mu(y_t|s_t)|​∣st​)−μ(yt​∣st​)∣。这更符合总变差距离（Total Variation Distance）的几何意义，且在长尾分布下保持有界。
- 连续梯度权重：DRPO 为每个 token 计算一个连续的权重 wtw_t​。
当更新方向使策略远离行为策略时，权重逐渐衰减至零，并在超出边界后变为负值，提供修正信号将策略拉回。
- 当更新方向使策略回归行为策略时，权重会被放大，鼓励平滑收敛。
⚠️ 反直觉发现 ：实验表明，标准的 KL 或 TV 惩罚项在 LLM RL 中表现不佳，因为它们的梯度形式重新引入了基于比率的几何特性，导致长尾 token 的梯度方差爆炸。DRPO 的优势在于其梯度权重始终有界（ [1−1/δ,1+1/δ][1 - 1/\delta, 1 + 1/\delta] 1/ δ , 1 + 1/ δ ] ），而 SPO 等基于比率的方法在低概率区间的权重会无界增长。
### 实验结果：全面超越基线作者在 Qwen3-4B/30B/35B 以及 DeepSeek-R1-Distill-Qwen-1.5B 上进行了广泛测试，涵盖 BF16 和 FP8 精度设置。主要结论如下：

- FP8 低精度场景：GRPO 和 SPO 经常因数值不匹配而崩溃。DRPO 在 Qwen3-30B-A3B-Base 的 FP8 E2E 设置下，不仅保持稳定，还达到了最高的最终准确率。
- 收敛效率：相比 DPPO，DRPO 由于提供了边界外的修正信号，收敛速度更快，且避免了硬掩码带来的梯度突变。
- 消融实验：移除绝对优势项 ∣At∣|A_t|​∣ 会导致性能下降和训练不稳定，证明该权重对于保持信任区域边界的独立性至关重要。
### 工程启示与落地建议- 替换 PPO/GRPO 的截断逻辑：如果你正在构建或优化 RLHF/RLVR 训练框架，考虑将现有的 clip 机制替换为 DRPO 的平滑正则化形式。代码改动极小，只需修改 Loss 计算部分的梯度权重。
- FP8 训练的必备组件：在低精度（FP8）训练环境下，数值噪声会放大离策略误差。DRPO 的有界梯度特性使其成为 FP8 RL 训练的稳定器，能显著减少崩溃概率。
- 关注梯度几何而非目标函数形式：论文指出，看似合理的 KL/TV 惩罚项如果其梯度形式不佳（如引入比率依赖），效果反而不如设计良好的平滑正则化。在调试 RL 训练时，检查梯度权重的分布比单纯调整 Loss 系数更有效。
DRPO 提供了一种更优雅、更稳定的方式来处理 LLM RL 中的离策略问题。它没有引入复杂的二阶优化，仅通过改进一阶梯度的加权方式，就实现了性能与稳定性的双赢。对于追求高效、稳定微调的工程团队来说，这是一个值得立即尝试的改进。
