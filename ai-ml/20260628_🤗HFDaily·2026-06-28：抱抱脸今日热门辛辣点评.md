## 模型 Top 5### 1. deepreinforce-ai/Ornith-1.0-35B-GGUF340 个赞、两万下载，热度直冲榜首——Ornith 1.0 的 35B GGUF 版本显然戳中了很多人的爽点。名字叫“鸟”，但本质是 Qwen 3.5 MoE 架构的量化版，MIT 许可证下放，诚意是有的。但仔细看 tags： image-text-to-text ，说明这是个多模态模型，可 README 里对视觉能力的 benchmark 一笔带过，倒是把纯文本评测贴了一堆。这种“我也有视觉”的遮遮掩掩，像极了相亲简历上写“爱好广泛”但问起来就支支吾吾。量化后的 35B MoE 实际激活参数大概只有 10B 左右，性价比确实不错，但别被“35B”三个字忽悠了。
### 2. deepreinforce-ai/Ornith-1.0-9B-GGUF同门师弟，229 赞，1.1 万下载。9B 版本基于 Qwen 3.5（非 MoE），量化后适合本地跑。但问题来了：既然 35B 版本是 MoE，9B 却是 dense，这系列的名字和架构关系让人一头雾水。更搞笑的是，9B 的 GGUF 版本下载量是 safetensors 版本的 7 倍，说明大家根本不关心原始权重，只想下量化版本地玩耍。不过，9B 的多模态能力比 35B 更弱——毕竟参数少，视觉 encoder 也缩水。如果你是冲着“图像理解”去的，建议直接跳过这俩 GGUF 版本，去下原始模型。
### 3. deepreinforce-ai/Ornith-1.0-9B176 赞，下载才 1500——跟 GGUF 版本的热度形成鲜明对比。原始 safetensors 权重无人问津，侧面印证了“本地推理党才是主力”。这个模型在 tags 里写了 eval-results ，但我去翻 README 里的评测表，发现全是 text-only benchmark，多模态评测一个都没有。既然 pipeline_tag 标了 image-text-to-text ，至少放几个 VQA 分数吧？这种“挂羊头卖狗肉”的标签行为，建议 HF 以后搞个“标签诚信指数”。
### 4. deepreinforce-ai/Ornith-1.0-35B168 赞，7571 下载。原始 35B MoE 版本，下载量居然比 GGUF 版少一半——大家宁可用量化版也不碰原版，说明普通玩家根本扛不动 35B 的显存需求。而且这个模型在 tags 里同时挂了 qwen3_5_moe 和 transformers ，但实际加载时要用 trust_remote_code=True ，因为用了自定义 MoE 实现。对于想尝鲜的人来说，这门槛比想象中高。建议团队直接把推理代码做成 Space，而不是扔一个需要手动魔改的权重包。
### 5. Comfy-Org/Krea-2161 赞，但下载只有 10 次，热度全靠点赞刷上去？这玩意儿标签只有 comfyui 和 license:other ，连 pipeline_tag 都是空的。点进去一看，原来是 ComfyUI 的一个自定义节点包，不是模型。把这种工具类项目混在模型排行榜里，HF 的 trending 算法是不是该打补丁了？不过话说回来，Krea-2 要是真能像它名字暗示的那样“创造”，那倒值得关注——可惜目前 README 只有一行字，连示例图都没有，纯属占坑。
## 数据集 Top 3### 1. WithinUsAI/claude_mythos_distilled_25k126 赞，3173 下载，热度 25。名字很唬人：“Claude 神话蒸馏 25K”。一看就是拿 Claude 生成的合成数据，然后蒸馏成小模型用的。Apache-2.0 许可证好评，但仔细看数据内容——全是神话故事相关的问答对？这种领域特定数据，除非你要训练一个“神话 GPT”，否则通用性堪忧。而且“蒸馏 25K”这个量级，对于现在动辄上百万的蒸馏数据来说太小了，更像是某个实验的副产品。建议当玩具数据用，别指望它能提升模型常识。
### 2. scholarweave/arxiv-latex24 赞，4007 下载，热度 24。名字朴实无华：arXiv 上的 LaTeX 源码。1M-10M 篇论文的规模，Parquet 格式，适合做 LaTeX 到文本的转换或代码生成。但有个大坑：许可证是 other ，没写清楚具体是哪个。arXiv 论文本身版权复杂，用这个数据集训练模型可能面临法律风险。而且 LaTeX 源码里混着各种宏包和自定义命令，清洗成本极高。如果你是做科学文本生成，不如直接用 arXiv 的原始摘要数据，省心得多。
### 3. BitRobot/HIW-50025 赞，43530 下载，热度 23。下载量惊人，4.3 万次！名字 HIW 可能是“Humanoid Interaction Walk”之类的缩写？标签有 robotics 和 humanoid ，CC-BY-4.0 许可。500 条数据就敢上热门，而且下载量这么高，大概率是机器人领域稀缺的高质量运动轨迹数据。不过 500 条对于训练一个通用人形机器人策略来说杯水车薪，更适合做 finetune 或评估集。团队要是能再放大一个数量级，绝对能成为机器人社区的宝藏。
