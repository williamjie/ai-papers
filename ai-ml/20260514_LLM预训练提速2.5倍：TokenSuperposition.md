# LLM预训练提速2.5倍：Token Superposition

**日期**: 2026-05-14

---

这篇论文值得关注的核心在于：它提供了一个“即插即用”的训练加速方案。在不修改模型架构、并行策略、Tokenizer 或优化器的前提下，仅通过改变输入表示和损失函数，就在 10B 参数规模的 MoE 模型上实现了 2.5 倍的预训练速度提升。对于正在烧钱做预训练的工程师来说，这种“白嫖”效率的方法极具吸引力。
## 问题与动机大语言模型（LLM）的预训练成本高昂，主要瓶颈在于数据吞吐量（Throughput）。现有的优化手段通常分为三类：
- 信息最大化：如改进分词（SuperBPE）或多token预测（MTP），增加单样本信息密度。
- 计算稀疏化：如稀疏注意力或 MoE，减少单token的计算量。
- 压缩建模：如使用更粗粒度的输入（如字节级或n-gram），减少序列长度。
然而，大多数方法要么需要修改模型架构（增加额外Head），要么影响推理时的效率。这篇论文的核心洞察是： 训练效率与推理效率可以解耦 。我们能否在训练阶段通过“粗粒度”输入提高吞吐量，而在推理阶段保持标准的“细粒度”因果预测？答案是肯定的，这就是 Token-Superposition Training (TST)。
## 方法拆解：TST 的核心 InsightTST 分为两个阶段：超位相（Superposition Phase）和恢复相（Recovery Phase）。其核心在于两个简单的修改：
### 1. 输入叠加：Bag-of-Token-Embeddings将连续 ss 个 token 的嵌入向量（Embeddings）取平均，合并为一个“超位 token”（s-token）。
- 直觉：这相当于在训练初期让模型先“看个大概”，捕捉局部的统计结构（如共现词组、主题）。
- 效率提升：因为序列长度变成了原来的 1/s1/s，在同等 FLOPs 下，模型处理的数据量增加了 ss 倍。为了公平比较，论文在超位相将序列长度 LL 扩展了 ss 倍，确保每一步的 FLOPs 与基线一致。
### 2. 输出超位：Multi-hot Cross-Entropy (MCE) Loss既然输入是 ss 个 token 的集合，输出也预测下一个 ss 个 token 的集合。
- 损失函数：将标准的单点 One-hot CE 损失扩展为 Multi-hot CE 损失。公式简化为对 ss 个目标 token 的 CE 损失求平均：
LMCE=1∣y∣∑y∈yLCE(z,y)L_{MCE} = \frac{1}{|y|} \sum_{y \in y} L_{CE}(z, y)​=∣y∣1​∑y∈y​LCE​(z,y)
- 为什么这样设计：这种“多热”标签强制模型学习预测一组 token 的联合分布，而不是逐个预测。虽然这破坏了严格的自回归顺序（Bag-of-Tokens 内部无序），但保留了宏观的因果方向（左边的 Bag 预测右边的 Bag）。
### 3. 两阶段训练与表示对齐如果全程使用 TST，模型将失去自回归能力，输出将是随机 token 的混合概率。因此，TST 在训练一定步数（比例 rr ）后，切换回标准的 Next-Token Prediction。
- 关键发现：论文发现，如果在两阶段之间随机初始化 Embedding 和 LM Head，TST 的优势将完全消失，甚至不如基线。这说明输入和输出表示在两阶段间的连续性（Alignment）至关重要。TST 的第一阶段实际上是一种“预预训练”（Pre-pre-training），为模型提供了良好的初始化先验。

## 工程启示- 粗粒度到细粒度的调度是通用的：不仅在 LLM 中，ViT 中也有类似从粗 Patch 到细 Patch 的训练策略。TST 证明了在 Token 嵌入空间做“由粗到细”的调度是提升预训练效率的有效手段。
- 无需修改架构的加速：对于资源受限的团队，TST 是一个极佳的优化选项。它不需要修改并行策略或引入复杂的辅助 Head，只需修改数据加载（Batch 拼接）和 Loss 计算部分。
- 超参数敏感性：超位大小 ss 和超位步数比例 rr 需要调优。论文建议 s∈[4,8]s \in [4, 8][4,8]，r∈[0.2,0.4]r \in [0.2, 0.4][0.2,0.4]。过大的 ss 可能导致信息丢失过多，U 型曲线表明存在最优区间。
## 局限与展望- 数据驱动而非计算驱动：TST 的前提是“计算受限，数据充足”。如果未来预训练瓶颈转向数据枯竭，这种通过增加 Token 消耗来换取效率的方法可能不再适用。
- 长上下文性能未验证：由于 TST 阶段序列更短，可能减少了长文本截断，论文推测其对长上下文有潜在帮助，但未做详细评估。
- 推理阶段无收益：TST 仅优化预训练，推理时仍需标准解码，无法享受训练阶段的加速红利。
总之，TST 是一个简单、高效且鲁棒的预训练加速技巧。它提醒我们，在追求更复杂的模型架构之前，先看看训练数据本身的表示方式是否有优化空间。
