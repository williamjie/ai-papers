论文 : PANDO: Efficient Multimodal AI Agents via Online Skill Distillation链接 : https://arxiv.org/abs/2605.24785现在的 Agent 圈有个怪现象：为了刷高准确率，大家拼命堆算力。多轮重试、Verifier 验证、离线工具发现……这些手段确实有效，但代价是 Token 消耗呈指数级增长。这篇论文提出了 PANDO 框架，核心观点很反直觉： Agent 不应该每次任务都“从零开始”，而应该像人一样，随着经验积累变得越用越便宜。
## 痛点：Token 经济学的陷阱VisualWebArena (VWA) 上的主流方案都在玩“Token 换准确率”的游戏。
Tree Search 通过增加分支因子（ NrolloutN_{rollout} ​ ）来提升成功率；SGV 引入双通道验证器，导致单次任务成本翻倍（ ρ≈2.2\rho \approx 2.2 2.2 ）；WALT 则在评估前进行耗时的离线工具发现。
作者拆解了这些方案的成本结构，发现三个主要浪费源：
- 重复动作循环：34-42% 的失败源于 Agent 在无效操作上死循环。
- 隐藏发现成本：如 WALT 的离线探索预算通常不计入最终评估成本。
- 缓存利用率低：传统 Prompt 结构导致 KV Cache 命中率低于 11%。
## 核心设计：技能库与在线蒸馏PANDO 的名字取自“潘多”白杨林——地表看似独立的树干，地下共享根系。其核心是一个 结构化技能库（Skill Library） ，包含规则（Rules）和例程（Routines）。
- 为什么用关键词检索而非 Embedding？
为了确定性、可审计性和缓存友好性。Embedding 检索不稳定且难以利用 Prompt Cache，而基于字面关键词的匹配能确保前缀稳定，大幅提升缓存命中率。
- 动态技能生命周期：
技能不是无限积累的。PANDO 引入了**置信度降级（Confidence Demotion）**机制。如果某个例程连续失败，它会被加入黑名单并停用。这解决了传统在线学习（如 Voyager）中“过时技能污染库”的问题。
- 极性对合并：
将“最便宜”和“最贵”这类方向相反但逻辑相同的操作合并为一个参数化例程 f±(x,d)f^\pm(x, d)(x,d)，减少冗余存储。
## 实验结果：帕累托最优的突破在 VWA-910 任务集上，PANDO 的表现令人印象深刻。它不仅准确率最高，而且 Token 消耗最低。

- 成本降低：Token 消耗仅为 SGV 的 42%（少用 58%），WALT 的 39%（少用 61%）。
- 效率指标：动作重复率（ARR）降至 9.1%，缓存利用率高达 72.4%。
消融实验显示，技能学习组件（规则、例程、蒸馏）贡献了主要的准确率提升；而路由、压缩和缓存感知提示则负责将 Token 消耗从 147K 压低至 115K。
## 工程启示：如何构建高效 Agent- 经验即资产：不要每次任务都清空上下文。构建可复用的技能库，让历史成功轨迹转化为未来的“免费”能力。
- 缓存意识设计：Prompt 结构的设计直接影响推理成本。稳定的前缀和确定性检索能显著提升 KV Cache 命中率，从而降低延迟和显存压力。
- 主动遗忘机制：在线学习系统必须包含“降级”或“遗忘”模块。过时的技能比没有技能更危险，它会误导 Agent 进入错误路径。
⚠️ 反直觉发现 ：PANDO 在任务流后期（最后 310 个任务）的平均步骤降至 8.9 步，Token 降至 103K。这意味着 Agent 越用越快、越用越省 ，这与传统模型“每次推理成本固定”的特性截然不同。
## 局限与展望PANDO 目前仅在 VWA 上验证，对于 OSWorld 等需要处理像素级误触、多窗口协调的桌面任务，仍需新的规则设计。此外，极性对合并仍是语法层面的，更广泛的程序等价性发现是未来方向。
总之，PANDO 证明了通过结构化记忆和在线蒸馏，可以在不牺牲准确率的前提下，大幅降低 Agent 的运行成本。对于追求生产级落地的团队来说，这比单纯堆砌大模型更有参考价值。
