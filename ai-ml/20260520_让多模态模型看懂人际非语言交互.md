# 让多模态模型看懂人际非语言交互

**日期**: 2026-05-20

---

论文 : GRASP: Learning to Ground Social Reasoning in Multi-Person Non-Verbal Interactions链接 : https://arxiv.org/abs/2605.15764现在的多模态大模型（MLLM）看视频，往往“看得见”动作，“看不懂”关系。
在多人社交场景中，眼神接触、指指点点这些非语言信号（Non-verbal Cues）才是理解对话意图的关键。但现有模型常犯“过度思考”的毛病：它们会基于语言常识瞎猜，或者干脆忽略了具体的视觉证据。这篇来自 UIUC 和 Amazon AGI 的论文 GRASP，通过构建大规模数据集和一种新颖的强化学习奖励机制，让模型学会了“对号入座”——在推理时精准锁定参与互动的人物 ID。
### 痛点：模型在“假装”理解社交目前的 MLLM 在处理社交视频时，存在两个核心缺陷：
- 感知碎片化：以前的数据集要么只标注“谁在看哪”，要么只标注“谁在指哪”。缺乏将两者结合并关联到具体人物的结构化监督。
- 推理脱节：即使模型给出了正确答案，其推理过程往往依赖场景级先验（如“那个人在说话，所以他在指别人”），而不是真正去追踪视频中人物的视线轨迹和手势变化。
### 方法拆解：从感知到“接地”的推理GRASP 的核心贡献在于一套“数据+训练”的组合拳，旨在解决推理与视觉证据脱节的问题。
#### 1. GRASP 数据集：结构化社交图谱作者构建了一个包含 46K 视频（总计 749 小时） 的大规模数据集，包含 290K 个问答对 。
- 底层逻辑：使用 SAM 3 和 RetinaFace 提取人物 ID 和面部位置，结合 GazeAnywhere 估计视线，再调用 Gemini 识别手势（如指向、展示）。
- 社交事件图谱：将视线和手势整合成结构化的“社交事件”（如共同注视、视线跟随、互视等），形成包含时间戳、人物 ID、事件类型的统一图谱。
- 16 类推理任务：涵盖视线推理、手势推理以及视线-手势联合推理，难度从易到难递进。
#### 2. Social Grounding Reward (SGR)：强制模型“看对人”
这是本文最关键的工程洞察。传统的强化学习（如 GRPO）只奖励“答案正确”，容易导致模型通过语言捷径（Shortcuts）猜对答案，但推理过程完全错误。
SGR 引入了一个直接针对 参与者身份 的奖励信号：
- 结构化输出：要求模型在推理中显式输出 <gaze> 和 <gesture> 标签。
- 奖励公式：rgnd=wi⋅P(Pipred,Pgt(q))r_{gnd} = w_i \cdot P(P_i^{pred}, P_{gt}(q))​=wi​⋅P(Pipred​,Pgt​(q))。
它计算模型推理中提到的人物 ID与真实社交事件参与者 ID之间的精确率（Precision）和召回率（Recall）。
- 直觉：如果模型在推理中提到了无关的人物，或者漏掉了关键互动者，奖励就会降低。这迫使模型在生成推理时，必须去视频中寻找正确的视觉证据，而不是靠猜。
### 关键结果：SGR 显著优于通用 RL在 GRASP-Bench 上的实验结果非常有说服力。以下是基于 Qwen3-VL-8B 基座模型的对比（数据源自 Table 1）：
模型 视线推理 (Avg) 手势推理 (Avg) 联合推理 (Avg) 总体 (Overall) Qwen3-VL-8B-Instruct (SFT) 34.3 36.7 37.6 36.6 Qwen3-VL-8B-Thinking (GRPO) 46.3 38.8 37.6 36.6 Qwen3-VL-8B + SGR (Ours) 50.8 45.6 48.0 48.1关键发现：
- SGR 全面超越：在视线推理上，SGR 比通用的 GRPO 方法高出 +4.5%，在联合推理上高出 +10.4%。
- 通用 RL 的局限：有趣的是，使用标准 GRPO 训练的模型（Qwen3-VL-8B-Thinking）在总体准确率上甚至不如简单的 SFT 模型。这说明，如果没有明确的“接地”信号，单纯的长推理（Chain-of-Thought）反而会放大模型的幻觉和错误假设。
- 泛化能力：在 MMSI 和 TVQA+ 等外部社交推理基准上，SGR 训练的模型依然保持了强大的零样本（Zero-shot）性能，证明这种“看对人”的能力是可以迁移的。
### 工程启示- 奖励函数要“具体”：在训练多模态 Agent 时，仅依赖答案正确的稀疏奖励是不够的。引入中间步骤的约束（如本文中对特定 ID 的精确率奖励），能显著提升推理的可靠性。
- 结构化输出即监督：强制模型输出结构化标签（如 <gaze>），不仅便于后续解析，更是引导模型注意力聚焦于关键视觉区域的有效手段。
- 数据构建自动化：利用基础模型（如 Gemini、SAM）自动化构建细粒度、时间对齐的社交事件图谱，是解决大规模多模态数据标注成本高昂的有效路径。
### 局限与展望目前 GRASP 主要关注视线和手势，对于更复杂的微表情、语调等非语言信号尚未覆盖。此外，高度依赖自动化标注管道，虽然通过自优化循环（Self-refinement）提升了质量，但底层感知模型的误差仍可能累积到高层推理中。未来，如何将这种“接地”推理扩展到更复杂的多人协作场景，是极具价值的研究方向。
