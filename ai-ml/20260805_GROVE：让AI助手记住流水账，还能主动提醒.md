# ⭐⭐⭐⭐ GROVE：让AI助手记住流水账，还能主动提醒

**日期**: 2026-08-05

---

论文 : GROVE: Growing and Reasoning over Temporally Stratified Memory from Streaming Video Experience链接 : https://arxiv.org/abs/2608.02392现在的视频理解模型大多像个“被动答题机”。你问它昨天发生了什么，它去搜；你不问，它就装死。但真正的个人助理不仅要能回溯过去（Reactive QA），还得能在关键时刻主动提醒你（Proactive Assistance）。这篇 GROVE 论文解决的核心痛点是： 如何让一个系统同时具备这两种能力，且不需要重新训练模型？
### 现有方案的尴尬：记忆与行动割裂现有的视频记忆系统通常只支持“查询驱动”的回忆。比如你问“钥匙在哪”，它去检索。而主动助手（Proactive Assistants）则往往使用独立的触发机制，缺乏对长期历史的深度理解。
这就导致了一个工程难题： 我们是否需要维护两套内存？ 一套用来存碎片信息供搜索，另一套用来监控当前状态以触发提醒？GROVE 的作者认为不需要。他们的核心洞察是： 时间尺度（Temporal Scale）就是接口。
### 方法拆解：分层记忆 + 原生检索技能GROVE 的设计非常巧妙，它把连续的流式视频因果地转化为四层“地层”（Strata），每一层对应一种信息粒度和专属的检索技能：
- 感知轨迹（Perceptual Trace）：最底层。保留实体、属性、计数和屏幕文字。
技能：感知查找（Perception Lookup）。适合找“现在桌上有几个杯子”这种瞬时细节。
- 时刻（Moments）：从片段中提炼出的带时间戳的事实。
技能：时刻回忆（Moment Recall）。适合回答“周二下午我做了什么”这类具体事实查询。
- 情景（Episodes）：语义连贯的活动单元，由自适应分割器动态划定边界。
技能：情景回放（Episode Replay）。适合理解“我是怎么组装那个架子的”这种过程性问题。
- 模式（Patterns）：跨天、跨周的重复行为规律。
技能：模式遍历（Pattern Traversal）。这是 GROVE 的杀手锏，用于发现长期习惯或周期性事件。
核心 Insight ：不是把视频压缩成文本，而是让每一层内存都暴露一个“原生检索接口”。Agent 不再盲目搜索所有记录，而是根据问题类型直接调用对应尺度的技能。比如问“习惯”，直接调 Pattern Traversal；问“细节”，直接调 Perception Lookup。
这种设计使得 被动问答 和 主动服务 共享同一套记忆底层。对于主动服务，系统不需要用户提问，而是将当前的感知状态转化为检索查询，去匹配过去的模式或情景，从而决定是否需要介入。
### 关键结果：全榜单通吃，效率还更高GROVE 在五个基准测试上均取得了最佳结果，数据非常有说服力：
基准测试 指标 GROVE 得分 最强基线 (ReMA/EgoMemo等) 提升幅度/优势 EgoServe Macro-F1 12.6 EgoMemo (8.0) +4.6 ，在安全、工具使用等细粒度任务上提升巨大 MM-Lifelong Day/Week/Month 23.50 / 22.75 / 19.98 ReMA (16.75 / 18.82 / 18.62) 全天候领先，尤其在 Day 尺度上优势明显 OVO-Bench Overall 67.5 StreamBridge (62.6) 实时感知与回溯能力均衡 ESTP-Bench Contextual QA 41.0 MiniCPM-V (26.6) 上下文理解能力大幅领先更令人惊喜的是效率。消融实验显示，引入分层结构后，Agent 所需的推理轮次从 6.25 轮降至 4.95 轮 ，单问题延迟从 59.3秒降至 47.6秒 。
⚠️ 反直觉发现 ：通常认为更复杂的记忆结构会增加检索开销，但 GROVE 证明， 结构化反而降低了搜索成本 。因为 Agent 可以直接定位到正确的“地层”，而不是在扁平的海量文本中大海捞针。
### 工程启示：给 Agent 开发者的建议- 不要只存 Caption：纯文本摘要会丢失计数、属性等关键细节。GROVE 的“双重感知”（叙事+结构化痕迹）表明，保留显式的实体和动作三元组对于后续推理至关重要。
- 时间尺度即 API：在设计 Agent 的记忆模块时，考虑为不同粒度的信息设计不同的访问接口。不要试图用一个 RAG 检索器解决所有问题。
- 主动服务的触发逻辑：无需复杂的独立监控线程。将当前感知状态转化为检索 Query，去匹配历史模式，是一种低成本且高效的主动干预策略。
### 局限与展望GROVE 依然依赖冻结的视觉语言模型（VLM），如果底层感知出错，后续的记忆巩固无法挽回。此外，随着视频流时间的延长，记忆构建和多轮检索的成本仍会线性增长。未来可能需要引入更激进的遗忘机制或增量索引优化，以应对长达数月的持续观测场景。
