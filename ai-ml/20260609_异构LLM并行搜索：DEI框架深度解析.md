论文 : DEI: Diversity in Evolutionary Inference for Quality-Diversity Search链接 : https://arxiv.org/abs/2605.27130在大规模语言模型（Large Language Models, LLMs）驱动的代码生成与进化搜索中，我们通常面临一个误区：认为“堆算力”等于“堆效果”。
现有的并行方案（如 FunSearch）往往只是简单复制同一个模型的推理过程。这种同质化并行忽略了不同模型因训练数据和架构差异带来的独特归纳偏置（Inductive Biases）。
这篇来自 Gensyn 的论文提出 DEI（Diversity in Evolutionary Inference） ，通过引入异构 LLM 节点进行分布式质量多样性（Quality-Diversity, QD）搜索。其核心发现极具冲击力：在同等计算预算下，模型多样性带来的收益远超单纯的并行计算。
## 痛点：同质化并行的天花板传统分布式进化算法（如岛屿模型 Island Model）依赖随机漂移产生多样性。但在 LLM 时代，这种随机性效率极低。
如果四个节点都运行 GPT-5.2，它们生成的变异体往往落在相似的行为空间内。即使增加节点数量，也无法填补单个模型生成分布中的“盲区”。更糟糕的是，异构硬件（如本地小模型与云端大模型）延迟差异巨大，同步屏障会导致整体吞吐量被最慢的节点拖垮。
## 核心设计：异步认知并行DEI 的核心直觉是： 将不同 LLM 的独特创意先验视为互补的行为新颖性来源。
### 1. 异构节点分配每个节点绑定一个特定的 LLM（如 GPT-5.4-mini, Claude Sonnet 4.6 等）。每个模型作为独立的变异算子，负责生成和突变程序。由于不同模型的偏好不同，它们会优先填充质量多样性档案（MAP-Elites Archive）中不同的行为区域。
### 2. 异步冠军共享协议为了解决异构延迟问题，DEI 摒弃了同步屏障，采用完全异步的 All-Gather 通信模式：
- 无阻塞通信：每个节点独立推进，不受其他节点速度影响。
- 交叉对抗压力：节点每轮结束时将“冠军”程序广播给同伴。接收方将这些异模冠军加入对手池（Opponent Pool），并作为种子植入本地档案。
这种设计创造了跨模型的“红皇后效应”（Red Queen Effect）：模型不仅要战胜自己的历史版本，还要战胜其他模型生成的策略，从而驱动更强的鲁棒性。
## 关键结果：多样性即算力实验在 Core War（一种模拟计算机内程序对战的基准测试）上进行。为了公平对比，所有实验保持总 LLM 调用次数一致。
实验条件 节点数 档案覆盖率 (Coverage) QD-Score Solo (单节点基线) 1 63.0% 20.46 Homogeneous Ensemble (同质并行) 4 59.0% 29.85 Diverse Ensemble (异构并行) 4 80.6% 45.90⚠️ 反直觉发现 ：同质化并行（Homogeneous）的覆盖率甚至低于单节点基线！这说明单纯增加同一模型的并行度，反而可能导致搜索陷入局部最优，无法有效探索行为空间。
相比之下，异构集合在同等预算下实现了 +124% 的 QD-Score 提升 和 +28% 的覆盖率提升 。
在泛化性（Generality）测试中，面对一组人类编写的战士程序，Claude Sonnet 4.6 在异构环境下的胜率从单节点的 0.775 提升至 0.850。这表明跨模型竞争确实能激发出更通用、更健壮的解决方案。
## 工程启示- 异构算力整合：你不需要昂贵的 GPU 集群。本地运行的开源小模型（如 Qwen-35B）可以与云端前沿模型协同工作。异步设计确保了慢速节点不会阻塞快速节点，实现了算力的民主化利用。
- 多样性优先于规模：在 Agent 协作或代码搜索中，引入不同架构或微调背景的模型组合，比单纯增加同一模型的调用次数更有效。
- 对抗性进化价值：将其他节点的“冠军”作为对手而非简单的参考，能有效打破单一模型的自我强化循环，防止过拟合于特定的生成模式。
## 局限与展望目前实验仅限于 Core War 这一结构化强、行为特征明确的领域。对于行为空间更复杂或评估成本更高的任务（如大型软件系统开发），其有效性仍需验证。
未来方向包括动态拓扑调整（自动连接互补性最强的节点）以及为不同模型分配不同的行为描述维度，以进一步挖掘异构并行的潜力。
