# 约束下共单调改进：风险分摊的致命细节

**日期**: 2026-04-28

---

论文 : Comonotonic improvement under feasibility constraints链接 : https://arxiv.org/abs/2604.24546这篇论文戳中了量化风控的一个致命痛点： 为啥有时候加了限制，最优解反而变” chaotic “（混乱）了？
先说结论：不是所有限制都能保持”共单调性”（comonotonicity）——这个我们默认的好性质。有些限制（比如 VaR 上限）会直接把它干碎，导致最优分摊方案不再是 aggregate loss 的单调函数。更关键的是，文章给出了一个简单的判别准则： componentwise convex-order solidity （分量凸序solidity）。
## 问题：为啥要关心共单调性？
在无约束风险分摊中，有个经典定理（Borch, 1962; Landsberger & Meilijson, 1994）：对于凸序一致偏好（convex-order-consistent preferences），任意帕累托最优分配都存在一个 共单调代表 ——每个 agent 的损失都是 aggregate loss S 的非减函数。
这意味着啥？分摊问题退化成一维重排：你只需要决定 S 的”切片”怎么切，不用处理高维耦合。这在实践中太重要了： 交易系统、再保险合约、资本分配 ，我们都希望分摊规则简单透明、可解释、可计算。
但现实呢？到处都是限制：
- 偿付能力II（Solvency II）的 VaR 资本上限- 再保险合同的 capacity limit- 巨灾债券的 attachment/exhaustion points- 每个 agent 的免赔额（deductible）
问题是：这些限制会不会破坏共单调性？论文说： 会，而且方式很诡异。
## 核心 insight：solidity 就是一切关键定义 ：一个可行集 X ⊆ An(S) 是 componentwise convex-order solid 的，如果：
对任意 X ∈ X 和任意 Y ∈ An(S)，只要 Yi ≤cx Xi 对所有 i 成立，就有 Y ∈ X。
翻译成人话： 如果你把某个 agent 的损失替换成一个”更稳”（凸序更小）的随机变量，结果还在可行集里，那这个可行集就是 solid 的。
为什么这很重要？因为共单调改进定理（Theorem 1）本质就是把每个 Xi 换成一个凸序更小的 X̄i。如果这个操作能把你踢出可行集，共单调性就没了。
Theorem 2（受约束共单调改进定理） ：如果可行集非空且 solid，那么：
- 任何可行分配都有 solid 内的共单调改进- 受约束下确界等于共单调受限下确界- Pareto 最优分配存在 solid 共单调代表重点 ：solid 是 preference-free 的，只要满足一次，所有凸序一致偏好都享受共单调缩减。
## 三类”致命”限制（破坏 solidity）
### 1. 私有 deductible 依赖 idiosyncratic state（Example 1）
设两个 agent 独立抛硬币，ζ1, ζ2 ~ Bernoulli(0.5)，S = ζ1+ζ2。每人有 deductible d=1：损失低于 1 时全额自留，不低于 1 时至少留 1 本身。
约束：Xi = ζi on {ζi < 1}（自留全部），Xi ≥ 1 on {ζi ≥ 1}。
问题 ：这个约束耦合了 Xi 和 idiosyncratic σ-algebra Gi = σ(ζi)，超出了 σ(S) 的范围。
结果 ：自持分配 (ζ1, ζ2) 可行，但条件期望 (S/2, S/2) 虽然在凸序下更优（X̄i ≤cx Xi），却违反了”{ζi=0} 上 Xi=0”的要求——因为在原子 (0,1) 上，Y1=0.5 ≠ 0。
破坏模式 ：约束依赖 S 之外的私有状态，共单调改进无法控制 Xi 与 ζi 的路径耦合。
### 2. 固定自付额 + 巨灾容量跳升（Example 2）
S 取值 {1,2,3} 各 1/3 概率。条约规定：S≤2 时 X1=1/4；S=3 时 X1∈[1/4, 7/4]。即非巨灾状态固定赔付，巨灾状态有弹性容量。
偏好：ρ1=ES0.2，ρ2=ES0.333（Expected Shortfall）。
计算 ：
- 任意可行分配：X1 = 1/4·1{S≤2} + a·1{S=3}，a∈[1/4, 7/4]- ρ1(X1)+ρ2(X2) 关于 a 严格递减 → 最优 a*=7/4（用满巨灾容量）
- 共单调要求 X2=S-X1 非减 → a≤5/4- 受约束最优值：19/8 = 2.375- 共单调受限最优值：29/12 ≈ 2.4167- 差距：1/24 ≈ 0.0417 > 0 → 共单调缩减失效几何解释 ：共单调等价于 1-Lipschitz 条件：X1(3)-X1(2) ≤ S(3)-S(2)=1。但约束允许从 (2,1/4) 跳到 (3,7/4)，斜率 1.5 > 1，X2 在 S=3 时反而下降。
机制 ：约束在巨灾层允许”超额跳升”，而共单调性强制两 agent 的分配在 S 每单位增量上的变化之和为 1。
### 3. VaR 上限（Example 3）
最致命的反例：VaR 上限直接破坏 solidity。
设定：四个互斥事件 A0, A1a, A1b, A2，概率分别为 0.9925, 0.0025, 0.0025, 0.0025。设 A1 = A1a∪A1b（P=0.005）。
endowment：ζ1=ζ2 = 1_A1 + 2·1_A2，故 S=2·1_A1 + 4·1_A2。
偏好：ρ1=ES0.99，ρ2=ES0.9925。
约束：Xi ≥ 0 且 VaR0.995(Xi) ≤ 1（Solvency II 式 VaR 帽）。
计算 ：
- 自持分配：(ζ1, ζ2) 满足 VaR0.995(ζi)=1，可行且共单调- 受约束最优解 (非共单调)：
X1 = 1_A1a + 2_A1b + 4_A2，X2 = 1_A1a总风险：25/12 ≈ 2.0833- 共单调受限最优解：
X1 = 1_A1 + 3_A2，X2 = 1_A1 + 1_A2总风险：9/4 = 2.25- 差距：2.25 - 2.0833 = 0.1667 > 0机制 ：VaR 上限允许在 S=2 的层（A1a∪A1b）内”选择性分配”——X1 在 A1a 取 1、A1b 取 2，而 S 相同。共单调强制 Xi 在 S 的每个水平集上为常数，无法利用这种不对称分配来降低总风险。
监管启示 ：VaR 的非凸性导致”拆分套利”——Weber (2018) 指出 Solvency II 下拆分子实体几乎能把 VaR 资本压到零。论文指出： 用 ES 替换 VaR 即可恢复 solidity ，因为 ES 是凸序一致的。
## admissible 限制家族（Theorem 3）
哪些限制是 solid 的？论文给出充分条件：
限制类型 数学形式 是否 solid 实例 确定性上下界 ℓ ≤ Xi ≤ u a.s. ✓ 合约Capacity上限、底线 线性期望约束 E[Xi] ≤/=/≥ c ✓ 保费预算、公平性约束 Orlicz型边界 E[φ(Xi)] ≤ c（φ凸下有界） ✓ Lp范数、熵边界、方差上限 风险测度上限 ϱ(Xi) ≤ c（ϱ凸序一致） ✓ ESα 上限、谱风险测度 VaR上限 VaRα(Xi) ≤ c ✗ Solvency II 标准资本要求 私有deductible Xi = ζi on {ζi<d} ✗ 基于自留额的保留规则Corollary 1 ：确定性容量上限 {0 ≤ Xi ≤ Ki} 是 solid 的。这在再保险、限额交易、公私合营池中很常见。
注意 ：S 相关的路径界 ℓ(S) ≤ Xi ≤ u(S) 不一定 solid，除非能证明满足凸序封闭——Example 2 显示即使 ℓ,u 非减，斜率超过 1 也会破坏 solidity。
## 均值-方差分摊的工程启示（Section 6）
无约束 ：ρi(X)=E[Xi]+δi Var(Xi)，最优是比例分摊：Xi ∝ 1/δi。
加 deterministic cap Ki （solid）：
- 未饱和 agent 按风险容忍度比例分摊- 一旦某人触限，剩余损失由其他人按比例吸收- 分摊规则变为分段仿射，在 saturate point 切换斜率加 VaR 上限 （non-solid）：
- 共单调比例分摊可能不可行- 最优解可能非共单调，需要求解完整高维问题实操建议 ：
- 设计合约/监管规则时，优先选 ES 而非 VaR- Capacity 上限要用 deterministic constant，别用 S 相关的滑动窗口- 免赔额尽量设计成基于 aggregate loss 而非 individual loss- 若必须用复杂约束，先验 solidity：任何”降低某 agent 风险会让其更易满足约束”的机制通常是对的## 局限与边界论文假设：
- 原子化概率空间（atomless）——实际离散数据需谨慎- L1 可积损失——重尾分布可能需要额外正则性- 凸序一致偏好——非凸偏好（如谷底风险规避）不适用- 无交易成本/摩擦——现实市场不完全未覆盖场景 ：
- 多期动态分摊- 异质信念（heterogeneous beliefs）——论文提到 Boonen & Ghossoub (2020) 在不同偏好下共单调性也失效- 博弈论内生约束（如道德风险）
## 最后说两句这篇论文的价值不在”提出新算法”，而在 厘清边界条件 。它告诉我们：
- 共单调性不是自动免费的：你以为加个合理限制不会破坏结构？Examples 2-3 告诉你，连”固定自付额+巨灾弹性”这种常见结构都会破坏。
- VaR 的缺陷不止是次可加：在风险分摊中，VaR 会诱导 agent 把损失”扔到尾部看不见的角落”，因为 VaR 只看分位点。ES 就不会。
- 设计约束要遵循”降低风险→更容易满足”的原则：这就是 solidity 的直觉。如果某个 agent 主动降低自身风险波动，结果反而不满足约束（如 VaR 上限下拆分实体），那这个约束就是在奖励赌博。
对量化风控工程师的 TL;DR：
- 再保险合约：capacity 用固定上限，别用 S 相关的滑动窗口- 监管报表：如果监管用 VaR，内部资本配置要考虑非共单调效应- 交易系统：多策略组合时，若单策略有 VaR 限制，组合优化可能找不到共单调解- 模型验证：检查约束集是否 convex-order solid——测试方法：取一个可行解，把每个分量独立”平滑化”（convex-order reduction），看是否仍可行分数 ：8.5/10。理论严谨，例子狠辣，工程指向明确。唯一缺憾是没给非 solid 情况下的数值求解指南——但这不是它的任务。
