# ⭐⭐⭐⭐ ReSGA：大模型如何重塑尾部风险预测

**日期**: 2026-06-04

---

论文 : ReSGA: A Large Tail Risk Model for Learning Value-at-Risk and Expected Shortfall链接 : https://arxiv.org/abs/2606.04576在 NLP 领域，大语言模型（LLM）已经证明了“规模即正义”。但在量化金融中，我们是否也能用类似的大模型思路来预测 Value-at-Risk (VaR) 和 Expected Shortfall (ES)？这篇来自港大与厦大的论文给出了肯定的答案。
传统的风控模型往往受限于参数数量，容易因模型误设（Model Misspecification）而失效。作者提出了 ReSGA （Retrieval-enhanced Self-grouping Autoencoder），一个拥有数百万参数的“大型尾部风险模型”。它不再为每只股票单独建模，而是利用海量截面数据和长时序动态，学习资产间的潜在关联。
### 为什么现有方案不够用？
ES 作为一致性风险度量（Coherent Risk Measure），比 VaR 更能捕捉极端下行风险。但 ES 本身不可激励（Not Elicitable），无法直接通过损失函数最小化来估计。
现有的主流方法通常基于 GARCH 或 GAS 等半参数模型，或者简单的机器学习回归。这些方法有两个致命弱点：
- 孤立建模：每只股票独立训练，忽略了市场中的传染效应和截面相关性。
- 信息利用率低：难以同时处理长达近百年的时序数据和上百个因子特征。
### ReSGA 的核心设计直觉ReSGA 的架构灵感来自 Transformer 和图神经网络，但针对金融风险做了专门定制。其核心由三个模块组成：
- Encoder（编码器）：提取资产的时序特征，并学习资产间的潜在分组结构（Latent Group Structures）。这意味着模型会自动发现哪些股票在风险行为上是相似的，无论它们的行业标签是否一致。
- Retriever（检索器）：这是 ReSGA 的杀手锏。它允许每只资产从其所在组的历史“经验”中检索信息。这不仅包括自身历史，还包括同组其他资产的长期历史表现。这种机制有效捕捉了**长记忆效应（Long Memory Effect）**和系统性风险的溢出。
- Decoder（解码器）：聚合组级、检索级和资产级的信息，输出最终的 VaR 和 ES 预测值。
为了处理 ES 不可激励的问题，作者构建了一个统一的深度学习框架，通过 Softplus 映射将潜在风险分数转换为满足 ES<VaR<0ES < VaR < 0 V a R < 0 约束的有效预测值，并直接最小化 Fissler-Ziegel (FZ) 损失函数。
### 关键实验结果：数据复杂度胜过模型复杂度作者在 1926-2023 年美国股票数据（超 4 万只股票，153 个因子）上进行了回测。以下是 ReSGA 与 12 个基线模型的对比表现：

- 全面碾压传统模型：ReSGA 在所有市值分组（从 Mega 到 Nano）中均取得最低损失。相比传统的 GARCH/GAS 模型，损失降低了约 30%。
- 截面信息至关重要：Spatial-temporal 模型（如 ReSGA, SGA）显著优于纯时序模型（如 LSTM, GRU），说明捕捉资产间的联动关系对尾部风险预测极具价值。
- 统计检验通过：在 Diebold-Mariano (DM) 测试中，ReSGA 显著优于除 SGA 外的所有模型；在 Model Confidence Set (MCS) 测试中，仅 ReSGA 和 SGA 保留在最优集合中。
⚠️ 反直觉发现：Scaling Law 的真相作者进行了系统的缩放分析（Scaling Analysis），发现 性能提升主要驱动力是数据复杂度（Data Complexity），而非模型复杂度（Model Complexity） 。
单纯增加参数量并不总是带来收益，最佳性能出现在中等规模参数时。然而，随着训练数据量的增加，所有模型的性能都呈现清晰的改善趋势。这意味着，在尾部风险预测中，“喂给模型更多、更丰富的历史数据”比“堆砌更大的神经网络”更有效。
### 工程启示：从风控到 Alpha 挖掘-左侧重动量策略（Left-side Momentum）：
ReSGA 的预测结果可以直接用于构建多空组合。作者提出了一种结合市值增强的左侧重动量信号：买入低尾部风险股票，卖出高尾部风险股票。该策略在 Fama-French 五因子模型下产生了显著的 Alpha，且 Sharpe Ratio 在所有对比模型中最高。
-可解释性与迁移学习：
特征重要性：ReSGA 的预测能力主要集中在 Value、Low Risk、Momentum、Quality 和 Short-Term Reversal 这五个经济主题上。
- 跨市场通用性：仅在美国数据上训练的 ReSGA，无需微调即可在中国、日本、英国等市场保持可靠的预测性能。这表明尾部风险的驱动因子具有跨市场的普遍性。
-系统架构建议：
对于金融科技工程师，构建下一代风控引擎时，应考虑引入检索增强机制。传统的滑动窗口处理时序数据可能丢失长期结构性变化，而通过聚类分组并检索同类资产的历史极端事件，能显著提升对黑天鹅事件的敏感度。
### 局限与展望尽管 ReSGA 表现优异，但其依赖大量历史数据和因子特征。对于新兴市场或数据稀缺的资产类别，其优势可能减弱。此外，模型的黑盒性质仍需通过诸如 SHAP 值等工具进一步解释，以满足合规要求。
总体而言，ReSGA 证明了在尾部风险预测领域，利用大规模数据和复杂空间-时间结构是可行的，且能带来显著的经济收益。这为量化金融中的“大模型时代”提供了一个具体的落地范式。
