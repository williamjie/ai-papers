# 波动率也要带记忆？LOV模型如何一箭双雕拟合美式期权

**日期**: 2026-04-30

---

论文 : Pricing with Passion: The Local Occupied Volatility (LOV) Model链接 : https://arxiv.org/abs/2604.26151一句话说清楚这篇论文在干嘛： 用”占据测度”给波动率加上记忆，一箭双雕同时拟合美式看涨/看跌期权 。这不是那种”换个激活函数”的灌水文章，而是切中了量化实操里一个真实痛点。
## 问题从哪来？美式期权的分裂现场想象一下你在交易Amazon（AMZN）期权。美国单只股票期权都是美式，但由于Amazon不分红， 看涨期权价格等于欧式 （Merton 1973结论）。但看跌期权不同——持有者可以提前行权拿现金，所以含有”提前行权溢价”。
市场报价是这样的：
c_A(K,T) = c_E(K,T) // 看涨：美式=欧式p_A(K,T) > p_E(K,T) // 看跌：美式>欧式（有溢价）
问题来了 ：如果你只用Dupire局部波动率（Local Vol, LV）模型，它能完美拟合所有欧式期权，但 必然低估美式看跌期权 ——因为LV是完全马尔可夫模型，没有路径记忆，算不出提前行权溢价。
论文里直接点出核心矛盾（第1页）：
The put options do carry an early exercise premium, and there is no guarantee that the local volatility model generates exactly the observed put option quotes.
这就是 联合美式-欧式校准问题 ：一个模型既要拟合欧式看涨（微笑曲面），又要拟合美式看跌（提前行权价值）。传统LV做不到，必须引入路径依赖。
## 核心洞察：波动率也需要”记住自己怎么走过来的”
论文给出的解法很Geek： 不是增加一个随机因子，而是给波动率注入对资产路径的记忆 。具体来说，引入了 占据测度（Occupied Measure） ：
O_t(A) = ∫_0^t 1_A(X_s) e^{κs} ds直观理解：这个积分记录了资产价格在区域A里”停留了多久”，但加了指数衰减权重e^{κs}—— 越近的路径权重越高 。κ=0是时钟时间，κ>0则让模型更关注最近走势，能捕捉波动率聚类现象。
然后， 波动率变成占据测度的函数 ：
σ_t = σ(O_t, X_t)
这就是**占据随机微分方程（OSDE）**框架。好处是什么？
- 路径依赖，但市场仍然完备（可以动态复制任何衍生品）
- OSDE可以简化为有限维马尔可夫系统，模拟效率高（不像传统路径依赖需要存历史）
## 技术核心：一阶马尔可夫展开如何保证微笑校准但这里有个关键矛盾：如果波动率完全依赖路径，定价时会很麻烦。论文的突破点在**“一阶马尔可夫展开”**（Section 3.1）。
核心公式（17）：
σ²_t = σ²_loc(t, X_t) + ℓ(t, X_t) · (F_t - F̂_t)
- σ²_loc：Dupire局部方差（来自欧式期权市场数据）
- F_t：路径特征函数（这里是占据测度O_t）
- F̂_t：条件期望E[F_t | X_t]（在给定当前价格下，占据测度的”投影”）
- ℓ：敏感性函数（Sensitivity Function），可以调整的自由度关键设计是 中心化项 (F_t - F̂_t) 。展开后取条件期望：
E[σ²_t | X_t] = σ²_loc(t, X_t) + ℓ(t, X_t)·E[F_t - F̂_t | X_t] = σ²_loc(t, X_t)
因为E[F_t - F̂_t | X_t] = 0。 这自动保证了欧式期权微笑校准条件 （公式14）。
这招太聪明了： 引入路径依赖，但通过中心化设计不破坏欧式期权定价 。在此基础上，敏感性函数ℓ就可以”自由发挥”去拟合美式看跌期权。
## LOV模型的具体形式将F_t=O_t代入，Frechét导数变成线性导数δ_O，最终得到 局部占据波动率（LOV）模型 （公式21）：
σ²_t = σ²_loc(t, X_t) + γ_t^κ ∫_{R+} ℓ(t, X_t, x) (O_t - Ô_t)(dx)
其中：
- γ_t^κ = O_t(R)^{-1} 是归一化因子（让ℓ的幅度保持稳定）
- Ô_t = E[O_t | X_t] 是条件投影- ℓ(t, X_t, x) 是核心：在每个位置x上的敏感性函数正性保证 （Proposition 1）：如果|ℓ| < ½σ²_loc，则σ²一定>0。给了实践者一个安全边界。
两个特例 （Section 3.2）：
- 单走廊LOV：只关心资产在某个区间A的停留时间。如A=[X₀,∞)（上涨区域）配合β>0可模拟杠杆效应（价格跌→波动升）。
- EMA-LOV：ℓ ∝ log x，对应指数移动平均（EMA）的路径偏差，捕捉趋势反转。
## 实验数据：AMZN期权上的实战表现论文用了 Amazon (AMZN) 2025年9月15日 的期权数据进行校准，数据量：
- 533个合约（275个看涨 + 258个看跌）
- 前五个月份的连续到期- 剔除bid-ask spread >25%的 Illiquid 合约- 无风险利率 r=3.7%训练资源消耗 （第13页）：
- 训练时间：10分钟（Apple MacBook Pro M3，纯CPU）
- 定价时间：20秒（212对反周期路径）
- 时间步长：δt = 1/252（日频）
- 占据分区：M=26-1=63个区间- 神经网络：2隐藏层 × 64节点（ReLU + Softplus）

## 工程落地价值：这东西能用来干嘛？
### 1. 交易策略：美式期权套利机会发现传统定价引擎对美式看跌期权普遍存在偏差。LOV提供了一个 同时校准欧式+美式 的统一框架，适合：
- 美式看跌期权相对价值套利- 提前行权边界动态监控（提前行权溢价变化）
- 波动率曲面包容性检验（同时检验欧式微笑和美式溢价是否自洽）
### 2. 风险控制：尾部风险 recalibration美式看跌期权在极端行情下的提前行权价值会飙升。LOV通过路径依赖捕捉这种 非对称风险 ，比LV在尾部场景更稳健。
### 3. 定价引擎升级路径LOV的模拟 不存储历史路径 ，只需维护占据区间的积分值（M个状态变量）。从工程上：
- 可无缝集成到现有LSMC定价框架- 神经网络参数化ℓ，支持GPU加速训练- 时间复杂度比传统随机波动率模型更低### 4. 数据需求：中等- 需要美式看跌报价（美股单名期权）
- 从欧式看涨提取局部波动率（Dupire公式）
- 无需额外另类数据，纯期权市场数据即可## 局限与待解问题（作者自己承认的）
-股息场景未覆盖（Section 5）：
有股息时，看涨期权也有提前行权溢价，微笑校准条件被破坏。作者说需要重新参数化σ_loc和ℓ，并用”去美式化”预处理，但这会引入模型风险。
-敏感性函数的经济解释待明确：
校准出的ℓ(x)在历史测度下的经济含义没有深挖。为什么非递增？是否意味着市场定价没有充分反映杠杆效应？
-三维校准的数值挑战：
敏感性函数ℓ(t,X_t,x)本质是三维函数。论文用了时间齐次假设（ℓ不显含t），大幅简化了问题。但若允许时间依赖，校准空间会爆炸。
-外推风险：
占据测度强调近期路径，对远期期权的影响函数设计需要谨慎，否则外推可能不稳定。
## 个人判断：一篇认真解决问题的实用主义论文这不是那种”换个损失函数”的AI+量化水文。它针对的是 衍生品定价中的一个经典gap ——欧式与美式期权的联合校准。方法设计干净：
- 用占据测度作为路径记忆的”压缩表示”（避免维度灾难）
- 一阶展开保证欧式校准自动满足- 神经网络参数化ℓ，让美式拟合有自由度落地评分 ：★★★★☆- 问题精准：✓ 美式看跌溢价实打实的存在- 方法新颖：✓ 占据测度+马尔可夫展开的组合- 工程可行：✓ 10分钟训练，20秒定价，MacBook可跑- 数据充足：✓ AMZN 533个期权，5个期限链实测- 适用面：◯ 目前仅验证无分红美股，股息场景待补如果你在做 期权做市、波动率曲面套利、或衍生品风险管理系统 ，这篇论文的LOV模型值得纳入候选框架。它没承诺”颠覆市场”，但实实在在地把一个问题包装成一个 可计算、可校准、可解释 的模型。
