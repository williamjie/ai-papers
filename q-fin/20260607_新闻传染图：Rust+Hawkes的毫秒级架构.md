# ⭐⭐⭐ 新闻传染图：Rust+Hawkes的毫秒级架构

论文 : Zero-Copy Semantic Contagion: An In-Memory Streaming Architecture for Evolving Attention Graphs链接 : https://arxiv.org/abs/2606.05733大多数量化团队还在用单标的模型预测价格，却忽略了跨公司的信息传导。这篇论文提出了一套 Rust + PyTorch 的流式架构，利用零拷贝解析和连续时间 Hawkes 过程，在毫秒级延迟下捕捉新闻引发的语义传染（Semantic Contagion）。
### 痛点：单标的模型的“盲区”
传统的时间序列模型（如 LSTM、Transformer）通常只关注单个股票的历史价格和情绪。但市场是联动的：台积电的工厂扰动会瞬间影响苹果的预期，而单标的模型在苹果股价真正波动前对此一无所知。
现有方案有两个工程硬伤：
- 语义提取器太慢，几百毫秒的延迟已经超过了新闻影响的预测窗口（通常 20-60 分钟）。
- 静态图无法表达注意力的快速衰减，缺乏连续时间动力学。
### 方法拆解：Rust 边缘 + Hawkes 核心作者设计了一个异构架构，将微秒级的摄入与毫秒级的推理解耦。
1. Rust 零拷贝摄入层（Ingestion Edge）
这是工程亮点。使用 Rust 实现零堆分配解析，直接返回字节切片引用。
- CSV/FIX 记录解析：~100 ns- 47 个标的扫描：~1.2 𝜇s- 单调时间戳强制：~25 ns总摄入延迟仅 ~2.1 𝜇s，相比纯 Python 方案提升了两个数量级。
2. 连续时间神经 Hawkes 过程（c-LSTM Hawkes）
推理端使用 PyTorch，每个节点维护一个 c-LSTM 隐藏状态。
- 双边潜投影（Bilinear Latent Projection）：计算有向激发 αij\alpha_{ij}​，允许非对称关系（如上游供应商对下游的影响远大于反向）。
- 自适应剪枝：当瞬时激发低于阈值时切断边，保证图密度有界，防止计算成本随流长度二次增长。
### 关键结果：图拓扑是唯一信号源在 FNSPID 数据集（2022年7月，47个标的，638篇文章）的测试中，模型表现如下：
指标 全模型 (Full) 随机基准 (Random) 同行业启发式 (Sector) 90th百分位精度 15.1% 8.9% 4.5% 提升倍数 - 1.70x 3.36x⚠️ 反直觉发现 ：消融实验显示，如果移除图拓扑（Graph Topology），精度直接归零。这意味着 c-LSTM 的动态和基准率本身不产生跨公司信号， 图结构是唯一的驱动力 。此外，双边投影和剪枝机制在当前稀疏数据集上并未提升精度，但保留了架构的不对称性和计算边界保证。
### 工程启示：从预测到传导- 特征工程新范式：该模型输出的“传染强度向量”可作为下游预测器的额外特征。它回答的不是“苹果明天涨多少”，而是“鉴于某新闻，哪些股票最可能异动”。
- 延迟预算分配：端到端延迟 ~13 ms（单 CPU），其中 80% 花在句子嵌入上。工程优化应聚焦于量化嵌入模型或蒸馏，而非解析层。
- 高频适用性：Rust 边缘可编译至 x86-64，配合 RDTSC 时间戳和 DPDK，摄入延迟可压至百纳秒级，具备接入日内高频策略的潜力。
### 局限与展望- 数据粒度：当前评估基于日线 OHLCV，导致预测领先时间长达 48-61 小时。未来需接入分钟级 TAQ 数据以验证微观结构下的 20-60 分钟传导窗口。
- 规模扩展：目前仅测试 47 个标的。作者预估扩展到 500 节点时，单线程推理可控制在 50 ms 以内，但需依赖批量邻域计算优化。
这套架构证明了，通过精心设计的系统栈（Rust 零拷贝 + Hawkes 连续时间），可以在不牺牲延迟的前提下，将定性新闻转化为定量的跨资产风险信号。对于构建另类数据驱动的宏观对冲或供应链交易策略，具有直接的参考价值。
