# 用LLM给金融网络去噪

**日期**: 2026-04-22

---

论文 : Cross-Stock Predictability via LLM-Augmented Semantic Networks链接 : https://arxiv.org/abs/2604.19476文本嵌入相似性不等于经济关联性。两个公司都在10-K里大谈”供应链中断”，不代表它们有业务往来。这篇论文直指这个痛点，用 LLM 做关系分类，给语义金融网络去噪。
## 问题：嵌入网络里的”假朋友”
基于10-K文件嵌入构建公司网络的做法越来越流行。思路很直观：把每个公司的披露文本编码成向量，计算余弦相似度，连出 top-K 邻居，得到一张语义网络。然后用这张网络做跨股票预测——经济关联公司的价格偏离往往会在未来均值回归。
但这里有个致命问题： 文本嵌入捕捉的是主题相似性，不是经济因果关系 。
两家公司都在年报里讨论”监管不确定性”和”供应链风险”，它们的嵌入向量会靠得很近。但价格发散并不携带任何均值回归信息——它们只是碰巧在聊同一个宏观话题。论文把这种边称为 spurious correlations（虚假相关） 。
这不只是理论问题。论文显示，用随机图代替语义网络，Sharpe 从 0.742 暴跌到 0.541，t统计量降到1.61不再显著。但反过来也成立：如果网络里有大量噪声边，真实信号会被稀释。
## 方法：先检索，再推理论文提出一个 Retrieve-then-Reason 两阶段框架：
第一阶段：轻量检索对 N 只股票，计算全量余弦相似度矩阵，每只股票保留 top-K 最近邻，对称化后得到候选图。复杂度从 O(N²) 降到 O(NK)，让后续 LLM 推理变得可行。
第二阶段：LLM 关系分类这是核心。对每条候选边 (v_i, v_j)，构造一个结构化 prompt：
- 从两家公司前一年的10-K中各抽取三段文本：Item 1 商业描述、产品/分部披露、竞争对手相关句子- 公司身份被匿名化为 “Firm A” 和 “Firm B”，防止 LLM 依赖记忆中的具体股票代码- LLM 从六个互斥类别中选择一个：competitor、supply chain、complementary、substitute、peer、unrelated- 输出结构化 JSON，包含标签和证据片段然后对关系做差异化处理：
- competitor（竞争者）边：直接移除。竞争者的价格发散反映的是结构性市场份额变化，不是暂时性定价偏差，不存在均值回归- substitute（替代品）边：降权- 其他关系边保留，用于后续信号聚合信号聚合：Gatev 距离加权 softmax对每条边计算滚动窗口的价差 z-score，然后用 per-stock softmax 聚合：
w_ij ∝ ω_r · exp(-d_ij)
其中 d_ij 是 Gatev 距离（标准化价差路径的累计平方和），距离越小（历史共运动越紧密）权重越高。degree 大的股票还会用 ni 做缩放，保持信号量级。

2. 关系类型 > 连接强度传统网络方法假设”越相似=越相关”，但论文证明关系类型更重要。竞争者关系不仅不该纳入均值回归信号，还会带来结构性噪音。实际工程中， 给边打标签再按类型差异化处理 ，比单纯用相似度阈值截断有效得多。
3. 匿名化 prompt 防止记忆偏差把公司匿名化为 Firm A/B 是个简单但关键的细节。LLM 训练数据里包含了大量公开公司信息，不匿名化时模型可能直接”记住”了两家公司的关系而不是真正推理。这个细节很多工程实现会忽略。
4. Gatev 距离加权是有道理的不是所有关联边同等重要。历史共运动更紧密的对子（距离更小），均值回归的统计基础更强。用 softmax 做距离加权比等权聚合更稳健，波动率更低。
## 局限与展望论文自己也提到了几个边界：
- 数据源单一：只用10-K文本，缺少实时新闻、供应链数据库等结构化数据- 年度静态图：经济关系是动态变化的，年度更新可能滞后- LLM 作为独立分类器：未来可以集成到 GNN 等可学习模型中，端到端优化- 截断导致信息损失：prompt 有 token 预算限制，关键信息可能被截断## 一句话总结用 LLM 给语义金融网络做关系分类和边过滤，把竞争者边踢出去，把供应链和互补关系留下来，Sharpe 提升 0.078，回撤缩小 262bp。核心 insight 是： 在量化金融中，知道谁和谁”没有关系”，往往比知道谁和谁”相似”更重要。
