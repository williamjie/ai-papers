论文 : Bootstrap inference in autoregressive duration models链接 : https://arxiv.org/abs/2607.28294做高频交易或微观结构分析，你肯定用过自回归条件持续时间（Autoregressive Conditional Duration, ACD）模型。但在给参数算置信区间时，你是不是直接套用了GARCH那套“大样本正态近似”？如果数据存在厚尾，你的风控模型可能正在失效。
这篇论文直击痛点： ACD模型的样本量是随机的 。
在固定时间窗口内，交易次数（即样本量 nn ）是由随机过程生成的。传统Bootstrap假设样本量固定或确定，这在ACD里是个伪命题。作者证明了，只要选对Bootstrap策略，即便在极端厚尾场景下，推断依然稳健。
### 核心痛点：随机样本量带来的陷阱ACD模型与GARCH不同。GARCH通常处理等频数据，样本量 NN 是确定的。
而ACD处理的是事件间隔（如两笔交易的时间差）。
在固定日历时间 TT 内，观测到的持续时间数量 n(T)n(T) 是一个随机变量。
⚠️ 关键直觉 ：当持续时间分布具有厚尾（Tail Index κ≤1\kappa \le 1 1 ）时，样本量 n(T)n(T) 的增长速度远慢于时间 TT 。这导致估计量的渐近分布不再是标准正态，而是混合正态（Mixed Normal）。
如果你无视这一点，直接用标准误算置信区间，覆盖率会严重不足。
### 方法拆解：固定计数 vs 随机计数作者对比了两种Bootstrap重采样策略：
-随机计数 Bootstrap (Random-count)：
保持原始时间跨度 TT 不变。
- 递归生成Bootstrap持续时间，直到累计时间超过 TT。
- 缺陷：在厚尾情况下，Bootstrap生成的样本量 n∗(T)n^*(T)(T) 波动极大，导致估计不稳定，置信区间过宽。
-固定计数 Bootstrap (Fixed-count)：（推荐）
保持原始观测到的事件数量 n(T)n(T) 不变。
- 直接重采样 n(T)n(T) 个残差，生成Bootstrap序列。
- 优势：计算稳定，且在 κ≥1\kappa \ge 11 时具有一阶有效性；即使在 κ<1\kappa < 11（无限均值）的极端情况下，其分位数推断依然有效。

### 工程启示：高频系统该怎么改？
对于量化工程师，这篇论文给出了明确的落地指南：
- 弃用标准误：在构建基于ACD/Duraton模型的风控指标或信号置信带时，不要依赖 summary() 输出的标准误。
- 实施固定计数残差重采样：
计算拟合残差 ϵ^i=xi/ψ^i\hat{\epsilon}_i = x_i / \hat{\psi}_i^i​=xi​/ψ^​i​。
- 对残差进行有放回重采样，保持样本量 nn 不变。
- 基于重采样数据重新估计参数，构建经验分布。
- 处理厚尾：加密货币ETF等资产的交易间隔往往具有厚尾特征（κ<1\kappa < 11）。此时固定计数Bootstrap是唯一能保证推断有效性的低成本方案。
### 局限与展望- 计算成本：虽然比随机计数稳定，但每次重采样都需要重新最大化似然函数。在超高频数据（百万级tick）下，需考虑并行化或近似算法。
- 模型扩展：论文主要验证了ACD(1,1)，但对于更复杂的非线性持续时间模型，其渐近性质仍需单独验证。
这篇论文不是理论象牙塔里的游戏，而是给高频策略风控补上了最后一块拼图： 在随机样本量下，用对Bootstrap，你的置信区间才不会骗人。
