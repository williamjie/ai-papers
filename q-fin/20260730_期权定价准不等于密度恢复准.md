# ⭐⭐⭐½ 期权定价准不等于密度恢复准

**日期**: 2026-07-30

---

论文 : Inverse Learning of Latent Risk-Neutral Densities from Irregular Option Quotes链接 : https://arxiv.org/abs/2607.27188很多量化团队在构建风险中性密度（Risk-Neutral Density, RND）时，习惯用“定价误差小”来代理“密度恢复准”。这篇论文直接戳破了这个幻觉： 准确的期权价格并不保证能准确恢复潜在的 RND。 对于做尾部风险管理和极端情景分析的工程师来说，这是一个必须警惕的工程陷阱。
### 痛点：观测稀疏与逆问题病态现实市场给出的期权报价是稀疏且不规则的（Irregular Option Quotes）。传统流程通常是平滑隐含波动率曲面，再通过 Breeden-Litzenberger (BL) 公式求二阶导数得到密度。
但这带来了两个被混淆的问题：
- 可观测价格重构：模型能否复现看到的报价？
- 潜在密度恢复：模型能否还原生成这些价格的真实分布？
论文指出，定价算子在数值上是病态的。在施加质量和远期约束后，126 维的空间中有 95 个方向是数值零空间（Numerical-Null） 。这意味着，两个 L1L^1 距离为 0.061 的不同密度，在覆盖的行权价范围内可以产生机器精度一致的价格。
### 方法拆解：双基准与目标依赖作者没有盲目堆砌新架构，而是设计了严格的对比实验：
- 合成基准：已知真实密度的模拟器，用于评估“潜在误差”。
- NIFTY 实盘基准：时间序列分割的真实交易数据，仅评估“持有期外价格误差”。
对比了四种学习算子（DeepONet, FNO, Quote Transformer, Set Decoder）与经典基线（双对数正态混合模型、正则化离散密度）。
核心发现是： 监督目标决定了性能上限。 使用密度 MSE 作为监督信号，比复合损失函数显著降低 L1L^1 误差（DeepONet 降低 57.3%）。
### 关键结果：没有万能赢家实验数据揭示了“目标依赖的归纳偏置”：

在 NIFTY 实盘测试中，经过测试时适应（Test-time Adaptation）的 DeepONet 将 RMSE 从 0.004833 降至 0.003464（降低 28.3%）。但这依然远逊于逐到期日重新拟合的经典模型（混合模型 RMSE 仅为 0.000166）。
### 工程启示- 明确下游目标：如果你关心的是标准期权定价，经典 SVI 或混合模型更稳、更快、更准。如果你关心的是极端分位数（如 1% VaR），DeepONet 等算子能带来显著优势（误差降低近 40%）。
- 警惕“伪精度”：不要以为神经网络拟合了价格就还原了市场观点。由于逆问题的病态性，模型可能在未观测到的尾部区域产生任意偏差。
- 适应优于零样本：在实盘中，利用测试时数据对预训练算子进行少量梯度步更新（0.138秒/曲面），能显著提升表现，但仍需接受其精度低于局部经典拟合的事实。
### 局限与展望论文承认合成数据的分布假设限制了通用性，且 NIFTY 数据缺乏买卖价差信息。未来方向可能在于结合图神经网络（如 Hexagon-Net）处理不规则报价几何结构，或引入更强的无套利约束投影。
对于工程落地，建议： 将深度学习算子作为“尾部风险探测器”而非“定价引擎” 。用经典模型做日常定价，用学习算子监控分布形状的异常漂移。
