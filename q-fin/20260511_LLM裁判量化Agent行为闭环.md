# LLM裁判量化Agent行为闭环

**日期**: 2026-05-11

---

论文 : Multi-Dimensional Behavioral Evaluation of Agentic Stock Prediction Systems Using LLM Judges with Closed-Loop Reinforcement Learning Feedback链接 : https://arxiv.org/abs/2605.05739传统的量化评估只看结果：夏普比率（Sharpe Ratio）高不高？最大回撤（Maximum Drawdown）大不大？但这就像只看考试成绩，不看解题过程。一个模型可能因为运气好猜对了方向，或者通过错误的逻辑推导出了正确的结论。对于现代基于大语言模型（LLM）的金融智能体（Agentic Systems），这种“黑盒”评估不仅无法诊断故障，更无法指导改进。这篇论文的核心贡献在于：它用 LLM 做裁判，给 Agent 的每一步决策打分，并把评分直接喂回强化学习（RL）回路中，实现了“评估即优化”。
### 痛点：aggregate metrics 的盲区现有的 Stock Prediction Systems 越来越像自主 Agent：它们先检测市场状态（Regime Detection），再路由到不同的预测路径（Routing），最后由强化学习控制器（如 SAC）调整参数。
问题在于，传统的 MAPE 或方向准确率（DA）是聚合指标。如果一个 Agent 在低波动期表现完美，但在高波动期风险失控，聚合指标会掩盖这一缺陷。我们需要知道：是状态检测错了？还是路由选错了？还是风控没跟上？这篇论文提出了 Multi-Dimensional Behavioral Evaluation ，试图回答这些问题。
### 方法拆解：从“打分”到“修正”
#### 1. 行为轨迹与六维评估论文首先定义了结构化行为轨迹（Behavioral Trace），包含市场上下文、自编码器输出、路由决策和 SAC 动作。每 5 天的轨迹组成一个 Episode，由三个 LLM 裁判（GPT-5.4, Claude-4.6 Opus, Gemini-3.1 Pro）独立打分。
评估维度分为两类：
- 架构决策：状态检测（RD）、路由一致性（RT）、适应性（AD）。
- 涌现行为：风险校准（RC）、策略连贯性（SC）、错误恢复（ER）。
#### 2. 扰动验证与因果归因为了证明 LLM 真的看懂了逻辑，而不是瞎猜，作者设计了 Perturbation-based Validation 。例如，故意反转状态标签，看 LLM 是否只降低 RD 分数，而不大幅影响其他分数。
- 结果：目标维度分数下降显著（-1.6 到 -2.4），非目标维度仅轻微下降（平均 -0.32）。
- 意义：这证明了 LLM 具备因果归因能力，能区分“上游错误”和“下游后果”。
#### 3. 闭环奖励整形（Closed-Loop Reward Shaping）
这是最硬核的工程部分。LLM 的评分不是用来写报告的，而是用来修改 SAC 的奖励函数：

- Credit Assignment：不同维度对应不同的 SAC 参数调整空间（如 RD 只改 Δτ\Delta \tau，RT 只改 Δα\Delta \alpha）。
这意味着，如果 LLM 判定“风险校准不足”，它不会惩罚整个模型，而是只惩罚 SAC 中负责风险参数的部分。
### 关键结果：真实提升在 2017-2025 的测试集上，经过 3 个周期的闭环微调，效果显著：
指标 基线 (Base) 优化后 (Cycle 3) 提升幅度 1-day MAPE 0.61% 0.54% ↓ 11.5% (p < 0.001) Directional Accuracy 71% 74% ↑ 3% (p = 0.002) Sharpe Ratio 1.00 (基准) 1.18 ↑ 18% (95% CI [8.2%, 27.4%])
值得注意的是，改进主要集中在 高波动率（High-Volatility） 时期，这正是原系统行为评估中最薄弱的环节。
### 工程启示- LLM 作为可解释的 Reward Model：在传统 RLHF 中，Reward Model 通常是一个小型神经网络。在金融 Agent 中，由于决策链条长且依赖上下文，LLM 作为 Judge 能提供更细粒度的反馈。但要注意，论文指出单模型（GPT-5.4）与三模型 Ensembles 的效果差异不大（MAPE 0.55% vs 0.54%），但 Ensembles 的方差更低（Score var. 0.29 vs 0.41）。工程建议：如果算力允许，使用 Ensembles 提高训练稳定性；如果追求低成本，单模型也可行。
- Credit Assignment 是关键：如果对所有维度使用统一的惩罚（Uniform Credit Assignment），会导致非缺陷维度性能下降（Table VI）。必须将评分映射到具体的参数子空间，避免“误伤”。
- 反馈强度 λ\lambda 的敏感性：λ\lambda 在 [0.10, 0.20] 之间效果最佳。过低（<0.10）导致欠修正，过高（≥0.25）导致 SAC 训练不稳定。这为其他金融 RL 系统提供了超参数调优的参考区间。
### 局限与展望- 离线回测局限：所有结果基于历史数据，未考虑滑点、延迟和市场冲击。
- LLM 的金融专业知识：裁判是通用 LLM，可能错过期权波动率曲面等细微结构。未来可考虑蒸馏为专用小模型以降低延迟和成本。
- 对齐风险：存在 Agent 为了讨好 LLM 评分而牺牲预测精度的理论风险，但在 λ∈[0.10,0.20]\lambda \in [0.10, 0.20][0.10,0.20] 范围内未观察到。
总之，这篇论文展示了一条新路径： 不要只优化结果，要优化过程 。通过 LLM 的结构化行为评估，我们可以让金融 Agent 从“黑盒预测器”进化为“可诊断、可修复”的智能体。
