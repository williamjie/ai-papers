### 为什么传统定价模型失效？
在量化金融中，我们习惯用库存模型（Storage Model）来定价期货： Ft=Ste(r+u−y)TF_t = S_t e^{(r+u-y)T} ​ = S t ​ e ( r + u − y ) T 。但对于算力来说，这个公式直接崩盘。
算力的本质是“服务流”而非“实物库存”。你今天没用的 GPU 小时，无法储存到明天再卖。这使得算力更像电力或航运运力，而不是石油或黄金。论文明确指出，由于算力不可存储（Non-storable），现货价格 StS_t ​ 与期货价格 Ft(T)F_t(T) ​ ( T ) 之间不存在直接的无套利链接。
⚠️ 核心洞察 ：算力的定价锚点不是“今天的现货”，而是“到期日的预期现货”减去“风险溢价”。
### 合成期货与风险溢价既然没有真实的期货历史数据，作者利用 Silicon Data 提供的长期租赁合约（Reserved Rentals）构建了“合成期货”面板。这些合约锁定了未来的算力容量，本质上包含了价格保险和容量锁定期权。
论文通过对比不同 GPU 世代（A100, H100, B200）和期限的合成收益率，发现了一个关键现象： 正的风险溢价（Positive Risk Premium） 。
这意味着什么？
在传统的商品市场中，如果生产商是主要套保者（空头），期货价格通常低于预期现货价格（Contango 结构中的风险溢价部分）。论文推测，算力市场的早期参与者主要是算力提供商（如 Neo-clouds）和大型 AI 开发者。提供商为了锁定收入，倾向于卖出合成期货；而投资者作为多头，需要获得补偿才愿意承担算力价格波动的风险。

### 工程启示：如何构建量化策略？
对于金融科技工程师，这篇论文提供了三个落地方向：
-指数构建的陷阱：
目前的算力指数（如 Silicon Data 和 Ornn）是基于“调查法”聚合的异构价格。论文指出，不同提供商（Hyper-scalers vs Neo-clouds）的价格相关性存在显著差异。Silicon Data 指数与 Ornn 指数甚至出现负相关。
建议：在开发算力因子时，务必区分底层数据源。使用混合数据源可能导致严重的基差风险（Basis Risk）。
-合成期货作为代理变量：
在真实期货上市前，长期租赁合约的收益率曲线可以作为合成期货价格的上界。因为物理租赁合同包含了“容量锁定”的期权价值，这通常高于纯金融期货的价格。
建议：监控 Reserved Rental 曲线的陡峭程度，作为算力供需紧张程度的领先指标。
-风险溢价的方向性交易：
如果正风险溢价假设成立，意味着长期持有合成多头头寸可能获得超额收益（Compensation for risk）。但随着 CME 期货上市，流动性提供者进入，这个溢价可能会收敛。
建议：关注期货-现货价差（Basis）的变化。初期市场可能由套保压力主导，后期转向投机驱动。
### 局限与展望论文坦诚地指出，当前数据存在早期质量问题和成熟度不足。例如，Silicon Data 的早期远期曲线与现货指数记录并未完全协调（Fig. 2 显示前期差异较大）。此外，算力市场的替代性（Substitutability）仍在演变中，路由平台（如 NVIDIA DGX Cloud Lepton）的出现可能会进一步同质化价格，改变现有的相关性结构。
总的来说，这是一篇极具前瞻性的工作。它提醒我们：AI 算力的金融化不是简单的“把芯片当股票炒”，而是一个涉及服务流定价、容量期权和风险转移的复杂系统工程。对于量化团队而言，现在是研究这一新资产类别微观结构的最佳窗口期。
