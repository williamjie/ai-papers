# ⭐⭐⭐⭐ LLM交易基准的防作弊与归因真相

**日期**: 2026-05-28

---

论文 : From Knowing to Doing: A Memory-Controlled Benchmark for LLM Trading Agents on Stock Markets链接 : https://arxiv.org/abs/2605.28359大模型（LLM）炒股是伪命题吗？这篇来自清华与阶跃星辰的 KTD-FIN 基准测试给出了一个残酷但清醒的答案：如果你不控制数据泄露，你测的不是智能，而是记忆力；如果你不做风格归因，你看到的不是 Alpha，而是 Beta。
### 现有方案的致命缺陷目前的 LLM 交易评测主要面临两个“作弊”路径：
- 记忆泄露（Memory Leakage）：回测区间往往与模型预训练截止日期重叠。模型可能直接背诵了历史价格或宏观叙事，而非基于当前数据推理。
- 归因混淆（Attribution Confusion）：累计收益是一个噪声极大的指标。正收益可能来自市场贝塔（Market Beta）或风格暴露（Style Exposure），而非个股选择能力（Stock-Selection Alpha）。
### 方法拆解：双管齐下的清洗机制KTD-FIN 引入了两套核心机制来“去伪存真”：
1. 四级数据遮蔽协议（Data-Side Masking）
这是为了防止模型“开卷考试”。协议定义了四个层级：
- Bright：真实代码 + 真实日期（对照组）。
- Stock-blind：匿名化代码 + 真实日期。
- Date-blind：真实代码 + 相对天数索引。
- Blinded：代码与日期双重匿名化。
关键在于，这种遮蔽是端到端的。即使在工具调用（Tool Use）返回的结果中，真实标识符也会被替换为别名（如 asset_0042 ）。论文通过独立的“十攻击者去匿名化探针”验证了该机制的有效性：在 Blinded 模式下，Ticker Top-1 恢复率仅为 3.0% ，联合恢复率（Ticker Top-5 且日期误差 ±7 天）不超过 1.5% 。这意味着模型几乎无法通过残留特征反推真实股票。
2. Barra 风格归因框架为了解耦收益来源，论文采用截面回归将每日收益分解为：

### 关键结果：记忆驱动交易，风格掩盖无能在 2024-2026 年的沪深 300 成分股回测中，10 个前沿 LLM Agent 的表现揭示了惊人事实：
1. 遮蔽改变了交易逻辑在 memory-only 模式下（仅提供股票代码，无因子数据）：
- Bright 模式：模型产生非平凡交易，收益 -0.16%。分析其理由发现，它依赖品牌叙事（如“防御性蓝筹”）。
- Blinded 模式：模型完全停止交易，现金持有率 100%，收益 0.00%。
这证明，一旦切断代码记忆，缺乏因子推理能力的模型会选择“躺平”。
2. 累计收益 vs. 选股 Alpha在 blinded × open-research 设置下，虽然部分模型实现了正累计收益，但 Barra 归因显示这些收益主要来自风格暴露：

3. LLM 与 ML 的风格差异传统机器学习基线（Alpha9-trained）倾向于低波动、趋势型大盘股；而 LLM Agent 倾向于高波动、近期异动标的（Intraday Momentum Loading +1.06σ）。这种风格偏好导致了更高的换手率和更大的回撤。
### 工程启示- 评测必须隔离记忆：在构建金融 LLM 基准时，简单的 Prompt 限制（“不要使用外部知识”）是无效的。必须在数据层进行匿名化处理，否则你只是在测试模型的预训练数据覆盖率。
- Alpha 归因优于累计收益：在量化系统中，不能仅看 PnL。必须引入类似 Barra 的归因模型，区分策略收益是来自市场 Beta、风格漂移还是真正的个股 Alpha。对于 LLM Agent，目前的结论是：它们擅长捕捉风格趋势，但不具备稳定的个股选股能力。
- 工具调用的价值：在 open-research 模式下，赋予模型主动检索因子数据的能力，显著提升了其相对于无工具基线的表现。这表明 LLM 作为“信息整合者”而非“预测引擎”更具潜力。
### 局限与展望目前 KTD-FIN 仅覆盖 A 股 CSI300，且仅使用价格量价数据（OHLCV），未包含新闻、财报等多模态输入。此外，全网格评估计算成本极高（单模型长窗口需 24-72 小时）。未来需扩展至美股/港股及多模态场景，以验证该结论的普适性。
