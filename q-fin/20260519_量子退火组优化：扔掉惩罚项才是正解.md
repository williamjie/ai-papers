# 量子退火组优化：扔掉惩罚项才是正解

**日期**: 2026-05-19

---

论文 : A Penalty-Free Pipeline for Direct Quantum-Annealer Portfolio Optimization链接 : https://arxiv.org/abs/2605.17628量子计算在金融领域的炒作声浪从未停歇，但真正能跑在硬件上的落地案例却寥寥无几。这篇论文直接泼了一盆冷水，同时也给出了一个极具工程价值的“偏方”：如果你想在 D-Wave 量子退火器上做组合优化， 别再用标准的惩罚项编码了 。作者通过深入剖析逻辑图与硬件拓扑的冲突，证明了一个反直觉的结论：抛弃约束惩罚项（Penalty-Free），转而依靠经典后处理，反而能让量子处理器在中等规模问题上跑得通、跑得稳。
### 为什么标准做法会崩盘？
在量化金融中，我们常把“从 N 个资产中选 K 个”这类基数约束（Cardinality Constraint）问题转化为无约束二进制二次优化（QUBO）。标准做法是引入一个巨大的惩罚系数 AA ，将约束 (∑xi−K)2(\sum x_i - K)^2 ​ − K ) 2 加到目标函数中。
直觉上这很完美，但在量子退火器上，这简直是灾难。论文指出的核心痛点在于： 惩罚项 A11⊤A \mathbf{1}\mathbf{1}^\top 是一个满秩矩阵，它让原本稀疏的逻辑交互图变成了完全图。
无论你的资产协方差矩阵 Σ\Sigma 多么稀疏，加上这个惩罚项后，QUBO 矩阵 QQ 的非对角元素全部非零。这意味着你需要把每个量子比特都连起来。然而，D-Wave 的硬件拓扑（Pegasus 或 Zephyr）是稀疏的。为了嵌入这个完全图，必须进行“次嵌入”（Minor Embedding），导致逻辑变量被映射到长长的量子比特链（Chains）上。
后果是什么？链越长，退火过程中链断裂（Chain Break）的概率就越高。论文数据显示：
- 在 N=24N=2424 的股票组合中，链断裂率高达 83%。
- 在 N=49N=4949 的全市场组合中，链断裂率飙升至 88%-92%。
- 最致命的是，在这些规模下，可行样本率为 0%。也就是说，量子处理器返回的成千上万个解，没有一个满足“恰好选 K 个资产”的条件。
### 尝试修复？稀疏化也不行面对链断裂，工程师的第一反应通常是“稀疏化”（Sparsification）：砍掉 QUBO 矩阵中较小的非对角元素，让图变稀疏，从而缩短链。
论文测试了阈值截断、Top-K 保留等方法。结果发现，虽然链断裂率降到了 0%，但引入了新问题： 约束稀释（Constraint Dilution） 。
当你砍掉非对角元素时，你同时也砍掉了惩罚项的权重。结果量子处理器不再关心“选多少个资产”，返回的原始样本几乎是全 1 向量（选了所有资产）。消融实验进一步揭示，在这种稀疏化+投影的管道中，最终解的质量几乎完全由经典投影器决定，量子处理器本身贡献甚微。
### 正解：无惩罚管道（Penalty-Free Pipeline）
既然惩罚项是密度的根源，也是约束失效的原因，作者提出了一个极其简单的方案： 直接扔掉惩罚项。
- 构建目标 QUBO：只保留 Qobj=−diag(μ)+λΣQ_{obj} = -\text{diag}(\mu) + \lambda \Sigma​=−diag(μ)+λΣ。对于股票，这保留了协方差结构；对于体育博彩，这保留了块对角结构。
- 量子采样：在 D-Wave 上运行这个稀疏的 QUBO。
- 经典后处理：使用贪婪投影（Greedy Projection）强制满足 ∑xi=K\sum x_i = K​=K。如果选多了，剔除边际贡献最小的；选少了，加入边际贡献最大的。
### 关键结果对比这个方法在 D-Wave Advantage 和 Advantage2 硬件上表现惊人：
指标 标准惩罚编码 ( N=49N=49 49 ) 无惩罚管道 ( N=49N=49 49 ) 链断裂率 88% - 92% < 0.04% 可行样本率 0% 100% (经后处理) 后悔度 (Regret) N/A (无可行解) ≤ 0.03% (相对贪婪基线)
在体育博彩案例中，由于协方差天然块对角，无惩罚管道在 N=39N=39 39 和 N=48N=48 48 时，甚至找到了比经典贪婪启发式更低的能量解。而在股票案例中，虽然量子解并未超越经典最优，但其后悔度控制在极低的 0.03% 以内，且完全可行。
### 工程启示与局限这篇论文对金融科技工程师的最大启示是： 不要迷信端到端的量子求解。
- 混合架构是常态：目前的量子退火器更适合处理“稀疏的目标函数评估”，而不是“严格的约束满足”。将约束检查卸载给经典 CPU，利用 QPU 探索解空间，是更务实的路径。
- 关注图结构而非算法复杂度：在量子金融应用中，逻辑图的密度比问题的 NP-Hard 性质更致命。如果你的问题导致完全图，量子加速无从谈起。
- 适用边界：该方法目前仅在 N≤49N \le 4949 的规模上验证。对于大规模组合优化，仍需依赖 D-Wave 的混合求解器（Hybrid Solvers）或经典启发式算法。
总之，如果你正在调研量子金融落地，这篇论文告诉你：先别急着调参，先检查一下你的 QUBO 矩阵是不是被惩罚项填满了。如果是，把它删掉，然后用经典代码补上约束，你可能会发现量子处理器突然“听话”了。
